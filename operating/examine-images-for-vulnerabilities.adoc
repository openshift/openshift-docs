= Examining images for vulnerabilities
:context: examine-images-for-vulnerabilities

toc::[]

[role="_abstract"]
As a security administrator or cluster operator, you can analyze images for vulnerabilities with {product-title} ({product-title-short}) to find and remediate vulnerable components before they reach production.

Use the {product-title-short} Scanner V4 to scan images, or configure an integration to use another supported scanner.
