= Helm CLI
:context: helm-cli

toc::[]

[role="_abstract"]
Helm is a package manager for Kubernetes. You use the `helm` CLI to install, upgrade, and manage Helm charts on your {product-title} cluster.

To install the Helm CLI, see "Installing Helm." To find the Helm CLI version that matches your cluster, see "Helm CLI for Red Hat OpenShift compatibility matrix."

You can also work with Helm charts and releases in the {product-title} web console. For more information, see "Understanding Helm."
