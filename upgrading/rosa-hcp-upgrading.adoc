= Upgrade a cluster
:context: rosa-hcp-upgrading

toc::[]

[role="_abstract"]
{product-title} provides independent upgrade lanes for the hosted control plane and individual machine pools. This decoupled upgrade strategy allows you to update control plane components without impacting your running application workloads.

You can upgrade the hosted control plane first to unlock new platform features, then schedule updates for individual machine pools. All upgrades can be scheduled either immediately, or at a specified future time.

In {product-title}, updating provisions a new component with updated software and uses it to replace an existing component that has outdated software.
