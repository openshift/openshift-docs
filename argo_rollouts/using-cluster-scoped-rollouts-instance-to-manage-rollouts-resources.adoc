= Cluster-scoped Argo Rollouts
:context: using-cluster-scoped-argo-rollouts-instance-to-manage-rollouts-resources

toc::[]

[role="_abstract"]
Cluster-scoped installation mode allows a single Argo Rollouts controller instance to manage rollout resources across multiple namespaces, reducing resource consumption compared to deploying separate namespace-scoped controllers.

[id="prerequisites_{context}"]
== Prerequisites
* You have logged in to the {OCP} cluster as an administrator.
* You have installed the {gitops-title} Operator on your {OCP} cluster.
* You have created a `RolloutManager` custom resource in the namespace where you want to run the Argo Rollouts controller.
