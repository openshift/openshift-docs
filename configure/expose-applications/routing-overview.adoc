= Control how your application is reached
:context: routing-overview

[role="_abstract"]
When you create a Knative service, an {ocp-product-title} route is automatically created and managed by the {ServerlessOperatorName}, which exposes the service through the same domain as the {ocp-product-title} cluster.

Knative leverages {ocp-product-title} TLS termination to provide routing for Knative services.

You can disable Operator control of {ocp-product-title} routing so that you can configure a Knative route to directly use your TLS certificates instead.

Knative routes can also be used alongside the {ocp-product-title} route to provide additional fine-grained routing capabilities, such as traffic splitting.
