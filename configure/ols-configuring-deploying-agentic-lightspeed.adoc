= Configure and deploy Agentic {ols-long}
include::_attributes/common-attributes.adoc[]
:context: ols-configuring-deploying-agentic-lightspeed

toc::[]

[role="_abstract"]
After you install the {ols-long} Operator, configure and deploy Agentic {ols-long} to enable autonomous, tool-calling AI assistance in your {ocp-product-title} cluster. Agentic {ols-long} connects to a large language model (LLM) provider and runs multi-step agentic workflows against your cluster.

[IMPORTANT]
====
Agentic {ols-long} is available in the {ols-long} 2.0 release stream. The configuration in this document applies to {ols-long} 2.0 and later versions.
====

[NOTE]
====
The instructions assume that you are configuring Agentic {ols-long} using the `kubeadmin` user account. If you are using a regular user account with `cluster-admin` privileges, read the section of the documentation that discusses Role-Based Access Control (RBAC).
====

To configure Agentic {ols-long}, you create a credentials secret for your LLM provider, an `LLMProvider` custom resource (CR) that defines the provider connection, and an `Agent` CR that pairs the provider with a model. You then verify that the deployment is operating.
