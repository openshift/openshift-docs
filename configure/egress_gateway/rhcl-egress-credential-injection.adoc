= Inject credentials into egress requests
:context: rhcl-egress-credential-injection

toc::[]

[role="_abstract"]
You can use an `AuthPolicy` custom resource (CR) with an egress gateway to inject credentials into requests to external services. This guide demonstrates credential injection by using HashiCorp Vault as the credential source.
