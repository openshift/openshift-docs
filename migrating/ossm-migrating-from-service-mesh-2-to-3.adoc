= Migrating from Service Mesh 2 to Service Mesh 3
include::_attributes/common-attributes.adoc[]
:context: ossm-migrating-from-service-mesh-2-to-3

toc::[]

[role="_abstract"]

Upgrade {SMProduct} 2.6 by following a guided migration path that includes pre-migration readiness checks, workload relocation strategies, and best practices for maintaining service availability throughout the upgrade process.

[IMPORTANT]
====
Red Hat no longer supports OpenShift Service Mesh 3.0. Instead, migrate to version 3.1. Refer to the migration guide in the OpenShift Service Mesh 3.1 documentation.
====
