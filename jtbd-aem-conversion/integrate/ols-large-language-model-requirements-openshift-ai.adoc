= {rhoai} requirements

[role="_abstract"]
{ols-long} supports {rhoai} as a self-hosted large language model (LLM) provider.

The {ols-long} Service does not provide the LLM for you, so you must configure the LLM before installing the {ols-long} Operator.

[NOTE]
====
Red{nbsp}Hat does not provide support for any specific models or make suggestions or support statements pertaining to models.
====

{rhoai} is OpenAI API-compatible, and you configure {rhoai} largely the same as the OpenAI provider.

You must deploy the LLM on the {rhoai} single-model serving platform that uses the virtual large language model (vLLM) runtime. If the model deployment runs in a different {ocp-short-name} environment than the {ols-long} deployment, include a route to expose the model deployment outside the cluster.

{ols-long} version 1.0 and later supports vLLM Server version 0.8.4 and later. When self-hosting the LLM with {rhoai}, you can use vLLM Server as the inference engine.
