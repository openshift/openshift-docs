= Creating the {watsonx} credentials secret by using the web console

[role="_abstract"]
Use the {ocp-product-title} web console to store the API token that {ols-long} uses to authenticate with {watsonx}.

.Prerequisites

* You have logged in to the {ocp-product-title} web console as a user with the `cluster-admin` role. As another option, you can log in to a user account that has permission to create a secret to store the Provider tokens.

* You have installed the {ols-long} Operator.

.Procedure

. Click the *Quick create* (image:fa-plus-circle.png[title="Quick create menu"]) menu in the upper-right corner of the {ocp-short-name} web console and select *Import YAML*.

. Paste the following YAML content into the text area of the web console.
+
[NOTE]
====
The YAML parameter is always `apitoken` regardless of what the LLM provider calls the access details.
====
+
[source,yaml]
----
apiVersion: v1
kind: Secret
metadata:
  name: watsonx-api-keys
  namespace: openshift-lightspeed
type: Opaque
stringData:
  apitoken: <api_token>
----
+
* `stringData.apitoken` represents the API token, and is not `base64` encoded.

. Click *Create*.
