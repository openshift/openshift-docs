= Configure support for trusted-ca certificates with AWS Bedrock

[role="_abstract"]
Configure custom TLS certificates to secure communication between {ols-long} and {aws-short} Bedrock service endpoints.

The {ols-long} Service supports custom TLS certificates for secure communication with {aws-short} Bedrock.

.Procedure

. Create a `ConfigMap` object that contains the certificates.
. Add the name of the object in the `OLSConfig` custom resource (CR) file:
+
[source,yaml]
----
ols:
  additionalCAConfigMapRef:
    name: <config_map_name>
----
+
where
+
`<config_map_name>`:: Enter the name of your `ConfigMap` object.
