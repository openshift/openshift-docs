= Creating the Google Vertex AI credentials secret by using the web console

[role="_abstract"]
Use the {ocp-product-title} web console to store the GCP service account credentials that {ols-long} uses to authenticate with Google Vertex AI.

.Prerequisites

* You have logged in to the {ocp-product-title} web console as a user with the `cluster-admin` role. As another option, you can log in to a user account that has permission to create a secret to store the Provider tokens.

* You have installed the {ols-long} Operator.

* You must possess a valid GCP service account JSON key file.

* The Vertex AI API must be enabled in your Google Cloud project.

* Your GCP service account must have appropriate Vertex AI permissions.

.Procedure

. Click the *Quick create* (image:fa-plus-circle.png[title="Quick create menu"]) menu in the upper-right corner of the {ocp-short-name} web console and select *Import YAML*.

. Paste the following YAML content into the text area of the web console.
+
[source,yaml]
----
apiVersion: v1
kind: Secret
metadata:
  name: llmcreds
  namespace: openshift-lightspeed
type: Opaque
stringData:
  gcp-service-account.json: <service_account_key_json>
----
+
[NOTE]
====
The Operator looks for a key named `apitoken` by default if you omit the `credentialKey` field later.
====

. Click *Create*.
