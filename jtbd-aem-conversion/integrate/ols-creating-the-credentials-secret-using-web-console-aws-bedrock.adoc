= Creating the AWS Bedrock credentials secret by using the web console

[role="_abstract"]
Use the {ocp-product-title} web console to store the credentials that {ols-long} uses to authenticate with {aws-short} Bedrock.

{aws-short} Bedrock supports multiple authentication methods: Bearer token, IAM keys, and IAM keys with STS role assumption.

.Prerequisites

* You have logged in to the {ocp-product-title} web console as a user with the `cluster-admin` role. As another option, you can log in to a user account that has permission to create a secret to store the Provider tokens.

* You have installed the {ols-long} Operator.

* You have an {aws-short} infrastructure account with active permission to access your required models.

.Procedure

. Click the *Quick create* (image:fa-plus-circle.png[title="Quick create menu"]) menu in the upper-right corner of the {ocp-short-name} web console and select *Import YAML*.

. Paste the following YAML content into the text area of the web console.
+
Use the following example to create the Secret using a Bearer token:
+
[source,yaml]
----
apiVersion: v1
kind: Secret
metadata:
  name: bedrock-credentials
  namespace: openshift-lightspeed
type: Opaque
stringData:
  apitoken: <mantle-bearer-token>
----

. Optional: As another option, you can use {aws-short} IAM keys to authenticate your LLM provider. Use the following example to authenticate by using IAM keys:
+
[source,yaml]
----
apiVersion: v1
kind: Secret
metadata:
  name: bedrock-credentials
  namespace: openshift-lightspeed
type: Opaque
stringData:
  aws_access_key_id: <aws-access-key-id>
  aws_secret_access_key: <aws-secret-access-key>
----

. Optional: If your primary access keys must assume a specific role to call {aws-short} Bedrock, use IAM keys with STS role assumption. Use the following example:
+
[source,yaml]
----
apiVersion: v1
kind: Secret
metadata:
  name: bedrock-credentials
  namespace: openshift-lightspeed
type: Opaque
stringData:
  aws_access_key_id: <aws-access-key-id>
  aws_secret_access_key: <aws-secret-access-key>
  role_arn: arn:aws:iam::123456789012:role/BedrockAccessRole
----

. Click *Create*.
