= Creating the {ols-long} custom resource file for {azure-openai} by using the web console

[role="_abstract"]
Use the {ocp-product-title} web console to create the custom resource (CR) file required to deploy {ols-long} with your {azure-openai} provider.

.Prerequisites

* You have logged in to the {ocp-product-title} web console as a user with the `cluster-admin` role. As another option, you have logged in to a user account that has permission to create a cluster-scoped CR file.

* You have an {azure-openai} provider available for use with the {ols-long} Service.

* You have installed the {ols-long} Operator.

.Procedure

. Click the *Quick create* (image:fa-plus-circle.png[title="Quick create menu"]) menu in the upper-right corner of the {ocp-short-name} web console and select *Import YAML*.

. Paste the following YAML content into the text area of the web console.
+
Use the following example to create the `OLSConfig` CR to configure {ols-long} with your {azure-openai} provider:
+
[source,yaml]
----
apiVersion: ols.openshift.io/v1alpha1
kind: OLSConfig
metadata:
  name: cluster
spec:
  llm:
    providers:
      - credentialsSecretRef:
          name: azure-api-keys
        apiVersion: <api_version_for_azure_model>
        deploymentName: <azure_ai_deployment_name>
        models:
        - name: <model_name>
        name: myAzure
        type: azure_openai
        url: <azure_ai_deployment_url>
  ols:
    defaultModel: <model_name>
    defaultProvider: myAzure
----

. Click *Create*.
