= AWS Bedrock requirements

[role="_abstract"]
{ols-long} supports {aws-short} Bedrock as a large language model (LLM) provider.

The {ols-long} Service does not provide the LLM for you, so you must configure the LLM before installing the {ols-long} Operator.

[NOTE]
====
For {aws-short} Bedrock, the only tested models are Anthropic and DeepSeek. Other models, such as Meta, Amazon, and Mistral, may work but are not tested. If you require additional models, you can test them. If they do not work, you must open a request for enhancement (RFE) for {ols-long}.
====

To use {aws-short} Bedrock with {ols-official}, you need an {aws-short} infrastructure account with active permission to access your required models.
