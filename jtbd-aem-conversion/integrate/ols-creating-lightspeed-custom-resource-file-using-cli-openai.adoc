= Creating the {ols-long} custom resource file for OpenAI by using the CLI

[role="_abstract"]
Use the command line interface to create the custom resource (CR) file required to deploy {ols-long} with your {openai} provider.

.Prerequisites

* You have access to the {oc-first} and have logged in as a user with the `cluster-admin` role. As another option, you have logged in to a user account that has permission to create a cluster-scoped CR file.

* You have an {openai} provider available for use with the {ols-long} Service.

* You have installed the {ols-long} Operator.

.Procedure

. Create an `OLSConfig` file that has the YAML content for your {openai} provider.
+
Use the following example to create the `OLSConfig` CR to configure {ols-long} with your OpenAI provider:
+
[source,yaml]
----
apiVersion: ols.openshift.io/v1alpha1
kind: OLSConfig
metadata:
  name: cluster
spec:
  llm:
    providers:
      - name: myOpenai
        type: openai
        credentialsSecretRef:
          name: credentials
        url: https://api.openai.com/v1
        models:
          - name: <model_name>
  ols:
    defaultModel: <model_name>
    defaultProvider: myOpenai
----

. Run the following command so that the Operator deploys {ols-long} using the information in the YAML configuration file.
+
[source,terminal]
----
$ oc create -f /path/to/config-cr.yaml
----
