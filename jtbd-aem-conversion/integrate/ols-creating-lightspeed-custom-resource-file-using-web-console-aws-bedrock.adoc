= Creating the {ols-long} custom resource file for AWS Bedrock by using the web console

[role="_abstract"]
Use the {ocp-product-title} web console to create the custom resource (CR) file required to deploy {ols-long} with your {aws-short} Bedrock provider.

.Prerequisites

* You have logged in to the {ocp-product-title} web console as a user with the `cluster-admin` role. As another option, you have logged in to a user account that has permission to create a cluster-scoped CR file.

* You have an {aws-short} Bedrock provider available for use with the {ols-long} Service.

* You have installed the {ols-long} Operator.

* You have created the credentials secret for your {aws-short} Bedrock provider.

.Procedure

. Click the *Quick create* (image:fa-plus-circle.png[title="Quick create menu"]) menu in the upper-right corner of the {ocp-short-name} web console and select *Import YAML*.

. Paste the following YAML content into the text area of the web console.
+
Use the following example to create the `OLSConfig` CR to configure {ols-long} with your {aws-short} Bedrock provider:
+
[source,yaml]
----
apiVersion: ols.openshift.io/v1alpha1
kind: OLSConfig
metadata:
  name: cluster
spec:
  llm:
    providers:
      - credentialsSecretRef:
          name: bedrock-credentials
        models:
        - name: anthropic.claude-opus-4-7
        - name: deepseek.v3.1
        name: bedrock
        type: bedrock
        url: https://bedrock-mantle.us-east-1.api.aws
  ols:
    defaultModel: anthropic.claude-opus-4-7
    defaultProvider: bedrock
----

. Click *Create*.
