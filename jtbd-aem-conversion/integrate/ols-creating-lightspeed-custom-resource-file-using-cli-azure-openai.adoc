= Creating the {ols-long} custom resource file for {azure-openai} by using the CLI

[role="_abstract"]
Use the command line interface to create the custom resource (CR) file required to deploy {ols-long} with your {azure-openai} provider.

.Prerequisites

* You have access to the {oc-first} and have logged in as a user with the `cluster-admin` role. As another option, you have logged in to a user account that has permission to create a cluster-scoped CR file.

* You have an {azure-openai} provider available for use with the {ols-long} Service.

* You have installed the {ols-long} Operator.

.Procedure

. Create an `OLSConfig` file that has the YAML content for your {azure-openai} provider.
+
Use the following example to create the `OLSConfig` CR to configure {ols-long} with your {azure-openai} provider:
+
[source,yaml]
----
apiVersion: ols.openshift.io/v1alpha1
kind: OLSConfig
metadata:
  name: cluster
spec:
  llm:
    providers:
      - credentialsSecretRef:
          name: azure-api-keys
        apiVersion: <api_version_for_azure_model>
        deploymentName: <azure_ai_deployment_name>
        models:
        - name: <model_name>
        name: myAzure
        type: azure_openai
        url: <azure_ai_deployment_url>
  ols:
    defaultModel: <model_name>
    defaultProvider: myAzure
----

. Run the following command so that the Operator deploys {ols-long} using the information in the YAML configuration file.
+
[source,terminal]
----
$ oc create -f /path/to/config-cr.yaml
----
