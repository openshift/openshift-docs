= {ols-long} version 1.1.4

[role="_abstract"]
{ols-official} 1.1.4 addresses security vulnerabilities, adds enhancements, and improves stability. This release helps ensure continued support and stability for clusters running {ocp-product-title} 4.16 and later.

[id="ols-1-1-4-enhancements_{context}"]
== Enhancements

[role="_abstract"]
{ols-official} 1.1.4 updates the Red Hat Offline Knowledge Portal (RHOKP) that provides {ocp-product-title} documentation for retrieval-augmented generation (RAG) and updates how the {ocp-product-title} Model Context Protocol (MCP) server is delivered.

{ols-official} 1.1.4 includes the following enhancements:

//No associated ticket
* With this update, {ols-long} includes Red Hat Offline Knowledge Portal (RHOKP) 1.2.12, which refreshes the {ocp-product-title} product documentation in the RAG knowledge base and expands coverage to the latest seven {ocp-product-title} versions. For more information, see link:https://access.redhat.com/errata/RHBA-2026:62194[RHBA-2026:62194].

//OLS-3303
* With this update, {ols-long} delivers the {ocp-product-title} Model Context Protocol (MCP) server by using the image published by the OpenShift MCP team. As a result, you receive the latest MCP server updates through {ols-official}.
