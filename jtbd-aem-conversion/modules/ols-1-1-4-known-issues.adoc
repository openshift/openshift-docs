= Known issues

[role="_abstract"]
{ols-official} 1.1.4 contains a known issue where questions that require the `get_alerts` tool time out.

//OLS-4353
* *Questions that require the `get_alerts` tool time out*
+
Any question that requires the `get_alerts` tool times out and does not return a response. This issue does not affect test or evaluation workflows.
+
Workaround: There is currently no workaround for this issue.
