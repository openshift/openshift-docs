= Choose a LokiStack storage backend

:context: choose-lokistack-storage-backend

toc::[]

[role="_abstract"]
If you chose Scenario 2 (Vector + Loki) or Scenario 3 (Vector + Loki + COO), you must select and plan for an S3-compatible object storage backend before installation. LokiStack stores all log data in object storage.

[IMPORTANT]
====
This planning topic covers **object storage** selection and requirements. This is separate from the **block storage** (StorageClass) requirement that applies to all scenarios.

Both storage types are mandatory for Loki deployments:

* **Block storage (StorageClass):** For LokiStack internal PVCs (ingesters, compactor)
* **Object storage (S3-compatible):** For actual log chunks and indices

Plan for both before proceeding to installation.
====
