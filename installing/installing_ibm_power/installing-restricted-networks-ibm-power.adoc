= Installing a cluster on {ibm-power-title} in a disconnected environment
:context: installing-restricted-networks-ibm-power

toc::[]

[role="_abstract"]
You can install {product-title} on {ibm-power-name} infrastructure that you provision in a disconnected environment by mirroring the required release images to an internal registry and then running the installation program.

[IMPORTANT]
====
Additional considerations exist for non-bare metal platforms. Review the guidelines for deploying {product-title} on non-tested platforms before you install an {product-title} cluster.
====
