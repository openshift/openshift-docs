= Installing a cluster on Google Cloud Dedicated
:context: installing-gcp-dedicated

toc::[]

[role="_abstract"]
You can install {product-title} on Google Cloud Dedicated (GCD), a sovereign cloud platform that provides {gcp-short} technology in a fully isolated environment with strict data and operational sovereignty guarantees.

To configure the sovereign cloud region, you modify parameters in the `install-config.yaml` file before you install the cluster.
