= Installing {product-title} on Google Cloud Dedicated
:context: installing-gcp-dedicated

toc::[]

You can install {product-title} on Google Cloud Dedicated sovereign cloud regions by using installer-provisioned infrastructure. Google Cloud Dedicated provides physically isolated infrastructure operated by independent local partners, enabling regulated-industry customers to meet data residency and operational sovereignty mandates.

This installation workflow follows the standard {gcp-short} installer-provisioned infrastructure process with sovereignty-specific configuration parameters and constraints, including private-cluster-only networking and `hyperdisk-balanced` storage.

== Prerequisites

* You reviewed details about the xref:../../architecture/architecture-installation.adoc#architecture-installation[{product-title} installation and update] processes.
* You read the documentation on xref:../../installing/overview/installing-preparing.adoc#installing-preparing[selecting a cluster installation method and preparing it for users].
* You have a Google Cloud Dedicated project with a domain-scoped project ID.
* You have obtained a service account credential file from the sovereign universe that includes the `universe_domain` field for your Google Cloud Dedicated region.
* You have set the `GOOGLE_CLOUD_UNIVERSE_DOMAIN` environment variable to the universe domain for your Google Cloud Dedicated region, for example `apis-berlin-build0.goog`.
* You have set the `GOOGLE_APPLICATION_CREDENTIALS` environment variable to the path of your Google Cloud Dedicated credential file.
* You have prepared a custom {op-system} image accessible within your Google Cloud Dedicated project.
* You have configured network connectivity (VPN or Cloud Interconnect) to the Google Cloud Dedicated environment for private cluster access.
* If you use a firewall, you xref:../../installing/install_config/configuring-firewall.adoc#configuring-firewall-module_configuring-firewall[configured it to allow the sites] that your cluster requires access to, including the Google Cloud Dedicated API endpoints for your region.
