= Installing Central services for RHACS on other platforms
:context: install-central-other

toc::[]

[role="_abstract"]
Central handles data persistence, API interactions, and {product-title-short} portal access. You can install Central services on other platforms by using Helm charts or by using the `roxctl` CLI.
