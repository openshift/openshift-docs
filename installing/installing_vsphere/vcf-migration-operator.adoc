= Migrate an OpenShift cluster to VCF9 or VVF9
include::_attributes/common-attributes.adoc[]
:context: vcf-migration-operator

toc::[]

[role="_abstract"]
You can use the VCF Migration Operator to migrate an {product-title} cluster from one {vmw-short} vCenter to another without reinstalling the cluster.
The operator supports migrating clusters from {vmw-short} 7.x, {vmw-short} 8.x, VCF 4.x, or VCF 5.x to VMware Cloud Foundation 9 (VCF9) or VMware vSphere Foundation 9 (VVF9).
The migration preserves running workloads and cluster state by migrating nodes one by one.
