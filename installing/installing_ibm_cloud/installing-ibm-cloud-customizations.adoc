= Installing a cluster on {ibm-cloud-title} with customizations
:context: installing-ibm-cloud-customizations

toc::[]

[role="_abstract"]
In {product-title} version {product-version}, you can install a customized cluster on {ibm-cloud-name} by using installer-provisioned infrastructure. Change parameters in the `install-config.yaml` file before you install the cluster.

By customizing your network configuration, your cluster can coexist with existing IP address allocations in your environment and integrate with existing MTU and VXLAN configurations.

You must set most of the network configuration parameters during installation, and you can change only `kubeProxy` configuration parameters in a running cluster.
