= Migrating existing {product-title-short} deployments to Operator management
include::modules/common-attributes.adoc[]
:context: migrate-to-operator

toc::[]

[role="_abstract"]

The installation by Helm chart and `roxctl` CLI (manifest) installation methods are deprecated and will be removed in the future. After those methods are removed, to upgrade existing deployments that were installed by using these methods, you must migrate existing deployments to Operator management or uninstall the existing installation and reinstall {product-title-short}. 

For the best results, Red Hat recommends uninstalling the existing installation and re-installing {product-title-short} by using the Operator. However, this course of action results in downtime and loss of data from Central. If you choose this method, you can still use the `migrate-to-operator` commands to to prepare custom resources for migration.
