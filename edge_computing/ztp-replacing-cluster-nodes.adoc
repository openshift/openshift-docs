= Replacing managed cluster nodes with ClusterInstance resources
include::_attributes/common-attributes.adoc[]
:context: ztp-replacing-cluster-nodes

toc::[]

[role="_abstract"]
You can replace failed control plane nodes and add compute nodes on a GitOps-managed {product-title} cluster by editing the `ClusterInstance` custom resource (CR).
The SiteConfig Operator applies the change and the Assisted Installer provisions the host again.
