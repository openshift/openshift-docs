= Installing Helm
include::_attributes/common-attributes.adoc[]
:context: installing-helm

toc::[]

[role="_abstract"]
Install the Helm CLI to manage software packages on your {product-title} cluster from a local workstation.

In {product-title} 4.22, you can use the Helm v3 CLI or the Helm v4 CLI. You can keep using the Helm v3 CLI in {product-title} 5.0, but you must move to Helm v4 before you upgrade to a later {product-title} release.

You can find the URL to the latest binaries in the {product-title} web console by clicking the help icon (*?*) and selecting *Command Line Tools*.

Replace `<version>` in the curl commands with a Helm version that is compatible with your {product-title} cluster version. Use the exact version folder name from the Helm CLI download directory. To find a compatible version, and for information about moving from Helm v3 to Helm v4, see the Red Hat Knowledgebase article "Helm CLI for Red Hat OpenShift compatibility matrix."

The following are the procedures to install the Helm CLI on Linux, Windows, and macOS. Complete the procedure for your operating system.

== On Linux

. Download the Helm binary by running the command for your system architecture:

* Linux (x86_64, amd64)
+
[source,terminal]
----
# curl -L https://mirror.openshift.com/pub/cgw/helm/<version>/helm-linux-amd64 -o /usr/local/bin/helm
----

* Linux on {ibm-z-name} and {ibm-linuxone-name} (s390x)
+
[source,terminal]
----
# curl -L https://mirror.openshift.com/pub/cgw/helm/<version>/helm-linux-s390x -o /usr/local/bin/helm
----

* Linux on {ibm-power-name} (ppc64le)
+
[source,terminal]
----
# curl -L https://mirror.openshift.com/pub/cgw/helm/<version>/helm-linux-ppc64le -o /usr/local/bin/helm
----

* Linux on ARM (arm64)
+
[source,terminal]
----
# curl -L https://mirror.openshift.com/pub/cgw/helm/<version>/helm-linux-arm64 -o /usr/local/bin/helm
----

. Make the binary file executable:
+
[source,terminal]
----
# chmod +x /usr/local/bin/helm
----

. Check the installed version:
+
[source,terminal]
----
$ helm version
----
+
.Example output
[source,terminal]
----
version.BuildInfo{Version:"v3.0", GitCommit:"b31719aab7963acf4887a1c1e6d5e53378e34d93", GitTreeState:"clean", GoVersion:"go1.13.4"}
----

== On Windows

. Go to the Helm CLI download directory, open the folder for your Helm version, and download `helm-windows-amd64.exe`.
. Click *Search* and type `env` or `environment`.
. Select *Edit environment variables for your account*.
. Select *Path* from the *Variable* section and click *Edit*.
. Click *New* and type the path to the directory with the exe file into the field or click *Browse* and select the directory, and click *OK*.

$ helm version
