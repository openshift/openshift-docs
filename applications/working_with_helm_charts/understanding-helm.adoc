= Understanding Helm

:context: understanding-helm

toc::[]

[role="_abstract"]
Helm is a software package manager that simplifies deployment of applications and services to {product-title} clusters.

Helm uses a packaging format called _charts_.
A Helm chart is a collection of files that describes the {product-title} resources.

Installing a chart in a cluster creates a running instance of the chart, called a _release_.

Each time you install a chart, or upgrade or roll back a release, Helm creates a revision of the release.

{product-title} supports the following ways to work with Helm:

* The Helm CLI, a Red Hat build of the `helm` command-line tool that you install on your workstation.
* The web console, where you can browse, install, and manage Helm charts and releases from your web browser.

== Key features

With Helm, you can:

* Search for charts in chart repositories.
* Install a chart to create a release.
* Upgrade a release, roll it back to an earlier revision, or delete it.
* Create your own charts with {product-title} or Kubernetes resources, and package and share them.

== Red Hat Certification of Helm charts for OpenShift

You can have Red Hat certify your Helm charts for all components you deploy on {product-title}. Charts go through an automated Red Hat OpenShift certification workflow that checks security compliance and integration with the platform. Certification assures chart integrity and confirms that your Helm chart works on Red Hat OpenShift clusters.
