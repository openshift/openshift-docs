[WARNING]
====
To prevent privilege escalation, assign a service account with minimum required permissions to the Operator group.

If no service account is specified, Operator Lifecycle Manager (OLM) installs the Operator using the default cluster-scoped permissions.

For more information, see link:https://access.redhat.com/articles/7149230[Audit and secure delegated Operator installations (Red Hat Knowledgebase)].
====
