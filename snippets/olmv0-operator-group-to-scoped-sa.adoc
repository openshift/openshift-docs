[WARNING]
====
To limit the permissions OLM uses during Operator installation and upgrades, assign a service account with the minimum required permissions to the Operator group. OLM still creates `APIService` and `CustomResourceDefinition` resources with `cluster-admin` privileges.

If no service account is specified, {olmv0-first} installs the Operator using the default cluster-scoped permissions.

For more information, see link:https://access.redhat.com/articles/7149230[Audit and secure delegated Operator installations (Red Hat Knowledgebase)].
====
