[WARNING]
====
Failed Operator installations do not automatically remove created permissions. Audit the Operator service account for remaining role bindings and cluster role bindings. Delete the bindings created by the failed installation. After you delete a binding, verify that OLM did not re-create it.

For more information, see link:https://access.redhat.com/articles/7149230[Audit and secure delegated Operator installations (Red Hat Knowledgebase)].
====
