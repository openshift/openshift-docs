[NOTE]
====
The `m7i` instance type is not available in every AWS region. In regions where `m7i` is not offered, you must specify a supported instance type when you create a cluster or cluster creation fails. For a complete list of supported regions, see link:https://docs.aws.amazon.com/ec2/latest/instancetypes/ec2-instance-regions.html[_Amazon EC2 instance types by Region_].
