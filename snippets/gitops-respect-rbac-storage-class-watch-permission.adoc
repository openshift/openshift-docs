[NOTE]
====
{OCP}'s basic-user role gives the Argo CD controller service account read-only (`get`/`list`) access to storage classes by default, but not `watch` permissions. If your custom ClusterRole does not add `watch` for this resource, you might see errors such as:

`storageclasses.storage.k8s.io is forbidden: ... cannot watch resource "storageclasses"`

To resolve this error, add `watch` to your ClusterRole's permissions for storage classes:

[source,yaml]
----
- apiGroups: ["storage.k8s.io"]
  resources: ["storageclasses"]
  verbs: ["get", "list", "watch"]
----
