[IMPORTANT]
====
When using the Gateway API custom resource definitions (CRDs) provided in {ocp} 4.19 or newer, you must create a `GatewayClass` named `openshift-default` and specify a `controllerName` of `openshift.io/gateway-controller/v1`. For more details, see "Getting started with Gateway API for the Ingress Operator" in the {ocp} documentation.
====
