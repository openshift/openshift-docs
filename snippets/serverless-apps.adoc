Serverless applications are created and deployed as Kubernetes services, defined by a route and a configuration, and contained in a YAML file. To deploy a serverless application by using {ServerlessProductName}, you must create a Knative `Service` object.

.Example Knative `Service` object YAML file
[source,yaml]
----
apiVersion: serving.knative.dev/v1
kind: Service
metadata:
  name: showcase
  namespace: default
spec:
  template:
    spec:
      containers:
        - image: quay.io/openshift-knative/showcase
          env:
            - name: GREET
              value: Ciao
----

In this example:

`metadata.name`:: The name of the application.
`metadata.namespace`:: The namespace the application uses.
`spec.template.spec.containers.image`:: The image of the application.
`spec.template.spec.containers.env`:: The environment variable printed out by the sample application.
