[IMPORTANT]
====
Set the `endpoint` field to the object storage service URL only. Do not include the bucket name in the endpoint. Specify the bucket name in the `bucketnames` field.

*Correct format:* `endpoint: https://s3.eu-central-1.amazonaws.com`

*Incorrect format:* `endpoint: https://s3.eu-central-1.amazonaws.com/<bucket-name>`
====
