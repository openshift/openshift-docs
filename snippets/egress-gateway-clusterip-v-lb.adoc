[IMPORTANT]
====
The egress `Gateway` object examples use the `networking.istio.io/service-type: ClusterIP` annotation because egress traffic originates inside the cluster. If workloads outside the cluster need to reach the egress `Gateway` object, set the same annotation to `LoadBalancer` instead.
====
