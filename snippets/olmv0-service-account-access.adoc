Users who can obtain an Operator service account token can use the permissions granted to that account. Creating workloads in the installation namespace can also give users access to Operator service account permissions.

Failed installations can leave previously created permissions in place, even if the Operator never runs. After a failed installation, inspect the Operator service account for remaining cluster role bindings. Delete the `ClusterRoleBinding` objects created by the failed installation. For more information, see link:https://access.redhat.com/articles/7149230[Audit and secure delegated Operator installations (Red Hat Knowledgebase)].
