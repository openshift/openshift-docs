= Understanding the External DNS Operator
include::_attributes/common-attributes.adoc[]
:context: external-dns-operator

toc::[]

[role="_abstract"]
The External DNS Operator deploys and manages `ExternalDNS` to provide the name resolution for services and routes from the external DNS provider to {product-title}.

The External DNS Operator follows semantic versioning and a branch-based release model that aligns the External DNS Operator releases with specific {product-title} versions. For more information about versioning, see "OpenShift Operator Life Cycles".

To view release notes for the External DNS Operator, see "External DNS Operator release notes".
