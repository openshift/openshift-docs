= Uninstalling a containerized eBPF program
include::_attributes/common-attributes.adoc[]
:context: bpfman-operator-uninstall

toc::[]

[role="_abstract"]
As a cluster administrator, you can uninstall a containerized eBPF application without uninstalling the eBPF Manager Operator. Delete the userspace workload and the custom resource that loaded the bytecode so that the Operator detaches and unloads the programs.
