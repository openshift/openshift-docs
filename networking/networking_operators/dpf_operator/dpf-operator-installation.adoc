[role="_abstract"]
After setting up the environment, install the NVIDIA DPF Operator and create the required DPF resources and DPU services.

[IMPORTANT]
====
You must install the DPF Operator before the DPF HCP Provisioner Operator (`dpf-hcp-provisioner-operator`) because that Operator requires DPF CRDs such as `DPUCluster`, `DPUFlavor`, `DPUDeployment`, and `DPFOperatorConfig`.
====
