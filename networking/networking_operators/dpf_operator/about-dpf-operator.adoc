= About the NVIDIA DPF Operator
include::_attributes/common-attributes.adoc[]
:context: about-dpf-operator
:dpf-version: 26.4.1

toc::[]

[role="_abstract"]
The NVIDIA DOCA Platform Framework (DPF) Operator enables hardware-accelerated networking on {product-title} by offloading OVN-Kubernetes data plane operations to NVIDIA BlueField-3 Data Processing Units (DPUs).

The DPF deployment creates a dual-cluster topology consisting of a management cluster running on x86 servers and a hosted DPU cluster running on BlueField-3 DPUs.
