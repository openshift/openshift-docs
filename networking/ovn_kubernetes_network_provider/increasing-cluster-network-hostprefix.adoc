= Increasing the cluster network host prefix
include::_attributes/common-attributes.adoc[]
:context: increasing-cluster-network-hostprefix

toc::[]

[role="_abstract"]
You can increase the number of pod IP addresses available on each node by changing the `hostPrefix` value in the cluster network configuration after installation. This procedure applies only to the cluster network, is supported only with OVN-Kubernetes, and requires sequential node maintenance to apply the updated per-node subnet size.
