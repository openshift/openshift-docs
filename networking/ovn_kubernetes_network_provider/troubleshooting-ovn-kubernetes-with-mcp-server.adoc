= Troubleshooting OVN-Kubernetes with the MCP server
include::_attributes/common-attributes.adoc[]
:context: troubleshooting-ovn-kubernetes-with-mcp-server

toc::[]

[role="_abstract"]
To troubleshoot OVN-Kubernetes networking issues in {product-title}, enable the Model Context Protocol (MCP) server `ovn-kubernetes` and `cni-diagnostics` toolsets, then apply toolset permissions and use layered diagnostic workflows.

The MCP server for Red{nbsp}Hat OpenShift can diagnose OVN-Kubernetes connectivity issues in {product-title} by collecting evidence across Kubernetes, OVN, Open vSwitch, and kernel networking layers with the `ovn-kubernetes` and `cni-diagnostics` toolsets.

OVN-Kubernetes connectivity problems often span Kubernetes objects, OVN logical topology, Open vSwitch bridges and OpenFlow tables, and kernel networking such as conntrack, nftables, and packet capture.
