= BGP routing for Google Cloud
include::_attributes/common-attributes.adoc[]
:context: bgp-routing-google-cloud

toc::[]

[role="_abstract"]
To provide direct, routed connectivity to pods and virtual machines (VMs) on user-defined networks, you can enable Border Gateway Protocol (BGP) routing on your {product-title} cluster running on {gcp-short}.

By using BGP routing, your {gcp-short} Virtual Private Cloud (VPC) learns the routes to pod and VM networks directly, so traffic does not require Network Address Translation (NAT).
