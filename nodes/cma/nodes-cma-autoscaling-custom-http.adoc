= Scaling applications based on HTTP traffic

[role="_abstract"]
You can scale a workload on {product-title} based on incoming HTTP requests, including scaling to zero replicas when traffic stops. The Kubernetes Event Driven Autoscaler (KEDA) HTTP Add-on counts requests at a proxy in front of the workload and reports those counts to the Custom Metrics Autoscaler Operator.

The HTTP add-on is optional. The Custom Metrics Autoscaler Operator does not install it until you enable it.
