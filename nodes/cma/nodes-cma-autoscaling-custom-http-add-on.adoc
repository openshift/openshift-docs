= Scaling applications based on HTTP traffic
include::_attributes/common-attributes.adoc[]

toc::[]

[role="_abstract"]
You can use the KEDA HTTP Add-on extends the Custom Metrics Autoscaler Operator to enable automatic scaling of HTTP-based applications based on incoming traffic metrics. 

With the HTTP Add-on, you can scale applications from zero replicas during low traffic periods to peak capacity when demand returns, enabling significant cost savings for variable-load HTTP workloads.

The HTTP Add-on provides a transparent, traffic-based scaling solution that works with standard Kubernetes Deployments without requiring application code changes. It combines an interceptor proxy that observes HTTP traffic with a scaler that determines replica counts based on configurable traffic thresholds.
