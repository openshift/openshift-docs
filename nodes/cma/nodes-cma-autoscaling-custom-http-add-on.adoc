= Scaling applications based on HTTP traffic
include::_attributes/common-attributes.adoc[]

toc::[]

[role="_abstract"]
You can use the HTTP Add-on to extend the Custom Metrics Autoscaler Operator to enable automatic scaling of HTTP-based applications based on incoming traffic metrics. 

With the HTTP Add-on, you can scale applications from zero replicas during low traffic periods to peak capacity when demand returns.

The HTTP Add-on scales a workload based on HTTP traffic without changing application code. An interceptor proxy counts requests, and a scaler reports those counts to the Custom Metrics Autoscaler. You set targetValue on the InterceptorRoute custom resource to control when the horizontal pod autoscaler adds replicas.
