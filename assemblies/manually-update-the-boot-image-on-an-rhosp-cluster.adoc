= Manually update the boot image on an RHOSP cluster
:context: manually-update-the-boot-image-on-an-rhosp-cluster

[role="_abstract"]
When managing a cluster deployed on Red Hat OpenStack Platform (RHOSP), learn how to manually upload the latest OpenShift Container Platform image to the RHOSP image service (Glance) and configure your worker machine sets to use it so that you can ensure new nodes successfully scale up with the most current operating system version.
