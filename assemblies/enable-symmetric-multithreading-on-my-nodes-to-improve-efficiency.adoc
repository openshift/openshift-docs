= Enable symmetric multithreading on my nodes to improve efficiency.
:context: enable-symmetric-multithreading-on-my-nodes-to-improve-efficiency
:job-gap:

[role="_abstract"]
When you want to enable multithreading on nodes in a specific pool, you can create a machine config object to set the nosmt extension, so that you can enable symmetric multithreading (SMT) on those nodes to improve node efficiency.
