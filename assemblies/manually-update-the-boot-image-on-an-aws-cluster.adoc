= Manually update the boot image on an AWS cluster
:context: manually-update-the-boot-image-on-an-aws-cluster

[role="_abstract"]
When managing a cluster deployed on Amazon Web Services (AWS), learn how to manually configure your machine sets to use the latest OpenShift Container Platform Amazon Machine Image (AMI) as the boot image so that you can ensure new nodes successfully scale up with the most current operating system version.
