= Secure the container software supply chain
:context: secure-the-container-software-supply-chain

[role="_abstract"]
When moving software from development to production, you want to establish continuous verification checkpoints across image registries, builds, and deployment gates, so that only authenticated, scanned, and digitally signed containers are permitted to run on the cluster.
