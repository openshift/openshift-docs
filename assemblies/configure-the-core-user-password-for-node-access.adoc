= Configure the `core` user password for node access.
:context: configure-the-core-user-password-for-node-access

[role="_abstract"]
When a node is down, you can use a machine config to set a password for the `core` user for nodes in a specific pool, so that you can access those nodes by using a serial console or a bare metal baseboard controller manager (BMC) with that user account.
