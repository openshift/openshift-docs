= Configure encryption using tag-based placement
:context: configure-encryption-using-tag-based-placement

[role="_abstract"]
When you need to provision encrypted volumes across multiple vSphere datastores, you want to configure storage classes to use tag-based placement, so that volumes are automatically placed on any datastore matching your encryption tag criteria without hardcoding specific datastore URLs.
