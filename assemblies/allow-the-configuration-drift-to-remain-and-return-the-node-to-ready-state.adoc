= Allow the configuration drift to remain and return the node to ready state.
:context: allow-the-configuration-drift-to-remain-and-return-the-node-to-ready-state
:job-gap:

[role="_abstract"]
When configuration drift is intentional but you still need the node to update, you can remediate drift by restoring the file contents or blocking drift detection, so you can unblock future machine config rollouts.
