= Detect and resolve node issues
:context: detect-and-resolve-node-issues

[role="_abstract"]
As a cluster administrator, when you detect that there are issues with one or more nodes, you want to isolate them from the pool to prevent application downtime, remediate the issue, and either return the node to the pool or replace it entirely.
