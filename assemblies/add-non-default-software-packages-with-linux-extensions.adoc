= Add non-default software packages with Linux extensions.
:context: add-non-default-software-packages-with-linux-extensions
:job-gap:

[role="_abstract"]
When you want to incorporate software that is not in the RHCOS base image onto nodes in a specific pool, you can create a machine config object to install Linux extensions across all the nodes in a pool.
