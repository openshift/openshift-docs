= Monitor platform vulnerabilities and audit security incidents
:context: monitor-platform-vulnerabilities-and-audit-security-incidents

[role="_abstract"]
When maintaining the long-term integrity of the production environment, you want to continuously track known vulnerabilities and maintain immutable audit logs of cluster activity, so that you can rapidly detect, investigate, and mitigate potential security threats or unauthorized system changes.
