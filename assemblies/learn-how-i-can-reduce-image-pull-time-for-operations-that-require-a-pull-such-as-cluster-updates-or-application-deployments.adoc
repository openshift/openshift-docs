= Learn how I can reduce image pull time for operations that require a pull, such as cluster updates or application deployments.
:context: learn-how-i-can-reduce-image-pull-time-for-operations-that-require-a-pull-such-as-cluster-updates-or-application-deployments
:job-gap:

[role="_abstract"]
When you need to reduce pod startup time for frequently-used images, you can pin container images to your machine config pools, so you can reduce image pull time and ensure critical images are always available locally to the nodes in that pool.
