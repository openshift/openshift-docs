Deploy, configure, and scale Argo CD instances and their supporting infrastructure on {OCP} clusters. Manage custom resource properties, webhook secrets, resource allocation, cluster sharding, the GitOps console plugin, container image updates, and CLI shell productivity features.

== Prerequisites

* You have logged in to the {OCP} cluster as an administrator.
* You have installed the {gitops-title} Operator on your {OCP} cluster.
* You have installed the OpenShift CLI (`oc`).
