Before you can install {SMProductName}, review the installation activities, ensure that you meet the prerequisites:

== Prerequisites

* Possess an active {product-title} subscription on your Red Hat account. If you do not have a subscription, contact your sales representative for more information.

ifdef::openshift-enterprise[]
* Review the xref:installation-overview_architecture-installation[{product-title} {product-version} overview].
* Install {product-title} {product-version}.
** xref:installing-aws-default[Install {product-title} {product-version} on AWS]
** xref:installing-aws-user-infra[Install {product-title} {product-version} on AWS with user-provisioned infrastructure]
** xref:installing-bare-metal[Install {product-title} {product-version} on bare metal]
** xref:installing-vsphere[Install {product-title} {product-version} on vSphere]
+
[NOTE]
====
If you are installing {SMProductName} on a xref:installing-preparing-supported-installation-methods-reference_installing-preparing[restricted network], follow the instructions for your chosen {product-title} infrastructure.
====
+
endif::[]

* Install the version of the {product-title} command-line utility (the `oc` client tool) that matches your {product-title} version and add it to your path.

ifdef::openshift-enterprise[]
** If you are using {product-title} {product-version}, see xref:cli-about-cli_cli-developer-commands[About the OpenShift CLI].
endif::[]
