= Run more than one container in your workload
include::_attributes/common-attributes.adoc[]
:context: run-more-than-one-container

toc::[]

[role="_abstract"]
Run a sidecar container alongside your main workload to handle cross-cutting concerns such as logging, proxying, or certificate rotation. Use an init container to perform setup tasks that must complete before your workload starts.
