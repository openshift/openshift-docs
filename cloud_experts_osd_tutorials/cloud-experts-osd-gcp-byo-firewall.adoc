= Tutorial: Retrofit Bring Your Own (BYO) firewall rules for {product-title} on {GCP}
:context: cloud-experts-osd-gcp-byo-firewall

toc::[]

[role="_abstract"]
{product-title} on {GCP} clusters are provisioned with platform-managed firewall rules that use {GCP} network tags to target instances. The Bring Your Own (BYO) firewall feature replaces these with rules that target Workload Identity Federation (WIF) service accounts instead. This gives you full ownership of your firewall rules while maintaining the same network security posture.

In this tutorial, you replace the tag-targeted firewall rules on an existing {product-title} on {GCP} cluster with service-account-targeted BYO rules. You then disable Cloud Controller Manager (CCM) firewall management and validate Day 2 operations.

====
This content is authored by Red{nbsp}Hat experts but has not yet been tested on every supported configuration.
====
