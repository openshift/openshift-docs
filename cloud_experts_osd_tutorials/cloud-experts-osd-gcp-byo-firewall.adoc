= Tutorial: Retrofitting BYO firewall rules on {product-title} on {GCP}

include::_attributes/attributes-openshift-dedicated.adoc[]
:context: cloud-experts-osd-gcp-byo-firewall

toc::[]

[role="_abstract"]
{product-title} on {GCP} clusters are provisioned with platform-managed firewall rules that use {GCP} network tags to target instances. The BYO (Bring Your Own) firewall feature replaces these with rules that target Workload Identity Federation (WIF) service accounts instead. This gives customers full ownership of their firewall rules while maintaining the same network security posture.

This tutorial walks through retrofitting an existing {product-title} on {GCP} cluster from tag-targeted rules to service-account-targeted BYO rules, disabling Cloud Controller Manager (CCM) firewall management, and validating Day-2 operations.
