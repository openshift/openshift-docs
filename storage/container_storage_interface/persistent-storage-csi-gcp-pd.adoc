== Google Cloud Dedicated

On Google Cloud Dedicated sovereign cloud infrastructure, the GCP PD CSI Driver Operator automatically detects the sovereign environment and adjusts its behavior:

* The default `StorageClass` uses `hyperdisk-balanced` instead of `pd-standard`. Other disk types (`pd-standard`, `pd-ssd`, `pd-balanced`) are not available on Google Cloud Dedicated.
* Google Cloud Filestore is not available on Google Cloud Dedicated.
* The CSI driver authenticates to Google Cloud Dedicated APIs using self-signed JWT credentials. This authentication is transparent and requires no manual configuration.
* Core storage operations are supported on Google Cloud Dedicated, including volume provisioning, snapshots, volume creation from snapshots, and persistent volume claim (PVC) resizing.

For more information about storage behavior on Google Cloud Dedicated, see xref:../../installing/installing_gcp/installing-gcp-dedicated.adoc#gcp-dedicated-storage-behavior_installing-gcp-dedicated[Storage behavior on Google Cloud Dedicated].
