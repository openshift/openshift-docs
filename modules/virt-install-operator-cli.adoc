= Installation of the {VirtProductName} Operator by using the CLI

[role="_abstract"]
You can install the {VirtProductName} Operator by using the `oc` CLI. Installing the Operator from the CLI is a two-stage task: first you subscribe the `{CNVNamespace}` namespace to the {VirtProductName} catalog, and then you deploy the Operator into that namespace.
