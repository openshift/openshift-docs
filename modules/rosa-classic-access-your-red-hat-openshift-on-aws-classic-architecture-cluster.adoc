= Access your Red Hat OpenShift Service on AWS (Classic architecture) cluster

[role="_abstract"]
It is recommended that you access your {product-title} cluster by using an identity provider (IDP) account. However, the cluster administrator who created the cluster can access it by using the quick access procedure.

This document describes how to access a cluster and set up an IDP by using the ROSA CLI (`rosa`). Alternatively, you can create an IDP account by using {cluster-manager} console.
