= Clean up the baseline test workload (optional)

[role="_abstract"]
If you deployed the baseline test workload earlier in this tutorial, remove it.

.Procedure
* Delete the test project:
+
[source,terminal]
----
$ oc delete project byo-fw-test
----

.Verification
* Verify that the test project no longer exists:
+
[source,terminal]
----
$ oc get project byo-fw-test
----
+
.Example output
[source,terminal]
----
Error from server (NotFound): namespaces "byo-fw-test" not found
----
