= Disable overcommitment for a project

[role="_abstract"]
You can disable overcommitment for a project to allow infrastructure components to be configured independently of overcommitment.

[.pr:openshift-enterprise .pr:openshift-origin .pr:microshift]#If overcommitment is enabled on a project, you can disable overcommitment for that project. This allows infrastructure components to be configured independently of overcommitment.#
[.pr:openshift-rosa .pr:openshift-rosa-hcp .pr:openshift-dedicated]#If required by your use case, you can disable overcommitment on any project that is not managed by Red Hat. For a list of projects that cannot be modified, see "Red Hat Managed resources" in _Support_.#

[role="pr:openshift-rosa pr:openshift-rosa-hcp pr:openshift-dedicated"]
.Prerequisites
* You are logged in to the cluster using an account with cluster administrator or cluster editor permissions.

.Procedure
. [.pr:openshift-enterprise .pr:openshift-origin .pr:microshift]#{empty}# Create or edit the namespace object file.
. [.pr:openshift-enterprise .pr:openshift-origin .pr:microshift]#{empty}# Add the following annotation:
+
[source,yaml,role="pr:openshift-enterprise pr:openshift-origin pr:microshift"]
----
apiVersion: v1
kind: Namespace
metadata:
  annotations:
    quota.openshift.io/cluster-resource-override-enabled: "false"
# ...
----
+
[role="pr:openshift-enterprise pr:openshift-origin pr:microshift"]
where:
+
[role="pr:openshift-enterprise pr:openshift-origin pr:microshift"]
--
`metadata.annotations.quota.openshift.io/cluster-resource-override-enabled.false`:: Specifies that overcommit is disabled for this namespace.
--

. [.pr:openshift-rosa .pr:openshift-rosa-hcp .pr:openshift-dedicated]#{empty}# Edit the namespace object file:
.. [.pr:openshift-rosa .pr:openshift-rosa-hcp .pr:openshift-dedicated]#{empty}# If you are using the web console:
... [.pr:openshift-rosa .pr:openshift-rosa-hcp .pr:openshift-dedicated]#{empty}# Click *Administration* -> *Namespaces* and click the namespace for the project.
... [.pr:openshift-rosa .pr:openshift-rosa-hcp .pr:openshift-dedicated]#{empty}# In the *Annotations* section, click the *Edit* button.
... [.pr:openshift-rosa .pr:openshift-rosa-hcp .pr:openshift-dedicated]#{empty}# Click *Add more* and enter a new annotation that uses a *Key* of `quota.openshift.io/cluster-resource-override-enabled` and a *Value* of `false`.
... [.pr:openshift-rosa .pr:openshift-rosa-hcp .pr:openshift-dedicated]#{empty}# Click *Save*.
.. [.pr:openshift-dedicated]#{empty}# If you are using the {oc-first}:
... [.pr:openshift-dedicated]#{empty}# Edit the namespace:
+
[source,terminal,role="pr:openshift-dedicated"]
----
$ oc edit namespace/<project_name>
----
.. [.pr:openshift-rosa .pr:openshift-rosa-hcp]#{empty}# If you are using the ROSA CLI (`rosa`):
... [.pr:openshift-rosa .pr:openshift-rosa-hcp]#{empty}# Edit the namespace:
+
[source,terminal,role="pr:openshift-rosa pr:openshift-rosa-hcp"]
----
$ rosa edit namespace/<project_name>
----
... [.pr:openshift-rosa .pr:openshift-rosa-hcp .pr:openshift-dedicated]#{empty}# Add the following annotation:
+
[source,yaml,role="pr:openshift-rosa pr:openshift-rosa-hcp pr:openshift-dedicated"]
----
apiVersion: v1
kind: Namespace
metadata:
  annotations:
    quota.openshift.io/cluster-resource-override-enabled: "false"
# ...
----
+
[role="pr:openshift-rosa pr:openshift-rosa-hcp pr:openshift-dedicated"]
where:
+
[role="pr:openshift-rosa pr:openshift-rosa-hcp pr:openshift-dedicated"]
--
`metadata.annotations.quota.openshift.io/cluster-resource-override-enabled.false`:: Specifies that overcommit is disabled for this namespace.
