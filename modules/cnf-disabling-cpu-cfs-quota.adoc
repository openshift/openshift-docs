= CPU quota annotation for pods

[role="_abstract"]
On {product-title}, you do not need the `cpu-quota.crio.io` annotation to disable the CPU completely fair scheduler (CFS) quota for pods.

Starting in {product-title} 4.20, the kubelet does not set a CPU CFS quota for pods that meet all of the following conditions:

* The pod has a `Guaranteed` quality of service (`QoS`) class.
* The pod requests whole CPUs.
* A performance profile enables the CPU manager static policy.

The `cpu-quota.crio.io: "disable"` annotation is no longer required for any pods.
If your workloads already include the annotation, you can leave it in place.
The annotation is harmless.
