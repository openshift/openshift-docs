= Adding tags to a machine pool

[role="_abstract"]
You can add tags for compute nodes, also known as worker nodes, in a machine pool to introduce custom user tags for AWS resources that are generated when you provision your machine pool. Note that you cannot edit the tags after you create the machine pool.

ifdef::openshift-rosa-hcp[]
[NOTE]
====
If a tag key is defined on both the cluster and the machine pool, the machine pool tag value takes precedence over the cluster tag value for AWS resources created by that machine pool.
====
endif::openshift-rosa-hcp[]

.Procedure

* Add tags to a machine pool by using {cluster-manager} or the {rosa-cli-first}.
