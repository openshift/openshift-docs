= `virt-platform-autopilot` controller metrics and alerts

[role="_abstract"]
The `virt-platform-autopilot` controller exposes Prometheus metrics and alerts that you can use to monitor the health and compliance of managed resources.
You can view these metrics in the {product-title} web console under *Observe* > *Metrics*.

.`virt-platform-autopilot` controller metrics
[cols="1,2",options="header"]
|===
|Metric
|Description

|`kubevirt_vpa_compliance_status`
|Reports the compliance state of each managed resource.
A value of `1` indicates that the resource matches the expected configuration.
A value of `0` indicates that the resource has drifted from the expected state.

|`kubevirt_vpa_paused_resources`
|Reports the number of managed resources that have paused reconciliation.
Reconciliation pauses when the `virt-platform-autopilot` controller detects rapid or repeated changes to a resource to prevent configuration thrashing.

|`kubevirt_vpa_reconcile_rate`
|Reports the rate of reconciliation operations per second.
Use this metric to understand how often the `virt-platform-autopilot` controller reconciles managed resources.

|`kubevirt_vpa_reconcile_errors_total`
|Reports the total number of reconciliation errors.
An increasing value indicates that the `virt-platform-autopilot` controller cannot apply or keep the expected configuration for one or more managed resources.

|`kubevirt_vpa_work_queue_depth`
|Reports the current depth of the reconciliation work queue.
A consistently high value might indicate that the `virt-platform-autopilot` controller is unable to process reconciliation requests quickly enough.
|===

.`virt-platform-autopilot` controller alerts
[cols="1,1,2",options="header"]
|===
|Alert
|Severity
|Description

|`KubeVirtVirtualizationPlatformAutopilotReconcileErrors`
|warning
|Fires when the `virt-platform-autopilot` controller encounters a sustained rate of reconciliation errors.
This alert indicates that one or more managed resources cannot be reconciled to their expected state.
Investigate the `virt-platform-autopilot` controller logs in the `{CNVNamespace}` namespace to identify the affected resources and the root cause of the errors.
|===
