= Starting a deployment

[role="_abstract"]
To begin a new rollout of your application in {product-title}, you can start a deployment from an existing `DeploymentConfig` object. Use the `oc rollout latest` command to create a new replication controller and run the deployment process.

.Procedure

. To start a new deployment process from an existing `DeploymentConfig` object, run the following command:
+
[source,terminal]
----
$ oc rollout latest dc/<name>
----
+
[NOTE]
====
If a deployment process is already in progress, the command displays a message and a new replication controller will not be deployed.
====
