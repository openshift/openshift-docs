= Configure registry authentication for {gitops-title} Helm charts

[role="_abstract"]
Before installing the {gitops-title} Operator, configure authentication to access the OCI Helm chart and container images in `registry.redhat.io`.

.Prerequisites

* You have an active Red Hat Developer account.

.Procedure

. Download your image pull secret from the Red Hat Hybrid Cloud Console:

.. Navigate to link:https://console.redhat.com/openshift/install/pull-secret[console.redhat.com/openshift/install/pull-secret].

.. Log in with your Red Hat account credentials.

.. Click *Download pull secret* and save the file to your local system, for example, `/path/to/pull-secret.txt`.

.Verification

The pull secret file is ready to use with Helm and kubectl commands for authenticating to `registry.redhat.io`.
