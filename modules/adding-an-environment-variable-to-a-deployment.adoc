= Central deployment environment variable example

[role="_abstract"]
The following overlay injects an environment variable into the `central` deployment.

[source,yaml]
----
apiVersion: platform.stackrox.io
kind: Central
metadata:
  name: central
spec:
  # ...
  overlays:
  - apiVersion: apps/v1
    kind: Deployment
    name: central
    patches:
    - path: spec.template.spec.containers[name:central].env[-1]
      value: |
        name: MY_ENV_VAR
        value: value
----
