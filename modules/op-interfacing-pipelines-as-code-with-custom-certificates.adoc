= Interface PAC with custom certificates

[role="_abstract"]
To configure {pac} with a Git repository that uses a privately signed or custom certificate, expose the certificate to {pac}.

.Procedure

* If you have installed {pac} by using the {pipelines-title} Operator, you can add your custom certificate to the cluster by using the `Proxy` object. The Operator exposes the certificate in all {pipelines-title} components and workloads, including {pac}.
