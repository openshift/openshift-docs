= Use the Driver Toolkit as a base image for building drivers

[role="_abstract"]
The Driver Toolkit image contains the kernel packages and build tools that match a specific {product-title} release. Use it as the base image for driver containers so that you can build kernel modules without entitled builds or privileged access to node content.
