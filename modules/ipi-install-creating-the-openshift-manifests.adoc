= Manifest configuration files

[role="_abstract"]
{product-title} manifest configuration files defines the target state and resources of your cluster.

== Creating the {product-title} manifests

Create the {product-title} manifests by running the following command:

[source,terminal]
----
$ ./openshift-baremetal-install --dir ~/clusterconfigs create manifests
----

[NOTE]
====
Consume the Install Config from target directory.
====

[IMPORTANT]
====
* Make control-plane schedulable by setting `MastersSchedulable` to true for Scheduler cluster settings.
* Discard the OpenShift Manifest that was provided in the target directory because its dependencies are dirty and it needs to be regenerated.
====
