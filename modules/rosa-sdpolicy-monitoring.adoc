= Monitoring

[role="_abstract"]
{product-title} clusters include an integrated monitoring stack and cluster notification system.

[id="rosa-sdpolicy-cluster-metrics_{context}"]
== Cluster metrics

{product-title} clusters come with an integrated Prometheus stack for cluster monitoring including CPU, memory, and network-based metrics. This is accessible through the web console. These metrics also allow for horizontal pod autoscaling based on CPU or memory metrics provided by a {product-title} user.
