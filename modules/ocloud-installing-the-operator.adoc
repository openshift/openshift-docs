= Install the O-Cloud Manager 

[role="_abstract"]
You can install the O-Cloud Manager on the hub cluster by creating a `Subscription` custom resource (CR) that deploys the Operator from the Red Hat Ecosystem Catalog.

.Prerequisites

* You have access to the hub cluster as a user with `cluster-admin` privileges.
* You have installed the OpenShift CLI (`oc`).
* {rh-rhacm-first} version 2.15 or later is installed on the hub cluster.
* The SiteConfig Operator is enabled in the `MultiClusterHub` CR.
* A default `StorageClass` that supports `ReadWriteOnce` access mode is configured, with at least 20 Gi of available `PersistentVolume` capacity.

.Procedure

. Create a namespace for the O-Cloud Manager by running the following command:
+
[source,terminal]
----
$ oc create namespace oran-o2ims
----
*
`oran-o2ims` is the namespace for the O-Cloud Manager.

. Create an `OperatorGroup` CR in the `oran-o2ims` namespace such as the following example:
+
[source,yaml]
----
apiVersion: operators.coreos.com/v1
kind: OperatorGroup
metadata:
  name: o-cloud-manager
  namespace: oran-o2ims
----
+
* `metadata.name` specifies a name for the `OperatorGroup` CR, such as `o-cloud-manager`.

. Create a `Subscription` CR to install the Operator such as the following example:
+
[source,yaml]
----
apiVersion: operators.coreos.com/v1alpha1
kind: Subscription
metadata:
  name: oran-o2ims
  namespace: oran-o2ims
spec:
  channel: "stable"
  name: oran-o2ims
  source: redhat-operators
  sourceNamespace: openshift-marketplace
----
+
`metadata.name` specifies a name for the `Subscription` CR, such as `oran-o2ims`.

. Apply the CRs by running the following commands, replacing `<operatorgroup_filename>` and `<subscription_filename>` with the names of the files you created:
+
[source,terminal]
----
$ oc apply -f <operatorgroup_filename>.yaml
$ oc apply -f <subscription_filename>.yaml
----

. Verify that the Operator is installed and running by running the following command:
+
[source,terminal]
----
$ oc get pods -n oran-o2ims
----

. Verify that the default `Inventory` CR was created by running the following command:
+
[source,terminal]
----
$ oc get inventory -n oran-o2ims
----
+
.Example output
[source,terminal]
----
NAME      AGE
default   4m20s
----

[source,terminal]

$ oc get routes -n oran-o2ims
