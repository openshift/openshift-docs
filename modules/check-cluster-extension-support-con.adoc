= Review supported cluster extensions with {olmv1}

[role="_abstract"]
Not all Operators in a catalog are compatible with {olmv1}. Before installing an Operator as a cluster extension, check that it meets the bundle format, install mode, and dependency requirements.

{olmv1-first} supports installing cluster extensions that meet the following requirements:

* The extension uses the `registry+v1` bundle format introduced in {olmv0}.
* The extension supports the `AllNamespaces` install mode. With this mode, the Operator watches and manages resources across all namespaces in the cluster.
* The extension does not declare dependencies by using any of the following file-based catalog properties:
** `olm.gvk.required`
** `olm.package.required`
** `olm.constraint`

Installing extensions that use webhooks is available only as a Technology Preview feature in {product-title} {product-version}.

Installing an extension with webhooks is a Technology Preview feature only.

{olmv1} checks that the extension you want to install meets its support constraints. If the extension does not meet these constraints, an error message is printed in the cluster extension's conditions.
