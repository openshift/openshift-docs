= Review supported cluster extensions with {olmv1}

[role="_abstract"]
Not all Operators in a catalog are compatible with {olmv1}. 

Before installing an Operator as a cluster extension, check that it meets the bundle format, install mode, and dependency requirements. {olmv1-first} supports extensions that use webhooks for validation, mutation, or conversion.

{olmv1-first} supports extensions that use the `AllNamespaces` install mode. With this mode, the Operator watches and manages resources across all namespaces in the cluster.
