= Review monitoring dashboards as a cluster administrator

[role="_abstract"]
[.pr:openshift-enterprise]#As an administrator, you can view dashboards relating to core OpenShift Container Platform cluster components.#
[.pr:openshift-origin]#As an administrator, you can view dashboards relating to core OKD cluster components.#
[.pr:openshift-dedicated]#As an administrator, you can view dashboards relating to core OpenShift Dedicated cluster components.#
[.pr:openshift-rosa]#As an administrator, you can view dashboards relating to core Red Hat OpenShift Service on AWS (classic architecture) cluster components.#
[.pr:openshift-rosa-hcp]#As an administrator, you can view dashboards relating to core Red Hat OpenShift Service on AWS cluster components.#
[.pr:microshift]#As an administrator, you can view dashboards relating to core Red Hat build of MicroShift cluster components.#

include::snippets/snip-unified-perspective-web-console.adoc[]


.Prerequisites

[role="pr:microshift pr:openshift-enterprise pr:openshift-origin"]
* You have access to the cluster as a user with the `cluster-admin` cluster role.


.Prerequisites

[role="pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp"]
* You have access to the cluster as a user with the `dedicated-admin` role.

.Procedure

. [.pr:openshift-enterprise]#In the OpenShift Container Platform web console, go to *Observe* -> *Dashboards*.# [.pr:openshift-origin]#In the OKD web console, go to *Observe* -> *Dashboards*.# [.pr:openshift-dedicated]#In the OpenShift Dedicated web console, go to *Observe* -> *Dashboards*.# [.pr:openshift-rosa]#In the Red Hat OpenShift Service on AWS (classic architecture) web console, go to *Observe* -> *Dashboards*.# [.pr:openshift-rosa-hcp]#In the Red Hat OpenShift Service on AWS web console, go to *Observe* -> *Dashboards*.# [.pr:microshift]#In the Red Hat build of MicroShift web console, go to *Observe* -> *Dashboards*.#

. Choose a dashboard in the *Dashboard* list. Some dashboards, such as *etcd* and *Prometheus* dashboards, produce additional sub-menus when selected.

. Optional: Select a time range for the graphs in the *Time range* list.

** Select a predefined time period.

** Set a custom time range by clicking *Custom time range* in the *Time range* list.
+
.. Input or select the *From* and *To* dates and times.
+
.. Click *Save* to save the custom time range.

. Optional: Select a *Refresh interval*.

. Hover over each of the graphs within a dashboard to display detailed information about specific items.
