= Delete entries from a mirror configuration

[role="_abstract"]
Delete platform channels, Operator catalogs, Operators, additional images, or saved configurations from a mirror configuration in the OpenShift Mirror Console. Removing unused entries keeps the `ImageSetConfiguration` file limited to the images required for the next mirror operation.

.Prerequisites

* You are logged in to the OpenShift Mirror Console.
* You have configured a pull secret.
* You have a saved `ImageSetConfiguration` file available in the OpenShift Mirror Console.

.Procedure

. Locate the entry to remove from the mirror configuration.
+
A *Minus* icon appears to the right of configuration entries such as platform channels, Operator catalogs, Operators, additional images, and saved mirror configurations.

. Click the *Minus* icon next to the entry to delete it.

. If you deleted entries from the form editor, save the updated configuration by doing one of the following:

.. Click *Save Configuration* to save the file with the auto-generated filename.

.. Optional: To rename the file before saving, click the *Edit* icon next to the filename and enter the new name into the text box.

.. Click *Download YAML* to download the updated `ImageSetConfiguration` file to your local system.

.Verification

* Confirm that the deleted entry no longer appears in the OpenShift Mirror Console.

* If you saved or downloaded the configuration, open the YAML file and confirm that the deleted entries are no longer present.
