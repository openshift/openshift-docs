= Delete entries from a mirror configuration

[role="_abstract"]
To remove unused entries from a mirror configuration, delete platform channels, Operator catalogs, Operators, or additional images in the OpenShift Mirror Console. The generated `ImageSetConfiguration` file then contains only the content that you want the next mirror operation to copy.

.Prerequisites

* The OpenShift Mirror Console is open in a browser.
* You have configured a pull secret.
* You have entries in the form editor that you want to remove.

.Procedure

. Locate the entry to remove from the mirror configuration.
+
Each configuration entry has a *Minus* icon.

. Click the *Minus* icon next to the entry to delete it.

. Save or download the updated configuration by doing one of the following:

.. Click *Save Configuration* to save the file with the default filename. The file then appears in the *ImageSetConfiguration File* list on the Mirror Operations page.

.. Click *Download YAML* to download a copy of the file to the default downloads folder on your computer. The copy does not appear on the Mirror Operations page.

.Verification

. Confirm that the OpenShift Mirror Console no longer displays the deleted entry.

. Open the saved or downloaded YAML file and confirm that it no longer contains the deleted entries.
