= Delete entries and saved mirror configurations

[role="_abstract"]
Remove content that you no longer need by deleting entries from a mirror configuration or deleting a saved configuration in the OpenShift Mirror Console. The generated `ImageSetConfiguration` file then contains only the content that you want the next mirror operation to copy.

To delete only a saved configuration, begin with the optional step for deleting a saved configuration.

.Prerequisites

* You have opened the OpenShift Mirror Console in a browser.
* You have configured a pull secret.
* You have entries in the form editor that you want to remove, or a saved configuration that you want to delete.

.Procedure

. Locate the entry to remove from the mirror configuration.
+
Each configuration entry has a *Minus* icon.

. Click the *Minus* icon next to the entry to delete it.

. Save or download the updated configuration by doing one of the following:

.. Click *Save Configuration* to save the file.
+
If you did not rename the file, the console saves it as `imageset-config-<utc_timestamp>.yaml`. The timestamp uses Coordinated Universal Time (UTC), for example, `imageset-config-2026-11-11-11-14-00-UTC.yaml`. If you enter the name of an existing configuration, the console overwrites it. The file appears in the *ImageSetConfiguration File* list on the Mirror Operations page.

.. Click *Download YAML* to download a copy of the file to the default downloads location on your local system. The copy does not appear on the Mirror Operations page.

. Optional: To delete a saved configuration, complete the following steps:

.. Go to the Mirror Operations page.

.. In the *ImageSetConfiguration File* list, select the configuration to delete.

.. Click the *Delete configuration* icon.

.. In the *Delete ImageSetConfiguration File* dialog, confirm the deletion.
+
[NOTE]
====
Deleting a saved configuration removes only the saved `ImageSetConfiguration` file. It does not delete mirrored content or operation history. You cannot undo this action.
====

.Verification

. If you removed entries from a configuration, verify the updated configuration:

.. Confirm that the OpenShift Mirror Console no longer displays the deleted entries.

.. Open the saved or downloaded YAML file.

.. Confirm that the file no longer contains the deleted entries.

. If you deleted a saved configuration, confirm that it no longer appears in the *ImageSetConfiguration File* list on the Mirror Operations page.
