= Collect host sosreports and journal logs

[role="_abstract"]
When a problem appears to originate at the host operating system level, you generate a `sosreport` archive on the affected node and collect journal logs from bootstrap and cluster nodes. Red{nbsp}Hat support uses this data to analyze low-level system state and diagnose issues that are not captured by `oc adm must-gather`.
