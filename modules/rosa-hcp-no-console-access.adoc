= Troubleshoot access to {hybrid-console}

[role="_abstract"]
If you can log in to your {product-title} cluster by using the OpenShift CLI (`oc`) but cannot access the web console, you can verify several criteria to troubleshoot access.

In {product-title} clusters, the {product-title} OAuth server is hosted in the Red Hat service's AWS account while the web console service is published by using the cluster's default ingress controller in the cluster's AWS account.

.Procedure

* Verify the console workloads are running.
* Verify the default ingress controller's load balancer is active.
* Verify you are accessing the console from a machine that has network connectivity to the cluster's VPC network.
