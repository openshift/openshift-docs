= Default TLS curves for the ingress controller

[role="_abstract"]
The {microshift-short} ingress controller includes default TLS curves. The advertised list changes when the node runs in FIPS mode. You cannot customize the TLS curves.

Default TLS curves::

The following list specifies the default TLS curves when the node does not run in FIPS mode:

* `X25519MLKEM768`
* `X25519`
* `P-256`
* `P-384`
* `P-521`

Default TLS curves in FIPS mode::

The following list specifies the default TLS curves when the node runs in FIPS mode:

* `P-256`
* `P-384`
* `P-521`

[NOTE]
====
If the node runs in FIPS mode, {microshift-short} also removes TLS 1.3 cipher suites that are not FIPS-approved, such as `TLS_CHACHA20_POLY1305_SHA256`.
====
