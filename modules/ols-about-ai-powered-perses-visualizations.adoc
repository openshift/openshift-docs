= AI-powered visualizations

[role="_abstract"]
After adding a generated chart or widget to a dashboard, you can analyze cluster metrics directly in the interactive visualization. You can customize the visualization by using native Red Hat build of Perses mechanisms, such as console tools or direct YAML editing.
