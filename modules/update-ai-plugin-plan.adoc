= Generating an update assessment

[role="_abstract"]
Use the web console to create an AI-generated update assessment to your target version.

.Prerequisites
* You have access to the cluster with `cluster-admin` privileges.
* You have access to the {product-title} web console.
* You installed OpenShift Lightspeed Service (OLS) and configured it to use a Large Language Model (LLM).
* You installed and configured the Lightspeed Agentic Operator.

.Procedure

. On the web console, navigate to *Administration* -> *Cluster Update*.

. Select a target version from the *Select Update Path* dropdown menu.

. Click *Analyse*.

. Review the assessment produced by AI to determine the readiness of your cluster for an update to the target version.
