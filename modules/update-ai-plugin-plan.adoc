= Generating an update plan

[role="_abstract"]
With the plugin installed, use the web console to generate a proposed cluster update plan to your target version. You can then approve the plan to begin a cluster update.

.Prerequisites
* You have access to the cluster with `cluster-admin` privileges.
* You have access to the {product-title} web console.
* You installed the Console plugin.

.Procedure

. On the web console, navigate to *Administration* -> *Cluster Update*.

. Select a target version in the *AI Update Agent* section.

. Click *Generate plan*.

. Review the proposed plan in the *AI generated plan* section to assess the readiness of your cluster for an update to the target version.

. If you reviewed the plan and are ready to begin a cluster update, click *Approve plan* and click *Start update*.
