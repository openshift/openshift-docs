= About the OpenShift CLI

[role="_abstract"]
With the {oc-first}, you can create applications and manage {product-title} projects from a terminal.

The OpenShift CLI is ideal in the following situations:

* Working directly with project source code.
* Scripting {product-title} operations
* [.pr:openshift-dedicated .pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa .pr:openshift-rosa-hcp]#{empty}# Managing projects while restricted by bandwidth resources and the web console is unavailable.
* [.pr:microshift]#{empty}# Managing projects while restricted by bandwidth resources.
