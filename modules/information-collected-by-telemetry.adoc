= Information collected by Telemetry

[role="_abstract"]
Telemetry does not collect identifying information such as user names, passwords, or the names or addresses of user resources.

[NOTE]
====
Telemetry data collection is active by default, except for the installations with the offline mode active.
====

Telemetry collects the following information:

* API, `roxctl` CLI, and user interface (UI) features and settings to know how you use {rh-rhacs-first}, which helps rank efforts.
* The time you use on UI screens to help us improve user experience.
* The integrations you configure to know if there are integrations that you have never used.
* The number of connected secured clusters and their configurations.
* Errors you meet to identify the most common problems.
