== Fixed issues

The following issues are fixed for this release:

* Before this update, the `AWSMachine` controller queued machine instances again before confirming the presence of tags. As a consequence, duplicate {aws-first} EC2 instances were created. With this release, the `AWSMachine` controller verifies tags before it queues instances again. As a result, duplicate EC2 instances are not created. (link:https://issues.redhat.com/browse/OCPBUGS-134666[OCPBUGS-134666])

* Before this update, `syncPodsForUserDefinedNetwork()` returned an unhandled `InvalidPrimaryNetworkError` when a namespace had the primary user-defined network (UDN) label but no valid UDN or `NetworkAttachmentDefinition` (NAD). As a consequence, the UDN controller could stall for up to 60 seconds and block pod creation in other correctly configured namespaces. With this release, `InvalidPrimaryNetworkError` is handled gracefully during pod sync. As a result, the UDN controller initializes without being stalled by misconfigured namespaces. (link:https://issues.redhat.com/browse/OCPBUGS-136124[OCPBUGS-136124])
