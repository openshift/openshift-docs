= Restrict external access to NodePort services on {microshift-short}

[role="_abstract"]
By default, OVN-Kubernetes does not restrict the host interface where a `NodePort` service can be accessed. Restrict external access to a `NodePort` service on a specific host interface to block unauthorized traffic and control which networks can reach your {microshift-short} workloads.
