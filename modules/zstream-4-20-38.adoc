== Fixed issues

* Before this update, Image-Based Installation (IBI) with a proxy configuration wrote the user-provided `noProxy` value directly into the cluster configuration without adding the cluster, service, and machine network Classless Inter-Domain Routing (CIDR) blocks and internal host names required for in-cluster communication. As a consequence, the `noProxy` value did not match the proxy settings applied by the Machine Config Operator template, causing the Operator to detect a configuration drift and trigger an additional node reboot during installation. With this release, IBI enriches the `noProxy` setting by using the same logic as standard installations, aligning the initial proxy configuration with the Machine Config Operator template and preventing the extra reboot. (link:https://issues.redhat.com/browse/OCPBUGS-112324[OCPBUGS-112324])
