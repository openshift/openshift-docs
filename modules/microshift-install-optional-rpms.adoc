= Install optional RPM packages

[role="_abstract"]
After installing {microshift-short}, you can add optional RPM packages to expand your deployment capabilities. Optional packages include networking extensions such as Multus, application lifecycle management with Operator Lifecycle Manager (OLM), GitOps, observability with OpenTelemetry, enhanced metrics exporters, and AI model serving with {rhoai}. Install only the packages that your deployment requires.
