= Count tokens in streaming responses

[role="_abstract"]
Count artificial intelligence (AI) tokens for streaming responses by asking the external AI service to include usage data in the final event of the stream.

An external AI service that streams a response sends the `usage` block only in the last server-sent event, and only when the request asks for it. If the request does not ask for usage data, the egress `Gateway` object cannot extract a token count.

Because the gateway updates the counter only after the response completes, a stream that is already in progress delivers all of its events even when the reported usage exceeds the limit. The updated counter applies to the requests that follow.

[IMPORTANT]
====
If a request sets `stream` to `true` but omits `stream_options.include_usage`, the egress `Gateway` object cannot extract the token usage. Depending on the failure mode of the `wasm-shim` module, the gateway either forwards the request without counting any tokens or rejects it.
====

.Prerequisites

include::snippets/egress-gateway-prereqs.adoc[]
include::snippets/egress-ai-service-prereqs.adoc[]

* You applied a `TokenRateLimitPolicy` CR to the route of your external AI service.

.Procedure

* Send a streaming request that sets the `stream` field to `true` and the `stream_options.include_usage` field to `true` by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc exec test-client -n egress-test -- sh -c '
    curl -s \
        -H "Host: _<api.example.com>_" \
        -H "Content-Type: application/json" \
        -H "Authorization: Bearer $(cat /var/run/secrets/kubernetes.io/serviceaccount/token)" \
        -X POST http://'"${EGRESS_IP}"'/v1/chat/completions \
        -d "{\"model\": \"_<model_name>_\", \"messages\": [{\"role\": \"user\", \"content\": \"What is Kubernetes?\"}], \"max_tokens\": 100, \"stream\": true, \"stream_options\": {\"include_usage\": true}}"
'
----
+
* Replace `_<api.example.com>_` with the hostname of your external AI service.
* Replace `_<model_name>_` with a model that your external AI service provides.

.Verification

* Confirm that the final server-sent event in the response includes a `usage` block with a `total_tokens` field. The egress `Gateway` object counts the reported tokens after the stream completes.
