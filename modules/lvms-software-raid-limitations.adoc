= Limitations of software RAID in {lvms}

[role="_abstract"]
You can encounter some performance related limitations when enabling software RAID in {lvms}. 

Thick provisioning only:: You can only use thick volume provisioning for software RAID configurations. Thin provisioning features are not available.

No RAID parameter modifications:: Once you create a RAID array, you cannot modify the RAID parameters such as type, stripes, or mirrors. Only device paths can be changed for disk replacement.

Performance impact with snapshots or clones:: Workloads that require frequent snapshots or clones can experience performance degradation because data must be physically copied.

Configuration requirement:: You must omit the `thinPoolConfig` field entirely when configuring RAID for a device class.
