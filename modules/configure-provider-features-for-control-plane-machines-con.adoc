= Configure provider features for control plane machines

[role="_abstract"]
Each cloud provider offers machine features that the control plane machine set can apply, such as dedicated tenancy, disk type, network acceleration, and boot diagnostics. You set these features in the provider specification of the control plane machine set, and the machine set then replaces the control plane machines to apply them.
