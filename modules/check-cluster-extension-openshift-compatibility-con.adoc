= Check cluster extension OpenShift compatibility

[role="_abstract"]
{olmv1-first} supports {olmv0} semantics for update paths, also known as upgrade edges or upgrade constraints. Support includes `replaces`, `skips`, and `skipRange` directives, with a few noted differences.

By supporting {olmv0} semantics, {olmv1} accurately reflects the update graph from catalogs.
