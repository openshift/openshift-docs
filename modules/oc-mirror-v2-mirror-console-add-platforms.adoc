= Configure platform channels for mirroring

[role="_abstract"]
Configure platform channels in the OpenShift Mirror Console to include {product-title} release channels in a mirror. You can select a channel, optionally set minimum and maximum versions and the shortest upgrade path, then preview and save the configuration.

.Prerequisites

* You are logged in to the OpenShift Mirror Console.
* You have configured a pull secret.

.Procedure

. On the Mirror Configuration page, click the *Platform Channels* tab to choose release channels for the mirror.

. Click *Add platform channel*.

. In the *Channel Name* drop-down list, select the channel to include in the mirror.

. Optional: In the *Min Version* field, enter the minimum release version to include in the mirror.

. Optional: In the *Max Version* field, enter the maximum release version to include in the mirror.
+
[NOTE]
====
If you do not set *Min Version* or *Max Version*, the mirror includes all versions for that channel.
====

. Optional: Select the *Shortest Path* checkbox to mirror only the most direct upgrade path between the minimum and maximum versions.

. To include another channel in the mirror, click *Add platform channel* and repeat the previous steps for each channel.

. Click the *Preview* tab to review the generated `ImageSetConfiguration` file before saving.

. To save the configuration, do one of the following:

.. Click *Save Configuration* to save the file with the auto-generated filename shown above the *Save Configuration* button.

.. Optional: To rename the file before saving, click the *Edit* icon next to the filename and enter the new name into the text box.

.. Click *Download YAML* to download the `ImageSetConfiguration` file to your local system.

.Verification

* Confirm that the downloaded or saved file contains the expected `operators` entries by selecting the *Preview* tab.
