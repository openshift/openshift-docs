= Configure platform channels for mirroring

[role="_abstract"]
To include {product-title} release channels in a mirror, configure platform channels in the OpenShift Mirror Console. Platform channels supply the {product-title} release images required for disconnected installation and cluster upgrades.

.Prerequisites

* The OpenShift Mirror Console is open in a browser.
* You have configured a pull secret.

.Procedure

. On the Mirror Configuration page, click the *Platform Channels* tab to select release channels for the mirror.

. Click *Add platform channel*.
+
To include another channel in the mirror, click *Add platform channel* again and repeat the following steps for each channel.

. In the *Channel Name* drop-down list, select the channel to include in the mirror, for example, `stable-4.18`.

. Optional: In the *Min version* field, enter the minimum release version to include in the mirror.

. Optional: In the *Max version* field, enter the maximum release version to include in the mirror.
+
[NOTE]
====
If you leave both *Min version* and *Max version* empty, the mirror includes all versions in the channel.
====

. Optional: Under the version fields, select the *Shortest Path* checkbox to mirror only the most direct upgrade path between the minimum and maximum versions.

. Click the *Preview* tab to review the generated `ImageSetConfiguration` file before saving.

. Optional: On the *Preview* tab, in the *Archive Size* field, enter the size of each archive in GiB. If you leave the field empty or enter `0`, oc-mirror uses the default archive size.

. Optional: To rename the file, use the *Edit* icon next to the filename to enter a new name.

. Save or download the configuration by doing one of the following:

.. Click *Save Configuration* to save the file with the default filename, or with the new name if you renamed it. The file then appears in the *ImageSetConfiguration File* list on the Mirror Operations page.

.. Click *Download YAML* to download a copy of the file to the default downloads folder on your computer. The copy does not appear on the Mirror Operations page.

.Verification

* Confirm that the *Preview* tab shows the expected `platform` entries.
