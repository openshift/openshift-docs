= DPF software requirements

[role="_abstract"]
The following software versions are required for deploying DPF v26.4.

.Software version requirements
[cols="1,1",options="header"]
|===
|Component |Required version

|{product-title}
|4.22

|OpenShift CLI (`oc`)
|4.22

|Hosted control planes {product-title} cluster
|4.22

|NVIDIA DPF Operator
|v26.4.0

|RHCOS BFB
|4.22

== Access requirements

* `cluster-admin` privileges are required for the management cluster.
