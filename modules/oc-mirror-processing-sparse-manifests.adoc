= How oc-mirror plugin v2 processes sparse manifests

[role="_abstract"]
You can configure oc-mirror plugin v2 to mirror only the architectures your cluster needs by adding a `platforms` field to your `ImageSetConfiguration` file. oc-mirror preserves the manifest list digest while pushing blobs only for the specified architectures.

When oc-mirror plugin v2 mirrors a multi-architecture image with architecture filtering enabled, it performs the following steps:

* Reads the manifest list from the source registry or disk archive.
* Pushes child manifests and blobs only for the architectures listed in the `ImageSetConfiguration` file.
* Pushes the unmodified manifest list to the target mirror registry, preserving its original digest.

[id="oc-mirror-sparse-manifest-imageset-config_{context}"]
== Interaction with the ImageSetConfiguration file

The oc-mirror plugin v2 reads the `platforms` fields from your `ImageSetConfiguration` file and evaluates them for platform release payload images, Operator catalog images, and additional images. For each type, it pushes only the child manifests and blobs for the architectures you specify.

For example, setting `mirror.platform.platforms` to `linux/amd64` mirrors only `amd64` child manifests and blobs while preserving the manifest list digest.
