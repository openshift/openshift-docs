= Sparse manifest processing in oc-mirror plugin v2

[role="_abstract"]
To mirror only selected architectures from a multi-architecture list, set the `platforms` fields in your `ImageSetConfiguration` file. Matching child manifests and blobs are then pushed, and the original manifest list digest is preserved.

When oc-mirror plugin v2 mirrors a multi-architecture image with architecture filtering enabled, it performs the following steps:

* Reads the manifest list from the source registry or disk archive.
* Pushes child manifests and blobs only for the architectures listed in the `ImageSetConfiguration` file.
* Pushes the unmodified manifest list to the target mirror registry and preserves the original digest of the manifest list.

[id="oc-mirror-sparse-manifest-supported-image-types_{context}"]
== Supported image types for the platforms fields

The `platforms` fields in your `ImageSetConfiguration` file apply to the following image types:

* Platform releases
* Operator catalog images
* Helm charts
* Additional images

For example, you can set `mirror.platform.platforms` to include only the `linux` operating system and the `amd64` architecture.
