= Prepare to create a CCS cluster on {GCP}

[role="_abstract"]
Complete the {GCP} prerequisites, resource limits, and command-line interface (CLI) setup before you create a Customer Cloud Subscription (CCS) cluster on {GCP}.

Confirm that your {GCP} project meets the requirements of the service. Completing this preparation prevents cluster creation failures due to insufficient quotas or missing network configuration.
