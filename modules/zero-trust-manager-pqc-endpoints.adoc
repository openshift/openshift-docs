= Endpoints that use hybrid key exchange

[role="_abstract"]
Strict mode applies to SPIRE Server identity and federation paths. Other {zero-trust-full} endpoints stay on preferred mode so that clients without hybrid Module-Lattice-Based Key-Encapsulation Mechanism (ML-KEM) can keep connecting.

.Hybrid key exchange by endpoint
[cols="2,3,3",options="header"]
|===
|Endpoint
|Preferred mode
|Strict mode

|SPIRE Server and SPIRE Agent gRPC
|Uses a hybrid ML-KEM group on TLS 1.3 when the peer offers one. Uses a classical curve when the peer does not offer a hybrid group.
|Requires TLS 1.3 and a hybrid ML-KEM group. Rejects a peer that does not negotiate a hybrid group.

|SPIRE federation bundle endpoints
|Uses a hybrid ML-KEM group on TLS 1.3 when the peer offers one. Uses a classical curve when the peer does not offer a hybrid group.
|Requires TLS 1.3 and a hybrid ML-KEM group. Rejects a peer that does not negotiate a hybrid group.

|SPIRE OpenID Connect (OIDC) Discovery Provider
|Uses a hybrid ML-KEM group on TLS 1.3 when the peer offers one. Uses a classical curve when the peer does not offer a hybrid group.
|Stays on preferred mode.

|SPIRE Controller Manager webhook
|Uses a hybrid ML-KEM group on TLS 1.3 when the peer offers one. Uses a classical curve when the peer does not offer a hybrid group.
|Stays on preferred mode, including connections from the Kubernetes API server.

|Operator metrics endpoint
|Follows the cluster TLS security profile and uses a hybrid ML-KEM group when the scraper offers one.
|Stays on the cluster TLS security profile so that metrics scrapers can connect.
|===

Confirm a hybrid ML-KEM connection with a Transport Layer Security (TLS) client that reports the negotiated group. The negotiated group is not part of the SPIRE or operator metrics.
