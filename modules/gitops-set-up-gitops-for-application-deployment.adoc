= GitOps Operator and CLI installation

[role="_abstract"]
Setting up {gitops-title} for application deployment requires installing the {gitops-title} Operator and the {gitops-shortname} `argocd` CLI tool on your {OCP} cluster.

Setting up {gitops-title} involves the following components:

* *{gitops-title} Operator*: Install the Operator by using the {OCP} web console or the CLI. The Operator manages Argo CD instances and related resources on your cluster.
* *{gitops-shortname} CLI*: Install the `argocd` CLI tool on Linux, macOS, or Windows to configure and manage {gitops-title} and Argo CD resources from the command line.
