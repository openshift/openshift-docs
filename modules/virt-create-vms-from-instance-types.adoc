= Create VMs from instance types

[role="_abstract"]
Standardize virtual machine (VM) resource allocation across your organization by applying predefined compute profiles. Instance types reduce configuration drift by ensuring that VMs use consistent CPU, memory, and device settings.

An instance type defines a reusable resource profile that you can apply to any VM. Instead of specifying CPU and memory in each `VirtualMachine` manifest, you reference an instance type that enforces a consistent configuration.

{VirtProductName} supports the following instance type workflows:

* Define instance types to create standardized resource profiles for your organization.
* Infer instance types from volume labels to automatically match a VM to the correct profile.
* Change instance types on existing VMs to adjust resource allocation without recreating the VM.
