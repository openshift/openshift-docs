= Connect a VM to the physical network by using an SR-IOV device

[role="_abstract"]
You can connect a virtual machine (VM) to the physical network by using a Single Root I/O Virtualization (SR-IOV) device. Configure SR-IOV for virtual machines that require high-performance, low-latency network access. 

To configure the SR-IOV network and attach the VM to that network, perform the following steps:

. Configure an SR-IOV physical network device.
. Define the secondary SR-IOV network.
. Attach the VM to the SR-IOV network.
