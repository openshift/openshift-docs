[id="zstream-4-18-59-fixed-issues_{context}"]
== Fixed issues

* Before this update, the vSphere Problem Detector (VPD) incorrectly treated a custom resource pool as requiring additional privileges instead of read-only access. As a consequence, some newly deployed clusters reported privilege-related VPD issues that did not affect older clusters. With this release, VPD correctly treats custom resource pools as read-only. As a result, those incorrect privilege warnings do not occur. (link:https://issues.redhat.com/browse/OCPBUGS-129532[OCPBUGS-129532])
