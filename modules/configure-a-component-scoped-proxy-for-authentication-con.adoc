= Component-scoped proxy for authentication

[role="_abstract"]
You can configure a dedicated proxy for the authentication stack so that the Cluster Authentication Operator and the OAuth server reach external identity providers without using the cluster-wide egress proxy. 

This limits proxy-based egress to authentication components only, which is useful in disconnected or restricted-network environments.
