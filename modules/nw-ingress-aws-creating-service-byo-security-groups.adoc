= Creating a service with a NLB by using BYO security groups

[role="_abstract"]
To create an NLB with BYO security groups, add the annotation `service.beta.kubernetes.io/aws-load-balancer-security-groups` with one or more security group IDs to the service manifest file.

.Prerequisites

* Check that the {aws-short} Identity and Access Management (IAM) role for each control plane node of your cluster includes the `elasticloadbalancing:SetSecurityGroups` permission.
** For new clusters installed on installer-provisioned infrastructure, the installation program adds this role to each control plane node.
** For user-provisioned infrastructure, you must add the permission to the IAM role of each control plane.
The following configuration adds the permission to the IAM role in a JSON file:
+
[source,json]
----
{
  "Effect": "Allow",
  "Action": [
    "elasticloadbalancing:SetSecurityGroups"
  ],
  "Resource": "*"
}
----

* You checked that the NLB security group is enabled in the {aws-short} CCM configuration.
If the security group is not enabled, you can specify the following congiruation in the CCM configuration:
+
[source,txt]
----
[Global]
NLBSecurityGroupMode = Managed
----

.Procedure

* To create an NLB with BYO security groups, add the annotation `service.beta.kubernetes.io/aws-load-balancer-security-groups` with one or more security group IDs to the service manifest:
+
[source,yaml]
----
apiVersion: v1
kind: Service
metadata:
  name: my-nlb-service
  namespace: my-namespace
  annotations:
    service.beta.kubernetes.io/aws-load-balancer-type: nlb
    service.beta.kubernetes.io/aws-load-balancer-security-groups: "<security_group_ID1>,<security_group_ID2>"
spec:
  selector:
    app: my-app
  ports:
    - port: 443
      targetPort: 8443
      protocol: TCP
  type: LoadBalancer
# ...
----
