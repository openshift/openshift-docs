= {ols-long} version 2.0

[role="_abstract"]
{ols-official} 2.0 provides new features, security fixes, and stability improvements. This release helps ensure continued support and stability for clusters running {ocp-product-title} 4.16 and later.

[id="ols-2-0-enhancements_{context}"]
== Enhancements

[role="_abstract"]
{ols-official} 2.0 introduces autonomous troubleshooting as a Technology Preview feature, along with expanded large language model (LLM) provider support, new observability and compliance capabilities, and greater transparency into how {ols-long} handles your data.

{ols-official} 2.0 includes the following enhancements:

[NOTE]
====
The {ols-long} autonomous agents features require {ocp-product-title} 5.0. These features include autonomous troubleshooting and the configuration of autonomous agents by using the `LLMProvider`, `Agent`, and `ApprovalPolicy` custom resources (CRs). The {ols-long} intelligent assistant continues to support {ocp-product-title} 4.16 and later.
====

* With this update, {ols-long} introduces {ols-long} autonomous agents for autonomous troubleshooting (Technology Preview). An AI-powered agent diagnoses cluster alerts and proposes one-click remediations in the {ocp-product-title} web console by running multi-step, tool-calling workflows against your cluster. A human-in-the-loop approval step governs every remediation action.

* With this update, you configure {ols-long} autonomous agents (Technology Preview) by using a chain of cluster-scoped custom resources (CRs), including `LLMProvider`, `Agent`, and `ApprovalPolicy`, in the `agentic.openshift.io/v1alpha1` API group. {ols-long} autonomous agents supports multiple LLM provider backends, including Anthropic, OpenAI, Azure OpenAI, {aws-first} Bedrock, Google Vertex AI, and Anthropic-compatible vLLM servers.

* With this update, the {ols-long} Operator 2.0 bundles both the {ols-long} intelligent assistant and {ols-long} autonomous agents into a single Operator installation.

* With this update, you can use {ols-long} to generate interactive {red-hat} build of Perses charts from natural language queries and save them directly to your dashboards, without manually writing PromQL queries.

With this update, {ols-long} adds audit logging and tracing for AI-assisted and agentic workflows. These records support reconstruction of key AI actions, including user/request correlation for the intelligent assistant, agentic proposals, approval identity, and executed actions.

* With this update, the documentation describes the {ols-long} trust boundary and data flow architecture, the security controls that {ols-long} applies by default in each deployment mode, and the prompt injection safeguards, including active tool-result safety inspection that detects and blocks injection attempts embedded in tool output.

* With this update, a glossary of artificial intelligence (AI) terms and {ols-official} product terms is available to help you understand the terminology used throughout the documentation.
