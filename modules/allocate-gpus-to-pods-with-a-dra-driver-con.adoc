= Allocate GPUs to pods with a DRA driver

[role="_abstract"]
A third-party Dynamic Resource Allocation (DRA) driver advertises the GPUs in the cluster and their attributes, such as product name and memory. You request a GPU by those attributes in a resource claim so the pod is scheduled onto a node that has a matching device.
