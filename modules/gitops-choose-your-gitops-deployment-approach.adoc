= GitOps deployment approaches

[role="_abstract"]
{gitops-title} supports two primary deployment architectures for managing applications across clusters: the traditional Argo CD architecture and the Argo CD Agent architecture.

Choosing a deployment approach involves the following considerations:

* *Traditional Argo CD architecture*: A centralized model where the Argo CD control plane connects directly to all managed clusters. Suitable for environments where the control plane has direct network access to target clusters.
* *Argo CD Agent architecture*: A hub-and-spoke model where lightweight agents on spoke clusters communicate with a central Principal component. Supports managed mode for centralized control and autonomous mode for independent operation.
* *Synchronization and security*: Evaluate the synchronization mechanisms, authentication models, and network requirements for each architecture to determine which fits your infrastructure and security posture.
