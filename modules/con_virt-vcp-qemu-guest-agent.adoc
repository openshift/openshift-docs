= QEMU guest agent for virtualized control planes

[role="_abstract"]
The QEMU guest agent is required on each control plane VM.
The hosting cluster uses a readiness probe to ping the guest agent and verify that the VM is healthy.
This health check enables the hosting cluster to safely coordinate node drain operations while maintaining `etcd` quorum.

Without the guest agent, the readiness probe cannot confirm that a VM is healthy, and the pod disruption budget cannot manage drain operations correctly.
