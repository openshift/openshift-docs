= Deleting the {pipelines-shortname} custom resources

[role="_abstract"]
You can remove the {pipelines-shortname} custom resources (CRs) to clean up the configuration before uninstalling the Operator. This involves deleting the optional `TektonResult` component, followed by the main `TektonConfig` CR.

.Procedure
. In the *Administrator* perspective of the web console, navigate to *Administration* -> *`CustomResourceDefinitions`*.

. Type `TektonResult` in the *Filter by name* field to search for the `TektonResult` Custom Resource Definition (CRD).

. Click the name of the `TektonResult` CRD to display the details page for the CRD.

. Click the `Instances` tab.

. If an instance appears, click the *Options* menu {kebab} for the displayed instance.

. Select *Delete `TektonResult`*.

. Click *Delete* to confirm the deletion of the CR.

. Repeat these steps, searching for `TektonConfig` in the *Filter by name* box. If any instances of this custom resource definition (CRD) exist, delete them.
+
[NOTE]
====
Deleting the CRs also deletes the {pipelines-title} components and all the tasks and pipelines on the cluster.
====
+
[IMPORTANT]
====
If you uninstall the Operator without removing the `TektonResult` CR, you cannot remove the {tekton-results} component later.
====
