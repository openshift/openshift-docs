= Plan a multiple network architecture

[role="_abstract"]
{product-title} administrators and users can use user-defined networks (UDNs) or `NetworkAttachmentDefinition` (NADs) to define the networks that handle the ordinary network traffic of the cluster. Understanding the available network topologies and their tradeoffs helps you select the right approach for your workloads and operational requirements.
