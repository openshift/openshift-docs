= View and manage ImageUpdaters in the GitOps Console

You can view, create, and manage Argo CD Image Updaters through the {gitops-shortname} Console plugin.

.Prerequisites

* The ImageUpdater CRD is installed on your cluster.
* You have access to the {OCP} web console.
* You have enabled the {gitops-shortname} Console plugin.
* Your permissions allow you to list ImageUpdaters in one or more namespaces.

.Procedure

. Navigate to *GitOps* -> *ImageUpdaters* in the *Administrator* or *Core platform* perspective.

. Optional: Select a specific project from the *Project* dropdown to view ImageUpdaters in that namespace, or select all projects to view ImageUpdaters across all namespaces.

. Optional: Filter ImageUpdaters using the available filters:
+
* *Apps*: Has Apps, No Apps
* *Ready*: Ready, Not Ready
+
For more information about filtering, searching, and pagination, see xref:../argocd_applications/gitops-console-features-troubleshooting.adoc#gitops-filter-search-paginate-about_gitops-console-features-troubleshooting[About filtering, searching, and pagination in the GitOps Console].

. To create a new ImageUpdater:
+
.. Click *Create ImageUpdater*.
.. Edit the YAML template with your ImageUpdater configuration including image list, update policy, and write-back method.
.. Click *Create*.

. To view ImageUpdater details, click an ImageUpdater name in the list.
+
The details page provides the following tabs:
+
* *Details*: View identity, status, and conditions
* *Recent Updates*: View image updates from the most recent reconciliation cycle
* *YAML*: Edit the ImageUpdater manifest
+
For more information about common console features, see xref:../argocd_applications/gitops-console-features-troubleshooting.adoc#ref-gitops-console-common-features_gitops-console-features-troubleshooting[Common console features].
