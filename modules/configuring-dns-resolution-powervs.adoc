= Configuring DNS resolution

[role="_abstract"]
DNS resolution configuration for {product-title} on {ibm-power-server-name} depends on whether you are installing a public or private cluster. Public clusters use {ibm-cloud-name} Internet Services (CIS) and private clusters use {ibm-cloud-name} DNS Services.

* If you are installing a public cluster, you use {ibm-cloud-name} Internet Services (CIS).
* If you are installing a private cluster, you use {ibm-cloud-name} DNS Services (DNS Services).
