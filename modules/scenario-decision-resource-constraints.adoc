= What are your cluster resource constraints?

*Tight on CPU/memory:*

* Use *Scenario 1* (Vector only) - minimal resource footprint
* Avoid Scenario 3 (COO adds significant overhead)

*Resources available:*

* *~5-10 vCPUs, ~10-20 GiB memory available*: Choose Scenario 2 with 1x.extra-small or 1x.small Loki
* *~40+ vCPUs, ~75+ GiB memory available*: Can support Scenario 3 with 1x.medium Loki
