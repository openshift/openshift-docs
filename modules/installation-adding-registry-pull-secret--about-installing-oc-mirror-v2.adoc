[id="installation-adding-registry-pull-secret_{context}"]
= Configure credentials that allow images to be mirrored

[role="_abstract"]
Create a container image registry credentials file so that you can mirror images from Red{nbsp}Hat to your mirror. Complete the following steps on the installation host.

[WARNING]
====
Do not use this image registry credentials file as the pull secret when you install a cluster. If you provide this file when you install cluster, all of the machines in the cluster will have write access to your mirror registry.
====

.Prerequisites
* [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# You configured a mirror registry to use in your disconnected environment.
* [.pr:openshift-rosa .pr:openshift-dedicated]#{empty}# You configured a mirror registry to use.
* You identified an image repository location on your mirror registry to mirror images into.
* You provisioned a mirror registry account that allows images to be uploaded to that image repository.
* You have write access to the mirror registry.

.Procedure
. [.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#{empty}# Download your `registry.redhat.io` {cluster-manager-url-pull}.

. [.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#{empty}# Make a copy of your pull secret in JSON format by running the following command:
+
[source,terminal,role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
----
$ cat ./pull-secret | jq . > <path>/<pull_secret_file_in_json>
----
+
[role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
Specify the path to the directory to store the pull secret in and a name for the JSON file that you create.
+
[role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
.Example pull secret
[source,json,role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
----
{
  "auths": {
    "cloud.openshift.com": {
      "auth": "b3BlbnNo...",
      "email": "you@example.com"
    },
    "quay.io": {
      "auth": "b3BlbnNo...",
      "email": "you@example.com"
    },
    "registry.connect.redhat.com": {
      "auth": "NTE3Njg5Nj...",
      "email": "you@example.com"
    },
    "registry.redhat.io": {
      "auth": "NTE3Njg5Nj...",
      "email": "you@example.com"
    }
  }
}
----
+

. [.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#{empty}# If the `$XDG_RUNTIME_DIR/containers` directory does not exist, create one by entering the following command:
+
[source,terminal,role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
----
$ mkdir -p $XDG_RUNTIME_DIR/containers
----
+

. [.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#{empty}# Save the pull secret file as `$XDG_RUNTIME_DIR/containers/auth.json`.

. Generate the base64-encoded user name and password or token for your mirror registry by running the following command:
+
[source,terminal]
----
$ echo -n '<user_name>:<password>' | base64 -w0
----
For `<user_name>` and `<password>`, specify the user name and password that you configured for your registry.
+
.Example output
[source,terminal]
----
BGVtbYk3ZHAtqXs=
----

. [.pr:openshift-origin]#{empty}# Create a `.json` file and add a section that describes your registry to it:
+
[source,json,role="pr:openshift-origin"]
----
{
  "auths": {
    "<mirror_registry>": {
      "auth": "<credentials>",
      "email": "you@example.com"
    }
  }
}
----
+
* [.pr:openshift-origin]#{empty}# For the `<mirror_registry>` value, specify the registry domain name, and optionally the port, that your mirror registry uses to serve content. For example, `registry.example.com` or `registry.example.com:8443`.
+
* [.pr:openshift-origin]#{empty}# For the `<credentials>` value, specify the base64-encoded user name and password for the mirror registry.

. [.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#{empty}# Edit the JSON file and add a section that describes your registry to it:
+
[source,json,role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
----
  "auths": {
    "<mirror_registry>": {
      "auth": "<credentials>",
      "email": "you@example.com"
    }
  },
----
+
* [.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#{empty}# For the `<mirror_registry>` value, specify the registry domain name, and optionally the port, that your mirror registry uses to serve content. For example, `registry.example.com` or `registry.example.com:8443`.
+
* [.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#{empty}# For the `<credentials>` value, specify the base64-encoded user name and password for the mirror registry.
+
[role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
