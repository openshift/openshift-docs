= About AppProjects in the GitOps Console

The {gitops-shortname} Console plugin provides list and details pages for Argo CD AppProjects in the {OCP} web console. You can view AppProjects, review destinations and allow or deny rules, and manage roles and sync windows.

The AppProjects list page provides the following capabilities:

* Filter AppProjects by description, applications, project type, source repositories, and destinations
* Search AppProjects by name
* View AppProject metadata including application count and configuration details
* Create AppProjects from YAML templates

The AppProject details page includes the following tabs:

* *Details*: Identity and project configuration summary
* *YAML*: Live manifest editor
* *Allow/Deny*: Allowed sources, destinations, and resource kind lists
* *Applications*: Applications that belong to this AppProject
* *Roles*: Argo CD project roles and bindings
* *Sync Windows*: Configured sync windows
* *Events*: Kubernetes events for the AppProject object

[NOTE]
====
{OCP} RBAC and Argo CD AppProject rules control different aspects. {OCP} RBAC controls console and API access to custom resources. AppProject rules control what Argo CD may sync for Applications in that project, including source repositories, destinations, and allowed resource kinds.
====
