= O-Cloud Manager REST APIs

[role="_abstract"]
The O-Cloud Manager exposes REST APIs that enable external systems to manage clusters without direct `oc` access to the hub cluster. These APIs support hand-off orchestration, where a Service Management and Orchestration (SMO) framework or external automation system drives the full cluster lifecycle through standard HTTP operations.

The APIs follow the O-RAN Alliance O2 IMS specification and are served over a single route on the hub cluster. Each API provides a distinct set of operations:

Inventory API:: `o2ims-infrastructureInventory/v2` — Query the physical infrastructure including resource pools, individual resources, locations, sites, resource types, and deployment managers.

Artifacts API:: `o2ims-infrastructureArtifacts/v1` — List available cluster templates, query template parameter schemas, and retrieve preconfigured defaults.

Provisioning API:: `o2ims-infrastructureProvisioning/v1` — Create, update, and delete provisioning requests to drive cluster lifecycle operations including provisioning, scaling, configuration changes, and upgrades.

Cluster API:: `o2ims-infrastructureCluster/v1` — Query provisioned node clusters, cluster resources, and node cluster types. Manage cluster event subscriptions for notifications on cluster state changes.

Monitoring API:: `o2ims-infrastructureMonitoring/v1` — Query and acknowledge alarms raised by managed clusters. Manage alarm subscriptions for event-driven monitoring and alerting.
