= Install the DTS console dashboard

[role="_abstract"]
You can install a DTS dashboard that integrates directly into the {product-title} web console.
This dashboard provides visibility of DPU telemetry metrics without requiring Grafana or additional tools.

.Prerequisites

* User workload monitoring is enabled in {product-title}.
* The DTS `ServiceMonitor` is configured and collecting metrics.
* You have access to the management cluster as a user with the `cluster-admin` role.

.Procedure

. Apply the console dashboard:
+
[source,terminal]
----
$ oc apply -f dts-console-dashboard.yaml
----

.Verification

. Verify that the dashboard `ConfigMap` is created:
+
[source,terminal]
----
$ oc -n openshift-config-managed get configmap dpf-dts-console-dashboard
----
+
.Example output
[source,terminal]
----
NAME                        DATA   AGE
dpf-dts-console-dashboard   1      ...
----

. Access the dashboard in the {product-title} web console:
+
.. Navigate to *Observe* -> *Dashboards*.
.. In the *Dashboard* dropdown menu, select *DOCA DPU Telemetry (DTS)*.
+
The dashboard displays PCIe link speed and width, uplink throughput, packets per second, errors and drops per second, and NIC channel activity, with each DPU as its own line.

[NOTE]
====
The DTS console dashboard renders against the platform Thanos/UWM Prometheus instance. No Grafana dependency is required for basic DPU telemetry viewing.
====
