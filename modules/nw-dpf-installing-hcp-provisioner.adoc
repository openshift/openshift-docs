= Install the DPF HCP Provisioner Operator

[role="_abstract"]
You can install the DPF HCP Provisioner Operator by using a Helm chart.
The Operator manages the lifecycle of hosted clusters for DPU environments.

.Prerequisites

* You have installed the multicluster engine for Kubernetes Operator and enabled hosted control planes.
* You have installed the MetalLB Operator and created a `MetalLB` instance.
* A storage class is available for etcd persistent volumes, such as {lvms} or an equivalent.
* You have installed the DPF Operator and the DPF CRDs are available.
* You have installed the `helm` CLI.

.Procedure

. Clone the DPF HCP Provisioner Operator repository:
+
[source,terminal]
----
$ git clone https://github.com/rh-ecosystem-edge/dpf-hcp-provisioner-operator.git
----

. Change to the cloned repository directory:
+
[source,terminal]
----
$ cd dpf-hcp-provisioner-operator
----

. Install the DPF HCP Provisioner Operator by using Helm:
+
[source,terminal]
----
$ helm install dpf-hcp-provisioner-operator \
    helm/dpf-hcp-provisioner-operator \
    --namespace dpf-hcp-provisioner-system \
    --create-namespace \
    --set image.repository=registry.redhat.io/dpu-kit-for-nvidia/dpf-hcp-provisioner-rhel10-operator \
    --set image.tag=v4.22
----
+
.Example output
[source,terminal]
----
NAME: dpf-hcp-provisioner-operator
LAST DEPLOYED: ...
NAMESPACE: dpf-hcp-provisioner-system
STATUS: deployed
----
+
[NOTE]
====
The Helm chart creates a singleton `DPFHCPProvisionerConfig` custom resource named `default` that defines the operator-wide configuration.
This resource controls settings such as the BlueField OCP layer image repository, MetalLB integration, and `DPUServiceTemplate` management.
To customize these settings, modify the `provisionerConfig` section in your Helm `values.yaml` file before running the `helm install` command.
====

.Verification

. Verify that the DPF HCP Provisioner Operator pod is running:
+
[source,terminal]
----
$ oc get pods -n dpf-hcp-provisioner-system
----
+
.Example output
[source,terminal]
----
NAME                                                    READY   STATUS    RESTARTS   AGE
dpf-hcp-provisioner-controller-manager-xxx-yyy          1/1     Running   0          1m
----


. Verify that the `DPFHCPProvisionerConfig` resource is created:
+
[source,terminal]
----
$ oc get dpfhcpprovisionerconfigs.provisioning.dpu.hcp.io default
----
