[id="rosa-sdpolicy-storage_{context}"]
= Storage

[role="_abstract"]
{product-title} provides encrypted-at-rest storage for an operating system (OS), node, and persistent volumes (PVs), with support for both block and shared storage.

[id="rosa-sdpolicy-encrytpted-at-rest-storage_{context}"]
== Encrypted-at-rest OS and node storage

[.product:rosa]#Worker#
[.product:rosa-classic]#Control plane, infrastructure, and worker#
nodes use encrypted-at-rest Amazon Elastic Block Store (Amazon EBS) storage.

[id="rosa-sdpolicy-encrytpted-at-rest-pv_{context}"]
== Encrypted-at-rest PV
EBS volumes that are used for PVs are encrypted-at-rest by default.

[id="rosa-sdpolicy-block-storage_{context}"]
== Block storage (RWO)
Persistent volumes (PVs) are backed by Amazon Elastic Block Store (Amazon EBS), which is ReadWriteOnce (RWO).

PVs can be attached only to a single node at a time and are specific to the availability zone in which they were provisioned. However, PVs can be attached to any node in the availability zone.

Each cloud provider has its own limits for how many PVs can be attached to a single node.

[id="rosa-sdpolicy-shared-storage_{context}"]
== Shared storage (RWX)
The AWS Container Storage Interface (CSI) Driver can be used to provide ReadWriteMany (RWX) support for {product-title}. A community Operator is provided to simplify setup.
