The {otel} 3.11.5 release resolves the following Common Vulnerabilities and Exposures (CVEs):

Go certificate verification no longer trusts certificates from compromised intermediate CAs::
Before this update, the certificate verification process in the Go `crypto/x509` package did not block trust in intermediate certificates associated with a compromised certificate authority (CA). As a consequence, a remote attacker could present a certificate that one of these intermediate authorities signed and impersonate a legitimate server during a secure connection. The attacker could then conduct a man-in-the-middle (MitM) attack to intercept or alter confidential communications. With this update, the Go `crypto/x509` package rejects the known untrusted intermediate certificates during certificate verification. As a result, Collector components that use the Go certificate verification process no longer trust certificates that are signed by the affected intermediate CAs. Connections to servers that present such certificates fail.
