= {istio} configuration

[role="_abstract"]

You can inspect and edit {istio} routing configuration in the console. Changes are written to the {ocp-product-title} API as {istio} custom resources.

The configuration list shows gateways, virtual services, destination rules, service entries, and related objects in the namespaces you select. Open an object to see its YAML, the workloads it selects, and any validation messages.

Wizards create the common routing objects without writing YAML first. Use a wizard to weight traffic across versions, inject a fault, or add a timeout. The wizard writes the same custom resources you can edit later in YAML. Wizards are described in "Configuration wizards".

You can also change YAML directly in the editor. Saving requires permission to update that resource in the namespace. The console does not keep a separate copy of the object. The {ocp-product-title} API is the source of the configuration.
