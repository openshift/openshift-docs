= Release notes for {pipelines-title} 1.23.4

[role="_abstract"]
{pipelines-title} General Availability 1.23.4 is available on {OCP} 4.14 and later supported versions.

[id="fixed-issues-1-23-4_{context}"]
== Fixed issues

.Operator

//SRVKP-14944
OLMv1 installation fails due to a duplicate multicluster proxy custom resource definition (CRD)::
Before this update, installing {pipelines-shortname} 1.22.6 or 1.23.0 using OLMv1 failed because of a duplicate multicluster proxy CRD. As a consequence, OLMv1 installation could not complete on those versions. With this update, {pipelines-shortname} resolves duplicate multicluster proxy CRD handling. As a result, OLMv1 installation succeeds in {pipelines-shortname} 1.23.4.
+
link:https://redhat.atlassian.net/browse/SRVKP-14944[SRVKP-14944]

.Security updates

//SRVKP-14294
CVE-2026-56854::
A security vulnerability (`CVE-2026-56854`) existed in the `golang.org/x/crypto/ssh` dependency in affected {pipelines-shortname} components, including `pipelines-triggers-core-interceptors-rhel9`, where `source-address` restrictions in authentication callback `Permissions` were not enforced across authentication callback types. With this update, {pipelines-shortname} upgrades the `golang.org/x/crypto` dependency to version 0.55.0, which addresses the vulnerability. As a result, {pipelines-shortname} enforces `source-address` restrictions across authentication callbacks.
+
link:https://redhat.atlassian.net/browse/SRVKP-14294[SRVKP-14294]
