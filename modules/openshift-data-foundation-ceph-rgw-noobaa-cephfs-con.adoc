= Configure image registry storage by using {rh-storage-first}

[role="_abstract"]
To back the {product-registry} with {rh-storage} on bare metal or {vmw-short}, install {rh-storage} and then point the registry at Ceph RGW, NooBaa, or CephFS storage.
