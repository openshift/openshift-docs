== Fixed issues

* Before this update, when you removed failure domains from the infrastructure specification, the {vmw-first} Problem Detector (VPD) logged errors about failure domain labels missing from nodes. As a consequence, VPD reported warnings that were not relevant after the failure domain change. With this release, VPD processing better handles failure domain changes in the infrastructure specification. As a result, those irrelevant warnings no longer appear. (link:https://issues.redhat.com/browse/OCPBUGS-127130[OCPBUGS-127130])

* Before this update, vSphere machine reconciliation made repeated vCenter API calls for the same virtual machine state and attached tags, and could repeat operations when task references were missing or status updates failed. As a consequence, reconciliation generated unnecessary vCenter API load, could submit duplicate virtual machine operations, and slowed machine provisioning in large clusters. With this release, VM power state and tag lookups are cached, attached-tag queries are batched, redundant property calls are skipped, and clone task references are retained across reconciles. As a result, new machines provision more reliably and with less vCenter load in large vSphere-backed clusters. (link:https://issues.redhat.com/browse/OCPBUGS-129659[OCPBUGS-129659])
