= {ols-long} version 1.1.5

[role="_abstract"]
{ols-official} 1.1.5 addresses security vulnerabilities, fixes software bugs, and improves stability. This release helps ensure continued support and stability for clusters running {ocp-product-title} 4.16 and later.

[id="ols-1-1-5-enhancements_{context}"]
== Enhancements

[role="_abstract"]
{ols-official} 1.1.5 remediates the `get_alerts` tool functionality by updating the Alertmanager port used by the {ocp-product-title} Model Context Protocol (MCP) server.

{ols-official} 1.1.5 includes the following enhancements:

//OLS-4353
* With this update, the {ocp-product-title} Model Context Protocol (MCP) server connects to Alertmanager on the correct port, `9094`, to align with the {ocp-product-title} monitoring stack. This ensures that questions that require the `get_alerts` tool work as expected.
