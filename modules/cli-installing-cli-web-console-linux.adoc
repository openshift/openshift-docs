= Install the OpenShift CLI on Linux using the web console

[role="_abstract"]
To manage your cluster and deploy applications from the command line on Linux, install the {oc-first} binary. You can download the {oc-first} from the web console.

.Procedure

. [.pr:microshift .pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp]#{empty}# From the web console, click *?*.
+
image::click-question-mark.png[]
. [.pr:microshift .pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp]#{empty}# Click *Command Line Tools*.
+
image::CLI-list.png[]
. [.pr:microshift .pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp]#{empty}# Select appropriate `oc` binary for your Linux platform, and then click *Download oc for Linux*.
. [.pr:microshift .pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp]#{empty}# Save the file.
. [.pr:microshift .pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp]#{empty}# Unpack the archive.
+
[source,terminal]
----
$ tar xvf <file>
----
. [.pr:openshift-rosa .pr:openshift-dedicated]#{empty}# Download the latest version of the `oc` CLI for your operating system from the link:https://console.redhat.com/openshift/downloads[*Downloads*] page on {cluster-manager}.
. [.pr:openshift-rosa .pr:openshift-dedicated]#{empty}# Extract the `oc` binary file from the downloaded archive.
+
[source,terminal]
----
$ tar xvf <file>
----
. Move the `oc` binary to a directory that is on your `PATH`.
+
To check your `PATH`, execute the following command:
+
[source,terminal]
----
$ echo $PATH
----

.Verification

* After you install the OpenShift CLI, you can use the `oc` command:
+
[source,terminal]
----
$ oc <command>
----
