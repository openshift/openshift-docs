= Argo CD Agent components and workflow

[role="_abstract"]
The Argo CD Agent extends {gitops-title} to manage applications across multiple clusters in a hub-and-spoke configuration. The Principal component runs on the hub cluster and the Agent component runs on each spoke cluster to synchronize application state.

To enable multi-cluster GitOps, you complete the following tasks:

. Review key Argo CD Agent concepts such as Principal and Agent namespaces, cluster contexts, and the hub-spoke communication model.
. Install the Principal component on the hub cluster by configuring an Argo CD custom resource (CR) with Agent support enabled, creating the required namespaces, and generating TLS certificates and secrets for secure communication.
. Set up the spoke cluster environment by creating Agent secrets on the Principal cluster, propagating CA certificates, and generating client certificates for each Agent.
. Install the Agent component on each spoke cluster by using Helm charts or an Argo CD CR in one of two operational modes:
* *Managed mode*: The Principal controls the Agent configuration and application lifecycle.
* *Autonomous mode*: The Agent operates independently and manages its own applications.
. Verify the Agent installation and deploy Argo CD applications in managed or autonomous mode.
