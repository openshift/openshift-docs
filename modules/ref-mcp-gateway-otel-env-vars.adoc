= OpenTelemetry environment variables

[role="_abstract"]
The standard {OTELName} environment variables configure how the {mcpg} components, `ext_proc`, router, and internal services, initialize OpenTelemetry SDK exporters and send observability data.

.OpenTelemetry environment variables
[cols="1,2,2", options="header"]
|===
| Variable | Description | Default

|`OTEL_EXPORTER_OTLP_ENDPOINT`
|Base OTLP endpoint for all signals
|none -- disabled

|`OTEL_EXPORTER_OTLP_TRACES_ENDPOINT`
|Override endpoint for traces only
|Falls back to base

|`OTEL_EXPORTER_OTLP_LOGS_ENDPOINT`
|Override endpoint for logs only
|Falls back to base

|`OTEL_EXPORTER_OTLP_INSECURE`
|Disable TLS verification
|false

|`OTEL_SERVICE_NAME`
|Service name reported in traces and logs
|mcp-gateway

|`OTEL_SERVICE_VERSION`
|Service version reported in traces and logs
|Build version
|===
