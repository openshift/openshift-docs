[id="zstream-4-14-76-fixed-issues_{context}"]
== Fixed issues

* Before this update, upstream GitHub Actions workflow and issue template files that were not used in the {product-title} downstream fork were present in the release branches. The downstream fork uses Prow and the `ci-operator` tool, but does not use the GitHub Actions. As a consequence, the `golangci-lint` job failed on every pull request. With this release, these unused files are removed from the release branches. As a result, the lint job does not fail on pull requests. (link:https://redhat.atlassian.net/browse/OCPBUGS-123714[OCPBUGS-123714])
