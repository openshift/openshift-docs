= Manage user authentication and identity providers

[role="_abstract"]
{product-title} authenticates every request to the API against a user identity that an identity provider supplies. By configuring identity providers, OAuth clients, and token policy, you control how team members and external tools log in to the cluster and how long their sessions remain valid.
