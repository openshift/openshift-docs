= Scenario decision matrix

[cols="2,3,3,3",options="header"]
|===
|Decision Factor |Scenario 1: Vector only |Scenario 2: Vector + Loki |Scenario 3: Vector + Loki + COO

|*Primary use case*
|Forward logs to existing external platform
|Local troubleshooting + optional external forwarding
|Complete observability in OpenShift console

|*Local log storage*
|No
|Yes (30 days max)
|Yes (30 days max)

|*Query interface*
|External platform UI (Splunk, CloudWatch, etc.)
|Grafana or Loki CLI
|OpenShift web console "Logs" tab

|*Object storage required*
|No
|Yes (S3, GCS, Azure Blob, or compatible)
|Yes (S3, GCS, Azure Blob, or compatible)

|*Resource requirements*
|Lowest (Vector DaemonSet only)
|Medium (Vector + Loki components)
|Highest (Vector + Loki + COO + monitoring stacks)

|*Operators to manage*
|1 (Red Hat OpenShift Logging Operator)
|2 (Logging + Loki)
|3 (Logging + Loki + COO)

|*Planning complexity*
|Simplest (configure destinations only)
|Moderate (sizing, object storage, retention)
|Complex (sizing, storage, multi-tenancy, UI plugins)
|===
