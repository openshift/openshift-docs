= Use persistent storage

[role="_abstract"]
Persistent storage on {microshift-short} lets applications retain data across pod restarts and node reboots. You can create and manage persistent volume claims (PVCs), control access modes, and use LVMS-backed thin volumes to provide durable storage to your workloads.
