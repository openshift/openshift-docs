= Do you already have a centralized logging platform?

*Yes, we use Splunk/ELK/Datadog/CloudWatch:*

* Consider *Scenario 1* (Vector only) if you never need to query logs locally
* Consider *Scenario 2* (Vector + Loki) if you want fast local queries for recent troubleshooting while also sending logs to your existing platform

*No, we need a logging solution:*

* Choose *Scenario 2* (Vector + Loki) for command-line or Grafana-based log queries
* Choose *Scenario 3* (Vector + Loki + COO) for browser-based log queries in OpenShift console
