= Monitor Argo CD custom resource workloads

[role="_abstract"]
Monitor Argo CD custom resource workloads to track workload availability and receive alerts when component pods fail to start or ready replicas do not match the desired count. Enable or disable workload monitoring for individual Argo CD instances.

[NOTE]
====
To monitor an Argo CD instance in a namespace not watched by the default openshift-monitoring stack, enable user workload monitoring. This applies to namespaces that do not start with `openshift-*`. Enabling user workload monitoring allows the monitoring stack to detect the created PrometheusRule.
====
