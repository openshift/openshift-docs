= Create an Argo CD instance

[role="_abstract"]
After installing the {gitops-title} Operator, create an Argo CD instance manually. Unlike on {OCP}, the Operator does not automatically create a default Argo CD instance on non-OpenShift Kubernetes platforms.

.Prerequisites

* You have installed the {gitops-title} Operator. For more information, see "Install {gitops-title} Operator via Helm chart".
* You have access to the cluster by using the `kubectl` or `oc` CLI.

.Procedure

. Create a namespace for your Argo CD instance:
+
[source,terminal]
----
$ kubectl create namespace openshift-gitops
----

. Create an Argo CD instance:
+
[source,terminal]
----
$ kubectl create -f - <<'EOF'
apiVersion: argoproj.io/v1beta1
kind: ArgoCD
metadata:
  name: openshift-gitops
  namespace: openshift-gitops
spec: {}
EOF
----

. Verify that the Argo CD instance pods are running:
+
[source,terminal]
----
$ kubectl get pods -n openshift-gitops
----
+
Example output:
+
----
NAME                                                     READY   STATUS    RESTARTS   AGE
openshift-gitops-application-controller-0                1/1     Running   0          2m
openshift-gitops-redis-7867d74fb4-xk2lm                  1/1     Running   0          2m
openshift-gitops-repo-server-6b8f8c8d7f-abc12            1/1     Running   0          2m
openshift-gitops-server-5d7f8c8b9c-def34                 1/1     Running   0          2m
----

.Verification

The Argo CD instance is created and running in the `openshift-gitops` namespace. All Argo CD components are running.
