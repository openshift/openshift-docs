= Edit cluster AWS tags by using the {rosa-cli}

[role="_abstract"]
Add, update, or remove the custom AWS tags on an existing {product-title} cluster by running the `rosa edit cluster` command with the `--tags` option. {product-title} applies cluster tags to all AWS resources that it creates for the cluster, including the resources for each machine pool.

.Prerequisites

* You installed and configured {rosa-cli} 1.2.68 or later.
* You logged in to your Red{nbsp}Hat account by using the {rosa-cli}.
* You have a {product-title} cluster that runs version 4.20.0 or later.

.Procedure

. Optional: To view the current tags for your cluster, run the following command:
+
[source,terminal]
----
$ rosa describe cluster --cluster=<cluster_name> --output json | jq '.aws.tags'
----
+
The output includes tags that Red{nbsp}Hat adds. Do not include these tags when you edit the cluster tags.

. Set the complete list of custom tags for the cluster by running the following command:
+
--
[source,terminal]
----
$ rosa edit cluster --cluster=<cluster_name> --tags '<key>:<value>,<key>:<value>'
----

where:

`<key>:<value>,<key>:<value>`:: Specifies the complete set of custom tags that you want on the cluster, as a comma-separated list of key-value pairs. {product-title} removes any existing custom tag that you omit. You can also specify the `--tags` option more than once. If a key or value includes a space or a colon, enclose the key or value in double quotation marks and enclose the entire value in single quotation marks, for example, `--tags '"Cost Center":"Finance Team"'`.
--
+
.Example command
[source,terminal]
----
$ rosa edit cluster --cluster=mycluster --tags cost-center:1234 --tags '"Cost Center":"Finance Team"'
----
+
[NOTE]
====
If you use the Windows Command Prompt (`cmd.exe`), escape double quotation marks by doubling them, for example, `--tags """Cost Center"":""Finance Team"""`.
====

. Optional: To remove all custom tags from the cluster, run the following command:
+
[source,terminal]
----
$ rosa edit cluster --cluster=<cluster_name> --tags ''
----
+
This command does not remove tags that you define on individual machine pools.

.Verification

* Verify that the cluster has the tags that you specified by running the following command:
+
[source,terminal]
----
$ rosa describe cluster --cluster=<cluster_name> --output json | jq '.aws.tags'
----
