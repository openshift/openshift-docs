= Install the {cgu-operator-full}

[role="_abstract"]
You can install the {cgu-operator-full} to orchestrate policy-based updates and configuration changes across your managed clusters.

After you install {cgu-operator}, see "Configure the {cgu-operator-full}".
To update a cluster with MachineConfigPools and ClusterGroupUpgrade resources, see "Update a cluster with MachineConfigPools and ClusterGroupUpgrade".
To upgrade managed clusters that you deployed with {ztp}, see "Upgrade managed clusters with the {cgu-operator-full}".
