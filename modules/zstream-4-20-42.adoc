== Fixed issues

* Before this update, the Berkeley Packet Filter (BPF) filesystem did not allow dots (".") in filenames. As a consequence, the Ingress Node Firewall could not attach rules to virtual LAN (VLAN) subinterfaces such as `bond0.12`. Attempting to pin a link for an interface containing a dot failed with an `operation not permitted` error. With this release, the Ingress Node Firewall sanitizes pin filenames by converting dots to a placeholder string. For example, `vlan.100` becomes `vlan_dot_100` before writing to the BPF filesystem. As a result, firewall rules can be successfully applied to subinterfaces such as VLANs on top of bonded interfaces. (link:https://issues.redhat.com/browse/OCPBUGS-31495[OCPBUGS-31495])

* Before this update, when you removed a MachineConfig that required a revert to a MachineOSBuild in a terminal state, the digested image push configuration was not changed. As a consequence, removing a MachineConfig in image mode failed and left the associated MachineConfigPool in an Updating state indefinitely. With this release, terminal builds update correctly when the digested image push configuration changes, enabling image reuse for a new build. As a result, you can successfully delete MachineConfigs in an image mode cluster. (link:https://issues.redhat.com/browse/OCPBUGS-128460[OCPBUGS-128460])

* Before this update, when a node with an assigned EgressIP was rebooted, the cluster manager immediately reassigned the EgressIP to a new node without waiting for the old node to remove it. As a consequence, both the old and new nodes responded to ARP requests for the same EgressIP with different MAC addresses, causing MAC address flapping. This could overload network switches, trigger port blocking, or disrupt network infrastructure depending on the configuration. With this release, the EgressIP removal process on the old node is prioritized to complete before the new node announces the IP. As a result, MAC address flapping and associated network disruptions are prevented. (link:https://issues.redhat.com/browse/OCPBUGS-128980[OCPBUGS-128980])
