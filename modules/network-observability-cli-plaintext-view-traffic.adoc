= Capture packets with OpenSSL plain text

[role="_abstract"]
Capture network packets and view the unencrypted plain text content from OpenSSL-encrypted connections by using the Network Observability CLI.

.Prerequisites

* The {oc-first} is installed.
* The Network Observability CLI (`oc netobserv`) plugin is installed.
* You have `cluster-admin` privileges.
* You have identified the pod IP address and port of the target application that uses OpenSSL.

.Procedure

. Start a packet capture with OpenSSL plain text enabled, filtering by the target pod IP and port:
+
[source,terminal]
----
$ oc netobserv packets --peer_ip=<pod_ip> --port=<pod_port> --enable_openssl
----
+
Replace `<pod_ip>` with the pod IP address and `<pod_port>` with the port number.
+
.Example
[source,terminal]
----
$ oc netobserv packets --peer_ip=10.131.0.15 --port=8443 --enable_openssl
----
+
The CLI displays a live table of captured packets with plain text data from OpenSSL-encrypted connections.

. Navigate the packet capture output:
+
--
* Press kbd:[Enter] to view detailed information about a selected packet.
* Use arrow keys (kbd:[↑] kbd:[↓]) to navigate through packets.
* Press kbd:[Tab] to switch between the packet list and detail panel.
--

. View the plain text content in the detail panel:
+
When you select a packet that contains decrypted OpenSSL data, the detail panel displays:
+
--
* Standard packet information (source, destination, protocol, length)
* Plain text content captured from the OpenSSL connection
* Associated network metadata
--

. Optional: Apply additional filters to narrow the capture scope:
+
[source,terminal]
----
$ oc netobserv packets --peer_ip=<pod_ip> --port=<pod_port> --protocol=TCP --enable_openssl
----
+
You can combine filters such as `--protocol`, `--namespace`, or other options to focus on specific traffic.

. Optional: Capture packets to a file for later analysis:
+
[source,terminal]
----
$ oc netobserv packets --peer_ip=<pod_ip> --port=<pod_port> --enable_openssl --output=file
----
+
The CLI writes captured packet data, including plain text content, to the `./output` directory.

. Stop the packet capture:
+
Press kbd:[Ctrl+C] to stop capturing packets and return to the shell prompt.

.Verification

. If you captured packets to a file, verify the output contains plain text data:
+
[source,terminal]
----
$ ls ./output/
----
+
The output directory contains timestamped capture files.

. Examine a capture file to confirm plain text data is present:
+
[source,terminal]
----
$ less ./output/<capture_file>
----
+
Look for decoded plain text content from OpenSSL connections alongside packet metadata.

[WARNING]
====
Captured plain text data can contain sensitive information such as passwords, API keys, or personal data. Implement appropriate access controls and retention policies for capture files. Delete files securely when no longer needed.
====
