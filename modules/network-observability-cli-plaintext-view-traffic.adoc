= Capture packets with OpenSSL plain text

[role="_abstract"]
Capture network packets and view the unencrypted plain text content from OpenSSL-encrypted connections by using the Network Observability CLI.

.Prerequisites

* The {oc-first} is installed.
* The Network Observability CLI (`oc netobserv`) plugin is installed.
* You have `cluster-admin` privileges.
* You have identified the pod IP address and port of the target application that uses OpenSSL.

[WARNING]
====
Plain text packet capture reveals unencrypted content from TLS connections, which can contain sensitive information such as passwords, API keys, or personal data. Ensure appropriate access controls and retention policies are in place. Delete capture files securely when no longer needed.
====

.Procedure

. Start a packet capture with OpenSSL plain text enabled, filtering by the target pod IP and port:
+
[source,terminal]
----
$ oc netobserv packets --peer_ip=<pod_ip> --port=<pod_port> --enable_openssl
----
+
Replace `<pod_ip>` with the pod IP address and `<pod_port>` with the port number.
+
.Example
[source,terminal]
----
$ oc netobserv packets --peer_ip=10.131.0.15 --port=8443 --enable_openssl
----
+
The CLI displays a live table of captured packets with plain text data from OpenSSL-encrypted connections.

. Pause the capture by pressing kbd:[Ctrl+Space].

. Navigate the packet capture output:
+
--
* Use the arrow keys (kbd:[↑] kbd:[↓]) to select a packet.
* When the capture is paused, the selected packet's payload appears in the detail panel.
* Press kbd:[Tab] to cycle focus between the filter input, packet table, and detail panel.
* Press kbd:[Esc] to resume the capture.
* You can also use the mouse to select packets and move focus between panels.
--

. Optional: Apply additional filters to narrow the capture scope:
+
[source,terminal]
----
$ oc netobserv packets --peer_ip=<pod_ip> --port=<pod_port> --namespace=<namespace> --protocol=TCP --enable_openssl
----
+
You can combine filters such as `--protocol`, `--namespace`, or other options to focus on specific traffic.

. Optional: Capture packets to a file for later analysis:
+
[source,terminal]
----
$ oc netobserv packets --peer_ip=<pod_ip> --port=<pod_port> --enable_openssl --copy
----
+
The CLI writes captured packet data, including plain text content, to the `./output/pcap` directory.

. Stop the packet capture:
+
Press kbd:[Ctrl+C] to stop capturing packets and return to the shell prompt.

.Verification

. If you captured packets to a file, verify the output:
+
[source,terminal]
----
$ ls ./output/pcap/
----
+
The directory contains timestamped `.pcapng` capture files. Open a capture file with Wireshark for packet-level analysis.

. Verify the captured plain text:
+
[source,terminal]
----
$ ls ./output/plaintext/
----
+
The directory contains timestamped `.jsonl` files with decoded plain text records.

. Examine a plaintext capture:
+
[source,terminal]
----
$ less ./output/plaintext/<timestamp>.jsonl
----
