= View and correlate decrypted traffic using the CLI

[role="_abstract"]
View and correlate decrypted plain text data with corresponding network packets in real time by using the Network Observability CLI.

.Prerequisites

* The {oc-first} is installed.
* The Network Observability CLI (`oc netobserv`) plugin is installed.
* Plain text capture is enabled in the `FlowCollector` custom resource.
* An application generating encrypted traffic is running in the cluster.

.Procedure

. Launch the Network Observability CLI in capture mode with plain text enabled:
+
[source,terminal]
----
$ oc netobserv flows --enable_plain_text=true
----
+
The CLI starts capturing network flows and plain text data, displaying them in an interactive text user interface (TUI).

. Use the TUI to view encrypted packets and plain text details:
+
* Use arrow keys to select flows in the main table.
* Press kbd:[Enter] to view detailed information about a selected flow.
* Use kbd:[Tab] to switch between different views in the TUI.

. View plain text data for encrypted connections:
+
.. In the flows table, identify flows with TLS encryption indicated by the `TLS` column.
.. Select an encrypted flow and press kbd:[Enter] to view details.
.. In the details view, scroll to the *Plain text* section to view the decrypted payload data.
+
The plain text section displays:
+
* The decrypted request or response payload
* The direction of the data (sent or received)
* The timestamp of the capture
* The correlation with the corresponding network packet

. Optional: Apply filters to focus on specific encrypted traffic:
+
[source,terminal]
----
$ oc netobserv flows --enable_plain_text=true --namespace=<target_namespace> --protocol=TCP --port=443
----
+
This example filters for HTTPS traffic on port 443 in a specific namespace.

. Optional: Correlate plain text data with packet details:
+
.. In the flow details view, note the packet sequence numbers and timestamps.
.. Compare the plain text data with packet metadata to verify correlation.
.. Use the packet capture feature to save raw packet data for further analysis:
+
[source,terminal]
----
$ oc netobserv packets --enable_plain_text=true --port=443
----

. To stop the capture, press kbd:[Ctrl+C].

. View the captured data, which is written to the `./output` directory:
+
[source,terminal]
----
$ ls ./output/flows/
----
+
The output includes flow data with embedded plain text information in JSON format.

.Verification

. Review the captured plain text data for expected content:
+
[source,terminal]
----
$ cat ./output/flows/<capture_date_time>.json | jq '.[] | select(.plain_text != null)'
----
+
This command displays flows that contain plain text data.

. Verify that plain text data corresponds to the expected application protocol:
+
.. For HTTP traffic, check for HTTP headers and request or response bodies.
.. For API traffic, verify JSON or XML payloads.
.. For custom protocols, confirm protocol-specific message formats.
