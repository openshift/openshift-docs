= Manage OLM Operators in a disconnected environment

[role="_abstract"]
Mirror and configure Operator catalogs for OLM to install and update Operators without internet connectivity.
For {product-title} clusters in disconnected environments, Operator Lifecycle Manager (OLM) by default cannot access the Red Hat-provided software catalog sources hosted on remote registries.
