= Verify an egress gateway

[role="_abstract"]
Verify the egress `Gateway` object and infrastructure that you created.

.Prerequisites

* You completed your `Gateway` object set up.
* You created a test pod in the `egress-test` namespace.

.Procedure

. Export the egress `Gateway` object IP address by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ export EGRESS_IP=$(oc get gtw _<kuadrant_egressgateway>_ -n _<gateway_system>_ \
    -o jsonpath='{.status.addresses[0].value}')
----
+
Replace `_<kuadrant_egressgateway>_` value with the egress `Gateway` object name.

. Send a request through the egress gateway infrastructure to verify connectivity by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc exec test-client -n egress-test -- \
    curl -s -o /dev/null -w "%{http_code}" -H "Host: _<httpbin.org>_" http://${EGRESS_IP}/get
----
+
Replace `_<httpbin.org>_` with the external target service.
+
.Expected output
[source,text]
----
200
----
