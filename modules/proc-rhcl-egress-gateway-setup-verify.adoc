= Verify an egress gateway

[role="_abstract"]
Verify the egress `Gateway` object and infrastructure that you created.

include::snippets/egress-gateway-ossm.adoc[]

.Prerequisites

include::snippets/egress-gateway-prereqs.adoc[]

.Procedure

. Create a test namespace such as `egress-test` by running the following command:
+
[source,terminal]
----
$ oc create namespace egress-test
----

. Create a test pod by using the following example:
+
[source,yaml]
----
apiVersion: v1
kind: Pod
metadata:
  name: test-client
  namespace: egress-test
spec:
  containers:
    - name: curl
      image: curlimages/curl:latest
      command: ["sleep", "infinity"]
  restartPolicy: Never
----

. Apply the `Pod` object by running the following command:
+
[source,terminal]
----
$ oc apply -f test-client
----

. Wait for the pod to be ready by running the following command:
+
[source,terminal]
----
$ oc wait --timeout=2m -n egress-test pod/test-client --for=condition=Ready
----

. Send a request through the egress gateway infrastructure to verify connectivity by running the following command:
+
[source,terminal]
----
$ oc exec test-client -n egress-test -- \
    curl -s -o /dev/null -w "%{http_code}" -H "Host: _<httpbin.org>_" http://${EGRESS_IP}/get
----
+
Replace `_<httpbin.org>_` with the external target service.
+
.Expected output
[source,text]
----
200
----
