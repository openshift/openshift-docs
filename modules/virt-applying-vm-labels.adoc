= Applying VM labels

[role="_abstract"]
Apply labels to a virtual machine in a cluster. Some labels are automatically applied and others are applied on a per-virtual machine basis. Labels allow administrators to group and filter virtual machines.

[IMPORTANT]
====
New labels are only applied to virtual machines created after the label is created.
====

.Prerequisites

* You have access to the {product-title} web console.
* You have `edit` or `admin` permissions in the target project.

.Procedure

. Click *Virtualization* -> *VirtualMachines* on the side menu to access the cluster settings. 

. Select a virtual machine using the *Local cluster* tree view or *Virtual machines* tab.

. Click the *Configuration* tab.

. Click *Labels and annotations*.

. Click *Add Labels*.

. Optional: Edit existing labels using the *Key* and *Value* fields.

. Optional: Add a new label.

.. Click *Add label*.
.. Use the *Key* and *Value* fields to add the new label values.
.. Click *Save*.

. Optional: Delete a label using the minus icon to the right of the *Value* field.
