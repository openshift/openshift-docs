= Create a virtual machine from a template

[role="_abstract"]
You can process a `VirtualMachineTemplate` to create a new virtual machine (VM) with your own parameter values.

.Prerequisites

* You have installed the `virtctl` CLI.
* A `VirtualMachineTemplate` exists in the cluster.
* You have the `process/create` subresource permission on the `VirtualMachineTemplate` resource.

.Procedure

. View the parameters defined in the template:
+
[source,terminal]
----
$ virtctl template process <template_name> --print-params
----

. Create a VM from the template:
+
[source,terminal]
----
$ virtctl template process <template_name> -p <PARAMETER>=<value> --create
----
+
Replace `<template_name>` with the name of the template. You must specify a value for each required parameter by using the `-p` flag. To set multiple parameters, repeat the `-p` flag.

.Verification

* Verify that the VM was created:
+
[source,terminal]
----
$ oc get vm
----
