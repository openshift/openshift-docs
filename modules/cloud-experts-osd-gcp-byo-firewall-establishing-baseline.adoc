= Establishing a baseline (optional)

[role="_abstract"]
Deploy a test workload to verify networking before, during, and after the migration.

.Procedure
. Create a test project and deploy a sample application:
+
[source,terminal]
----
$ oc new-project byo-fw-test
$ oc create deployment hello --image=quay.io/openshift/origin-hello-openshift
$ oc expose deployment hello --port=8080
$ oc expose svc hello
----

. Create a `LoadBalancer` service to test Cloud Controller Manager (CCM) behavior:
+
[source,terminal]
----
$ oc create -f - <<EOF
apiVersion: v1
kind: Service
metadata:
  name: test-lb
  namespace: byo-fw-test
spec:
  type: LoadBalancer
  ports:
  - port: 80
    targetPort: 8080
  selector:
    app: hello
EOF
----

. Wait for {GCP} to assign an external IP address to the load balancer. Assignment can take up to 90 seconds:
+
[source,terminal]
----
$ oc get svc test-lb -n byo-fw-test -w
----
+
.Example output
[source,terminal]
----
NAME      TYPE           CLUSTER-IP      EXTERNAL-IP     PORT(S)        AGE
test-lb   LoadBalancer   172.30.100.10   34.72.100.200   80:31234/TCP   75s
----

.Verification
. Verify that the API server is healthy:
+
[source,terminal]
----
$ oc get --raw /healthz
----
+
.Example output
[source,terminal]
----
ok
----

. Verify that the ingress route is responding:
+
[source,terminal]
----
$ curl -s http://$(oc get route hello -n byo-fw-test -o jsonpath='{.spec.host}')
----
+
.Example output
[source,terminal]
----
Hello OpenShift!
----
