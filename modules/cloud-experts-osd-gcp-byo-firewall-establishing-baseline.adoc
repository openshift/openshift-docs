= Establishing a baseline (optional)

[role="_abstract"]
Deploy a test workload to verify networking before, during, and after the migration.

.Procedure
. Create a test project and deploy a sample application:
+
[source,terminal]
----
$ oc new-project byo-fw-test
$ oc create deployment hello --image=quay.io/openshift/origin-hello-openshift
$ oc expose deployment hello --port=8080
$ oc expose svc hello
----

. Create a `LoadBalancer` service to test CCM behavior:
+
[source,terminal]
----
$ oc create -f - <<EOF
apiVersion: v1
kind: Service
metadata:
  name: test-lb
  namespace: byo-fw-test
spec:
  type: LoadBalancer
  ports:
  - port: 80
    targetPort: 8080
  selector:
    app: hello
EOF
----

. Wait for the load balancer to be assigned an external IP. This may take up to 90 seconds:
+
[source,terminal]
----
$ oc get svc test-lb -n byo-fw-test -w
----

.Verification
. Verify the API server is healthy:
+
[source,terminal]
----
$ curl -sk $(oc whoami --show-server)/healthz
----
+
The output should be `ok`.

. Verify the ingress route is responding:
+
[source,terminal]
----
$ curl -s http://$(oc get route hello -n byo-fw-test -o jsonpath='{.spec.host}')
----
+
The output should be `Hello OpenShift!`.
