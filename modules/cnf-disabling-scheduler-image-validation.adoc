= Disabling scheduler image validation

[role="_abstract"]
You can disable scheduler image validation by setting the `SCHEDULER_IMAGE_VALIDATION` environment variable to `false` in the NUMA Resources Operator subscription.

[WARNING]
====
Disabling scheduler image validation removes an important security control. With validation disabled, any user with write access to the `NUMAResourcesScheduler` custom resource can specify an arbitrary container image that will run with full scheduler privileges.

This creates a significant privilege escalation risk. A malicious scheduler image can:

* Access and manipulate all pods and nodes in the cluster
* Bind workloads to nodes in ways that compromise security or stability
* Observe sensitive cluster resource topology information
* Execute arbitrary code with scheduler service account permissions

Only disable validation in exceptional circumstances. If you disable validation, ensure that only cluster administrators can modify `NUMAResourcesScheduler` resources, and implement additional security controls to verify scheduler image integrity.
====

.Prerequisites

* You have installed the OpenShift CLI (`oc`).
* You have logged in as a user with `cluster-admin` privileges.
* You have installed the NUMA Resources Operator.

.Procedure

. Disable validation by patching the NUMA Resources Operator subscription by running the following command:
+
[source,terminal]
----
$ oc patch subscription numaresources-operator \
  -n openshift-numaresources \
  --type=merge \
  -p '{"spec":{"config":{"env":[{"name":"SCHEDULER_IMAGE_VALIDATION","value":"false"}]}}}'
----

. Wait for the NUMA Resources Operator pod to restart by monitoring the pod status with the following command:
+
[source,terminal]
----
$ oc get pods -n openshift-numaresources -w
----

. Verify that validation is disabled by checking the NUMA Resources Operator pod environment by running the following command:
+
[source,terminal]
----
$ oc exec -n openshift-numaresources deploy/numaresources-controller-manager -- \
  printenv SCHEDULER_IMAGE_VALIDATION
----
+
An example of the expected output is provided below:
+
[source,terminal]
----
false
----
