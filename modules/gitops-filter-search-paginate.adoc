= Filter, search, and paginate resources

You can search, filter, and paginate resources on the {gitops-shortname} Console plugin list pages.

.Prerequisites

* You have access to the {OCP} web console.
* The {gitops-shortname} Console plugin is enabled.

.Procedure

. To search for resources:

.. In the {OCP} web console, navigate to *GitOps* and select a resource type.

.. On the list page, use the search field to match resources by *Name* or *Label*.

.. Choose the search mode from the dropdown next to the field, for example, *Name* with *Search by name...*, or *Label*.
+
You can use search and filters together.

. To filter resources:

.. In the {OCP} web console, navigate to *GitOps* and select a resource type.

.. On the list page, click *Filter* to narrow the displayed resources by status or other properties.

.. Optional: Combine multiple filters to narrow the results further.

.. To clear filters, click the *Clear all filters* link or remove individual filter selections.

. To use pagination:

.. On the list page or details table, locate the pagination controls above and below the table.

.. To change the page size, select *10*, *20*, *50*, or *100* items per page from the dropdown. The default is *50*.

.. To navigate pages, use the *Previous* and *Next* buttons or click a specific page number.
+
When you use search or filters, pagination applies only to the matching resources. Changing the search or filters returns you to page 1.
