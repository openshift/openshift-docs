[id="self-managed-ocp-on-azure-boost_{context}"]
== Support for {VirtProductName} on self-managed {OCP} on Microsoft Azure Boost instances

In addition to the full-service model on ARO, Red{nbsp}Hat supports {VirtProductName} on self-managed {OCP} running on Microsoft Azure Boost instances.

This support is for a self-managed operator on a self-managed {OCP-short} cluster. The customer manages the control plane, underlying OS, and the cluster health.

The deployment should follow the architecture, sizing, and deployment guidelines specified for ARO.

[NOTE]
====
Running {VirtProductName} on self-managed {OCP} is optimized for standard enterprise applications, with no high-performance requirements.

For running I/O-intensive workloads, consult with a Red{nbsp}Hat representative about additional tuning.
====
