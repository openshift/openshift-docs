= Cloud platforms

[role="_abstract"]
{VirtProductName} is compatible with various public cloud platforms, each with specific storage options and support levels.

--
ifdef::openshift-enterprise[]
Installing {VirtProductName} on certain cloud platforms is a Technology Preview feature only.

include::snippets/technology-preview.adoc[]
:!FeatureName:
endif::[]
--

[cols="1,1,2a,2a", options="header"]
|===
| Vendor
| Status
| Storage
| Resources

| Amazon Web Services (AWS)
| GA
| * Elastic Block Store (EBS)
* Red{nbsp}Hat OpenShift Data Foundation (ODF)
* Portworx
* FSx (NetApp)
| For more information, see "Installing a cluster on AWS with customizations" in the Additional resources section.

| Red{nbsp}Hat OpenShift Service on AWS (ROSA)
| GA
| * EBS
* Portworx
* FSx (Q3)
* ODF

* link:https://docs.aws.amazon.com/rosa/latest/userguide/what-is-rosa.html[What is Red{nbsp}Hat OpenShift Service on AWS?] in the AWS documentation

| Oracle Cloud Infrastructure (OCI)
| GA

| * link:https://access.redhat.com/articles/7118050[{VirtProductName} and Oracle Cloud Infrastructure (OCI) known issues and limitations] in the Red{nbsp}Hat Knowledgebase

| GA

| Technology Preview
| * {gcp-short} native storage
| * link:https://access.redhat.com/articles/7120382[{VirtProductName} and Google Cloud known storage issues and limitations] in the Red{nbsp}Hat Knowledgebase

Bare-metal instances or servers offered by other cloud providers are not supported.
