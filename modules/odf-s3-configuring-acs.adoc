= Configuring {rh-storage} S3 integration in {product-title}

To configure {rh-storage} S3 backups, create a new S3 API compatible integration in {product-title}.

.Prerequisites
* {rh-storage-first} is installed and configured on your OpenShift cluster.
* The Multicloud Object Gateway is available.
* You have created an `ObjectBucketClaim` (OBC) for the backup bucket.
For more information, see "Object Bucket Claim" in the {rh-storage} documentation.
* You have the following information from the OBC secret and config map:
** The S3 endpoint URL
** The *Access key ID*
** The *Secret access key*
** The bucket name
* You have `read`, `write`, and `delete` permissions for the bucket.

.Procedure
. In the {product-title-short} portal, go to *Platform Configuration* -> *Integrations*.
. Scroll down to the *External backups* section and select *S3 API Compatible*.
. Click *New Integration*.
. Enter a name for *Integration Name*.
. Enter the number of backups to retain in the *Backups To Retain* box.
. For *Schedule*, select the backup frequency as daily or weekly, and select the time to run the backup process.
. Enter the *Bucket* name from your `ObjectBucketClaim`.
. Optional: Enter an *Object Prefix* if you want to save the backups in a specific folder structure.
. Enter the *Endpoint* for the Multicloud Object Gateway S3 service.
+
Use the internal service endpoint if Central runs on the same cluster as {rh-storage}, for example, `\https://s3.openshift-storage.svc`.
If Central runs on a different cluster, use the externally accessible S3 route.
. Enter a *Region* value, for example, `us-east-1`.
. Select *Path* as the *URL style*.
+
The Multicloud Object Gateway uses path-style bucket addressing.
. Enter the *Access Key ID* and the *Secret Access Key* from the OBC secret.
. Select *Test* to confirm that the integration with {rh-storage} S3 is working.
. Select *Create* to generate the configuration.

After the integration is configured, {product-title-short} automatically backs up all data according to the specified schedule.
