= Manage troubleshooting workflows from the CLI

[role="_abstract"]
When you resolve cluster incidents, monitor and control agentic runs directly from the command line so that you can manage troubleshooting workflows efficiently within your terminal-based environment.

Install the `oc-agentic` command-line interface (CLI) plugin to interact with the troubleshooting workflows system as an alternative to using the web console.

.Prerequisites

* You have installed the {oc-first}.

.Procedure

. Download and extract the plugin binary for your operating system:

** For Linux (amd64):
+
[source,terminal]
----
$ curl -L https://github.com/openshift/lightspeed-agentic-operator/releases/latest/download/oc-agentic_linux_amd64.tar.gz | tar xz
----

** For macOS (arm64):
+
[source,terminal]
----
$ curl -L https://github.com/openshift/lightspeed-agentic-operator/releases/latest/download/oc-agentic_darwin_arm64.tar.gz | tar xz
----

. Move the binary to a directory in your `$PATH`:
+
[source,terminal]
----
$ sudo mv oc-agentic /usr/local/bin/
----

. Verify the installation:
+
[source,terminal]
----
$ oc agentic version
----
