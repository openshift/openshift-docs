= Control virtualization role assignment with the web console

[role="_abstract"]
Disable automatic virtualization permissions to enforce stricter authorization boundaries in your cluster.

Disabling {VirtProductName} role aggregation is a Technology Preview feature only.

include::snippets/technology-preview.adoc[]
:!FeatureName:

.Prerequisites

* You have access to the cluster as a user with `cluster-admin` permissions.
* {VirtProductName} is installed.

.Procedure

. Navigate to *Virtualization* -> *Settings* in the web console.

. Click the *Preview features* tab.

. Toggle *Control default Virtualization permissions* to on to enable control over default virtualization role assignments.

. Click the *Cluster* tab.

. Under *General settings*, expand *Automatically grant Virtualization roles*.

. Select the required state:
+
* To disable role aggregation, toggle *Automatically grant Virtualization roles* to off.
* To enable role aggregation, toggle *Automatically grant Virtualization roles* to on.

.Verification

Navigate to *Virtualization* -> *Settings* -> *Cluster* and verify that *Automatically grant Virtualization roles* shows the intended state.
