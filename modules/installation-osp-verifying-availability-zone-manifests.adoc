= Check OpenStack availability zones in generated manifests

[role="_abstract"]
You can check Nova and Cinder zone pairs in the manifests before you install the cluster on {rh-openstack-first}. The manifests show zone pairs for control plane and compute machines.

.Prerequisites

* You have set Nova and Cinder availability zones in the `install-config.yaml` file.
* You have finished all other installation configuration changes.

.Procedure

. From the installation program directory, generate manifests by running the following command:
+
[source,terminal]
----
$ ./openshift-install create manifests --dir <installation_directory>
----

. In the `<installation_directory>/openshift/` directory, open the generated `ControlPlaneMachineSet` manifest. Check the `failureDomains.openstack` field to see whether each Nova zone pairs with the intended Cinder zone.

. Open the generated compute machine set manifests in the same directory. Check the `availabilityZone` and `rootVolume.availabilityZone` fields to see whether each machine set uses the intended Nova and Cinder zones.
