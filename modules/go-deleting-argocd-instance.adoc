= Deleting the Argo CD instances

[role="_abstract"]
Delete the Argo CD instances before you uninstall the {gitops-title} Operator. Deleting the `GitopsService` object does not delete `ArgoCD` custom resources.

.Procedure

. Delete the default Argo CD instance:
+
[source,terminal]
----
$ oc delete argocd openshift-gitops -n openshift-gitops
----

. Delete the Argo CD instances in any other namespace:
+
[source,terminal]
----
$ oc delete argocd --all -n <namespace>
----
+
--
where:

`<namespace>`:: Specifies a namespace that contains an Argo CD instance other than `openshift-gitops`.
--

. Optional: Delete an Argo CD instance from the web console.
+
.. In the *Administrator* perspective, click *Operators* -> *Installed Operators*.
.. Select the project that contains the Argo CD instance.
.. Select the {gitops-title} Operator, and then open the *Argo CD* tab.
.. Delete the instance from the options menu for that row.
