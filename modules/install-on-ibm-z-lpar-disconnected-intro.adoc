= Install on IBM Z (LPAR) in a disconnected environment

[role="_abstract"]
In {product-title} version {product-version}, you can install a cluster directly in a logical partition (LPAR) on {ibm-z-name} or {ibm-linuxone-name} infrastructure that you provision in a disconnected environment, without using a hypervisor layer.

[NOTE]
====
While this document refers to only {ibm-z-name}, all information in it also applies to {ibm-linuxone-name}.
====
