= Revert any changes I made by using the on-cluster mode of {image-mode-os-lower}

[role="_abstract"]
When you no longer need the software or drivers that you added with the on-cluster mode of {image-mode-os-lower}, remove the layer from a node by removing the node label. The node then reboots with the base image.
