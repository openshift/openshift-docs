= Cluster API operations

[role="_abstract"]
The Cluster API provides information about managed clusters (node clusters), their resource composition (cluster resources), node cluster types, and cluster resource types. It also supports subscriptions for change notifications when cluster resources are created, modified, or deleted.

All endpoints use the base path `/o2ims-infrastructureCluster/v1`.

The identifiers in this API, such as `nodeClusterId`, `nodeClusterTypeId`, `clusterResourceId`, `clusterResourceTypeId`, and `alarmDictionaryId`, are generated by the O-Cloud Manager. Use the corresponding list operation to discover these values. For example, send a request to the `/nodeClusters` endpoint to find a `nodeClusterId`. The `subscriptionId` value is returned in the response when you create a subscription.

|`GET`

|`/clusterResources`

|List cluster resource types

|`GET`

|`GET`
|`/subscriptions`
|List cluster subscriptions

|`GET`
|`/subscriptions/{subscriptionId}`
|Get a specific subscription

|`POST`
|`/subscriptions`
|Create a cluster subscription

|`DELETE`

|`/alarmDictionaries`
|List alarm dictionaries

|`GET`
|`/alarmDictionaries/{alarmDictionaryId}`
