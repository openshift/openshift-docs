= Edit the Keda Controller CR

[role="_abstract"]
You can use the following procedure to modify the `KedaController` custom resource (CR), which is automatically installed during the installation of the Custom Metrics Autoscaler Operator.

.Procedure

. In the {product-title} web console, click *Ecosystem* -> *Installed Operators*.

. Click *Custom Metrics Autoscaler*.

. On the *Operator Details* page, click the *KedaController* tab.

. On the *KedaController* tab, click *Create KedaController* and edit the file.
+
[source,yaml]
----
kind: KedaController
apiVersion: keda.sh/v1alpha1
metadata:
  name: keda
  namespace: openshift-keda
spec:
  watchNamespace: ''
  operator:
    logLevel: info
    logEncoder: console
    caConfigMaps:
    - thanos-cert
    - kafka-cert
    volumeMounts:
    - mountPath: /<path_to_directory>
      name: <name>
    volumes:
    - name: <volume_name>
      emptyDir:
        medium: Memory
    env:
      - name: KEDA_HTTP_DEFAULT_TIMEOUT
        value: "10000"
  metricsServer:
    logLevel: '0'
    auditConfig:
      logFormat: "json"
      logOutputVolumeClaim: "persistentVolumeClaimName"
      policy:
        rules:
        - level: Metadata
        omitStages: ["RequestReceived"]
        omitManagedFields: false
      lifetime:
        maxAge: "2"
        maxBackup: "1"
        maxSize: "50"
    env:
      - name: KEDA_HTTP_DEFAULT_TIMEOUT
        value: "10000"
  admissionWebhooks:
    env:
      - name: KEDA_HTTP_DEFAULT_TIMEOUT
        value: "10000"
  serviceAccount: {}
----
+
where:

`spec.watchNamespace`:: Specifies a single namespace in which the Custom Metrics Autoscaler Operator scales applications. Leave it blank or leave it empty to scale applications in all namespaces. This field should have a namespace or be empty. The default value is empty.
`spec.operator.logLevel`:: Specifies the level of verbosity for the Custom Metrics Autoscaler Operator log messages. The allowed values are `debug`, `info`, `error`. The default is `info`.
`spec.operator.logEncoder`:: Specifies the logging format for the Custom Metrics Autoscaler Operator log messages. The allowed values are `console` or `json`. The default is `console`.
`spec.operator.caConfigMaps`:: Specifies one or more config maps with CA certificates, which the Custom Metrics Autoscaler Operator can use to connect securely to TLS-enabled metrics sources. This field is optional.
`spec.operator.volumeMounts`:: Specifies the container mount path. This field is optional.
`spec.operator.volumes`:: Specifies a `volumes` block to list each projected volume source. This field is optional.
`spec.operator.env`:: Specifies specific environment variables that configure the Custom Metrics Autoscaler operator component. For each environment variable, specify a `name` and `value`. For example:
+
--
* `KEDA_HTTP_DEFAULT_TIMEOUT` configures a uniform timeout duration for all HTTP-based metrics providers, specified by the `value` setting in milliseconds. If not specified, outbound HTTP requests initiated by individual scalers fall back to hard-coded client defaults, which can cause failures in high-latency network environments. 
--
+ 
For a list of supported environment variables, see link:https://keda.sh/docs/2.20/operate/cluster/[Cluster in the KEDA documentation].
`spec.metricsServer.logLevel`:: Specifies the logging level for the Custom Metrics Autoscaler Metrics Server. The allowed values are `0` for `info` and `4` for `debug`. The default is `0`.
`spec.metricsServer.auditConfig`:: Specifies the audit logging configuration for the Custom Metrics Autoscaler Metrics Server and the audit policy to use, as described in the "Configuring audit logging" section.
`spec.metricsServer.env`:: Specifies specific environment variables that configure the Custom Metrics Autoscaler Metrics Server component. For each environment variable, specify a `name` and `value`.
`spec.admissionWebhooks.env`:: Specifies specific environment variables that configure the Custom Metrics Autoscaler admission webhooks component. For each environment variable, specify a `name` and `value`.

. Click *Save* to save the changes.
