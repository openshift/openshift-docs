= Query provisioned clusters

[role="_abstract"]
You can query the O-Cloud Manager Cluster API to discover provisioned clusters, their types, and the individual nodes within them. Each managed cluster registered with {rh-rhacm} corresponds to a node cluster in the API.

.Prerequisites

* You authenticated to the O-Cloud Manager REST API and set the `API_BASE_URL` and `MY_TOKEN` environment variables.
* At least one cluster has been provisioned through the O-Cloud Manager.

.Procedure

. List all provisioned node clusters by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureCluster/v1/nodeClusters" | jq
----
+
.Example output
[source,json]
----
[
  {
    "nodeClusterId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "nodeClusterTypeId": "d1eabf91-f0e6-5170-97dc-797d35146dad",
    "name": "my-sno-cluster",
    "description": "SNO RAN DU cluster",
    "extensions": {
      "clusterID": "c5e3f8a2-1b4d-4e6f-8a9b-0c1d2e3f4a5b",
      "platform": "BareMetal",
      "openshiftVersion": "4.20.4"
    }
  }
]
----

. Get details for a specific cluster by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureCluster/v1/nodeClusters/<node_cluster_id>" | jq
----
+
* Replace `<node_cluster_id>` with the `nodeClusterId` value.

. Filter clusters by name by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureCluster/v1/nodeClusters?filter=(eq,name,<cluster_name>)" | jq
----
+
* Replace `<cluster_name>` with the name of the cluster.

. List node cluster types to view the classification of managed clusters by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureCluster/v1/nodeClusterTypes" | jq
----
+
Each node cluster references a `nodeClusterTypeId` that maps to an entry in this list, categorizing clusters by platform and version.

. List individual nodes within a cluster by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureCluster/v1/clusterResources" | jq
----

. Optional: Create a subscription to receive notifications when cluster resources change:

.. Create a cluster resource subscription by running the following command:
+
[source,terminal]
----
$ curl -ks -X POST \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${MY_TOKEN}" \
  -d '{
    "consumerSubscriptionId": "69253c4b-8398-4602-855d-783865f5f25c",
    "filter": "",
    "callback": "https://smo.example.com/v1/o2ims_cluster_observer"
  }' \
  "https://${API_BASE_URL}/o2ims-infrastructureCluster/v1/subscriptions" | jq
----
+
* `consumerSubscriptionId` must be a valid UUID identifying this subscription on the consumer side.
* `callback` is the URL where the O-Cloud Manager sends change notifications. The callback URL must be reachable from the hub cluster and must respond to `GET` requests with a `204` status code. Unreachable endpoints are rejected at subscription creation time.
* `filter` can be left empty to receive all change notifications.

.. List existing subscriptions by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureCluster/v1/subscriptions" | jq
----
