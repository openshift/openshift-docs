= About data, telemetry, transcript, and feedback collection

[role="_abstract"]
{ols-long} sends your messages and cluster data through a redaction layer. It does this to clean the data before it goes to the LLM.

Do not enter anything into the {ols-long} interface that you want to keep private from the LLM.

Conversation data, including user inputs, LLM outputs, tool call details, retrieval-augmented generation (RAG) context, and associated metadata, is only sent to {red-hat} if telemetry is enabled. You can disable telemetry to stop all data collection by {red-hat}.

The transcript recording data uses the {red-hat} Insights system. It follows the same security rules and access limits as that system.
