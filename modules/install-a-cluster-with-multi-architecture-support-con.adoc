= Install a cluster with multi-architecture support

[role="_abstract"]
You can install an {product-title} cluster with support for configuring multi-architecture compute machines. Configuring the installation program to use the `multi` payload lets you deploy control plane and compute nodes with the CPU architectures that your workloads require.
