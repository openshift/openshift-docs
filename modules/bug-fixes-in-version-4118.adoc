= Bug fixes and security updates in version 4.11.8

[role="_abstract"]
This release includes the following bug fixes:

//ROX-37694
* Before this update, `NetworkPolicy` YAML files viewed or exported from the {product-title-short} portal were missing the `apiVersion` field, which made the exported YAML file invalid for use with tools such as `oc`. With this release, Red{nbsp}Hat fixed the `NetworkPolicy` YAML generation. As a result, users can apply exported `NetworkPolicy` YAML files directly to clusters.

//ROX-37822
* Before this update, the Scanner V4 matcher could run out of memory and crash while loading vulnerability data on clusters with default memory limits. With this release, Red{nbsp}Hat reduced the memory that the Scanner V4 matcher uses to process vulnerability data. As a result, the matcher loads vulnerability data without crashing.
