= External DNS Operator release notes

[role="_abstract"]
Review new features, enhancements, notable technical changes, and known bugs for the External DNS Operator. 

The External DNS Operator deploys and manages `ExternalDNS` to provide name resolution for services and routes, enabling your external DNS provider to resolve hostnames directly to {product-title} resources.
