= Migrating from local encryption to KMS encryption

[role="_abstract"]
You can migrate from local etcd encryption to KMS encryption to centralize key management.

.Prerequisites

* You have access to the cluster as a user with the `cluster-admin` role.
* You have enabled the `TechPreviewNoUpgrade` feature set to enable the `KMSEncryption` feature gate.
* Your cluster is currently using `aescbc` or `aesgcm` encryption.
* You have created the credential secret and optional CA bundle config map in the `openshift-config` namespace.
* You have the fully qualified OCI image pull spec with SHA256 digest for the KMS plugin image.

[IMPORTANT]
====
Create an etcd backup before migrating.
====

.Procedure

. Back up the current etcd encryption configuration by entering the following command:
+
[source,terminal]
----
$ oc get apiserver cluster -o yaml > apiserver-backup.yaml
----

. Edit the APIServer custom resource by entering the following command:
+
[source,terminal]
----
$ oc edit apiserver cluster
----

. Change the encryption type from `aescbc` or `aesgcm` to `KMS` and add the inline Vault configuration:
+
[source,yaml]
----
apiVersion: config.openshift.io/v1
kind: APIServer
metadata:
  name: cluster
spec:
  encryption:
    type: KMS
    kms:
      type: Vault
      vault:
        kmsPluginImage: <registry>/<repository>@sha256:<digest>
        vaultAddress: https://vault.example.com:8200
        vaultKeyPath: transit/keys/kms-key
        authentication:
          type: AppRole
          appRole:
            secret:
              name: vault-approle-secret
----

. Save and exit.
+
After configuration validation succeeds, migration starts.

.Verification

. Verify migration completion for the OpenShift API server by entering the following command:
+
[source,terminal]
----
$ oc get openshiftapiserver -o jsonpath='{range .items[0].status.conditions[?(@.type=="Encrypted")]}{.reason}{"\n"}{end}'
----

. Verify migration completion for the Kubernetes API server by entering the following command:
+
[source,terminal]
----
$ oc get kubeapiserver -o jsonpath='{range .items[0].status.conditions[?(@.type=="Encrypted")]}{.reason}{"\n"}{end}'
----

. Verify migration completion for the authentication Operator by entering the following command:
+
[source,terminal]
----
$ oc get authentication.operator.openshift.io -o jsonpath='{range .items[0].status.conditions[?(@.type=="Encrypted")]}{.reason}{"\n"}{end}'
----
+
All outputs show `EncryptionCompleted`.
