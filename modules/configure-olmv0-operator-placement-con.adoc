= Configure Operator placement

[role="_abstract"]
You can install OLM-based Operators on your {product-title} cluster by using Operator Lifecycle Manager (OLM).

[NOTE]
====
For information about how OLM updates Operators in the same namespace, see "Multitenancy and Operator colocation". This topic also describes an alternative method for installing Operators with custom global Operator groups.
====
