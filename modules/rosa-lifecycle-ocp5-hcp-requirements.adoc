= OpenShift 5 architecture and lifecycle requirements

[role="_abstract"]
Starting with Red Hat OpenShift 5.0, hosted control planes (HCP) is the mandatory architecture for {product-title}.

[IMPORTANT]
====
Red Hat OpenShift 5.x does not support Classic cluster architectures. New installations of OpenShift 5.x and in-place upgrades from OpenShift 4.x to 5.x are only available on hosted control planes.
====

== Key lifecycle considerations for OpenShift 5

* *Supported deployment architecture:* OpenShift 5.x clusters on {product-title} can only be provisioned using hosted control planes.
* *OpenShift 4.x Classic support:* OpenShift 4.x Classic clusters remain fully supported through the standard OpenShift 4 lifecycle policy. Customers can continue to deploy new OpenShift 4.x Classic clusters where supported.
* *In-place upgrades:* Direct in-place upgrades from OpenShift 4.x Classic clusters to OpenShift 5.x are not supported. Customers on Classic 4.x clusters must migrate workloads to a Hosted Control Planes cluster before updating to OpenShift 5.x.
