= OpenShift 5 architecture and lifecycle requirements

[role="_abstract"]
ifdef::openshift-rosa-hcp[]
Starting with Red{nbsp}Hat {OCP-short} 5.0, hosted control planes (HCP) is the standard architecture for {product-title}.
endif::openshift-rosa-hcp[]

ifdef::openshift-rosa,openshift-dedicated[]
Starting with Red{nbsp}Hat {OCP-short} 5.0, hosted control planes (HCP) is the standard architecture for managed {OCP-short} deployments.
endif::openshift-rosa,openshift-dedicated[]

[id="key-lifecycle-ocp5_{context}"]
== Key lifecycle considerations for OpenShift 5
ifdef::openshift-rosa-hcp[]
* *Supported deployment architecture:* {OCP-short} 5.x clusters on {product-title} can only be provisioned using hosted control planes.
endif::openshift-rosa-hcp[]
ifdef::openshift-rosa,openshift-dedicated[]
* *Supported deployment architecture:* Managed {OCP-short} 5.x clusters can only be provisioned using hosted control planes.
endif::openshift-rosa,openshift-dedicated[]
* *{product-title} 4.x support:* {product-title} 4.x clusters remain fully supported through the standard {product-title} 4 lifecycle policy. Customers can continue to deploy new {product-title} 4.x clusters where supported.
* *In-place upgrades:* Direct in-place upgrades from {product-title} 4.x clusters to {OCP-short} 5.x are only available on {hcp}.
