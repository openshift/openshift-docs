= OpenShift 5 architecture and lifecycle requirements

[role="_abstract"]
ifdef::openshift-rosa-hcp[]
Starting with Red{nbsp}Hat {OCP-short} 5.0, hosted control planes (HCP) is the mandatory architecture for {product-title}.
endif::openshift-rosa-hcp[]

ifdef::openshift-rosa,openshift-dedicated[]
Starting with Red{nbsp}Hat {OCP-short} 5.0, hosted control planes (HCP) is the mandatory architecture for managed {OCP-short} deployments.
endif::openshift-rosa,openshift-dedicated[]

[IMPORTANT]
====
Red{nbsp}Hat {OCP-short} 5.x does not support classic cluster architectures. New installations of {OCP-short} 5.x and in-place upgrades from {OCP-short} 4.x to 5.x are only available on hosted control planes.
====

[id="key-lifecycle-ocp5_{context}"]
== Key lifecycle considerations for OpenShift 5
ifdef::openshift-rosa-hcp[]
* *Supported deployment architecture:* {OCP-short} 5.x clusters on {product-title} can only be provisioned using hosted control planes.
endif::openshift-rosa-hcp[]
ifdef::openshift-rosa,openshift-dedicated[]
* *Supported deployment architecture:* Managed {OCP-short} 5.x clusters can only be provisioned using hosted control planes.
endif::openshift-rosa,openshift-dedicated[]
* *{OCP-short} 4.x Classic support:* {OCP-short} 4.x Classic clusters remain fully supported through the standard {OCP-short} 4 lifecycle policy. Customers can continue to deploy new {OCP-short} 4.x Classic clusters where supported.
* *In-place upgrades:* Direct in-place upgrades from {OCP-short} 4.x Classic clusters to OpenShift 5.x are not supported. Customers on Classic 4.x clusters must migrate workloads to a hosted control planes cluster before updating to {OCP-short} 5.x.
