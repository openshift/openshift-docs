= GitOps uninstallation and cleanup process

[role="_abstract"]
Uninstalling {gitops-title} is a two-step process that requires you to first delete the Argo CD instances and then uninstall the {gitops-title} Operator. Uninstalling only the Operator does not remove the Argo CD instances that were created.

The uninstallation process involves the following steps:

* *Delete Argo CD instances*: Remove Argo CD instances from the `openshift-gitops` namespace and any other namespaces where they were created.
* *Uninstall the {gitops-title} Operator*: Remove the Operator from your {OCP} cluster to complete the cleanup.
