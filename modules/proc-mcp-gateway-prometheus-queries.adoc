= Evaluate {mcpg} health and tool availability

[role="_abstract"]
Use Prometheus Query Language (`PromQL`) queries to evaluate the operational health, tool availability, failure rates, latency, and payload footprint for your {mcpg} deployment. {OCP} includes a built-in monitoring and alerting platform based on Prometheus.

You can use the {OCP} web console for inspection and visualization.

.Prerequisites

* You installed the Prometheus Operator.
* You configured your metrics endpoints.
* You logged into the OpenShift web console with developer or administrator permissions.

.Procedure

. Navigate to *Observe > Metrics* or *Observe > Targets* to verify scraping status.

. Select the target project or namespace, such as `mcp-system`.

. Paste `PromQL` queries directly into the *Expression* search bar and click *Run Queries*.

. Check the current tool count per upstream server by using the following `PromQL` query:
+
[source,text]
----
`mcp_broker_tools_discovered`
----
. Check the tool discovery failure rate per server by using the following `PromQL` query:
+
[source,text]
----
`sum(rate(mcp_broker_discovery_total{status="failure"}[5m])) by (server_name)`
----

. See MCP servers with active connection failures by using the following `PromQL` query:
+
[source,text]
----
`sum(rate(mcp_broker_upstream_connection_failures_total[5m])) by (server_name) > 0`
----

. See the `p99` discovery latency per MCP server by using the following `PromQL` query:
+
[source,text]
----
`histogram_quantile(0.99, sum(rate(mcp_broker_discovery_duration_seconds_bucket[5m])) by (server_name, le))`
----

. See the total `tools/list` context footprint across all MCP servers by using the following `PromQL` query:
+
[source,text]
----
`sum(mcp_broker_tools_list_response_bytes)`
----

. Switch between the *Table* view for exact numeric readouts and the *Chart* view to see visual trends over time.
