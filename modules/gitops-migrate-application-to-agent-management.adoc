= Migrate an existing application to agent management

Move the application responsibility from the hub application controller (push model) to the spoke local application controller (pull model). Migrate one application at a time. Applications without the agent label continue to be reconciled by the hub application controller.

.Prerequisites

* The principal is enabled with a label selector on the hub cluster.
* The agent is enabled with a label selector on the spoke cluster.

.Procedure

. Verify the agent cluster secret on the hub cluster has the required annotation:
+
[source,terminal]
----
$ oc get secret <cluster_secret_name> -n <principal_namespace> -o jsonpath='{.metadata.annotations.argocd\.argoproj\.io/skip-reconcile}'
----
+
The output should show `true`. The `argocd-agentctl agent create` command adds the `argocd.argoproj.io/skip-reconcile: "true"` annotation automatically. This annotation prevents the hub application controller from reconciling applications whose destination is the agent cluster.

. Update the `AppProject` that the application references to add the agent cluster as a destination:
+
[source,terminal]
----
$ oc patch appproject <project_name> -n <principal_namespace> --type=json \
    -p '[{"op":"add","path":"/spec/destinations/-","value":{"name":"<agent_name>","namespace":"*"}}]'
----
+
Replace `<agent_name>` with the name of your agent cluster.
+
[NOTE]
====
This command adds the agent cluster to the existing destinations list. If you need to add the agent namespace to `sourceNamespaces`, run:

[source,terminal]
----
$ oc patch appproject <project_name> -n <principal_namespace> --type=json \
    -p '[{"op":"add","path":"/spec/sourceNamespaces/-","value":"<agent_namespace>"}]'
----

Replace `<agent_namespace>` with the namespace where the agent is deployed.
====

. Label the `AppProject`:
+
[source,terminal]
----
$ oc label appproject <project_name> -n <principal_namespace> argocd-agent=true
----

. Label the repository secrets that the application uses:
+
[source,terminal]
----
$ oc label secret <repository_secret_name> -n <principal_namespace> argocd-agent=true
----
+
[NOTE]
====
The agent syncs only project-scoped repository secrets. Ensure that your repository secrets are scoped to the `AppProject` to avoid authentication failures after migration.
====

. Update the application destination to the agent cluster:
+
[source,terminal]
----
$ oc patch application <application_name> -n <principal_namespace> --type=merge \
    -p '{"spec":{"destination":{"name":"<agent_name>"}}}'
----

. Label the application:
+
[source,terminal]
----
$ oc label application <application_name> -n <principal_namespace> argocd-agent=true
----
+
The principal detects the labeled application and sends it to the agent. The spoke cluster application controller reconciles the application and reports status back to the hub.

.Verification

. Verify the application is synced and healthy:
+
[source,terminal]
----
$ oc get application <application_name> -n <principal_namespace> -o jsonpath='{.status.sync.status} {.status.health.status}'
----
+
The output should show `Synced Healthy`.

. Verify the application destination points to the agent cluster:
+
[source,terminal]
----
$ oc get application <application_name> -n <principal_namespace> -o jsonpath='{.spec.destination.name}'
----
+
The output should match `<agent_name>`.
