= Supported platforms for Service Mesh

[role="_abstract"]

The following platform versions support Service Mesh control plane version 3.5:

ifdef::openshift-rosa,openshift-rosa-hcp,openshift-dedicated[]
* Red Hat OpenShift Container Platform, applicable versions listed on the link:https://access.redhat.com/support/policy/updates/openshift_operators[OpenShift Operator Life Cycles] page
endif::openshift-rosa,openshift-rosa-hcp,openshift-dedicated[]
ifndef::openshift-rosa,openshift-rosa-hcp,openshift-dedicated[]
* Red Hat OpenShift Container Platform, applicable versions listed on the link:https://access.redhat.com/support/policy/updates/openshift_operators[OpenShift Operator Life Cycles] page
endif::openshift-rosa,openshift-rosa-hcp,openshift-dedicated[]
* {product-dedicated} version 4
* Azure Red Hat OpenShift (ARO) version 4
* Red Hat OpenShift Service on AWS (ROSA)

The OpenShift Service Mesh Operator supports many versions of `{istio}`.

If you are installing Service Mesh on a "Restricted network", follow the instructions for your chosen OpenShift Container Platform infrastructure.

For additional information about Service Mesh lifecycle and supported platforms, see the "Support Policy".
