= Configure image registry storage on {gcp-short} user-provisioned infrastructure

[role="_abstract"]
Save your container images to a durable storage location by configuring the built-in image registry to use dedicated {gcp-short} storage. This setup provides persistent, scalable storage for your registry that is separate from ephemeral cluster storage.
