= Understanding deployment scenarios

OpenShift Logging supports three deployment scenarios based on which components you install:

* *Scenario 1: Vector only* - Forward logs to external systems without local storage
* *Scenario 2: Vector + Loki* - Local log storage plus optional external forwarding
* *Scenario 3: Vector + Loki + COO* - Full observability stack with console UI

Your scenario choice acts as a gate: some planning topics only apply to scenarios that include Loki or the Cluster Observability Operator (COO). Use this guide to identify which scenario fits your needs, then follow the relevant planning topics.
