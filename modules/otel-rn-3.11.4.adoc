The {otel} 3.11.4 release resolves these Common Vulnerabilities and Exposures (CVEs):

System certificate authority store included intermediate CA certificates with weak private keys::
Before this update, the system certificate authority (CA) store in Red Hat products, distributed via the `ca-certificates` RPM package, included root CA certificates that signed intermediate CA certificates with weak private keys. These certificates were issued by the eMudhra certificate authority. As a consequence, a man-in-the-middle attacker could use this vulnerability to issue certificates for arbitrary host names that a TLS/SSL client using the system CA store would consider trusted, potentially causing the client to connect to malicious sites. With this update, the vulnerable CA certificates are removed from the system CA store. As a result, clients no longer trust certificates signed by these compromised intermediate CAs.
