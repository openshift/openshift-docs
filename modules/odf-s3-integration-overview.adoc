= {rh-storage} S3 backup integration overview

[role="_abstract"]
You can use {rh-storage-first} as a supported S3-compatible storage destination for {product-title} Central database backups.
{rh-storage} provides the Multicloud Object Gateway, which exposes an S3-compatible endpoint for object storage.
After integrating with {rh-storage}, you can schedule daily or weekly backups and perform manual on-demand backups.

The backup includes the entire {product-title-short} database, which includes all configurations, resources, events, and certificates.
Make sure that you store backups securely.

{product-title-short} uses the *S3 API Compatible* integration type to connect to {rh-storage}.
