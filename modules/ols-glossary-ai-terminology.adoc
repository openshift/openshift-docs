= Artificial intelligence terminology

[role="_abstract"]
The following industry-standard artificial intelligence (AI) terms are common terminology throughout the {ols-official} documentation.

agent::
An AI system that plans and takes actions to accomplish specific goals, often by calling tools or other services, instead of only returning text. Workflows that use this capability are described as _agentic_.

artificial intelligence (AI)::
The capability of a computer system to perform tasks that typically require human intelligence, such as reasoning, language understanding, and problem solving.

context window::
The maximum amount of text, measured in tokens, that a large language model can process at one time, including both the input prompt and the generated output.

embedding::
A numerical vector representation of text that captures its meaning so that a system can compare and retrieve semantically similar content.

fine-tuning::
The process of further training a pretrained model on a specialized dataset to improve its performance for a specific domain or task.

generative AI (gen AI)::
A class of AI that creates new content, such as text, code, or images, based on patterns learned from training data.

hallucination::
A response from a large language model that is presented as factual but is incorrect, fabricated, or not supported by the provided context.

inference::
The process in which a trained model is loaded into memory and then makes predictions based on input data. For example, "The Llama-3.2-90B-Vision-Instruct-FP8-dynamic model performs inference to identify objects in an image."

large language model (LLM)::
A machine learning model trained on extensive text datasets to generate and interpret natural language. {ols-official} connects to an LLM to answer user questions.

prompt::
The input text sent to a large language model to request a response.

retrieval-augmented generation (RAG)::
An architecture pattern that grounds large language model responses by retrieving relevant information from external knowledge bases.

system prompt::
Instruction text that sets a large language model's behavior and is combined with the user's question.

token::
A fundamental unit of text, such as a word fragment or character sequence, that a large language model processes. Model input and output limits are measured in tokens.
