= Artificial intelligence terminology

The following general artificial intelligence (AI) terms are used throughout the {ols-official} documentation.

agent::
An AI system that can plan and take actions to accomplish a goal, often by calling tools or other services, instead of only returning text. Workflows that use this capability are described as _agentic_.

artificial intelligence (AI)::
The capability of a computer system to perform tasks that typically require human intelligence, such as reasoning, language understanding, and problem solving.

context window::
The maximum amount of text, measured in tokens, that a large language model can consider at one time, including both the input and the generated output.

embedding::
A numerical vector representation of text that captures its meaning so that a system can compare and retrieve semantically similar content.

fine-tuning::
The process of further training a pretrained model on a specialized data set to improve its performance for a specific domain or task.

generative AI (gen AI)::
A class of AI that creates new content, such as text, code, or images, based on patterns learned from training data.

hallucination::
A response from a large language model that is presented as factual but is incorrect, fabricated, or not supported by the provided context.

inference::
The process of running a trained model to generate a response from a given input.

large language model (LLM)::
A machine learning model trained on large amounts of text that generates and interprets natural language. {ols-official} connects to an LLM to answer user questions.

prompt::
The input text sent to a large language model to request a response. A _system prompt_ is instruction text that sets the model's behavior and is combined with the user's question.

retrieval-augmented generation (RAG)::
A technique that supplements a large language model with relevant information retrieved from an external knowledge source so that responses are grounded in that content.

token::
The unit of text, such as a word fragment or character sequence, that a large language model processes. Model input and output limits are measured in tokens.
