= IPv6 limitations

[role="_abstract"]
{product-title} supports IPv6 on Nutanix with platform-specific limitations.

Guest IPv6 is supported only on unmanaged (Network Controller) VLAN subnets when the physical fabric provides IPv6. Basic VLAN subnets do not support IPv6.
