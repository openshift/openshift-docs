= Spectrum-X deployment considerations

[role="_abstract"]
Use these considerations to assess the example configuration and confirm platform support before deploying Spectrum-X on {product-title}.

The host configuration repository in the additional resources section describes a lab that ran NVIDIA Network Operator 26.1.0 and Spectrum-X RA2.1 with Dell XE9680 H200 worker nodes and BlueField-3 SuperNICs.
Its README file lists {product-title} 4.20 and 4.21 as tested cluster versions.

[NOTE]
====
The repository's tested versions describe its lab baseline, not the supported product matrix.
Meeting notes mention {product-title} 4.22, which the repository does not list.
Confirm the supported combination with Red Hat and NVIDIA before deployment.
====

.Spectrum-X deployment support considerations
[cols="1,2",options="header"]
|===

|Area |Scope

|Guide scope
|This guide documents the repository's single-plane example.
It does not establish support for other hardware, firmware, operator releases, or Spectrum-X reference architecture versions.

|OpenShift version
|NVIDIA Network Operator platform support does not by itself confirm Spectrum-X reference architecture support for a particular OpenShift version.

|Hardware
|The repository example uses Dell XE9680 H200 workers, BlueField-3 SuperNICs, and Spectrum switches. Match the adapter model and firmware, switch model and software, and host configuration against the applicable vendor support matrix.

|NVIDIA Network Operator
|The example pins NVIDIA Network Operator 26.1.0 and driver package version 3.3.0.
Use a compatible, supported set of Operator, driver, firmware, and NIC configuration versions for the target system.

|Spectrum-X profile
|The example configures the RA2.1 profile.
The NVIDIA 26.1 NIC configuration documentation identifies Spectrum-X NIC configuration as Technology Preview.
Check the status in the documentation for the version you deploy.

|Other deployment modes
|The configuration procedures in this guide apply to one plane.
They do not configure or imply support for a multi-plane deployment.

|===
