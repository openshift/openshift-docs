= Spectrum-X deployment considerations

[role="_abstract"]
A single-plane Spectrum-X deployment on {product-title} requires compatible worker hardware, adapters, switches, firmware, and Operator versions.

The Spectrum-X host configuration examples repository describes a deployment with NVIDIA Network Operator 26.1.0, Spectrum-X RA2.1, Dell XE9680 H200 worker nodes, and BlueField-3 SuperNICs.
Its `README` file lists {product-title} 4.20 and 4.21 as tested cluster versions.

[NOTE]
====
The repository's tested versions describe its lab baseline, not the supported product matrix.
Confirm the supported combination with Red Hat and NVIDIA before deployment.
====

.Spectrum-X deployment support considerations
[cols="1,2",options="header"]
|===

|Area |Scope

|Example scope
|The single-plane example covers network fabric configuration, rather than an end-to-end artificial intelligence (AI) workload, storage service, or data processing unit (DPU) deployment.
The example does not establish support for other hardware, firmware, Operator releases, or Spectrum-X reference architecture versions.

|OpenShift version
|NVIDIA Network Operator platform support does not by itself confirm Spectrum-X reference architecture support for a particular OpenShift version.

|Hardware
|The example uses Dell XE9680 H200 workers, BlueField-3 SuperNICs, and Spectrum switches. The adapter model and firmware, switch model and software, and host configuration must match the applicable vendor support matrix.

|NVIDIA Network Operator
|The example uses NVIDIA Network Operator 26.1.0 and driver package version 3.3.0. The Operator, driver, firmware, and network interface controller (NIC) configuration versions must be compatible with the target system.

|Spectrum-X profile
|The example configures the RA2.1 profile.
The NVIDIA 26.1 NIC configuration documentation identifies Spectrum-X NIC configuration as Technology Preview.
The feature status must be confirmed in the documentation for the deployed version.

|Other deployment modes
|The example configuration applies to one plane and does not establish support for a multi-plane deployment.

|===
