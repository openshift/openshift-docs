= Egress gateway test pod reference

[role="_abstract"]
You can set up a test pod to check that traffic is flowing as expected through your egress `Gateway` object and infrastructure. Use your test pod at various points in your workflow to solve problems.

.Prerequisites

include::snippets/egress-gateway-prereqs.adoc[]

.Procedure

. Set up a test pod by using the following YAML as an example:
+
[source,yaml]
----
---
apiVersion: v1
kind: Namespace
metadata:
  name: egress-test
---
apiVersion: v1
kind: Pod
metadata:
  name: test-client
  namespace: egress-test
spec:
  containers:
    - name: curl
      image: curlimages/curl:latest
      command: ["sleep", "infinity"]
  restartPolicy: Never
----

. Apply the `Pod` object by running the following command:
+
[source,terminal]
----
$ oc apply -f test-client
----

. Wait for the pod to be ready by running the following command:
+
[source,terminal]
----
$ oc wait --timeout=2m -n egress-test pod/test-client --for=condition=Ready
----
