= Updating the cluster to {op-system} 10.x


[role="_abstract"]
If you have {product-title} 5.0 with {op-system-first} version 9.x, you can update the nodes in your cluster to use {op-system} 10.x.

For new installations of {product-title} 5.0, {op-system} 10.x is installed by default.

{op-system} is a purpose-designed operating system for use with containers that is deployed by default on all {product-title} nodes. Each version of {op-system} is based on a specific version of {op-system-base-full}. {op-system} 10.x is based on {op-system-base} 10.x.

[IMPORTANT]
====
You cannot update the {op-system} version in a cluster that is using the runC container runtime, because runC is deprecated in {product-title} 5.0. You must configure your cluster to use the crun container runtime. Starting in {product-title} 4.18, crun is the default container runtime for new installations. For more information, see "Configuring the container runtime".
====
