= Install the SR-IOV Network Operator

[role="_abstract"]
The SR-IOV Network Operator centralizes the configuration and lifecycle management of Single Root I/O Virtualization (SR-IOV) devices and network attachments. Install the Operator before you configure SR-IOV networking on your cluster.
