= Update the boot loader on RHCOS nodes

[role="_abstract"]
{op-system-first} nodes that boot with UEFI Secure Boot use the GRUB boot loader, which is updated separately from the operating system. You can let the cluster update the boot loader automatically, or apply the update manually to each node.
