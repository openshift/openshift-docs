= Configure a cluster-wide proxy

[role="_abstract"]
{product-title} lets you route egress HTTP and HTTPS traffic through a cluster-wide proxy. You can configure the proxy by creating or updating the cluster `Proxy` object, verify that the configuration is active, and remove the proxy when it is no longer needed.
