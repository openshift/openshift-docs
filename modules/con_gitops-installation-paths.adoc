= Installation paths

[role="_abstract"]
You can install the {gitops-title} Operator using the {OCP} web console or the OpenShift CLI (`oc`). Both methods install the same Operator and create the default Argo CD instance.

*Web console installation*

Install through the OperatorHub interface in the {OCP} web console. This method provides a graphical interface for selecting the Operator version, approval strategy, and installation namespace.

Use web console installation when:

* You prefer a visual installation workflow
* You are new to {OCP} or Operators
* You want to review available versions before installing

*CLI installation*

Install by creating Subscription and OperatorGroup custom resources using the `oc` command-line tool. This method enables automation and scripting.

Use CLI installation when:

* You are automating cluster configuration
* You manage infrastructure as code
* You need to install on multiple clusters with consistent configuration
* You prefer command-line workflows

Both installation methods create the default cluster-scoped Argo CD instance in the `openshift-gitops` namespace automatically.
