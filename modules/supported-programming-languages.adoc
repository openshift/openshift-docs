= Supported programming languages

[role="_abstract"]
Scanner can check for vulnerabilities in dependencies for the following programming languages:

[cols="1,3",options="header"]
|===
| Programming language | Package format

| Go^[1]^
| Binaries: Scanner V4 analyzes the standard library version used to build the binary. If the build uses module support (go.mod), Scanner V4 also analyzes the dependencies.

| Java
| JAR, WAR, EAR, JPI, HPI

| JavaScript
| package.json

| Python
| egg, wheel

| Ruby
| gem
|===
. Only supported in Scanner V4.
