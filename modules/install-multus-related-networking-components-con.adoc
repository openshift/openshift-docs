= Install Multus-related networking components

[role="_abstract"]
{product-title} includes the Multus CNI meta-plug-in by default, enabling pods to connect to multiple networks simultaneously. Use `NetworkAttachmentDefinition` (NAD) resources to define the secondary networks and CNI plug-in configurations that Multus attaches to your pods.
