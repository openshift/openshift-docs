= Configure SSO by using Dex

[role="_abstract"]
Configure Single Sign-On (SSO) by using Dex to manage multiple users in Argo CD. After the {gitops-title} Operator is installed, Argo CD automatically creates a user with `admin` permissions.

[NOTE]
====
The `spec.dex` parameter in the ArgoCD CR is no longer supported from {gitops-title} v1.10.0 onwards. Consider using the `.spec.sso` parameter instead.
====
