= Installing packages to a Toolbx container in {op-system} 10.x

[role="_abstract"]
You can collect node-specific data that requires a support tool that is not part of the image by using Toolbx to install additional packages.

ifndef::openshift-origin[]
By default, running the `toolbox create` command starts a Toolbx container with the default Red Hat Universal Base Image (UBI) for the matching {op-system-base-full} version, for example, `registry.access.redhat.com/ubi10/toolbox:10.2`. If the package you need is not in that base image, you can launch a Toolbx container and install that package.
endif::openshift-origin[]
ifdef::openshift-origin[]
By default, running the `toolbox` command starts a container with the default Toolbx image for the currently installed {op-system-base-full} version. If the package you need is not in that base image, you can launch a Toolbx container and install that package.
endif::openshift-origin[]

.Prerequisites

* Your cluster is running {op-system-first} 10.x.
* You can access your system as a user with root privileges.

.Procedure

. Access a node by running the following command.
+
[source,terminal]
----
$ oc debug node/<node_name>
----
+
Replace `<node_name>` with the name of the node. 

. Set `/host` as the root directory within the debug shell by running the following command. The debug pod mounts the host's root file system in the `/host` directory within the pod. By changing the root directory to `/host`, you can run binaries contained in the host's executable paths.
+
[source,terminal]
----
# chroot /host
----

. Launch Toolbx:

.. Start the Toolbx container by running the following command:
+
[source,terminal]
----
# toolbox create
----
+
[NOTE]
====
If an existing `toolbox` container is already running, Toolbx outputs an error. Remove the existing Toolbx container by running the `toolbox rm <name>` or `toolbox rm --force <name>` command, where `<name>` is the name of the container. Then spawn a new toolbox container.
====

.. If prompted, download the Toolbx image by entering `y` at the prompt:
+
[source,terminal]
----
Image required to create Toolbx container.
Download registry.access.redhat.com/ubi10/toolbox:10.2 (345MB)? [y/N]
----

.. Enter the Toolbx container to execute commands by running the following command:
+
[source,terminal]
----
# toolbox enter
----

. Install the additional package, such as `wget`, by running the following command:
+
[source,terminal]
----
# dnf install -y <package_name>
----
+
Replace `<package_name>` with the name of the additional package.
