= Create a mirror registry with Mirror Registry for Red Hat OpenShift

[role="_abstract"]
The mirror registry for Red Hat OpenShift is a small and streamlined container registry that you can use as a target for mirroring the required container images of {product-title} for disconnected installations.
Deploy Mirror Registry for Red Hat OpenShift to have a supported registry solution that meets your mirroring needs.
