= Machine pool upgrade requirements

[role="_abstract"]
Each machine pool in a {product-title} cluster upgrades independently. Because the machine pools upgrade independently, they must remain within two minor (Y-stream) versions of the hosted control plane. For example, if your hosted control plane is 4.16.z, your machine pools must be at least 4.14.z.
