= Review and apply autopilot recommendations by using the web console

[role="_abstract"]
You can use the {product-title} web console to review the recommended YAML configuration for an autopilot-managed capability and apply the recommendation.

.Prerequisites

* You have access to the cluster as a user with `cluster-admin` privileges.
* The `virt-platform-autopilot` controller is enabled on the cluster.
* The operator that you want to review is installed on the cluster.

.Procedure

. In the web console, go to *Virtualization* -> *Settings* -> *Recommended Capabilities*.
+
The *Recommended Capabilities* tab displays two tables:
+
--
* *Autopilot-managed capabilities*: Capabilities that the `virt-platform-autopilot` controller configures automatically.
* *Additional recommended capabilities*: Capabilities that must be manually installed and configured.
--

. In the *Autopilot-managed capabilities* table, identify the capability that you want to review.
+
The *Configuration status* column indicates the current state of each capability:
+
--
* *Recommended*: The `virt-platform-autopilot` controller is managing the capability with its opinionated defaults.
* *Manual*: The capability has been opted out of autopilot management.
--
+
[NOTE]
====
The *Review recommendation* option is only available for operators that are installed on the cluster.
====

. Click the options menu {kebab} for the capability, and select *Review recommendation*.
+
The *Review recommendation* modal displays the autopilot-recommended YAML configuration alongside the current configuration.

. Review the recommended configuration changes.

. Click *Apply recommendation* to apply the recommended configuration.

.Verification

* In the *Autopilot-managed capabilities* table, verify that the *Configuration status* column shows *Recommended* for the capability.

[NOTE]
====
For more granular customization options such as JSON patches and field masking, see xref:virt-customizing-opt-out-autopilot_{context}[].
====
