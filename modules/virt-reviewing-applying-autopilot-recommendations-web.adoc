= Review and apply autopilot recommendations by using the web console

[role="_abstract"]
You can use the {product-title} web console to review the recommended YAML configuration for an autopilot-managed capability and apply the recommendation. Reviewing the recommendation before applying it allows you to compare the autopilot defaults with your current configuration.

.Prerequisites

* You have access to the cluster as a user with `cluster-admin` privileges.
* The `virt-platform-autopilot` controller is enabled on the cluster.
* The Operators for the capability that you want to review are installed on the cluster.

.Procedure

. In the web console, go to *Virtualization* -> *Settings* -> *Recommended Capabilities*.
+
The *Recommended Capabilities* tab lists capabilities that are managed by the `virt-platform-autopilot` controller under the *Install capabilities automatically* heading at the top of the table.
+
[NOTE]
====
Only capabilities whose Operators are installed on the cluster can be reviewed and applied.
====

. Under *Install capabilities automatically*, identify the capability that you want to review.

. Click the options menu {kebab} for the capability, and select *Review recommendation*.
+
The *Review recommendation* modal displays the autopilot-recommended YAML configuration alongside the current configuration.

. Review the recommended configuration changes.

. Click *Apply recommendation* to apply the recommended configuration.

.Verification

* Under *Install capabilities automatically*, verify that the capability shows the applied configuration status.
