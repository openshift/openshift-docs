= Infrastructure tab

[role="_abstract"]
The Infrastructure tab shows cards for GitOps-related operators and custom resources in the selected project or across all projects. Most resource cards show a Total count in the card title, an entry for each resource, and links to view the list or create a resource. The GitOps Operator card does not show a Total count; it shows Operator CSV details when found.

The tab contains these cards, in order:

* GitOps Operator
* Argo CD Instances
* App Projects
* Applications
* ApplicationSets
* Image Updaters
* Rollout Managers
* Rollouts

The console always displays all cards. When a resource CRD does not exist on the cluster, the card shows an error instead of a count.

The *GitOps Operator card* shows ClusterServiceVersion (CSV) details when the console finds the {gitops-title} Operator in the selected scope. The card displays the CSV name as a link to its details page, the install phase (for example, Succeeded, Pending, or Failed) with a status icon, and these fields: Version, Display Name, Provider, Namespace (the project you select in the project bar, or *All Namespaces*, not the namespace where the Operator exists), Message (the status message from the CSV), and Created At.

For Applications, ApplicationSets, App Projects, Image Updaters, Rollout Managers, and Rollouts, *View list* opens the corresponding GitOps list page for the current scope when you have permission to list that resource. *Create* appears only when you select a specific project and you have permission to create that resource. In *All Projects*, the console does not show a create link. Argo CD Instances does not provide a view-list link. A create action can appear when the console detects the Operator, finds no instances, and you select a single project. The GitOps Operator card links to the ClusterServiceVersion details when the console finds the Operator; the card does not offer a create link.
