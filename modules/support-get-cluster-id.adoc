= Obtaining your cluster ID

[role="_abstract"]
When providing information to Red Hat Support, it is helpful to provide the unique identifier for your cluster. You can have your cluster ID autofilled by using the {product-title} web console. You can also manually obtain your cluster ID by using the web console or the OpenShift CLI (`oc`).

.Prerequisites

* [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# You have access to the cluster as a user with the `cluster-admin` role.
* [.pr:openshift-rosa .pr:openshift-dedicated]#{empty}# You have access to the cluster as a user with the `dedicated-admin` role.
* You have access to the web console or the OpenShift CLI (`oc`) installed.

.Procedure
* [.pr:openshift-rosa .pr:openshift-dedicated]#To manually obtain your cluster ID using {cluster-manager-url}:#
.. [.pr:openshift-rosa .pr:openshift-dedicated]#Navigate to *Cluster List*.#
.. [.pr:openshift-rosa .pr:openshift-dedicated]#Click on the name of the cluster you need to open a support case for.#
.. [.pr:openshift-rosa .pr:openshift-dedicated]#Find the value in the *Cluster ID* field of the *Details* section of the *Overview* tab.#
* [.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa]#To open a support case and have your cluster ID autofilled using the web console:#
.. [.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa]#From the toolbar, navigate to *(?) Help* and select *Share Feedback* from the list.#
.. [.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa]#Click *Open a support case* from the *Tell us about your experience* window.#

* [.pr:openshift-origin]#To open a bug and have your cluster ID autofilled using the web console:#
.. [.pr:openshift-origin]#From the toolbar, navigate to *(?) Help* -> *Report Bug*.#
.. [.pr:openshift-origin]#The *Cluster ID* value is autofilled after you click `Submit Bug`.#

* To manually obtain your cluster ID using the web console:
.. Navigate to *Home* -> *Overview*.
.. The value is available in the *Cluster ID* field of the *Details* section.

* To obtain your cluster ID using the OpenShift CLI (`oc`), run the following command:
+
[source,terminal]
----
$ oc get clusterversion -o jsonpath='{.items[].spec.clusterID}{"\n"}'
----
