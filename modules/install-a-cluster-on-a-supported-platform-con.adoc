= Install a cluster on a supported platform

[role="_abstract"]
Installing {product-title} with installer-provisioned infrastructure follows the same journey on every supported platform. You set up an installation host, generate and customize an `install-config.yaml` file, supply cloud credentials, run the installation program, and log in to the cluster that it creates. Only the details of each step change from platform to platform.

Use this page to understand the shape of the installation and to prepare your installation host. Then follow the supplement for your platform, which walks the same journey with the values, machine types, and credential model that your platform requires.

.The installation journey
[cols="1,3",options="header"]
|===
|Phase |What you do

|1. Verify prerequisites
|Confirm that your account, quotas, and network meet the platform requirements.

|2. Set up the installation host
|Generate an SSH key, obtain the installation program, and install the OpenShift CLI (`oc`). This phase is identical on every platform.

|3. Generate the installation configuration file
|Run `openshift-install create install-config` to produce `install-config.yaml`.

|4. Size the cluster
|Choose machine types that meet the minimum resource requirements.

|5. Customize the installation configuration file
|Edit `install-config.yaml` to set your network, DNS, proxy, and platform-specific parameters.

|6. Configure cluster credentials
|Choose a Cloud Credential Operator mode and create the credentials the cluster needs.

|7. Customize the cluster network
|Set the network plugin and any Network Operator configuration that you cannot change after installation.

|8. Deploy the cluster
|Run `openshift-install create cluster`.

|9. Access and verify the cluster
|Log in with the CLI and the web console.

|10. Complete post-installation configuration
|Create DNS records, configure registry storage, and finish any platform-specific tasks.
|===

Phases 2 and 9 are the same everywhere. Phases 1 and 3 through 10 vary by platform, which is why each platform has its own supplement.
