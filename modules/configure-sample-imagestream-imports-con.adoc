= Configure sample imagestream imports

[role="_abstract"]
You can configure scheduled imports for Cluster Sample Operator image stream tags to periodically retrieve updated images and retry imports after temporary failures. Scheduling periodic imports ensures that your cluster always has access to the latest versions of the Cluster Sample Operator images.
