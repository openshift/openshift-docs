= Network Observability Operator 2.0.1 fixed issues

[role="_abstract"]
The Network Observability Operator 2.0.1 release includes fixed issues that improve Loki memory efficiency and IPFIX export reliability.

Reduced Loki memory usage by removing owner names from default labels::
Before this update, source and destination owner names were included as Loki labels by default, increasing the number of active Loki streams and overall memory consumption.
+
With this release, owner names are excluded from the default Loki label set. As a result, Loki memory usage is significantly reduced.
+
link:https://issues.redhat.com/browse/NETOBSERV-2425[NETOBSERV-2425]

Invalid IP Flow Information Export (IPFIX) records no longer sent when IP or MAC address data is missing::
Before this update, when a flow record was missing IP or MAC address data, the IPFIX exporter sent an invalid record to receiving collectors. As a consequence, external IPFIX collectors reported deserialization errors, including unsupported flow version numbers and unexpected end-of-file errors.
+
With this release, the IPFIX exporter skips flow records that are missing required IP or MAC address fields. As a result, external IPFIX collectors receive only valid flow records.
+
link:https://issues.redhat.com/browse/NETOBSERV-3060[NETOBSERV-3060]
