The distributed tracing 3.11.3 release resolves this Common Vulnerabilities and Exposures (CVE) issue:

The verification bypass vulnerability is fixed in the `crypto/x509` package::
Before this update, the certificate verification process in the Go `crypto/x509` package did not block trust in intermediate certificates from a compromised Certificate Authority (CA). As a consequence, a remote attacker could present a certificate signed by these intermediate authorities to impersonate legitimate servers and conduct a man-in-the-middle (MitM) attack to intercept or alter confidential communications. With this update, the certificate verification process correctly blocks trust in these compromised intermediate certificates. As a result, the system rejects unauthorized certificates and prevents impersonation attacks.
