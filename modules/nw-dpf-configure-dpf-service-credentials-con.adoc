= Configuring DPF service credentials and hosted cluster access

[role="_abstract"]
You configure the authentication credentials and access settings that allow DPF services running on DPU nodes to communicate with the management cluster and the DPU hosted cluster. This includes creating the OVN-Kubernetes credentials and configuring hosted cluster authentication.
