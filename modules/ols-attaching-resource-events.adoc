= Attaching resource events to your question

[role="_abstract"]
Attach the most recent events for a resource to give {ols-long} event data for detailed troubleshooting and analysis.

.Procedure

. Navigate to a supported resource in the {ocp-product-title} web console. For example, click *Workloads* -> *Pods*, and then click the name of a pod.

. Click the {ols-official} icon in the lower-right corner of the screen.

. Click the attachment menu button (*+*) next to the message field, and then select *Events*.
+
The *Configure events attachment* window opens.
+
[NOTE]
====
If the resource has no events, the *Events* option is not available. If only one event is available, that event is attached without the option to change the number.
====

. Use the slider to set the number of most recent events to attach. By default, up to 10 of the most recent events are attached.

. Click *Attach*.

. Enter a question.

. Click the *Submit* button.
+
{ols-long} returns information based on your question and the attached events.
