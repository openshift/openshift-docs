= OBI Receiver

[role="_abstract"]
The OpenTelemetry eBPF Instrumentation (OBI) Receiver uses the extended Berkeley Packet Filter (eBPF) for zero-code instrumentation of applications at the Linux kernel level. The eBPF enables this receiver to capture traces and metrics without code changes or language-specific agents.

This receiver inspects processes and the operating system networking stack.

This receiver can capture trace spans, application metrics, runtime metrics, network metrics, and Rate Errors Duration (RED) metrics.
