= Platform-managed firewall rules reference

[role="_abstract"]
A standard {product-title} on {GCP} cluster has six platform-managed rules, all using network tags as their targeting mechanism.

.Platform-managed firewall rules
[cols="3,2,1",options="header"]
|===
|Rule name pattern |Ports |Targeting

|`<infra_id>-api`
|tcp:6443
|Network tags

|`<infra_id>-etcd`
|tcp:2379-2380
|Network tags

|`<infra_id>-control-plane`
|tcp:2379-2380, 6443, 9258-9259, 10257-10259, 22623-22624
|Network tags

|`<infra_id>-health-checks`
|tcp:6080, 6443, 22624
|Network tags

|`<infra_id>-internal-cluster`
|tcp, udp, icmp (all)
|Network tags

|`<infra_id>-internal-network`
|tcp, udp (various)
|Network tags
|===
