= Audit logging configuration reference

[role="_abstract"]
Reference information for the `spec.audit` fields on the `OLSConfig` and `AgenticOLSConfig` custom resources.

Both resources expose an identical `spec.audit` structure. You configure them independently: enabling or disabling audit logging on one does not affect the other.

[IMPORTANT]
====
Audit logging is enabled by default. When the `spec.audit` field is absent from the CR, audit logging runs as if `enabled: true` is set. To turn off audit logging, you must explicitly set `enabled: false`.
====

== spec.audit

[cols="2,1,1,4",options="header"]
|===
| Field | Type | Default | Description

| `enabled`
| boolean
| `true`
| Controls whether audit logging is active. When absent, audit logging is enabled. Set to `false` to disable. There is no verbosity dial; audit logging is always full fidelity when enabled.

| `otel`
| object
| —
| Optional. OpenTelemetry Collector configuration. When absent, audit events are written as structured JSON to stdout only.

|===

== spec.audit.otel

[cols="2,1,1,4",options="header"]
|===
| Field | Type | Default | Description

| `endpoint`
| string
| —
| gRPC OTLP endpoint for the OpenTelemetry Collector, for example `grpc://otel-collector.observability.svc.cluster.local:4317`. When absent, the system uses a no-op OTEL exporter and emits all audit events to stdout only.

|===

== Example: audit logging enabled with OTEL export

The following example enables audit logging and configures an OTEL Collector endpoint on the `OLSConfig` CR:

[source,yaml]
----
apiVersion: ols.openshift.io/v1alpha1
kind: OLSConfig
metadata:
  name: cluster
spec:
  audit:
    enabled: true
    otel:
      endpoint: grpc://otel-collector.observability.svc.cluster.local:4317
  llm:
    ...
----

The following example shows the equivalent configuration on the `AgenticOLSConfig` CR:

[source,yaml]
----
apiVersion: ols.openshift.io/v1alpha1
kind: AgenticOLSConfig
metadata:
  name: cluster
spec:
  audit:
    enabled: true
    otel:
      endpoint: grpc://otel-collector.observability.svc.cluster.local:4317
----

== Example: disable audit logging

The following example disables audit logging on the `OLSConfig` CR:

[source,yaml]
----
apiVersion: ols.openshift.io/v1alpha1
kind: OLSConfig
metadata:
  name: cluster
spec:
  audit:
    enabled: false
  llm:
    ...
----
