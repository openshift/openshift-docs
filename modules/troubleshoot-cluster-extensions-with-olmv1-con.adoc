= Troubleshoot cluster extensions with {olmv1}

[role="_abstract"]
When an extension does not install or update as expected, you can inspect its state to decide what to do next.

{olmv1-first} reports progress through the rollout of the extension and surfaces the most common failure classes, such as unresolved catalog content and invalid extension deployment settings.
