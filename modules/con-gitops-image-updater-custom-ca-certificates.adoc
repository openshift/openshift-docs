= Custom CA certificates for container registries

[role="_abstract"]
When Argo CD Image Updater connects to container registries that use certificates signed by a private Certificate Authority (CA), you need to configure the CA certificates so Image Updater can verify the TLS connection.

Image Updater supports two methods for providing custom CA certificates, listed in order of precedence:

. *Inline data configuration*: Embed the CA certificate directly in the registry configuration.

. *Automatic discovery*: Image Updater automatically discovers CA certificates from Argo CD's `argocd-tls-certs-cm` ConfigMap.
