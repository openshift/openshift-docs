[id="secrets-store-auto-rotation_{context}"]
= Automatic rotation

[role="_abstract"]
The {secrets-store-operator} automatically rotates secret content in mounted volumes to maintain synchronization with your external secret provider. By default, secret rotation is enabled, but you can configure the rotation behavior to optimize for your specific security and operational requirements.

When rotation is enabled, the {secrets-store-operator} polls the external secret store at a configurable interval to check for secret updates. This process ensures that updates in the external store are automatically reflected in your pods and secrets. The default polling interval is 2 minutes, but you can adjust this value to balance security needs with transaction costs and performance overhead.

If you enabled synchronization of mounted content as Kubernetes secrets, the Kubernetes secrets are also rotated when the external secrets are updated.

Applications consuming the secret data must watch for file system changes to detect updated secrets. The {secrets-store-operator} updates the content of the mounted volume, and applications should reload the secrets when changes are detected.

[NOTE]
====
You can disable automatic rotation or configure a custom polling interval by modifying the `rotation` settings in the `Driver` custom resource. For more information, see "Configuring secret rotation for the Secrets Store CSI Driver".
====

[IMPORTANT]
====
When rotation is disabled, secrets are mounted only when pods start and are not updated thereafter, even if the values change in the external secret store. To pick up secret changes when rotation is disabled, you must restart the affected pods.
====
