= Configuring an approval policy for autonomous agents

[role="_abstract"]
The `ApprovalPolicy` custom resource (CR) controls which workflow stages run automatically and which require manual approval before an `AgenticRun` can proceed. Creating an `ApprovalPolicy` CR is optional. When no `ApprovalPolicy` exists, every stage requires manual approval, so each step blocks until you approve it. Create an `ApprovalPolicy` CR to automatically approve the stages that you trust and to reserve manual approval for the stages that change your cluster.

.Prerequisites

* You have installed the {ols-long} Operator and configured {ols-long} autonomous agents.
* You have logged in to the cluster as a user with the `cluster-admin` role, or with permission to create cluster-scoped custom resources.

.Procedure

. Create an `ApprovalPolicy` CR by running the following command:
+
[source,terminal]
----
$ oc apply -f - <<'EOF'
apiVersion: agentic.openshift.io/v1alpha1
kind: ApprovalPolicy
metadata:
  name: cluster
spec:
  maxConcurrentRuns: 5 # <1>
  stages:
    - name: Analysis # <2>
      approval: Automatic
    - name: Execution # <3>
      approval: Manual
    - name: Verification
      approval: Automatic
    - name: Escalation
      approval: Automatic
EOF
----
<1> The maximum number of `AgenticRun` resources that can run concurrently.
<2> Set `approval` to `Automatic` to run a stage without manual approval, or to `Manual` to require approval before the stage runs.
<3> The example policy reserves manual approval for the `Execution` stage, which applies changes to the cluster, and automatically approves the `Analysis`, `Verification`, and `Escalation` stages.

.Verification

* Confirm that the policy exists by running the following command:
+
[source,terminal]
----
$ oc get approvalpolicy cluster
----
