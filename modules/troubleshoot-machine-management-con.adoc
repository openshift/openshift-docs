= Troubleshoot machine management

[role="_abstract"]
A machine that does not reach the state you expect can stall the workload or the control plane that depends on it. Start from the symptom: a machine that never becomes a node, a member that must be replaced, or a machine that needs removing so its machine set builds a fresh one.
