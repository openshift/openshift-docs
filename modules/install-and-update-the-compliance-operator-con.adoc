= Install and update the Compliance Operator

[role="_abstract"]
You can install the Compliance Operator on your {product-title} cluster by using the web console or the CLI, and update or remove the Operator when your compliance requirements change. Before installing, ensure that persistent storage is configured in the cluster to store raw scan results.
