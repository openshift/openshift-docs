= Attach context to get more relevant answers

[role="_abstract"]
Attach cluster data to a question to give {ols-long} specific context so that it returns more relevant, data-driven answers. You attach context from the attachment menu next to the message field in the {ols-official} interface.

The available attachment options depend on the page you are viewing and the type of resource that is in context:

Full YAML file::
Attaches the complete YAML definition of the resource that you are currently viewing.

Filtered YAML::
Attaches only the `Kind`, `Metadata`, and `Status` sections of the resource. Use a filtered attachment to reduce the attachment size when you do not need the full definition.

Logs::
Attaches the most recent lines from a container log. For more information, see "Attach container logs to troubleshoot an issue".

Events::
Attaches the most recent events for a resource. For more information, see "Attach resource events to troubleshoot an issue".

Upload from computer::
Attaches a YAML file from your local computer. For more information, see "Upload a local file as context".

[NOTE]
====
When you view a {red-hat} Advanced Cluster Management `ManagedCluster` resource, the menu presents an *Attach cluster info* option that attaches the cluster information for that managed cluster.
====

Before you submit a question, you can preview an attachment and, where supported, edit its content. For more information, see "Review and edit an attachment before you submit".
