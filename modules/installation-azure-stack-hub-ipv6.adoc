= IPv6 limitations

[role="_abstract"]
Review IPv6 networking limitations before you install {product-title} on Azure Stack Hub.

[IMPORTANT]
====
Azure Stack Hub does not provide IPv6 networking. You cannot install a cluster that uses IPv6 or dual-stack networking on Azure Stack Hub.
====
