= Configure {kueue-name} quotas and queues

[role="_abstract"]
As an administrator, you configure quotas in {kueue-name} to optimize resource allocation and system throughput for user workloads, including CPU, memory, pods, and GPU. You configure a cluster queue, a resource flavor, and a local queue, after which users submit their workloads to the local queue.
