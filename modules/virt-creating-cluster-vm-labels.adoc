= Creating cluster auto-applied labels

[role="_abstract"]
Create labels that are automatically applied to every virtual machine created in a cluster. Labels allow administrators to group and filter virtual machines.

[IMPORTANT]
====
New labels are only applied to virtual machines created after the label is created.
====

.Prerequisites

* You have access to the {product-title} web console.
* You have `edit` or `admin` permissions in the target project.

.Procedure

. Click *Virtualization* -> *Settings* on the side menu to access the cluster settings. 

. Click the *Cluster* tab.

. Click *Auto-applied VM labels*.

. Click *Add new key*.

. Enter the label name in the *Key* field.

. Click the checkmark icon to save the new label.
+
[NOTE]
====
Click the trash can icon to discard the change if needed.
====

. Optional: Enter a default value in the *Value* field.
.. Click the pencil icon.
.. Enter a value in the *Value* field.
.. Click the checkmark icon to save the new value.

. Optional: Select the *Required* slider to make a value for this label mandatory for all cluster VMs.
