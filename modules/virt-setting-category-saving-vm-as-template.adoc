= Setting a category when saving a VM as a template

[role="_abstract"]
You can optionally set a category when saving a virtual machine (VM) as a template. The category is stored as the `vm.kubevirt.io/category` label on the new template.

.Prerequisites

* You have access to the {product-title} web console.
* You have `edit` or `admin` permissions in the project.
* You have a running or stopped VM.

.Procedure

. In the {product-title} web console, navigate to *Virtualization* -> *VirtualMachines*.
. Click the name of the VM that you want to save as a template.
. Click *Actions* -> *Save as template*.
. In the template creation dialog, configure the template details.
. Optional: In the *Category* field, select a category from the list or type a custom category name.
. Click *Save*.

.Verification

* Navigate to *Virtualization* -> *Templates* and verify that the new template appears with the assigned category in the *Category* column.
