= User permissions and RBAC compliance

[role="_abstract"]
The visualization feature integrates natively with standard Kubernetes role-based access control (RBAC). {ols-long} enforces the active namespace and resource-level permissions of the authenticated user account.

When processing a natural language prompt, {ols-long} verifies access privileges before executing metric queries or rendering previews. If an account lacks read permissions for a specific namespace, metric, or workload type, the cluster API blocks the generation task. Viewing metrics relies on workload read access, but saving a panel requires Red Hat build of Perses editor roles, such as the `persesdashboard-editor-role` role.
