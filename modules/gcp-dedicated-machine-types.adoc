= Tested instance types for Google Cloud Dedicated

The following instance types have been tested with {product-title} on Google Cloud Dedicated sovereign cloud regions.
Only the C3, M3, and A3 Edge machine series are available.
Other series such as N2, E2, and T2A are not available in Google Cloud Dedicated.

[NOTE]
====
ARM-based machine types are not available in Google Cloud Dedicated.
All instance types use the x86_64 architecture.

All instance types use the `hyperdisk-balanced` disk type.
Other disk types such as `pd-ssd`, `pd-standard`, and `pd-balanced` are not available.

====
