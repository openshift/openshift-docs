= Uninstall the VCF Migration Operator

[role="_abstract"]
After the migration completes and you verify that the cluster is healthy on the target vCenter, you can uninstall the VCF Migration Operator.
The Operator is no longer needed after migration, and removing it frees cluster resources.

[IMPORTANT]
====
Uninstalling the Operator does not affect the migrated cluster.
The migration is already complete and the cluster continues to operate normally on the target vCenter.
====

.Prerequisites

* The migration CR status shows `Ready=True`, or you deleted the migration CR.
* You verified that the cluster is healthy on the target vCenter.
* You destroyed the source infrastructure, if applicable.

.Procedure

. Delete the `VmwareCloudFoundationMigration` CR:
+
[source,terminal]
----
$ oc delete vcfm cluster -n openshift-vcf-migration
----

. Uninstall the Operator by using one of the following methods:

** *Web console*: In the {product-title} web console, go to *Operators* -> *Installed Operators*. Find the *VCF Migration Operator*, click the options menu {kebab}, and select *Uninstall Operator*. Confirm the uninstallation.

** *CLI*: Delete the Operator subscription and the cluster service version (CSV):
+
[source,terminal]
----
$ oc delete subscription vcf-migration-operator -n openshift-vcf-migration
----
+
[source,terminal]
----
$ oc delete csv -n openshift-vcf-migration \
  -l operators.coreos.com/vcf-migration-operator.openshift-vcf-migration=
----

. Optional: Delete the custom resource definition (CRD).
+
OLM does not automatically remove CRDs when you uninstall an Operator, to prevent accidental data loss.
If you no longer need the CRD, delete it manually:
+
[source,terminal]
----
$ oc delete crd vmwarecloudfoundationmigrations.migration.openshift.io
----

. Optional: Remove the Operator namespace if it is no longer needed:
+
[source,terminal]
----
$ oc delete namespace openshift-vcf-migration
----

.Verification

* Verify that the Operator subscription and CSV are removed:
+
[source,terminal]
----
$ oc get subscriptions,csv -n openshift-vcf-migration
----
+
The command should return no resources.

* If you deleted the CRD in the previous step, verify that it is removed:
+
[source,terminal]
----
$ oc get crd vmwarecloudfoundationmigrations.migration.openshift.io
----
+
The expected output is `Error from server (NotFound)`.
