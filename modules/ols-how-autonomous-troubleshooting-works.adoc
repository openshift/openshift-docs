= How autonomous troubleshooting works

[role="_abstract"]
When a cluster alert fires, autonomous troubleshooting diagnoses the issue and proposes a fix so that you can evaluate the security and governance model before you enable it.

:FeatureName: Autonomous agentic troubleshooting
include::snippets/technology-preview.adoc[]
:FeatureName!:

For {ocp-product-title} 5, when the {ols-long} 2.0 Service is installed, autonomous agentic troubleshooting is enabled by default. The feature introduces Agentic Lightspeed, an AI-powered agent that operates as an autopilot site reliability engineer (SRE) model for your cluster, focusing on self-healing systems and reliability engineering. Agentic Lightspeed diagnoses cluster alerts and proposes one-click remediations in the {ocp-product-title} web console.

[NOTE]
====
Autonomous agentic troubleshooting is available only on {ocp-product-title} 5 clusters that have {ols-long} 2.0 installed.
====

[id="ols-alert-to-resolution-pipeline_{context}"]
== Alert-to-resolution pipeline

The agent moves each alert through the following stages:

* *Alert reception*: The `lightspeed-agentic-alerts-adapter` periodically polls the Alertmanager API to retrieve active Prometheus alerts.

* *Investigation*: The agent investigates cluster conditions by using cluster tools such as `oc` and `kubectl`.

* *Remediation proposal*: The agent generates a diagnosis and proposed remediation steps.

* *Human approval*: A cluster administrator reviews and approves or denies the remediation, either through the *Agentic Runs* view in the web console or by using the `oc-agentic` CLI plugin. All critical execution steps require explicit administrator approval.

* *Execution*: Upon approval, the agent executes the remedy in a sandboxed pod using least-privilege role-based access control (RBAC).

== Feature comparison

The following table compares user-initiated {ols-long} chat with autonomous agentic troubleshooting.

.User-initiated chat compared to autonomous agentic troubleshooting
[cols="1,2,2",options="header"]
|===
|Capability |User-initiated {ols-long} chat |Autonomous agentic troubleshooting

|Trigger
|User enters a prompt in the chat interface.
|Agent automatically responds to Prometheus alerts.

|Scope
|Single user query.
|Cluster-wide alert diagnosis and remediation.

|Execution
|Informational responses only.
|Executes approved remediations in a sandboxed environment.

|Approval
|Not applicable.
|All remediations require human approval in the Decision Queue.

|Continuity
|Session-based interaction.
|Continuous operation based on subscription policies.
|===
