= Disabling the Vertical Pod Autoscaler Operator pause behavior

[role="_abstract"]
You can disable the Vertical Pod Autoscaler (VPA) pause behavior by removing the `autoscaling.openshift.io/default-vpa-controller-created` annotation from the `openshift-vertical-pod-autoscaler` namespace object. 

You can pause VPA behavior without the need to uninstall the Operator as described in "Pausing and restarting the Vertical Pod Autoscaler Operator".

If you remove the annotation and a VPA controller does not exist, {product-title} creates a new default Vertical Pod Autoscaler Controller.

You can restart the VPA pause behavior by replacing the annotation in the namespace object.

.Procedure

. Edit the `openshift-vertical-pod-autoscaler` namespace object:
+
[source,terminal]
----
$ oc edit 
----

. Remove the `autoscaling.openshift.io/default-vpa-controller-created` annotation:
+
.Example object
[source,yaml]
----
[source,terminal]
----
apiVersion: v1
kind: Namespace
metadata:
  annotations:
    autoscaling.openshift.io/default-vpa-controller-created: "true"
# ...
  name: openshift-vertical-pod-autoscaler
# ...
----
+
This example shows the CR with only the annotation to remove.

. Optional: Replace the annotation to restart the pause behavior.
+
[source,terminal]
----
$ oc annotate namespace openshift-vertical-pod-autoscaler autoscaling.openshift.io/default-vpa-controller-created=true
----
