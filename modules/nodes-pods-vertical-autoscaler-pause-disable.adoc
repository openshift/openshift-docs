= Disabling the Vertical Pod Autoscaler Operator pause behavior

You can disable the Vertical Pod Autoscaler (VPA) pause behavior by removing the `autoscaling.openshift.io/default-vpa-controller-created` annotation from the `openshift-vertical-pod-autoscaler` namespace object. 

By deleting the `VerticalPodAutoscalerController` custom resource (CR), you can pause VPA behavior without the need to uninstall the Operator as described in "Pausing and restarting the Vertical Pod Autoscaler Operator".

If you remove the annotation and a VPA controller does not exist, {product-title} creates a new default Vertical Pod Autoscaler Controller.

.Procedure

. Edit the `openshift-vertical-pod-autoscaler` namespace object:
+
[source,terminal]
----
$ oc edit 
----

. Remove the `autoscaling.openshift.io/default-vpa-controller-created` annotation:
+
[source,yaml]
----
apiVersion: v1
kind: Namespace
metadata:
  annotations:
    autoscaling.openshift.io/default-vpa-controller-created
    openshift.io/sa.scc.mcs: s0:c27,c19
    openshift.io/sa.scc.supplemental-groups: 1000740000/10000
    openshift.io/sa.scc.uid-range: 1000740000/10000
    security.openshift.io/MinimallySufficientPodSecurityStandard: restricted
  creationTimestamp: "2026-10-16T18:40:15Z"
  labels:
    kubernetes.io/metadata.name: openshift-vertical-pod-autoscaler
    olm.operatorgroup.uid/31c81fee-b79f-4bc2-8c23-5d8a854d3114: ""
    pod-security.kubernetes.io/audit: restricted
    pod-security.kubernetes.io/audit-version: latest
    pod-security.kubernetes.io/warn: restricted
    pod-security.kubernetes.io/warn-version: latest
    security.openshift.io/scc.podSecurityLabelSync: "true"
----
+
This example shows the CR with the annotation to remove.
