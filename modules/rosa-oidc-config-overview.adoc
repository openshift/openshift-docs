= OpenID Connect configuration overview

[role="_abstract"]
When using a cluster hosted by Red{nbsp}Hat, you can create a managed or unmanaged OpenID Connect (OIDC) configuration by using the {rosa-cli-first}. Your choice of OIDC configuration determines where the OIDC keys are stored.

A managed OIDC configuration is stored within Red{nbsp}Hat's AWS account, while a generated unmanaged OIDC configuration is stored within your AWS account. The OIDC configuration is registered to be used with {cluster-manager}. When creating an unmanaged OIDC configuration, the {rosa-cli} provides the private key for you.
