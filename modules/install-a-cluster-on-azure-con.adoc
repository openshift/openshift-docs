= Install a cluster on Azure

[role="_abstract"]
Install a {product-title} cluster on {azure-first} by using installer-provisioned infrastructure. This supplement follows the common installation journey and adds the steps that are specific to {azure-short}: subscribing to a Marketplace offer, enabling trusted launch and confidential VMs, applying user-defined tags, and configuring short-term credentials with the Cloud Credential Operator utility.

Before you begin, set up your installation host by following the common installation journey.
