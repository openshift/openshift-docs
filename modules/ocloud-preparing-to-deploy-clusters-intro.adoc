= Prepare the O-Cloud Manager environment

[role="_abstract"]
Before you can provision clusters, you must install the Operator on the hub cluster, configure the GitOps repository, and set up API authentication. If you use a Service Management and Orchestration (SMO) framework, you must also configure mutual TLS (mTLS) and register with the SMO.

The O-Cloud Manager is a Technology Preview feature only.
