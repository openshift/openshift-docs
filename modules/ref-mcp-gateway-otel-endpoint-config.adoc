= {OTELName} endpoint configuration for the {mcpg}

[role="_abstract"]
The URL scheme in the `OTEL_EXPORTER_OTLP_ENDPOINT` environment variable determines the transport protocol and port that the {mcpg} uses to export telemetry data.

.OTLP endpoint schemes and transport protocols
[cols="1,2", options="header"]
|===
|Scheme |Transport Protocol and Port

|`http://`
|OTLP/HTTP on port 4318 without TLS

|`https://`
|OTLP/HTTP on port 4318 with TLS. Set `OTEL_EXPORTER_OTLP_INSECURE="false"` to enable TLS verification.

|`rpc://`
|OTLP/gRPC on port 4317
|===

.Example endpoint configurations
[cols="1,2", options="header"]
|===
|Transport |Environment Variable

|OTLP/HTTP without TLS
|`OTEL_EXPORTER_OTLP_ENDPOINT="http://collector.namespace.svc.cluster.local:4318"`

|OTLP/HTTP with TLS
|`OTEL_EXPORTER_OTLP_ENDPOINT="https://collector.namespace.svc.cluster.local:4318"` + `OTEL_EXPORTER_OTLP_INSECURE="false"`

|OTLP/gRPC
|`OTEL_EXPORTER_OTLP_ENDPOINT="rpc://collector.namespace.svc.cluster.local:4317"`
|===
