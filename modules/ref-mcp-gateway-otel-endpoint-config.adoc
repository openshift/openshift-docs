= {OTELName} endpoint configuration for the {mcpg}

[role="_abstract"]
The URL scheme in each OTLP endpoint environment variable selects HTTP or gRPC transport protocols. The port that the {mcpg} uses to export telemetry data are what you configured. Ports `4318` and `4317` are typical collector ports.

.OTLP endpoint schemes and transport protocols
[cols="1,2", options="header"]
|===
|Scheme |Transport Protocol and Port

|`http://`
|OTLP/HTTP on port 4318 with an insecure transport

|`https://`
|OTLP/HTTP on port 4318 with a secure transport by default. Set `OTEL_EXPORTER_OTLP_INSECURE="true"` to use an insecure transport.

|`rpc://`
|OTLP/gRPC on port 4317 with a secure transport by default. Set `OTEL_EXPORTER_OTLP_INSECURE="true"` to use an insecure transport.
|===

.Example endpoint configurations
[cols="1,2", options="header"]
|===
|Transport |Environment Variable

|OTLP/HTTP without TLS
|`OTEL_EXPORTER_OTLP_ENDPOINT="http://collector.namespace.svc.cluster.local:4318"`

|OTLP/HTTP with TLS
|`OTEL_EXPORTER_OTLP_ENDPOINT="https://collector.namespace.svc.cluster.local:4318"`

|OTLP/gRPC
|`OTEL_EXPORTER_OTLP_ENDPOINT="rpc://collector.namespace.svc.cluster.local:4317"`
|===
