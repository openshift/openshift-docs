= IPv6 limitations

[role="_abstract"]
{product-title} supports IPv6 on {aws-first} with platform-specific limitations. Dual-stack cluster installation on {aws-short} is a Technology Preview feature.

:FeatureName: Dual-stack cluster installation on {aws-short}
include::snippets/technology-preview.adoc[]

Consider the following IPv6 limitations on {aws-short}:

* Dual-stack installation is not supported in {aws-short} Wavelength Zones.
* Classic Load Balancers (CLB) do not support IPv6.
