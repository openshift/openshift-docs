= Switch to manual configuration by using the web console

[role="_abstract"]
You can use the {product-title} web console to switch from autopilot management back to manual configuration for a specific capability. When you switch to manual configuration, the `virt-platform-autopilot` controller stops reconciling the configuration for that capability, and you take full ownership of its configuration.

.Prerequisites

* You have access to the cluster as a user with `cluster-admin` privileges.
* The `virt-platform-autopilot` controller is enabled on the cluster.
* The Operators for the capability that you want to switch to manual configuration are installed on the cluster.

.Procedure

. Go to the Operator details page by using one of the following methods:
+
--
* Go to *Virtualization* -> *Settings* -> *Recommended Capabilities*. Under *Install capabilities automatically*, click the options menu {kebab} for the capability and select *View operator details*.
* Go to *Operators* -> *Installed Operators* and select the Operator.
--

. On the Operator details page, switch the capability from autopilot to manual configuration.

.Verification

* On the Operator details page, verify that the capability shows manual configuration status.
