= Checking project status by using the CLI

[role="_abstract"]
You can review the status of your project by using the {oc-first}.

.Prerequisites

* You have installed the {oc-first}.
* You have created a project.

.Procedure

. Switch to your project by entering the following command:
+
[source,terminal]
----
$ oc project <project_name>
----
** Replace `<project_name>` with the name of your project.

. To obtain a high-level overview of the project, enter the following command:
+
[source,terminal]
----
$ oc status
----
