= Automatic configuration

[role="_abstract"]
{product-title} includes default integrations with standard registries and can automatically configure integrations based on artifacts found in monitored clusters, such as image pull secrets. You usually do not need to configure registry integrations manually.

[IMPORTANT]
====
* If you use a Google Container Registry (GCR), {product-title} does not create a registry integration automatically.
* If you use {product-title-managed}, automatic configuration is unavailable, and you must manually create registry integrations.
====
