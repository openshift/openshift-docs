= Google Cloud Dedicated sovereign cloud support

[role="_abstract"]
{product-title} {product-version} introduces support for deploying self-managed clusters on Google Cloud Dedicated sovereign cloud regions by using installer-provisioned infrastructure.

This feature enables regulated-industry customers in Europe to deploy {product-title} on physically isolated, partner-operated infrastructure that meets data residency and operational sovereignty mandates.
The following sovereign cloud partners are supported:

* **S3NS** (Thales and Google Cloud) in France
* **Thales and Google Cloud Germany** in Germany

.Key capabilities

* Installer-provisioned infrastructure installation on Google Cloud Dedicated sovereign cloud regions
* Automatic sovereign endpoint configuration from domain-scoped project IDs
* KMS encryption extended to bootstrap and image registry storage buckets
* Transparent cluster operator authentication to sovereign API endpoints

.Supported configurations

* Self-managed clusters
* Connected and restricted network installations
* Private clusters only (`publish: Internal`)

.Constraints

* The installation program defaults to `hyperdisk-balanced` storage. Other disk types are generally not available on Google Cloud Dedicated, and Filestore is not supported.
* Only private clusters are supported. Public-facing endpoints are not available on Google Cloud Dedicated infrastructure.
* Single region per sovereign universe
* Hive-based cluster provisioning is not supported

[NOTE]
====
Google Cloud Dedicated is a Google infrastructure tier, not a managed {product-title} offering.
Do not confuse Google Cloud Dedicated with {product-dedicated}.
====
