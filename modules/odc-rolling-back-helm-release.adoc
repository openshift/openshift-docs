= Rolling back a Helm release

[role="_abstract"]
If a release fails, you can roll back the Helm release to an earlier version.

.Procedure

. Navigate to *Ecosystem* -> *Helm*.
. Click the overflow menu in the release's row and select *Rollback*.
. On the Rollback Helm Release page, select the Revision you want to roll back to and click Rollback.
. On the *Ecosystem* -> *Helm* page, click the chart to see the details and resources for that release.
. Go to the *Revision History* tab to see all the revisions for the chart.
. Optional: Click the overflow menu next to a revision and select the revision to roll back to.
