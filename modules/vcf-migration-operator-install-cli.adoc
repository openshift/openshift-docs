= Install the {vcf-migration-operator} from the CLI

[role="_abstract"]
You can install the {vcf-migration-operator} with Operator Lifecycle Manager (OLM) by creating an Operator group and a subscription with the {oc-first}.

// Release review: Confirm the released catalog and channel. The repository currently documents a custom CatalogSource and dev-preview channel; do not assume redhat-operators or stable.

.Prerequisites

* You have installed the {oc-first} and logged in with `cluster-admin` privileges.
* A catalog that contains the {vcf-migration-operator} is available on the cluster.

.Procedure

. Find the catalog and channel for the Operator by running the following command:
+
[source,terminal]
----
$ oc get packagemanifest vcf-migration-operator -n openshift-marketplace -o yaml
----
+
Record the `status.catalogSource`, `status.catalogSourceNamespace`, and `status.defaultChannel` values for the subscription.

. Create the Operator namespace by running the following command:
+
[source,terminal]
----
$ oc create namespace openshift-vcf-migration
----

. Create an `operator-group.yaml` file with the following content:
+
[source,yaml]
----
apiVersion: operators.coreos.com/v1
kind: OperatorGroup
metadata:
  name: vcf-migration-operator
  namespace: openshift-vcf-migration
spec: {}
----
+
The Operator supports only the `AllNamespaces` installation mode. Keep `spec` empty so that the Operator watches all namespaces.

. Create the Operator group by running the following command:
+
[source,terminal]
----
$ oc create -f operator-group.yaml
----

. Create a `subscription.yaml` file with the following content:
+
[source,yaml]
----
apiVersion: operators.coreos.com/v1alpha1
kind: Subscription
metadata:
  name: vcf-migration-operator
  namespace: openshift-vcf-migration
spec:
  channel: <channel_name>
  name: vcf-migration-operator
  source: <catalog_source_name>
  sourceNamespace: <catalog_source_namespace>
  installPlanApproval: Automatic
----
+
where:
+
`<channel_name>`:: The update channel from `status.defaultChannel` in the package manifest.
`<catalog_source_name>`:: The catalog name from `status.catalogSource` in the package manifest.
`<catalog_source_namespace>`:: The namespace from `status.catalogSourceNamespace` in the package manifest.

. Create the subscription by running the following command:
+
[source,terminal]
----
$ oc create -f subscription.yaml
----

.Verification

. Verify that the Operator's cluster service version has a `PHASE` of `Succeeded` by running the following command:
+
[source,terminal]
----
$ oc get csv -n openshift-vcf-migration
----

. Verify that the Operator pod is running and its containers are ready by running the following command:
+
[source,terminal]
----
$ oc get pods -n openshift-vcf-migration
----
