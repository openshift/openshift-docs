= Sequence of high-level steps to deploy federated SPIRE

[role="_abstract"]

Before federating SPIRE across clusters, review these high-level steps to understand the sequence of deployment.

. Install the Zero Trust Workload Identity Manager Operator on each cluster.

. Deploy the Zero Trust Workload Identity Manager operands on each cluster.

. Enable and verify SPIRE federation between clusters.

. Configure the `{istio}` resource on each cluster to support SPIRE-enabled sidecar injection.

. Deploy an east-west gateway on each cluster.

. Enable cross-cluster service discovery.
