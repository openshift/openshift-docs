= List the container images included in a {microshift-short} release

[role="_abstract"]
Preview the contents of a {microshift-short} RPM package before you deploy or mirror it. Listing the container images included in a release helps you confirm a supported configuration of {op-system-bundle} and identify the exact image references that your version requires.
