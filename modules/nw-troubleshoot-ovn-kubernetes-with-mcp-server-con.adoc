= Troubleshoot OVN-Kubernetes networking issues with the MCP server

[role="_abstract"]
You can troubleshoot OVN-Kubernetes networking issues in {product-title} by enabling the Model Context Protocol (MCP) server `ovn-kubernetes` and `cni-diagnostics` toolsets and applying toolset permissions.

The MCP server for Red{nbsp}Hat OpenShift can diagnose OVN-Kubernetes connectivity issues in {product-title} by collecting evidence across Kubernetes, OVN, Open vSwitch, and kernel networking layers with the `ovn-kubernetes` and `cni-diagnostics` toolsets.

[NOTE]
====
The `ovn-kubernetes` and `cni-diagnostics` toolsets must only be enabled on clusters that use OVN-Kubernetes.
====
