= Creating execution RBAC for the agentic Operator

[role="_abstract"]
Create the execution role-based access control (RBAC) that the agentic Operator requires to run the execution step of an `AgenticRun`.

[IMPORTANT]
====
The agentic Operator is a Technology Preview feature. The OLM-granted `ClusterRole` for the agentic Operator only covers core resources, agentic CRDs, and RBAC. When the execution step creates a per-run `Role` granting the sandbox access to deployments, jobs, and similar resources, Kubernetes RBAC escalation prevention blocks it because the Operator service account does not have those permissions itself.

The analysis LLM dynamically proposes the RBAC for each execution sandbox based on the remediation it plans, so an execution step can require permissions on any API group, for example `monitoring.coreos.com`, `tekton.dev`, or `route.openshift.io`. Because of this, the scoped `ClusterRole` in the following procedure covers only a common set of API groups and fails whenever an execution step needs permissions outside that set. For Technology Preview, granting `cluster-admin` to the agentic Operator service account is the only reliable option. A scoped execution RBAC design is not yet available.
====

.Prerequisites

* You have installed the {ols-long} Operator.

* You have `cluster-admin` access to the cluster.

.Procedure

* Create the execution `ClusterRole` and `ClusterRoleBinding` by running the following command:
+
[source,terminal]
----
$ oc apply -f - <<'EOF'
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRole
metadata:
  name: agentic-operator-escalation
rules:
- apiGroups: ["", "apps", "batch", "networking.k8s.io"]
  resources: ["*"]
  verbs: ["get", "list", "watch", "create", "update", "patch", "delete"]
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: agentic-operator-escalation-binding
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: agentic-operator-escalation
subjects:
- kind: ServiceAccount
  name: lightspeed-agentic-operator-controller-manager
  namespace: openshift-lightspeed
EOF
----
