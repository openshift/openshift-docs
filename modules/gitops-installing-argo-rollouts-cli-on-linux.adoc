= Installing Argo Rollouts CLI on Linux

[role="_abstract"]
For Linux distributions, you can download the Argo Rollouts CLI, `kubectl-argo-rollouts`, as a `tar.gz` archive. The Argo Rollouts CLI is a plugin that extends the `oc` and `kubectl` commands.

.Prerequisites

* You have installed the {OCP} CLI (`oc`).

.Procedure

. Download the Argo Rollouts CLI for your operating system and architecture from one of the following locations:
+
* link:https://developers.redhat.com/content-gateway/rest/browse/pub/cgw/openshift-gitops/latest/[Red Hat Developer content gateway]
* link:https://mirror.openshift.com/pub/cgw/openshift-gitops/[Red Hat OpenShift mirror site]
+
[options="header"]
|===
|Operating system |Architecture |Tarball

|Linux |x86_64, amd64 |`kubectl-argo-rollouts-linux-amd64.tar.gz`
|Linux on ARM |aarch64, arm64 |`kubectl-argo-rollouts-linux-arm64.tar.gz`
|===

. Extract the archive by running the following command:
+
[source,terminal]
----
$ tar xvzf <file>
----

. Move the binary to a directory on your `PATH` environment variable and rename it to `kubectl-argo-rollouts` by running the following command:
+
[source,terminal]
----
$ sudo mv ./kubectl-argo-rollouts-linux-amd64 /usr/local/bin/kubectl-argo-rollouts
----
+
[IMPORTANT]
====
Ensure that you have superuser privileges to run this command. The file must be named `kubectl-argo-rollouts` on your `PATH` environment variable, because the `oc` and `kubectl` commands discover the plugin by this file name.
====

. Make the file executable by running the following command:
+
[source,terminal]
----
$ sudo chmod +x /usr/local/bin/kubectl-argo-rollouts
----

. After you install the Argo Rollouts CLI, verify that it is available by running the following command:
+
[source,terminal]
----
$ oc argo rollouts version
----
+
