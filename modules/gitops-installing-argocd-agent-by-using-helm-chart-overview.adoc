= Argo CD Agent Helm chart installation

[role="_abstract"]
You can install the Argo CD Agent component on the workload cluster by using Helm charts. The installation deploys an Argo CD instance and configures the Agent in managed or autonomous mode.

. Deploy an Argo CD instance on the Agent cluster.
. Install the Agent component using the Helm chart in one of the following modes:
* *Managed mode*: The Principal manages the Agent configuration and lifecycle.
* *Autonomous mode*: The Agent functions independently of the Principal.
