= Scale workloads in a hosted cluster

[role="_abstract"]
The compute capacity of a hosted cluster comes from its node pools. You scale a hosted cluster by changing the replica count of a node pool, by adding a node pool, or by enabling autoscaling so that the node pool sizes itself to demand.
