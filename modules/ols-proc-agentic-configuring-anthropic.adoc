= Connect an Anthropic provider to Agentic {ols-long}

[role="_abstract"]
To use the Anthropic API directly as the large language model (LLM) provider for Agentic {ols-long}, create a credentials secret, an `LLMProvider` custom resource (CR) with the `Anthropic` type, and an `Agent` CR that uses that provider.

.Prerequisites

* You have installed the {ols-long} Operator.
* You have logged in to the cluster as a user with the `cluster-admin` role, or with permission to create cluster-scoped custom resources.
* You have an Anthropic API key.

.Procedure

. Create a credentials secret in the `openshift-lightspeed` namespace by running the following command:
+
[source,terminal]
----
$ oc create secret generic llm-credentials \
  --from-literal=ANTHROPIC_API_KEY=<api_key> \
  -n openshift-lightspeed
----

. Create an `LLMProvider` CR that uses the `Anthropic` type:
+
[source,yaml]
----
apiVersion: agentic.openshift.io/v1alpha1
kind: LLMProvider
metadata:
  name: anthropic
spec:
  type: Anthropic
  anthropic:
    credentialsSecret:
      name: llm-credentials # <1>
    url: <api_endpoint_url> # <2>
----
<1> The name of the credentials secret that contains the `ANTHROPIC_API_KEY` key in the `openshift-lightspeed` namespace.
<2> Optional: An override for the Anthropic API endpoint. Set this value only for custom deployments or API proxies. Omit it to use the default Anthropic endpoint.

. Create an `Agent` CR that references the `LLMProvider` and specifies the model to use:
+
[source,yaml]
----
apiVersion: agentic.openshift.io/v1alpha1
kind: Agent
metadata:
  name: default # <1>
spec:
  llmProvider:
    name: anthropic # <2>
  model: <model_id> # <3>
  maxTurns: 200
----
<1> The `default` agent must exist. The deployment uses it when a workflow step does not specify an agent.
<2> The name of the `LLMProvider` CR that you created.
<3> The identifier of the Anthropic model to use.

. Apply the custom resources by running the following command:
+
[source,terminal]
----
$ oc apply -f <cr_filename>.yaml
----

.Verification

* Confirm that the resources exist by running the following commands:
+
[source,terminal]
----
$ oc get llmprovider anthropic
----
+
[source,terminal]
----
$ oc get agent default
----
