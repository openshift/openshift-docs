= Using Terraform to upgrade a {product-title} cluster from simple mode to enhanced mode (Day-2)

[role="_abstract"]
You can upgrade an existing simple-mode cluster to enhanced mode by adding the AWS infrastructure resources and associating the SQS queue URL with the cluster.

.Prerequisites
. You have SQS queue configured.
. You have your EventBridge rules configured.
. You have the associated resource policy configured.

.Procedure

. Add the `termination_handler_queue_url` attribute to your existing cluster resource:
+
[source,text]
----
resource "rhcs_cluster_rosa_hcp" "cluster" {
  name              = var.cluster_name
  cloud_region      = var.aws_region
  aws_account_id    = var.aws_account_id
  operator_role_arn = var.operator_role_arn

  # Add this line to upgrade from simple to enhanced mode
  termination_handler_queue_url = aws_sqs_queue.spot_termination.url
}
----

. Apply the configuration:
+
[source,terminal]
----
$ terraform plan && terraform apply -auto-approve
----
+
Terraform performs a patch update on the cluster. Existing Spot machine pools immediately benefit from graceful termination handling.
