= ApproverPolicyManager custom resource fields

[role="_abstract"]
You can configure the approver-policy operand managed by the {cert-manager-operator} by modifying the `ApproverPolicyManager` custom resource (CR).

:FeatureName: Managing certificate request approval by using approver-policy
include::snippets/technology-preview.adoc[leveloffset=+1]

The following table lists the parameters for configuring the `ApproverPolicyManager` CR.

[cols="3,1,5a",options="header"]
|===
|Field |Type |Description

|`spec.approveSignerNames`
|`array`
|Optional. Specifies the signer names for which approver-policy can approve certificate requests. The Operator creates and reconciles the required RBAC resources based on this setting.
|===
