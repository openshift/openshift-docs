== Fixed issues

* Before this update, Kubernetes API server rollouts in clusters that had encrypted etcd caused transmission control protocol (TCP) reset storms. This behavior resulted in application pod traffic drops. With this release, Kubernetes API server rollouts do not cause traffic drops in encrypted clusters, which improves service stability. (link:https://issues.redhat.com/browse/OCPBUGS-128828[OCPBUGS-128828])
