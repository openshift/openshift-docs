== New features and enhancements

*Multi-architecture filtering with sparse manifests*

With this release, the oc-mirror plugin v2 supports multi-architecture filtering with sparse manifests. You can add a `platforms` field to your `ImageSetConfiguration` file to mirror only the platforms that your cluster requires. Filtering applies to platform release payload images, Operator catalogs, Helm charts, and additional images. The oc-mirror plugin v2 pushes child manifests and blobs only for the architectures that you specify. It preserves the original manifest list digest, so image references and signatures remain valid. Your target registry must support sparse manifests. The `platforms` field replaces the deprecated `architectures` field. You must set `platforms` explicitly in each section that you want to filter.

For more information, see Multi-architecture filtering with sparse manifests for the oc-mirror v2 plugin
