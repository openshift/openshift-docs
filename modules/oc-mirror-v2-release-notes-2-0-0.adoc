== New features and enhancements

*Building and mirroring image sets with the OpenShift Mirror Console*

With this release, the oc-mirror plugin v2 supports the OpenShift Mirror Console, a guided web UI for disconnected mirroring. You can build an `ImageSetConfiguration` file for platform channels, Operator catalogs, and additional images without manually editing YAML files for common setups. You can then start mirror operations. You can also preview, save, or download the configuration, load an existing file, sync Operator catalog digests, and review operation history. A pull secret is required before mirroring operations are available.

For more information, see Mirror images for disconnected environments by using the OpenShift Mirror Console
