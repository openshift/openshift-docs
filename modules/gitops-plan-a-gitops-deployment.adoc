= GitOps deployment planning considerations

[role="_abstract"]
Before you install {gitops-title} on {OCP}, review the deployment architecture options, resource requirements, and security considerations to ensure a successful deployment.

Planning your {gitops-title} deployment involves the following areas:

* *Deployment architecture options*: Evaluate namespace-scoped, cluster-scoped, and default cluster-scoped instance models to determine which best fits your organizational structure and access requirements.
* *Resource requirements and sizing*: Review the resource sizing details for the default Argo CD instance and plan your cluster capacity accordingly.
* *Version compatibility*: Verify compatibility between your {OCP} cluster version and the {gitops-title} Operator version.
* *Security and access planning*: Plan your RBAC, SSO, and namespace isolation strategy before installation.
