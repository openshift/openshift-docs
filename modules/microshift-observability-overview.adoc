= {microshift-short} Observability overview

[role="_abstract"]
{microshift-short} Observability collects and transmits system data for monitoring and analysis. The data includes performance and usage metrics, and error reporting.

To set up observability for your {microshift-short} node, you must complete the following steps:

* Install and enable {microshift-short} Observability.
* Configure the observability service for your environment.
* Select a configuration size that matches your workload needs.
* Verify the observability service is running correctly.
