= How primary and secondary networks work

[role="_abstract"]
User-defined networks (UDNs) extend OVN-Kubernetes with custom layer{nbsp}2 and layer{nbsp}3 segments that can serve as either a primary or a secondary network for a pod. Understanding how these segments relate to default pod connectivity helps you plan where traffic flows.
