[id="completing-assisted-installer-oci_{context}"]
= Completing the remaining {ai-full} steps

[role="_abstract"]
After provisioning {oci-distributed} resources and uploading {product-title} custom manifests to {oci-distributed-no-rt}, complete the remaining cluster installation steps on the {ai-full} before you can create an {oci-distributed-no-rt} instance.

These steps include assigning node roles and adding custom manifests.
