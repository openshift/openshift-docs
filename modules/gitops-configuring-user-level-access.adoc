= Configuring user level access

[role="_abstract"]
To manage and change the user level access, configure the role-based access control (RBAC) section in the Argo CD custom resource (CR).

.Procedure

. Edit the `argocd` CR:
+
[source,terminal]
----
$ oc edit argocd <argocd-instance-name> -n <namespace>
----

. Add the policy under `spec.rbac`. The default policy grants `role:admin` to the `system:cluster-admins` and `cluster-admins` groups. Add a `g, <username>, role:<role>` line to grant a role to one user:
+
[source,yaml]
----
spec:
  rbac:
    policy: |
      g, system:cluster-admins, role:admin
      g, cluster-admins, role:admin
      g, <username>, role:<role>
    scopes: '[groups]'
----
