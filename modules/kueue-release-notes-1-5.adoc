[id="release-notes-1.5-new-features_{context}"]
== New features and enhancements

Hierarchical cohorts::
You can configure `Cohort` custom resources to create a hierarchy for sharing unused quota between related cluster queues. Cohort-level quotas add a shared resource pool. Borrowing and lending limits control resource sharing between a child cohort and its parent.
+
For more information, see xref:../../ai_workloads/kueue/using-cohorts.adoc#using-cohorts[Using cohorts].
