= SPIRE within a single cluster

[role="_abstract"]
Within a single mesh, you can issue workload identities and establish trust across applications by deploying the SPIFFE Runtime Environment (SPIRE). 

To deploy SPIRE on a single cluster, you complete two high-level steps:

. Install the Zero Trust Workload Identity Manager (ZTWIM) Operator and deploy the SPIRE components (server, agent, CSI driver, and OIDC discovery provider).
. Integrate the {istio} control plane with SPIRE by configuring the {istio} CR to use SPIFFE identities instead of default {istio} certificates.

[NOTE]
====
For multi-cluster environments where workloads need to communicate across cluster boundaries, use a federated SPIRE deployment instead. Federated deployments enable workloads on different clusters to verify each other's SPIFFE identities through established trust relationships between SPIRE servers.
====
