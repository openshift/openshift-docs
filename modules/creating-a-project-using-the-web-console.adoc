= Creating a project by using the web console

[role="_abstract"]
You can use the {product-title} web console to create a project in your cluster.

[NOTE]
====
Projects starting with `openshift-` and `kube-` are considered critical by {product-title}. 
{product-title} does not allow you to create projects starting with `openshift-` by using the web console.
====

.Prerequisites

* You have the appropriate roles and permissions to create projects, applications, and other workloads in {product-title}.

.Procedure

. Navigate to *Home* -> *Projects*.

. Click *Create Project*:
+
.. In the *Create Project* dialog box, enter a unique name, such as `myproject`, in the *Name* field.
+
.. Optional: Add the *Display name* and *Description* details for the project.
+
.. Click *Create*.
+
The dashboard for your project is displayed.
+
.. Optional: Select the *Details* tab to view the project details.
+
.. Optional: If you have adequate permissions for a project, select the *RoleBindings* tab to provide or revoke admin, edit, and view privileges for users and groups in the project.
