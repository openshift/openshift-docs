= Identity provider and OAuth integration

[role="_abstract"]
Integrate the MCP server for Red{nbsp}Hat OpenShift with an identity provider and OAuth so that users authenticate through single sign-on and the server accesses {product-title} resources with their identity.

An _identity provider_ (IdP) is a centralized service that creates, maintains, and manages user identity information and authenticates users to applications and systems. Instead of separate credentials per application, an IdP lets users authenticate once (single sign-on) and pass that verification securely to other services.

_OAuth_ (specifically OAuth 2.0) is an open-standard authorization framework. It allows a third-party application to access a user's resources on another service without exposing the user's password. Instead of sharing login credentials, OAuth uses access tokens that grant specific, limited permissions (scopes).

The MCP gateway validates the OAuth token and passes it to the MCP server, which uses it to authenticate against the {product-title} API. The server either passes the token through (default) or exchanges it depending on configuration: Controlled by `cluster_auth_mode` and whether a `[token_exchange]` block is configured..

There are two Identity and Access Management (IAM) platforms that you can use:

* Red{nbsp}Hat build of Keycloak

* Microsoft Entra ID
