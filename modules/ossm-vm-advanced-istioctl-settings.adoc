= Advanced istioctl settings for the virtual machine address

[role="_abstract"]

By default, the proxy detects the address that it registers with the control plane. This detection is unreliable when the virtual machine has more than one routable network interface, because the proxy can select an interface that in-cluster workloads cannot reach. Set the address explicitly in that case.

The `istioctl x workload entry configure` command provides two options for this purpose. Both options write the address to the `ISTIO_SVC_IP` variable in the generated `cluster.env` file, and they are mutually exclusive.

.Options for setting the virtual machine address
[options="header"]
[cols="1,3"]
|===
|Option |When to use it

|`--internalIP`
|The virtual machine is directly reachable from the cluster at this address, with no network address translation (NAT) on the connection path. Set the option to the address of the interface that in-cluster workloads connect to.

|`--externalIP`
|The virtual machine is not directly reachable, and traffic to it passes through a load balancer or is subject to NAT. Set the option to the address that in-cluster workloads connect to, rather than to an address configured on the virtual machine.
|===

For a virtual machine that is directly reachable at `10.0.2.2`, run the following command:

[source,terminal]
----
$ istioctl x workload entry configure \
  --name vm-app \
  --namespace external-vm \
  --autoregister \
  --internalIP 10.0.2.2 \
  -o vm-files
----

For a virtual machine that in-cluster workloads reach at `203.0.113.10` through a load balancer, run the following command:

[source,terminal]
----
$ istioctl x workload entry configure \
  --name vm-app \
  --namespace external-vm \
  --autoregister \
  --externalIP 203.0.113.10 \
  -o vm-files
----

[NOTE]
====
When you use the `--externalIP` option, the command also sets the `REWRITE_PROBE_LEGACY_LOCALHOST_DESTINATION` variable to `true` in the `cluster.env` file, so that health probes are rewritten to the local address of the virtual machine rather than to the external address.
====
