= Bug fixes and security updates in version 4.11.5

[role="_abstract"]
This release includes the following bug fixes:

//ROX-36439
* Before this update, vulnerability scans failed with "unexpected status code: 403 Forbidden" errors when scanning container images that included large files. With this release, Red{nbsp}Hat fixed the scanning logic for large files. As a result, vulnerability scans complete successfully, regardless of file size.

//ROX-33402
* Before this update, creating ad hoc vulnerability reports from the *Results* tab required the `WorkflowAdministration` "write" permission that is needed for users to modify or delete other users' report configurations. With this release, Red{nbsp}Hat separated the report creation permission from report configuration management. As a result, users can now create ad hoc reports without requiring excessive permissions.

//ROX-36389
* Before this update, vulnerability counts displayed in the {ocp} web console differed from the counts shown in the {product-title-short} portal. With this release, Red{nbsp}Hat aligned the vulnerability reporting logic between the two interfaces. As a result, vulnerability counts are now consistent across the {ocp} web console and {product-title-short} portal.

This release also addresses the following security vulnerabilities:

//ROX-37062, ROX-37063, ROX-37064, ROX-37065, ROX-37066, ROX-37067, ROX-37068
* gRPC-Go: Denial of Service through malformed RPC requests (link:https://access.redhat.com/security/cve/CVE-2026-84445[CVE-2026-84445])
