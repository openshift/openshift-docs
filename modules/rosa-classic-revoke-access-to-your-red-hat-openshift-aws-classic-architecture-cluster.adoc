= Revoke access to your Red Hat OpenShift AWS (Classic Architecture) cluster

[role="_abstract"]
An identity provider (IDP) controls access to a {product-title} cluster. To revoke access of a user to a cluster, you must configure that within the IDP that was set up for authentication.
