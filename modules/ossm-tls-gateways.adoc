[id="ossm-tls-gateways_{context}"]
= Configure TLS for gateways

[role="_abstract"]

Secure traffic entering and leaving the mesh by configuring Transport Layer Security (TLS) on your gateways. TLS encryption is a baseline requirement for any gateway and is independent of other security features such as {pqc-short}.
