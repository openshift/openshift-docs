= Example configuration for defining parameter values

[role="_abstract"]
Build strategies support parameters that you can configure with specific values in a `Build` custom resource (CR). Parameters enable you to customize build behavior without modifying the build strategy itself.

Define parameters in a `ClusterBuildStrategy` CR::
The following example defines several parameters in a `ClusterBuildStrategy` CR:
+
[source,yaml]
----
apiVersion: shipwright.io/v1beta1
kind: ClusterBuildStrategy
metadata:
  name: buildah
spec:
  parameters:
    - name: build-args
      description: "The values for the args in the Dockerfile. Values must be in the format KEY=VALUE."
      type: array
      defaults: []
    # ...
    - name: storage-driver
      description: "The storage driver to use, such as 'overlay' or 'vfs'."
      type: string
      default: "vfs"
# ...
steps:
# ...
----

Assign values to parameters in a `Build` CR::
The following example overrides the default value of the `storage-driver` parameter defined in the `ClusterBuildStrategy` CR:
+
[source,yaml]
----
apiVersion: shipwright.io/v1beta1
kind: Build
metadata:
  name: <your_build>
  namespace: <your_namespace>
spec:
  paramValues:
    - name: storage-driver
      value: "overlay"
  strategy:
    name: buildah
    kind: ClusterBuildStrategy
  output:
  # ...
----
+
where:
+
`<your_build>`:: Specifies the name of the `Build` CR.
`<your_namespace>`:: Specifies the namespace where the `Build` CR is created.

Use a `ConfigMap` CR to define parameter values centrally::
If multiple builds use the same parameter value, store the value in a `ConfigMap`. This enables you to update the value in one location and reuse it across multiple builds.
+
[source,yaml]
----
apiVersion: v1
kind: ConfigMap
metadata:
  name: buildah-configuration
  namespace: <your_namespace>
data:
  storage-driver: overlay
----
+
where:
+
`<your_namespace>`:: Specifies the namespace where the `ConfigMap` CR is created.
+
Reference the `ConfigMap` value in your `Build` CR:
+
[source,yaml]
----
apiVersion: shipwright.io/v1beta1
kind: Build
metadata:
  name: <your_build>
  namespace: <your_namespace>
spec:
  paramValues:
    - name: storage-driver
      configMapValue:
        name: buildah-configuration
        key: storage-driver
  strategy:
    name: buildah
    kind: ClusterBuildStrategy
  output:
  # ...
----
+
where:
+
`<your_build>`:: Specifies the name of the `Build` CR.
`<your_namespace>`:: Specifies the namespace where the `Build` CR is created.

Assign values to array parameters in a `Build` CR::
You can assign multiple values to parameters of the `array` type. For example, the following configuration specifies a registry to search for images:
+
[source,yaml]
----
apiVersion: shipwright.io/v1beta1
kind: Build
metadata:
  name: <your_build>
  namespace: <your_namespace>
spec:
  paramValues:
    - name: storage-driver
      configMapValue:
        name: buildah-configuration
        key: storage-driver
    - name: registries-search
      values:
        - value: registry.redhat.io
  strategy:
    name: buildah
    kind: ClusterBuildStrategy
  output:
  # ...
----
+
where:
+
`<your_build>`:: Specifies the name of the `Build` CR.
`<your_namespace>`:: Specifies the namespace where the `Build` CR is created.

Reference a `Secret` in a `Build` CR::
You can reference a value from a `Secret` as a parameter. The following example blocks specific registries by using a value stored in a `Secret`:
+
[source,yaml]
----
apiVersion: shipwright.io/v1beta1
kind: Build
metadata:
  name: <your_build>
  namespace: <your_namespace>
spec:
  paramValues:
    - name: storage-driver
      configMapValue:
        name: buildah-configuration
        key: storage-driver
    - name: registries-block
      values:
        - secretValue:
            name: registry-configuration
            key: reg-blocked
  strategy:
    name: buildah
    kind: ClusterBuildStrategy
  output:
  # ...
----
+
where:
+
`<your_build>`:: Specifies the name of the `Build` CR.
`<your_namespace>`:: Specifies the namespace where the `Build` CR is created.
