= Enhance user authentication on your nodes

[role="_abstract"]
Node-level authentication controls who can log in to the underlying host rather than to the cluster API. You can harden it by managing the core user password and by adding {op-system-base-full} authentication extensions to a machine config pool through a `MachineConfig` object.
