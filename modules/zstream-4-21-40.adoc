== Fixed issues

* Before this update, selecting a specific project in the project selector caused the Namespace column to be hidden in the Pods tab on the Node Details page, even when Namespace was enabled under Manage Columns. As a consequence, users could not determine which namespace each pod belonged to, even though the tab displayed pods from multiple namespaces. With this release, the Namespace column is displayed correctly in the Node Details Pods tab regardless of the selected project. As a result, users can identify the namespace of each pod when viewing the Pods tab on a node. (link:https://issues.redhat.com/browse/OCPBUGS-132569[*OCPBUGS-132569*])

* Before this update, the {product-title} web console expected an Ingress Controller to exist even when the Ingress capability was disabled in hosted control plane clusters. As a consequence, hosted control plane clusters with disabled Ingress capability could not access the web console. With this release, the web console correctly handles hosted control plane clusters without Ingress Controllers. As a result, the web console is accessible in hosted control plane environments with disabled Ingress capability. (link:https://issues.redhat.com/browse/OCPBUGS-130936[*OCPBUGS-130936*])

* Before this update, the boot image controller required an exact match between machine set failure domains and the platform's configured failure domains. As a consequence, machine sets with valid but non-matching failure domain configurations were skipped during boot image updates. With this release, the boot image controller accepts machine sets with compatible failure domain configurations even when they do not exactly match the platform configuration. As a result, boot images are updated correctly across all valid machine sets. (link:https://issues.redhat.com/browse/OCPBUGS-129667[*OCPBUGS-129667*])

* Before this update, when you navigated to a *Terminal* tab of a node in the {product-title} web console, the component checked for the debug pod even if the pod was still being created. As a consequence, a `Debug pod not found or was deleted.` error appeared before the terminal loaded successfully. With this release, a loading spinner is shown when the debug pod is being created, and the cleanup logic guards against an undefined namespace to prevent errors on early unmount. As a result, the *Terminal* tab of a node loads without displaying a false error message. (link:https://issues.redhat.com/browse/OCPBUGS-111098[*OCPBUGS-111098*])
