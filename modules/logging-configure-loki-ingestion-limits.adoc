= Configure LokiStack ingestion limits

[role="_abstract"]
Adjust the LokiStack ingestion rate limit and per-stream rate limit to match your workload's log volume. Use PromQL metrics to determine appropriate values before making changes.

[IMPORTANT]
====
Increasing ingestion limits increases the resource consumption of LokiStack pods. Verify that the nodes where LokiStack pods run have sufficient CPU and memory before raising limits.
====

The following table describes the configurable ingestion limit fields on the `LokiStack` custom resource:

[cols="2,1,3",options="header"]
|===
| Field | Default | Description

| `ingestionRate`
| 4 MB per second
| Maximum total bytes per second that LokiStack accepts across all streams for a tenant. Enforced globally and distributed across distributor replicas.

| `ingestionBurstSize`
| 6 MB
| Maximum bytes accepted in a single push request per distributor. Should be at least the size of the largest expected push request.

| `perStreamRateLimit`
| 3 MB per second
| Maximum bytes per second from a single log stream. Must be less than `ingestionRate`.

| `perStreamRateLimitBurst`
| 15 MB
| Maximum bytes accepted in a burst from a single stream.
|===

[NOTE]
====
`ingestionRate` must always be greater than `perStreamRateLimit`. The recommended maximum values are 5 MB per second for `perStreamRateLimit` and 20 MB for `perStreamRateLimitBurst`.
====

.Prerequisites

* You have administrator permissions.
* You have installed the OpenShift CLI (`oc`).

.Procedure

. Measure the actual ingestion rate for each tenant to determine an appropriate `ingestionRate` value:
+
[source,promql]
----
sum by (tenant) (rate(loki_distributor_bytes_received_total[5m]))
----
+
Run this query in the OpenShift web console under *Observe* -> *Metrics* during a representative workload period. Use the result as the baseline for `ingestionRate`.

. Review the current LokiStack ingestion limits:
+
[source,terminal]
----
$ oc get lokistack <lokistack_name> -n openshift-logging \
  -o jsonpath='{.spec.limits}' | jq
----

. Edit the `LokiStack` custom resource to update the ingestion limits:
+
[source,terminal]
----
$ oc patch lokistack <lokistack_name> -n openshift-logging \
  --type merge -p '{
    "spec": {
      "limits": {
        "global": {
          "ingestion": {
            "ingestionRate": <ingestion_rate>,
            "ingestionBurstSize": <ingestion_burst_size>,
            "perStreamRateLimit": <per_stream_rate>,
            "perStreamRateLimitBurst": <per_stream_burst>
          }
        }
      }
    }
  }'
----
+
Replace the placeholder values with values appropriate for your workload. Ensure that `ingestionRate` is greater than `perStreamRateLimit`.

. Verify that the LokiStack accepts the new configuration and returns to a ready state:
+
[source,terminal]
----
$ oc get lokistack <lokistack_name> -n openshift-logging
----

. Monitor the discard metric to confirm that rate limit errors have resolved:
+
[source,promql]
----
sum by (tenant, reason) (rate(loki_discarded_samples_total[2m]))
----
