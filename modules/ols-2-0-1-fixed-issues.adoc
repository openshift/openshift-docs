= Fixed issues

[role="_abstract"]
{ols-official} 2.0.1 resolves tool-result inspection regressions and provides better insight into why a tool result is rejected.

{ols-official} 2.0.1 fixes the following issues:

* Before this update, tool-result inspection could fail to classify results when using reasoning-capable models or Anthropic models hosted on Vertex AI. With this update, these classifier paths are corrected. If inspection cannot be completed, {ols-official} reports that condition separately from a tool result that fails safety inspection.
