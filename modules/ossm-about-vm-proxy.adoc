= About running the {istio} proxy on a virtual machine

[role="_abstract"]

To run the proxy in the operating system instead of in a pod, you install the `istio-proxy` RPM on the machine, provision the machine with the mesh configuration and credentials, and run the proxy as a systemd service.

After the service is running, the workload participates in the mesh in the same way as any other workload. Mutual TLS, traffic policy, telemetry, and service discovery all apply.

The `istio-proxy` RPM provides the following components:

* The Envoy proxy binary, which handles data plane traffic for the workload.

* The `pilot-agent` binary, which connects to the control plane, requests workload certificates, and manages the proxy process.

* The systemd integration, which configures iptables traffic interception and starts the proxy as a dedicated, unprivileged system user.

Red Hat builds and ships the `istio-proxy` RPM for Red Hat Enterprise Linux (RHEL) 9. The upstream {istio} project publishes a separate community package named `istio-sidecar`, which Red Hat does not provide or support.
