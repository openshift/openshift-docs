= Prerequisites for installing a cluster on {azure-short}

[role="_abstract"]
Before you install an {product-title} cluster on {azure-short}, ensure that you have selected a cluster installation method and configured an {azure-short} account to host the cluster and determine the tested and validated region to deploy the cluster to.

If you use a firewall, you must configure it to allow the sites that your cluster requires access to.
