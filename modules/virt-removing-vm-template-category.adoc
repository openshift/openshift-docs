= Remove a category from a VM template

[role="_abstract"]
You can remove the category from a `VirtualMachineTemplate` object by using the {product-title} web console.

.Prerequisites

* You have access to the {product-title} web console.
* You have `edit` or `admin` permissions on the template.

.Procedure

. In the {product-title} web console, navigate to *Virtualization* -> *Templates*.
. Click the name of the *VirtualMachineTemplate* that you want to edit.
. On the template details page, click the edit icon next to the *Category* field.
. In the *Edit category* dialog, click the clear icon (x) in the *Category* field to remove the current category.
+
The *Category* field displays the *Select or create new* placeholder text.
. Click *Save*.

.Verification

* On the template details page, verify that the *Category* field displays *None*.
