= Defining required Terraform variables

[role="_abstract"]
Update you local Terraform variables file with the NodePoolManagement role ARN.

.Procedure

. (Optional): Retrieve the NodePoolManagement role ARN from an existing cluster:
+
[source,terminal]
----
rosa describe cluster -c <cluster-name> -o json | jq -r '.aws.sts.role_arn'
----

. Add the following variables to your `variables.tf` file:
+
[source,text]
----
variable "cluster_name" {
  description = "Name of the ROSA HCP cluster"
  type        = string
}

variable "nodepool_management_role_arn" {
  description = "ARN of the NodePoolManagement IAM role for the cluster"
  type        = string
}
----
+
The NodePoolManagement role ARN typically follows this pattern:
+
[source,text]
----
arn:aws:iam::<account-id>:role/ManagedOpenShift-HCP-ROSA-NodePoolManagement-Role
----
