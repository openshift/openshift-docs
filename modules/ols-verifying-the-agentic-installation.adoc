= Verifying the installation

[role="_abstract"]
Verify that all deployments and custom resources (CRs) are in place, and then submit a test `AgenticRun` to confirm that Agentic {ols-long} is working.

.Prerequisites

* You have installed the {ols-long} Operator.

* You have configured Agentic {ols-long}.

.Procedure

. Check that all deployments are ready by running the following command:
+
[source,terminal]
----
$ oc get deploy -n openshift-lightspeed
----
+
All of the following deployments must show as `READY`:
+
* `lightspeed-operator-controller-manager`
* `lightspeed-agentic-operator-controller-manager`
* `lightspeed-app-server`
* `lightspeed-agentic-console-plugin`
* `lightspeed-console-plugin`
* `lightspeed-otel-collector`
* `lightspeed-postgres-server`
* `lightspeed-rhokp`
* `openshift-mcp-server`

. Check that all CRs are in place by running the following commands:
+
[source,terminal]
----
$ oc get olsconfig cluster
----
+
[source,terminal]
----
$ oc get llmprovider openai -n openshift-lightspeed
----
+
[source,terminal]
----
$ oc get agent default -n openshift-lightspeed
----
+
[source,terminal]
----
$ oc get approvalpolicy cluster
----

. Submit a test `AgenticRun` by running the following command:
+
[source,terminal]
----
$ oc apply -f - <<'EOF'
apiVersion: agentic.openshift.io/v1alpha1
kind: AgenticRun
metadata:
  name: namespace-inventory
  namespace: openshift-lightspeed
spec:
  request: |
    Investigate what is running in the openshift-lightspeed namespace.
    List all pods, deployments, and services. Summarize each workload,
    its current status, and flag any problems (CrashLoopBackOff,
    ImagePullBackOff, Pending, restarts, etc.). Propose remediation
    for any issues found.
  analysis:
    agent: default
  execution:
    agent: default
EOF
----

. Watch the progress of the run by running the following command:
+
[source,terminal]
----
$ oc get agenticrun namespace-inventory -n openshift-lightspeed -w
----

. Check the status and conditions of the run by running the following command:
+
[source,terminal]
----
$ oc get agenticrun namespace-inventory -n openshift-lightspeed \
  -o jsonpath='{.status.conditions[*].message}' | tr ',' '\n'
----

.Verification

* A successful run produces output similar to the following example:
+
[source,terminal]
----
Analysis complete — no action required
Outcome: Succeeded
----
+
The run also populates `status.tokenUsage` with input and output token counts.

[NOTE]
====
If the run fails with the reader RBAC error, create the reader RBAC for the agent service account.

If the analysis stage is set to `Manual` in the `ApprovalPolicy`, or no policy exists, the run blocks at `analysis pending approval`. Either update the policy to auto-approve the analysis stage or approve it manually by using the `AgenticRunApproval` resource.
====

. Clean up the test run by running the following command:
+
[source,terminal]
----
$ oc delete agenticrun namespace-inventory -n openshift-lightspeed
----
