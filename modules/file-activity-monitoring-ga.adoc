= File activity monitoring is Generally Available

// JIRA: ROX-32074

[role="_abstract"]
File activity monitoring is now GA. This feature provides custom wildcard path matching, process and ancestor filtering, file rename detection, and combined policy rules.

In addition, file activity monitoring includes the following changes in this release:

* {product-title-short} added access control list (ACL) changes as a file access operation for runtime policies.
* File access policies now detect extended attribute (xattr) changes.

For more information, see "Configuring file activity monitoring".
