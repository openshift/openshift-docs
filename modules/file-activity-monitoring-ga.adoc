= File activity monitoring is Generally Available

// JIRA: ROX-32074

[role="_abstract"]
File activity monitoring is now GA. This feature provides custom wildcard path matching, process and ancestor filtering, file rename detection, and combined policy rules.

For more information, see "Configuring file activity monitoring".
