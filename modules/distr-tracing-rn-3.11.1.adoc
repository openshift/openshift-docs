The {dt} 3.11.1 release fixes this issue:

{Dit} images include root CA certificates::
Before this update, the {dt} images shipped in the 3.11.0 release lacked root CA certificates. As a consequence, the external storage certificates failed verification with an `x509: certificate signed by unknown authority` error, preventing connections. With this update, the {dt} images include root CA certificates. As a result, the external storage certificates are verified correctly, and connections succeed.
