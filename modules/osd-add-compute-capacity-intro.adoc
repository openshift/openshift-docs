= Add compute capacity

[role="_abstract"]
You can add compute capacity to your cluster by creating a machine pool using {cluster-manager-first}.

On {product-title}, you can also create machine pools that use Windows License Included (LI) instances, AWS Capacity Reservations, or spot instances.
