= Hosting cluster maintenance for virtualized control planes

[role="_abstract"]
Hosting cluster maintenance, such as operating system updates or hardware repairs, can disrupt control plane VMs on the affected node.
To preserve `etcd` quorum during these operations, maintenance must follow a sequential, one-node-at-a-time approach.

Before any node is cordoned, all control plane VMs must be healthy and `etcd` quorum must be intact.
Only one hosting cluster node is drained at a time.
After the drained node's control plane VM shuts down, the remaining control plane VMs must still maintain `etcd` quorum before maintenance proceeds.
The node is returned to service and the VM and `etcd` member are verified healthy before the next node is drained.
