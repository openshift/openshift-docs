= Recommended network topology

[role="_abstract"]
A two-node {product-title} cluster with fencing requires network connectivity for Pacemaker cluster communication, fencing, and application traffic. The recommended physical topology uses two top-of-rack (TOR) switches in a multi-chassis link aggregation (MC-LAG) configuration with cross-cabled baseboard management controller (BMC) interfaces. As explained below, node NICs should form a bond using Link Aggregation Control Protocol (LACP).

.Recommended TNF network topology
image::tnf-recommended-network-topology.png[Diagram showing two TNF nodes connected to two TOR switches. Each node bonds two Kubernetes network interface cards (NICs) across both switches by using Link Aggregation Control Protocol (LACP). BMC interfaces are cross-cabled to the opposite switch.]

The recommended topology has the following characteristics. They are explained further in the xref:tnf-bmc-network-isolation-for-fencing_{context}[BMC network isolation for fencing] section:

Dual-switch Kubernetes fabric::
Each node bonds two network interface cards (NICs) across both TOR switches by using LACP. If one switch fails, Pacemaker cluster communication continues through the surviving switch. Active/Standby bonding is supported as an alternative to LACP.

MC-LAG inter-switch link::
The two TOR switches are connected by an MC-LAG link that allows them to present a single logical interface to each bonded NIC pair. This provides redundancy at the switch level.

Cross-cabled BMC interfaces::
Each node's BMC interface connects to the TOR switch on the _opposite_ side of the topology. Node 1's BMC connects to TOR Switch 2, and Node 2's BMC connects to TOR Switch 1.

[IMPORTANT]
====
A single-switch topology, where each node's Kubernetes NICs connect to only one switch, is not recommended. A single switch failure in this configuration causes a full network partition between nodes, which forces the cluster into degraded mode, in which only one node remains operational and critical operations such as certificate rotation and upgrades are disabled.
====
