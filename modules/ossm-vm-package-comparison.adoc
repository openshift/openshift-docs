= Comparison with the community istio-sidecar package

[role="_abstract"]

The upstream {istio} project publishes a community package named `istio-sidecar`, available as both an RPM and a Debian package. {SMProductName} ships a different package, named `istio-proxy`, which Red Hat builds and supports.

Both packages install the same upstream components and use the same configuration files, but they differ in packaging, file locations, service name, and privilege model. Review the following differences before you adapt a procedure that was written for the community package.

[IMPORTANT]
====
Red Hat provides and supports only the `istio-proxy` package. The community `istio-sidecar` package is not supported.
====

.Differences between the community `istio-sidecar` package and the {SMProductName} `istio-proxy` package
[options="header"]
[cols="1,2,2"]
|===
|Characteristic |Community `istio-sidecar` |{SMProductName} `istio-proxy`

|Distribution
|Published as a release artifact by the {istio} project, as an RPM and a Debian package.
|Published by Red Hat for Red Hat Enterprise Linux (RHEL) 9. The package is signed and is accompanied by a source RPM and debuginfo packages.

|Build
|Repackages pre-built binaries.
|Built from source by Red Hat against the system OpenSSL library.

|Proxy binary
|`/usr/local/bin/envoy`
|`/usr/bin/envoy`

|Agent binary
|`/usr/local/bin/pilot-agent`
|`/usr/bin/pilot-agent`

|Startup script
|`/usr/local/bin/istio-start.sh`
|`/usr/libexec/istio-proxy/istio-start.sh`

|systemd unit
|`istio.service`
|`istio-proxy.service`

|Process owner
|Runs as `root`, then drops to the `istio-proxy` user by using `sudo`.
|Runs as the `istio-proxy` user. Only the iptables setup and teardown run as `root`.

|Log destination
|`/var/log/istio/istio.log` and `/var/log/istio/istio.err.log`
|The systemd journal.

|SELinux
|No policy is provided, so the service runs unconfined.
|The optional `istio-proxy-selinux` subpackage provides a confined domain.

|Package removal
|Leaves iptables rules and directories in place.
|Removes iptables rules and the installed directories.
|===
