= Enable the agent component in hybrid architecture

Enable the agent component on the spoke cluster.

.Prerequisites

* You have installed the agent component. For more information, see _Installing the agent component_.
* You have configured the agent client mode to connect to the principal.
* You have set up TLS certificates for secure communication.
* You have configured Redis for the agent's state storage.

.Procedure

* Configure the `ArgoCD` CR on the spoke cluster:
+
[source,yaml]
----
apiVersion: argoproj.io/v1beta1
kind: ArgoCD
metadata:
  name: argo-cd-agent
spec:
  argoCDAgent:
    agent:
      enabled: true
      labelSelector: "argocd-agent=true"
      destinationBasedMapping:
        enabled: true
        createNamespace: true
      allowedNamespaces:
          - "*"
----
+
where:
+
`labelSelector`:: Restricts the agent to labeled resources only. Existing applications without this label remain unaffected.
`destinationBasedMapping.enabled`:: Routes applications based on destination cluster name rather than namespace.
`destinationBasedMapping.createNamespace`:: Automatically creates target namespaces for application resources.
`allowedNamespaces`:: Specifies the namespaces where the agent watches Argo CD resources.
+
[NOTE]
====
The hybrid architecture requires the agent to be configured in managed mode. Ensure that the agent's mode is set to `managed` in your agent configuration.
====
