= Edit a VM template category

[role="_abstract"]
You can edit the category of a `VirtualMachineTemplate` by using the {product-title} web console. This procedure applies to both `v1alpha1` and `v1beta1` `VirtualMachineTemplate` objects, and is the only way to assign a category to a `v1alpha1` template.

.Prerequisites

* You have access to the {product-title} web console.
* You have `edit` or `admin` permissions on the template.

.Procedure

. In the {product-title} web console, navigate to *Virtualization* -> *Templates*.
. Click the name of the `VirtualMachineTemplate` that you want to edit.
. On the template details page, click the *Actions* menu and select *Edit category*.
+
You can also click the edit icon next to the *Category* field in the details grid.
. Select a category from the list, or type a custom category name.
. Click *Save*.

.Verification

* On the template details page, verify that the *Category* field displays the updated category.
* Navigate to *Virtualization* -> *Templates* and verify that the *Category* column displays the updated category for the template.
