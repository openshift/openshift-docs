== Known issues

Kustomize 5.8.x namespace propagation issue for Helm-generated resources::
In {gitops-title} 1.20, the bundled Kustomize versions 5.8.0 and 5.8.1 contain an upstream issue that prevents namespace propagation for Helm-generated resources. If your applications rely on Kustomize to set `metadata.namespace` for resources generated from Helm charts, the generated resources do not include a namespace. As a result, application synchronization fails with an `InvalidSpecError`.
+
As a workaround, configure the Argo CD custom resource (CR) to use Kustomize v5.7.1, which is not affected by this issue.
+
* Add the Kustomize v5.7.1 binary to the `repo-server` pod by configuring the `spec.repo.initContainers`, `spec.repo.volumes`, and `spec.repo.volumeMounts` fields in the Argo CD CR.
+
* Add the custom Kustomize version to the Argo CD CR by configuring the `spec.kustomizeVersions` field:
+
[source,yaml]
----
  spec:
   kustomizeVersions:
   - version: v5.7.1
     path: /custom-tools/kustomize_5_7_1
----

* Set `kustomize.version: v5.7.1` in the affected `Application` resources to use the custom Kustomize version.
+
