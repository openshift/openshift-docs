= Inheriting the cluster TLS security profile

[role="_abstract"]
The operator and the SPIRE operands read the cluster TLS security profile and apply it to their TLS listeners.

The profile is stored in `spec.tlsSecurityProfile` on the `apiserver.config.openshift.io/cluster` resource. The operands apply the minimum TLS version and cipher suites from that profile. When the profile defines key-exchange groups, the operands apply those groups as well.

When an administrator changes the cluster TLS security profile, the affected operands roll out and start using the updated profile.

If the API server is temporarily unavailable, the operands use the Intermediate TLS security profile until they can read the cluster profile again.
