= Known issues

[role="_abstract"]
{ols-official} 1.1.5 contains a known issue where tool-result inspection can fail at the tool call step for certain models.

//No associated ticket
* *Tool-result inspection can fail at the tool call step for certain models*
+
Tool-result inspection might fail at the tool call step for certain models across the supported providers. When this issue occurs, the tool call does not complete successfully.
+
Workaround: Disable the tool-result inspection flag in your {ols-official} configuration custom resource (CR).
