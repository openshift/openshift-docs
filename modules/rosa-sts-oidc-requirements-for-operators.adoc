= OIDC requirements for Operator authentication

[role="_abstract"]
For {product-title} installations that use the AWS Security Token Service (STS), you must create a cluster-specific OpenID Connect (OIDC) provider that is used by the cluster Operators to authenticate or create your own OIDC configuration for your own OIDC provider.
