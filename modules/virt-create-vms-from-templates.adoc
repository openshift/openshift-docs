= Create VMs from templates

[role="_abstract"]
Deploy virtual machines (VMs) from preconfigured templates to ensure consistent settings across your organization. Templates define a reusable VM configuration that you can share across teams and projects, reducing manual setup and configuration drift.

{VirtProductName} supports the following template workflows:

* Use existing templates to create VMs from Red Hat-supplied or custom templates with preconfigured settings.
* Customize templates to adjust compute, storage, and network settings for your environment.
* Create new templates to define organization-specific VM configurations that other users can deploy.
* Organize templates by category to make it easier for users to find the right template for their workload.
