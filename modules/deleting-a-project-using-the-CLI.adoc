= Delete a project by using the CLI

// Moved intro paragraph to working-with-projects.adoc

[role="_abstract"]
You can delete a project by using the {oc-first}.

.Prerequisites

* You have installed the {oc-first}.
* You have created a project.
* You have the required permissions to delete the project.

.Procedure

. Delete your project:
+
[source,terminal]
----
$ oc delete project <project_name>
----
+
`<project_name>`:: Replace `<project_name>` with the name of the project that you want to delete.
