= Q3 2026

[role="_abstract"]
The following items were added during the third quarter of 2026.

Default worker node instance type is now `m7i.xlarge`::
+
Starting September 9, new {product-title} clusters that do not specify a worker node instance type use `m7i.xlarge` by default. For more information, see link:https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws/4/html-single/introduction_to_rosa/index#rosa-sts-overview-of-the-default-cluster-specifications_rosa-sts-creating-a-cluster-quickly[Overview of the default cluster specifications].
+
[NOTE]
====
The `m7i` instance type is not available in every AWS region. In regions where `m7i` is not offered, you must specify a supported instance type or cluster creation fails. Currently, the `m7i` instance type is _not_ supported in Calgary `ca-west-1` and Bahrain `me-south-1`. For a complete list of supported regions, see link:https://docs.aws.amazon.com/ec2/latest/instancetypes/ec2-instance-regions.html[_Amazon EC2 instance types by Region_].
====

Disaster recovery policies are updated::

A new backup and recovery strategy for the {product-title} cluster control planes is implemented, minimizing cluster risk from disaster events. For more information, see link:https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws/4/html-single/introduction_to_rosa/index#rosa-policy-disaster-recovery_rosa-policy-responsibility-matrix[Disaster recovery].
