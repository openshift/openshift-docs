[id="zstream-4-14-73-fixed-issues_{context}"]
== Fixed issues

* Before this update, the OLM CSV annotation contained unexpected JSON , which was successfully parsed, but then threw a runtime error when attempting to use the resulting value. With this release, JSON values from OLM annotations are validated before use, and errors are logged, but the console does not fail when unexpected JSON is received in an annotation. (link:https://redhat.atlassian.net/browse/OCPBUGS-90614[OCPBUGS-90614])
