= Manage VM fleets at scale

[role="_abstract"]
Operate large numbers of virtual machines (VMs) as a group by running bulk actions from the web console and automating VM lifecycle tasks in CI/CD pipelines.

Managing a few VMs by hand does not scale. At fleet size, the same change must reach many VMs at once, repeat reliably, and run without a person in the web console.

{VirtProductName} supports several approaches, which you can combine:

Web console bulk actions:: Select several VMs in the *VirtualMachines* list and act on them together, for example to apply labels, take snapshots, or live migrate.

CI/CD pipelines:: {pipelines-title} runs each step of a pipeline in its own container, so that you can create and manage VMs and their disks as part of an automated deployment workflow.
