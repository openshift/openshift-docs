= OpenShift Pipelines component observability metrics reference

In {pipelines-title}, observability metrics are collected in OpenTelemetry (OTel) format. You can use these metrics to monitor component health, operational performance, and resource usage in Prometheus or Grafana.

[id="op-metrics-pipeline_{context}"]
== Tekton Pipelines metrics

The Tekton Pipelines controller exposes core operational metrics and Knative infrastructure metrics.

.Core Tekton Pipelines metrics
[cols="3,1,2,2",options="header"]
|===
| Metric name | Type | Labels | Description

| `tekton_pipelines_controller_pipelinerun_duration_seconds`
| Histogram
| `status`, `pipeline`, `namespace`, `reason` (optional)
| Duration of PipelineRun executions in seconds.

| `tekton_pipelines_controller_pipelineruns_total`
| Counter
| `status`, `namespace`
| Total number of PipelineRuns created.

| `tekton_pipelines_controller_running_pipelineruns`
| Gauge
| `namespace`
| Number of currently running PipelineRuns.

| `tekton_pipelines_controller_pipelineruns_waiting_on_pipeline_resolution_count`
| Gauge
| `namespace`
| Number of PipelineRuns waiting for remote pipeline resolution.

| `tekton_pipelines_controller_pipelineruns_waiting_on_task_resolution_count`
| Gauge
| `namespace`
| Number of PipelineRuns waiting for task resolution.

| `tekton_pipelines_controller_taskrun_duration_seconds`
| Histogram
| `status`, `task`, `pipeline`, `pipelinerun`, `namespace`, `reason`
| Duration of TaskRuns within a PipelineRun context.

| `standalone_taskrun_duration_seconds`
| Histogram
| `status`, `task`, `namespace`, `reason`
| Duration of standalone TaskRun executions in seconds.

| `tekton_pipelines_controller_taskruns_total`
| Counter
| `status`, `namespace`
| Total number of TaskRuns created.

| `tekton_pipelines_controller_running_taskruns`
| Gauge
| `namespace`
| Number of currently running TaskRuns.

| `tekton_pipelines_controller_taskruns_waiting_on_task_resolution_count`
| Gauge
| `namespace`
| Number of TaskRuns waiting for task resolution.

| `tekton_pipelines_controller_taskruns_throttled_by_resource_quota_count`
| Gauge
| `namespace`
| Number of TaskRuns throttled due to resource quota limits.

| `tekton_pipelines_controller_taskruns_throttled_by_node_constraints_count`
| Gauge
| `namespace`
| Number of TaskRuns throttled due to node constraints.

| `tekton_pipelines_controller_pod_latency_milliseconds`
| Histogram
| `namespace`, `pod`
| Pod creation and scheduling latency in milliseconds.
|===

.Pipeline controller infrastructure metrics
[cols="3,1,3",options="header"]
|===
| Metric name | Type | Description

| `kn_workqueue_adds_total`
| Counter
| Total number of reconciliations added to the workqueue.

| `kn_workqueue_depth`
| Gauge
| Current depth of the workqueue.

| `kn_workqueue_queue_duration_seconds`
| Histogram
| Time items spend in the workqueue before processing.

| `kn_workqueue_work_duration_seconds`
| Histogram
| Time taken to process items from the workqueue.

| `kn_workqueue_retries_total`
| Counter
| Total retries during workqueue reconciliation.

| `kn_workqueue_unfinished_work_seconds`
| Gauge
| Total duration of currently unfinished work in seconds.

| `http_client_request_duration_seconds`
| Histogram
| Duration of HTTP client requests made by the controller.

| `http_requests_total`
| Counter
| Total Kubernetes API client HTTP responses by status code.

| `process_*` / `go_*`
| Various
| Go runtime memory, garbage collection, and thread metrics.
|===

== Tekton Results metrics

.Tekton Results watcher metrics
[cols="3,1,3",options="header"]
|===
| Metric name | Type | Description

| `pipelinerun_deletions_total`
| Counter
| Total PipelineRun delete operations processed by the watcher.

| `taskrun_deletions_total`
| Counter
| Total TaskRun delete operations processed by the watcher.

| `pipelinerun_deletion_duration_seconds`
| Histogram
| Time taken to process PipelineRun deletions in seconds.

| `taskrun_deletion_duration_seconds`
| Histogram
| Time taken to process TaskRun deletions in seconds.

| `db_failed_runs_total`
| Counter
| Total runs that failed to store in the database.

| `db_latency_seconds`
| Histogram
| Latency for storing runs in database storage.
