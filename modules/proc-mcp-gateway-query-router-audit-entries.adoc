= Query router audit entries

[role="_abstract"]
You can filter router audit log entries by using the `grep` command on the router pod logs. For production environments, send router pod logs to a log aggregation system such as Loki, Elasticsearch, or Splunk.

.Prerequisites

* You set up log aggregation for {mcpg}.

.Procedure

. Tail live audit entries by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc logs -f -n _<mcp_system>_ -l app.kubernetes.io/name=mcp-gateway | \
  grep 'audit=true'
----
+
Replace `_<mcp_system>_` with the namespace where your {mcpg} instance is deployed.

. List audited tool calls with a non-`200` HTTP status in the last hour by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc logs -n _<mcp_system>_ --tail=-1 --since=1h -l app.kubernetes.io/name=mcp-gateway | \
  grep 'audit=true' | \
  grep -vE '(^|[[:space:]])status=200([[:space:]]|$)'
----
+
Replace `_<mcp_system>_` with the namespace where your {mcpg} instance is deployed.
+
This query filters HTTP response status only. It does not find all MCP or tool failures because an error can be returned with HTTP `200`. Correlate the request with the MCP response and application logs to determine the tool outcome.

. List entries with a specific reported user subject by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc logs -n _<mcp_system>_ --tail=-1 --since=1h -l app.kubernetes.io/name=mcp-gateway | \
  grep 'audit=true' | \
  grep -E '(^|[[:space:]])user=alice([[:space:]]|$)'
----
+
Replace `_<mcp_system>_` with the namespace where your {mcpg} instance is deployed.
+
The router decodes this subject without validating the JWT. Entries for requests rejected before authentication can contain unverified user values.

. List entries for a specific upstream tool name by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc logs -n _<mcp_system>_ --tail=-1 --since=1h -l app.kubernetes.io/name=mcp-gateway | \
  grep 'audit=true' | \
  grep -E '(^|[[:space:]])tool=echo([[:space:]]|$)'
----
+
Replace `_<mcp_system>_` with the namespace where your {mcpg} instance is deployed.
+
After successful rewriting, `tool` contains the unprefixed upstream name. When investigating an early failure, also search for the client-supplied tool name, including its prefix.
