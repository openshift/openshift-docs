= Query router audit entries

[role="_abstract"]
You can filter router audit log entries by using the `grep` command on the router pod logs. For production environments, send router pod logs to a log aggregation system such as Loki, Elasticsearch, or Splunk.

.Prerequisites

* You set up log aggregation for {mcpg}.

.Procedure

. Tail live audit entries by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc logs -f -n _<mcp_system>_ -l app.kubernetes.io/name=_<mcp_gateway>_ \
  \| grep 'audit=true'
----
+
* Replace `_<mcp_gateway>_` with the name of your {mcpg} instance.
* Replace `_<mcp_system>_` with the namespace where your {mcpg} instance is deployed.

. List all failed tool calls in the last hour by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc logs -n _<mcp_system>_ -l app.kubernetes.io/name=_<mcp_gateway>_ --since=1h \
  \| grep 'audit=true' \| grep -v 'status=200'
----
+
* Replace `_<mcp_gateway>_` with the name of your {mcpg} instance.
* Replace `_<mcp_system>_` with the namespace where your {mcpg} instance is deployed.

. List calls by a specific user by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc logs -n _<mcp_system>_ -l app.kubernetes.io/name=_<mcp_gateway>_ --since=1h \
  \| grep 'audit=true' \| grep 'user=alice'
----
+
* Replace `_<mcp_gateway>_` with the name of your {mcpg} instance.
* Replace `_<mcp_system>_` with the namespace where your {mcpg} instance is deployed.

. List calls to a specific tool by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc logs -n _<mcp_system>_ -l app.kubernetes.io/name=_<mcp_gateway>_ --since=1h \
  \| grep 'audit=true' \| grep 'tool=everything_echo'
----
+
* Replace `_<mcp_gateway>_` with the name of your {mcpg} instance.
* Replace `_<mcp_system>_` with the namespace where your {mcpg} instance is deployed.
