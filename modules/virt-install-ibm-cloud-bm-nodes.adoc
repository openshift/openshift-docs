= Installation of {VirtProductName} on {ibm-cloud-title} bare-metal nodes

[role="_abstract"]
Install {VirtProductName} on {ibm-cloud-title} bare-metal nodes by using the Assisted Installer. The cluster has six bare-metal nodes: three control plane nodes and three compute nodes. An additional virtual machine is required for bootstrapping and to act as a Samba server, DHCP server, network gateway, and load balancer.

== Prerequisites

* You have an account in {ibm-cloud-title} with permissions to order and operate bare-metal nodes.
* You have an {ibm-cloud-title} SSL VPN user for accessing the Supermicro Intelligent Platform Management Interface (IPMI) of a node.
* You have installed the {oc-first}.
