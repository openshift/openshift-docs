= Creating MachineConfig objects for nmconnection file setup

[role="_abstract"]
Before you specify your hardware MTU in an existing `NetworkManager` connection file, prepare your nodes for a hardware MTU change. To do this create `MachineConfig` objects for both control plane and compute nodes. 

Creating `MachineConfig` objects ensures that the updated network interface settings are ready for deployment without causing immediate cluster instability.

.Procedure

. Convert your custom script to a base-64-encoded string by entering the following command:
+
[source,terminal]
----
$ cat update-mtu.sh | base64 -w0
----

. Create two `MachineConfig` objects, one for the control plane nodes and another for the compute nodes in your cluster.
+
[IMPORTANT]
====
The `MachineConfig` objects provide examples for a specific deployment. The examples do not represent every deployment variation.
====
+
.. Create the `MachineConfig` object for control plane nodes:
+
[source,yaml, subs="attributes+"]
----
apiVersion: machineconfiguration.openshift.io/v1
kind: MachineConfig
metadata:
  name: 99-master-update-mtu
  labels:
    machineconfiguration.openshift.io/role: master
spec:
  config:
    ignition:
      version: 3.2.0
    storage:
      files:
        - path: /usr/local/bin/update-mtu.sh
          mode: 493
          overwrite: true
          contents:
            source: data:text/plain;base64,<encoded_content>
    systemd:
      units:
        - name: update-mtu.service
          enabled: true
          contents: |
            [Unit]
            Description=Set or update MTU in NM keyfiles before NetworkManager (nmcli --offline)
            Wants=network-pre.target
            Before=network-pre.target NetworkManager.service
            Requires=local-fs.target
            After=local-fs.target dbus.service
            DefaultDependencies=no
            [Service]
            Type=oneshot
            ExecStart=/usr/local/bin/change-mtu.sh
            RemainAfterExit=false
            StandardOutput=journal+console
            StandardError=journal+console
            [Install]
            WantedBy=network-pre.target
----
+
