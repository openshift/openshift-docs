= Install the Multiarch Tuning Operator by using the CLI

[role="_abstract"]
You can install the Multiarch Tuning Operator with `oc` commands and YAML manifests. Installing from the CLI lets you enable architecture-aware scheduling from a pipeline instead of from the console.
