= Clusters with restrictive network policies

[role="_abstract"]
If your cluster uses restrictive network policies, Knative system pods might not be able to access your Knative application.

If you are using a cluster that multiple users have access to, your cluster might use network policies to control which pods, services, and namespaces can communicate with each other over the network. For example, if your namespace has the following network policy, which denies all requests, Knative system pods cannot access your Knative application:

.Example NetworkPolicy object that denies all requests to the namespace
[source,yaml]
----
kind: NetworkPolicy
apiVersion: networking.k8s.io/v1
metadata:
  name: deny-by-default
  namespace: example-namespace
spec:
  podSelector:
  ingress: []
----
