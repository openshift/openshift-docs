= Starting an alternative image with Toolbx in {op-system} 10.x

[role="_abstract"]
ifndef::openshift-origin[]
The Toolbx commands create a container from the default Red Hat Universal Base Image (UBI) Toolbx image for the matching {op-system-base-full} version. You can create a container from an alternative image by running the `toolbox create` command with the path to the image you want to run.

[NOTE]
====
Running older {op-system-base}-based images is not supported on {product-title} {product-version}.
====
endif::openshift-origin[]

ifdef::openshift-origin[]
By default, running the `toolbox` command starts a container with the default Toolbx image for the currently installed {op-system-base-full} version. You can create a container from an alternative image by running the `toolbox create` command with the path to the image that you want to run.
endif::openshift-origin[]

.Prerequisites

* Your cluster is running {op-system-first} 10.x.
* You can access your system as a user with root privileges.

.Procedure

. Access a node by running the following command.
+
[source,terminal]
----
$ oc debug node/<node_name>
----
+
Replace `<node_name>` with the name of the node. 

. Access the host namespaces by using the following command:
+
[source,terminal]
----
sh-5.1# nsenter -a -t 1
----

. Specify the image to use as an alternative image by running the following command: 
+
[source,terminal]
----
-sh-5.2# toolbox create --image <image-url> <image_name>
----
+
Replace `<image-url>` with path to the alternative image you want to use. Optionally, specify a name for the resulting Toolbx container. If you do not specify a name, Toolbx assigns a name. 
+
.Example command
[source,terminal]
----
-sh-5.2# toolbox create --image quay.io/toolbx/ubuntu-toolbox:latest ubuntu-dev
----
+
[NOTE]
====
If an existing `toolbox` container is already running, Toolbx outputs an error. Remove the existing Toolbx container by running the `toolbox rm <name>` command, where `<name>` is the name of the container. Then spawn a new toolbox container.
====
+
.Example output
[source,terminal]
----
Created container: ubuntu-dev
Enter with: toolbox enter ubuntu-dev
----

. Enter the Toolbx container by entering the following command:
+
[source,terminal]
----
-sh-5.2# toolbox enter <container_name>
----
+
Replace `<container_name>` with the name of the container.
