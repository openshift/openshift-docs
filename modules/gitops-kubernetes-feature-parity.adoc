= Feature parity between OpenShift and non-OpenShift platforms

[role="_abstract"]
The following table compares how {gitops-title} features work on {OCP} versus non-OpenShift Kubernetes platforms.

[cols="1,2,2",options="header"]
|===
|Feature
|{OCP}
|Non-OpenShift Kubernetes

|External routing
|OpenShift Routes (automated)
|Kubernetes Ingress, LoadBalancer, or vendor-specific mechanisms

|Authentication with external providers
|OpenShift OAuth via Dex or direct OIDC
|Direct OIDC, or LDAP and GitHub via Dex

|Security policy
|Security Context Constraints (SCCs)
|Standard RBAC and Pod Security Standards

|{OCP} web console integration
|Console plugin for GitOps resources
|Not applicable

|Metrics and monitoring
|Prometheus Operator with ServiceMonitor
|Direct Prometheus scraping or vendor-specific observability

|Automatic TLS certificate management
|Service CA operator
|Not supported (use cert-manager or manual certificates)

|Default Argo CD instance
|Created automatically in `openshift-gitops` namespace
|Not created (you must create an Argo CD instance manually)

|===
