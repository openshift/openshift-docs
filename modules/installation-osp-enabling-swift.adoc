= Enabling Swift on {rh-openstack}

[role="_abstract"]
// TODO: OSDOCS-20003 storage/identity SME: confirm the role required by OCP registry credentials for native Swift and Ceph RGW. RHOSO's RGW authentication procedure still assigns swiftoperator, but its SRBAC overview says legacy roles are replaced by admin/member/reader.
Swift is operated by a user account with the `swiftoperator` role. Add the role to an account before you run the installation program.

[IMPORTANT]
====
If the {rh-openstack-first} Object Storage service (Swift) is available, {product-title} uses Swift as the image registry storage. If Swift is unavailable, the installation program relies on the {rh-openstack} Block Storage service (Cinder).

If Swift is present and you want to use it, you must enable access to Swift. If Swift is not present, or if you do not want to use Swift, skip this section.
====

.Prerequisites

* You have a {rh-openstack} administrator account on the target environment.
* The Swift service is installed.
* If your deployment uses Ceph Object Gateway (RGW) to provide the Swift API, your storage administrator has configured the following settings:
** `rgw_swift_account_in_url` is set to `true`.
** `rgw_max_attr_size` is set to at least `1024` to allow container image uploads to the {product-title} registry.

.Procedure

* As an administrator in the {rh-openstack} CLI, add the `swiftoperator` role to the account that will access Swift:
+
[source,terminal]
----
$ openstack role add --user <user> --project <project> swiftoperator
----
+
Your {rh-openstack} deployment can now use Swift for the image registry.
