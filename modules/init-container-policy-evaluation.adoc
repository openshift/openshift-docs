= Init container policy evaluation

// JIRA: ROX-33067

[role="_abstract"]
{product-title-short} now evaluates build and deploy stage security policies on init containers, so you can monitor and prevent insecure deployments that use init containers.

By default, existing and new policies evaluate all container types, including init containers. As a result, existing policies might report new violations for deployments that include init containers. You can configure a policy to skip evaluating init containers or main containers.

Runtime policies do not evaluate init containers.
