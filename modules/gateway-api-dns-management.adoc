= Gateway API DNS management requirements and namespace constraints

[role="_abstract"]
Automatic DNS record management by the Ingress Operator applies to Gateway API resources under specific namespace conditions. To enable automatic DNS record creation and lifecycle management for Gateway API resources, create the `Gateway` custom resource (CR) in the `openshift-ingress` namespace.

[IMPORTANT]
====
To enable automatic DNS record creation and lifecycle management for Gateway API resources, ensure you meet the following criteria:

* You must create the `Gateway` CR in the `openshift-ingress` namespace.
* The listener hostnames must match or fall under the cluster base domain. To inspect the base domain of your cluster, enter the following command:
+
[source,terminal]
----
$ oc get ingress.config.openshift.io cluster -o jsonpath='{.spec.domain}'
----
====

If you create the `Gateway` object in any other namespace, note the following limitations:

* The Ingress Operator does not provision or manage external DNS records for the Gateway.
* You must manually configure and manage external DNS records for all hostnames associated with that Gateway.

When you deploy a `Gateway` object in the `openshift-ingress` namespace to use automatic DNS management, you must configure listener route attachment rules to support multi-namespace deployments.

[NOTE]
====
Setting `spec.listeners[*].allowedRoutes.namespaces.from` to `Same` on a Gateway in `openshift-ingress` restricts route attachment to the `openshift-ingress` namespace. If you deploy `HTTPRoute` or `GRPCRoute` objects in user namespaces, you cannot attach routes to the Gateway.
====

The following example sets `allowedRoutes.namespaces.from` to `Selector` and defines `matchLabels` to restrict access to specific namespaces. For more information about supported and unsupported values for `listeners.allowedRoutes`, see "Gateway listener configuration reference".

[source,yaml]
----
apiVersion: gateway.networking.k8s.io/v1
kind: Gateway
metadata:
  name: managed-dns-gateway
  namespace: openshift-ingress
spec:
  gatewayClassName: openshift-gateway-manager
  listeners:
  - name: https
    hostname: "*.example.com"
    port: 443
    protocol: HTTPS
    allowedRoutes:
      namespaces:
        from: Selector
        selector:
          matchLabels:
            gateway-access: "true"
    tls:
      mode: Terminate
      certificateRefs:
      - kind: Secret
        name: wildcard-example-com-tls
----
+
where:

`metadata.namespace`:: Deploying in `openshift-ingress` enables automatic DNS record management by the Ingress Operator.
`spec.listeners.allowedRoutes.namespaces.from`:: Configured to `Selector` (or `All`) so `HTTPRoute` resources in designated application namespaces can attach. `Same` is not supported for cross-namespace application routes.
