= Connect a Google Cloud Vertex AI provider to Agentic {ols-long}

[role="_abstract"]
To use Google Cloud Vertex AI as the large language model (LLM) provider for Agentic {ols-long}, create a credentials secret from a Google Cloud service account JSON key, an `LLMProvider` custom resource (CR) with the `GoogleCloudVertex` type, and an `Agent` CR that uses that provider. The `GoogleCloudVertex` type supports Anthropic, Google, and OpenAI model families on Vertex AI.

.Prerequisites

* You have installed the {ols-long} Operator.
* You have logged in to the cluster as a user with the `cluster-admin` role, or with permission to create cluster-scoped custom resources.
* You have a Google Cloud service account JSON key file.
* The Vertex AI API is enabled in your Google Cloud project, and the service account has the required Vertex AI permissions.

.Procedure

. Create a credentials secret in the `openshift-lightspeed` namespace from your service account JSON key by running the following command:
+
[source,terminal]
----
$ oc create secret generic llm-credentials \
  --from-file=GOOGLE_APPLICATION_CREDENTIALS=<path_to_service_account_key>.json \
  -n openshift-lightspeed
----

. Create an `LLMProvider` CR that uses the `GoogleCloudVertex` type:
+
[source,yaml]
----
apiVersion: agentic.openshift.io/v1alpha1
kind: LLMProvider
metadata:
  name: vertex-ai
spec:
  type: GoogleCloudVertex
  googleCloudVertex:
    credentialsSecret:
      name: llm-credentials # <1>
    projectID: <gcp_project_id> # <2>
    region: <gcp_region> # <3>
    modelProvider: Anthropic # <4>
----
<1> The name of the credentials secret that contains the `GOOGLE_APPLICATION_CREDENTIALS` key in the `openshift-lightspeed` namespace.
<2> The Google Cloud project ID where Vertex AI is enabled.
<3> The Google Cloud region for the Vertex AI endpoint, for example, `us-central1`.
<4> The model family to use on Vertex AI. Allowed values are `Anthropic`, `Google`, and `OpenAI`. For agentic and tool-calling workloads, use `Anthropic`.

. Create an `Agent` CR that references the `LLMProvider` and specifies the model to use:
+
[source,yaml]
----
apiVersion: agentic.openshift.io/v1alpha1
kind: Agent
metadata:
  name: default # <1>
spec:
  llmProvider:
    name: vertex-ai # <2>
  model: <model_id> # <3>
  maxTurns: 200
----
<1> The `default` agent must exist. The deployment uses it when a workflow step does not specify an agent.
<2> The name of the `LLMProvider` CR that you created.
<3> The identifier of the model to use. The identifier must match the model family set in `spec.googleCloudVertex.modelProvider`.

. Apply the custom resources by running the following command:
+
[source,terminal]
----
$ oc apply -f <cr_filename>.yaml
----

.Verification

* Confirm that the resources exist by running the following commands:
+
[source,terminal]
----
$ oc get llmprovider vertex-ai
----
+
[source,terminal]
----
$ oc get agent default
----
