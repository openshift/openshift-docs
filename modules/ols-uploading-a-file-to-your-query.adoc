= Upload a local file as context

[role="_abstract"]
Upload a YAML file from your computer to attach it to your question as context.

.Procedure

. Click the {ols-official} icon in the lower-right corner of the screen.

. Click the attachment menu button (*+*) next to the message field, and then select *Upload from computer*.

. Select a YAML file from your computer.
+
[NOTE]
====
The file must be valid YAML and no larger than 1 MB. If the file is not valid YAML or exceeds the maximum size, an error is displayed and the file is not attached.
====

. Enter a question.

. Click *Submit*.
+
{ols-long} returns information based on your question and the attached file.
