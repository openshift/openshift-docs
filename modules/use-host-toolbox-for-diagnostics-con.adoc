= Use the host toolbox for diagnostics

[role="_abstract"]
When you need diagnostic tools that are not available on a {product-title} node by default, you use the toolbox container to run commands directly on the host or install additional packages. You can also start an alternative diagnostic image and use the toolbox to gather diagnostic information for Red{nbsp}Hat support.
