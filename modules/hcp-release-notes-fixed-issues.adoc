= Fixed issues

[role="_abstract"]
This section lists the fixed issues in the {product-title} HCP release.

* Before this update, the wrong restoration of `kubeadmin` password hashes caused new passwords not to work in a restored cluster. As a consequence, the restored cluster used the old `kubeadmin` password instead of the new one, resulting in login failure. With this release, the `kubeadmin` password hash mismatch in restored clusters has been addressed, and reconciliation logic has been updated. As a result, new `kubeadmin` passwords in restored clusters now match, allowing successful login. (link:https://redhat.atlassian.net/browse/OCPBUGS-38898[OCPBUGS-38898])
