= Start a mirror operation

[role="_abstract"]
Start a mirror operation in the OpenShift Mirror Console to run a mirror from a saved configuration. You can select an `ImageSetConfiguration` file and a destination folder, optionally configure advanced options, then start the operation.

.Prerequisites

* You are logged in to the OpenShift Mirror Console.
* You have configured a pull secret.
* You have a saved `ImageSetConfiguration` file available in the OpenShift Mirror Console.

.Procedure

. Navigate to the Mirror Operations page to start a mirror from a saved configuration..

. In the *ImageSetConfiguration File* drop-down list, select the `ImageSetConfiguration` file to use for the operation.

. In the *Mirror Destination Folder* list, select the local destination folder for the mirrored content.

. Optional: Click *Advanced Options*, and configure any of the following settings as needed:

* *Remove signatures*: Turn on this option if you do not want image signatures copied to the mirror destination.

* *Image timeout*: Turn on this option, then set the maximum time to wait when pulling each image. The default timeout is 10 minutes.

* *Retry delay*: Turn on this option, then set the fixed wait time in seconds before each retry after a failure. Set the value to `0` to use the default oc-mirror behavior, which starts with a short wait and roughly doubles after each failed attempt.

* *Retry times*: Turn on this option, then set how many times the oc-mirror retries a failed image pull. The default is 5 retries.

. Click *Start Operation* to begin the mirror operation.

.Verification

* On the *Operation History* page, confirm that the new operation displays with a `Running` or `Success` status.
