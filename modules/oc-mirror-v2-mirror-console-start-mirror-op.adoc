= Start a mirror operation

[role="_abstract"]
To run a mirror from a saved configuration, start a mirror operation in the OpenShift Mirror Console. Mirror operations copy the images defined in the `ImageSetConfiguration` file to a destination folder for use in disconnected environments.

.Prerequisites

* You have opened the OpenShift Mirror Console in a browser.
* You have configured a pull secret.
* You have saved an `ImageSetConfiguration` file by clicking *Save Configuration*.

.Procedure

. Go to the Mirror Operations page to start a mirror from a saved configuration.

. In the *ImageSetConfiguration File* drop-down list, select the `ImageSetConfiguration` file to use for the operation.

. In the *Mirror Destination Folder* list, select the folder for the mirrored content.
+
The default folder is named `default`. The console writes the output to `/app/data/mirrors/<folder_name>` inside the container.

. Optional: To create a destination folder, complete the following steps:

.. In the *Mirror Destination Folder* list, click *Create new folder*.

.. In the *Enter folder name* field, enter a name containing only letters, numbers, underscores, or hyphens.

.. Press *Enter* to confirm.
+
To cancel folder creation, press *Escape*.

. Optional: To change the advanced settings, complete the following steps:

.. Click *Advanced Options*.

.. Optional: Set the *Remove signatures* switch to on to exclude image signatures from the mirror destination.

.. Optional: To change the image timeout, complete the following steps:

... Set the *Image timeout* switch to on.

... Enter the minutes component of the maximum wait time in the minutes field.
+
The initial value is 10 minutes.

... Enter the seconds component of the maximum wait time in the seconds field.
+
The initial value is 0 seconds. The combined value specifies the maximum time to wait when pulling each image.

.. Optional: To change the retry delay, complete the following steps:

... Set the *Retry delay* switch to on.

... Enter the wait time in seconds before each retry after a failure.
+
A positive value sets a fixed delay. A value of `0` uses the default oc-mirror delay, which roughly doubles after each failed attempt.
For example, the delays can be 1, 2, then 4 seconds.

.. Optional: To change the retry count, complete the following steps:

... Set the *Retry times* switch to on.

... Enter the maximum number of retries after a failed image pull.
+
The default is 5 retries.

. Click *Start Operation*.

.Verification

. On the Mirror Operations page, confirm that the running operation appears.

. On the History page, confirm that the completed operation has a *Success* status.
