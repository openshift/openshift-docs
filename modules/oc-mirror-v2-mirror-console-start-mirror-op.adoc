= Start a mirror operation

[role="_abstract"]
To run a mirror from a saved configuration, start a mirror operation in the OpenShift Mirror Console. Mirror operations copy the images defined in the `ImageSetConfiguration` file to a destination folder for use in disconnected environments.

.Prerequisites

* The OpenShift Mirror Console is open in a browser.
* You have configured a pull secret.
* You have saved an `ImageSetConfiguration` file by clicking *Save Configuration*.

.Procedure

. Go to the Mirror Operations page to start a mirror from a saved configuration.

. In the *ImageSetConfiguration File* drop-down list, select the `ImageSetConfiguration` file to use for the operation.

. In the *Mirror Destination Folder* list, select the folder for the mirrored content. The default folder is named `default`. To use a different folder, click *Create new folder*.
+
The console writes the output to `data/mirrors/<folder_name>` in the console data volume.

. Optional: Click *Advanced Options*, and then configure any of the following settings:
+
* *Remove signatures*: Set the switch to on if you do not want image signatures copied to the mirror destination.
* *Image timeout*: Set the switch to on, and then enter the maximum time to wait when pulling each image. The default timeout is 10 minutes.
* *Retry delay*: Set the switch to on, and then enter the fixed wait time in seconds before each retry after a failure. Set the value to `0` to use the default oc-mirror behavior.
* *Retry times*: Set the switch to on, and then enter how many times oc-mirror retries a failed image pull. The default is 5 retries.

. Click *Start Operation*.

.Verification

* On the History page, confirm that the new operation displays with a *Success* status.
