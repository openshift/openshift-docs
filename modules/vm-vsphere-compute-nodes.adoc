= Virtual machine compute nodes without {vmw-short} integration

[role="_abstract"]
You can provision virtual machines (VMs) on {VirtProductName} and add them as compute nodes to an existing {product-title} cluster on {vmw-short}. These nodes join the cluster without {vmw-short} integration.

The target cluster is the existing {product-title} cluster on {vmw-short} that the new compute nodes join. The hosting cluster runs {VirtProductName} and manages the VM resources.

Each VM requires the following configuration:

* A {op-system-first} image that matches the target cluster version.
* The worker Ignition configuration from the target cluster.
* Network connectivity to the target cluster's machine network, with persistent IP addresses, hostname reservations, and forward and reverse DNS resolution.

The requirement to disable the native {vmw-short} Container Storage Interface (CSI) driver applies to workload storage in the target cluster. Configure storage for the VM disks on the hosting cluster as part of VM provisioning.

Create and configure the VMs on the hosting cluster. After you start the VMs, approve their certificate signing requests (CSRs) and remove the cloud provider uninitialized taint in the target cluster.
