= Applying VM annotations

[role="_abstract"]
Apply annotations to a virtual machine in a cluster to attach descriptive information. 

.Prerequisites

* You have access to the {product-title} web console.
* You have `edit` or `admin` permissions in the target project.

.Procedure

. Click *Virtualization* -> *VirtualMachines* on the side menu to access the cluster settings. 

. Select a virtual machine using the *Local cluster* tree view or *Virtual machines* tab.

. Click the *Configuration* tab.

. Click *Labels and annotations*.

. Click *Add annotations*.

. Optional: Edit existing annotations using the *Key* and *Value* fields.

. Optional: Add a new annotation.

.. Click *Add more*.
.. Use the *Key* and *Value* fields to add the new label values.
.. Click *Save*.

. Optional: Delete an annotation using the minus icon to the right of the *Value* field.
