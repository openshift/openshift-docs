= Mirror configuration in the OpenShift Mirror Console

[role="_abstract"]
A mirror configuration specifies the platform channels, Operator catalogs, and additional images to include before a mirror operation. Defining that content first keeps the mirrored image set limited to what the disconnected environment requires.

The OpenShift Mirror Console generates an `ImageSetConfiguration` YAML file from the Mirror Configuration page. Preview the file, then save or download it before starting a mirror operation.
