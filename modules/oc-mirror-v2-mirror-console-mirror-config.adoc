= Mirror configuration in the OpenShift Mirror Console

[role="_abstract"]
Mirror configuration in the OpenShift Mirror Console defines what to mirror before a mirror operation.

On the Mirror Configuration page, you configure platform channels, optionally add Operator catalogs and additional images, then preview the generated YAML and save or download the file.
