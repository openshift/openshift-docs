= Mirror configuration in the OpenShift Mirror Console

[role="_abstract"]
A mirror configuration lists the platform channels, Operator catalogs, and additional images to mirror. Defining the content first keeps the image set limited to what you need.

The console generates an `ImageSetConfiguration` file from the Mirror Configuration page. Before you start a mirror operation, you can preview the file and then save or download it.
