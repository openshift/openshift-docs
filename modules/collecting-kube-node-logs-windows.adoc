= Collect Kubernetes node logs for Windows containers

[role="_abstract"]
Windows container logging works differently from Linux container logging; the Kubernetes node logs for Windows workloads are streamed to the `C:\var\log` directory by default. Therefore, you must gather the Windows node logs from that directory.

The `windows-exporter` process runs without a `kube-log-runner` wrapper and writes its log file directly to `C:\var\log\windows_exporter\windows_exporter.log`.

.Prerequisites

* You installed the Windows Machine Config Operator (WMCO) using Operator Lifecycle Manager (OLM).
* You have created a Windows compute machine set.

.Procedure

* View a list of the Windows node logs under all directories within the `C:\var\log` directory by running the following command:
+
[source,terminal]
----
$ oc adm node-logs -l kubernetes.io/os=windows --path=/
----
+
.Example output
[source,terminal]
----
compute-1.example.com containers/
compute-1.example.com hybrid-overlay/
compute-1.example.com kube-proxy/
compute-1.example.com kubelet/
compute-1.example.com pods/
compute-1.example.com wicd/
compute-1.example.com windows_exporter/
----
+
You can now list files in the directories by using the same command and view the individual log files. 
+
For example, to view the kubelet logs, run the following command:
+
[source,terminal]
----
$ oc adm node-logs -l kubernetes.io/os=windows --path=/kubelet/kubelet.log
----
