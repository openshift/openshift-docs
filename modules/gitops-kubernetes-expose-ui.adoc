= Expose the Argo CD UI

[role="_abstract"]
After creating an Argo CD instance, configure external access to the Argo CD server so that you can access the web UI. You can configure access by using a Kubernetes Ingress resource or a LoadBalancer service.

.Prerequisites

* You have created an Argo CD instance. For more information, see "Create an Argo CD instance".
* For Ingress access, you have an Ingress controller installed and configured on your cluster.

.Procedure

Choose one of the following methods to expose the Argo CD UI:

* *Option A: Using Ingress*
+
Configure an Ingress resource in the Argo CD custom resource (CR):
+
[source,yaml]
----
apiVersion: argoproj.io/v1beta1
kind: ArgoCD
metadata:
  name: openshift-gitops
  namespace: openshift-gitops
spec:
  server:
    host: argocd.example.com
    insecure: false
    ingress:
      enabled: true
      ingressClassName: nginx
      path: /
      annotations:
        nginx.ingress.kubernetes.io/ssl-redirect: "true"
----
+
where:
+
`host`:: Replace `argocd.example.com` with your DNS hostname.
`insecure`:: Set to `false` to enable HTTPS. Set to `true` for HTTP only.
`ingressClassName`:: Replace `nginx` with your Ingress controller class name, for example, `alb` for AWS Application Load Balancer or `gce` for Google Cloud Load Balancer.
`path`:: Specifies the path for the Ingress resource. Use `/` for most Ingress controllers, or `/*` for AWS Application Load Balancer.
`annotations`:: Add Ingress controller-specific annotations as needed.
+
Apply the updated Argo CD CR:
+
[source,terminal]
----
$ kubectl apply -f argocd.yaml
----

* *Option B: Using LoadBalancer service*
+
Patch the Argo CD server service to use the LoadBalancer type:
+
[source,terminal]
----
$ kubectl patch svc openshift-gitops-server -n openshift-gitops \
  -p '{"spec": {"type": "LoadBalancer"}}'
----
+
Get the external IP address or hostname:
+
[source,terminal]
----
$ kubectl get svc openshift-gitops-server -n openshift-gitops
----
+
Example output:
+
----
NAME                       TYPE           CLUSTER-IP      EXTERNAL-IP                                 PORT(S)
openshift-gitops-server    LoadBalancer   10.100.200.50   a1b2c3d4e5.us-west-2.elb.amazonaws.com      80:30080/TCP,443:30443/TCP
----

.Verification

. Retrieve the Argo CD administrator password:
+
[source,terminal]
----
$ kubectl get secret openshift-gitops-cluster -n openshift-gitops \
  -o jsonpath='{.data.admin\.password}' | base64 -d
----

. Open the Argo CD web UI by navigating to the configured hostname or external IP address:
+
* For Ingress: Navigate to the hostname you configured in the Argo CD CR, for example, `https://argocd.example.com`.
* For LoadBalancer: Navigate to the external IP address or hostname from the LoadBalancer service.

. Log in by using `admin` as the username and the retrieved administrator password.
