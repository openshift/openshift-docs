= Next steps

[role="_abstract"]
After deploying your first application, explore additional {gitops-title} capabilities to build production-ready GitOps workflows.

*Configure GitOps infrastructure*

* *Deploy additional Argo CD instances* - Create namespace-scoped instances for team isolation or environment separation.
* *Scale Argo CD with cluster sharding* - Distribute application workload across multiple shards for better performance.
* *Configure resource limits* - Adjust CPU and memory allocations based on your workload.

See xref:../configure/deploy-and-manage-argo-cd-instances.adoc#deploy-and-manage-argo-cd-instances[Deploy and manage Argo CD instances].

*Secure access and permissions*

* *Configure SSO authentication* - Integrate with LDAP, SAML, OIDC, or {OCP} OAuth for centralized authentication.
* *Set up RBAC policies* - Control which users can deploy to which clusters and namespaces.
* *Create AppProjects* - Group applications and enforce security boundaries.

See xref:../secure/configure-sso-and-external-authentication.adoc#configure-sso-and-external-authentication[Configure SSO and external authentication] and xref:../secure/manage-local-users-and-permissions.adoc#manage-local-users-and-permissions[Manage local users and permissions].

*Manage applications at scale*

* *Use ApplicationSets* - Generate multiple applications from templates for multi-cluster or multi-tenant deployments.
* *Deploy to multiple clusters* - Configure cluster credentials and deploy applications across environments.
* *Implement progressive rollouts* - Use Argo Rollouts for canary and blue-green deployments.

See xref:../deploy/manage-applicationsets.adoc#manage-applicationsets[Manage ApplicationSets] and xref:../extend/understand-and-set-up-argo-rollouts.adoc#understand-and-set-up-argo-rollouts[Set up Argo Rollouts].

*Integrate with CI/CD pipelines*

* *Automate image updates* - Configure Argo CD Image Updater to automatically update container image tags in Git.
* *Trigger deployments from pipelines* - Integrate {gitops-title} with OpenShift Pipelines or external CI tools.
* *Implement GitOps workflows* - Set up pull request workflows for application promotions between environments.

See xref:../configure/keep-container-images-up-to-date-automatically.adoc#keep-container-images-up-to-date-automatically[Keep container images up to date automatically].

*Monitor and troubleshoot*

* *Access monitoring dashboards* - View Argo CD metrics in the {OCP} web console or Prometheus.
* *Configure notifications* - Set up alerts for sync failures, health issues, or deployment events.
* *Troubleshoot common issues* - Learn how to diagnose and resolve sync failures, authentication problems, and resource issues.

See xref:../observe/monitor-argo-cd-health-and-performance.adoc#monitor-argo-cd-health-and-performance[Monitor Argo CD health and performance] and xref:../troubleshoot/diagnose-and-resolve-gitops-issues.adoc#diagnose-and-resolve-gitops-issues[Diagnose and resolve GitOps issues].
