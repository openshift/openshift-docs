= Back up and restore applications on ROSA with STS

[role="_abstract"]
You can install and configure the OpenShift API for Data Protection (OADP) on Red Hat OpenShift Service on AWS (ROSA) clusters that use AWS Security Token Service (STS) authentication to back up and restore application data.
