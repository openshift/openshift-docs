= Use advanced VM provisioning methods

[role="_abstract"]
Create VMs from existing disk images, cloned storage, or platform-specific configurations when you need more control over the source media and target environment. These methods help you migrate existing workloads to {VirtProductName} or deploy VMs on specialized hardware.

{VirtProductName} supports the following advanced provisioning methods:

Cloning:: Duplicate an existing VM from the CLI by copying its persistent volume claims (PVCs). For web console cloning, see "Create a VM from the web console".

Disk image imports:: Import VM images from HTTP servers, container registries, or S3-compatible object storage by using the `DataVolume` API.

Platform-specific provisioning:: Create VMs with requirements specific to AWS (license-included Windows images) or {ibm-z-title} ({ibm-title} Secure Execution, confidential computing).
