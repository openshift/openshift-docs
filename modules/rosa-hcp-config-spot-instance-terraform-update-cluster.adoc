= Using Terraform to update an existing {product-title} cluster with Spot machine pools (Day-2)

[role="_abstract"]
You can add Spot machine pools to an existing {product-title} cluster managed by Terraform.

.Procedure

. Add a new `rhcs_hcp_machine_pool` resource to your existing Terraform configuration:
+
[source,text]
----
resource "rhcs_hcp_machine_pool" "spot_pool_new" {
  cluster       = rhcs_cluster_rosa_hcp.cluster.id
  name          = "spot-workers"
  replicas      = 3
  instance_type = "m5.xlarge"

  spot_market_options {
    max_price = "0.50"
  }
}
----

. Apply the configuration:
+
[source,terminal]
----
$ terraform plan && terraform apply -auto-approve
----

[WARNING]
====
If the cluster does not have the `termination_handler_queue_url` attribute configured, the Spot machine pool operates in simple mode. This means nodes will not be gracefully drained upon interruption.
====
