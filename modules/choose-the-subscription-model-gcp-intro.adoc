= Choose the subscription model

[role="_abstract"]
You can install {product-title} on {GCP} using a cloud account that you own or using a cloud account that is owned by Red Hat. Select the appropriate subscription model for your {product-title} deployment on {GCP} to align with your organization's billing, operational, and compliance requirements.
