= Upload and use an {ibm-title} Secure Execution bootable image on {ibm-z-title} and {ibm-linuxone-title}

[role="_abstract"]
You can upload an {ibm-name} Secure Execution bootable image and associate it with a predefined preference so that virtual machines (VMs) created from the image automatically enable the `launchSecurity` setting.

The following predefined preferences are available:

* `fedora.s390x.secex`
* `rhel.<stream>.secex`, where `<stream>` is a supported {op-system-base} version 9 or later

.Prerequisites

* You have created an {ibm-name} Secure Execution disk image.

.Procedure

. In the {product-title} web console, click *Virtualization* -> *Bootable volumes*.

. Click *Add volume* -> *With form*.

. In the *Add volume* window, complete the following steps:

.. From the *Source type* list, select *Upload new Volume*.

.. Select your {ibm-name} Secure Execution disk image to upload.

.. In the *Volume name* field, enter a name for the new boot source image.

.. From the *Preference* list, select the `.secex` preference that matches the operating system of your image.

.. From the *Default Instance Type* list, select the instance type with the correct CPU and memory requirements for your image.

.. For heterogeneous clusters only: From the *Architecture* list, select the architecture that corresponds with the selected volume.

.. Click *Save*.

[NOTE]
====
When you create a new VM from the uploaded bootable image, {product-title} automatically enables `launchSecurity`.
