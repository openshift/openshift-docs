= About disconnected support and the oc-mirror plugin in {olmv1}

[role="_abstract"]
After you use the oc-mirror plugin for the {oc-first} to mirror images to a mirror registry, {olmv1} relies on specific resource sets to function.

oc-mirror plugin v2 automatically generates `ImageDigestMirrorSet`, `ImageTagMirrorSet`, and `ClusterCatalog` resources.

[NOTE]
====
The oc-mirror plugin v2 is the recommended version for mirroring.
====
