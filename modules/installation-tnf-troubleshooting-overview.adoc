= About troubleshooting and recovering two-node clusters with fencing

[role="_abstract"]
Two-node {product-title} clusters with fencing (TNF) include automated recovery mechanisms to handle disruption events. However, you might need to perform manual recovery when automated recovery is unavailable or when specific failure scenarios occur.

Common troubleshooting and recovery scenarios include:

* Manually recovering from disruption events when automated recovery fails
* Replacing failed control plane nodes while maintaining cluster quorum
* Verifying etcd health after recovery procedures

Understanding these procedures ensures you can restore cluster functionality when automated systems cannot resolve the issue.
