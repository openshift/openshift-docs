= Configure advanced hardware management

[role="_abstract"]
You can configure advanced hardware management to control how the O-Cloud Manager selects hosts and applies hardware profiles. You define resource selectors in the `ClusterTemplate` CR and override defaults per site in the `ProvisioningRequest` CR.

You can perform these operations by editing the `ProvisioningRequest` CR directly or through the Provisioning REST API. For more information about advanced provisioning with the Provisioning API, see "Provision with hardware overrides using the Provisioning API".

The O-Cloud Manager is a Technology Preview feature only.
