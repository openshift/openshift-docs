= View and manage ApplicationSets in the GitOps Console

You can view, create, and manage Argo CD ApplicationSets through the {gitops-shortname} Console Plugin.

.Prerequisites

* You have access to the {OCP} web console.
* You have enabled the {gitops-shortname} Console plugin.
* Your permissions allow you to list ApplicationSets in one or more namespaces.

.Procedure

. Navigate to *GitOps* -> *ApplicationSets* in the *Administrator* perspective.

. Optional: Select a specific project from the *Project* dropdown to view ApplicationSets in that namespace, or select all projects to view ApplicationSets across all namespaces.

. Optional: Filter ApplicationSets by health status:
+
* *Health Status*: Healthy, Error, Unknown

. To create a new ApplicationSet:
+
.. Click *Create ApplicationSet*.
.. Edit the YAML template with your generator configuration and Application template.
.. Click *Create*.

. To view ApplicationSet details, click an ApplicationSet name in the list.
+
The details page provides the following tabs:
+
* *Details*: View identity, status, and conditions
* *YAML*: Edit the ApplicationSet manifest
* *Generators*: View generator configuration in structured format
* *Applications*: View generated Applications in list or graph view
* *Events*: View Kubernetes events

. To view generated Applications:
+
.. Click the *Applications* tab.
.. Switch between *List view* and *Graph view* as needed.
+
The graph view shows:
+
* Standard owner-reference tree layout
* Progressive Sync Flow View when progressive sync is enabled
