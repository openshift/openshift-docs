= View the firewall rules associated with your cluster

[role="_abstract"]
After you create a cluster that uses bring your own (BYO) firewall rules, you can confirm which firewall rule set the cluster uses by viewing the cluster details in {cluster-manager}.

.Prerequisites

* You created an {product-title} cluster on {gcp-short} and selected a firewall rule set during cluster creation.
* You have access to the {cluster-manager} web console.

.Procedure

. Log in to {cluster-manager-url}.
. From the *Clusters* list, select your cluster.
. Click the *Networking* tab.
. In the *VPC Details* card, locate the *Firewall Rules* row:
+
* For a Shared VPC cluster, the *Firewall Rules* row appears in the *Shared VPC* section, alongside *Host project ID* and *DNS Zone*.
* For a non-Shared VPC cluster, the *Firewall Rules* row appears in the *VPC Details* section, alongside the VPC name.

.Verification

* The *Firewall Rules* row displays the name of the firewall rule set that you selected during cluster creation.

[NOTE]
====
If the *Firewall Rules* row is not displayed, the cluster does not use BYO firewall rules. In this case, {product-title} creates and manages the firewall rules for the cluster.
====
