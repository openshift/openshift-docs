= Deploying a containerized eBPF program

[role="_abstract"]
To run custom networking or security logic on your cluster nodes, you can deploy containerized eBPF programs. You can use containerized eBPF programs to monitor kernel events and manage network traffic efficiently at the node level.

As a cluster administrator, you can deploy an eBPF program to nodes on your cluster. In this procedure, a sample containerized eBPF program is installed in the `go-xdp-counter` namespace.

.Prerequisites

* You have installed the OpenShift CLI (`oc`).
* You have an account with administrator privileges.
* You have installed the eBPF Manager Operator.
* You have installed the Security Profiles Operator. For more information, see xref:../../../security/security_profiles_operator/spo-enabling.adoc#spo-enabling[Enabling the Security Profiles Operator].

.Procedure

. Create a YAML file that defines the sample eBPF application:
+
[source,terminal]
----
$ cat << EOF > go-xdp-counter-install-selinux.yaml
apiVersion: v1
kind: Namespace
metadata:
  labels:
    pod-security.kubernetes.io/enforce: privileged
    pod-security.kubernetes.io/warn: privileged
  name: go-xdp-counter
---
apiVersion: v1
kind: ServiceAccount
metadata:
  name: bpfman-app-go-xdp-counter
  namespace: go-xdp-counter
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: xdp-binding
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: bpfman-user
subjects:
- kind: ServiceAccount
  name: bpfman-app-go-xdp-counter
  namespace: go-xdp-counter
---
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: go-xdp-counter-ds
  namespace: go-xdp-counter
  labels:
    k8s-app: go-xdp-counter
spec:
  selector:
    matchLabels:
      name: go-xdp-counter
  template:
    metadata:
      labels:
        name: go-xdp-counter
    spec:
      serviceAccountName: bpfman-app-go-xdp-counter
      nodeSelector: {}
      dnsPolicy: ClusterFirstWithHostNet
      securityContext:
        runAsNonRoot: true
        fsGroup: 65534
      tolerations:
      - key: node-role.kubernetes.io/control-plane
        operator: Exists
        effect: NoSchedule
      - key: node-role.kubernetes.io/master
        operator: Exists
        effect: NoSchedule
      containers:
      - name: go-xdp-counter
        image: quay.io/bpfman-userspace/go-xdp-counter:latest
        imagePullPolicy: IfNotPresent
        securityContext:
          allowPrivilegeEscalation: false
          capabilities:
            drop:
            - ALL
          runAsUser: 65534
          runAsGroup: 65534
          seLinuxOptions:
            type: bpfman-secure.process
        env:
        - name: NODENAME
          valueFrom:
            fieldRef:
              fieldPath: spec.nodeName
        volumeMounts:
        - name: go-xdp-counter-maps
          mountPath: /run/xdp/maps
          readOnly: true
      volumes:
      - name: go-xdp-counter-maps
        csi:
          driver: csi.bpfman.io
          volumeAttributes:
            csi.bpfman.io/program: go-xdp-counter-example
            csi.bpfman.io/maps: xdp_stats_map
---
apiVersion: bpfman.io/v1alpha1
kind: ClusterBpfApplication
metadata:
  name: go-xdp-counter-example
spec:
  nodeSelector: {}
  byteCode:
    image:
      url: quay.io/bpfman-bytecode/go-xdp-counter:latest
  programs:
  - name: xdp_stats
    type: XDP
    xdp:
      links:
      - interfaceSelector:
          primaryNodeInterface: true
        priority: 55
---
apiVersion: security-profiles-operator.x-k8s.io/v1alpha2
kind: SelinuxProfile
metadata:
  name: bpfman-secure
  namespace: go-xdp-counter
spec:
  allow:
    '@self':
      bpf:
      - map_read
      - map_write
    spc_t:
      bpf:
      - map_read
      - map_write
  inherit:
  - kind: System
    name: container
EOF
----

. To deploy the sample eBPF application, enter the following command:
+
[source,terminal]
----
$ oc create -f go-xdp-counter-install-selinux.yaml
----
+
.Example output
[source,text]
----
namespace/go-xdp-counter created
serviceaccount/bpfman-app-go-xdp-counter created
clusterrolebinding.rbac.authorization.k8s.io/xdp-binding created
daemonset.apps/go-xdp-counter-ds created
clusterbpfapplication.bpfman.io/go-xdp-counter-example created
selinuxprofile.security-profiles-operator.x-k8s.io/bpfman-secure created
----

. Confirm that the SELinux profile is installed:
+
[source,terminal]
----
$ oc get selinuxprofile bpfman-secure -n go-xdp-counter
----
+
.Example output
[source,text]
----
NAME            USAGE                   STATE
bpfman-secure   bpfman-secure.process   Installed
----
+
The `USAGE` value is the SELinux type that the daemon set sets in `seLinuxOptions.type`. Until the profile reports `Installed`, the daemon set pods can report `CreateContainerError`.

. To confirm that the example XDP program is running, enter the following command:
+
[source,terminal]
----
$ oc get clusterbpfapplication go-xdp-counter-example
----
+
.Example output
[source,text]
----
NAME                     NODESELECTOR   STATUS    AGE
go-xdp-counter-example                  Success   44s
----

. To confirm that the XDP program is collecting data, enter the following command:
+
[source,terminal]
----
$ oc logs <pod_name> -n go-xdp-counter
----
+
Replace `<pod_name>` with the name of an XDP program pod, such as `go-xdp-counter-ds-4m9cw`.
+
.Example output
[source,text]
----
2024/08/13 15:20:06 15016 packets received
2024/08/13 15:20:06 93581579 bytes received
...
----
