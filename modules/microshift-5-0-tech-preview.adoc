[id="microshift-5-0-trust-manager-tp_{context}"]
== Support for the trust-manager operand

With this release, you can use the trust-manager operand with cert-manager on {microshift-short} as a Technology Preview feature. The operand distributes certificate authority (CA) certificates across the node so that edge applications can verify TLS connections to local host hardware endpoints. You can consolidate certificates from multiple sources into a synchronized trust bundle and automatically update target objects when source certificates change. For more information, see the following link:

* xref:../microshift_running_apps/microshift-cert-manager-trust-manager.adoc#microshift-cert-manager-trust-manager[Distributing certificates by using the trust-manager operand]
