= Assign SR-IOV networks to a VRF

[role="_abstract"]
You can assign SR-IOV network interfaces to a Virtual Routing and Forwarding (VRF) domain to isolate network traffic for your workloads.
Use this job when your workloads run on SR-IOV virtual functions and each workload needs its own routing domain.

.Prerequisites

* The SR-IOV Network Operator is installed.
* The SR-IOV network devices are configured.

To assign secondary networks that are not SR-IOV to a VRF, see the "Assign secondary networks to a VRF and chain CNI plugins" job.
