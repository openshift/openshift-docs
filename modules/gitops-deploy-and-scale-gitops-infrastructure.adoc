= GitOps infrastructure management with Argo CD

[role="_abstract"]
{gitops-title} provides tools for deploying, configuring, and scaling Argo CD instances and their supporting infrastructure on {OCP} clusters.

Infrastructure management includes the following areas:

* *Deploy Argo CD instances*: Install and configure default and user-defined Argo CD instances, manage replicas, and customize console links.
* *Configure Argo CD custom resource properties*: Set TLS trust, enable annotation-based resource tracking, configure notifications, and manage Config Management plugins.
* *Configure webhook secrets*: Configure webhook secrets for Git providers to enable automatic synchronization.
* *Configure resource allocation and scaling*: Manage resource requests, limits, and quotas for Argo CD workloads.
* *Scale Argo CD with cluster sharding*: Distribute cluster management across multiple Argo CD application controller replicas using round-robin or dynamic scaling algorithms.
* *Customize the GitOps console experience*: Configure the GitOpsService custom resource for the GitOps console plugin.
* *Keep container images up to date*: Use the Argo CD Image Updater to automatically update container images in your deployments.
* *Configure shell environment*: Configure productivity features such as tab completion for the {gitops-shortname} CLI.
