= Test new Kubernetes features in MicroShift

[role="_abstract"]
Use feature gates to test new Kubernetes features for potential use in your {microshift-short} deployments. Feature gates let you experiment with upcoming Kubernetes capabilities to evaluate their potential benefits for specific edge use cases.
