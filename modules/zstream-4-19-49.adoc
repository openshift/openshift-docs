= RHSA-2026:71447 - {product-title} 4.19.49 bug fix and security update

Issued: 30 September 2026

[role="_abstract"]
{product-title} release 4.19.49 is now available. The list of bug fixes that are included in the update is documented in the link:https://access.redhat.com/errata/RHSA-2026:71447[RHSA-2026:71447] advisory. There are no RPM packages for this release.

[id="zstream-4-19-49-fixed-issues_{context}"]
== Fixed issues

* Before this update, the `EventRecorder` component of the Machine Config Operator (MCO) was incorrectly initialized and prevented emission of the `drain-failure` events when a drain operation failed. As a consequence, administrators did not receive proper event notifications when node drains were blocked by the `PodDisruptionBudgets` or other policies, making it difficult to troubleshoot drain failures. With this release, the `EventRecorder` component is properly initialized to emit drain events. As a result, `drain-failure` events are successfully emitted and visible in cluster events, improving observability of drain operations. (link:https://issues.redhat.com/browse/OCPBUGS-120741[OCPBUGS-120741])

* Before this update, upstream GitHub Actions workflow and issue template files that are not used in the {product-title} downstream fork (which uses Prow and the `ci-operator` tool, not GitHub Actions) were present in the release branches. As a consequence, the `golangci-lint` job failed on every pull request. With this release, these unused files have been removed from the release branches. As a result, the lint job no longer fails on pull requests. (link:https://issues.redhat.com/browse/OCPBUGS-123613[OCPBUGS-123613])
