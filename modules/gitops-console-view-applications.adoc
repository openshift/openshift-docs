= View and manage Applications in the GitOps Console

You can view, create, and manage Argo CD Applications through the {gitops-shortname} Console Plugin.

.Prerequisites

* You have access to the {OCP} web console.
* You have enabled the {gitops-shortname} Console plugin.
* Your permissions allow you to list Applications in one or more namespaces.

.Procedure

. Navigate to *GitOps* -> *Applications* in the *Administrator* perspective.

. Optional: Select a specific project from the *Project* dropdown to view Applications in that namespace, or select all projects to view Applications across all namespaces.

. Optional: Filter Applications by sync status or health status using the available filters:
+
* *Sync Status*: Synced, OutOfSync, Unknown
* *Health Status*: Healthy, Progressing, Suspended, Degraded, Missing, Unknown

. To create a new Application:
+
.. Click *Create Application*.
.. Edit the YAML template with your repository URL, path, target revision, and cluster destination.
.. Click *Create*.

. To view Application details, click an Application name in the list.
+
The details page provides the following tabs:
+
* *Details*: View and edit identity, status, and sync policy
* *YAML*: Edit the Application manifest
* *Sources*: View repository sources
* *Resources*: View managed resources in list or graph view
* *Sync Status*: View the latest sync operation
* *History*: View sync and deployment history
* *Events*: View Kubernetes events

[NOTE]
====
The Application kebab menu and details page do not include *Sync* or *Rollback* actions. To perform a manual sync or rollback, use the Argo CD UI or the `argocd` CLI.
====
