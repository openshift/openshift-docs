= OpenShift Virtualization compliance profile scheduling

// JIRA: ROX-32634

[role="_abstract"]
With Compliance Operator 1.10 or later, {product-title-short} can schedule new compliance profiles supporting OpenShift Virtualization.

The following profiles are available:

* Node profile: `ocp4-cis-vm-extension-node`
* Platform profiles: `ocp4-cis-vm-extension`, `ocp4-stig-vm-extension`

These new profiles are built using CEL-scanner technology introduced to Compliance Operator. This technology is supported with {product-title-short} version 5.0 and versions 4.9.3, 4.10.7, and 4.11.3.
