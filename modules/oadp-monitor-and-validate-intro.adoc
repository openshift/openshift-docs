= Monitor and validate OADP

[role="_abstract"]
Monitor the health of your OpenShift API for Data Protection (OADP) installation and validate that backup and restore operations complete successfully. Use OADP metrics, alerting rules, and the Data Protection Test (DPT) custom resource to verify your data protection configuration.
