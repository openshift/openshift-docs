= Technology Preview limitations for Telecom Grandmaster on Intel Granite Rapids-D

[role="_abstract"]
Telecom Grandmaster (T-GM) deployments on Intel Granite Rapids-D (GNR-D) platforms are available as a Technology Preview feature in {product-title} {product-version}.
Understand the Technology Preview support policy, platform-specific restrictions, and feature limitations before deploying T-GM in your environment.

== Technology Preview support policy

Technology Preview features are not fully supported under Red Hat production service level agreements (SLAs) and might not be functionally complete.
Technology Preview features are provided to enable early customer feedback and evaluation of upcoming functionality.

Not recommended for production use:: Do not deploy Technology Preview features in production environments.
Use Technology Preview features only in development, test, or proof-of-concept environments.

Support cases limited to Severity 3-4:: Red Hat Support handles Technology Preview feature issues as Severity 3 (moderate impact) or Severity 4 (low impact) cases only.
Severity 1 (critical impact) and Severity 2 (high impact) cases are not accepted for Technology Preview features.

No guaranteed migration path:: Red Hat does not guarantee a migration path from Technology Preview features to generally available (GA) features.
Configuration changes, API modifications, or feature removal might occur in future releases without a migration tool or procedure.

Features might change or be removed:: Technology Preview features might be modified, deprecated, or removed in future releases without notice.
Do not build production workflows or integrations that depend on Technology Preview features remaining unchanged.

For more information about the Red Hat Technology Preview Features Support Scope, see link:https://access.redhat.com/support/offerings/techpreview[].

== Platform-specific restrictions

The following platform-specific restrictions apply to Telecom Grandmaster deployments in {product-title} {product-version}:

Dell PowerEdge XR8720t XCC variant only:: Only the XCC (eXtreme Compute Cluster) variant of the Dell PowerEdge XR8720t is supported in this Technology Preview release.
The HCC (High Core Count) variant is not supported.

No T-BC support in {product-title} {product-version}:: Telecom Boundary Clock (T-BC) configurations are not supported on Intel Granite Rapids-D hardware in {product-title} {product-version}.
T-BC support on GNR-D platforms is deferred to a future release.

No dual TR port HA:: Dual time receiver (TR) port high availability configurations are not supported in {product-title} {product-version}.
Dual TR port HA is deferred to a future release.

HPE platforms not supported until {product-title} 5.2:: HPE server platforms (EL140 and DL110 models) are not supported in {product-title} {product-version} or {product-title} 5.1.
HPE platform support is planned for {product-title} 5.2 and later releases.

[id="nw-ptp-gnrd-tech-preview-limitations-reference-features_{context}"]
== Feature limitations

The following feature-level limitations apply to Telecom Grandmaster deployments in {product-title} {product-version}:

Field tuning capability is Technology Preview:: The ability to configure field-tunable precision timing parameters without kernel or firmware upgrades is a Technology Preview feature.
Configuration changes to field-tunable parameters might require validation testing before deployment.

HardwareConfig v2alpha1 API is Technology Preview:: The `HardwareConfig` custom resource (CR) API version `v2alpha1` is a Technology Preview API.
API schema changes, field deprecation, or structural modifications might occur in future releases without a guaranteed migration path from `v2alpha1` to a stable API version.

DPLL operational state monitoring requires kernel backport:: Digital phase-locked loop (DPLL) operational state monitoring on Carter Flat NICs requires a RHEL kernel backport of upstream DPLL subsystem support.
If the required kernel version is not available, DPLL loss detection relies on timing offset thresholds only.
