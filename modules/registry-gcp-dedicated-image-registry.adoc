= Image registry on Google Cloud Dedicated

[role="_abstract"]
The {product-title} integrated image registry is supported in Google Cloud Dedicated (GCD) sovereign cloud environments, using {gcp-short} Cloud Storage (GCS) as the storage backend.

When you provide GCS credentials that include a `universe_domain` field specifying a non-default universe domain, the Image Registry Operator automatically configures itself to use the corresponding GCD API endpoints. No additional registry configuration is required beyond supplying valid GCD credentials.

The Operator also automatically sets `spec.disableRedirect` to `true` when it detects a non-default universe domain. This is required because GCS-generated signed URLs reference `storage.googleapis.com`, which is not reachable from GCD sovereign cloud environments that use different API endpoint formats.

.Configuring the image registry for GCD

To configure the image registry on a GCD cluster, create the `image-registry-private-configuration-user` secret in the `openshift-image-registry` namespace using a GCD service account key file. The key file must be a {gcp-short} service account JSON credential that includes the `universe_domain` field for your GCD region.

[source,terminal]
----
$ oc create secret generic image-registry-private-configuration-user \
  --from-file=REGISTRY_STORAGE_GCS_KEYFILE=<path_to_gcd_keyfile> \
  --namespace openshift-image-registry
----

After the secret is created, configure the GCS storage settings in the `configs.imageregistry.operator.openshift.io/cluster` resource:

[source,terminal]
----
$ oc edit configs.imageregistry.operator.openshift.io/cluster
----

.Example configuration
[source,yaml]
----
apiVersion: imageregistry.operator.openshift.io/v1
kind: Config
metadata:
  name: cluster
spec:
  storage:
    gcs:
      bucket: <bucket_name> <1>
      projectID: <gcd_project_id> <2>
      region: <gcd_region> <3>
----
<1> The name of your GCS bucket in the GCD environment.
<2> The GCD project ID, which includes the mandatory domain prefix, for example `eu0:my-project`.
<3> The GCD region identifier, for example `u-germany-northeast1`.

[NOTE]
====
After you apply the configuration with valid GCD credentials, the Operator automatically sets `spec.disableRedirect: true`. You do not need to set this manually.
====
