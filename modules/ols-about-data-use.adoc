= How your data is used and protected

[role="_abstract"]
{ols-long} adds cluster and environment details to your messages. Then, it sends this data directly from the {ols-long} Service pod on your cluster to the configured large language model (LLM) provider endpoint. No {red-hat}-managed cloud services are involved in this data exchange.

{ols-long} has limited ability to filter or hide the data you send to the LLM. Do not enter any information into the interface that you want to keep private from the LLM.

[IMPORTANT]
====
If you configure filtering or redacting in the `OLSConfig` custom resource (CR) file and you enable a Model Context Protocol (MCP) server, such as by setting `introspectionEnabled` to `true`, the content that the tools return is not filtered and is visible to the LLM. If a tool returns secrets, personally identifiable information (PII), or credentials, that content reaches the LLM unfiltered. Consider this behavior before you enable cluster interaction or agentic features.
====

When you send transcripts or feedback to Red{nbsp}Hat, you agree that Red{nbsp}Hat can use the data to improve our Service. The transcript recording data uses the Red{nbsp}Hat{nbsp}Insights system. It follows the same security rules and access limits as that system. Telemetry and remote data collection can be completely disabled at your discretion.

To request deletion of your data, open a support ticket with {red-hat}.
