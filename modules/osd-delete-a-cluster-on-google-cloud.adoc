= Delete an OSD cluster on {GCP}

[role="_abstract"]
When you no longer need an {product-title} cluster on {GCP}, delete it and release the {GCP} resources that it used. Deleting the cluster through the supported workflow ensures that the service removes the resources that it provisioned.
