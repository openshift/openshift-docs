= About GitHub authentication

[role="_abstract"]
Configure GitHub authentication so users can log in with GitHub or GitHub Enterprise credentials. Separate {product-title} user accounts are not required.

To prevent anyone with any GitHub user ID from logging in to your {product-title} cluster, you can restrict access to only those in specific GitHub organizations.
