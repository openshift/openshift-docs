= IPv6 limitations

[role="_abstract"]
Review IPv6 networking limitations before you install {product-title} on {ibm-power-server-name}.

[IMPORTANT]
====
{ibm-power-server-name} does not provide IPv6 on private subnets. Private subnets support IPv4 CIDR ranges only. You cannot install a cluster that uses IPv6 or dual-stack networking on {ibm-power-server-name}.
====
