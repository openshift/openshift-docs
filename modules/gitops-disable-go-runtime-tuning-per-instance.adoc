= Disable Go runtime tuning for a specific instance

Disable Go runtime tuning for a specific Argo CD instance when you want to manage the `GOMEMLIMIT` and `GOMAXPROCS` environment variables manually, or when automatic tuning conflicts with custom Application Controller configurations. Disabling tuning prevents the Operator from injecting these environment variables into the Application Controller StatefulSet.

.Prerequisites

* You have access to the {OCP} cluster with `cluster-admin` privileges.

.Procedure

* Disable Go runtime tuning by setting `.spec.controller.goRuntime.enabled` to `false`:
+
[source,terminal]
----
$ oc patch argocd example-argocd -n argocd --type='merge' -p='{"spec": {"controller": {"goRuntime": {"enabled": false}}}}'
----

.Verification

* Verify that the `GOMEMLIMIT` and `GOMAXPROCS` environment variables are no longer set in the Application Controller StatefulSet:
+
[source,terminal]
----
$ oc get statefulset argocd-application-controller -n argocd -o jsonpath='{.spec.template.spec.containers[0].env[?(@.name=="GOMEMLIMIT")]}'
----
+
*Expected output:*
+
The command returns no output if the environment variable is not set.
