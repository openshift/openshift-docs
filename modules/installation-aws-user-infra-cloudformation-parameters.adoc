= CloudFormation template parameters for AWS user-provisioned infrastructure

[role="_abstract"]
Each CloudFormation template used to create AWS user-provisioned infrastructure requires a set of input parameters. Use the following tables as a reference when creating parameter JSON files for each stack.

[id="installation-aws-user-infra-cloudformation-parameters-vpc_{context}"]
== VPC

[cols="1,2,2",options="header"]
|===
|Parameter |Description |Value

|`VpcCidr`
|The CIDR block for the VPC.
|A CIDR block in the format `x.x.x.x/16-24`.

|`AvailabilityZoneCount`
|The number of availability zones to deploy the VPC in.
|An integer between `1` and `3`.

|`SubnetBits`
|The size of each subnet in each availability zone.
|An integer between `5` and `13`, where `5` is `/27` and `13` is `/19`.

|===

[id="installation-aws-user-infra-cloudformation-parameters-security_{context}"]
== Security groups and roles

[cols="1,2,2",options="header"]
|===
|Parameter |Description |Value

|`InfrastructureName`
|The name for your cluster infrastructure encoded in your Ignition config files.
|The infrastructure name extracted from the Ignition config file metadata, in the format `<cluster-name>-<random-string>`.

|`VpcCidr`
|The CIDR block for the VPC.
|The CIDR block parameter that you used for the VPC, in the format `x.x.x.x/16-24`.

|`PrivateSubnets`
|The private subnets that you created for your VPC.
|The `PrivateSubnetIds` value from the output of the CloudFormation template for the VPC.

|`VpcId`
|The VPC that you created for the cluster.
|The `VpcId` value from the output of the CloudFormation template for the VPC.

|===

[id="installation-aws-user-infra-cloudformation-parameters-dns_{context}"]
== Networking and load balancing

[cols="1,2,2",options="header"]
|===
|Parameter |Description |Value

|`ClusterName`
|A short, representative cluster name to use for hostnames.
|The cluster name that you used when you generated the `install-config.yaml` file for the cluster.

|`InfrastructureName`
|The name for your cluster infrastructure encoded in your Ignition config files.
|The infrastructure name extracted from the Ignition config file metadata, in the format `<cluster-name>-<random-string>`.

|`HostedZoneId`
|The Route 53 public zone ID to register the targets with.
|The Route 53 public zone ID, which has a format similar to `Z21IXYZABCZ2A4`. You can obtain this value from the AWS console.

|`HostedZoneName`
|The Route 53 zone to register the targets with.
|The Route 53 base domain that you used when you generated the `install-config.yaml` file for the cluster. Do not include the trailing period (.) that is displayed in the AWS console.

|`PublicSubnets`
|The public subnets that you created for your VPC.
|The `PublicSubnetIds` value from the output of the CloudFormation template for the VPC.

|`PrivateSubnets`
|The private subnets that you created for your VPC.
|The `PrivateSubnetIds` value from the output of the CloudFormation template for the VPC.

|`VpcId`
|The VPC that you created for the cluster.
|The `VpcId` value from the output of the CloudFormation template for the VPC.

|===

[id="installation-aws-user-infra-cloudformation-parameters-bootstrap_{context}"]
== Bootstrap node

[cols="1,2,2",options="header"]
|===
|Parameter |Description |Value

|`InfrastructureName`
|The name for your cluster infrastructure encoded in your Ignition config files.
|The infrastructure name extracted from the Ignition config file metadata, in the format `<cluster-name>-<random-string>`.

|`RhcosAmi`
|The current {op-system-first} AMI for the bootstrap node based on your selected architecture.
|A valid `AWS::EC2::Image::Id` value.

|`AllowedBootstrapSshCidr`
|The CIDR block to allow SSH access to the bootstrap node.
|A CIDR block in the format `x.x.x.x/16-24`.

|`PublicSubnet`
|The public subnet associated with your VPC to launch the bootstrap node into.
|The `PublicSubnetIds` value from the output of the CloudFormation template for the VPC.

|`MasterSecurityGroupId`
|The master security group ID for registering temporary rules.
|The `MasterSecurityGroupId` value from the output of the CloudFormation template for the security group and roles.

|`VpcId`
|The VPC that created resources will belong to.
|The `VpcId` value from the output of the CloudFormation template for the VPC.

|`BootstrapIgnitionLocation`
|The location to fetch the bootstrap Ignition config file from.
|The S3 bucket and file name in the form `s3://<bucket_name>/bootstrap.ign`.

|`AutoRegisterELB`
|Whether to register a network load balancer (NLB).
|`yes` or `no`. If you specify `yes`, you must provide a Lambda Amazon Resource Name (ARN) value.

|`RegisterNlbIpTargetsLambdaArn`
|The ARN for the NLB IP target registration lambda group.
|The `RegisterNlbIpTargetsLambda` value from the output of the CloudFormation template for DNS and load balancing. Use `arn:aws-us-gov` if deploying to an AWS GovCloud region.

|`ExternalApiTargetGroupArn`
|The ARN for the external API load balancer target group.
|The `ExternalApiTargetGroupArn` value from the output of the CloudFormation template for DNS and load balancing. Use `arn:aws-us-gov` if deploying to an AWS GovCloud region.

|`InternalApiTargetGroupArn`
|The ARN for the internal API load balancer target group.
|The `InternalApiTargetGroupArn` value from the output of the CloudFormation template for DNS and load balancing. Use `arn:aws-us-gov` if deploying to an AWS GovCloud region.

|`InternalServiceTargetGroupArn`
|The ARN for the internal service load balancer target group.
|The `InternalServiceTargetGroupArn` value from the output of the CloudFormation template for DNS and load balancing. Use `arn:aws-us-gov` if deploying to an AWS GovCloud region.

|===

[id="installation-aws-user-infra-cloudformation-parameters-control-plane_{context}"]
== Control plane machines

[cols="1,2,2",options="header"]
|===
|Parameter |Description |Value

|`InfrastructureName`
|The name for your cluster infrastructure encoded in your Ignition config files.
|The infrastructure name extracted from the Ignition config file metadata, in the format `<cluster-name>-<random-string>`.

|`RhcosAmi`
|The current {op-system-first} AMI for the control plane machines based on your selected architecture.
|A valid `AWS::EC2::Image::Id` value.

|`AutoRegisterDNS`
|Whether to perform DNS etcd registration.
|`yes` or `no`. If you specify `yes`, you must provide hosted zone information.

|`PrivateHostedZoneId`
|The Route 53 private zone ID to register the etcd targets with.
|The `PrivateHostedZoneId` value from the output of the CloudFormation template for DNS and load balancing.

|`PrivateHostedZoneName`
|The Route 53 zone to register the targets with.
|`<cluster_name>.<domain_name>`, where `<domain_name>` is the Route 53 base domain used when you generated the `install-config.yaml` file. Do not include the trailing period (.) that is displayed in the AWS console.

|`Master0Subnet`, `Master1Subnet`, `Master2Subnet`
|A subnet, preferably private, to launch each control plane machine on.
|A subnet from the `PrivateSubnets` value from the output of the CloudFormation template for DNS and load balancing.

|`MasterSecurityGroupId`
|The master security group ID to associate with control plane nodes.
|The `MasterSecurityGroupId` value from the output of the CloudFormation template for the security group and roles.

|`IgnitionLocation`
|The location to fetch the control plane Ignition config file from.
|The generated Ignition config file location: `https://api-int.<cluster_name>.<domain_name>:22623/config/master`.

|`CertificateAuthorities`
|The base64-encoded certificate authority string to use.
|The value from the `master.ign` file in the installation directory. This is the long string with the format `data:text/plain;charset=utf-8;base64,ABC...xYz==`.

|`MasterInstanceProfileName`
|The IAM profile to associate with control plane nodes.
|The `MasterInstanceProfile` parameter value from the output of the CloudFormation template for the security group and roles.

|`MasterInstanceType`
|The type of AWS instance to use for the control plane machines based on your selected architecture.
|The instance type that meets the minimum resource requirements for control plane machines, for example `m6i.xlarge` for AMD64
ifndef::openshift-origin[]
or `m6g.xlarge` for ARM64.
endif::openshift-origin[]

|`AutoRegisterELB`
|Whether to register a network load balancer (NLB).
|`yes` or `no`. If you specify `yes`, you must provide a Lambda Amazon Resource Name (ARN) value.

|`RegisterNlbIpTargetsLambdaArn`
|The ARN for the NLB IP target registration lambda group.
|The `RegisterNlbIpTargetsLambda` value from the output of the CloudFormation template for DNS and load balancing. Use `arn:aws-us-gov` if deploying to an AWS GovCloud region.

|`ExternalApiTargetGroupArn`
|The ARN for the external API load balancer target group.
|The `ExternalApiTargetGroupArn` value from the output of the CloudFormation template for DNS and load balancing. Use `arn:aws-us-gov` if deploying to an AWS GovCloud region.

|`InternalApiTargetGroupArn`
|The ARN for the internal API load balancer target group.
|The `InternalApiTargetGroupArn` value from the output of the CloudFormation template for DNS and load balancing. Use `arn:aws-us-gov` if deploying to an AWS GovCloud region.

|`InternalServiceTargetGroupArn`
|The ARN for the internal service load balancer target group.
|The `InternalServiceTargetGroupArn` value from the output of the CloudFormation template for DNS and load balancing. Use `arn:aws-us-gov` if deploying to an AWS GovCloud region.

|===
