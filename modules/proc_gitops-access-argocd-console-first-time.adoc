= Access the Argo CD web console for the first time

[role="_abstract"]
Access the Argo CD web console to view and manage applications through a graphical interface. The default installation creates a route for the Argo CD server that provides web console access.

.Prerequisites

* You have installed the {gitops-title} Operator.
* You have access to an {OCP} cluster.
* You have the `cluster-admin` role or sufficient permissions to access routes in the `openshift-gitops` namespace.

.Procedure

. Log in to the {OCP} web console.

. Navigate to *Networking* -> *Routes*.

. Select the *openshift-gitops* project from the *Project* dropdown.

. Click the URL in the *Location* column for the `openshift-gitops-server` route.
+
The Argo CD login page opens in a new browser tab.

. Retrieve the default admin password:
+
[source,terminal]
----
$ oc get secret openshift-gitops-cluster -n openshift-gitops -o jsonpath='{.data.admin\.password}' | base64 -d
----
+
*Example output:*
[source,terminal]
----
abc123DEF456xyz
----

. Log in to the Argo CD web console:
+
** *Username*: `admin`
** *Password*: Use the password from the previous step

. Optional: Change the default admin password after your first login by navigating to *User Info* -> *Update Password* in the Argo CD web console.

.Verification

After logging in successfully, the Argo CD dashboard displays. The default installation shows the Argo CD server health status and any applications that have been created.

[TIP]
====
Bookmark the Argo CD server URL for quick access. The URL format is:

`https://openshift-gitops-server-openshift-gitops.apps.<cluster_domain>`
====
