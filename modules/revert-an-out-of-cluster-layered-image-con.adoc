= Revert any changes I made by using the out-of-cluster mode of {image-mode-os-lower}

[role="_abstract"]
When you no longer need the software or drivers that you added with the out-of-cluster mode of {image-mode-os-lower}, remove the layered image from the affected nodes. The nodes then return to the base image.
