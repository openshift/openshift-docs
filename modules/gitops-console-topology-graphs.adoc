= Use graphs and topology views

You can view Application resources, ApplicationSet applications, and Rollout workloads in graphical layouts.

.Prerequisites

* You have access to the {OCP} web console.
* The {gitops-shortname} Console plugin is enabled.

.Procedure

. To view an Application resource graph:

.. Navigate to *GitOps* -> *Applications*.

.. Click an Application name to open the details page.

.. Click the *Resources* tab.

.. Switch to *Graph view*.
+
The graph shows immediate managed resources for the Application. You can pan, zoom, select resources, and use context-menu actions on graph nodes.

. To view an ApplicationSet application graph:

.. Navigate to *GitOps* -> *ApplicationSets*.

.. Click an ApplicationSet name to open the details page.

.. Click the *Applications* tab.

.. Switch to *Graph view*.
+
The graph shows Applications generated by the ApplicationSet.

.. Optional: If progressive sync is enabled and step status is available, switch to *Progressive Sync Flow View* from the toolbar to see Applications grouped by sync step.

. To view Rollout topology:

.. Navigate to the *Developer* perspective.

.. Click *Topology*.

.. Optional: Use the *Filter by resource* control and select *Rollout* to show only Rollout workloads.
+
You can also open this view directly from the {gitops-shortname} *Rollouts* list page by clicking the *Topology view* control.
