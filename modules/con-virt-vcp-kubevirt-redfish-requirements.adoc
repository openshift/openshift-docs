= KubeVirt Redfish requirements

[role="_abstract"]
KubeVirt Redfish exposes VMs through the Redfish API.

You need the following to use KubeVirt Redfish:

* Network access from the installation workstation to the KubeVirt Redfish route.
* Credentials configured in KubeVirt Redfish for API authentication.
* VMs labeled to be exposed through the Redfish API.
* A shared storage location for the installation ISO. During installation of the virtualized control plane, KubeVirt Redfish uses this location to create a data volume, download the installation ISO into that volume, and attach the volume to the VM as virtual media. Because VMs can be scheduled on any worker node in the hosting cluster, this storage location must be accessible from all nodes. Do not use a node-local storage class such as {lvms}.
