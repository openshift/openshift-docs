= Troubleshooting the MCP server

[role="_abstract"]
Diagnose MCP server deployment failures, stalled rollouts, and connectivity issues by inspecting the `MCPServer` custom resource (CR) status conditions, operator logs, and server logs.

.Procedure
* Check the CR status conditions by running the following command:
+
[source,terminal]
----
$ oc get mcpserver <name> -o jsonpath='{.status.conditions}'
----
+
Where `<name>`is the name of the MCP server.

.Common issues
[cols="1,1,2",options="header"]
|===
|Symptom |Status condition/signal |Resolution

|Deployment fails to start
|// SME CONFIRM: condition (e.g., Degraded=True, reason=...)
|// SME CONFIRM: check image pull, RBAC, toolset config

|Rollout stalls after a version change
|// SME CONFIRM: Progressing=True stuck
|// SME CONFIRM

|Client cannot connect
|// SME CONFIRM: gateway/HTTPRoute/auth signal
|Verify the gateway and HTTPRoute; check the API key Secret; re-check authentication

|Toolset refuses to load
|Server refuses to start if a required toolset config is missing (for example, `ossm` without the `kiali` config block)
|Add the required `toolsetConfigs` block for the enabled toolset
|===
