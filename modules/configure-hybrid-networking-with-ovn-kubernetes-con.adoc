= Configure hybrid networking with OVN-Kubernetes

[role="_abstract"]
OVN-Kubernetes hybrid networking allows Linux and Windows nodes to run in the same cluster. Configure a hybrid overlay so that Windows workloads receive addresses from a separate cluster network.
