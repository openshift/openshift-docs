= Virtualization dashboards overview

[role="_abstract"]
{VirtProductName} includes Perses-based dashboards that provide visibility into virtual machine (VM) health, resource utilization, and capacity planning across your cluster.

The dashboards are deployed automatically as `PersesDashboard` custom resources by the HyperConverged Cluster Operator (HCO) in the `{CNVNamespace}` namespace.

You can access these dashboards from the web console by navigating to *Observe* -> *Dashboards*.

The dashboards require the Cluster Observability Operator with the monitoring stack enabled.

[id="available-dashboards_{context}"]
== Available dashboards

The following table describes the available {VirtProductName} dashboards:

[cols="1,2a",options="header"]
|===
| Dashboard | Description

| *Virtual Machines Inventory*
| Lists all VMs in the cluster with status, instance type, guest OS, resource allocation, and operational flags such as live-migratable and evictable.

Use this dashboard to manage your VM fleet and find VMs that match specific criteria.

| *Virtual Machines Utilization*
| Shows resource usage for each VM, including CPU, memory, swap, storage, network, and filesystem metrics.

Use this dashboard to monitor resources, right-size VMs, and optimize costs.

| *Virtual Machines Service Level*
| Tracks VM uptime and downtime over 24 hours, showing planned and unplanned breakdowns.

Use this dashboard for SLA reporting and to find VMs with unexpected downtime.

| *Virtual Machines Time in Status*
| Shows how long each VM has been in its current state, with filters for time thresholds.

Use this dashboard to find stuck VMs or long-stopped VMs that can be cleaned up.

| *Top Consumers*
| Ranks VMs by resource consumption across memory, CPU, storage, network, vCPU wait time, and swap.

Use this dashboard for capacity planning and to identify resource contention.

| *Nodes Memory*
| Shows memory usage per node, including overcommit ratios, memory pressure, and system reservations.

Use this dashboard for memory capacity planning and to prevent out-of-memory events.
|===
