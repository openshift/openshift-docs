= Disable the service monitor

[role="_abstract"]
You can disable the service monitor in {pipelines-shortname} if you do not need to expose telemetry data or want to reduce resource consumption. To do this, set the `enableMetrics` parameter to `false` in the `TektonConfig` custom resource (CR).

.Example
[source,yaml]
----
apiVersion: operator.tekton.dev/v1alpha1
kind: TektonConfig
metadata:
  name: config
spec:
  pipeline:
    params:
       - name: enableMetrics
         value: 'false'
----
