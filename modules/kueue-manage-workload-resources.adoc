= Manage workload resources with gang scheduling

[role="_abstract"]
To manage workload admission and readiness in {kueue-name}, configure gang scheduling. Set admission modes, cluster-wide readiness timeouts, and retry limits.

The following example uses the `ByWorkload` policy with parallel admission. It sets a 10-minute start timeout, a 30-minute recovery timeout, and a retry limit of five.

.Prerequisites

* You have cluster administrator permissions.
* You installed the {kueue-name} Operator on your cluster.
* You created a `Kueue` custom resource (CR) named `cluster`.
* You installed the {oc-first}.

.Procedure

. Update the `Kueue` CR configuration by setting the `spec.config.gangScheduling` field to the following values. Keep the other CR settings.
+
[source,yaml]
----
apiVersion: kueue.openshift.io/v1
kind: Kueue
metadata:
  name: cluster
spec:
  config:
    integrations:
      frameworks:
      - BatchJob
    gangScheduling:
      policy: ByWorkload
      byWorkload:
        admission: Parallel
        timeoutSeconds: 600
        recoveryTimeoutSeconds: 1800
        requeuingStrategy:
          timeReference: Eviction
          retryLimit: 5
          backoffBaseSeconds: 120
          backoffMaxSeconds: 7200
# ...
----
+
For more information about policy and admission fields, see "Gang scheduling configuration". For more information about timeout and requeue fields, see "Gang scheduling timeout and requeue fields".

. Apply the updated `Kueue` CR to the cluster by running the following command:
+
[source,terminal]
----
$ oc apply -f <filename>.yaml
----
