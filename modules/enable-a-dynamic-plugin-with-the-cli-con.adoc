= Enable a dynamic plugin with the CLI

[role="_abstract"]
After a scripted installation, you can activate a dynamic plugin without opening the web console. Patching the console Operator configuration with the {oc-first} adds the plugin to the list of enabled plugins, which lets you enable plugins from an automated workflow.
