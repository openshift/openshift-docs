= Adding compute machines to vSphere

[role="_abstract"]
You can add compute machines hosted on {vmw-first} to your {product-title} cluster by using compute machine sets or by provisioning the machines manually.

See xref:../../machine_management/creating_machinesets/creating-machineset-vsphere.adoc#creating-machineset-vsphere[use compute machine sets] for more information.

You can also provision additional {vmw-short} virtual machines (VMs) manually and add them to your cluster.

See xref:../../machine_management/user_infra/adding-vsphere-compute-user-infra.adoc#adding-vsphere-compute-user-infra[Adding compute machines to vSphere manually] for more information.

You can manually add bare-metal compute machines or VMs hosted outside {vmw-short} to your existing cluster. These nodes join without {vmw-short} integration.

For more information, see xref:../../machine_management/user_infra/adding-bare-metal-compute-vsphere-user-infra.adoc#adding-bare-metal-compute-vsphere-user-infra[Add compute machines without {vmw-short} integration].
