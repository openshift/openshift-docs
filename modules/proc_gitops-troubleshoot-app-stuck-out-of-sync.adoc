= Applications stuck in OutOfSync or Unknown state

[role="_abstract"]
Troubleshoot applications that remain in OutOfSync or Unknown state after synchronization attempts. These states indicate that Argo CD cannot reconcile the application or determine its sync status.

.Prerequisites

* You have access to the Argo CD web console or CLI.
* You have permissions to view application details and logs.

.Procedure

. Check the application sync status details:
+
[source,terminal]
----
$ argocd app get <application_name>
----
+
Review the sync status message for specific errors.

. Common causes and solutions for OutOfSync state:
+
** *Git repository changes not detected:*
+
... Force a refresh to check for new commits:
+
[source,terminal]
----
$ argocd app get <application_name> --refresh
----
+
... If the issue persists, check the repository server logs:
+
[source,terminal]
----
$ oc logs -n openshift-gitops deployment/openshift-gitops-repo-server
----
+
** *Resource hooks preventing sync:*
+
... Check for PreSync or PostSync hooks that failed:
+
[source,terminal]
----
$ argocd app get <application_name> --show-operation
----
+
... Delete failed hook resources manually if they are blocking sync:
+
[source,terminal]
----
$ oc delete job <hook_job_name> -n <namespace>
----
+
** *Immutable field changes:*
+
... Review the diff to identify immutable fields:
+
[source,terminal]
----
$ argocd app diff <application_name>
----
+
... Delete the resource and let Argo CD recreate it:
+
[source,terminal]
----
$ oc delete <resource_type> <resource_name> -n <namespace>
$ argocd app sync <application_name>
----

. Common causes and solutions for Unknown state:
+
** *Missing health check definitions:*
+
... Add custom health checks for CRDs in the `argocd-cm` ConfigMap.
... Alternatively, configure Argo CD to ignore health status for specific resources.
+
** *Resource not found on cluster:*
+
... Verify the resource exists:
+
[source,terminal]
----
$ oc get <resource_type> <resource_name> -n <namespace>
----
+
... If missing, manually sync to create it:
+
[source,terminal]
----
$ argocd app sync <application_name> --resource <resource_type>:<resource_name>
----
+
** *RBAC permissions preventing status checks:*
+
... Check application controller logs for permission errors:
+
[source,terminal]
----
$ oc logs -n openshift-gitops deployment/openshift-gitops-application-controller | grep -i permission
----
+
... Grant the necessary permissions to the Argo CD service account.

. Force a hard refresh to clear cached state:
+
[source,terminal]
----
$ argocd app get <application_name> --hard-refresh
----

. If the application remains stuck, check for finalizers blocking deletion:
+
[source,terminal]
----
$ oc get <resource_type> <resource_name> -n <namespace> -o yaml | grep finalizers -A5
----
+
Remove blocking finalizers if safe:
+
[source,terminal]
----
$ oc patch <resource_type> <resource_name> -n <namespace> --type=json -p='[{"op": "remove", "path": "/metadata/finalizers"}]'
----

.Verification

After applying fixes, sync the application and verify the status changes to Synced:

[source,terminal]
----
$ argocd app sync <application_name>
$ argocd app wait <application_name> --sync
----

[WARNING]
====
Deleting resources or removing finalizers can cause data loss. Ensure you have backups and understand the impact before proceeding.
====
