= Delete a cluster

[role="_abstract"]
As a cluster administrator, delete an {product-title} cluster on Amazon Web Services (AWS) when you no longer need it to avoid unnecessary costs and remove resources that you no longer use.

Deleting a cluster helps you to do the following:

* Release the AWS resources that the cluster consumes.
* Keep your AWS account free of unused clusters.
* Complete the cluster lifecycle in a controlled way.
