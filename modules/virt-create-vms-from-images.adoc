= Create VMs from images

[role="_abstract"]
Create virtual machines (VMs) from disk images and container disks when you need direct control over the boot media. These methods support custom operating system images, generalized images for reuse, and container-packaged disks for portable VM definitions.

{VirtProductName} supports the following image-based creation methods:

* Upload images from your local machine to a VM disk by using the `virtctl` CLI tool.
* Create VMs from web images by referencing a disk image hosted on an HTTP or HTTPS URL.
* Generalize images to remove machine-specific configuration from Linux or Windows disks, producing reusable base images.
* Use container disks to package VM disk images as container images that you can store in a registry and reference in `VirtualMachine` manifests.
