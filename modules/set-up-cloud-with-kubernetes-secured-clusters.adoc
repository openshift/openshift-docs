= Set up RHACS Cloud Service with Kubernetes secured clusters

[role="_abstract"]
To protect non-OpenShift Kubernetes clusters with {rh-rhacscs-first}, generate authentication credentials and deploy sensor components to monitor container workloads. Install these secured cluster services using either Helm charts or the roxctl CLI, depending on your organization's deployment workflow.
