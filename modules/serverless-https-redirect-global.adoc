= HTTPS redirection global settings

[role="_abstract"]
You can redirect all HTTP requests to HTTPS across the cluster by setting the `httpProtocol` spec to `redirected` in the `KnativeServing` custom resource (CR).

.Example `KnativeServing` CR that enables HTTPS redirection
[source,yaml]
----
apiVersion: operator.knative.dev/v1beta1
kind: KnativeServing
metadata:
  name: knative-serving
spec:
  config:
    network:
      httpProtocol: "redirected"
...
----
