= Use OVN network tools to inspect the cluster

[role="_abstract"]
OVN-Kubernetes includes built-in CLI tools for inspecting the logical and physical network state of your cluster. You can list logical resources, query the Northbound and Southbound databases, and run diagnostic commands directly from `ovnkube-node` pods.
