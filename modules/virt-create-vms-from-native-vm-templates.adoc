= Create virtual machines from native VM templates

[role="_abstract"]
Native virtual machine templates (`VirtualMachineTemplate`) are the next-generation template system for {product-title}. You can create reusable VM blueprints from existing VMs and deploy consistent virtual machines across namespaces with parameterized values.
