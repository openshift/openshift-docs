= Requirements for virtual machine scanning

[role="_abstract"]
To use {product-title} ({product-title-short}) to scan virtual machines (VMs), you must meet specific requirements.

{ocp-virt-first} must meet the following requirements:

* You installed the {ocp-virt} Operator in the cluster you want to scan.
* You patched the HyperConverged resource to enable virtual socket (vsock) support.

VMs must meet the following requirements:

* VM resources include vsock support with the setting `spec.domain.devices.autoattachVSOCK: true`.
* VMs are running {op-system-base-full}. You must register any host where you installed the scan agent with Red Hat Subscription Manager and have an active {op-system-base} subscription.
* VMs have internet access to download repository-to-Common Platform Enumeration (CPE) mappings.
* You installed DNF.

{product-title-short} must meet the following requirements:

* You deployed Scanner V4 and it is available.

For resource requirements, such as CPU and memory resource allocation, see "Resource requirements for virtual machine scanning".
