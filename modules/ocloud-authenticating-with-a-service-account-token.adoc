= Authenticate using a service account token

[role="_abstract"]
You can authenticate to the O-Cloud Manager REST API using a Kubernetes service account token. This method is suitable for development, testing, and standalone automation environments that do not require OAuth2 with mutual TLS (mTLS).

.Prerequisites

* You have `cluster-admin` permissions on the hub cluster.
* You installed the O-Cloud Manager Operator.

.Procedure

. Create a service account with API access permissions by running the following commands:
+
[source,terminal]
----
$ oc create serviceaccount -n oran-o2ims <service_account_name>
----
+
[source,terminal]
----
$ oc adm policy add-cluster-role-to-user oran-o2ims-admin-role \
  -n oran-o2ims -z <service_account_name>
----
+
where:
+
`<service_account_name>`:: Specifies a name for the service account used to access the API.
`oran-o2ims-admin-role`:: An aggregated ClusterRole deployed by the Operator that grants read, write, and subscription access to all O-Cloud Manager API endpoints.

. Get the base URL for all O-Cloud Manager API requests from the ingress routes by running the following command:
+
[source,terminal]
----
$ export API_BASE_URL=$(oc get routes -n oran-o2ims -o jsonpath='{.items[0].spec.host}')
----

. Create a scoped bearer token by running the following command:
+
[source,terminal]
----
$ export MY_TOKEN=$(oc create token -n oran-o2ims <service_account_name> --duration=24h \
  --audience=alarms-server \
  --audience=resource-server \
  --audience=cluster-server \
  --audience=artifacts-server \
  --audience=provisioning-server)
----
+
* The `--audience` flags scope the token to all O-Cloud Manager API services. Each service validates its own audience claim.
* The `--duration` flag sets the token lifetime. Adjust as needed for your environment.

. Verify the connection by querying the O-Cloud information endpoint by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureInventory/v2" | jq
----

.Verification

* A successful response returns O-Cloud metadata including the unique identifier and supported API versions.
