= Enforcing signature verification

[role="_abstract"]
To prevent users from using unsigned images, you can enforce signature verification by using the {product-title-short} admission controller. You must first enable the *Contact Image Scanners* feature in your cluster configuration settings. Then, while creating a security policy to enforce signature verification, you can use the *Inform and enforce* option.
