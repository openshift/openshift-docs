= Analyzing update risk and status using AI

[role="_abstract"]
To quickly assess either the risk of an update path or the status of an in-progress update, you can use the web console to generate AI-powered guidance specific to your cluster.

Using this AI assessment feature opens OpenShift Lightspeed Service (OLS) with pre-loaded prompts and requires no manually written prompts. Cluster state data is processed by the LLM provider that you have configured OLS to use.

[IMPORTANT]
====
The data provided by this feature is intended only for evaluation.

Always review the AI-generated update analysis before beginning an update.
====

.Prerequisites

* You have OLS installed and actively connected to an LLM.
* You have access to the cluster with `cluster-admin` privileges.
* You have access to the {product-title} web console.

.Procedure

. On the web console, navigate to *Administration* -> *Cluster Settings*.

. If you want to evaluate an update to the latest version, click *Pre-check with AI* in the *AI Assessment* section. You can click *Troubleshoot* to troubleshoot any issues identified by the assessment.

. If you want to assess a specific update path, perform the following steps:

.. Click *Select a version*.

.. Choose a target update version from the *Select a version* dropdown menu.

.. Click *Pre-check with AI*. You can click *Troubleshoot* to troubleshoot any issues identified by the assessment.

. If you want to evaluate the status of an in-progress update, click *Update status* in the *AI Assessment* section while an update is in progress.
