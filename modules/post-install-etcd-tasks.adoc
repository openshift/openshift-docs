= etcd tasks

[role="_abstract"]
Back up etcd, enable or disable etcd encryption, or defragment etcd data.

[NOTE]
====
If you deployed a bare-metal cluster, you can scale the cluster up to 5 nodes as part of your post-installation tasks.
====
