= ImageUpdaters in the GitOps Console

The {gitops-shortname} Console plugin provides list and details pages for Argo CD Image Updater custom resources in the {OCP} web console. You can search and filter ImageUpdaters, create them from a YAML template, and review matched applications, managed images, and recent update activity.

The *ImageUpdaters* page is available when the ImageUpdater custom resource definition is installed on the cluster.

.Prerequisites

* The ImageUpdater CRD exists on your cluster.
* The {gitops-shortname} Console plugin is active.
* You connect to the {OCP} web console.
* You possess permissions to list ImageUpdaters in one or more namespaces.

.Procedure

To access the ImageUpdaters list page:

. From the *Administrator* perspective, go to *GitOps* -> *ImageUpdaters*.

. Optional: Scope the list to a single namespace by selecting a project from the *Project* dropdown, or select all projects to display ImageUpdaters from every namespace.

The list page provides filtering, search, and creation controls. For more information, see "Filter, search, and paginate resources" and "Common console features". The following filters are available:

* *Apps*: Has Apps, No Apps
* *Ready*: Ready, Not Ready

The ImageUpdaters table columns include: *Name*, *Namespace*, *Apps*, *Images*, *Last Checked*, *Ready*, *Labels*, and row actions.

To view ImageUpdater details:

. From the ImageUpdaters list, click an ImageUpdater name.

. The details page breadcrumb shows *ImageUpdaters* -> *ImageUpdater details*.

. Use the page header *Actions* menu for the same edit and delete actions as the list.

The details page includes the following tabs.


The *Details* tab summarizes identity and ImageUpdater status.

Section title: *ImageUpdater details*.

*Summary (left)*

* *Name*
* *Namespace*
* *Labels*, with *Edit*
* *Annotations*
* *Created at*

*Status and configuration (right)*

* *Ready*: Whether the last reconciliation completed without errors (*True* or *False*)
* *Applications Matched*: Number of applications matched by this ImageUpdater
* *Images Managed*: Number of images eligible for update checking
* *Last Checked At*: When the controller last checked for image updates
* *Last Updated At*: When the controller last performed an image update
* *Observed Generation*: Generation of the resource that was last reconciled

*Conditions*

When the ImageUpdater reports status conditions, a *Conditions* section appears below the summary. Use this table to diagnose reconciliation problems. Common condition types include *Ready*, *Reconciling*, and *Error*.

The conditions table includes the following columns:

|===
| Column | Description

| *Type*
| Condition type

| *Status*
| *True*, *False*, or *Unknown*

| *Updated*
| When the condition last changed

| *Reason*
| Short machine-readable cause

| *Message*
| Human-readable details
|===


The *Recent Updates* tab shows image updates from the most recent reconciliation cycle in a paginated, sortable table.

Section title: *Recent Updates*.

|===
| Column | Description

| *Alias*
| Image alias from the ImageUpdater configuration

| *Image*
| Container image that was updated

| *New Version*
| New image version written by the updater

| *Apps Updated*
| Number of applications updated for this change

| *Updated At*
| When the update was recorded

| *Message*
| Status or detail message for the update
|===

If no updates were recorded in the last cycle, the tab shows an empty state.


The *YAML* tab provides a live editor for the ImageUpdater manifest. For more information, see "Common console features".
