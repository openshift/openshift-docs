= Transport encryption configuration values

[role="_abstract"]
The transport-encryption feature flag is an enum configuration that defines how Addressable resources, such as Brokers, Channels, and Sinks, accept events. It controls whether these resources must accept events over HTTP or HTTPS based on the selected setting.

The possible values for `transport-encryption` are as follows:

[cols=2,options=header]
|===
|Value
|Description

|`disabled`
a|
* Addressable resources can accept events to HTTPS endpoints.
* Producers can send events to HTTPS endpoints.

|`permissive`
a|
* Addressable resources must accept events on both HTTP and HTTPS endpoints.
* Addressable resources must advertise both HTTP and HTTPS endpoints.
* Producers must send events to HTTPS endpoints, if available.

|`strict`
a|
* Addressable resources must not accept events to non-HTTPS endpoints.
* Addressable resources must only advertise HTTPS endpoints.
|===
