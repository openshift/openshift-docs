= Set deployment triggers

[role="_abstract"]
You can set deployment triggers for a `DeploymentConfig` object by using the `oc set triggers` command.

.Procedure

. To set an image change trigger, use the following command:
+
[source,terminal]
----
$ oc set triggers dc/<dc_name> \
    --from-image=<project>/<image>:<tag> -c <container_name>
----
