= Running a scan with a shipped CEL profile

[role="_abstract"]
Bind a CEL `Profile` object that the Compliance Operator created from a `ProfileBundle` to a `ScanSetting` object and review the scan output.

.Prerequisites

* You have installed the Compliance Operator.
* A `ProfileBundle` object references a content image that includes a CEL bundle file in `spec.celContentFile`.
* The `ProfileBundle` object status is `VALID`.

.Procedure

. Verify that the `ProfileBundle` object is valid by running the following command:
+
[source,terminal]
----
$ oc get profilebundle -n openshift-compliance
----

. List CEL profiles by running the following command:
+
[source,terminal]
----
$ oc get profiles.compliance.openshift.io -n openshift-compliance   -o jsonpath='{range .items[*]}{.metadata.name}{"\t"}{.metadata.annotations.compliance\.openshift\.io/scanner-type}{"\n"}{end}'
----
+
Note the name of the CEL profile you want to scan.

. Create a `ScanSettingBinding` object that references the CEL `Profile` object directly:
+
[source,yaml]
----
apiVersion: compliance.openshift.io/v1alpha1
kind: ScanSettingBinding
metadata:
  name: cel-profile-scan
  namespace: openshift-compliance
profiles:
  - apiGroup: compliance.openshift.io/v1alpha1
    kind: Profile
    name: <cel_profile_name>
settingsRef:
  apiGroup: compliance.openshift.io/v1alpha1
  kind: ScanSetting
  name: default
----
+
Replace `<cel_profile_name>` with the profile name from the previous step.

. Apply the `ScanSettingBinding` object by running the following command:
+
[source,terminal]
----
$ oc apply -f cel-profile-scan.yaml
----

. Wait for the scan to finish and list `ComplianceCheckResult` objects by running the following commands:
+
[source,terminal]
----
$ oc get compliancescan -n openshift-compliance
$ oc get compliancecheckresults -n openshift-compliance
----

.Verification

* Confirm that the `ProfileBundle` object status is `VALID` before you create the `ScanSettingBinding` object.
* Confirm that `ComplianceCheckResult` objects exist for the CEL rules in the selected profile.
