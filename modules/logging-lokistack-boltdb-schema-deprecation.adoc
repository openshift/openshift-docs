= About the BoltDB storage schema deprecation

[role="_abstract"]
After you install {logging-title-uc} 6.7, the {loki-op} rejects `LokiStack` configurations that reference BoltDB-based schemas (v11 or v12), causing the `LokiStack` to enter a degraded state. Migrating to the Time Series Database (TSDB) schema (v13) before upgrading prevents this condition.

If a `LokiStack` still references a BoltDB schema after you upgrade to {logging-title-uc} 6.7, the {loki-op} returns an error during reconciliation and the `LokiStack` reports a `Degraded` condition. The operator does not make changes to any managed resources until you remove the unsupported schema entries.

If you upgrade without completing the migration, you can roll back to your earlier {logging-title-uc} version, complete the migration, and then upgrade again.
