= Add pre-packaged software that is not in the base {op-system} image to my nodes

[role="_abstract"]
You can add supported software that is not in the {op-system} base image, such as USB device control or specialized kernel modules, by creating a machine config that enables the matching {op-system-base} extension. Extensions are supported by Red{nbsp}Hat, so you can add this functionality without affecting the supportability of your cluster.
