= Upgrading mirror registry for Red Hat OpenShift

[role="_abstract"]
You can upgrade the _mirror registry for Red{nbsp}Hat OpenShift_ by using the `mirror-registry upgrade` command. Use this command for z-stream updates only, for example, from 3.0.0 to 3.0.1. The `upgrade` command replaces the container image of the installed registry in place and preserves all existing data, credentials, certificates, hostname, and port.

[IMPORTANT]
====
Use `mirror-registry upgrade` only for _mirror registry for Red{nbsp}Hat OpenShift_ 3.0 z-stream updates. To migrate from _mirror registry for Red{nbsp}Hat OpenShift_ 2.0.x to 3.0, use `mirror-registry migrate` instead.
====

The upgrade preserves the following:

* All registry data, including the database, images, and blob storage
* Credentials, including the admin password and JWT signing keys
* TLS certificates
* Hostname and port

.Prerequisites

* You have installed the _mirror registry for Red{nbsp}Hat OpenShift_ 3.0 on the local host.

.Procedure

. Download the `mirror-registry` bundle for the latest version of the _mirror registry for Red{nbsp}Hat OpenShift_ from the link:https://console.redhat.com/openshift/downloads#tool-mirror-registry[OpenShift console *Downloads*] page.

. Extract the bundle and make the binary executable by running the following commands:
+
[source,terminal]
----
$ tar -xzf mirror-registry-amd64.tar.gz
----
+
[source,terminal]
----
$ chmod +x mirror-registry
----

. Upgrade the _mirror registry for Red{nbsp}Hat OpenShift_ by running the following command:
+
* For an air-gapped environment, specify the path to the new container image archive:
+
[source,terminal]
----
$ ./mirror-registry upgrade -image-archive image-archive.tar
----
+
* For a connected environment where the host has internet access, omit `-image-archive` to pull the new image directly:
+
[source,terminal]
----
$ ./mirror-registry upgrade
----
+
[NOTE]
====
For air-gapped environments, always use `-image-archive`. The hostname, port, and data directory are detected from the existing installation and do not need to be specified.
====

* Optional: To replace TLS certificates during upgrade, pass both the `-ssl-cert` and `-ssl-key` flags together:
+
[source,terminal]
----
$ ./mirror-registry upgrade \
  -image-archive image-archive.tar \
  -ssl-cert /path/to/new-cert.pem \
  -ssl-key /path/to/new-key.pem
----

.Verification

. Verify that the _mirror registry for Red{nbsp}Hat OpenShift_ is running with the updated image by entering the following command:
+
[source,terminal]
----
$ systemctl status quay.service
----
+
For a non-root installation, use:
+
[source,terminal]
----
$ systemctl --user status quay.service
----
