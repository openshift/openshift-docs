= Customization and opt-out options for managed configurations

[role="_abstract"]
The `virt-platform-autopilot` controller applies opinionated defaults, but you can override managed configurations to suit your environment. You can switch between autopilot and manual configuration from the operator details page in the web console. The CLI provides more granular customization options.

The CLI provides the following customization options:

Exclude a resource:: Prevent the controller from creating or reconciling a specific resource by disabling it in the `HyperConverged` custom resource (CR).

Customize specific values:: Keep a resource managed by the controller, but apply a JSON patch on top of the reconciled configuration to retain your custom settings.

Exclude specific fields:: Keep a resource managed by the controller, but exclude specific fields from reconciliation so that the controller ignores them.

Stop reconciliation of a resource:: Mark a resource as unmanaged so that the controller does not reconcile it after it is created. You take full ownership of that resource's configuration.

You can combine these approaches across different resources in the same cluster.
