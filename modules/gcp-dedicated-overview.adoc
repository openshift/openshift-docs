= Google Cloud Dedicated overview

[role="_abstract"]
You can install {product-title} on Google Cloud Dedicated sovereign cloud infrastructure by using installer-provisioned infrastructure.
Google Cloud Dedicated provides physically and logically isolated infrastructure operated by independent local partners, enabling you to meet data residency and operational sovereignty mandates while you use a familiar installation workflow.

Google Cloud Dedicated is a sovereign cloud offering from {gcp-short} that delivers infrastructure operated by independent local partners in specific European countries.
Unlike standard {gcp-short}, Google Cloud Dedicated runs in an isolated universe with separate API endpoints, partner-operated data centers, and dedicated identity infrastructure.
This model supports three pillars of digital sovereignty: data residency, technological autonomy, and supply chain resilience.

The following partners and regions are available for Google Cloud Dedicated:

* **France**: S3NS (a partnership between Thales and Google Cloud) operates the `u-france-east1` region.
* **Germany and Netherlands**: Thales and Google Cloud Germany operate the `europe-west3` (Germany) and `europe-west4` (Netherlands) regions.

[discrete]
== OpenShift on Google Cloud Dedicated

{product-title} supports installer-provisioned infrastructure installation on Google Cloud Dedicated sovereign cloud regions.
The installation workflow is the same as standard {gcp-short} installer-provisioned infrastructure, with the following sovereignty-specific constraints:

* **Private clusters only**: Only private clusters are supported on Google Cloud Dedicated because the sovereign infrastructure lacks public DNS zones and global load balancers. Set `publish: Internal` in the `install-config.yaml` file. If you do not set this value, the installation fails during infrastructure provisioning.
* **Hyperdisk-balanced storage**: The installation program defaults to `hyperdisk-balanced` block storage on Google Cloud Dedicated. The Google Cloud Dedicated infrastructure determines which disk types are available; `pd-standard`, `pd-ssd`, `pd-balanced`, and Filestore are generally not provisioned in the sovereign universe.
* **Custom RHCOS image**: You must specify both the `name` and `project` fields for `osImage` in your `install-config.yaml` file.
* **Domain-scoped project IDs**: Google Cloud Dedicated projects use a domain-scoped format such as `eu0:my-project`.
* **No Hive support**: Hive-based cluster provisioning is not supported on Google Cloud Dedicated.

[discrete]
== Automatic environment detection

The installation program automatically detects a Google Cloud Dedicated sovereign cloud environment from the domain-scoped project ID format.
When the installation program detects a known sovereign cloud project prefix (such as `eu0`), it automatically configures the cluster for the sovereign environment, including setting appropriate default instance types and disk types.
