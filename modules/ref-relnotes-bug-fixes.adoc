= Fixed issues

[role="_abstract"]
See the included list for bugs that are fixed in {prodname} {version}.

* Before this release, generated `EnvoyFilter` resources did not preserve a deterministic order for rule matches and HTTP route match indices during controller updates. The Kuadrant Operator generated non-deterministic custom resource specifications on consecutive reconciliation cycles, causing the controller to detect false state changes and continuously re-apply `EnvoyFilter` updates to the API server. As a result, {ocp} clusters had high CPU and memory consumption from reconciliation loops, excessive API server audit log churn, and unnecessary control-plane traffic. With this release, `EnvoyFilter` generation logic is updated to sort and preserve the order of rules and HTTP match indices deterministically. Operator CPU and API server load remain stable, eliminating background reconciliation churn and ensuring that `EnvoyFilter` custom resources are updated only when functional policy changes occur. (link:https://github.com/Kuadrant/kuadrant-operator/pull/2184[2184])
