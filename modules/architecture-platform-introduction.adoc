= Introduction to {product-title}

[role="_abstract"]
You can use the {product-title} to develop and run containerized applications. 
With {product-title}, applications and their supporting data centers can expand from just a few machines and applications to thousands of machines that serve millions of clients.

With the foundation of {product-title} in Kubernetes, {product-title} incorporates the same technology that serves as the engine for massive telecommunications, streaming video, gaming, banking, and other applications. 
With the {product-title} implementation in open
Red{nbsp}Hat technologies, you can extend your containerized applications beyond a single cloud to on-premises and multi-cloud environments.
