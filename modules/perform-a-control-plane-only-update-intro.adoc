= Perform a Control Plane Only update

[role="_abstract"]
In a Control Plane Only update, only the control plane portion of {product-title} is updated. This procedure reduces the total update duration and the number of times worker nodes are restarted. You can perform a Control Plane Only update between two Extended Update Support (EUS) versions, skipping one or more intermediate minor versions.
