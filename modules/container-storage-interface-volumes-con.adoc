= Container Storage Interface volumes

[role="_abstract"]
The Container Storage Interface (CSI) is the standard that lets {product-title} use storage from any vendor that ships a CSI driver. A CSI driver runs as a controller deployment and a node daemon set, and it provisions persistent volumes dynamically from a storage class.
