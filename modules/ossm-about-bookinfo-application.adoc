= Example application used throughout this documentation

[role="_abstract"]

The `bookinfo` application is a sample multi-service application used throughout this documentation to demonstrate deployment, traffic routing, and other mesh features. It works with both sidecar and ambient data plane modes.

The application displays information about a book, similar to a single catalog entry of an online book store. It consists of several microservices, including three versions of the `reviews` service (`reviews-v1`, `reviews-v2`, and `reviews-v3`), which makes it useful for testing traffic routing and policy enforcement.
