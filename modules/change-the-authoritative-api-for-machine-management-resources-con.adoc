= Change the authoritative API for machine management resources

[role="_abstract"]
A cluster can manage a machine resource through the Machine API or through the Cluster API, and one of the two is authoritative at a time. A synchronization controller keeps a matching resource for the other API, so you can change which one is authoritative and change it back.
