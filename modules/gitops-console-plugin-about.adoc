= About the GitOps Console plugin

The {gitops-shortname} Console plugin extends the {product-title} web console with GitOps resource management capabilities. The plugin provides dedicated pages for viewing and managing Argo CD Applications, ApplicationSets, AppProjects, ImageUpdaters, and Argo Rollouts.

The plugin is cluster-scoped. A single plugin deployment serves all Argo CD instances on the cluster. You do not install a separate plugin for each Argo CD instance.

When multiple Argo CD instances exist in different namespaces, their resources appear together in the GitOps pages. Use the namespace selector to limit the view to one namespace or to browse across namespaces.

The *View in Argo CD* action opens the selected application in the Argo CD user interface. This action requires a Route to the Argo CD server.

The {gitops-title} Operator enables the plugin automatically during installation. If you disable the plugin, you can re-enable it manually through the web console or the CLI.
