= Install on vSphere with customizations by using installer-provisioned infrastructure

[role="_abstract"]
In {product-title} version {product-version}, you can install a cluster on your {vmw-first} instance by using installer-provisioned infrastructure with customizations, including network configuration options. You modify parameters in the `install-config.yaml` file before you install the cluster.
