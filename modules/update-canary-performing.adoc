= Performing the cluster update

[role="_abstract"]
After the machine config pools (MCP) enter a ready state, you can perform the cluster update.

[IMPORTANT]
====
When you update by using the web console:

* Select *Control plane only update*.
* Select the custom machine config pools that must remain paused.
* Do not select *Full cluster update*; that option can resume paused pools and update those nodes immediately.

When you update by using the CLI, the update respects the existing `spec.paused` values on your machine config pools.
====
