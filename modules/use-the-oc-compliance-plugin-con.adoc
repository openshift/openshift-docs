= Use the oc-compliance plugin

[role="_abstract"]
Although the Compliance Operator automates many of the checks and remediations for the cluster, you can use the `oc-compliance` plugin to perform the full process of bringing a cluster into compliance by interacting with the Compliance Operator API and other components.
