= Understand how I can use software and drivers that are not available as RHCOS extensions with my nodes.

[role="_abstract"]
As a cluster admin, you can add software or drivers that are not available as extensions in the base {op-system} image by using Image mode for {product-title} to extend the functionality of the base {op-system} image.
