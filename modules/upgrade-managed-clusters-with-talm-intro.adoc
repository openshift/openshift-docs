= Upgrade managed clusters with the {cgu-operator-full}

[role="_abstract"]
You can use the {cgu-operator-full} to orchestrate policy-based platform and Operator updates for managed clusters that you deployed with {ztp} and `PolicyGenerator` resources.

For telco cloud-native network function (CNF) clusters that you update with `ClusterGroupUpgrade` resources outside that {ztp} workflow, see "Update telco CNF clusters".
