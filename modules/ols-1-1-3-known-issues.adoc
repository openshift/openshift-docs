= Known issues

[role="_abstract"]
{ols-official} 1.1.3 contains known issues regarding incorrect documentation version references in the Red Hat Offline Knowledge Portal (RHOKP) RAG source and missing branding logos in the console interface.

* *Incorrect documentation version referenced by the RHOKP RAG source*
+
When you use the RHOKP RAG source on {ocp-product-title} 4.16 and 4.17 clusters, {ols-long} references {ocp-product-title} 4.18 documentation instead of the matching cluster version. As a result, responses generated from product documentation might reflect behavior or features that do not apply to your cluster version.
+
Workaround: There is currently no workaround for this issue.

* *Missing branding logos in the {ols-long} console interface*
+
Branding logos and visual identity markers do not render in the assistant panel when you open {ols-long} in the {ocp-product-title} web console. Only the panel text and standard console icons remain visible. This is a visual issue and does not affect assistant capabilities, prompts, or navigation.
+
Workaround: There is currently no workaround required, as core functionality is unaffected.
