== Fixed issues

The following issues are fixed for this release:

* Before this update, JSON merge patches could bypass field-level Common Expression Language (CEL) immutability rules on the `HostedCluster` custom resource by removing the `spec.infraID` or `spec.clusterID` specifications. As a consequence, the controller re-provisioned the infrastructure and orphaned existing resources. With this release, parent-level CEL validation rules reject API requests attempting to clear these fields. (link:https://issues.redhat.com/browse/OCPBUGS-129443[OCPBUGS-129443])

* Before this update, when reconciling virtual machines (VMs) on {azure-first}, a creation operation could fail and leave a virtual network interface controller (NIC) attached to a load balancer without a corresponding VM. As a consequence, the load balancer could not be used until the orphaned NIC was removed. With this release, the reconciler cleans up orphaned NICs when VM creation fails. As a result, load balancers are not blocked by orphaned NICs after failed VM creation. (link:https://issues.redhat.com/browse/OCPBUGS-133099[OCPBUGS-133099])

* Before this update, an infinite boot loop occurred during Lenovo SR645 V3 hardware provisioning after {op-system-first} was written to the disk. As a consequence, the host stalled on a boot option restoration screen and could not complete the provisioning. With this release, the `ironic` resource skips setting the boot device. As a result, non-volatile random-access memory (NVRAM) loss does not occur, and provisioning succeeds. (link:https://issues.redhat.com/browse/OCPBUGS-134138[OCPBUGS-134138])
