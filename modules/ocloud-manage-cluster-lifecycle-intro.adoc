= Manage infrastructure and cluster lifecycle with the O-Cloud Manager

[role="_abstract"]
The O-Cloud Manager automates the full cluster lifecycle, from provisioning and hardware management to Day 2 configuration, scaling, and upgrades, by using declarative custom resources built on {rh-rhacm-first} and the SiteConfig Operator.

The O-Cloud Manager also exposes REST APIs for programmatic access to inventory, provisioning, alarms, and monitoring operations.

The O-Cloud Manager is a Technology Preview feature only.
