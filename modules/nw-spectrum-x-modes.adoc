= Spectrum-X networking modes

[role="_abstract"]
Spectrum-X fabrics can use single-plane or multi-plane designs.
The procedures in this guide configure a single plane.

[cols="1,2,2",options="header"]
|===

|Mode |Description |This guide

|Single plane
|A single network plane connects the worker adapters to the Spectrum-X fabric.
The repository examples configure one plane and repeat the rail resources for each adapter rail in that plane.
|The procedures in this guide cover a single-plane deployment.

|Multi-plane
|A multi-plane design uses more than one network plane.
Adapter naming, switch connectivity, routing, and configuration resources depend on the selected reference architecture and Operator release.
|This guide does not provide a multi-plane configuration. Confirm support and use the vendor instructions for the exact platform and release.

|===
