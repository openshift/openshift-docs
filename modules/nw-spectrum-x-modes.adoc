= Spectrum-X networking modes

[role="_abstract"]
Spectrum-X fabrics can use one or more network planes to connect worker adapters. Each plane has separate connectivity and configuration requirements.

.Comparison of Spectrum-X networking modes
[cols="1,2",options="header"]
|===

|Mode |Description

|Single plane
|A single network plane connects the worker adapters to the Spectrum-X fabric.
The single-plane example repeats the rail resources for each adapter rail in that plane.

|Multi-plane
|A multi-plane design uses more than one network plane.
Adapter naming, switch connectivity, routing, and configuration resources depend on the selected reference architecture and Operator release.
The selected platform and release must support the multi-plane design.

|===
