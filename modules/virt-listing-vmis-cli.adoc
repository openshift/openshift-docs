= List all VMIs by using the CLI

[role="_abstract"]
You can use the {oc-first} to list all virtual machine instances (VMIs) in your cluster. The list includes standalone VMIs and VMIs that are owned by virtual machines (VMs).

.Prerequisites

* You have installed the {oc-first}.

.Procedure

* List all VMIs by running the following command:
+
[source,terminal]
----
$ oc get vmis -A
----
