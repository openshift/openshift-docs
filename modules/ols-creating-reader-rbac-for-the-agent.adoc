= Creating reader RBAC for the agent service account

[role="_abstract"]
Create the reader role-based access control (RBAC) that the agent service account requires to run.

[NOTE]
====
As of v2.0.0, these `ClusterRoleBinding` resources are not created automatically by the Operator. The agentic controller discovers existing `ClusterRoleBinding` resources by looking for ones with `lightspeed-agent` as a subject. Without these bindings, every `AgenticRun` fails immediately with the following error:

----
claim sandbox: add subject to reader ClusterRoleBinding: no ClusterRoleBinding
found with subject openshift-lightspeed/lightspeed-agent — ensure reader RBAC
is configured
----

The quickstart script (`hack/quickstart/deploy-operator.sh`) creates them manually. The OLM bundle does not.
====

.Prerequisites

* You have installed the {ols-long} Operator.

* You have `cluster-admin` access to the cluster.

.Procedure

* Create the reader `ClusterRoleBinding` resources by running the following command:
+
[source,terminal]
----
$ oc apply -f - <<'EOF'
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: lightspeed-agent-cluster-reader
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: cluster-reader
subjects:
- kind: ServiceAccount
  name: lightspeed-agent
  namespace: openshift-lightspeed
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: lightspeed-agent-monitoring-view
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: cluster-monitoring-view
subjects:
- kind: ServiceAccount
  name: lightspeed-agent
  namespace: openshift-lightspeed
EOF
----
