= Egress IP node selectors

[role="_abstract"]
You can use the `egressNodeSelector` field to restrict which nodes are eligible to host the egress IP addresses of an `EgressIP` object.

:FeatureName: Egress IP node selectors
include::snippets/technology-preview.adoc[]

By default, an `EgressIP` object that does not specify the `egressNodeSelector` field can be assigned to any node labeled with `k8s.ovn.org/egress-assignable=""`.
This label defines the default pool of egress nodes for the cluster.
If you specify the `egressNodeSelector` field, your selector replaces that default for the object.
Only nodes that match the selector are eligible to host its egress IP addresses, and those nodes are not required to carry the `k8s.ovn.org/egress-assignable` label.

A node is eligible to host the egress IP addresses of an `EgressIP` object only if it matches all of the conditions that you specify in the `matchLabels` and `matchExpressions` fields.

[NOTE]
====
An empty `egressNodeSelector` value of `{}` matches every node in the cluster, including control plane nodes. Unless this configuration is intentional, avoid using an empty selector.
====
