= Configure CA certificates with a file path

[role="_abstract"]
Mount your CA certificate bundle as a volume and reference it in the registry configuration. This method has the highest precedence when you configure multiple CA methods.

.Prerequisites

* You have access to an {OCP} cluster with `cluster-admin` privileges.
* You have installed the {gitops-title} Operator on your cluster.
* You have enabled the Argo CD Image Updater.
* You have the CA certificate for your private container registry in PEM format.

.Procedure

. Create a ConfigMap or Secret containing your CA certificate:
+
[source,yaml]
----
apiVersion: v1
kind: ConfigMap
metadata:
  name: registry-ca-certs
  namespace: openshift-gitops
data:
  registry-ca.pem: |
    -----BEGIN CERTIFICATE-----
    MIIDXTCCAkWgAwIBAgIJAKZ...
    -----END CERTIFICATE-----
----

. Mount the CA certificate in the Image Updater deployment:
+
[source,yaml]
----
spec:
  template:
    spec:
      containers:
      - name: argocd-image-updater
        volumeMounts:
        - name: registry-ca
          mountPath: /app/config/certs
          readOnly: true
      volumes:
      - name: registry-ca
        configMap:
          name: registry-ca-certs
----

. Reference the CA file in your registry configuration (`/app/config/registries.conf`):
+
[source,yaml]
----
registries:
- name: Private Registry
  api_url: https://registry.example.com
  prefix: registry.example.com
  ca_file: /app/config/certs/registry-ca.pem
  credentials: secret:openshift-gitops/registry-creds#creds
----
