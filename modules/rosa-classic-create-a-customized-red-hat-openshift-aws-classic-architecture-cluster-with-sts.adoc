= Create a customized {product-title} cluster with STS

[role="_abstract"]
Create a {product-title} cluster with the AWS Security Token Service (STS) using customizations. You can deploy your cluster by using {cluster-manager-first} or the {rosa-cli-first}.

With the procedures in this document, you can also choose between the `auto` and `manual` modes when creating the required AWS Identity and Access Management (IAM) resources.
