= Uninstallation of {VirtProductName} by using the web console

[role="_abstract"]
You can uninstall {VirtProductName} by using the web console to delete {VirtProductName} workloads, the Operator, and its resources.

To uninstall {VirtProductName}, perform the following tasks:

. Delete the `HyperConverged` CR.
. Delete the {VirtProductName} Operator.
. Delete the `{CNVNamespace}` namespace.
. Delete the {VirtProductName} custom resource definitions (CRDs).

== Prerequisites

* All virtual machine instances are deleted. You cannot uninstall {VirtProductName} while its workloads remain on the cluster.
