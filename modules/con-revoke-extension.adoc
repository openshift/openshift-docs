= Revoke a standalone extension

[role="_abstract"]
When you want to
Revoking an extension is an RBAC change: delete the binding and its next handshake fails authorization (existing sessions are unaffected until they re-handshake — see [Authentication and credentials](#authentication-and-credentials)). There is no shared secret to rotate; the kubelet rotates the token automatically and the SDK re-reads the file.
