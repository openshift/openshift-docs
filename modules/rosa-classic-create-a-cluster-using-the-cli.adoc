= Create a cluster using the CLI

[role="_abstract"]
As a cluster administrator, create a {product-title} cluster from the command line by using the {rosa-cli-first}. The {rosa-cli} gives you precise control over cluster configuration for scripted and repeatable deployments.

Creating a cluster by using the {rosa-cli} helps you to do the following:

* Script and automate cluster creation for consistent, repeatable deployments.
* Customize cluster settings, networking, and encryption during creation.
* Integrate cluster provisioning into your existing command-line workflows.
