= {OTELName} for the {mcpg}

[role="_abstract"]
The {mcpg} uses {OTELName} throughout all components to give you consistent logging, {DTShortName}, and metrics.

By using observability, you can achieve the following goals:

* Monitor total system performance, saturation, and overall service health in real time.
* Discover which component generated an error, such as Envoy, an {mcpg} component, or a backend Model Context Protocol (MCP) server.
* Understand how requests flow through the system components.
* Track the lifecycle of a request through contexts, tool calls, and APIs.
* See which tools were called and which MCP servers executed those tools.
* Understand where to find relevant logs for each component.
* Examine metrics about tool call patterns, success rates, and error rates.
* Examine {DTShortName} across the request path.
