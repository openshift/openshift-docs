= About Toolbx

[role="_abstract"]
Toolbx is a tool for creating persistent containers on a {op-system-first} system. Because {op-system} is immutable, you can use Toolbx containers to install and run your favorite debugging or administration tools, even if they are not included in the {op-system} base image.

[role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
