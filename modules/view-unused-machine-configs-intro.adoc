= View no-longer used machine config objects

[role="_abstract"]
Over time, your cluster can accumulate a large number of rendered machine configs that are no longer used, which can contribute to disk space and performance issues. Before you remove these objects, you can view the rendered machine configs on your cluster to identify which ones are no longer in use.
