= VM exposure as a Kubernetes service

[role="_abstract"]
You can expose a virtual machine (VM) within or outside the cluster by exposing a VM as a Kubernetes service. You can use native load balancing and observability tools that provide unified traffic management, consistent SSL termination, and centralized security policies across hybrid workloads.
