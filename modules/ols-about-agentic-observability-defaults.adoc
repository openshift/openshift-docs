= OpenTelemetry, tracing, and logging defaults

[role="_abstract"]
The OpenTelemetry (OTEL) collector, PostgreSQL backend, and audit logging are deployed and enabled by default with the `OLSConfig` CR. No explicit configuration is needed.

The observability pipeline works as follows:

* Operator traces are sent to the OTEL collector, which exports them to `traces.jsonl` by using the file exporter.

* Sandbox logs are sent to the OTEL collector, which writes them to PostgreSQL in the `templogs.logs` table.

* The dataverse export sidecar container reads traces for Red Hat telemetry.

As a reference point for a verified installation, a successful `AgenticRun` produced 2,276 log rows in PostgreSQL and 23 OTEL trace spans.
