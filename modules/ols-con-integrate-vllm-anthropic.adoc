= Integrate {ols-long} with vLLM by using the Anthropic provider

[role="_abstract"]
As an administrator, you can integrate a self-hosted vLLM server as a large language model (LLM) provider for {ols-long} by using the Anthropic provider type and the Anthropic-compatible `/v1/messages` endpoint. Use this pathway for agentic and tool-calling workloads to help ensure that tool calls and structured outputs work reliably.

vLLM version 0.24, the version currently supported with {rhelai}, supports the Anthropic-compatible `/v1/messages` endpoint. Use the Anthropic provider for agentic and tool-calling workloads to help ensure that tool calls and structured outputs are preserved. Model quality also affects agentic outcomes, so results can vary by model.
