= Capture OVS interface state on a {microshift-short} node

[role="_abstract"]
Capture the current state and configuration data of the Open vSwitch (OVS) interfaces on a running {microshift-short} node. Reviewing OVS interface data helps you audit or troubleshoot network connections on the node.
