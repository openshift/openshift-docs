= Disable Go runtime tuning cluster-wide

Disable Go runtime tuning for all Argo CD instances in the cluster by setting the `DISABLE_GO_RUNTIME_TUNING` environment variable in the {gitops-title} Operator Subscription. This global setting overrides per-instance configurations and prevents the Operator from automatically configuring `GOMEMLIMIT` and `GOMAXPROCS` for any Application Controller. Use this setting when you need centralized control over Go runtime tuning across all instances.

.Prerequisites

* You have access to the {OCP} cluster with `cluster-admin` privileges.

.Procedure

. Edit the {gitops-title} Operator Subscription:
+
[source,terminal]
----
$ oc edit subscription openshift-gitops-operator -n openshift-operators
----

. Add the `DISABLE_GO_RUNTIME_TUNING` environment variable to the Subscription:
+
[source,yaml]
----
apiVersion: operators.coreos.com/v1alpha1
kind: Subscription
metadata:
  name: openshift-gitops-operator
  namespace: openshift-operators
spec:
  config:
    env:
    - name: DISABLE_GO_RUNTIME_TUNING
      value: "true"
----

. Save and exit the editor.

[IMPORTANT]
====
When you set the `DISABLE_GO_RUNTIME_TUNING` environment variable to `"true"`, per-instance `.spec.controller.goRuntime` settings cannot re-enable tuning.
====

.Verification

* Verify that the `DISABLE_GO_RUNTIME_TUNING` environment variable is set in the Operator Subscription:
+
[source,terminal]
----
$ oc get subscription openshift-gitops-operator -n openshift-operators -o jsonpath='{.spec.config.env[?(@.name=="DISABLE_GO_RUNTIME_TUNING")].value}'
----
+
*Expected output:*
+
[source,terminal]
----
true
----
