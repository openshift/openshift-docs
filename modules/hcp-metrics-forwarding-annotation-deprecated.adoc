= Deprecated annotation: hypershift.openshift.io/enable-metrics-forwarding

[role="_abstract"]
The `hypershift.openshift.io/enable-metrics-forwarding` annotation is deprecated as of {product-title} 5.0. The `spec.monitoring.metricsForwarding` field on the `HostedCluster` API replaces this annotation and provides per-cluster configuration that the annotation cannot support.

[cols="1,2", options="header"]
|===
|Property |Details

|Annotation
|`hypershift.openshift.io/enable-metrics-forwarding`

|Deprecated since
|{product-title} 5.0

|Replacement
|`spec.monitoring.metricsForwarding` on the `HostedCluster` API

|Removal timeline
|Not yet scheduled.
The annotation continues to be honored until removal is announced.
Administrators must migrate to `spec.monitoring.metricsForwarding` before removal.
|===

== Backward compatibility

The annotation continues to be honored when `spec.monitoring` is not set on the `HostedCluster` object.
If you set `spec.monitoring.metricsForwarding` on a cluster, the spec field takes precedence
and the annotation is ignored for that cluster, even if both are present.

The annotation and the spec field can coexist on the same object during the migration window.
The spec field is always authoritative when both are set.

== Required action

Migrate all hosted clusters that use the `hypershift.openshift.io/enable-metrics-forwarding` annotation to use `spec.monitoring.metricsForwarding` before the annotation is removed in a future release.

For migration instructions, see
xref:../hosted_control_planes/hcp-observability.adoc#hcp-metrics-forwarding-migrate-from-annotation_{context}[Migrating from annotation-based to API-based metrics forwarding].

For a description of the new API fields, see
xref:../hosted_control_planes/hcp-observability.adoc#hcp-metrics-forwarding-api-reference_{context}[Per-cluster metrics forwarding API reference].
