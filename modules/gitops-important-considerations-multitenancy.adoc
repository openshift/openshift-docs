= Important considerations when adopting the multitenancy model

[role="_abstract"]
Granting multitenant cluster administration privileges might allow tenants to bypass any multitenancy efforts and permission restrictions because they might elevate their privileges by using permissions granted to the application by Argo CD. To prevent such situations, you must understand the permission model for Argo CD installed through the {gitops-title} Operator and how to use it to be successful with OpenShift {gitops-shortname} for application delivery.
