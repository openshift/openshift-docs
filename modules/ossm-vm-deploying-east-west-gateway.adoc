= Deploying an east-west gateway

[role="_abstract"]

Because the virtual machine belongs to a different network than the in-cluster workloads, traffic between the two networks passes through an east-west gateway. Deploy a gateway that forwards cross-network traffic to in-cluster services without terminating TLS, so that mutual TLS remains end to end between the virtual machine and the destination workload.

[NOTE]
====
The following procedure uses the {k8s} Gateway API, which requires the Gateway API custom resource definitions (CRDs). {ocp-product-title} 4.19 and later versions install these CRDs by default. If you cannot use the {k8s} Gateway API, you can deploy the east-west gateway by using gateway injection instead. For an example of an east-west gateway that is deployed by using gateway injection, see xref:../install/ossm-multi-cluster-topologies#ossm-installing-multi-primary-multi-network-mesh_ossm-multi-cluster-topologies[Installing a multi-primary multi-network mesh].
====

.Procedure

. Create a `Gateway` resource named `eastwestgateway.yaml` similar to the following example:
+
[source,yaml]
----
apiVersion: gateway.networking.k8s.io/v1
kind: Gateway
metadata:
  name: eastwestgateway
  namespace: istio-system
  labels:
    topology.istio.io/network: cluster-network # <1>
spec:
  gatewayClassName: istio
  listeners:
  - name: cross-network
    hostname: "*.local" # <2>
    port: 15443 # <3>
    protocol: TLS
    tls:
      mode: Passthrough # <4>
      options:
        gateway.istio.io/listener-protocol: auto-passthrough
----
<1> Identifies the gateway as the entry point for the cluster network. The control plane advertises the address of this gateway to workloads on other networks.
<2> Matches the `.local` suffix of in-cluster service hostnames.
<3> The standard port for cross-network mutual TLS traffic.
<4> Passes the connection through without terminating TLS, so that mutual TLS is established between the virtual machine proxy and the destination workload rather than with the gateway.

. Apply the `Gateway` resource by running the following command:
+
[source,terminal]
----
$ oc apply -f eastwestgateway.yaml
----

.Verification

. Verify that the gateway is programmed and has an external address by running the following command:
+
[source,terminal]
----
$ oc get gateway eastwestgateway -n istio-system
----
+
*Example output:*
+
[source,terminal]
----
NAME              CLASS   ADDRESS                                   PROGRAMMED   AGE
eastwestgateway   istio   abcd1234.us-east-1.elb.amazonaws.com       True         45s
----
+
The virtual machine must be able to reach this address on port 15443.
