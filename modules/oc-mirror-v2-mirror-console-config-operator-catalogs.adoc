= Configure Operator catalogs for mirroring

[role="_abstract"]
To include Operators in a mirror, configure Operator catalogs and Operators in the OpenShift Mirror Console. Operator catalogs supply the Operator images for disconnected installation and cluster operation.

.Prerequisites

* The OpenShift Mirror Console is open in a browser.
* You have configured a pull secret.

.Procedure

. On the Mirror Configuration page, click the *Operators* tab.

. Click *Add operator catalog*.
+
To add another Operator catalog, click *Add operator catalog* again and repeat the following steps for each catalog.

. From the *Select a catalog* menu, select the Operator catalog to mirror.

. Click *Add operator*.

. Select the Operator to mirror by using the *Operator* field:

.. Type the name of the Operator.
+
The field suggests matching Operators as you type.

.. Select the Operator from the suggestions.
+
The console shows the *Default Channel* for the Operator and the *Available Channels* list.
+
[NOTE]
====
When an Operator has required dependencies, the console automatically adds those Operators to the configuration. A notification reports the auto-added dependency packages. The *Operators* tab lists them under *Auto-added for* the selected Operator. The generated `ImageSetConfiguration` file includes those dependencies.
====

. Optional: Configure channels for the Operator:

.. In the *Available Channels* list, click each channel you want to include in the mirror.
+
[NOTE]
====
If the default channel is not among the channels that you select, the console adds the `defaultChannel` field to the `ImageSetConfiguration` file. The value of the field is the first channel that you selected. If the default channel is among the channels that you select, the console does not add the `defaultChannel` field.
====

.. Optional: Click *Add channel* to include another channel for the same Operator.

. Click the *Preview* tab to review the generated `ImageSetConfiguration` file before saving.

. Optional: On the *Preview* tab, configure any of the following settings:
+
* *Use digest references*: Under *Catalog References*, set the switch to on to make each `operators.catalog` value use an image digest instead of a tag.
* *Archive Size*: Enter the size of each archive in GiB. If you leave the field empty or enter `0`, oc-mirror uses the default archive size.
+
[NOTE]
====
The *Use digest references* switch stays disabled until you fetch catalog digests on the *Sync Catalogs* tab in *Settings*. For more information, see "Sync Operator catalogs".
====

. Optional: To rename the file, use the *Edit* icon next to the filename to enter a new name.

. Save or download the configuration by doing one of the following:

.. Click *Save Configuration* to save the file with the default filename, or with the new name if you renamed it. The file then appears in the *ImageSetConfiguration File* list on the Mirror Operations page.

.. Click *Download YAML* to download a copy of the file to the default downloads folder on your computer. The copy does not appear on the Mirror Operations page.

.Verification

* Confirm that the *Preview* tab shows the expected `operators` entries.
