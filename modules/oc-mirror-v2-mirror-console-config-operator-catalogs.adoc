= Configure Operator catalogs for mirroring

[role="_abstract"]
Configure Operator catalogs and Operators in the OpenShift Mirror Console to include them in a mirror. Select catalogs and Operators, optionally add channels and digest references, then preview and save.

.Prerequisites

* You are logged in to the OpenShift Mirror Console.
* You have configured a pull secret.

.Procedure

. On the Mirror Configuration page, click the *Operators* tab to choose Operator content for the mirror.

. Click *Add operator catalog*.

. In the *Operators* drop-down list, select the Operator catalog to mirror.

. Click *Add operator*.

. In the *Operator* drop-down list, select the Operator to mirror.
+
The console shows the *Default Channel* for the Operator and the *Available Channels* list.
+
[NOTE]
====
When an Operator has required dependencies, the console automatically adds those Operators to the configuration. A notification reports the auto-added dependency packages, and the *Operators* tab lists them under *Auto-added for* the selected Operator. Those dependencies are included in the generated `ImageSetConfiguration` file.
====

. Optional: In *Available Channels*, click each channel you want to include in the mirror.
+
[NOTE]
====
If you select a channel that is not the default channel, the `defaultChannel` field is automatically added to the `ImageSetConfiguration` file.
====

. Optional: To add another channel for the same Operator, click *Add channel*.

. Optional: To add another Operator catalog, click *Add operator catalog* and repeat the previous steps for each catalog.

. Click the *Preview* tab to review the generated `ImageSetConfiguration` file before saving.

. Optional: If you need digest-based catalog references instead of tags, under *Catalog References*, turn on *Use digest references*.
+
When *Use digest references* is enabled, each `operators.catalog` value in the `ImageSetConfiguration` file uses an image digest instead of a tag.

. To save the configuration, do one of the following:

.. Click *Save Configuration* to save the file with the auto-generated filename shown above the *Save Configuration* button. 

.. Optional: To rename the file before saving, click the *Edit* icon next to the filename and enter the new name into the text box.

.. Click *Download YAML* to download the `ImageSetConfiguration` file to your local system.

.Verification

* Confirm that the downloaded or saved file contains the expected `operators` entries by selecting the *Preview* tab.
