= Configure SSO by using OIDC

[role="_abstract"]
Configure Single Sign-On (SSO) with external OpenID Connect (OIDC) providers to manage multiple users in Argo CD. After the {gitops-title} Operator is installed, Argo CD automatically creates a user with `admin` permissions.
