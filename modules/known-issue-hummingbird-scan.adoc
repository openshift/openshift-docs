= Known issue as of July 15, 2026

[role="_abstract"]
Due to a recently identified data gap in the Red{nbsp}Hat VEX security data feed, {product-title-short} version 4.11 no longer supports vulnerability reporting for Red{nbsp}Hat hardened images (Project Hummingbird). The Red{nbsp}Hat Product Security Team is working to address this data gap so that {product-title-short} can re-introduce support for Red{nbsp}Hat hardened images.
