= Delete your cluster

[role="_abstract"]
Delete a {product-title} cluster by using either {cluster-manager-first} or the {rosa-cli-first}, then clean up the AWS Identity and Access Management (IAM) resources the cluster used.

Cleaning up IAM roles, policies, and OpenID Connect (OIDC) configuration after deletion prevents orphaned resources that can accrue cost or create security risk.
