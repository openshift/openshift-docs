= Include high-performing, lightweight microservices on my nodes that {product-title} can manage and containerize

[role="_abstract"]
You can run WebAssembly (WASM) workloads on your nodes by creating a machine config that enables the {op-system-base} WASM extension. WASM workloads start quickly and use fewer node resources than conventional containers.
