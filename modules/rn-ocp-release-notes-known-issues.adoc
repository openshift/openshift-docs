= Known issues

[role="_abstract"]
This section includes several known issues for {product-title} {product-version}.

* {product-title} ships with Gateway API 1.5, which introduces the `ListenerSet` object. However, `ListenerSet` is not yet supported by the {product-title} Gateway API implementation. If a `ListenerSet` is created with a `parentRef` targeting an {product-title}-managed `Gateway`, the `ListenerSet` is not reconciled. This situation means that the listeners the `ListenerSet` defines are never programmed onto the Gateway and do not route traffic. The unsupported state is now surfaced: the `ListenerSet` reports an `Accepted=False` status condition with reason `UnsupportedByController` and the `ListenerSetOnManagedGateway` alert fires. As a workaround, define the listeners directly on the `Gateway` resource instead of using a `ListenerSet` resource. (link:https://issues.redhat.com/browse/OCPBUGS-98155[OCPBUGS-98155])
