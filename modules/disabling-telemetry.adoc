= Disabling Telemetry

[role="_abstract"]
You can stop {rh-rhacs-first} from collecting Telemetry data by turning off online telemetry data collection in the {product-title-short} portal.

.Procedure

. In the {product-title-short} portal, go to *Platform Configuration > System Configuration*.
. In the *System Configuration* header, click *Edit*.
. Scroll down and set *Online Telemetry Data Collection* to *Disabled*.
