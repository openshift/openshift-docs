= Retrieving logs from a {product-title-short} diagnostic bundle

[role="_abstract"]
You can access Collector logs by downloading a diagnostic bundle from the {product-title} ({product-title-short}) user interface.

Once you have downloaded the diagnostic bundle, you can inspect the logs for all the Collector pods. For more information, see "Generating a diagnostic bundle".
