= Project-level limits

[role="_abstract"]
You can set per-project resource limit ranges to control overcommit, specifying memory and CPU limits and defaults.

[.pr:openshift-enterprise .pr:openshift-origin .pr:microshift]#To help control overcommit, you can set per-project resource limit ranges, specifying memory and CPU limits and defaults for a project that overcommit cannot exceed.#
[.pr:openshift-rosa .pr:openshift-rosa-hcp .pr:openshift-dedicated]#In {product-title}, because overcommitment of project-level resources is enabled by default, if required by your use case, you can disable overcommitment on projects that are not managed by Red Hat.#

[role="pr:openshift-enterprise pr:openshift-origin pr:microshift"]
For information on project-level resource limits, see the _Additional resources_ section.

[role="pr:openshift-enterprise pr:openshift-origin pr:microshift"]
Alternatively, you can disable overcommitment for specific projects.

[role="pr:openshift-rosa pr:openshift-rosa-hcp pr:openshift-dedicated"]
For the list of projects that are managed by Red Hat and cannot be modified, see "Red Hat Managed resources" in _Support_.
