= Migrate from ROSA Classic to hosted control planes for OpenShift 5

[role="_abstract"]
Because OpenShift 5.x requires a hosted control plane architecture, workloads running on OpenShift 4.x Classic clusters must be migrated to a new ROSA Hosted Control Planes cluster.

== Migration workflow overview

. *Provision a ROSA HCP Cluster:* Deploy a new OpenShift 4.x or 5.x ROSA cluster with hosted control planes (HCP) by using the ROSA CLI (`rosa`) or {hybrid-console}.
. *Migrate Application Workloads:* Use the *Migration Toolkit for Applications (MTA)* or *Migration Toolkit for Containers (MTC)* to transfer stateful and stateless application components from the Classic cluster to the HCP cluster.
. *Update to OpenShift 5.x:* Once running on an HCP cluster, manage cluster minor and patch updates directly to OpenShift 5.x by using the ROSA CLI or {hybrid-console-second}.
