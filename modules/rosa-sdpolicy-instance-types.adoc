= Instance types

[role="_abstract"]
All {product-title} clusters require a minimum of two worker nodes. Shutting down the underlying (Amazon Elastic Compute Cloud (EC2) instance) infrastructure through the cloud provider console is unsupported and can lead to data loss and other risks.

[NOTE]
====
Approximately one vCPU core and 1 GiB of memory are reserved on each worker node and removed from allocatable resources. This reservation of resources is necessary to run processes required by the underlying platform. These processes include system daemons such as udev, kubelet, and container runtime among others. The reserved resources also account for kernel reservations.

{product-title} core systems such as audit log aggregation, metrics collection, Domain Name System (DNS), image registry, the OVN-Kubernetes Container Network Interface (CNI) plugin, and others might consume additional allocatable resources to maintain the stability and maintainability of the cluster. The additional resources consumed might vary based on usage. For details, see Kubernetes documentation on the `systemReserved` setting.
====
