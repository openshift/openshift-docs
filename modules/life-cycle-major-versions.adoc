= Major versions (X.y.z)

[role="_abstract"]
Major versions of {product-title}, for example version 4, are supported for one year following the release of a later major version or the retirement of the product.

For example, if version 5 was made available for {product-title} on January 1, version 4 would be allowed to continue running on managed clusters for 12 months, until December 31. After this time, clusters would need to be upgraded or migrated to version 5.

ifdef::openshift-rosa-hcp[]
[IMPORTANT]
====
Starting with {product-title} version 5.x, only {hcp} architecture is supported. Classic cluster architecture is not available for version 5.x deployments or upgrades. You must migrate your workloads to a {hcp} cluster if you are running version 4.x classic clusters and want to adopt version 5.x.
====
endif::openshift-rosa-hcp[]

ifdef::openshift-rosa[]
[IMPORTANT]
====
Classic cluster architecture is not available for version 5.x deployments or upgrades. You must migrate your workloads to a {hcp} cluster if you are running version 4.x {product-title} clusters and want to adopt version 5.x.
====
endif::openshift-rosa[]

ifdef::openshift-dedicated[]
[IMPORTANT]
====
Classic cluster architecture is not available for version 5.x deployments or upgrades. {product-title} on hosted control planes architecture will be available in mid to late 2027.
====
endif::openshift-dedicated[]
