[id="rosa-major-versions_{context}"]
= Major versions (X.y.z)

[role="_abstract"]
Major versions of {product-title} are supported for at least 18 months following the release of a later major version. See the _Life cycle dates_ section for specific dates and support types.

ifdef::openshift-rosa-hcp[]
[IMPORTANT]
====
Starting with {product-title} version 5.x, only {hcp} architecture is supported. New installations of {OCP-short} 5.x and in-place upgrades from {OCP-short} 4.x to 5.x are only available on hosted control planes.
====
endif::openshift-rosa-hcp[]

ifdef::openshift-rosa[]
[IMPORTANT]
====
{product-title} is not available for version 5.x deployments or upgrades. New installations of {OCP-short} 5.x and in-place upgrades from {OCP-short} 4.x to 5.x are only available on hosted control planes.
====
endif::openshift-rosa[]

ifdef::openshift-dedicated[]
[IMPORTANT]
====
Classic cluster architecture is not available for version 5.x deployments or upgrades. {product-title} on hosted control planes architecture will be available in mid to late 2027.
====
endif::openshift-dedicated[]
