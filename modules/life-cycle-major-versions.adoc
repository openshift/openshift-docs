= Major versions (X.y.z)

[role="_abstract"]
Major versions of {product-title}, for example version 4, are supported for one year following the release of a later major version or the retirement of the product.

For example, if version 5 was made available for {product-title} on January 1, version 4 would be allowed to continue running on managed clusters for 12 months, until December 31. After this time, clusters would need to be upgraded or migrated to version 5.

ifdef::openshift-rosa-hcp,openshift-dedicated[]
[IMPORTANT]
====
Starting with {product-title} version 5.x, only Hosted Control Planes (HCP) architecture is supported. Classic cluster architecture is not available for version 5.x deployments or upgrades. Customers running version 4.x Classic clusters who want to adopt version 5.x must migrate their workloads to an HCP cluster.
====
endif::openshift-rosa-hcp,openshift-dedicated[]

ifdef::openshift-rosa[]
[IMPORTANT]
====
Classic cluster architecture is not available for version 5.x deployments or upgrades. Customers running version 4.x Classic clusters who want to adopt version 5.x must migrate their workloads to an HCP cluster.
====
endif::openshift-rosa[]
