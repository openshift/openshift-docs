= Configuring multi-profile mode overcommit

[role="_abstract"]
You can use the Cluster Resource Override Operator to help you control overcommit in your cluster by creating multiple `ClusterResourceOverride` custom resources (CR) and assign each CR to specific namespaces using ClusterResourceOverrideBinding objects.

Use the following procedure to create one or more `ClusterResourceOverride` custom resource (CR) objects in the `clusterresourceoverride-operator` namespace.

.Prerequisites

* The Cluster Resource Override Operator must be installed.

* The Cluster Resource Override Operator has no effect if limits have not been set on containers. You must specify default limits for a project using a `LimitRange` object or configure limits in `Pod` specs for the overrides to apply.
