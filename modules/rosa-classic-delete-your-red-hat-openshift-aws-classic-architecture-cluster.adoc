= Delete your Red Hat OpenShift Service on AWS (Classic architecture) cluster

[role="_abstract"]
This document provides steps to delete a {product-title} cluster that uses the AWS Security Token Service (STS). After deleting your cluster, you can also delete the AWS Identity and Access Management (IAM) resources that are used by the cluster.
