= Default Operator install modes and behavior

[role="_abstract"]
When you install Operators in {product-title} by using the web console as an administrator, you can choose between single namespace and all namespaces install modes.

Single namespace:: Installs the Operator in the selected namespace to watch and be made available for use in that namespace. The pod and service account for the Operator are also located in the selected namespace.

All namespaces:: Installs the Operator in the default `openshift-operators` namespace to watch and be made available to all namespaces in the cluster. In some cases, an Operator author can define metadata to suggest an alternative installation namespace.

Selecting an install mode does not restrict the permissions granted to the Operator to the selected namespaces. Review the permissions requested by the Operator before installation.

This choice also means that users in the affected namespaces get access to the Operators APIs, which can leverage the custom resources (CRs) they own, depending on their role in the namespace:

* The `namespace-admin` and `namespace-edit` roles can read/write to the Operator APIs, meaning they can use them.
* The `namespace-view` role can read CR objects of that Operator.
