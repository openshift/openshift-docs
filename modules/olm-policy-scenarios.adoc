= Installation scenarios

[role="_abstract"]
To predict the success of an installation or update operation, review the scenarios Operator Lifecycle Manager (OLM) considers when installing or upgrading an Operator.

include::snippets/olmv0-operator-group-to-scoped-sa.adoc[]

OLM considers the following Operator group scenarios when installing or upgrading an Operator:

* A cluster administrator creates a new Operator group and specifies a service account. OLM uses the permissions granted to the specified service account to install and upgrade Operators associated with this Operator group.

* A cluster administrator creates a new Operator group and does not specify any service account. OLM uses the default cluster-scoped permissions for Operator installations and upgrades.

* For existing Operator groups that do not specify a service account, OLM uses the default cluster-scoped permissions for Operator installations and upgrades.

* A cluster administrator updates an existing Operator group and specifies a service account. Existing Operators continue to run with their current permissions. OLM uses the specified service account for later installations and upgrades.

* A cluster administrator changes the permissions granted to the specified service account or specifies a different service account. OLM uses the updated permissions or the replacement account for later installations and upgrades. Review permissions already granted to installed Operators separately.

* A cluster administrator removes the service account from an Operator group. OLM uses the default cluster-scoped permissions for Operator installations and upgrades.
