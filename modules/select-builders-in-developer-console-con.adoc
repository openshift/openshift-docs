= Select builders in the Developer Console

[role="_abstract"]
You can browse the available Source-to-Image (S2I) builder images from the *Developer* perspective of the {product-title} web console and select one when you import a source repository. The *Import from Git* flow detects a suitable builder image for your code and lets you override that choice.
