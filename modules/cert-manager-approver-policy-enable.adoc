= Enable approver-policy

[role="_abstract"]
You can enable approver-policy before deploying the approver-policy operand. Enabling approver-policy requires an OpenShift feature set and a {cert-manager-operator} feature gate.

:FeatureName: Managing certificate request approval by using approver-policy
include::snippets/technology-preview.adoc[leveloffset=+1]

[IMPORTANT]
====
The exact feature-gate configuration and supported OpenShift feature set must be confirmed before publication. Replace the placeholders with the final, tested procedure.
====

.Prerequisites

* You have access to the cluster with `cluster-admin` privileges.

* You have installed a version of the {cert-manager-operator} that supports approver-policy.

* You have enabled the required OpenShift feature set: `<feature_set>`.

.Procedure

. Enable the approver-policy feature gate in the `CertManager` CR:
+
[source,yaml]
----
apiVersion: operator.openshift.io/<api_version>
kind: CertManager
metadata:
  name: cluster
spec:
  <approver_policy_feature_gate_configuration>
----

. Apply the updated `CertManager` CR by running the following command:
+
[source,terminal]
----
$ oc apply -f cert-manager.yaml
----

.Verification

* Confirm that the {cert-manager-operator} reports no degraded conditions by running the following command:
+
[source,terminal]
----
$ oc get certmanager cluster -o yaml
----
