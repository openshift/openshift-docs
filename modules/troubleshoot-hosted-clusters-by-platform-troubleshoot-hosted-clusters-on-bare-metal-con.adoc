= Troubleshoot hosted clusters on bare metal

[role="_abstract"]
On bare metal, a hosted cluster depends on the agent platform to discover and provision machines. When nodes are not added to the hosted cluster, the cause is usually in agent discovery or in the {op-system} boot.
