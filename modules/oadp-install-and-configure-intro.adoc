= Install and configure OADP

[role="_abstract"]
Install and configure the OpenShift API for Data Protection (OADP) Operator to protect applications on your {product-title} cluster. OADP supports multiple cloud storage providers including AWS, Microsoft Azure, GCP, and IBM Cloud for backup and restore operations.
