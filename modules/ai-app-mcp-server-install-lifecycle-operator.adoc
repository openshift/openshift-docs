= Enable the MCP Lifecycle Operator

[role="_abstract"]
To install the MCP server for Red Hat OpenShift feature, install the Model Context Protocol (MCP) server by using the MCP Lifecycle Operator.

:FeatureName: MCP Lifecycle Operator
include::snippets/technology-preview.adoc[]

.Prerequisites
* MCP gateway is installed.
* Access to OpenShift console with admin rights.

.Procedure
* For information about installing by using MCP Lifecycle Operator, see "Enable MCP server lifecycle management (Red{nbsp}Hat OpenShift AI documentation)".
+
[IMPORTANT]
====
To install the MCP Lifecycle Operator, you need to install Red{nbsp}Hat OpenShift AI v3.6.0-ae2, which is an Early Release version of the software. 
====
+
Red{nbsp}Hat OpenShift AI v3.6.0-ae2 is available in the console under *Software Catalog* -> *AI/Machine Learning* -> *Red{nbsp}Hat OpenShift AI*. Under *Channel*, select *beta*, and under *Version*, select *3.6.0-ae.2*.
