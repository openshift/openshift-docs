= Detail views

[role="_abstract"]

The console provides filtered lists and detail pages for applications, services, workloads, and {istio} configuration in the namespaces you can access on {ocp-product-title}. Each list shows health, labels, and links into the graph. Select a row to open the detail page for that object.

== Overview tab

Overview is the default tab on a detail page. It shows health, a mini-graph of current traffic, related objects, linked {istio} configuration, and an *Actions* menu. Service detail also shows network information. Workload detail also shows the backing pods.

You can add extra fields to service and workload overview by setting `spec.additional_display_details` in the `Kiali` custom resource. Those fields come from annotations on the object.

== Traffic, logs, and metrics

The *Traffic* tab lists inbound and outbound traffic for the selected application, service, or workload.

Workload detail includes a *Logs* tab that shows application logs and Envoy proxy logs in one view. You can filter with a substring or a regular expression, open the view full screen, overlay trace spans, and change the proxy log level without restarting the pod.

Each detail page includes inbound metrics, outbound metrics, or both. Application and workload pages show request volume, duration, size, and TCP traffic. Service pages show inbound metrics only. You can change the charted dimensions, switch between source and destination proxy metrics, and overlay trace spans.

When you configure {TempoName}, each detail page also includes a *Traces* tab. Tracing in the console is described in "Tracing".

== Dashboards

The console adds a tab for each built-in or custom dashboard that applies to the workload. Built-in dashboards include Envoy, Go, Node.js, Quarkus, and Spring Boot. The Envoy tab is available for any workload that runs an Envoy proxy. It exposes proxy internals that are separate from the default {istio} telemetry.

Attach a dashboard to a workload with the pod annotation `kiali.io/dashboards`, set to a comma-separated list of dashboard names. Prometheus must scrape the application. Custom dashboards are described in "Custom dashboards".
