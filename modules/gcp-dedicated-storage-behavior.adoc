= Storage behavior on Google Cloud Dedicated

[role="_abstract"]
The installation program defaults to `hyperdisk-balanced` block storage on Google Cloud Dedicated.
You must plan your workload storage architecture around this default, especially if your applications require shared filesystems.

On Google Cloud Dedicated, the installation program prefers `hyperdisk-balanced` as the default disk type.
The Google Cloud Dedicated infrastructure determines which disk types are provisioned in the sovereign universe.
The following standard {gcp-short} disk types are generally not available in Google Cloud Dedicated environments:

* `pd-standard`
* `pd-ssd`
* `pd-balanced`

If a preferred disk type is unavailable, the installation program falls back to `pd-ssd`.
Additionally, Google Cloud Filestore is generally not available on Google Cloud Dedicated.
If your applications require shared filesystem access, you must use an alternative storage solution.

[discrete]
== Automatic StorageClass configuration

The GCP PD CSI Driver Operator automatically detects the Google Cloud Dedicated environment and deploys a default storage class configured with `hyperdisk-balanced`.
This replaces the standard `standard-csi` `StorageClass` (which uses `pd-standard`) that the Operator normally deploys on standard {gcp-short}.

You do not need to manually create or configure a storage class for basic block storage on Google Cloud Dedicated.

[discrete]
== Supported storage operations

The following storage operations are validated on Google Cloud Dedicated:

* Persistent volume provisioning
* Volume snapshots
* Volume creation from snapshots
* Persistent volume claim (PVC) resizing

[discrete]
== Hyperdisk-balanced capabilities

Hyperdisk-balanced volumes provide the following capabilities:

* Up to 160,000 IOPS
* Up to 2,400 MiB/s throughput
* Zonal availability only (regional persistent disks are not supported with hyperdisk-balanced)

For current performance specifications and limits, see the link:https://cloud.google.com/compute/docs/disks/hyperdisks[Google Cloud Hyperdisk documentation].

[discrete]
== CSI driver authentication

The GCP PD CSI driver authenticates to the Google Cloud Dedicated APIs transparently using self-signed JWT credentials.
The CSI driver detects the universe domain from the mounted service account credentials and routes API requests to the appropriate sovereign endpoints.
No manual CSI driver configuration is required.
