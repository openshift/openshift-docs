[id="zstream-4-20-43-fixed-issues_{context}"]
== Fixed issues

* Before this update, in dual-stack hosted clusters, mismatched IP SAN (storage area network) byte lengths such as 4-byte versus 16-byte IPv4-mapped addresses caused false validation failures. As a consequence, the Control Plane Operator was forced to continuously regenerate `kas-server-crt`, which caused generation churn that could stall installations. With this release, IP SANs are normalized using net.IP.To16() before comparison. As a result, unnecessary certificate regeneration and continuous `kube-apiserver` rolling updates do not occur. (link:https://issues.redhat.com/browse/OCPBUGS-112733[OCPBUGS-112733])

* Before this update, hosted clusters in non-commercial {aws-first} regions (ISO or classified) defaulted to an unsupported 9001 maximum transmission unit (MTU), causing networking failures. With this release, an optional immutable MTU field in the `OVNKubernetesConfig` parameter and an `--ovn-kubernetes-mtu` CLI flag to configure a compatible MTU are added. (link:https://issues.redhat.com/browse/OCPBUGS-129370[OCPBUGS-129370])
