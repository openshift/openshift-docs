== Fixed issues

* Before this update, on dual-stack hosted clusters, ValidateKeyPair compared certificate IP SANs by using byte-slice sorting that treated IPv4 addresses inconsistently after an X.509 round-trip. As a consequence, validation falsely reported that IP addresses differed, and the control-plane operator repeatedly resigned the kube-apiserver server certificate in an infinite reconciliation loop. With this release, IP SAN comparison normalizes address forms before comparison. As a result, dual-stack hosted clusters no longer enter that resign loop. (link:https://issues.redhat.com/browse/OCPBUGS-112733[OCPBUGS-112733])

* Before this update, hosted clusters on some non-commercial AWS regions (ISO or classified) assumed a 9001 MTU that those regions do not support. As a consequence, networking on hosted cluster nodes could fail to configure correctly. With this release, an optional immutable mtu field is available in OVNKubernetesConfig on the `HostedCluster` API, along with a --ovn-kubernetes-mtu CLI flag, so you can set a compatible MTU. As a result, hosted clusters in those AWS regions can configure networking with a supported MTU. (link:https://issues.redhat.com/browse/OCPBUGS-129370[OCPBUGS-129370])
