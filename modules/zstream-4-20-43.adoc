== Fixed issues

* Before this update, in dual-stack hosted clusters, mismatched IP SAN byte lengths such as 4-byte versus 16-byte IPv4-mapped addresses caused false validation failures. As a consequence, the Control Plane Operator was forced to continuously regenerate `kas-server-crt`, causing generation churn that could stall installations. With this release, IP SANs are normalized using net.IP.To16() before comparison. As a result, unnecessary certificate regeneration and continuous `kube-apiserver` rolling updates do not occur. (link:https://issues.redhat.com/browse/OCPBUGS-112733[OCPBUGS-112733])

* Before this update, hosted clusters on some non-commercial AWS regions (ISO or classified) assumed a 9001 MTU that those regions do not support. As a consequence, networking on hosted cluster nodes could fail to configure correctly. With this release, an optional immutable mtu field is available in `OVNKubernetesConfig` on the `HostedCluster` API, along with a `--ovn-kubernetes-mtu` CLI flag, so you can set a compatible MTU. As a result, hosted clusters in those AWS regions can configure networking with a supported MTU. (link:https://issues.redhat.com/browse/OCPBUGS-129370[OCPBUGS-129370])
