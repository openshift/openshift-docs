= Basic StorageClass object definition

[role="_abstract"]
A `StorageClass` object defines the metadata, provisioner type, and plugin-specific parameters that determine how persistent volumes (PVs) are dynamically created in your cluster. 

Each storage provisioner type requires different parameters, and annotations control cluster-wide defaults, making this structure the foundation for all dynamic storage provisioning.

[role="pr:openshift-enterprise pr:openshift-origin pr:openshift-dedicated pr:microshift"]
.Example `StorageClass` definition
[source,yaml,role="pr:openshift-enterprise pr:openshift-origin pr:openshift-dedicated pr:microshift"]
----
kind: StorageClass
apiVersion: storage.k8s.io/v1
metadata:
  name: <storage-class-name>
  annotations:
    storageclass.kubernetes.io/is-default-class: 'true'
    ...
provisioner: kubernetes.io/aws-ebs
parameters:
  type: gp3
...
----
* [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-dedicated .pr:microshift]#{empty}# `kind`: API object type.

* [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-dedicated .pr:microshift]#{empty}# `apiversion`: The current apiVersion.

* [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-dedicated .pr:microshift]#{empty}# `metadata.name`: The name of the storage class.

* [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-dedicated .pr:microshift]#{empty}# Optional: `metadata.annotations`: Annotations for the storage class.

* [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-dedicated .pr:microshift]#{empty}# `provisioner`: The type of provisioner associated with this storage class.

* [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-dedicated .pr:microshift]#{empty}# Optional: `parameters`: The parameters required for the specific provisioner. This is different for each plugin.
