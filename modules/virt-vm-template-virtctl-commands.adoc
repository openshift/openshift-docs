= Virtual machine template commands

[role="_abstract"]
You can use the `virtctl template` commands to create, process, and convert virtual machine (VM) templates from the command line. These commands perform the same operations as the corresponding custom resources.

.Template creation commands
[width="100%",cols="2a,1a",options="header"]
|===
|Command |Description

|`virtctl template create --vm-name <vm_name>`
|Create a `VirtualMachineTemplate` from an existing VM by creating a `VirtualMachineTemplateRequest` CR. The template is created in the current namespace with a randomized name.

|`virtctl template create --vm-name <vm_name> --name <template_name>`
|Create a template, specifying a name for the template.

|`virtctl template create --vm-name <vm_name> --vm-namespace <namespace>`
|Create a template from a source VM that runs in a different namespace. The template is created in the current namespace.
|===

.Template processing commands
[width="100%",cols="2a,1a",options="header"]
|===
|Command |Description

|`virtctl template process <template_name> --print-params`
|Print the parameters of a template, including the description, generator, and default value of each parameter.

|`virtctl template process <template_name> -p <PARAMETER>=<value>`
|Process a template on the server and print the resulting `VirtualMachine` manifest. Repeat the `-p` flag to set multiple parameters.

|`virtctl template process <template_name> --params-file <file_name>`
|Process a template by using parameters from a JSON or YAML file.

|`virtctl template process <template_name> -p <PARAMETER>=<value> --create`
|Process a template and create the resulting VM by using the `process` subresource API.

|`virtctl template process <template_name> --local`
|Process a template from the cluster on the client instead of calling the `process` subresource API.

|`virtctl template process -f <template_file>`
|Process a template file on the client. Specify `-` to read the template from standard input.

|`virtctl template process <template_name> -o json`
|Print the processed manifest in JSON format. The default format is YAML.
|===

.Template conversion commands
[width="100%",cols="2a,1a",options="header"]
|===
|Command |Description

|`virtctl template convert <template_name>`
|Convert an existing `Template` object in the cluster to a `VirtualMachineTemplate` manifest.

|`virtctl template convert -f <template_file>`
|Convert an existing `Template` object from a file. Specify `-` to read the template from standard input.

|`virtctl template convert <template_name> -o json`
|Print the converted manifest in JSON format. The default format is YAML.
|===

[NOTE]
====
The following flag combinations are rejected:

* `--create` with `--file`, `--local`, or `--print-params`
* `--file` with `--name` or `--local`
* `--param` with `--params-file`

Because `--file` processes a template on the client, you do not need to specify `--local` with it.
====
