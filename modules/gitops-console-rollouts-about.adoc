= About Rollouts in the GitOps Console

The {gitops-shortname} Console plugin provides list and details pages for Argo Rollouts in the {OCP} web console. You can view Rollouts, scale replicas, inspect revisions and pods, and open Rollouts in the Developer Topology view.

The Rollouts list page provides the following capabilities:

* Filter Rollouts by rollout status
* Search Rollouts by name
* View Rollout metadata including status, replica count, and pod count
* Create Rollouts from YAML templates
* Open the Developer Topology view

The Rollout details page includes the following tabs:

* *Details*: Identity, scale, strategy, and status
* *YAML*: Live manifest editor
* *Revisions*: Rollout revisions with promote, abort, retry, and restart actions
* *Pods*: Pods managed by the Rollout
* *Events*: Kubernetes events for the Rollout object

The plugin integrates with the {OCP} Console Developer Topology view. When the Rollout custom resource definition is installed, Rollout workloads appear in the topology graph with visual decorators and context actions.

[NOTE]
====
The Rollouts page is available only when the Rollout custom resource definition is installed on the cluster.
====
