[id="network-observability-network-policy-examples_{context}"]
= Example NetworkPolicy manifests for network observability

[role="_abstract"]
You can use these example NetworkPolicy manifests as a starting point for securing network observability components. Customize these examples based on your specific environment and security requirements.

[NOTE]
====
These examples provide a foundation for securing network observability. You might need to add additional egress rules for Kafka exporters, external storage, or other integrations based on your specific deployment.

For security best practices, avoid using allow-all CIDR rules such as `0.0.0.0/0` or `::/0` in network policies. Instead, use specific namespace selectors and pod selectors to limit traffic to only required destinations.
====

[id="default-deny-policy-netobserv-namespace_{context}"]
== Default deny policy for the netobserv namespace

This policy sets a default deny for all ingress and egress traffic in the `netobserv` namespace. Apply this first, then add specific `allow` policies for required traffic.

[source,yaml]
----
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: default-deny
  namespace: netobserv
spec:
  podSelector: {}
  policyTypes:
  - Ingress
  - Egress
----

[id="allow-dns-for-all-pods_{context}"]
== Allow DNS for all pods

This policy allows all pods in the `netobserv` namespace to access DNS for name resolution.

[source,yaml]
----
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: allow-to-dns
  namespace: netobserv
spec:
  podSelector: {}
  egress:
  - to:
    - namespaceSelector:
        matchLabels:
          kubernetes.io/metadata.name: openshift-dns
    ports:
    - protocol: TCP
      port: 5353
    - protocol: UDP
      port: 5353
  policyTypes:
  - Egress
----

[id="allow-flowlogs-pipeline-to-access-Loki_{context}"]
== Allow FlowLogs pipeline to access Loki

This policy allows the FlowLogs Pipeline to send flow data to Loki.

[source,yaml]
----
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: allow-flp-to-loki
  namespace: netobserv
spec:
  podSelector:
    matchLabels:
      app: flowlogs-pipeline
  egress:
  - to:
    - namespaceSelector:
        matchLabels:
          kubernetes.io/metadata.name: openshift-netobserv
    ports:
    - protocol: TCP
      port: 3100
  policyTypes:
  - Egress
----

where:

`kubernetes.io/metadata.name: openshift-netobserv`:: Replace with the namespace where Loki is deployed in your environment.
`port: 3100`:: Adjust the port number if Loki uses a different port.

[id="allow-agent-to-flowlogs-pipeline-communication_{context}"]
== Allow agent to FlowLogs pipeline communication

This policy allows eBPF agents running on nodes to send flow data to the FlowLogs Pipeline.

[source,yaml]
----
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: allow-agents-to-flp
  namespace: netobserv
spec:
  podSelector:
    matchLabels:
      app: flowlogs-pipeline
  ingress:
  - from:
    - namespaceSelector:
        matchLabels:
          policy-group.network.openshift.io/host-network: ""
    ports:
    - protocol: TCP
      port: 2055
  policyTypes:
  - Ingress
----

where:

`policy-group.network.openshift.io/host-network: ""`:: This namespace selector allows traffic from host-networked pods, which includes the eBPF agents.
`port: 2055`:: Adjust the port number based on your FlowCollector configuration for agent-to-FLP communication.

[id="complete-example-standard-deployment_{context}"]
== Complete example for standard deployment

This example combines multiple policies for a standard Network Observability Operator deployment with Loki storage.

[source,yaml]
----
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: netobserv-policies
  namespace: netobserv
spec:
  podSelector: {}
  policyTypes:
  - Ingress
  - Egress
  egress:
  # Allow DNS
  - to:
    - namespaceSelector:
        matchLabels:
          kubernetes.io/metadata.name: openshift-dns
    ports:
    - protocol: TCP
      port: 5353
    - protocol: UDP
      port: 5353
  # Allow access to Loki
  - to:
    - namespaceSelector:
        matchLabels:
          kubernetes.io/metadata.name: openshift-netobserv
    ports:
    - protocol: TCP
      port: 3100
  ingress:
  # Allow from OpenShift Console
  - from:
    - namespaceSelector:
        matchLabels:
          kubernetes.io/metadata.name: openshift-console
    ports:
    - protocol: TCP
      port: 9001
  # Allow from monitoring
  - from:
    - namespaceSelector:
        matchLabels:
          kubernetes.io/metadata.name: openshift-monitoring
    ports:
    - protocol: TCP
      port: 9102
  # Allow from agents
  - from:
    - namespaceSelector:
        matchLabels:
          policy-group.network.openshift.io/host-network: ""
    ports:
    - protocol: TCP
      port: 2055
----

[id="operator-network-policy_{context}"]
== Operator network policy

This example shows the automatically deployed network policy for the Network Observability Operator in the `openshift-netobserv-operator` namespace. This policy is deployed by the StaticReconciler when `OPERATOR_NETWORK_POLICY` is set to `true` in the CSV.

[source,yaml]
----
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: netobserv-operator
  namespace: openshift-netobserv-operator
spec:
  podSelector:
    matchLabels:
      app: netobserv-operator
  policyTypes:
  - Ingress
  - Egress
  egress:
  # Allow DNS
  - to:
    - namespaceSelector:
        matchLabels:
          kubernetes.io/metadata.name: openshift-dns
    ports:
    - protocol: TCP
      port: 5353
    - protocol: UDP
      port: 5353
  # Allow API server access
  - to:
    - namespaceSelector:
        matchLabels:
          kubernetes.io/metadata.name: default
    ports:
    - protocol: TCP
      port: 6443
  ingress:
  # Allow webhooks
  - from:
    - namespaceSelector: {}
    ports:
    - protocol: TCP
      port: 9443
  # Allow metrics scraping
  - from:
    - namespaceSelector:
        matchLabels:
          kubernetes.io/metadata.name: openshift-monitoring
    ports:
    - protocol: TCP
      port: 8443
----
+
where:

`app: netobserv-operator`:: Pod selector that targets the Network Observability Operator pods.
`port: 6443`:: API server port for Kubernetes API access.
`port: 9443`:: Webhook server port for admission webhooks.
`port: 8443`:: Metrics endpoint port for Prometheus scraping.
