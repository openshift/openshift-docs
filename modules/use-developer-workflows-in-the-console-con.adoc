= Use developer workflows in the console

[role="_abstract"]
The *Developer* perspective of the {product-title} web console gives you a visual path through the application lifecycle, from deploying an application to monitoring its metrics in the *Topology* view.

You can deploy an application from a sample, a Git repository, an existing container image, or the developer catalog, then view its composition, edit it, and delete it when you are done.
