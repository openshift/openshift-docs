= Back up applications

[role="_abstract"]
Use the OpenShift API for Data Protection (OADP) to back up applications, persistent volumes, and application data on your {product-title} cluster. OADP supports CSI snapshots, Kopia-based file-system backups, and provider-specific snapshot methods.
