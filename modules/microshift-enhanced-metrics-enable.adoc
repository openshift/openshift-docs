= Enabling enhanced metrics in {microshift-short}

[role="_abstract"]
To enable enhanced metrics in {microshift-short}, install one or more optional metrics RPM packages and restart the {microshift-short} service. Each exporter is deployed automatically when its RPM is installed.

.Prerequisites

* {microshift-short} is installed and running.
* You have root access to the {microshift-short} host.
* The {oc-first} is installed.

.Procedure

. Install the RPM packages for the exporters that you want to enable.
+
Install only the exporters that your monitoring workflow requires. You can enable the exporters in any combination.
+
[cols="1,2",options="header"]
|===
|Exporter |RPM package

|node-exporter
|`microshift-metrics-node-exporter`

|metrics-server
|`microshift-metrics-server`

|kube-state-metrics
|`microshift-metrics-kube-state-metrics`
|===
+
For example, to install node-exporter and metrics-server, run the following command:
+
[source,terminal]
----
$ sudo dnf install -y microshift-metrics-node-exporter microshift-metrics-server
----

. Restart {microshift-short} to deploy the installed exporters.
+
[source,terminal]
----
$ sudo systemctl restart microshift
----

. Verify that the exporter pods are running in the `openshift-monitoring` namespace.
+
[source,terminal]
----
$ oc get pods -n openshift-monitoring
----
+
When node-exporter is enabled, the output includes a `node-exporter` pod on each node. When metrics-server or kube-state-metrics is enabled, the output includes the corresponding deployment pods.

. Verify that the metrics Services are available.
+
[source,terminal]
----
$ oc get svc -n openshift-monitoring
----

. If you installed metrics-server, verify that resource metrics are available.
+
[source,terminal]
----
$ oc top nodes
$ oc top pods -A
----
