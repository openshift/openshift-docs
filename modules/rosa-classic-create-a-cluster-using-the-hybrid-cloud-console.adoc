= Create a cluster using the {hybrid-console-second}

[role="_abstract"]
As a cluster administrator, create a {product-title} cluster from the web console. The guided console workflow is well suited to creating a cluster interactively without scripting.

Creating a cluster by using the {hybrid-console} helps you to do the following:

* Create a cluster through a guided, web-based workflow.
* Review and confirm configuration choices before you deploy.
* Manage your cluster alongside your other Red{nbsp}Hat subscriptions and services.
