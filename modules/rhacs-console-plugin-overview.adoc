= {rh-rhacs-console-plugin} dynamic plugin overview

[role="_abstract"]
The {product-title-short} Operator includes the {rh-rhacs-console-plugin} dynamic plugin, which provides vulnerability management information directly in the {ocp} web console.

{product-title-short} gathers data that the {rh-rhacs-console-plugin} dynamic plugin displays in the {ocp} interface, providing information about CVEs, image and workload vulnerabilities, and verified image signature status. Authorized security administrators, platform engineers, and application developers gain a unified view of security status within their day-to-day {ocp} workflows.
