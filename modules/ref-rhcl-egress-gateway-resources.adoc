= Egress gateway infrastructure resources

[role="_abstract"]
The egress `Gateway` object infrastructure consists of the following resources that you create and manage:

.Gateway infrastructure resources
[cols="1,3",options="header"]
|===
| Resource | Purpose

| `Gateway`
| Defines the egress `Gateway` object with `gatewayClassName: istio` and a `ClusterIP` service type. User managed. Creates the egress gateway infrastructure.

| `ServiceEntry`
| Registers the external service in the {service-mesh} service registry, making the hostname routable. User-managed. Registers external service in {service-mesh}. {prodname} does not create or manage this {service-mesh} resource.

| `DestinationRule`
| Configures TLS origination so the `Gateway` object can establish TLS to the external service. User managed. {prodname} does not create or manage this {service-mesh} resource.

| `HTTPRoute`
| Routes traffic matching the external hostname through the `Gateway` object to the external service. User managed.
|===

{prodname} automatically generates the following resources to enforce policies:

.{prodname} egress `Gateway` object resources
[cols="1,3",options="header"]
|===
| Resource | Purpose

| `WasmPlugin`, `EnvoyFilter`
| Data plane policy enforcement. {prodname} managed.

| `AuthPolicy`, `RateLimitPolicy`
| Policy definitions. User managed.

| `AuthConfig`, Limitador Operator limits.
| Policy decisions consumed by Authorino and Limitador Operators. {prodname} managed.
|===
