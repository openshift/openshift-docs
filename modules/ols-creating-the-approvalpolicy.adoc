= Creating the ApprovalPolicy

[role="_abstract"]
Optionally, create the `ApprovalPolicy` custom resource (CR) to control how each stage of an `AgenticRun` is approved. Without an `ApprovalPolicy`, all stages default to `Manual` except `Escalation`, and every step blocks until you approve it. Create this CR if you want auto-approval for the analysis, verification, and escalation stages so that only the execution stage requires manual approval.

.Prerequisites

* You have installed the {ols-long} Operator.

* You have created the default `Agent` CR.

.Procedure

* Create the `ApprovalPolicy` CR by running the following command:
+
[source,terminal]
----
$ oc apply -f - <<'EOF'
apiVersion: agentic.openshift.io/v1alpha1
kind: ApprovalPolicy
metadata:
  name: cluster
spec:
  maxConcurrentRuns: 5
  stages:
    - name: Analysis
      approval: Automatic
    - name: Execution
      approval: Manual
    - name: Verification
      approval: Automatic
    - name: Escalation
      approval: Automatic
EOF
----
