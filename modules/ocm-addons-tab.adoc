= Add-ons tab

[role="_abstract"]
[.product:rosa-classic]#The **Add-ons** tab displays all of the optional add-ons that can be added to the cluster. Select the desired add-on, and then select **Install** below the description for the add-on that displays.#
[.product:rosa]#The Add-ons tab is not currently supported on hosted control plane clusters.#
