= MCPServer CRD reference

[role="_abstract"]
The `MCPServer` custom resource definition (CRD) defines the desired state of a Model Context Protocol (MCP) server managed by the MCP Lifecycle Operator.

.MCPServer spec fields
[cols="1,1,1,2",options="header"]
|===
|Field |Type |Required |Description

|`spec.version`      |string  |// CONFIRM |The MCP server version to deploy.
|`spec.toolsets`     |array   |// CONFIRM |Toolsets to enable (`core`, `config`, `netedge`, `ossm`^[1]^ , `tekton`, `kubevirt`).
|`spec.toolsetConfigs` |object |// CONFIRM |Per-toolset configuration blocks (for example, `kiali` for the `ossm` toolset^[1]^).
|`spec.replicas`     |integer |// CONFIRM |Number of server replicas.
|===
--
1.

The `ossm` toolset is enabled by name `ossm`, but its config block and tool names use `kiali` (for example, toolsetConfigs.kiali, kiali_* tools).
