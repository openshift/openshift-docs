= Installing Argo Rollouts CLI on Windows

[role="_abstract"]
For Windows, you can download the Argo Rollouts CLI, `kubectl-argo-rollouts`, as a compressed `zip` archive.

.Prerequisites

* You have installed the {OCP} CLI (`oc`).

.Procedure

. Download the Argo Rollouts CLI from one of the following locations:
+
* link:https://developers.redhat.com/content-gateway/rest/browse/pub/cgw/openshift-gitops/latest/[Red Hat Developer content gateway]
* link:https://mirror.openshift.com/pub/cgw/openshift-gitops/[Red Hat OpenShift mirror site]
+
[options="header"]
|===
|Operating system |Architecture |Archive

|Windows |x86_64 |`kubectl-argo-rollouts-windows-amd64.zip`
|===

. Extract the archive with a ZIP program.

. Rename the extracted file from `kubectl-argo-rollouts-windows-amd64` to `kubectl-argo-rollouts.exe`:
+
[IMPORTANT]
====
The archive contains a file that has no file name extension. You must rename the file to `kubectl-argo-rollouts.exe`. Windows requires the `.exe` extension to run the file, and the `oc` and `kubectl` commands discover the plugin by this exact file name.
====

. Move the binary to a directory on your `PATH` environment variable by running the following command:
+
[source,terminal]
----
C:\> move kubectl-argo-rollouts.exe <directory>
----

. Verify that the plugin is installed correctly by running the following command:
+
[source,terminal]
----
C:\> oc argo rollouts version
----
+
--

----
