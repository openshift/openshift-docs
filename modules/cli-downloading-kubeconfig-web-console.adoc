= Download a kubeconfig file from the web console

[role="_abstract"]
You can download a kubeconfig file from the {product-title} web console to access the cluster with the {oc-first} or other tools without running `oc login`.

.Prerequisites

* You're logged in to the web console.
* You installed `oc`.

.Procedure

* In the web console, click your user name, then select *Download kubeconfig*.
+
Your browser downloads a file named `kubeconfig`. The file contains the cluster API server URL, the cluster certificate authority (CA) certificate, your current access token, and a context that combines them so `oc` can connect.
+
[IMPORTANT]
====
The file contains your current access token and doesn't refresh it automatically. Authentication fails when the token expires or when someone revokes it, including when you log out of the web console. When that happens, log in again and download a new file.

Anyone who has the file can access the cluster with your permissions. Store it securely, and don't share it.
====

.Verification

* Run the following command, using the file you downloaded:
+
[source,terminal]
----
$ oc --kubeconfig <path_to_kubeconfig_file> whoami
----
+
The output shows your user name.
