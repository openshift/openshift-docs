= Namespace access for each user

[role="_abstract"]

After {KialiServer} can read a namespace, the console still hides that namespace from a user who is not allowed to see it. The check uses the user's {ocp-product-title} RBAC.

`GET` on one namespace shows that namespace. Grant it with a `RoleBinding` in the namespace. `LIST` on namespaces shows every namespace the list returns. Grant it with a `ClusterRoleBinding`.

By default, a user who can list namespaces sees every namespace in that list. {KialiServer} does not check `GET` on each one. In a multi-tenant cluster, listing is often broad and `GET` is limited per user. Turn on the per-namespace check:

[source,yaml]
----
spec:
  kiali_feature_flags:
    authz:
      require_namespace_get: true
----

With this flag, a successful list is not enough. The user must be able to `GET` the namespace. Users who cannot list namespaces are already checked with `GET`, whether or not the flag is set.

The flag adds one `GET` request for each namespace when the user's cache is empty. On a cluster with many namespaces, the first load after login is slower. Later requests in the same session use the cache.
