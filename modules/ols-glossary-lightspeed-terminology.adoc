= OpenShift Lightspeed terminology

The following terms are specific to {ols-official}.

bring your own (BYO) model::
A deployment approach in which you connect {ols-long} to a large language model that you select and configure, rather than a model that is bundled with the service.

conversation::
An exchange between a user and {ols-long} that consists of one or more questions and responses. {ols-long} uses the conversation history to provide context-aware answers.

disconnected mode::
A configuration in which {ols-long} runs in an environment that does not have direct access to the public internet. See also _bring your own (BYO) model_.

large language model (LLM) provider::
The service that hosts the large language model that {ols-long} sends questions to, such as OpenAI, Microsoft Azure OpenAI, Red Hat Enterprise Linux AI, Google Vertex AI, or Amazon Web Services (AWS) Bedrock. You define one or more providers in the `OLSConfig` custom resource.

OLSConfig custom resource::
The custom resource (CR) that configures {ols-long}, including the large language model provider, credentials, and service settings. The {ols-long} Operator reconciles this resource.

{ols-official}::
A generative AI service that provides context-aware recommendations to help developers and administrators solve problems in {ocp-product-title}. Use the full name on first mention, {ols-long} on subsequent mentions, and {ols-short} only when the context is clear.

{ols-official} Operator::
The Operator that installs, configures, and manages the {ols-long} Service on {ocp-product-title}.

question validation::
A screening step in which {ols-long} determines whether a submitted question is relevant to {ocp-product-title} before sending it to the large language model.

redaction::
The filtering of sensitive or unwanted information from a user query before it is sent to the large language model provider. You define redaction rules in the `OLSConfig` custom resource.

role-based access control (RBAC)::
The {ocp-product-title} mechanism that governs which users are authorized to interact with {ols-long}.

transcript::
A record of a user conversation that can be collected, subject to the configured data collection settings, to help improve the service.

user feedback::
Ratings and comments that users submit about {ols-long} responses, which can be collected to help improve the service.
