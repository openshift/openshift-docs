= OpenShift Lightspeed terminology

[role="_abstract"]
The following terms are specific to {ols-official}.

agentic run::
A single execution of an autonomous troubleshooting workflow, in which an agent diagnoses a cluster alert and proposes or applies a remediation. Each agentic run is represented by an `AgenticRun` custom resource.

[[byo-model]]bring your own (BYO) model::
A deployment approach in which you connect {ols-long} to a large language model that you select and configure, rather than a model that is bundled with the service.

conversation::
An exchange between a user and {ols-long} that consists of one or more questions and responses. {ols-long} uses the conversation history to provide context-aware answers.

large language model (LLM) provider::
A service that hosts the large language model that {ols-long} sends questions to, such as OpenAI, Microsoft Azure OpenAI, Red Hat Enterprise Linux AI, Google Vertex AI, or Amazon Bedrock. You define one or more providers in the `OLSConfig` custom resource.

local mode::
A configuration in which {ols-long} runs in an environment that does not have direct access to the public internet, which can include offline or disconnected deployments. See also <<byo-model,bring your own (BYO) model>>.

`OLSConfig` custom resource::
The custom resource (CR) that configures {ols-long}, including the large language model provider, credentials, and service settings. The {ols-long} Operator reconciles this resource.

question validation::
A screening step in which {ols-long} determines whether a submitted question is relevant to {ocp-product-title} before sending it to the large language model.

redaction::
The filtering of sensitive or unwanted information from a user query before it is sent to the large language model provider. You define redaction rules in the `OLSConfig` custom resource.

{ols-official}::
A generative AI service that provides context-aware recommendations to help developers and administrators solve problems in {ocp-product-title}.

{ols-official} Operator::
The {k8s} Operator that installs, configures, and manages the {ols-long} Service on {ocp-product-title}.

transcript::
A stored record of a conversation between a user and {ols-long}. It can be collected to improve the service. Transcript collection depends on the data collection settings that you configure.

user feedback::
Ratings and comments that users submit about {ols-long} responses, which can be collected to help improve the service.
