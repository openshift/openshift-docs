= Import a VM image from S3 object storage

[role="_abstract"]
You can import a virtual machine (VM) image from an S3-compatible object storage bucket by using a `DataVolume` object.
The Containerized Data Importer (CDI) pulls the image from the S3 endpoint and populates a persistent volume claim (PVC) that you can use to create a VM.

.Prerequisites

* A VM image is stored in an S3-compatible bucket.
* S3 access credentials are stored in a `Secret` object.
* You have installed the {oc-first}.

.Procedure

. Create a `Secret` object for your S3 access credentials:
+
[source,yaml]
----
apiVersion: v1
kind: Secret
metadata:
  name: s3-secret
type: Opaque
stringData:
  accessKeyId: "<access_key>"
  secretKey: "<secret_key>"
----
+
where:
+
`<access_key>`:: Specifies the access key ID for your S3-compatible storage account.
`<secret_key>`:: Specifies the secret key for your S3-compatible storage account.

. Apply the `Secret` object:
+
[source,terminal]
----
$ oc create -f <secret_manifest>.yaml
----

. Create a `DataVolume` object that specifies the S3 source URL and secret reference:
+
[source,yaml]
----
apiVersion: cdi.kubevirt.io/v1beta1
kind: DataVolume
metadata:
  name: s3-image-datavolume
spec:
  source:
    s3:
      url: "https://s3.example.com/my-bucket/my-vm-image.qcow2"
      secretRef: s3-secret
  storage:
    resources:
      requests:
        storage: 20Gi
----
+
where:
+
`url`:: Specifies the S3 URL of the VM image. For non-AWS S3 services, specify the full endpoint URL.
`secretRef`:: Specifies the name of the `Secret` with the S3 access credentials.
`certConfigMap`:: Optional: Specifies the name of a `ConfigMap` with custom CA certificates for the S3 endpoint. Add this field under `spec.source.s3` if your endpoint uses a custom certificate authority.

. Apply the `DataVolume` object by running the following command:
+
[source,terminal]
----
$ oc create -f <datavolume_manifest>.yaml
----

. Monitor the import progress by running the following command and observing the output:
+
[source,terminal]
----
$ oc get dv <datavolume_name>
----

.Verification

* Confirm that the data volume reaches the `Succeeded` phase by running the following command and observing the output:
+
[source,terminal]
----
$ oc get dv <datavolume_name>
----

* Confirm that the PVC is created and bound by running the following command and observing the output:
+
[source,terminal]
----
$ oc get pvc
----
