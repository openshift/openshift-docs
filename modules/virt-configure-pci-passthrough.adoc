= PCI passthrough configuration

[role="_abstract"]
The Peripheral Component Interconnect (PCI) passthrough feature enables you to access and manage hardware devices from a virtual machine (VM). When PCI passthrough is configured, the PCI devices function as if they were physically attached to the guest operating system.

To configure PCI passthrough, you prepare the nodes, prepare the host devices by enabling IOMMU and binding them to the VFIO driver, expose the devices in the cluster, and then assign them to VMs. On {ibm-z-name} and {ibm-linuxone-name}, you can also configure PCI passthrough for Network Express RoCE adapters and {ibm-name} Internal Shared Memory (ISM) virtual PCI devices.
