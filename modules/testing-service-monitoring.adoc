= Testing service monitoring

[role="_abstract"]
You can monitor metrics for a service in {ocp-product-title} by configuring monitoring stacks managed by the {coo-first}. Test service monitoring to verify that your metrics collection functions as expected.

.Procedure

. Deploy a sample service that defines a service endpoint.

. Create a `ServiceMonitor` object that specifies how the service is to be monitored by the {coo-short}.

. Create a `MonitoringStack` object to discover the `ServiceMonitor` object.
