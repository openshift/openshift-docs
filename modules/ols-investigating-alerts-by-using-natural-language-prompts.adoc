= Investigate alerts by using natural language prompts

[role="_abstract"]
When a cluster alert fires, you can use the {ols-long} chat interface to quickly investigate its root cause. Trigger an AI-assisted investigation directly from an active alert in the {ocp-product-title} web console to diagnose the root causes and review recommended remediation steps.

.Prerequisites

* You are logged in to the {ocp-product-title} web console as a user with permission to view cluster alerts.
* The {ols-long} Operator is installed.
* At least one alert is firing in the cluster.
* Your environment is a single-cluster {ocp-product-title} 5.0 deployment.

.Procedure

. In the {ocp-product-title} web console, click the {ols-long} floating action button.

. In the chat window, switch to *Troubleshooting* mode to enable alert investigation capabilities.

. Enter a natural language prompt to investigate the alert. For example: "Investigate the KubePodCrashLooping alert in the payments namespace and identify the root cause."

. Examine the dynamically generated Perses charts in the {ols-long} chat panel and the evidence summary, reviewing the *Source* (telemetry origin), *Signal* (specific metric, log, or alert), and *Finding* (inferred root cause) fields to verify the telemetry correlation.

. To steer the investigation toward specific cluster telemetry, in the prompt box of the chat interface, enter a natural language follow-up prompt (such as specifying a target namespace, pod, or resource).

. In the chat window, inspect the generated causal chain within the evidence summary to evaluate how the identified root cause maps across correlated metrics, logs, and affected namespaces.

. Review each recommended step and execute the commands or configuration changes as appropriate for your environment.
+
[IMPORTANT]
====
Follow a `trust, but verify` operational model by validating the AI logic before applying any remediation. To do this, analyze the generated evidence summary by interpreting how the *Source* (the telemetry origin), *Signal* (the specific metric, log, or alert), and *Finding* (the inferred root cause) map together to establish the causal chain.
====

.Verification

* Ensure that the {ols-long} panel provides an evidence summary.
* Ensure that the recommended remediation steps appear in a read-only format for human review.
