= Agent self-registration overview

Agent self-registration automates the cluster secret creation process when you onboard Argo CD Agents. When you enable this feature, the principal component automatically creates the cluster secret the first time an agent connects with valid credentials.

By default, onboarding an Argo CD Agent requires you to manually create a cluster secret on the principal by running the `argocd-agentctl agent create` command. Self-registration eliminates this manual step while maintaining the same security requirements.

[IMPORTANT]
====
Self-registration does not bypass authentication requirements. Agents still need valid authentication credentials, such as an mTLS client certificate, to connect to the principal. Self-registration only removes the manual cluster secret creation step.
====

Self-registered cluster secrets use a shared TLS client certificate that you create once and configure in the principal's `ArgoCD` custom resource (CR). When an authenticated agent connects for the first time, the principal automatically creates a cluster secret for that agent. You can then manage applications on that agent cluster without any additional manual configuration steps.

This feature is particularly useful when you need to onboard multiple agent clusters quickly or when you want to streamline your agent deployment workflow in dynamic environments.
