= Deploy approver-policy by using the ApproverPolicyManager CR

[role="_abstract"]
You can create an `ApproverPolicyManager` custom resource (CR) to deploy the approver-policy operand. The Operator creates and updates the required RBAC resources based on the `approveSignerNames` setting.

:FeatureName: Managing certificate request approval by using approver-policy
include::snippets/technology-preview.adoc[leveloffset=+1]

.Prerequisites

* You have enabled approver-policy.

* You know the signer names that approver-policy must be allowed to approve.

.Procedure

. Create a YAML file, for example, `approver-policy-manager.yaml`, that defines the `ApproverPolicyManager` CR as shown in the following example:
+
.Example approver-policy-manager.yaml
[source,yaml]
----
apiVersion: operator.openshift.io/<api_version>
kind: ApproverPolicyManager
metadata:
  name: cluster
spec:
  approveSignerNames:
    - <signer_name>
----

. Create the `ApproverPolicyManager` CR by running the following command:
+
[source,terminal]
----
$ oc apply -f approver-policy-manager.yaml
----
+
[NOTE]
====
Confirm the final API group, CR name, namespace, status conditions, and `approveSignerNames` syntax before publication.
====

.Verification

* Verify that the approver-policy pods are running by running the following command:
+
[source,terminal]
----
$ oc get pods -n cert-manager
----

* Verify the status of the `ApproverPolicyManager` CR by running the following command:
+
[source,terminal]
----
$ oc get approverpolicymanager cluster -o yaml
----
