= Plain text packet capture for OpenSSL encrypted traffic

[role="_abstract"]
The Network Observability CLI packet capture feature can intercept and display the unencrypted content of OpenSSL-encrypted network traffic.

This feature helps you debug encrypted connections when you need to inspect payload data that would otherwise be unreadable.

The CLI uses eBPF probes to intercept OpenSSL library functions before encryption and after decryption, capturing the plain text content without requiring TLS certificates or keys.

This is a CLI-only feature that requires no Operator or agent configuration.

This capability is particularly valuable for the following tasks:

* Debugging application-level protocol issues in OpenSSL-encrypted traffic.
* Verifying API request and response payloads between services.
* Analyzing encrypted traffic content without disabling TLS.
* Troubleshooting encrypted connections where you lack access to certificates.

[NOTE]
====
Plain text capture currently supports OpenSSL encrypted traffic only. The feature works with the `oc netobserv packets` subcommand for packet-level capture, not with flow-level capture.
====

[id="how-plain-text-capture-works_{context}"]
== How plain text capture works

When you enable plain text capture during packet capture, the following actions occur:

. The CLI attaches eBPF probes to OpenSSL library functions in the target process.
. The probes intercept data before encryption (for outgoing traffic) and after decryption (for incoming traffic).
. Plain text content is captured and displayed alongside standard packet information.
. You can filter captures by pod IP, port, or other criteria to focus on specific traffic.

[id=key-considerations_{context}]
== Key considerations

When using plain text capture, consider the following conditions:

Privileged access:: The CLI requires sufficient permissions to attach eBPF probes to running processes. You must have cluster-admin privileges or equivalent access.
OpenSSL only:: The feature captures plain text from applications that use dynamically linked `OpenSSL` or `libssl` only. Applications that use static `OpenSSL` or other TLS libraries are not supported.
Packet capture only:: Plain text capture works with `oc netobserv packets` for packet-level data, not with `oc netobserv flows` for flow-level aggregation.
Performance impact:: eBPF probes have minimal performance impact, but capturing large volumes of plain text data can consume additional resources. Use filters to limit capture scope in production environments.
Security and compliance:: Captured plain text data can contain sensitive information such as passwords, API keys, or personal data. Ensure appropriate access controls and retention policies are in place.
