= Supported architectures

[role="_abstract"]
{zero-trust-full} supports {product-title} clusters that use AMD64 or ARM64 nodes. Confirm that the cluster nodes use a supported architecture before you install the Operator.

You must use the same installation and configuration procedures on ARM64 nodes as on AMD64 nodes.

{zero-trust-full} supports the following architectures:

* AMD64 (`x86_64`)
* ARM64 (`aarch64`), including Amazon Web Services (AWS) Graviton

[NOTE]
====
You must use {zero-trust-full} 1.2 or later for ARM64 support, including AWS Graviton.
====
