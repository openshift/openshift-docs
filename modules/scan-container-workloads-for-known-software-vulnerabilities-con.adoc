= Scan container workloads for known software vulnerabilities

[role="_abstract"]
Using the {rhq-cso}, you can view vulnerability scan results for the container images used by active pods directly in the {product-title} web console. Scanning running workloads lets you identify and remediate flawed dependencies before they become a risk in production.
