= Configure agents

[role="_abstract"]
An `Agent` custom resource handles each step of an `AgenticRun` workflow: analysis, execution, and verification. Configure which agent handles each step in the `alerts-adapter-config` ConfigMap under the `agent` key:

`agent.default`:: The agent name to use for all three workflow steps.
`agent.analysis`, `agent.execution`, `agent.verification`:: Override the agent for a specific step. A per-step value takes precedence over `agent.default`.

If you omit the `agent` key entirely, the adapter uses `default` for every step. The specified name must match an existing `Agent` custom resource in the cluster.

The following example configures a specialized agent for the execution step and uses the default agent for the remaining steps:

[source,yaml]
----
agent:
  default: "default"
  execution: "execution-agent"
----
