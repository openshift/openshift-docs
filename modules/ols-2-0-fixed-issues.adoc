= Fixed issues

[role="_abstract"]
{ols-official} 2.0 resolves a known issue from version 1.1.5 where tool-result inspection could fail at the tool call step for certain models.

{ols-official} 2.0 fixes the following issues:

* Before this update, tool-result inspection failed during the tool call step for certain models across supported providers, which prevented the tool call from completing successfully. With this update, tool-result inspection completes reliably during the tool call step, and tool calls finish successfully.

* Before this update, an issue with the temperature parameter for OpenAI models caused unexpected model responses. With this update, the temperature parameter is processed correctly for OpenAI providers.

* Before this update, an incorrect build path for the Bring Your Own (BYO) Knowledge tool caused builds to fail. With this update, the BYO Knowledge build path aligns with the documentation, and builds complete successfully.
