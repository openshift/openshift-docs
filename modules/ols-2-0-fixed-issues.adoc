= Fixed issues

[role="_abstract"]
{ols-official} 2.0 resolves a known issue from version 1.1.5 where tool-result inspection could fail at the tool call step for certain models.

{ols-official} 2.0 fixes the following issues:

* Previously, tool-result inspection might fail at the tool call step for certain models across the supported providers, which prevented the tool call from completing successfully. With this update, tool-result inspection no longer fails at the tool call step, and tool calls complete as expected.
