= Install the OpenShift Mirror Console

[role="_abstract"]
To build image sets and start mirror operations from a web interface, run the published OpenShift Mirror Console container image with Podman.

.Prerequisites

* You have installed Podman.
* You have credentials for `registry.redhat.io`.

.Procedure

. Log in to `registry.redhat.io` by running the following command:
+
[source,terminal]
----
$ podman login registry.redhat.io
----
+
[NOTE]
====
This login lets Podman pull the console image. It does not configure registry authentication in the console.
====

. Start the OpenShift Mirror Console container by running the following command:
+
[source,terminal]
----
$ podman run -p 8080:8080 -p 3001:3001 registry.redhat.io/mirror-gui/mirror-gui-rhel9:latest
----
+
The command runs in the foreground. To run other commands, open a new terminal window.
+
[WARNING]
====
This command does not mount any host directories. The console stores pull secrets, saved `ImageSetConfiguration` files, mirrored content, cache, operation history, and logs inside the container.

If you remove or recreate the container, you lose this data. Stopping and restarting the same container keeps the data.

To keep your data when you replace the container or upgrade the image, configure persistent storage. For more information, see "Deploy the OpenShift Mirror Console with persistent storage".
====

. In a web browser, go to `http://localhost:3001`.

.Verification

. Confirm that the OpenShift Mirror Console dashboard loads in the browser and that you can open *Settings*. For more information, see "OpenShift Mirror Console dashboard".

. Confirm that *OC Mirror Version* shows the installed oc-mirror version, for example, `2.0.0`.
