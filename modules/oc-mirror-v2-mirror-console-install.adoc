= Install the OpenShift Mirror Console

[role="_abstract"]
To prepare mirrored content for disconnected environments, install the OpenShift Mirror Console. The local web interface supports building image sets and starting mirror operations with oc-mirror plugin v2.

.Prerequisites

* You have a pull secret from the {hybrid-console} or credentials for `registry.redhat.io`.
* You have installed Podman. Docker is not supported.
* You have installed the following software:
** {oc-first}
** `jq`
** Python 3
** PyYAML

.Procedure

. Clone the OpenShift Mirror Console repository by running the following command:
+
[source,terminal]
----
$ git clone https://github.com/openshift/mirror-gui.git
----
+
The repository and the container use the name `mirror-gui`, so the command creates a `mirror-gui` directory.

. Change to the project directory by running the following command:
+
[source,terminal]
----
$ cd mirror-gui
----

. Give the build script access to `registry.redhat.io` by using one of the following methods. The script fetches catalogs from this registry during the build.

.. Save the downloaded `pull-secret.json` file in the `pull-secret` directory.

.. If the pull secret is not in that location, log in to the registry from the host by running the following command:
+
[source,terminal]
----
$ podman login registry.redhat.io
----

. Build and run the OpenShift Mirror Console locally by running the following command:
+
[source,terminal]
----
$ ./local-build.sh
----
+
The script fetches catalogs from `registry.redhat.io`, builds the container image, starts the container, and displays the URL for the console.
+
The default port is 3000. If port 3000 is busy, the script selects another port.

. Optional: To use a specific port, run the script with the `WEB_PORT` environment variable set, as in the following example:
+
[source,terminal]
----
$ WEB_PORT=8080 ./local-build.sh
----

. Optional: To build the image without starting the container, run the following command:
+
[source,terminal]
----
$ ./local-build.sh --build
----

. Optional: To run a previously built image without rebuilding or fetching catalogs, run the following command:
+
[source,terminal]
----
$ ./local-build.sh --run
----

. If the script started the container, go to the URL that the script displays in a web browser.

.Verification

. Confirm that the OpenShift Mirror Console dashboard loads in the browser and that you can open *Settings*. For more information, see "OpenShift Mirror Console dashboard".

. Confirm that *OC Mirror Version* shows the installed oc-mirror version, for example, `4.22.0`.

. After you configure a pull secret, confirm that the `No pull secret detected` warning no longer appears on the dashboard.
