= Install the OpenShift Mirror Console

[role="_abstract"]
Install the OpenShift Mirror Console on an administrator workstation so you can open the web UI in a browser. Clone the repository and run the local build script to fetch catalogs, build the container image, and start the container.

.Prerequisites

* You have a Red Hat pull secret from the link:https://console.redhat.com[console.redhat.com].

.Procedure

. Clone the OpenShift Mirror Console repository by running the following command:
+
[source,terminal]
----
$ git clone https://github.com/openshift/mirror-gui.git
----

. Change to the project directory by running the following command:
+
[source,terminal]
----
$ cd mirror-gui
----

. Build and run the OpenShift Mirror Console locally by running the following command:
+
[source,terminal]
----
$ ./local-build.sh
----
+
The script fetches catalogs, builds the container image, and starts the container.
+
Optional: To build the image without starting the container, run the following command:
+
[source,terminal]
----
$ ./local-build.sh --build
----
+
Optional: To run a previously built image without rebuilding or fetching catalogs, run the following command:
+
[source,terminal]
----
$ ./local-build.sh --run
----

. Open a web browser and go to `http://localhost:3000`.

.Verification

* Confirm that the OpenShift Mirror Console dashboard loads in the browser and that you can open *Settings* -> *Pull Secret* to upload your pull secret.
