= IPv6 single-stack and dual-stack networking support

// JIRA: ROX-10856

[role="_abstract"]
{product-title-short} is now validated on {ocp} clusters that are configured for IPv6 single-stack and dual-stack IPv4 and IPv6 networking. No additional {product-title-short} configuration is required.

You can deploy and operate {product-title-short} on IPv6-enabled clusters with full feature parity, including vulnerability scanning, policy enforcement, runtime detection, network baseline management, and compliance checks.

The following networking configurations are supported:

* IPv4 single-stack
* IPv6 single-stack
* Dual-stack IPv4 and IPv6, with either IPv4 or IPv6 as the primary address family

The following platforms are supported:

* Bare metal
* Amazon Web Services (AWS)
* Microsoft Azure

For more information, see the {product-title-short} Support Matrix (Red Hat Knowledgebase).
