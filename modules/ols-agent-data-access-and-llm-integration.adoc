= Agent data access and LLM integration

[role="_abstract"]
When you deploy autonomous troubleshooting, verify what cluster data is transmitted to the large language model (LLM) provider so that you can ensure compliance with data governance and privacy policies.

The agent collects cluster data by executing standard {k8s} command-line tools, such as `oc` and `kubectl`, directly from within the isolated execution sandbox. The gathered data types include:

* Cluster telemetry
* {k8s} resource metadata
* Prometheus alert data
* Infrastructure conditions
* Diagnostic artifacts collected during the investigation

This data is transmitted to your configured LLM provider during investigation workflows.

[IMPORTANT]
====
The use of autonomous agentic troubleshooting is subject to the acceptable use policy (AUP) of your configured LLM provider. Verify that your LLM provider configuration complies with your organization's data governance and privacy requirements.
====
