= Monitor SR-IOV and secondary network traffic

[role="_abstract"]
Configure the Network Observability Operator to monitor traffic on SR-IOV network interfaces and secondary networks attached to virtualization workloads. This enables visibility into high-performance networking paths that bypass the standard pod network.
