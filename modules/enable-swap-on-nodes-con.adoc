[id="enable-swap-on-nodes-con_{context}"]
= Enable swap on nodes

[role="_abstract"]
Swap memory is disabled by default so that pod quality of service can rely on node memory. Enable swap on worker nodes only when your workloads can tolerate running without those memory guarantees.
