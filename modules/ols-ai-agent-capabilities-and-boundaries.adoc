= AI agent capabilities and boundaries

[role="_abstract"]
When you delegate troubleshooting tasks to the agent, review its permitted, conditional, and restricted capabilities so that you can prevent unauthorized cluster modifications.

The agent performs some actions automatically, while other actions require explicit human approval.

[id="ols-autonomous-actions_{context}"]
== Autonomous actions

The agent performs the following actions without human approval:

* Subscribes to Prometheus alerts based on configured policies
* Runs investigations in response to matching alerts
* Accesses cluster data through `oc` commands
* Generates diagnoses, risk assessments, and remediation proposals

[id="ols-actions-that-require-human-approval_{context}"]
== Actions that require human approval

The following actions require explicit administrator approval through the Decision Queue:

* Executing any remediation
* Applying any changes to cluster resources

[id="ols-prohibited-actions_{context}"]
== Prohibited actions

The agent cannot perform the following actions:

* Execute remediations without administrator approval
* Access data outside the scope of the sandbox pod's dynamically assigned RBAC permissions
* Modify alert subscription policies or its own RBAC permissions
