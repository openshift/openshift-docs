= OpenShift Mirror Console dashboard

[role="_abstract"]
To check whether the environment is ready to mirror, review the dashboard status, pull secret setup, and mirror operation summary. The dashboard displays a warning when you need to take action.

[id="oc-mirror-dashboard-environment_{context}"]
== Environment

The Environment pane shows the current state of the mirror setup.

OC Mirror Version:: The version of oc-mirror currently installed, for example, `4.22.0`.

Environment Status:: The overall health of the mirroring environment. Displays one of the following statuses:
+
* *Healthy*: The environment passes all checks and is ready to mirror.
* *Low Disk Space*: The available disk space is below the warning threshold.
* *Warning*: TBD
* *Error*: TBD
* *Unknown*: TBD
+
The *Information* icon next to *Environment Status* shows these details:
+
* *Architecture*: The CPU architecture of the host, for example, `x86_64`.
* *Disk Available*: Free disk space for mirror operations, for example, `408.17 GB`.
* *Disk Total*: The total disk capacity of the host, for example, `816.34 GB`.
* *Warning Threshold*: The minimum disk space required before the console triggers a low-disk warning, for example, `30 GB`.

Pull Secret:: The status of the pull secret configuration. Displays one of the following statuses:
+
* *Present*: You have added a pull secret.
* *Missing*: You have not added a pull secret. Mirror operations stay unavailable until you add one in *Settings* -> *Pull Secret*. The dashboard also displays a `No pull secret detected` warning with a *Go to Settings* link.

[id="oc-mirror-dashboard-operation-statistics_{context}"]
== Operation statistics

The Operation Statistics pane summarizes all of the mirror operations that ran in this environment.

Total Operations:: The total number of mirror operations that the console has run.

Successful:: The number of operations that completed without errors.

Failed:: The number of operations that did not complete successfully.

Running:: The number of operations currently in progress.

[id="oc-mirror-dashboard-recent-operations_{context}"]
== Recent operations

The Recent Operations pane lists recent mirror operations and their results.

Operation:: The operation name, which is `Mirror Operation` followed by the first 8 characters of the operation ID.

Config:: The `ImageSetConfiguration` file used for the operation.

Status:: The result of the operation. Displays one of the following statuses:
+
* *Success*: The operation completed without errors.
* *Running*: The operation is in progress.
* *Failed*: The operation did not complete successfully.
* *Stopped*: You stopped the operation before it finished.

Started:: The date and time the operation began, for example, `5/1/2026, 10:21:58 PM`.

Duration:: The total time the operation ran, for example, `38s`. Displays `-` when the console has not recorded a duration, including while the operation is running.
