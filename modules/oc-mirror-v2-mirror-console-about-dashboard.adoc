= OpenShift Mirror Console dashboard

[role="_abstract"]
The OpenShift Mirror Console dashboard displays the current environment status, pull secret configuration, and a summary of mirroring operation statistics for your {product-title} mirroring environment.

[id="oc-mirror-dashboard-warning-banners_{context}"]
== Warning banners

The dashboard displays warning banners when action is required before mirroring operations can proceed.

No pull secret detected:: Indicates that no pull secret is configured. Mirroring operations are unavailable. The banner includes a *Go to Settings* link to the *Pull Secret* page.

[id="oc-mirror-dashboard-environment_{context}"]
== Environment

The *Environment* section displays the current state of your mirroring environment.

OC Mirror Version:: The version of oc-mirror currently installed, for example, `4.21.0`.

Environment Status:: The overall health of the mirroring environment. Displays one of the following statuses:
+
* *Healthy* — The environment is configured correctly and ready for mirroring operations.
* *Degraded* — One or more environment checks have failed.
+
The *Information* icon next to *Environment Status* shows the following environment details:
+
* *Architecture*: The CPU architecture of the host, for example, `x86_64`.
* *Disk Available*: The amount of disk space currently available for mirroring operations, for example, `408.17 GB`.
* *Disk Total*: The total disk capacity of the host, for example, `816.34 GB`.
* *Warning threshold*: The minimum disk space required before a low-disk warning is triggered, for example, `30 GB`.

Pull Secret:: The status of the pull secret configuration. Displays one of the following statuses:
+
* *Healthy*: A valid pull secret is configured.
* *Missing*: No pull secret has been provided. Mirroring operations are unavailable until you configure a pull secret in *Settings* -> *Pull Secret*.

[id="oc-mirror-dashboard-operation-statistics_{context}"]
== Operation Statistics

The *Operation Statistics* section displays a summary of all mirroring operations performed in this environment.

Total Operations:: The total number of mirroring operations that have been run.

Successful:: The number of operations that completed without errors.

Failed:: The number of operations that did not complete successfully.

Running:: The number of operations currently in progress.

[id="oc-mirror-dashboard-recent-operations_{context}"]
== Recent Operations

The *Recent Operations* section displays a table listing the most recently run mirroring operations and their outcomes.

Operation:: The name and configuration file of the mirroring operation. The operation name includes a unique identifier, for example, `Mirror Operation 04504fda`. The configuration file used for the operation is displayed below the operation name, for example, `gs-ci-test.yaml`.

Status:: The result of the operation. Displays one of the following statuses:
+
* *Success* — The operation completed without errors.
* *Stopped* — The operation was manually stopped before it was completed.
* *Failed* — The operation did not complete successfully.

Started:: The date and time the operation began, for example, `5/1/2026, 10:21:58 PM`.

Duration:: The total time the operation ran, for example, `38s`. Displays `-` if the operation failed before a duration could be recorded.
