= OpenShift Mirror Console dashboard

[role="_abstract"]
The OpenShift Mirror Console dashboard shows the environment status, pull secret setup, and a summary of mirror job stats. The dashboard shows whether the environment is ready to mirror and displays warnings when an action is required.

[id="oc-mirror-dashboard-environment_{context}"]
== Environment

The *Environment* section shows the current state of the mirror setup.

OC Mirror Version:: The version of oc-mirror currently installed, for example, `4.21.0`.

Environment Status:: The overall health of the mirroring environment. Displays one of the following statuses:
+
* *Healthy* — The environment is configured correctly and ready to mirror.
* *Degraded* — One or more environment checks have failed.
+
The *Information* icon next to *Environment Status* shows these details:
+
* *Architecture*: The CPU architecture of the host, for example, `x86_64`.
* *Disk Available*: Free disk space for mirror jobs, for example, `408.17 GB`.
* *Disk Total*: The total disk capacity of the host, for example, `816.34 GB`.
* *Warning threshold*: The minimum disk space required before a low-disk warning is triggered, for example, `30 GB`.

Pull Secret:: The status of the pull secret configuration. Displays one of the following statuses:
+
* *Healthy*: A valid pull secret is configured.
* *Missing*: No pull secret has been provided. Mirror jobs stay unavailable until a pull secret is set in *Settings* -> *Pull Secret*.

[id="oc-mirror-dashboard-operation-statistics_{context}"]
== Operation Statistics

The *Operation Statistics* section summarizes all of the mirror jobs that ran in this environment.

Total Operations:: The total number of mirroring operations that have been run.

Successful:: The number of operations that completed without errors.

Failed:: The number of operations that did not complete successfully.

Running:: The number of operations currently in progress.

[id="oc-mirror-dashboard-recent-operations_{context}"]
== Recent Operations

The *Recent Operations* section lists recent mirror jobs and their results.

Operation:: The operation name, which includes a unique identifier, and the `ImageSetConfiguration` file used for the mirroring operation.

Status:: The result of the operation. Displays one of the following statuses:
+
* *Success* — The operation completed without errors.
* *Stopped* — The operation was manually stopped before it was completed.
* *Failed* — The operation did not finish.

Started:: The date and time the operation began, for example, `5/1/2026, 10:21:58 PM`.

Duration:: The total time the operation ran, for example, `38s`. Displays `-` if the operation failed before a duration could be recorded.
