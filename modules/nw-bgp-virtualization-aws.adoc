= About BGP routing for OpenShift Virtualization on AWS

[role="_abstract"]
BGP Cloud Connector integrates {product-title} with {aws-first} Route Server allowing direct, routed connectivity to {VirtProductName} virtual machines (VMs) on {aws-short}.
By using the BGP Cloud Connector, you do not need Network Address Translation (NAT).

:FeatureName: BGP routing for {VirtProductName} on {aws-short}
include::snippets/technology-preview.adoc[leveloffset=+1]

When migrating VM workloads to {VirtProductName} on {aws-short}, NAT-based connectivity often requires redesigning existing network architectures, security models, and tooling. 
BGP Cloud Connector avoids this situation by using Border Gateway Protocol (BGP) peering with the {aws-short} Route Server to advertise pod and VM network routes directly into your {aws-short} VPC.

BGP Cloud Connector consists of the following two core layers:

* Cloud infrastructure layer, where the underlying {aws-short} VPC, subnets, and {aws-short} Route Server provisioned alongside your cluster.
* In-cluster Operator layer, where an Operator that manages cluster-wide and project-scoped custom resources (CRs) to reconcile your local Autonomous System Number (ASN) and BGP configuration.

The Operator automatically discovers your {aws-short} Route Server topology and establishes BGP peering sessions between designated compute nodes and local availability zone Route Server endpoints through `FRRConfiguration` CRs.

The Operator also automates the following required {aws-short}-side networking configuration:

* Managing Route Server peers dynamically as nodes scale, reboot, or undergo cluster upgrades.
* Disabling source or destination checks on primary Elastic Network Interfaces (ENIs) so BGP-enabled compute nodes can forward external traffic.

The following list details key benefits of using {aws-short} Route Server with BGP Cloud Connector:

* Direct, NAT-free routed connectivity to VM network interfaces.
* Native cloud routing integration without custom downstream implementations.
* Compatibility with standard enterprise BGP tools and multi-cloud architectures.
