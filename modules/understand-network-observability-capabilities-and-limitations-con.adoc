= Understand Network Observability capabilities and limitations

[role="_abstract"]
Network observability collects, enriches, and stores network flows so that you can see how traffic moves through the cluster. Knowing what it can do, and which `FlowCollector` options constrain a deployment, helps you decide whether to deploy it.
