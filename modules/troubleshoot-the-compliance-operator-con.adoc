= Troubleshoot the Compliance Operator

[role="_abstract"]
You can troubleshoot the Compliance Operator to diagnose a problem or provide information in a bug report. 

When troubleshooting, review Kubernetes events for the Operator, filter controller logs for the affected API object, and collect a `must-gather` archive to share diagnostic information with Red{nbsp}Hat support.
