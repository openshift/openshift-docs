= Install and configure the NUMA Resources Operator

[role="_abstract"]
To deploy high performance workloads with optimal efficiency, use NUMA-aware scheduling. This feature aligns pods with the underlying hardware topology in your {product-title} cluster, which minimizes latency and maximizes resource utilization.
