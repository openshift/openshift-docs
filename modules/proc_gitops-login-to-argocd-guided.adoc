= Log in to Argo CD

[role="_abstract"]
Log in to the Argo CD web console to create and manage applications. You can access Argo CD through the {OCP} web console or by navigating directly to the Argo CD route.

.Prerequisites

* You have installed the {gitops-title} Operator.
* You have the `cluster-admin` role or sufficient permissions to access the `openshift-gitops` namespace.

.Procedure

. Access the Argo CD web console:
+
** *Option 1: From the {OCP} web console*
+
... Log in to the {OCP} web console.
... Click the application launcher icon (grid icon) in the top navigation bar.
... Select *Cluster Argo CD* from the list.
+
The Argo CD login page opens in a new tab.
+
** *Option 2: Direct URL access*
+
... Get the Argo CD server URL:
+
[source,terminal]
----
$ oc get route openshift-gitops-server -n openshift-gitops -o jsonpath='{.status.ingress[0].host}{"\n"}'
----
+
... Navigate to the URL in your web browser: `https://<route_url>`

. Get the admin password:
+
[source,terminal]
----
$ oc get secret openshift-gitops-cluster -n openshift-gitops -o jsonpath='{.data.admin\.password}' | base64 -d ; echo
----

. Log in to Argo CD:
+
** *Username*: `admin`
** *Password*: Paste the password from step 2

. Optional: Enable SSO login for your organization:
+
If you prefer to use {OCP} credentials or an external identity provider, configure SSO authentication instead of the default admin credentials. See the Additional resources for SSO configuration details.

.Verification

After logging in, the Argo CD dashboard displays showing:

* Application tiles for any deployed applications
* Cluster health and connection status
* Repository connections

[NOTE]
====
The default admin password is generated automatically during installation. For production environments, consider configuring SSO authentication or creating additional local users with limited permissions.
====
