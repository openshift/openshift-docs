= Creating an application by using the `oc` tool

[role="_abstract"]
You can create Argo CD applications in your terminal by using the `oc` tool.

.Prerequisites

* You have installed the {gitops-title} Operator on your {OCP} cluster.
* You have logged in to an Argo CD instance.
* You have access to the `oc` CLI tool.

.Procedure

. Download link:https://github.com/redhat-developer/openshift-gitops-getting-started[the sample application]:
+
[source,terminal]
----
$ git clone git@github.com:redhat-developer/openshift-gitops-getting-started.git
----

. Create and configure the destination namespace:
+
[source,terminal]
----
$ oc create namespace spring-petclinic
----
+
[source,terminal]
----
$ oc label namespace spring-petclinic argocd.argoproj.io/managed-by=openshift-gitops
----

. Create the application:
ifdef::app[]
+
[source,terminal]
----
$ oc create -f openshift-gitops-getting-started/argo/app.yaml
----
endif::app[]

ifdef::cluster[]
+
[source,terminal]
----
$ oc create -f openshift-gitops-getting-started/argo/cluster.yaml
----
endif::cluster[]

. Run the `oc get` command to review the created application:
+
[source,terminal]
----
$ oc get application -n openshift-gitops
----

.Cleanup (optional)

To delete the application and namespace after you are done:

. Delete the application:
ifdef::app[]
+
[source,terminal]
----
$ oc delete -n openshift-gitops -f openshift-gitops-getting-started/argo/app.yaml
----
endif::app[]
ifdef::cluster[]
+
[source,terminal]
----
$ oc delete -n openshift-gitops -f openshift-gitops-getting-started/argo/cluster.yaml
----
endif::cluster[]

. Delete the namespace:
+
[source,terminal]
----
$ oc delete namespace spring-petclinic
----
