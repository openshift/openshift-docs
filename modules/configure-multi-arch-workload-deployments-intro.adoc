= Configure multi-architecture node workload deployments

[role="_abstract"]
When you need fine-grained control over pod placement in multi-architecture clusters, you can configure `nodeAffinity`, taints, tolerations, and namespace annotations. Configuring these settings lets you implement custom scheduling policies for different workload types.
