= Embed applications in a {op-system-ostree} image

[role="_abstract"]
You can embed microservices-based workloads and applications in a {op-system-ostree-first} image to run in a {microshift-short} node. Embedded applications can be installed directly on edge devices to run in disconnected or offline environments.

You can embed applications in a {op-system-ostree} image using one of the following methods:

* Build your own RPM that includes your application manifests, add the RPM to your {op-system-ostree} blueprint, and create a bootable ISO.
* Embed workload container images directly into the {op-system-ostree} image for fully offline, air-gapped deployments.
