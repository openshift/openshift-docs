= Enable stream-based retention with Loki

[role="_abstract"]
You can configure retention policies based on log streams. You can set retention rules globally, per-tenant, or both. If you configure both, tenant rules apply before global rules.

include::snippets/logging-retention-period-snip.adoc[]

[NOTE]
====
* Although logging version 5.9 and later supports schema `v12`, schema `v13` is recommended for future compatibility.

* You can configure retention in Loki, in object storage, or both:
+
** **Loki retention (primary)**: Configure `spec.limits` to manage retention within Loki. The compactor removes index references and subsequently deletes the corresponding chunks from object storage. The maximum supported retention period is 30 days.
+
** **Object storage lifecycle policies (safety net)**: Configure lifecycle deletion on your object storage provider as a safety net against orphaned chunks. Set the lifecycle expiration longer than your Loki retention period plus the compactor deletion delay to avoid deleting chunks that Loki still references. Lifecycle deletion is not index-aware and can cause data loss if it runs before the compactor has processed the chunks.
+
For guidance on setting lifecycle expiration relative to Loki retention, see the link:https://grafana.com/docs/loki/latest/operations/storage/retention/#compactor-retention-versus-object-store-lifecycle-policies[Grafana Loki documentation on compactor retention versus object store lifecycle policies].
====

.Prerequisites 

* You have administrator permissions.
* You have installed the {loki-op}.
* You have installed the {oc-first}.

.Procedure

. To enable stream-based retention, create a `LokiStack` CR and save it as a YAML file. In the following example, it is called `lokistack.yaml`.
+
--
The following example shows global stream-based retention for S3:
+
[source,yaml]
----
apiVersion: loki.grafana.com/v1
kind: LokiStack
metadata:
  name: logging-loki
  namespace: openshift-logging
spec:
  limits:
   global:
      retention:
        days: 20
        streams:
        - days: 4
          priority: 1
          selector: '{kubernetes_namespace_name=~"test.+"}'
        - days: 1
          priority: 1
          selector: '{log_type="infrastructure"}'
  managementState: Managed
  replicationFactor: 1
  size: 1x.small
  storage:
    schemas:
    - effectiveDate: "2020-10-11"
      version: v13
    secret:
      name: logging-loki-s3
      type: s3
  storageClassName: gp3-csi
  tenants:
    mode: openshift-logging
----

spec.limits.global::
  Set the retention policy for all log streams. The compactor enforces this policy by removing index references and deleting the corresponding chunks from object storage.

spec.limits.global.retention::
  Enable retention in the cluster by adding the `retention` block to the CR.

spec.limits.global.retention.streams.selector::
  Specify the link:https://grafana.com/docs/loki/latest/logql/query_examples/#query-examples[LogQL query] to match log streams to the retention rule.
--
+
.Example per-tenant stream-based retention for S3
[source,yaml]
----
apiVersion: loki.grafana.com/v1
kind: LokiStack
metadata:
  name: logging-loki
  namespace: openshift-logging
spec:
  limits:
    global:
      retention:
        days: 20
    tenants:
      application:
        retention:
          days: 1
          streams:
            - days: 4
              selector: '{kubernetes_namespace_name=~"test.+"}'
      infrastructure:
        retention:
          days: 5
          streams:
            - days: 1
              selector: '{kubernetes_namespace_name=~"openshift-cluster.+"}'
  managementState: Managed
  replicationFactor: 1
  size: 1x.small
  storage:
    schemas:
    - effectiveDate: "2020-10-11"
      version: v13
    secret:
      name: logging-loki-s3
      type: s3
  storageClassName: gp3-csi
  tenants:
    mode: openshift-logging
----

spec.limits.tenants::
  Set the retention policy per-tenant. Valid tenant types are `application`, `audit`, and `infrastructure`.

spec.limits.tenants.application.retention.streams.selector::
  Specify the link:https://grafana.com/docs/loki/latest/logql/query_examples/#query-examples[LogQL query] to match log streams to the retention rule.

. Apply the `LokiStack` CR:
+
[source,terminal]
----
$ oc apply -f lokistack.yaml
----
