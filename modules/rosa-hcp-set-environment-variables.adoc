= Setting environment variables for cluster creation

[role="_abstract"]
You can set environment variables to streamline resource creation for your {product-title} cluster.

.Procedure

* Set your environment variable by running the following command:
+
[source,terminal]
----
$ export <variable_name>=<variable_value>
----

.Verification

* You can confirm that your variable has been set by running the following command:
+
[source,terminal]
----
$ echo <variable_name>
----
