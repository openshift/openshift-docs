= Update cluster configuration with the O-Cloud Manager

[role="_abstract"]
After a cluster is provisioned, you can apply configuration changes, update firmware, and modify cluster metadata by updating the `ProvisioningRequest` custom resource (CR) or creating a new `ClusterTemplate` CR version. The O-Cloud Manager orchestrates the Day 2 operations.

You can perform these operations by editing the `ProvisioningRequest` CR directly or through the Provisioning REST API.

The O-Cloud Manager is a Technology Preview feature only.
