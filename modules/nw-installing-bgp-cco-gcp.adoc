= Installing the BGP Cloud Connector Operator on Google Cloud

[role="_abstract"]
You can install the BGP Cloud Connector Operator on an {product-title} cluster by using either the {oc-first} or the web console.
After you install the Operator, you can deploy the Operator through the {olm-first}.

.Prerequisites

* If using CLI method, you installed the {oc-first}.
* You logged in as a user with `cluster-admin` privileges.

.Procedure

. To install the BGP Cloud Connector Operator by using the {oc-first}, complete the following steps:
+
.. Create a dedicated namespace and an `OperatorGroup` manifest file for the BGP Cloud Connector Operator by entering the following command:
+
[source,terminal]
----
$ oc create namespace bgp-cloud-connector
----
+
.. Create an `OperatorGroup` manifest file in the dedicated namespace by entering the following command:
+
[source,terminal]
----
$ echo '{"apiVersion":"operators.coreos.com/v1","kind":"OperatorGroup","metadata":{"name":"bgp-cloud-connector-operatorgroup","namespace":"bgp-cloud-connector"}, "spec":{"targetNamespaces":["bgp-cloud-connector"]}}' | oc apply -f -
----
+
.. Configure {gcp-short} authentication for the Operator based on the credential mode of your cluster. The Cloud Credential Operator (CCO) automatically manages {gcp-short} credentials for the Operator based on the credential mode of your cluster.
+
* Mint mode: No manual credential setup is required.
CCO automatically creates a service account with the necessary permissions and populates the required secret in the namespace of the Operator.
* Manual mode with Workload Identity Federation: Pass the project number, the Workload Identity Federation pool ID and provider ID, and the service account email to the Operator by using environment variables. CCO updates the `CredentialsRequest` and provisions a secret containing the federated credential.
+
If you are deploying the Operator manually through a `Subscription` CR, set the environment variables in your manifest:
+
[source,yaml]
----
apiVersion: operators.coreos.com/v1alpha1
kind: Subscription
metadata:
  name: bgp-cloud-connector-operator
  namespace: bgp-cloud-connector
spec:
  channel: stable
  name: bgp-cloud-connector
  source: redhat-operators
  sourceNamespace: openshift-marketplace
  config:
    env:
      - name: PROJECT_NUMBER
        value: "<project_number>"
      - name: POOL_ID
        value: <pool_id>
      - name: PROVIDER_ID
        value: <provider_id>
      - name: SERVICE_ACCOUNT_EMAIL
        value: <service_account_email>
----
+
where:
+
--
`PROJECT_NUMBER`:: Specifies the project number of the {gcp-short} project that hosts the cluster.
Do not specify the project ID in this variable.
`POOL_ID`:: Specifies the ID of the Workload Identity Federation pool that the `ccoctl` utility created for your cluster.
`PROVIDER_ID`:: Specifies the ID of the Workload Identity Federation provider that the `ccoctl` utility created for your cluster.
`SERVICE_ACCOUNT_EMAIL`:: Specifies the email address of the {gcp-short} service account that you created while preparing the {gcp-short} environment.
--
+
[NOTE]
====
All four environment variables are required.
If any variable is missing, or if `PROJECT_NUMBER` contains a project ID instead of a project number, the Operator cannot request credentials from the CCO.

If you install the Operator by using the web console, the console automatically prompts you for the *Project Number*, *Pool ID*, *Provider ID*, and *Service Account Email* and then populates the variables for you.

You must create the service account and the Workload Identity Federation binding in {gcp-short} before you set these variables.
The Operator cannot generate its own service account.

Changing these variables requires a new Operator pod.
Changes to the `Subscription` CR roll the deployment of the Operator automatically.
====
+
.. Verify that the Operator installation succeeded by entering the following command:
+
[source,terminal]
----
$ oc get csv -n bgp-cloud-connector
----
+
Confirm that the `PHASE` column displays `Succeeded`.

. To install BGP Cloud Connector Operator by using the web console, complete the following steps:
+
.. Log in to the web console as a cluster administrator.
+
.. Go to *Ecosystem* > *Software Catalog*
+
.. Search for `BGP cloud connector`.
+
.. Click the *Install* button.
+
.. Select `bgp-cloud-connector` as the namespace.
+
.. Click the *Install* button.
