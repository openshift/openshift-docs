= TLS policy

[role="_abstract"]

One TLS policy applies to the Kiali server and to every outbound client {KialiServer} opens, including Prometheus, tracing, and login. On {ocp-product-title} the policy defaults to the cluster TLS security profile.

[source,yaml]
----
spec:
  deployment:
    tls_config:
      source: auto
----

`source: auto` reads `TLSSecurityProfile` from `APIServer/cluster`. Restart the Kiali pod after the cluster profile changes. The policy is read once at startup.

Set `source: config` when you need a fixed minimum version. TLS 1.0 and TLS 1.1 are rejected and the server does not start. `cipher_suites` applies to TLS 1.2 only. `groups` applies to TLS 1.2 and TLS 1.3.

[source,yaml]
----
spec:
  deployment:
    tls_config:
      source: config
      min_version: TLSv1.2
      max_version: TLSv1.3
      cipher_suites:
      - ECDHE-RSA-AES128-GCM-SHA256
      - ECDHE-ECDSA-AES128-GCM-SHA256
      groups:
      - X25519
      - secp256r1
----

`insecure_skip_verify` on an external service skips certificate checks for that service. It does not relax the TLS version, cipher, or group policy. The startup log records the policy source, the version range, and how many ciphers and groups were accepted.
