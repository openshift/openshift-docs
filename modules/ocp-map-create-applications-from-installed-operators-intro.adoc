= Create applications from Operators installed with {olmv0}

[role="_abstract"]
You can deploy applications on your {product-title} cluster from Operators that a cluster administrator installed. Use the *Installed Operators* page in the web console to create an application from an Operator custom resource (CR) API, such as an etcd cluster.
