= Set up RHACS Cloud Service with Red Hat OpenShift secured clusters

[role="_abstract"]
To protect {osp} clusters with {rh-rhacscs-first}, create a cloud instance, generate cluster registration credentials, and deploy secured cluster services. Complete this setup by using the {product-title-short} Operator, Helm charts, or the roxctl CLI, depending on your organization's deployment workflow.
