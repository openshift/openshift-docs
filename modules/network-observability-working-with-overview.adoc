= Work with the Overview view

[role="_abstract"]
Navigate to the network traffic *Overview* view in the {product-title} console to visualize flow rate statistics and customize the display scope for monitoring cluster network activity.

.Prerequisite
* Access to the cluster with administrator rights.

.Procedure
. Navigate to *Observe* → *Network Traffic*.
. In the *Network Traffic* page, click the *Overview* tab.
. Optional: When analyzing specific network features, select a preconfigured feature view from the view selector to instantly display feature-specific panels and columns:
** *All Traffic* - Default view showing all network traffic
** *DNS* - Preconfigured view for DNS tracking metrics (when DNS tracking is enabled)
** *TLS* - Preconfigured view for TLS monitoring metrics (when TLS tracking is enabled)
** *Packet Drops* - Preconfigured view for packet drop analysis (when packet drop tracking is enabled)
** *RTT* - Preconfigured view for round-trip time (RTT) metrics (when RTT tracking is enabled)
** *Network Events* - Preconfigured view for network events (when network events are enabled)
+
[NOTE]
====
Feature views reduce the number of clicks needed to access feature-specific data. When you change columns or panels in a feature view, the view name changes to *Custom*. To restore the preconfigured view, click *Restore defaults* in the *Manage columns* or *Manage panels* dialog.
====
. Click the menu icon to configure the scope of each flow rate data.
