= Work with the Overview view

[role="_abstract"]
Navigate to the network traffic *Overview* view in the {product-title} console to visualize flow rate statistics and customize the display scope for monitoring cluster network activity.

.Prerequisite
* Access to the cluster with administrator rights.

.Procedure
. Navigate to *Observe* → *Network Traffic*.
. In the *Network Traffic* page, click the *Overview* tab.
. Click the menu icon to configure the scope of each flow rate data.
