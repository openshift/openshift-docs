= Optimize build performance

[role="_abstract"]
You can optimize build performance by configuring resource limits for CPU and memory allocations. Resource limits control how much compute and memory each build step can consume, helping to balance build speed with cluster resource availability.

By setting appropriate resource limits, you can:

* Prevent builds from consuming excessive cluster resources
* Ensure predictable build execution times
* Improve overall build throughput by efficiently allocating resources
* Avoid resource contention between concurrent builds

Configure resource limits at the build configuration level for consistent behavior across all build runs, or override them for specific build runs when you need temporary adjustments for testing or troubleshooting.
