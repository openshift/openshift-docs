= Focus mesh resources on specific namespaces

[role="_abstract"]

By default, the mesh control plane discovers workloads in all namespaces across a cluster. Each proxy receives configuration for every namespace, including workloads not enrolled in the mesh.

Use discovery selectors to limit the mesh to specific namespaces. This reduces unnecessary processing and is especially useful when running many service meshes in the same cluster.
