= Using {pac} with a Git repository hosting service provider
:context: using-pipelines-as-code-repos

toc::[]
[role="_abstract"]
After installing {pac}, cluster administrators can configure a Git repository hosting service provider.

The following services are supported:

* GitHub App
* GitHub Webhook
* GitLab
* Bitbucket Data Center
* Bitbucket Cloud

[NOTE]
====
GitHub App is the recommended service for using with {pac}.
====
