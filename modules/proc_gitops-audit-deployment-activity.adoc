= Audit deployment activity

[role="_abstract"]
Audit deployment activity by reviewing Argo CD application events, synchronization history, and resource changes. This helps you track who deployed what, when changes occurred, and troubleshoot deployment issues.

.Prerequisites

* You have access to an Argo CD instance.
* You have the necessary permissions to view application details.

.Procedure

. View application synchronization history in the web console:
+
.. Log in to the Argo CD web console.
.. Click an application to view its details.
.. Click the *HISTORY AND ROLLBACK* tab.
+
The history displays all synchronization events, including:
+
* Sync status (succeeded or failed)
* Revision (Git commit SHA)
* Timestamp
* User who initiated the sync
* Sync source (manual, automated, or webhook)

. View detailed event logs:
+
.. In the application details view, click the *EVENTS* tab.
.. Review resource-level events showing creation, updates, deletions, and errors.

. View deployment activity using the CLI:
+
[source,terminal]
----
$ argocd app get <application_name> --show-operation
----
+
Replace `<application_name>` with your application name.
+
*Example output:*
[source,terminal]
----
Name:               spring-petclinic
Sync Status:        Synced
Health Status:      Healthy
Last Sync:          2024-11-13 10:30:00 UTC
Initiated By:       admin
Revision:           abc123def456
----

. Review synchronization audit logs in the Argo CD server logs:
+
[source,terminal]
----
$ oc logs -n openshift-gitops deployment/openshift-gitops-server | grep -i sync
----

. Optional: Export audit data for compliance:
+
[source,terminal]
----
$ argocd app history <application_name> --output json > app-audit-$(date +%Y%m%d).json
----

.Verification

The synchronization history displays all deployment events with timestamps, user information, and Git revisions, providing a complete audit trail.

[TIP]
====
Configure notification webhooks to send deployment events to external logging or SIEM systems for centralized audit tracking. See xref:../observe/monitor-application-health-and-configure-alerts.adoc#monitor-application-health-and-configure-alerts[Monitor application health and configure alerts].
====
