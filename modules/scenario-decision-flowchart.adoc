= Decision flowchart

Use this flowchart to narrow your scenario choice:

. *Do you need local log storage?*
* No → *Scenario 1* (Vector only)
* Yes → Continue to step 2

. *Can you provision object storage (S3/GCS/Azure Blob)?*
* No → *Scenario 1* (Vector only - cannot use Loki without object storage)
* Yes → Continue to step 3

. *Do you need to query logs in the OpenShift web console?*
* No → *Scenario 2* (Vector + Loki, query with Grafana or CLI)
* Yes → *Scenario 3* (Vector + Loki + COO)

. *Verify resource availability:*
* Scenario 1: ~100m CPU, ~256 MiB memory per node (Vector only)
* Scenario 2: Add ~5-40 vCPUs, ~10-75 GiB memory (depends on Loki size)
* Scenario 3: Add ~500m CPU, ~1 GiB memory more than Scenario 2 (for COO)
