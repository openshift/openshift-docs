= Install the {vcf-migration-operator} from the web console

[role="_abstract"]
You can install the {vcf-migration-operator} from the software catalog in the {product-title} web console.

// Release review: Validate this procedure against the released catalog. The current bundle uses dev-preview and supports only AllNamespaces. Catalog publication and the final channel are not confirmed.

.Prerequisites

* You have access to the web console with `cluster-admin` privileges.
* A catalog that contains the {vcf-migration-operator} is available on the cluster.

.Procedure

. In the web console, navigate to *Ecosystem* -> *Software Catalog*.
. Search for and select *{vcf-migration-operator}*, and select *Install*.
. On the installation page, configure the following settings:
+
* Select the update channel for the Operator version that you want to install.
* Set *Installation mode* to *All namespaces on the cluster*.
* Set *Installed Namespace* to `openshift-vcf-migration`. Create this namespace if it does not exist.
* Select an update approval strategy. If you select *Manual*, approve the installation plan when prompted.

. Select *Install*.

.Verification

* Navigate to *Ecosystem* -> *Installed Operators*, and verify that the {vcf-migration-operator} has a status of *Succeeded* in the `openshift-vcf-migration` namespace.
