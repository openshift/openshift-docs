= Install the OpenShift CLI by downloading the binary from the web console

[role="_abstract"]
You can download the {oc-first} from the web {product-title} console and install it to interact with {product-title} clusters from a terminal on Linux, Windows, or macOS.

[IMPORTANT]
====
If you installed an earlier version of `oc`, you cannot use it to complete all
of the commands in
[.pr:microshift .pr:openshift-dedicated .pr:openshift-enterprise .pr:openshift-origin]#{empty}# {product-title} {product-version}.
[.pr:openshift-rosa .pr:openshift-rosa-hcp]#{empty}# {product-title}.
Download and
install the new version of `oc`.
If you are upgrading a cluster in a restricted network, install the `oc` version that you plan to upgrade to.
====
