= Adding custom fields to workflow MDC

[role="_abstract"]
You can extend the default workflow MDC with additional fields by implementing the `MDCPopulator` interface and registering it as a Java service. Custom fields are added alongside the default workflow context fields for each workflow instance.

.Procedure

. Create a class that implements `org.jbpm.process.instance.MDCPopulator`:
+
[source,java]
----
package com.example;

import java.util.Map;
import org.jbpm.process.instance.MDCPopulator;
import org.jbpm.process.instance.ProcessInstance;

public class CustomMDCPopulator implements MDCPopulator {

    @Override
    public Map<String, String> info2Add(ProcessInstance processInstance) {
        return Map.of("<custom_field_name>", "<custom_field_value>");
    }
}
----
+
where:
+
`<custom_field_name>`:: The MDC key to add to the log output.
`<custom_field_value>`:: The value for the MDC key.
+
The method receives the current `ProcessInstance` and returns a map of additional MDC key-value pairs. Return only the fields you want to add; the default workflow context fields are added automatically.

. Register the implementation by creating the file `src/main/resources/META-INF/services/org.jbpm.process.instance.MDCPopulator` with the fully qualified class name of your implementation:
+
[source,text]
----
com.example.CustomMDCPopulator
----

. To include the custom MDC keys in log output, add the following configuration to `application.properties`:
+
[source,properties]
----
quarkus.log.console.format=%d{yyyy-MM-dd HH:mm:ss,SSS} %-5p [%c{3.}] (%t) [%X{processId}/%X{instanceId}/%X{<custom_field_name>}] %s%e%n
----

.Verification

Start a workflow instance and inspect the console log output. Each log line includes both the default workflow context fields and your custom fields.
