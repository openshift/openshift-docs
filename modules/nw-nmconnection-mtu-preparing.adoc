= Updating MTU in existing nmconnection files

[role="_abstract"]
If your hardware MTU is already specified in an existing `NetworkManager` connection file (`.nmconnection`), you must update the MTU value directly in that file by using a `MachineConfig` manifest file. 

.Prerequisites

* You installed the {oc-first}.
* You have access to the cluster as a user with the `cluster-admin` role.

.Procedure

. Log in to the node by entering the following command:
+
[source,terminal]
----
$ oc debug node/<node_name>
----
+
Replace `<node_name>` with the name of your node.

. Identify the active primary device by running the following command:
+
[source,terminal]
----
sh-5.1# device_name="br-ex"
----

. Get the `NetworkManager` connection profile name by running the following command:
+
[source,terminal]
----
sh-5.1# connection_name=$(nmcli -g GENERAL.CONNECTION dev show "$device_name")
----
+
.Example output
[source,text]
----
sh-5.1# echo "$connection_name"
infra-bond.120
----

. Find the `.nmconnection` file path for the primary network interface by running the command:
+
[source,terminal]
----
sh-5.1# connection_file=$(nmcli -f NAME,FILENAME c show | awk -v name="$connection_name" '$1==name {print $2}')
----
+
.Example output
[source,text]
----
sh-5.1# echo "$connection_file"
/etc/NetworkManager/system-connections/infra-bond.120.nmconnection
----

. Create a script, such as `change-mtu.sh`, with the following information:
+
[source,bash]
----
#!/bin/bash
set -exuo pipefail
 
MTU_VALUE=""
CONNECTION_NAME=""
CONN_FILE=""
TEMP_FILE=$(mktemp /tmp/${CONNECTION_NAME}.XXXXXXXXXX.nmconnection.tmp)

sudo cat "$CONN_FILE" | sudo nmcli --offline c mod ethernet.mtu $MTU_VALUE > "$TEMP_FILE"

sudo mv "$TEMP_FILE" "$CONN_FILE"

sudo restorecon -v "$CONN_FILE"

sudo chmod 600 "$CONN_FILE"
sudo chown root:root "$CONN_FILE"

exit 0
----

. Set values for `MTU_VALUE`, `CONNECTION_NAME`, and `CONN_FILE` shell variables in the script. The following example shows example values:
+
[source,bash]
----
# ...
MTU_VALUE="9100"
CONNECTION_NAME="infra-bond.120"
CONN_FILE="/etc/NetworkManager/system-connections/infra-bond.120.nmconnection"
# ...
----
