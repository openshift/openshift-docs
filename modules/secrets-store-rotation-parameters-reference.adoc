= Secret rotation configuration parameters

[role="_abstract"]
You can configure secret rotation behavior for the {secrets-store-operator} by setting parameters in the `secretRotation` section under `spec.driverConfig.secretsStore` of the `ClusterCSIDriver` custom resource.

The following table describes the parameters available for configuring secret rotation:

.Secret rotation configuration parameters
[cols="2,1,3,2",options="header"]
|===
|Parameter
|Type
|Description
|Default value

|`type`
|String
|Specifies the secret rotation mode. Valid values are `Custom` (enables rotation with a configurable interval) or `None` (disables rotation). When set to `None`, secrets are fetched only at initial pod mount time and are not updated thereafter.
|When omitted, rotation defaults to enabled with a 120-second interval

|`custom.minimumRefreshAge`
|Integer
|Specifies the minimum number of seconds between rotation attempts. Valid range is 1 to 31,560,000 seconds (approximately 1 year). This parameter is only effective when `type` is set to `Custom`.
|`120` (2 minutes)

|===

== Configuration examples

The following examples demonstrate different rotation configurations:

.Example 1: Enable rotation with a 5-minute refresh interval
[source,yaml]
----
apiVersion: operator.openshift.io/v1
kind: ClusterCSIDriver
metadata:
  name: secrets-store.csi.k8s.io
spec:
  driverConfig:
    driverType: SecretsStore
    secretsStore:
      secretRotation:
        type: Custom
        custom:
          minimumRefreshAge: 300
----

.Example 2: Disable rotation to prevent polling
[source,yaml]
----
apiVersion: operator.openshift.io/v1
kind: ClusterCSIDriver
metadata:
  name: secrets-store.csi.k8s.io
spec:
  driverConfig:
    driverType: SecretsStore
    secretsStore:
      secretRotation:
        type: None
----

.Example 3: High-frequency rotation for time-sensitive secrets
[source,yaml]
----
apiVersion: operator.openshift.io/v1
kind: ClusterCSIDriver
metadata:
  name: secrets-store.csi.k8s.io
spec:
  driverConfig:
    driverType: SecretsStore
    secretsStore:
      secretRotation:
        type: Custom
        custom:
          minimumRefreshAge: 60
----

.Example 4: Low-frequency rotation for cost optimization
[source,yaml]
----
apiVersion: operator.openshift.io/v1
kind: ClusterCSIDriver
metadata:
  name: secrets-store.csi.k8s.io
spec:
  driverConfig:
    driverType: SecretsStore
    secretsStore:
      secretRotation:
        type: Custom
        custom:
          minimumRefreshAge: 3600
----

== Considerations

When configuring secret rotation parameters, consider the following:

* Shorter polling intervals provide faster secret updates but increase transaction costs and performance overhead.
* Longer polling intervals reduce costs and overhead but delay the propagation of secret updates to pods.
* Disabling rotation eliminates polling overhead entirely but requires pod restarts to pick up secret changes.
* The polling interval applies globally to all secrets mounted by the {secrets-store-operator}.
* Applications consuming secret data must watch for file system changes to detect updated secrets when rotation is enabled.
