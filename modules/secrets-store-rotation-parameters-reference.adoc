= Secret rotation configuration parameters

[role="_abstract"]
You can configure secret rotation behavior for the {secrets-store-operator} by setting parameters in the `rotation` section of the `Driver` custom resource.

The following table describes the parameters available for configuring secret rotation:

.Secret rotation configuration parameters
[cols="2,1,3,2",options="header"]
|===
|Parameter
|Type
|Description
|Default value

|`enabled`
|Boolean
|Enables or disables automatic secret rotation. When set to `true`, the {secrets-store-operator} polls the external secret store at the interval specified by `pollingInterval` to check for secret updates. When set to `false`, secrets are mounted only when pods start and are not updated thereafter, and the `RequiresRepublish` flag is set to `false` to prevent unnecessary kubelet calls.
|`true`

|`pollingInterval`
|String (duration)
|Specifies the interval for checking external secret stores for updates. The value must be a duration string using time units such as `s` (seconds), `m` (minutes), or `h` (hours). Valid examples include `30s`, `2m`, `5m`, `1h`. This parameter is only effective when `enabled` is set to `true`.
|`2m`

|===

== Configuration examples

The following examples demonstrate different rotation configurations:

.Example 1: Enable rotation with a 5-minute polling interval
[source,yaml]
----
apiVersion: csidriver.openshift.io/v1
kind: Driver
metadata:
  name: secrets-store.csi.k8s.io
spec:
  rotation:
    enabled: true
    pollingInterval: "5m"
----

.Example 2: Disable rotation to prevent polling
[source,yaml]
----
apiVersion: csidriver.openshift.io/v1
kind: Driver
metadata:
  name: secrets-store.csi.k8s.io
spec:
  rotation:
    enabled: false
----

.Example 3: High-frequency rotation for time-sensitive secrets
[source,yaml]
----
apiVersion: csidriver.openshift.io/v1
kind: Driver
metadata:
  name: secrets-store.csi.k8s.io
spec:
  rotation:
    enabled: true
    pollingInterval: "30s"
----

.Example 4: Low-frequency rotation for cost optimization
[source,yaml]
----
apiVersion: csidriver.openshift.io/v1
kind: Driver
metadata:
  name: secrets-store.csi.k8s.io
spec:
  rotation:
    enabled: true
    pollingInterval: "1h"
----

== Considerations

When configuring secret rotation parameters, consider the following:

* Shorter polling intervals provide faster secret updates but increase transaction costs and performance overhead.
* Longer polling intervals reduce costs and overhead but delay the propagation of secret updates to pods.
* Disabling rotation eliminates polling overhead entirely but requires pod restarts to pick up secret changes.
* The polling interval applies globally to all secrets mounted by the {secrets-store-operator}.
* Applications consuming secret data must watch for file system changes to detect updated secrets when rotation is enabled.
