= Debugging the console

[role="_abstract"]

Read the {KialiServer} log to see why a view is empty or slow. The default log level is `info`. Set `debug` or `trace` while you investigate, then return to `info`. `trace` is the noisiest level.

[source,yaml]
----
spec:
  deployment:
    logger:
      log_level: debug
      log_format: json
----

`log_format` is `text` or `json`. Read the log with:

[source,terminal]
----
$ oc logs -n istio-system deployment/kiali
----

Messages for one console request share a `request-id`. The `route` field names the API. `GraphNamespaces` builds the main graph. `AppMetrics`, `ServiceMetrics`, and `WorkloadMetrics` build the metric charts. `ConfigValidationSummary` builds the validation summary.

{KialiServer} also records how long those requests take. Durations under 3 seconds are not written to the log. They are still exported as metrics. Use those metrics when a page is slow and the log does not show a long timer.

{KialiProduct} has its own log. Read it with `oc logs` on the operator deployment in the namespace where the operator is installed.
