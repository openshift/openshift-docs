= Explore STS resources for IAM clusters

[role="_abstract"]
{hcp-title-first} uses the AWS Security Token Service (STS) to provide temporary, limited-permission credentials for your cluster. Before deploying your cluster, you must create specific account-wide IAM roles and policies, cluster-specific Operator IAM roles, and an OpenID Connect (OIDC) provider.
