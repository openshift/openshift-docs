= Supported package formats

[role="_abstract"]
Scanner can check for vulnerabilities in images that use the following package formats:

[cols="2",options="header"]
|===
| Package format | Package managers

| apk
| apk

| dpkg
| apt, dpkg

| rpm
| dnf, microdnf, rpm, yum
|===
