= Create a VM from the web console

[role="_abstract"]
Create and configure virtual machines (VMs) through a guided visual workflow instead of writing YAML manifests. The web console creation wizard helps you get a VM running quickly with built-in validation at each step.

The wizard supports the following workflows:

Custom configuration:: Build a VM with a specific combination of compute, storage, and network settings.

Create from template:: Deploy a VM from a preconfigured template with an available boot source.

Clone existing `VirtualMachine`:: Duplicate an existing VM and its configuration.
