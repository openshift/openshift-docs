= Configure my nodes with IPsec for pod-to-pod network traffic with Libreswan

[role="_abstract"]
You can prepare your nodes for IPsec-encrypted pod-to-pod traffic by creating a machine config that enables the {op-system-base} `ipsec` extension. The extension installs Libreswan on every node in the machine config pool that you target.
