= Supported storage backends for lazy pulling

[role="_abstract"]
When using the `additionalLayerStores` field to configure lazy pulling with additional CRI-O storage, you must install one of the supported storage backends.

You are responsible for obtaining, installing, and maintaining the storage backend. 

The following storage backends are supported for lazy pulling:

.Supported storage backends and compatibility matrix
[options="header"]
|===

|Technology |Type |Support |Image Format

|zstd:chunked
|Native (built-in)
|GA
|zstd:chunked

|composefs 
|Native (built-in) 
|TP
|zstd:chunked

|stargz-snapshotter
|BYOS (Build Your Own Server) plugin
|TP 
|eStargz, zstd:chunked

|nydus-storage-plugin 
|BYOS plugin 
|TP 
|eStargz, Nydus

|===
