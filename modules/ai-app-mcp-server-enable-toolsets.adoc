= Enable OVN-Kubernetes and CNI diagnostics toolsets

[role="_abstract"]
Enable the `ovn-kubernetes` and `cni-diagnostics` toolsets in the MCP server `config.toml` file so that AI agents can use OVN, OVS, and CNI diagnostic tools on your cluster.

.Prerequisites
* You have installed the MCP server for Red Hat OpenShift and it is running.
* You have configured RBAC permissions for the MCP server service account.
* Your cluster uses the OVN-Kubernetes network plugin and `ovnkube-node` pods are running in the `openshift-ovn-kubernetes` namespace.

.Procedure

. Edit the MCP server `config.toml` file and add the `ovn-kubernetes` and `cni-diagnostics` toolsets.
+
Keep the `core` toolset enabled. The `core` toolset is required to discover `ovnkube-node` pods by using `pods_list`.
+
.Example toolset configuration
[source,toml]
----
toolsets = ["core", "ovn-kubernetes", "cni-diagnostics"]
----
+
.. Optional: Customize container images for CNI diagnostics debug pods.
+
.Example CNI diagnostics image configuration
[source,toml]
----
[toolset_configs.cni-diagnostics]
kernel_debug_image = "nicolaka/netshoot:v0.16"
tcpdump_image = "nicolaka/netshoot:v0.16"
pwru_image = "docker.io/cilium/pwru:v1.0.10"
----

. Restart or redeploy the MCP server so that it loads the updated configuration.

.Verification

. Verify that the toolsets are available by prompting your MCP client to list `ovnkube-node` pods and run a read-only OVN command.
+
.Example prompts
[source,terminal]
----
List pods in the openshift-ovn-kubernetes namespace with label app=ovnkube-node
----
+
[source,terminal]
----
Use ovn_show on an ovnkube-node pod in openshift-ovn-kubernetes to show the OVN Northbound database
----
+
If the toolsets are enabled and RBAC is configured correctly, the MCP server returns OVN configuration output without permission errors.
