= Metrics for user-defined networks

[role="_abstract"]
You can use OVN-Kubernetes metrics to monitor `NetworkAttachmentDefinition` (NAD) sync, node annotation updates, and northbound database (NBDB) programming for a user-defined network (UDN). These metrics help you identify bottlenecks when you create or scale user-defined networks.

The following metrics are available from the `ovnkube-cluster-manager` and `ovnkube-controller` metrics endpoints when scale metrics are enabled.

[cols="1,1a,1"]
|===
| Name | Description | Explanation

|`ovnkube_clustermanager_udn_nad_sync_duration_seconds`
|`name`: specifies the UDN or cluster user-defined network (CUDN) name
|The time spent syncing `NetworkAttachmentDefinition` objects during UDN reconciliation.

|`ovnkube_clustermanager_udn_update_node_annotation_duration_seconds`
|`name`: specifies the UDN or CUDN name
|The time spent updating node annotations during UDN network allocation.

|`ovnkube_controller_udn_nbdb_programmed_duration_seconds`
|`topology`: specifies the UDN topology, such as `layer2` or `layer3`
|The time the OVN-Kubernetes controller takes to program logical objects for a UDN in the OVN northbound database (NBDB) when initializing the network on a node. Values are aggregated by topology.
|===
