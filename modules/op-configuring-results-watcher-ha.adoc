= Configuring high availability for the Results Watcher controller

[role="_abstract"]
By default, the {tekton-results} Watcher controller uses leader election for high availability and scaling. You can configure horizontal scaling by using leader election or StatefulSet ordinals mode in the `spec.performance` configuration of the `TektonConfig` custom resource.

Review the following scaling mechanisms comparison:
* *Leader election (default)*: Provides fast failover during pod disruption. However, traffic can concentrate on a single replica, which can cause hot spots. Failover or rollouts can cause temporary outages of up to 100% until a new leader is elected.
* *StatefulSet ordinals mode*: Distributes keys deterministically across replicas. Failover is slower than leader election, but disruption is bounded to the disrupted pod ordinal. For example, in a three-replica deployment, disruption affects at most 33% of keys.

.Prerequisites
* You have access to the cluster with `cluster-admin` permissions.
* You have installed {pipelines-title}.
* You have installed the OpenShift CLI (`oc`).

.Procedure
. Edit the `TektonConfig` custom resource:
+
[source,terminal]
----
$ oc edit tektonconfig config
----

. In the `spec` section, add or update the `performance` stanza:
+
[source,yaml]
----
apiVersion: operator.tekton.dev/v1alpha1
kind: TektonConfig
metadata:
  name: config
spec:
  # ...
  performance:
    disable-ha: false
    replicas: 3
    statefulset-ordinals: true
    buckets: 3
----
+
The following table describes the supported `spec.performance` parameters:
[cols="2,1,1,4",options="header"]
|===
| Parameter
| Type
| Default
| Description

| `disable-ha`
| Boolean
| `false`
| Enables or disables high availability for the Results Watcher controller.

| `replicas`
| Integer
| `1`
| Sets the number of controller replicas to deploy.

| `statefulset-ordinals`
| Boolean
| `false`
| Deploys the Results Watcher controller as a `StatefulSet` object when set to `true`. When set to `false`, the controller deploys as a `Deployment` object with leader election.

| `buckets`
| Integer
| `1`
| Defines the number of reconciler partitions (range: 1 to 10). In leader election mode, replicas compete for buckets. In StatefulSet ordinals mode, the bucket count must match the `replicas` value.
|===

. Save your changes and exit the editor.

.Verification
* Verify that the controller runs as a `StatefulSet` object:
+
[source,terminal]
----
$ oc get statefulset tekton-results-watcher -n openshift-pipelines
----

[NOTE]
====
Modifying or removing properties in `spec.performance` updates the `tekton-results-watcher` `Deployment` or `StatefulSet` object and the `tekton-results-config-leader-election` `ConfigMap` object. This update automatically restarts the `tekton-results-watcher` pods.
====
