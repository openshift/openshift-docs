= Deprecated features

[role="_abstract"]
The following features are deprecated in this release of {LoggingProductName}.

`BoltDB` schema support deprecated; Prometheus alert added::
`BoltDB`-based schemas are deprecated in this release. The `BoltDB` index type will be removed in a future Loki release. A Prometheus alert is included to warn users when a `LokiStack` is configured with a `BoltDB` schema that must be migrated. To prepare for this removal, update your `LokiStack` schema to use `tsdb` before upgrading to a Loki release that removes `BoltDB` support.
