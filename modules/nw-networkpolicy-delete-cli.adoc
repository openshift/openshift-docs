= Delete a {name} policy using the CLI

[role="_abstract"]
You can delete a {name} policy in a namespace by using the CLI.


[NOTE,role="pr:openshift-dedicated pr:openshift-enterprise pr:openshift-origin pr:openshift-rosa pr:openshift-rosa-hcp"]
====
[.pr:openshift-dedicated .pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa .pr:openshift-rosa-hcp]#If you log in with `cluster-admin` privileges, you can delete network policies in any namespace in the cluster. In the web console, you can delete policies directly in YAML or by using the *Actions* menu.#
====


.Prerequisites
[role="pr:openshift-dedicated pr:openshift-enterprise pr:openshift-origin pr:openshift-rosa pr:openshift-rosa-hcp"]
* Your cluster uses a network plugin that supports `NetworkPolicy` objects, such as the OVN-Kubernetes network plugin, with `mode: NetworkPolicy` set.
* You installed the OpenShift CLI (`oc`).
* You logged in to the cluster with a user with `{role}` privileges.
* You are working in the namespace where the {name} policy exists.


.Prerequisites
[role="pr:microshift"]
* You installed the OpenShift CLI (`oc`).
* You are working in the namespace where the {name} policy exists.

.Procedure

* To delete a {name} policy object, enter the following command. Successful output lists the name of the policy object and the `deleted` status.
+
[source,terminal,subs="attributes+"]
----
$ oc delete {name}policy <policy_name> -n <namespace>
----
+
where:
+
`<policy_name>`:: Specifies the name of the {name} policy.
`<namespace>`:: Optional parameter. If you defined the object in a different namespace than the current namespace, the parameter specifices the namespace.
