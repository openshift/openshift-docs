= Installation configuration parameters for IBM Cloud

[role="_abstract"]
Before you deploy an {product-title} cluster on {ibm-cloud-name}, you give values for parameters to customize your cluster and the platform that hosts it.

When you create the `install-config.yaml` file, you give values for the required parameters through the command line. You can then change the `install-config.yaml` file to customize your cluster further.
