= Configure the eBPF agent for plain text capture

[role="_abstract"]
Configure the eBPF agent to intercept and collect unencrypted data from TLS-encrypted connections by enabling plain text capture in the `FlowCollector` custom resource.

.Prerequisites

* The Network Observability Operator is installed.
* A running {product-title} cluster.
* Access to the cluster with `cluster-admin` privileges.

.Procedure

. Edit the `FlowCollector` custom resource:
+
[source,terminal]
----
$ oc edit flowcollector cluster -n netobserv
----

. Configure plain text capture for TLS implementations in the `agent.ebpf` section:
+
[source,yaml]
----
apiVersion: flows.netobserv.io/v1beta2
kind: FlowCollector
metadata:
  name: cluster
spec:
  agent:
    type: eBPF
    ebpf:
      plaintextCapture:
        enable: true
        openssl:
          enable: true
        goTLS:
          enable: true
        kernelTLS:
          enable: true
          cGroupPath: "/sys/fs/cgroup"
----
+
--
Where:

`plaintextCapture.enable`:: Enables plain text capture globally.
`openssl.enable`:: Enables plain text capture for OpenSSL-encrypted connections.
`goTLS.enable`:: Enables plain text capture for Go TLS-encrypted connections.
`kernelTLS.enable`:: Enables plain text capture for kernel TLS (kTLS) connections.
`kernelTLS.cGroupPath`:: Specifies the cgroup root path for kTLS. The default value is `/sys/fs/cgroup`.
--

. Optional: Configure process exclusions to reduce noise from system processes:
+
[source,yaml]
----
apiVersion: flows.netobserv.io/v1beta2
kind: FlowCollector
metadata:
  name: cluster
spec:
  agent:
    type: eBPF
    ebpf:
      plaintextCapture:
        enable: true
        processExclusions:
          - name: kube-apiserver
            namespace: openshift-kube-apiserver
          - name: etcd
            namespace: openshift-etcd
          - name: openshift-apiserver
            namespace: openshift-apiserver
----
+
The `processExclusions` setting excludes specific processes from plain text capture to reduce noise.

. Save and exit the editor.
+
The Network Observability Operator applies the configuration changes and restarts the eBPF agent pods.

. Optional: Adjust the configuration based on your specific requirements:
+
* **Disable specific TLS implementations**: Set `enable: false` for implementations you do not need to capture.
* **Add additional process exclusions**: Include other high-traffic system processes that generate noise.
* **Configure kTLS cgroup path**: Adjust `cGroupPath` if your cluster uses a non-standard cgroup mount point.

.Verification

* Verify the eBPF agent pods restarted with the new configuration:
+
[source,terminal]
----
$ oc get pods -n netobserv -l app=netobserv-ebpf-agent
----
+
Check that the pods have recent restart times and are in `Running` status.

* Check the eBPF agent logs for plain text capture initialization:
+
[source,terminal]
----
$ oc logs -n netobserv -l app=netobserv-ebpf-agent --tail=50 | grep -i "plain text"
----
+
.Example output
[source,terminal]
----
{"level":"info","msg":"Plain text capture enabled for OpenSSL"}
{"level":"info","msg":"Plain text capture enabled for Go TLS"}
{"level":"info","msg":"Plain text capture enabled for kernel TLS"}
----
