= Access and operate virtual machines

[role="_abstract"]
Keep running virtual machines (VMs) healthy and current: connect to a guest to diagnose it, adjust its resources as the workload changes, and apply the same change to many VMs at once.

After you create a VM, the work shifts from provisioning to operation. Choose an interface based on the work:

{product-title} web console:: Interactive work on a single VM.

`virtctl` and the {oc-first}:: Scripted, repeatable work.
