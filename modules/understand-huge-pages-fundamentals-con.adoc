= Understand huge pages fundamentals

[role="_abstract"]
Huge pages let the kernel map memory in blocks that are much larger than the default 4 KiB page, which reduces page table overhead for memory-intensive applications. Understand how {product-title} presents huge pages as a schedulable resource before you allocate them to workloads.
