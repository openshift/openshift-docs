= Cluster upgrade considerations

[role="_abstract"]
Before upgrading a cluster that has signature verification enabled, ensure that all required signatures are mirrored to your disconnected registry. The Cluster Version Operator (CVO) requires verified images to move pods to new nodes during the upgrade process. If signatures are missing or invalid, the upgrade can fail.

The default `ClusterImagePolicy` object named `openshift` enforces signature verification for {product-title} release images in the `quay.io/openshift-release-dev/ocp-release` and `quay.io/openshift-release-dev/ocp-v4.0-art-dev` repositories. When using a mirror registry, you must mirror the sigstore signatures for these repositories to ensure successful upgrades.
