= Configure GRPCRoute resources

[role="_abstract"]
A `GRPCRoute` custom resource (CR) specifies how a gateway matches incoming gRPC requests and forwards them to backend services. Define `GRPCRoute` rules to control the routing behavior for the gRPC applications behind your gateway.
