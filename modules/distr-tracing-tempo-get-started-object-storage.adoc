= Set up object storage

[role="_abstract"]
To deploy {dt}, choose an object storage provider that fits your infrastructure, compliance requirements, and operational preferences.

These providers are supported across cloud and on-premise environments:

* {odf-full} ({odf-short})
* MinIO
* {ibm-cloud-object-storage}
* Amazon S3
* Amazon S3 with Security Token Service (STS)
* Microsoft Azure Blob Storage
* {gcp-full} Storage on {gcp-first}
