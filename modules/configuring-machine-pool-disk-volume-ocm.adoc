= Configuring machine pool disk volume using {cluster-manager}

endif::openshift-rosa[]

[role="_abstract"]
Configure the disk volume size for machine pools during cluster creation or when adding new machine pools by using {cluster-manager-first}.

.Prerequisites

* You have access to {cluster-manager-url}.

.Procedure

* To configure disk volume during cluster creation:

.. From the {product-title} cluster wizard, navigate to *Cluster settings*.

.. Navigate to *Machine pool* step.

.. Select the desired *Root disk size*.

.. Select *Next* to continue creating your cluster.

* To configure disk volume for a new machine pool after cluster installation:

.. Navigate to {cluster-manager-url} and select your cluster.

.. Navigate to *Machine pool tab*.

.. Click *Add machine pool*.

.. Select the desired *Root disk size*.

.. Select *Add machine pool* to create the machine pool.
