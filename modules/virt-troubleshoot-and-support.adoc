= Troubleshoot and get support

[role="_abstract"]
Diagnose root causes for failing or degraded virtual machines and cluster components by using logs, structured diagnostic procedures, and alert runbooks, so you can restore healthy operations and reduce mean time to resolution.

Most {VirtProductName} problems resolve along one of two paths. Recognizing which one you are on saves time.

When a virtual machine (VM) misbehaves but the cluster reports nothing unusual, the evidence sits in logs and events. Start there. When the cause goes beyond what you can fix yourself, Red{nbsp}Hat Support needs diagnostic data in a set form before anyone can act on it. The data you gather while diagnosing is the same data a support case requires, so escalating early rarely saves effort.

Alerts are the exception. When the {VirtProductName} Operator raises an alert, you do not have to work out where to look: each alert has a runbook that names the likely causes and the checks to run. Consult the runbook first, then follow whichever path the findings point to.
