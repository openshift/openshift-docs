= RHSA-2026:70617 - {product-title} 4.18.56 bug fix and security update

Issued: 01 October 2026

[role="_abstract"]
{product-title} release 4.18.56 is now available. The list of bug fixes that are included in the update is documented in the link:https://access.redhat.com/errata/RHSA-2026:70617[RHSA-2026:70617] advisory. The RPM packages that are included in the update are provided by the link:https://access.redhat.com/errata/RHSA-2026:70614[RHSA-2026:70614] advisory.

Space precluded documenting all of the container images for this release in the advisory.

You can view the container images in this release by running the following command:

[source,terminal]
----
$ oc adm release info 4.18.56 --pullspecs
----

[id="zstream-4-18-56-deprecated-removed-features_{context}"]
== Deprecated and removed features

* The old kubebuilder envtest tool has been deprecated. Ensure that you no longer use the link:https://storage.googleapis.com/kubebuilder-tools[kubebuilder-tools storage location].

[id="zstream-4-18-56-fixed-issues_{context}"]
== Fixed issues

* Before this update, upstream GitHub Actions workflow and issue template files that were not used in the {product-title} downstream fork, which uses Prow and the `ci-operator` tool and not the GitHub Actions were present in the release branches. As a consequence, the `golangci-lint` job failed on every pull request. With this release, these unused files are removed from the release branches. As a result, the lint job no longer fails on pull requests. (link:https://issues.redhat.com/browse/OCPBUGS-123680[OCPBUGS-123680])
