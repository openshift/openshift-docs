= Bug fixes and security updates in version 4.10.11

[role="_abstract"]
This release includes the following bug fixes:

//ROX-36432
* Before this update, some nodes displayed stale scan timestamps even though Central continued to update the node regularly. This occurred when users created the default Scanner V4 integration before node scanning was available and it lacked the NODE_SCANNER category. With this release, Red{nbsp}Hat fixed the integration reconciliation logic. As a result, node scan timestamps update correctly.

//ROX-37454
* With this release, Red{nbsp}Hat updated the {product-title-short} Operator metadata in OperatorHub. The documentation link now points to the correct version. As a result, users installing from OperatorHub receive accurate product information.

This release also addresses the following security vulnerabilities:

//ROX-37348
* Central issues new authentication tokens in case of SAML response replay (link:https://access.redhat.com/security/cve/CVE-2026-103314[CVE-2026-103314])

//ROX-37682
* ca-certificates: Distrust eMudhra intermediate CA certificates due to security concerns (link:https://access.redhat.com/security/cve/CVE-2026-114406[CVE-2026-114406])

* Go and golang.org:
//ROX-37689
** Go crypto/x509: Man-in-the-middle attacks via untrusted intermediate certificates (link:https://access.redhat.com/security/cve/CVE-2026-111943[CVE-2026-111943])
//ROX-36710, ROX-36713
** golang.org/x/crypto: Unauthorized access via crafted SSH certificate (link:https://access.redhat.com/security/cve/CVE-2026-56854[CVE-2026-56854])
** golang.org/x/net/dns/dnsmessage: Denial of Service via invalid DNS record parsing (link:https://access.redhat.com/security/cve/CVE-2026-46600[CVE-2026-46600])
** golang net/url: Denial of Service from quadratic complexity in path resolution (link:https://access.redhat.com/security/cve/CVE-2026-56860[CVE-2026-56860])
** Go encoding/asn1: Denial of Service via excessive recursion in Unmarshal (link:https://access.redhat.com/security/cve/CVE-2026-33818[CVE-2026-33818])
** Golang crypto/tls: Denial of Service via indefinite KeyUpdate messages (link:https://access.redhat.com/security/cve/CVE-2026-56862[CVE-2026-56862])
** Go html/template: Cross-Site Scripting via pathological input (link:https://access.redhat.com/security/cve/CVE-2026-56858[CVE-2026-56858])
** Go net/http: Unencrypted HTTP/2 connections vulnerable to Denial of Service (link:https://access.redhat.com/security/cve/CVE-2026-56853[CVE-2026-56853])
