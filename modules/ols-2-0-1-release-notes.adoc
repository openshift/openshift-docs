= {ols-long} version 2.0.1

[role="_abstract"]
{ols-official} 2.0.1 improves the autonomous agents log viewing experience in the {ocp-product-title} web console. This release helps ensure continued support and stability for clusters running {ocp-product-title} 4.16 and later.

[id="ols-2-0-1-enhancements_{context}"]
== Enhancements

[role="_abstract"]
{ols-official} 2.0.1 adds log download and raw log viewing controls to the {ols-long} autonomous agents log viewer.

{ols-official} 2.0.1 includes the following enhancements:

//OLS-4188
* With this update, the per-stage log viewer for `AgenticRun` workflows in the {ocp-product-title} web console provides a *Download* action to save logs as a file and a *View raw logs* action to open the unformatted logs in a new browser tab. These controls appear on the run detail page for the analysis, execution, and verification stages, and they match the log viewing experience in the *Pod* -> *Logs* view.
