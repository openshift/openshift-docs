= Install and configure the operators

[role="_abstract"]
To enable natural language generation of Red Hat build of Perses dashboards, you must install and configure the {ols-official} Operator and the Cluster Observability Operator (COO).

.Prerequisites

* You have logged in to the cluster as a user with `cluster-admin` privileges.
* Your {ocp-product-title} cluster runs version 4.22 or later.
* You have an LLM provider account and API credentials.

.Procedure

. Install the {ols-official} Operator from the *Software Catalog* (`OperatorHub`) in your {ocp-product-title} web console.
+
// TODO: Add updated UI screenshot of installing the {ols-official} Operator from the Software Catalog. Tracked in https://redhat.atlassian.net/browse/OU-1422

. Create a secret with your LLM API token, for example, an OpenAI API key, in the `openshift-lightspeed` namespace so that the Operator can authenticate with the LLM:
+
[source,terminal]
----
$ oc create secret generic -n openshift-lightspeed credentials --from-literal=apitoken=<YOUR_API_KEY>
----
+
[NOTE]
====
Replace `<YOUR_API_KEY>` with your active API key, for example, your OpenAI API key.
====

. Apply an `OLSConfig` custom resource (CR) to configure your LLM provider and default model:
+
[NOTE]
====
The following YAML manifest uses OpenAI as an example. You can adjust the provider, model, and credential parameters to match your specific LLM provider.
====
+
[source,yaml]
----
$ oc apply -f - <<EOF
apiVersion: ols.openshift.io/v1alpha1
kind: OLSConfig
metadata:
  llm:
    providers:
      - credentialsSecretRef:
          name: credentials
        models:
          - name: gpt-5.4
        name: openai
        type: openai
        url: 'https://api.openai.com/v1'
  ols:
    introspectionEnabled: true
    conversationCache:
    defaultModel: gpt-5.4
    defaultProvider: openai
EOF
----

. Install the Cluster Observability Operator (COO) version 1.5 or later from the *Software Catalog*.
+
// TODO: Add updated UI screenshot of installing the Cluster Observability Operator from the Software Catalog. Tracked in https://redhat.atlassian.net/browse/OU-1422

. Create a `UIPlugin` custom resource to enable the Red Hat build of Perses:
+
[source,yaml]
----
$ oc apply -f - <<EOF
apiVersion: observability.openshift.io/v1alpha1
kind: UIPlugin
metadata:
  name: monitoring
spec:
  monitoring:
    perses:
      enabled: true
  type: Monitoring
EOF
----

. Create the `PersesGlobalDatasource` configuration to establish the global Prometheus data source connection:
+
[source,yaml]
----
$ oc apply -f - <<EOF
apiVersion: perses.dev/v1alpha2
kind: PersesGlobalDatasource
metadata:
  name: perses-global-ds
spec:
  client:
    tls:
      caCert:
        certPath: /ca/service-ca.crt
        type: file
      enable: true
  config:
    default: true
  display:
    name: Perses Datasource
  plugin:
    kind: PrometheusDatasource
    spec:
      proxy:
        kind: HTTPProxy
        spec:
          secret: perses-global-ds-secret
          url: 'https://thanos-querier.openshift-monitoring.svc.cluster.local:9091'
EOF
----
