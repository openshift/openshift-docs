= Creating the default Agent

[role="_abstract"]
Create the default `Agent` custom resource (CR) for Agentic {ols-long}. The default agent is required. Additional tiers, such as `smart` and `fast`, are optional.

.Prerequisites

* You have installed the {ols-long} Operator.

* You have created the `LLMProvider` CR.

.Procedure

* Create the default `Agent` CR by running the following command:
+
[source,terminal]
----
$ oc apply -f - <<'EOF'
apiVersion: agentic.openshift.io/v1alpha1
kind: Agent
metadata:
  name: default
  namespace: openshift-lightspeed
spec:
  llmProvider:
    name: openai
  model: gpt-5.6-luna
  reasoningConfig:
    effort: high
    summary: auto
  timeouts:
    analysisSeconds: 600
    executionSeconds: 600
    verificationSeconds: 600
EOF
----
