== New features and enhancements

*Support for trust-manager on the Secrets Management page*

With this release, the web console supports trust-manager on the secrets management page. The page detects when trust-manager is installed and lists its `Bundle` resources in a resource table. From the table, you can inspect a `Bundle` resource or delete it. You can now distribute certificate authority (CA) trust bundles from the console, without switching to the command line.

*Role-based access to the {external-secrets-console-plugin}*

With this release, users without cluster administrator privileges can access the {external-secrets-console-plugin} by using their role-based access control (RBAC) permissions. The plugin detects installed Operators without the `GET customresourcedefinitions` permission, and it displays only the resources and actions that the permissions allow.

*Support for {external-secrets-operator} generators on the secrets management page*

With this release, the Secrets Management page lists generators from the {external-secrets-operator}. The Secrets Management page shows the generators alongside the secret stores, external secrets, and push secrets. A single table combines all generator kinds, including `ClusterGenerator`. From the table, you can inspect a generator or delete it. The *Generators* section appears only when the{external-secrets-operator} is installed.
