= Toolset tools list

[role="_abstract"]
Each toolset in the MCP server for Red{nbsp}Hat OpenShift provides a set of tools that assistants call to perform tasks. These tables list the tools in each toolset and describe what each tool does.

Each tool name is shown as the assistant calls it.

.`ossm` tools
[cols="1,2",options="header"]
|===
|Name |What it does
|`ossm_get_logs`|Returns logs for a pod or workload in a namespace.
|`ossm_get_mesh_status`|Returns mesh health, including the control plane, data plane, observability backends, and how those components connect.

Use this first when you need a mesh-wide view.
|`ossm_get_mesh_traffic_graph`|Returns service-to-service traffic, dependencies, and network metrics, such as throughput, response time, and mTLS.
|`ossm_get_metrics`|Returns latency, traffic, throughput, and payload metrics for a service, workload, or application.
|`ossm_get_pod_performance`|Compares a pod's current CPU and memory use with its requests and limits.
|`ossm_get_resource_details`|Lists applications, services, workloads, namespaces, or Argo{nbsp}CD applications, or returns details for one resource.
|`ossm_get_trace_details`|Returns the call hierarchy of one distributed trace.

Use it after `ossm_list_traces`.
|`ossm_list_mesh_clusters`|Lists the mesh clusters Kiali can access, and identifies the home cluster where Kiali runs.
|`ossm_list_traces`|Lists distributed traces for a service.
|`ossm_manage_istio_config`|Creates, updates, or deletes service mesh configuration, including Istio, Gateway API, and Inference API resources.

This tool is hidden when the server is read-only.
|`ossm_manage_istio_config_read`|Lists service mesh configuration or returns one resource.

Valid and invalid objects are reported separately.
|===
