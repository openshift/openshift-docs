= Google Cloud Filestore CSI Driver Operator

[role="_abstract"]
The Google Cloud Platform (GCP) Filestore Container Storage Interface (CSI) Driver Operator provisions and manages GCP Filestore Storage in {product-title} with dynamic volume provisioning, eliminating the need to pre-provision storage.
