[id="hcp-connectivity-metrics_{context}"]
= Connectivity monitoring for {hcp}

[role="_abstract"]
Cluster service providers can monitor connectivity metrics to ensure proper function during updates and to detect connectivity issues between the control plane and the data plane. Studying the metrics over time also informs capacity planning and scaling decisions.
