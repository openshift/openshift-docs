= Administrative events as Prometheus metrics

// JIRA: ROX-35181, ROX-35313

[role="_abstract"]
{product-title-short} Central now exposes administrative events as Prometheus metrics, allowing you to monitor {product-title-short} health directly within existing Prometheus stacks and configure automated alerts without relying on manual checks in the {product-title-short} portal.

Administrative event metrics follow the same configurable pattern as other custom metrics, such as image vulnerabilities and policy violations. You can complete the following tasks:

* Enable or disable the predefined `rox_central_admin_event_domain_level` and `rox_central_admin_event_resource_level` metrics on the *System Configuration* page.
* Adjust the gathering period, or set it to `0` to disable gathering.
* Create custom metrics with label subsets and include or exclude filters by using the `/v1/config` API endpoint.

For more information, see "Metric categories for custom metrics".
