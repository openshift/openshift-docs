= Enhanced metrics resource usage

[role="_abstract"]
Use the following typical resource usage values to plan capacity when you enable enhanced metrics exporters on a {microshift-short} node.

[cols="2,2,2",options="header"]
|===
|Exporter |Typical CPU usage |Typical memory usage

|node-exporter
|~0.013 cores
|~46 MiB

|metrics-server
|~0.007 cores
|~80 MiB

|kube-state-metrics
|~0.009 cores
|Depends on the number of Kubernetes objects in the cluster
|===

Resource usage varies with workload activity, scrape frequency, and cluster size. Monitor your deployment after enabling exporters to validate capacity on resource-constrained edge nodes.
