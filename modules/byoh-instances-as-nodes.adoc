= BYOH Windows instances

[role="_abstract"]
You can create Bring-Your-Own-Host (BYOH) Windows instances to bring existing Windows Server virtual machines (VMs) into {product-title}. By using BYOH Windows instances, you can mitigate major disruptions if a Windows server goes offline.
