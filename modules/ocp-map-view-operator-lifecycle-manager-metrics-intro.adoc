= View Operator Lifecycle Manager metrics

[role="_abstract"]
Operator Lifecycle Manager (OLM) exposes OLM-specific metrics that the Prometheus-based {product-title} cluster monitoring stack can use to track catalog sources, cluster service versions, install plans, and subscriptions.
