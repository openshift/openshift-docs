= Overlay examples

[role="_abstract"]
The following examples show how to patch different kinds of Kubernetes resources by using the `.spec.overlays` field of the `Central` custom resource. The same patch structure applies to the `SecuredCluster` custom resource.

Each example patches a different resource type: a `Deployment`, a `NetworkPolicy`, a `ConfigMap`, and a `ServiceAccount`. Use them as a starting point for your own customizations, and replace the resource names, paths, and values with the ones that apply to your environment.
