= Network policy ingress rule example

[role="_abstract"]
The following overlay adds an ingress rule for port 999 traffic to the `allow-ext-to-central` network policy.

[source,yaml]
----
apiVersion: platform.stackrox.io
kind: Central
metadata:
  name: central
spec:
    # ...
    overlays:
    - apiVersion: networking.k8s.io/v1
      kind: NetworkPolicy
      name: allow-ext-to-central
      patches:
        - path: spec.ingress[-1]
          value: |
            ports:
            - port: 999
              protocol: TCP
----
