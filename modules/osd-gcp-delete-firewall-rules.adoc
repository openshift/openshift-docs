= Delete firewall rules for {product-title} on {gcp-short}

[role="_abstract"]
When you no longer need the firewall rules or when deleting a cluster, you can generate a script to delete the firewall rules that were created for reduced Workload Identity Federation (WIF) permissions.

.Prerequisites

* You have previously created firewall rules by using the `ocm gcp create firewall-rules` command.
* You know the firewall rule prefix that was used when creating the firewall rules.
* You have downloaded the latest version of the {cluster-manager} CLI (`ocm`) for your operating system from the link:https://console.redhat.com/openshift/downloads[Downloads] page on {cluster-manager}.

.Procedure

. Generate a deletion script by running the following command:
+
[source,terminal]
----
$ ocm gcp delete firewall-rules <firewall_rule_prefix> \
    --project-id <host_project_id> \
    --output-file <output_file_path>
----
+
where:
+
`<firewall_rule_prefix>`:: The prefix used when creating the firewall rules.
`<host_project_id>`:: The ID of the {gcp-short} project where the firewall rules are located.
`<output_file_path>`:: The path to the file where the command saves the generated deletion script.

. Review the generated script and run it to delete the firewall rules:
+
[source,terminal]
----
$ chmod +x <output_file_path>
$ ./<output_file_path>
----
