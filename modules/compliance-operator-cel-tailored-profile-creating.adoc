= Creating a tailored profile with CEL

[role="_abstract"]
Define a `CustomRule` object with a CEL expression, reference it from a `TailoredProfile` object, and run a platform scan with a `ScanSettingBinding` object.

.Prerequisites

* You have installed the Compliance Operator.
* You have `cluster-admin` access or sufficient permissions to create `CustomRule`, `TailoredProfile`, and `ScanSettingBinding` objects in the `openshift-compliance` namespace.

.Procedure

. Create a `CustomRule` object that uses the CEL scanner.
  The following example checks that every namespace enforces Pod Security admission by using the `pod-security.kubernetes.io/enforce` label:
+
[source,yaml]
----
apiVersion: compliance.openshift.io/v1alpha1
kind: CustomRule
metadata:
  name: check-pod-security-standard
  namespace: openshift-compliance
spec:
  id: check-pod-security-standard
  title: Ensure Pod Security Standards are enforced
  severity: high
  checkType: Platform
  scannerType: CEL
  expression: |
    namespaces.items.all(ns,
      has(ns.metadata.labels) &&
      "pod-security.kubernetes.io/enforce" in ns.metadata.labels
    )
  failureReason: One or more namespaces do not enforce Pod Security Standards
  inputs:
    - name: namespaces
      kubernetesInputSpec:
        apiVersion: v1
        resource: namespaces
----

. Apply the manifest by running the following command:
+
[source,terminal]
----
$ oc apply -f custom-rule.yaml
----

. Create a `TailoredProfile` object that enables the `CustomRule`:
+
[source,yaml]
----
apiVersion: compliance.openshift.io/v1alpha1
kind: TailoredProfile
metadata:
  name: custom-cel-profile
  namespace: openshift-compliance
  annotations:
    compliance.openshift.io/product-type: Platform
spec:
  title: Custom CEL profile
  description: Profile with custom CEL rules
  enableRules:
    - name: check-pod-security-standard
      kind: CustomRule
      rationale: Enforce pod security standards on all namespaces
----

. Apply the tailored profile by running the following command:
+
[source,terminal]
----
$ oc apply -f tailored-profile.yaml
----

. Verify that the `TailoredProfile` object is ready by running the following command:
+
[source,terminal]
----
$ oc get tailoredprofile custom-cel-profile -n openshift-compliance
----
+
.Example output
[source,terminal]
----
NAME                 STATE
custom-cel-profile   READY
----

. Create a `ScanSettingBinding` object that references the tailored profile:
+
[source,yaml]
----
apiVersion: compliance.openshift.io/v1alpha1
kind: ScanSettingBinding
metadata:
  name: custom-cel-scan
  namespace: openshift-compliance
profiles:
  - apiGroup: compliance.openshift.io/v1alpha1
    kind: TailoredProfile
    name: custom-cel-profile
settingsRef:
  apiGroup: compliance.openshift.io/v1alpha1
  kind: ScanSetting
  name: default
----

. Apply the `ScanSettingBinding` object by running the following command:
+
[source,terminal]
----
$ oc apply -f scan-setting-binding.yaml
----
+
Applying the `ScanSettingBinding` object starts a compliance scan.

.Verification

* Confirm that the `TailoredProfile` object reports `READY` before you create the `ScanSettingBinding` object.
