= About role aggregation

[role="_abstract"]
By default, {VirtProductName} uses role aggregation to grant users virtualization-related roles automatically.

:FeatureName: Configuring role aggregation
include::snippets/technology-preview.adoc[]

When role aggregation is enabled, {VirtProductName} extends the default {product-title} cluster roles with permissions for accessing virtualization objects. For example, a user with the `edit` cluster role automatically receives the `kubevirt.io:edit` role, which allows them to create and modify VMs.

When role aggregation is disabled, users do not receive virtualization-related roles by default. You must explicitly grant virtualization roles to users who need access to virtualization resources. Disabling role aggregation provides more granular control over which users can access virtualization resources in your cluster.

You can re-enable role aggregation at any time to restore the default behavior.
