= Configure Go runtime tuning for an Argo CD instance

Configure Go runtime tuning for a specific Argo CD instance by using the `.spec.controller.goRuntime` field in the `ArgoCD` CR. You can customize the percentage of the memory limit used to compute `GOMEMLIMIT`, or disable automatic tuning entirely for the instance. These settings take effect when you configure resource limits on the Application Controller.

.Prerequisites

* You have access to the {OCP} cluster with `cluster-admin` privileges.
* You have installed the {gitops-title} Operator in your cluster.

.Procedure

. Configure the Application Controller resource limits and Go runtime tuning settings:
+
[source,yaml]
----
apiVersion: argoproj.io/v1alpha1
kind: ArgoCD
metadata:
  name: example-argocd
  namespace: argocd
spec:
  controller:
    resources:
      limits:
        cpu: '2'
        memory: 2Gi
    goRuntime:
      enabled: true
      memoryLimitPercent: 75
----
+
where:
+
`goRuntime.enabled`:: Set to `true` to enable Go runtime tuning for this instance. Set to `false` to disable tuning. The default value is `true`.
+
`goRuntime.memoryLimitPercent`:: The percentage (from 1 through 100) of the memory limit used to compute `GOMEMLIMIT`. The default value is `80`.

. Apply the configuration:
+
[source,terminal]
----
$ oc apply -f example-argocd.yaml
----

.Verification

. Verify the `GOMEMLIMIT` environment variable value in the Application Controller StatefulSet:
+
[source,terminal]
----
$ oc get statefulset argocd-application-controller -n argocd -o jsonpath='{.spec.template.spec.containers[0].env[?(@.name=="GOMEMLIMIT")].value}'
----
+
*Example output for a 2Gi memory limit with 75% configured:*
+
[source,terminal]
----
1610612736
----

. Verify the `GOMAXPROCS` environment variable value in the Application Controller StatefulSet:
+
[source,terminal]
----
$ oc get statefulset argocd-application-controller -n argocd -o jsonpath='{.spec.template.spec.containers[0].env[?(@.name=="GOMAXPROCS")].value}'
----
+
*Example output for a 2 CPU limit:*
+
[source,terminal]
----
2
----
