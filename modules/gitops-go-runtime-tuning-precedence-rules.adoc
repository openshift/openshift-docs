= Go runtime tuning precedence rules

Environment variables that you define in `.spec.controller.env` always take precedence over the Operator-computed values. If you manually set `GOMEMLIMIT` or `GOMAXPROCS` in the `ArgoCD` CR, the Operator does not override those values.

For example, to set an explicit `GOMEMLIMIT` value:

[source,yaml]
----
apiVersion: argoproj.io/v1alpha1
kind: ArgoCD
metadata:
  name: example-argocd
  namespace: argocd
spec:
  controller:
    env:
    - name: GOMEMLIMIT
      value: "1610612736"
    resources:
      limits:
        memory: 2Gi
----

[NOTE]
====
When you manually set `GOMEMLIMIT` or `GOMAXPROCS` in `.spec.controller.env`, the Operator does not update these values when you change resource limits. To return to automatic tuning, remove the manual environment variable entries.
====
