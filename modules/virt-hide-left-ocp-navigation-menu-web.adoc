= Hide left navigation menu of the {product-title} web console

[role="_abstract"]
You can hide the left navigation menu of the {product-title} web console to increase the viewing area of the *VirtualMachines* page.

.Procedure

. In the left navigation menu, navigate to  *Virtualization* ->  *Settings*. Open the *User* tab and the *General* section.

. Click the *Auto-hide navigation menu* toggle.
+
The navigation menu is hidden when you open the *VirtualMachines* page.

. To display the left navigation menu when the *VirtualMachines* page is open, click the menu icon in the upper-left corner of the screen.
