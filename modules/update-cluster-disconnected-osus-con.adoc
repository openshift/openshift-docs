= Update a cluster in a disconnected environment using OSUS

[role="_abstract"]
You can install and configure the OpenShift Update Service (OSUS) in a disconnected environment to get an update experience similar to connected clusters.
Use OSUS to provide update recommendations and manage cluster updates without internet access.
