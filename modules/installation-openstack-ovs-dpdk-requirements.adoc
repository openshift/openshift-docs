= Requirements for clusters on {rh-openstack} that use OVS-DPDK

[role="_abstract"]
To use Open vSwitch with the Data Plane Development Kit (OVS-DPDK) with your deployment, you must meet specific requirements.

The requirements are as follows:

* Plan your OVS-DPDK deployment, including CPU pinning, huge pages, and NUMA alignment. For more information, see "Plan an OVS-DPDK deployment".

* Configure the {rh-openstack} data plane for OVS-DPDK, including a custom OVS-DPDK Compute service. For more information, see "Deploy the data plane for SR-IOV and DPDK".
