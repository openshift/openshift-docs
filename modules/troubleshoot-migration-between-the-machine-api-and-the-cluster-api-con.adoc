= Troubleshoot migration between the Machine API and the Cluster API

[role="_abstract"]
On clusters that support changing the authoritative API for a machine management resource, the two-way synchronization controller maintains a matching resource for the API that is not authoritative. The differences between the two APIs cause symptoms that you can recognize, such as duplicated resources, commands that act on the wrong object, and configuration that does not migrate.
