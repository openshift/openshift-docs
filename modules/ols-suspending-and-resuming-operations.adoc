= Suspend and resume operations

[role="_abstract"]
You can temporarily halt all autonomous troubleshooting activity across the cluster during system maintenance or emergencies.

.Procedure

. To immediately suspend all agentic operations across the cluster, enter the following command:
+
[source,terminal]
----
$ oc agentic suspend --yes
----

. To check the current suspension status, enter the following command:
+
[source,terminal]
----
$ oc agentic status
----

. To resume normal operations, enter the following command:
+
[source,terminal]
----
$ oc agentic resume
----
