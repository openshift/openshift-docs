= Shared ingress architecture for hosted clusters on {azure-short}

[role="_abstract"]
Understanding the shared ingress architecture helps you correctly interpret the connectivity behavior of the Kubernetes API Server and avoid misconfiguration during verification. For self-managed {hcp}, each cluster with private topology receives a dedicated Private Link Service infrastructure.

The topology directly drives the `IngressController` `LoadBalancer` scope:

* `Public` topology: `ExternalLoadBalancer` scope
* `Private` or `PublicAndPrivate` topology: `InternalLoadBalancer` scope

Each cluster with private topology also receives a dedicated {azure-short} Private Link Service infrastructure (Internal load balancer → Private Link Service → Private Endpoint → Private DNS zones).
