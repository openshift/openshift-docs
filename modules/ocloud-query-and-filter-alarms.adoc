= Query and filter infrastructure alarms

[role="_abstract"]
You can query the O-Cloud Manager Alarms API to list active infrastructure and cluster alarms. The Alarms API aggregates alerts from {rh-rhacm} Observability Alertmanager and exposes them as O-RAN O2 IMS compliant alarm records with standardized severity levels, timestamps, and resource associations.

.Prerequisites

* You authenticated to the O-Cloud Manager REST API and set the `API_BASE_URL` and `MY_TOKEN` environment variables.
* {rh-rhacm} Observability is configured and running on the hub cluster.

.Procedure

. Set the Alarms API base URL by running the following command:
+
[source,terminal]
----
$ export ALARMS_URL="https://${API_BASE_URL}/o2ims-infrastructureMonitoring/v1"
----

. List all active alarms by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "${ALARMS_URL}/alarms" | jq
----
+
.Example output
[source,json]
----
[
  {
    "alarmEventRecordId": "e213f273-b6fa-48db-9aa2-a00df5de5747",
    "alarmDefinitionID": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "probableCauseID": "00000000-0000-0000-0000-000000000000",
    "alarmRaisedTime": "2025-09-10T19:45:16.78Z",
    "alarmChangedTime": "2025-09-25T16:25:12.977032Z",
    "alarmAcknowledged": false,
    "perceivedSeverity": 3,
    "extensions": {
      "alertname": "UpdateAvailable",
      "severity": "info",
      "summary": "Your upstream update recommendation service recommends you update your cluster."
    }
  }
]
----

. Filter alarms by severity by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "${ALARMS_URL}/alarms?filter=(eq,perceivedSeverity,0)" | jq
----
+
The `perceivedSeverity` field uses the following values, mapped from Prometheus alert severity labels:
+
[cols="1,1,2",options="header"]
|===
|Value |Severity |Prometheus severity labels

|`0`
|Critical
|`critical`

|`1`
|Major
|`major`, `important`

|`2`
|Minor
|`minor`, `low`

|`3`
|Warning
|`warning`, `info`, `moderate`

|`4`
|Indeterminate
|Missing severity label

|`5`
|Cleared
|`cleared`
|===

. Filter alarms by acknowledgment status by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "${ALARMS_URL}/alarms?filter=(eq,alarmAcknowledged,false)" | jq
----

. Get a specific alarm by its identifier by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "${ALARMS_URL}/alarms/<alarm_id>" | jq
----
+
* Replace `<alarm_id>` with the `alarmEventRecordId` value.

.Verification

* A successful response returns a JSON array of alarm records. An empty array indicates no alarms match the filter criteria.
