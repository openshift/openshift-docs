= Model and provider evaluation results
:context: ols-model-provider-evaluation-results

[role="_abstract"]
Red{nbsp}Hat evaluates supported large language model (LLM) provider and model combinations by using open source evaluation harnesses. The following tables summarize the most recent evaluation harness results for conversational and Agentic {ols-long}. You can run the same harnesses yourself against any supported provider with the models of your choosing.

[NOTE]
====
Red{nbsp}Hat does not provide support for any specific models or make suggestions or support statements pertaining to models. The following results are provided for guidance only. Model quality can change between model versions, and your results can vary depending on your workloads, prompts, and configuration.
====

The following table columns describe each evaluation:

Evaluation scope:: The number of scenarios multiplied by the number of runs per scenario, and the number of runs that ended in an error.
Evaluation score:: The mean correctness score on a 0–100 scale, calculated by averaging available scores within each scenario and then across scenarios. Evaluations without a numeric score (errors) are excluded. Brackets show an approximate 95% confidence interval (CI).
Token usage:: The input and output token counts at the 99th percentile (p99).
Response time:: The end-to-end response time at the 99th percentile (p99), in seconds.

All results were produced during the Q3 2026 evaluation period.

[NOTE]
====
These results represent a point-in-time evaluation. Model providers may release new versions, and Red{nbsp}Hat periodically updates these evaluations. Check the documentation publication date for result currency.
====

== Evaluation methodology and resources

The evaluations used the open source link:https://github.com/lightspeed-core/lightspeed-evaluation[`lightspeed-evaluation`] project, with selected troubleshooting scenarios from the link:https://github.com/rhobs/troubleshooting-scenarios/tree/67f897e2b333e76bd252429a638fac29ef7a63df/agentic[`troubleshooting-scenarios`] repository. These projects are evaluation resources and are not components of {ols-long}.

You can adapt these resources to evaluate your own provider, model, and environment by configuring your {ols-long} deployment and evaluation setup or dataset.
