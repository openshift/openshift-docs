= Container build tool options

[role="_abstract"]
Building and managing containers with `buildah`, `podman`, and `skopeo` results in industry-standard container images that include features specifically tuned for deploying containers in {product-title} or other Kubernetes environments. These daemonless, rootless tools reduce overhead while tuning your containers for Kubernetes.

[IMPORTANT]
====
Support for Docker Container Engine as a container runtime is deprecated in Kubernetes 1.20 and will be removed in a future release. However, Docker-produced images continue to work in your cluster with all runtimes, including CRI-O. For more information, see the "Kubernetes blog announcement".
====

When you ultimately run your containers in {product-title}, you use the CRI-O container engine. 
CRI-O runs on every compute and control plane machine in an {product-title} cluster, 
but CRI-O is not yet supported as a standalone runtime outside of {product-title}.
