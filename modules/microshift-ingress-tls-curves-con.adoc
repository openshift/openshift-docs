= About TLS curves for the ingress controller

[role="_abstract"]
The ingress controller advertises TLS curves, also called key-exchange groups, during the TLS handshake. By default, the advertised list includes a hybrid post-quantum group. You cannot set TLS curves in the {microshift-short} configuration file.

The `ingress.tlsSecurityProfile` parameter configures the minimum TLS version and the cipher suites only. {microshift-short} selects the TLS curves for the ingress router based on whether the node runs in FIPS mode.

When the node does not run in FIPS mode, the default list includes `X25519MLKEM768`. `X25519MLKEM768` is a hybrid post-quantum group that combines the classical `X25519` key exchange with the Module-Lattice-Based Key-Encapsulation Mechanism 768 (ML-KEM-768). Clients that do not support `X25519MLKEM768` can negotiate another advertised curve.

If the node runs in FIPS mode, {microshift-short} advertises only FIPS-approved National Institute of Standards and Technology (NIST) curves. {microshift-short} also removes TLS 1.3 cipher suites that are not FIPS-approved. The OpenSSL FIPS 140-3 provider does not support ML-KEM or `X25519`.
