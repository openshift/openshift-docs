= Removed features

[role="abstract"]
This section includes removed features for {product-title} {product-version}.

*Removal of oc-mirror plugin v1 documentation*

The oc-mirror plugin v1 documentation has been removed from the Red Hat Customer Portal and is no longer available. In future releases, oc-mirror will adopt an asynchronous release schedule. As a result, the oc-mirror documentation will be published independently of {product-title} general availability (GA) releases.

For more information on disconnected image mirroring, see link:https://docs.redhat.com/en/documentation/openshift_container_platform/latest/html-single/disconnected_environments/index#about-installing-oc-mirror-v2[Mirroring images for a disconnected installation by using the oc-mirror plugin v2].
