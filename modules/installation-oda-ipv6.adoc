= IPv6 limitations

[role="_abstract"]
Review IPv6 networking limitations before you install {product-title} on {oda-first}.

[IMPORTANT]
====
{oda-first} does not provide IPv6 networking. You cannot install a cluster that uses IPv6 or dual-stack networking on {oda}.
====
