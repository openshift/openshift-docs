= Create an OSD cluster on {GCP} with WIF authentication

[role="_abstract"]
Create an {product-title} cluster on {GCP} that authenticates with Workload Identity Federation (WIF).

WIF lets an {product-title} cluster authenticate to {GCP} by using short-lived credentials instead of long-lived service account keys. WIF is the recommended authentication method on {GCP} because it reduces the risks associated with managing and storing static credentials.
