= Access the GitOps Overview dashboard

[role="_abstract"]
Navigate to the GitOps Overview dashboard to view Application status and GitOps infrastructure.

.Procedure

. In the *Administrator* or *Core platform* perspective, navigate to *GitOps* -> *Overview*.

. Optional: Use the project (namespace) selector to limit the dashboard to one project, or choose *All Projects*.
+
When you change the project, the console updates both tabs. Counts, charts, and lists reflect Applications and other resources in that scope.
