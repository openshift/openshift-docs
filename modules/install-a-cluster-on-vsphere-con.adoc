= Install a cluster on vSphere

[role="_abstract"]
Install a {product-title} cluster on {vmw-first} by using installer-provisioned infrastructure. This supplement follows the common installation journey and adds the steps that on-premise platforms require: defining vSphere regions, zones, and host groups, configuring an external load balancer for the API and ingress endpoints, and configuring storage for the internal image registry.

Before you begin, set up your installation host by following "Prepare to install OpenShift".
