= Plan observability to monitor mesh health

[role="_abstract"]

A service mesh generates telemetry for every connection between services.
With the right tools in place, you can use this telemetry to see how traffic flows through your mesh, identify failing or slow services before users are affected, and trace a single request across multiple services to pinpoint where problems occur.

{SMProductShortName} builds on the monitoring stack already included in {ocp-product-title} and integrates with Kiali for mesh-specific visualization and management.
