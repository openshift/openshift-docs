= Application Overview tab

[role="_abstract"]
The Application Overview tab summarizes Application status for the selected project or all projects.

The *Sync status* card shows a donut chart of Applications by sync state: Synced, OutOfSync, or Unknown. Legend entries include counts and percentages. Click a sync status link to open the Applications list filtered to that status.

The *Health status* card shows a donut chart of Applications by health: Healthy, Progressing, Degraded, Missing, Suspended, or Unknown. Legend entries include counts and percentages. Click a health status link to open the Applications list filtered to that health.

The *Operational metrics* card shows live Argo CD metrics for the selected scope. Metric labels link to the console metrics query browser. Values refresh about every 10 seconds when metrics are available, and the card title shows the time of the last update. The card shows:

* *Successful syncs*: Cumulative count of syncs with phase Succeeded (not limited to the last 24 hours).
* *Failed syncs*: Count of syncs that are not Succeeded in a 24-hour sliding window.
* *Orphaned resources*: Resources that no Application manages.
* *Apps with Autosync enabled*: Applications that enable automatic synchronization.
* *Apps with Autosync disabled*: Applications that require manual synchronization.
* *Repo Queue*: Number of repository operations in the queue.
* *Git fetch failures*: Count of failed Git fetch operations.

Click a metric to open the related query in monitoring.

[NOTE]
====
If a query fails, that metric shows a red dash (`----`). If the query succeeds but returns no data, the metric shows `0000`, which looks the same as a real zero. When a value looks wrong, open the query in monitoring to confirm whether Prometheus collects the metric.
====

The *Applications Needing Attention* card lists Applications that are not both Healthy and Synced. The title includes the count of matching Applications. Each row can show the Application name, details (for example, conditions or resource status), and status (health and sync). Use the Application name link to open the Application details page. Use *View Applications List Page* when present to open the Applications list for the current scope. The card lists up to 20 Applications. When more than 20 need attention, the card ends with *...and _n_ more*, and the count in the title remains the full number. When every Application is Healthy and Synced, the card shows an empty state.

The *Recent Operations* card lists up to the last 5 finished Application operations, newest first. Each row can show the Application name, phase (for example, Succeeded, Failed, Running), message, and finished timestamp. Use the Application name link to open details. When no finished operations exist, the card shows an empty state.

The *Application Sync Activity (24 hours)* card charts three Prometheus series over the last 24 hours for the selected project or all projects:

[cols="1,3",options="header"]
|===
|Series |Description

|Syncs (24h sliding window)
|Number of sync operations in a 24-hour moving window. A sync adds one to this count and drops off 24 hours later.

|Synced
|Number of Applications in the Synced state.

|Out of Sync
|Number of Applications in the OutOfSync state.
|===

When metrics do not exist, the card shows loading, empty, or error content. Use *View in Observe/Metrics* when metrics load without error to open the related monitoring query.

The *Application Reconciliation Performance (24 hours)* card charts Application reconciliations from the `argocd_app_reconcile_count` metric for the selected project or all projects. Use it to see how often Applications are reconciled in the selected scope:

[cols="1,3",options="header"]
|===
|Series |Description

|Reconciliations (24h sliding window)
|Number of Application reconciliations in a 24-hour moving window.
|===

When metrics do not exist, the card shows loading, empty, or error content. Use *View in Observe/Metrics* when metrics load without error to open the related monitoring query.
