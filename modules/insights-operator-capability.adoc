= Insights Operator

[role="_abstract"]

The {insights-operator} provides the features for the `Insights` capability.

The {insights-operator} gathers {product-title} configuration data and sends it to Red{nbsp}Hat. 

The data is used to produce proactive insights recommendations about potential issues that a cluster might be exposed to. These insights are communicated to cluster administrators through the {red-hat-lightspeed} advisor service on link:https://console.redhat.com/[console.redhat.com].


Notes::
+
{insights-operator} complements {product-title} Telemetry.
