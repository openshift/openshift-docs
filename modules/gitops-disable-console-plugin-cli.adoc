= Disable the GitOps Console plugin using the CLI

You can disable the GitOps Console plugin using the OpenShift CLI.

.Prerequisites

* You have access to the cluster with `cluster-admin` permissions.
* You have installed the OpenShift CLI (`oc`).

.Procedure

. Edit the Console operator and remove `gitops-plugin` from `spec.plugins`:
+
[source,terminal]
----
$ oc edit console.operator.openshift.io cluster
----
+
.Example
[source,yaml]
----
spec:
  plugins:
    - monitoring-plugin
    # remove: - gitops-plugin
----

. After saving the change, refresh the browser.

.Verification

* The *GitOps* entry disappears from the navigation menu when the plugin is disabled.
