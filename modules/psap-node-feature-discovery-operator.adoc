= About the Node Feature Discovery Operator

endif::perf[]
[role="_abstract"]
You can use the Node Feature Discovery Operator (NFD) to detect hardware features and system configuration on cluster nodes, labeling them with attributes such as PCI cards, kernel version, operating system version, and CPU capabilities. These labels enable workload scheduling based on specific hardware requirements.

The NFD Operator can be found on the OperatorHub by searching for “Node Feature Discovery”.
