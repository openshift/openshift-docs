= Configuring the trust manager operand

[role="_abstract"]
To establish secure TLS connections between containerized applications and host hardware device endpoints, configure the trust-manager operand to distribute host CA certificates to your application namespaces.

:FeatureName: Distributing certificates by using trust manager
include::snippets/technology-preview.adoc[leveloffset=+1]

.Prerequisites

* You have administrative access to the {microshift-short} node.
* The cert-manager operator and the trust-manager operand are installed and active.
* The custom CA certificate of the host hardware device is available as a `ConfigMap` named `host-device-ca` in the `cert-manager` namespace.

.Procedure

. Define a `Bundle` custom resource that specifies the source certificate and the target namespaces. Create a file named `host-device-bundle.yaml` with the following content:
+
[source,yaml]
----
apiVersion: trust.cert-manager.io/v1alpha1
kind: Bundle
metadata:
  name: host-device-trust
spec:
  sources:
    - configMap:
        name: host-device-ca
        key: ca.crt
  target:
    configMap:
      key: ca-bundle.crt
----

. Apply the `Bundle` custom resource manifest to your node by running the following command:
+
[source,terminal]
----
$ oc apply -f host-device-bundle.yaml
----

. Edit your application `Pod` specification to mount the distributed trust bundle `ConfigMap`. Create a file named `application-pod.yaml` with the following content:
+
[source,yaml]
----
apiVersion: v1
kind: Pod
metadata:
  name: host-device-app
  namespace: app-namespace
spec:
  containers:
    - name: device-connector
      image: ubi8/ubi:8.10
      volumeMounts:
        - name: trust-bundle
          mountPath: /etc/pki/ca-trust/extracted/pem
          readOnly: true
  volumes:
    - name: trust-bundle
      configMap:
        name: host-device-trust
----

. Create the `Pod` in your namespace by running the following command:
+
[source,terminal]
----
$ oc apply -f application-pod.yaml
----

.Verification

. Verify that the trust-manager operand successfully created and distributed the `ConfigMap` to your application namespace by running the following command:
+
[source,terminal]
----
$ oc get configmap host-device-trust -n app-namespace
----
+
.Expected output:

[source,text]
----
NAME                DATA   AGE
host-device-trust   1      2m
----

. Verify that the application container can read the mounted CA certificate file from the mount path by running the following command:
+
[source,bash]
----
$ oc exec host-device-app -n app-namespace -- ls /etc/pki/ca-trust/extracted/pem
----
+
Expected output:
+
[source,text]
----
ca-bundle.crt
----
