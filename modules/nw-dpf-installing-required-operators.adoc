= Required Operators

[role="_abstract"]
Before you install the DPF Operator, you must install the {cert-manager-operator}, MetalLB Operator, {gitops-title}, and NVIDIA Maintenance Operator.

The multicluster engine Operator and the Node Feature Discovery Operator can be installed during management cluster creation by using the Assisted Installer. After installation, configure those Operators, MetalLB, {gitops-shortname}, and the Cluster Network Operator as described in "Configure the required Operators".
