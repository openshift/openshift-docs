= Status bar

[role="_abstract"]
The *Status Bar* provides at-a-glance numerical counters for key resources. The counters reflect what is visible within your current access scope. The roles associated with your user profile define this scope. Counters are clickable, providing fast access to needed list view pages as follows:

[cols="1,1"]
|===
| Counter | Destination

| Clusters
| Platform Configuration -> Clusters

| Nodes
| Configuration Management -> Application & Infrastructure → Nodes

| Violations
| Violations main menu

| Deployments
| Configuration Management -> Application & Infrastructure → Deployments

| Images
| Vulnerability Management -> Dashboard -> Images

| Secrets
| Configuration Management -> Application & Infrastructure -> Secrets
|===
