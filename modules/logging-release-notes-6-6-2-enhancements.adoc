= New features and enhancements

[role="_abstract"]
This release of {LoggingProductName} includes the following new features and enhancements.

Prometheus alert for BoltDB storage schema deprecation::
With this release, a new Prometheus alert warns administrators when LokiStack is configured to use the BoltDB storage schema. BoltDB is deprecated and will not be supported in future versions of Loki. The alert prompts administrators to migrate to a supported schema before upgrading to future versions of the operator. (link:https://issues.redhat.com/browse/LOG-10395[LOG-10395])

Loki ingester data durability on shutdown::
With this release, Loki ingesters flush in-memory log data to object storage when shutting down, rather than writing only to local disk. This increases data durability by ensuring that log data is not local to the ingester pod and is not lost if the pod is terminated unexpectedly. The ingester shutdown grace period has been increased to accommodate the additional flush time. (link:https://issues.redhat.com/browse/LOG-10324[LOG-10324])
