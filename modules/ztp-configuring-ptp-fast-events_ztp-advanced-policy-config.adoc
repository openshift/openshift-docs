= Configuring PTP events that use HTTP transport

[role="_abstract"]
You can configure PTP events that use HTTP transport on managed clusters that you deploy with the {ztp-first} pipeline.

.Prerequisites

* You have installed the OpenShift CLI (`oc`).

* You have logged in as a user with `cluster-admin` privileges.

* You have created a Git repository where you manage your custom site configuration data.

.Procedure

. Apply the following `PolicyGenTemplate` changes to `group-du-3node-ranGen.yaml`, `group-du-sno-ranGen.yaml`, or `group-du-standard-ranGen.yaml` files according to your requirements:

.. In `spec.sourceFiles`, add the `PtpOperatorConfig` CR file that configures the transport host:
+
[source,yaml]
----
include::snippets/pgt-ztp-configuring-ptp-fast-events.yaml[]
----

====
In [.pr:openshift-enterprise]#OpenShift Container Platform# [.pr:openshift-origin]#OKD# [.pr:openshift-dedicated]#OpenShift Dedicated# [.pr:openshift-rosa]#Red Hat OpenShift Service on AWS (classic architecture)# [.pr:openshift-rosa-hcp]#Red Hat OpenShift Service on AWS# [.pr:microshift]#Red Hat build of MicroShift# 4.13 or later, you do not need to set the `transportHost` field in the `PtpOperatorConfig` resource when you use HTTP transport with PTP events.
====
