= Can you provision S3-compatible object storage?

*Yes:*

* Proceed to choose between Scenario 2 or 3

*No:*

* Use *Scenario 1* (Vector only) - forward logs to an external system that provides storage

*Note:* Object storage is a hard requirement for Loki. Without it, you cannot use Scenarios 2 or 3.
