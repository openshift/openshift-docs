= Native virtual machine templates

[role="_abstract"]
A `VirtualMachineTemplate` is a native, in-cluster resource that defines a reusable virtual machine (VM) blueprint with parameterized values. You can use `VirtualMachineTemplates` to deploy consistent VMs across namespaces, capturing storage state such as `DataVolume` snapshots and cloned disks.

Unlike traditional templates, `VirtualMachineTemplates` are native to {product-title} and support new use cases, such as creating templates from existing VMs and importing and exporting templates to and from the cluster.

The `VirtualMachineTemplate` feature introduces two custom resource definitions (CRDs):

`VirtualMachineTemplate`:: Defines a reusable VM blueprint with parameters. Each template contains a VM specification with parameter placeholders and a list of parameter definitions that control how those placeholders are resolved during processing.

`VirtualMachineTemplateRequest`:: Creates a `VirtualMachineTemplate` from an existing VM. This enables you to convert a configured VM into a reusable template.
