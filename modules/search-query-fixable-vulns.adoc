= Finding deployments that have serious but fixable vulnerabilities

[role="_abstract"]
You can search for deployments that have vulnerabilities with a high CVSS score and an available fix.

|===
| Query | Example

| `CVSS:<expression_and_score>`
| `CVSS:>=6` `Fixable:.*`
|===
