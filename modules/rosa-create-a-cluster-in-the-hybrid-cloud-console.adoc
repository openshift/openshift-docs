= Create a cluster in the {hybrid-console-second}

[role="_abstract"]
Create a {product-title} cluster with the default options by using {cluster-manager-first} in the {hybrid-console-second}.

After you prepare your AWS account, you can create a {product-title} cluster from a web interface. {cluster-manager-first} in the {hybrid-console-second} guides you through cluster creation with a visual workflow and a guided experience.
