=  Enhancing the {product-title} web console with Operators

[role="_abstract"]
Cluster administrators can install Operators from the software catalog to extend the {product-title} web console beyond layered products. For example, the {web-terminal-op} adds a browser-based terminal with common CLI tools for interacting with the cluster.
