= External claims sourcing parameters

[role="_abstract"]
Use these parameters in the `externalClaimsSources` field of the `oidcProviders` configuration to configure external claims sourcing.

:FeatureName: External claims sourcing
include::snippets/technology-preview.adoc[]

`externalClaimsSources`::
Specifies a list of external sources for additional identity information. Each source defines an external HTTP endpoint, authentication credentials, and claim mappings. Between 1 and 5 sources can be configured. Mapping names must be unique across all sources.

`externalClaimsSources[].authentication`::
Specifies how the API server authenticates with the external source endpoint. When omitted, no authentication is used.

`externalClaimsSources[].authentication.type`::
Specifies the authentication mode. Must be one of the following values:
+
--
`RequestProvidedToken`::: Passes the user's ID token from the incoming request as a bearer token to the external endpoint. Use for standard OIDC `UserInfo` endpoints.
`ClientCredential`::: Uses OAuth2 client credentials to obtain an access token for the external endpoint. Requires the `clientCredential` field. Use for APIs that require separate authentication, such as the Microsoft Graph API.
--

`externalClaimsSources[].authentication.clientCredential`::
Specifies the OAuth2 client credential configuration. Required when `authentication.type` is `ClientCredential`. Must not be set when `authentication.type` is `RequestProvidedToken`.

`externalClaimsSources[].authentication.clientCredential.clientID`::
Specifies the OAuth2 client identifier. 1-256 printable ASCII characters.

`externalClaimsSources[].authentication.clientCredential.clientSecret.name`::
Specifies the name of a secret in the `openshift-config` namespace that stores the OAuth2 client secret in the `client-secret` key. Valid DNS subdomain name, 1-253 characters.

`externalClaimsSources[].authentication.clientCredential.tokenEndpoint`::
Specifies the OAuth2 token endpoint URL for exchanging client credentials for an access token. Must be a valid HTTPS URL with a host and path. Must not contain query parameters, fragments, or user information. Maximum 2048 characters.

`externalClaimsSources[].authentication.clientCredential.scopes`::
Specifies the OAuth2 scopes to request. Each scope must be 1-256 printable ASCII characters, excluding spaces, double quotes, and backslashes. Between 1 and 16 unique scopes can be configured.

`externalClaimsSources[].authentication.clientCredential.tls`::
Specifies the TLS configuration for the OAuth2 token endpoint.

`externalClaimsSources[].authentication.clientCredential.tls.certificateAuthority.name`::
Specifies a config map in the `openshift-config` namespace containing the PEM-encoded CA bundle in the `ca-bundle.crt` key. Valid DNS subdomain name, 1-253 characters.

`externalClaimsSources[].tls`::
Specifies the TLS configuration for the external source endpoint. When omitted, system CA trust is used.

`externalClaimsSources[].tls.certificateAuthority.name`::
Specifies a config map in the `openshift-config` namespace containing the PEM-encoded CA bundle in the `ca-bundle.crt` key. Valid DNS subdomain name, 1-253 characters.

`externalClaimsSources[].url`::
Specifies the URL for the external source endpoint.

`externalClaimsSources[].url.hostname`::
Specifies the hostname of the external source endpoint, with an optional port (up to 65535). Valid DNS subdomain, maximum 259 characters.

`externalClaimsSources[].url.pathExpression`::
Specifies a CEL expression that constructs the URL path. Must return a `list(string)`. Each string is path-escaped and joined with `/` to form the request path. The `claims` variable provides access to JWT token claims. 1-1024 characters.
+
.Example path expressions
[source]
----
['realms', 'k8s', 'protocol', 'openid-connect', 'userinfo']
['v1.0', 'users', claims.preferred_username, 'memberOf']
['admin', 'realms', 'k8s', 'users'] + [claims.sub] + ['groups']
----
+
`['realms', 'k8s', 'protocol', 'openid-connect', 'userinfo']`:: Static path resolving to `/realms/k8s/protocol/openid-connect/userinfo`.
`['v1.0', 'users', claims.preferred_username, 'memberOf']`:: Dynamic path that uses the `preferred_username` claim, resolving to `/v1.0/users/<username>/memberOf`.
`['admin', 'realms', 'k8s', 'users'] + [claims.sub] + ['groups']`:: Dynamic path that uses list concatenation, resolving to `/admin/realms/k8s/users/<sub>/groups`.

`externalClaimsSources[].mappings`::
Specifies claim mappings that extract values from the external source response. Between 1 and 16 mappings can be configured. Names must be unique across all configured external claims sources.

`externalClaimsSources[].mappings[].name`::
Specifies the claim name. Lowercase alphabetic characters and underscores only, 1-256 characters. Must be unique across all mappings in all external claims sources.

`externalClaimsSources[].mappings[].expression`::
Specifies a CEL expression that extracts the claim value from the external source response. The `response.body` variable provides access to the parsed JSON response body. Must return a string or string array value. 1-1024 characters.
+
.Example mapping expressions
[source]
----
has(response.body.groups) ? response.body.groups : []
has(response.body.value) ? response.body.value.map(x, x.displayName) : []
has(response.body.email) ? response.body.email : ""
----
+
`has(response.body.groups) ? response.body.groups : []`:: Extracts a `groups` array directly from the response.
`has(response.body.value) ? response.body.value.map(x, x.displayName) : []`:: Extracts group display names from a nested response structure, such as the Microsoft Graph API.
`has(response.body.email) ? response.body.email : ""`:: Extracts a single string value, falling back to an empty string.

`externalClaimsSources[].predicates`::
Specifies CEL expressions that control whether this external source is queried. All expressions must evaluate to `true` for the source to be queried. When omitted, the source is always queried. Between 1 and 16 predicates can be configured.

`externalClaimsSources[].predicates[].expression`::
Specifies a CEL expression that evaluates to a boolean. The `claims` variable provides access to JWT token claims. 1-1024 characters.
+
.Example predicate expressions
[source]
----
!has(claims.groups)
claims.iss == 'https://idp.example.com'
----
+
`!has(claims.groups)`:: Queries the external source only when the JWT token does not contain a `groups` claim.
`claims.iss == 'https://idp.example.com'`:: Queries the external source only when the token was issued by a specific identity provider.
