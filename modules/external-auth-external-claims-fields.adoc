= External claims sourcing parameters

[role="_abstract"]
Use these parameters in the `externalClaimsSources` field of the `oidcProviders` configuration to configure external claims sourcing.

:FeatureName: External claims sourcing
include::snippets/technology-preview.adoc[]

`externalClaimsSources`::
Specifies a list of external sources for additional identity information. Each source defines an external HTTP endpoint, authentication credentials, and claim mappings. A minimum of 1 and maximum of 5 sources can be configured. Mapping names must be unique across all sources.

`externalClaimsSources[].authentication`::
Specifies how the API server authenticates with the external source endpoint. When omitted, no authentication is used.

`externalClaimsSources[].authentication.type`::
Specifies the authentication mode for the external source. Must be one of the following values:
+
--
`RequestProvidedToken`::: Specifies that the user's ID token from the incoming request is passed as a bearer token to the external endpoint. Use for standard OIDC `UserInfo` endpoints.
`ClientCredential`::: Specifies that the API server uses OAuth2 client credentials to obtain an access token for the external endpoint. Requires the `clientCredential` field. Use for APIs that require separate authentication, such as the Microsoft Graph API.
--

`externalClaimsSources[].authentication.clientCredential`::
Specifies the OAuth2 client credential configuration. Required when `authentication.type` is set to `ClientCredential`. Must not be set when `authentication.type` is set to `RequestProvidedToken`.

`externalClaimsSources[].authentication.clientCredential.clientID`::
Specifies the OAuth2 client identifier for the external source. Must be between 1 and 256 printable ASCII characters.

`externalClaimsSources[].authentication.clientCredential.clientSecret.name`::
Specifies the name of a secret in the `openshift-config` namespace that stores the OAuth2 client secret in the `client-secret` key. Must be a valid DNS subdomain name between 1 and 253 characters.

`externalClaimsSources[].authentication.clientCredential.tokenEndpoint`::
Specifies the URL for the OAuth2 token endpoint used to exchange client credentials for an access token. Must be a valid HTTPS URL with a host and path. Must not contain query parameters, fragments, or user information. Maximum 2048 characters.

`externalClaimsSources[].authentication.clientCredential.scopes`::
Specifies the OAuth2 scopes to request when obtaining an access token. Each scope must be 1-256 printable ASCII characters, excluding spaces, double quotes, and backslashes. Between 1 and 16 unique scopes can be configured.

`externalClaimsSources[].authentication.clientCredential.tls`::
Specifies the TLS configuration for the OAuth2 token endpoint.

`externalClaimsSources[].authentication.clientCredential.tls.certificateAuthority.name`::
Specifies the name of a config map in the `openshift-config` namespace that stores the Privacy-Enhanced Mail (PEM)-encoded certificate authority bundle in the `ca-bundle.crt` key. Must be a valid DNS subdomain name between 1 and 253 characters.

`externalClaimsSources[].tls`::
Specifies the TLS configuration for the external source endpoint. When omitted, the system certificate authority trust is used.

`externalClaimsSources[].tls.certificateAuthority.name`::
Specifies the name of a config map in the `openshift-config` namespace that stores the PEM-encoded certificate authority bundle in the `ca-bundle.crt` key. Must be a valid DNS subdomain name between 1 and 253 characters.

`externalClaimsSources[].url`::
Specifies the URL for the external source endpoint.

`externalClaimsSources[].url.hostname`::
Specifies the hostname of the external source endpoint. Can include an optional port number up to 65535. Must be a valid DNS subdomain and must not exceed 259 characters.

`externalClaimsSources[].url.pathExpression`::
Specifies a CEL expression that constructs the URL path for the external source request. Must return a `list(string)` value. Each string is path-escaped and joined with `/` to form the request path. The `claims` variable provides access to JWT token claims for constructing dynamic paths. Must be between 1 and 1024 characters.
+
.Example path expressions
[source]
----
['realms', 'k8s', 'protocol', 'openid-connect', 'userinfo']
['v1.0', 'users', claims.preferred_username, 'memberOf']
['admin', 'realms', 'k8s', 'users'] + [claims.sub] + ['groups']
----
+
`['realms', 'k8s', 'protocol', 'openid-connect', 'userinfo']`:: Specifies a static path that resolves to `/realms/k8s/protocol/openid-connect/userinfo`.
`['v1.0', 'users', claims.preferred_username, 'memberOf']`:: Specifies a dynamic path that uses the `preferred_username` claim from the JWT token to resolve to `/v1.0/users/<username>/memberOf`.
`['admin', 'realms', 'k8s', 'users'] + [claims.sub] + ['groups']`:: Specifies a dynamic path by using list concatenation to resolve to `/admin/realms/k8s/users/<sub>/groups`.

`externalClaimsSources[].mappings`::
Specifies a list of claim mappings that extract values from the external source response. Between 1 and 16 mappings can be configured. Mapping names must be unique across all configured external claims sources.

`externalClaimsSources[].mappings[].name`::
Specifies the name of the claim to create from the external source response. Must contain only lowercase alphabetic characters and underscores, between 1 and 256 characters. Must be unique across all mappings in all configured external claims sources.

`externalClaimsSources[].mappings[].expression`::
Specifies a CEL expression that extracts the claim value from the external source response. The `response.body` variable provides access to the parsed JSON response body. Must return a string or string array value. Must be between 1 and 1024 characters.
+
.Example mapping expressions
[source]
----
has(response.body.groups) ? response.body.groups : []
has(response.body.value) ? response.body.value.map(x, x.displayName) : []
has(response.body.email) ? response.body.email : ""
----
+
`has(response.body.groups) ? response.body.groups : []`:: Specifies an expression that extracts a `groups` array directly from the response.
`has(response.body.value) ? response.body.value.map(x, x.displayName) : []`:: Specifies an expression that extracts group display names from a nested response structure, such as the Microsoft Graph API response.
`has(response.body.email) ? response.body.email : ""`:: Specifies an expression that extracts a single string value, falling back to an empty string.

`externalClaimsSources[].predicates`::
Specifies a list of CEL expressions that control whether this external source is queried for a given request. All expressions must evaluate to `true` for the source to be queried. When omitted, the source is always queried. Between 1 and 16 predicates can be configured.

`externalClaimsSources[].predicates[].expression`::
Specifies a CEL expression that evaluates to a boolean value. The `claims` variable provides access to JWT token claims. Must be between 1 and 1024 characters.
+
.Example predicate expressions
[source]
----
!has(claims.groups)
claims.iss == 'https://idp.example.com'
----
+
`!has(claims.groups)`:: Specifies an expression that only queries the external source when the JWT token does not contain a `groups` claim.
`claims.iss == 'https://idp.example.com'`:: Specifies an expression that only queries the external source when the token was issued by a specific identity provider.
