= Convert to IPv4/IPv6 dual-stack networking

[role="_abstract"]
You can convert a single-stack cluster to dual-stack networking so that the cluster network carries both IPv4 and IPv6 traffic. After conversion, pods can use both address families when you re-create your workloads.
