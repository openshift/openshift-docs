= Uninstall the Multiarch Tuning Operator

[role="_abstract"]
You can uninstall the Multiarch Tuning Operator from your cluster by using the {oc-first} or the web console. Before uninstalling, you must delete the `ClusterPodPlacementConfig` object to avoid unexpected behavior.
