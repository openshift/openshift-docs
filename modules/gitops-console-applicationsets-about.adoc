= About ApplicationSets in the GitOps Console

The {gitops-shortname} Console plugin provides list and details pages for Argo CD ApplicationSets in the {OCP} web console. You can view ApplicationSets, review generated Applications, inspect generators, and use the graphical view for owner-reference and progressive sync layouts.

The ApplicationSets list page provides the following capabilities:

* Filter ApplicationSets by health status
* Search ApplicationSets by name
* View ApplicationSet metadata including generated Applications count and generators count
* Create ApplicationSets from YAML templates

The ApplicationSet details page includes the following tabs:

* *Details*: Identity, status, conditions, and related counts
* *YAML*: Live manifest editor
* *Generators*: Structured view of generator configuration
* *Applications*: Generated Applications in list or graph view
* *Events*: Kubernetes events for the ApplicationSet object

The *Applications* tab graph view provides two layouts:

* *Standard layout*: Owner-reference tree when progressive sync is not active
* *Progressive Sync Flow View*: Step groups when progressive sync is enabled
