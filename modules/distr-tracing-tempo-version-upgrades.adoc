= Version upgrades

[role="_abstract"]
The Operator Lifecycle Manager (OLM) manages the {TempoOperator} on the {ocp-product-title} by default.

For version upgrades, OLM queries for available upgrades for the installed {TempoOperator}.

When OLM upgrades the {TempoOperator}, the Operator scans for running TempoStack instances and upgrades those instances to match the Operator's updated version.
