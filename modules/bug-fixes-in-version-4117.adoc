= Bug fixes and security updates in version 4.11.7

[role="_abstract"]
This release addresses the following security vulnerabilities:

//ROX-37689
* Man-in-the-middle attacks through untrusted intermediate certificates (link:https://access.redhat.com/security/cve/CVE-2026-111943[CVE-2026-111943])

//ROX-37683
* Distrust eMudhra intermediate CA certificates due to security concerns (link:https://access.redhat.com/security/cve/CVE-2026-114406[CVE-2026-114406])

//ROX-37824, ROX-37825, ROX-37828, ROX-37829, ROX-37832, ROX-37833, ROX-37835
* klauspost/compress: Denial of Service via crafted `zstd` compressed input (link:https://access.redhat.com/security/cve/CVE-2026-116591[CVE-2026-116591])
