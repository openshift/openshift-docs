== Current limitations

* HashiCorp Vault Enterprise is the only supported KMS provider. Vault Community Edition is not supported. // cite:1
// cite:1 VERIFIED [97]: https://github.com/openshift/api/blob/9edb1b2/config/v1/types_kmsencryption.go#L17-L19 - "Vault Enterprise server that is managed by the user outside the purview of the control plane"
// cite:1 VERIFIED [97]: https://github.com/openshift/api/blob/9edb1b2/config/v1/types_kmsencryption.go#L44 - KubeBuilder Enum=Vault (only provider type)
* Unused KMS plugins are not automatically removed from the `EncryptionConfiguration` after migration completes. You must manually decommission old providers. // cite:2
// cite:2 VERIFIED [92]: https://github.com/openshift/enhancements/blob/66c24fe/enhancements/kube-apiserver/kms-encryption-foundations.md#L400 - "The removal mechanism is out of scope in Tech Preview v2"
// cite:2 VERIFIED [92]: https://github.com/openshift/enhancements/blob/66c24fe/enhancements/kube-apiserver/kms-encryption-foundations.md#L65 - TP v3 goal: "Removal of unused KMS plugins from EncryptionConfiguration after migration completes"
* The `KMSEncryption` feature gate requires the `TechPreviewNoUpgrade` feature set. Clusters with this feature set enabled cannot be upgraded to later versions. // cite:3
// cite:3 VERIFIED [97]: https://github.com/openshift/api/blob/9edb1b2/features/features.go#L669-L674 - FeatureGateKMSEncryption enabled in inDevPreviewNoUpgrade(), inTechPreviewNoUpgrade()
