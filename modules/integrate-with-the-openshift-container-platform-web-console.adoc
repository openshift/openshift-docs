= Integrate with the {ocp} web console

[role="_abstract"]
Check workload vulnerabilities in the same console you use to run the cluster. Enable the {rh-rhacs-console-plugin} dynamic plugin that the {product-title-short} Operator includes, then click *Security* -> *Vulnerabilities* to review CVEs, images, and deployments.
