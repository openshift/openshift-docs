= Disabling RTE image validation

[role="_abstract"]
You can disable Resource Topology Exporter (RTE) image validation by setting the `RTE_IMAGE_VALIDATION` environment variable to `false` in the NUMA Resources Operator subscription.

[WARNING]
====
Disabling RTE image validation removes an important security control. With validation disabled, any user with write access to the `NUMAResourcesOperator` custom resource can specify an arbitrary container image that will run with RTE privileges on worker nodes.

This creates a security risk. A malicious RTE image can:

* Access sensitive hardware topology information on worker nodes
* Observe node resource allocation and NUMA zone configurations
* Read detailed system information that could facilitate other attacks
* Execute code with the RTE daemon set service account permissions

Only disable validation in exceptional circumstances. If you disable validation, ensure that only cluster administrators can modify `NUMAResourcesOperator` resources, and implement additional security controls to verify RTE image integrity.
====

.Prerequisites

* You have installed the OpenShift CLI (`oc`).
* You have logged in as a user with `cluster-admin` privileges.
* You have installed the NUMA Resources Operator.

.Procedure

. Disable validation by patching the NUMA Resources Operator subscription by running the following command:
+
[source,terminal]
----
$ oc patch subscription numaresources-operator \
  -n openshift-numaresources \
  --type=merge \
  -p '{"spec":{"config":{"env":[{"name":"RTE_IMAGE_VALIDATION","value":"false"}]}}}'
----

. Wait for the NUMA Resources Operator pod to restart by monitoring the pod status with the following command:
+
[source,terminal]
----
$ oc get pods -n openshift-numaresources -w
----

. Verify that validation is disabled by checking the NUMA Resources Operator pod environment by running the following command:
+
[source,terminal]
----
$ oc exec -n openshift-numaresources deploy/numaresources-controller-manager -- \
  printenv RTE_IMAGE_VALIDATION
----
+
An example of the expected output is provided below:
+
[source,terminal]
----
false
----
