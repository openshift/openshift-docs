= Uninstall {pipelines-shortname}

[role="_abstract"]
To completely uninstall {pipelines-title}, you must remove custom resources, uninstall the Operator, and clean up custom resource definitions. This process ensures that all {pipelines-title} components are properly removed from your cluster.

The uninstallation process requires removing custom resources for optional components such as `TektonHub` and `TektonResult`, along with the `TektonConfig` custom resource, before uninstalling the Operator. After removing the Operator, you must also delete the custom resource definitions from the `operator.tekton.dev` group.

[CAUTION]
====
If you uninstall the Operator without removing the custom resources of optional components, you cannot remove the components later.
====

Uninstalling only the Operator will not remove the {pipelines-title} components created by default when you install the Operator.
