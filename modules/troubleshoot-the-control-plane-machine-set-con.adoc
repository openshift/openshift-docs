= Troubleshoot the control plane machine set

[role="_abstract"]
A control plane machine set cannot manage your control plane machines if the machine set state is wrong, if a required provider parameter is missing, or if an upgraded cluster still carries a machine configuration that the machine set does not accept. Check the machine set state first, then apply the fix for your platform.
