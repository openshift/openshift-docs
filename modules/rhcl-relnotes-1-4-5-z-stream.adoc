== Bug fixes

// KEEP AS AN EXAMPLE
* Before this update, gateways did not detect unresponsive authorization or rate-limiting pods during restarts or rolling updates. As a result, applications using `AuthPolicy` or `RateLimitPolicy` custom resources (CRs) returned `500` or `503` errors during routine cluster maintenance. With this update, active health checking is added for authorization and rate-limiting connections and Authorino load is distributed evenly across all healthy replicas. Now, `AuthPolicy` and `RateLimitPolicy` CRs remain available during pod restarts and scaling events. (link:https://redhat.atlassian.net/browse/CONNLINK-1732[CONNLINK-1732])
