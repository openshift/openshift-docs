= Configure external IP addresses on services

[role="_abstract"]
You can configure ExternalIP addresses on services so that external traffic reaches your cluster through specific IP addresses. {product-title} provides controls to restrict which IP addresses can be set as external IPs, ensuring that cluster administrators retain control over external access.
