= Query infrastructure resources

[role="_abstract"]
You can query the O-Cloud Manager Inventory API to discover available infrastructure resources, including locations, sites, resource pools, and physical servers. This enables an Service Management and Orchestration (SMO) framework or automation system to identify what infrastructure is available before submitting provisioning requests.

.Prerequisites

* You authenticated to the O-Cloud Manager REST API and set the `API_BASE_URL` and `MY_TOKEN` environment variables.

.Procedure

. List all resource pools by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureInventory/v2/resourcePools" | jq
----
+
.Example output
[source,json]
----
[
  {
    "resourcePoolId": "7108c495-18c9-45ac-be47-e4b900c6f204",
    "oCloudSiteId": "fddfbbae-0fb3-402e-8408-6adbb6ba382a",
    "name": "dell-xr8620t-pool",
    "description": "Dell XR8620t compute resources",
    "extensions": {}
  }
]
----

. List the resources within a specific resource pool by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureInventory/v2/resourcePools/<resource_pool_id>/resources" | jq
----
+
* Replace `<resource_pool_id>` with the target `resourcePoolId` value.
* A resource with `usageState: IDLE` and `adminState: LOCKED` is available for allocation by a new provisioning request.
+
.Example output
[source,json]
----
[
  {
    "resourceId": "f3e79178-b199-4eb6-bfe3-b1417b7d5b8d",
    "resourcePoolId": "7208c495-18c9-45ac-be47-e4b900c6f204",
    "description": "XR8620t server",
    "resourceTypeId": "d1eabf91-f0e6-5170-97dc-797d35146dad",
    "globalAssetId": "296S2Z3",
    "extensions": {
      "adminState": "LOCKED",
      "operationalState": "DISABLED",
      "usageState": "IDLE",
      "powerState": "OFF",
      "vendor": "Dell Inc.",
      "model": "PowerEdge XR8620t"
    }
  }
]
----
+
[NOTE]
====
A `BareMetalHost` resource appears in the Inventory API only if it has a `resources.clcm.openshift.io/resourcePoolName` label and has completed hardware inspection. Servers that have not reached the `available` provisioning state or later do not appear in the API response.
====

. List all locations to view geographic site information by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureInventory/v2/locations" | jq
----

. List O-Cloud sites within a location by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureInventory/v2/oCloudSites" | jq
----

. List resource types to understand the classification of discovered resources by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureInventory/v2/resourceTypes" | jq
----
+
Each resource in a resource pool references a `resourceTypeId` that maps to an entry in this list.

. List deployment managers to view the managed clusters acting as infrastructure management endpoints by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureInventory/v2/deploymentManagers" | jq
----

. Filter resources by a specific field by running the following command:
+
[source,terminal]
----
$ curl -ks -H "Authorization: Bearer ${MY_TOKEN}" \
  "https://${API_BASE_URL}/o2ims-infrastructureInventory/v2/resourcePools?filter=(eq,name,<pool_name>)" | jq
----
+
* Replace `<pool_name>` with the name of the resource pool to filter.
