= Understand {mcpg} guardrails

[role="_abstract"] 
Guardrails can block dangerous calls or mask sensitive information. When guardrails are enabled on the MCP Gateway, every tool call request and/or response routed through the gateway is checked against the guardrails path.

MCP Gateway Guardrails Technical Definitions::

* _Guardrail configurations:_ A set of files that define what type of guardrails are applied (e.g PII detection, prompt injection detection) and how they are applied. These need to be defined as part of the NeMo Guardrails deployment process, before referencing them in the MCP Gateway

* _Global guardrails:_ Guardrail configurations that applied to every registered MCP server behind the Gateway

* _Per-server guardrails:_ Additional guardrail configurations that are applied to specific MCP servers (e.g servers that have access to sensitive information or vulnerable tools). When defined, per-server guardrails are merged with the global guardrails. During runtime, the global guardrails run first in order, before the per-server guardrails for each MCP server
