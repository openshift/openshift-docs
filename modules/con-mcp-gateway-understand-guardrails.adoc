= Understand {mcpg} guardrails

[role="_abstract"] 
You can add custom NeMo guardrails to your MCP Servers to enable protection when tool calling. Enabling guardrails allows tool calls to be checked and verified before execution, so potential dangerous calls are rejected.

MCP Gateway Guardrails Technical Definitions::

Guardrail configurations:: A set of files that define what type of guardrails are applied (e.g PII detection, prompt injection detection) and how they are applied. These need to be defined as part of the NeMo Guardrails deployment process, prior to referencing them in the MCP Gateway

Global guardrails:: Guardrail configurations that applied to every registered MCP server behind the Gateway

Per-server guardrails:: additional guardrail configurations that are applied to specific MCP servers (e.g servers that have access to sensitive information or vulnerable tools). When defined, per-server guardrails are merged with the global guardrails. During runtime, the global guardrails run first in order, before the per-server guardrails for each MCP server
