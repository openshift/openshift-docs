= Verifying the {ols-long} installation

[role="_abstract"]
After you install the {ols-long} Operator and configure the Service, verify that all of the expected workloads are deployed and that the custom resources (CRs) are in place.

.Prerequisites

* You have installed the {ols-long} Operator.

* You have configured the {ols-long} intelligent assistant, autonomous agents, or both.

* You have installed the {oc-first} and logged in to the cluster.

.Procedure

. Verify that all of the expected deployments are ready by running the following command:
+
[source,terminal]
----
$ oc get deploy -n openshift-lightspeed
----
+
--
Depending on your configuration, the following deployments are expected to be ready:

* `lightspeed-operator-controller-manager`
* `lightspeed-agentic-operator-controller-manager`
* `lightspeed-app-server`
* `lightspeed-agentic-console-plugin`
* `lightspeed-console-plugin`
* `lightspeed-otel-collector`
* `lightspeed-postgres-server`
* `lightspeed-rhokp`
* `openshift-mcp-server`
--
+
[NOTE]
====
The {ols-long} autonomous agents deployments, such as `lightspeed-agentic-operator-controller-manager` and `lightspeed-agentic-console-plugin`, are present only when you configure {ols-long} autonomous agents on {ocp-product-title} 5.0.
====

. Verify that the custom resources are in place by running the following commands:
+
[source,terminal]
----
$ oc get olsconfig cluster
----
+
If you configured {ols-long} autonomous agents, also confirm the agentic custom resources by running the following commands:
+
[source,terminal]
----
$ oc get llmprovider -n openshift-lightspeed
$ oc get agent -n openshift-lightspeed
----
