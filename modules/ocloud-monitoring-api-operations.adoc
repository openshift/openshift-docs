= Monitoring API operations

[role="_abstract"]
The Monitoring API provides access to alarms raised by managed clusters. Use this API to query and acknowledge alarms, retrieve the alarm service configuration, and manage alarm subscriptions for event-driven notifications.

All endpoints use the base path `/o2ims-infrastructureMonitoring/v1`.

The `alarmEventRecordId` value is generated by the O-Cloud Manager. Use the `/alarms` endpoint to discover the identifiers for active alarms. The alarm subscription identifier is returned in the response when you create a subscription.

.Monitoring API endpoints
[cols="1,3,3",options="header"]
|===
|Method |Path |Description

|`GET`
|`/alarms`
|List all alarms

|`GET`
|`/alarms/{alarmEventRecordId}`
|Get a specific alarm

|`PATCH`
|`/alarms/{alarmEventRecordId}`
|Acknowledge an alarm

|`GET`
|`/alarmServiceConfiguration`
|Get alarm service configuration

|`GET`
|`/alarmSubscriptions`
|List alarm subscriptions

|`POST`
|`/alarmSubscriptions`
|Create an alarm subscription

|`DELETE`
|`/alarmSubscriptions/{subscriptionId}`
|Delete an alarm subscription
|===
