= Understand Operator Lifecycle Manager workflow

[role="_abstract"]
Operator Lifecycle Manager (OLM) resolves Operator installs and upgrades in {product-title}. The OLM lifecycle involves interacting with catalog sources, subscriptions, and cluster service versions (CSVs).
