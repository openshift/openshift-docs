= Bug fixes and security updates in version 4.10.12

[role="_abstract"]
This release addresses the following security vulnerabilities:

//ROX-37823, ROX-37826, ROX-37827, ROX-37830, ROX-37831, ROX-37834
* klauspost/compress: Denial of Service via crafted `zstd` compressed input (link:https://access.redhat.com/security/cve/CVE-2026-116591[CVE-2026-116591])

* Go and golang.org:
//ROX-39668, ROX-39669, ROX-39670, ROX-39671, ROX-39672, ROX-39673
** net/http: Denial of Service via HTTP/2 trailer header memory exhaustion (link:https://access.redhat.com/security/cve/CVE-2026-78659[CVE-2026-78659])
//ROX-39683
** net/http: HTTP response smuggling via malformed HTTP/2 framing headers (link:https://access.redhat.com/security/cve/CVE-2026-78660[CVE-2026-78660])
//ROX-39812, ROX-39814, ROX-39816
** golang.org/x/net/html: Denial of Service via crafted HTML input (link:https://access.redhat.com/security/cve/CVE-2026-78661[CVE-2026-78661])
