= Troubleshooting approver-policy

[role="_abstract"]
You can use the following guidance to investigate common approver-policy issues, such as an operand that does not deploy, certificate requests that remain pending or are denied, and operand pods that do not run.

:FeatureName: Managing certificate request approval by using approver-policy
include::snippets/technology-preview.adoc[leveloffset=+1]

[cols="1,2",options="header"]
|===
|Symptom |Resolution

|The `ApproverPolicyManager` CR does not deploy the operand.
|Verify that the required OpenShift feature set and {cert-manager-operator} feature gate are enabled. Check the CR status and the {cert-manager-operator} logs for reconciliation errors.

|A certificate request remains pending.
|Verify that a `CertificateRequestPolicy` matches the request issuer and namespace. Verify that approver-policy has permission to approve the request signer name.

|A certificate request is denied.
|Review the policy selectors and allowed request attributes. Update the request or the policy only when the requested certificate is permitted by your organization's security requirements.

|The approver-policy pod is not running.
|Check the pod events and logs in the operand namespace. Verify that the `ApproverPolicyManager` CR is valid and that the Operator has reconciled its dependent resources.
|===
