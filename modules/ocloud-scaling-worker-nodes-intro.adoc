= Scale worker nodes with the O-Cloud Manager

[role="_abstract"]
After a multi-node cluster is provisioned, you can adjust its capacity by adding, removing, or replacing worker nodes by updating the `ProvisioningRequest` custom resource. The O-Cloud Manager automatically coordinates hardware allocation, node provisioning, and cluster membership changes. You can perform these operations by editing the `ProvisioningRequest` CR directly or through the Provisioning REST API.

The O-Cloud Manager is a Technology Preview feature only.
