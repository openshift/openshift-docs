= Ensure host and control plane resilience against application resource exhaustion

[role="_abstract"]
Configure strict resource boundaries so that application misbehavior, such as RAM leaks, CPU spikes, or unbounded logs, does not compromise the host operating system or the {microshift-short} control plane.
