= Red{nbsp}Hat {ServerlessProductName} 1.37.3

[role="_abstract"]
{ServerlessProductName} 1.37.3 is now available. This release of {ServerlessProductName} addresses identified Common Vulnerabilities and Exposures (CVEs) to enhance security and reliability. The following notes describe the fixed issues that affect {ServerlessProductName} on {ocp-product-title}.

[id="serverless-fixed-issues-1-37-3_{context}"]
== Fixed issues

Knative Serving webhook NetworkPolicies missing with OpenShift Service Mesh::

Before this update, when {ServerlessProductName} was used together with OpenShift Service Mesh (OSSM), OSSM could apply the restrictive `istio-mesh` NetworkPolicy to the `knative-serving` namespace before the {ServerlessProductName} operator created its allow NetworkPolicies required for the Knative admission webhooks. As a consequence, the Kubernetes API server could not reach the Knative admission webhook, causing `KnativeServing` to report `Ready=False` with `context deadline exceeded` webhook timeout errors, even when the webhook deployment was healthy.
+
With this update, the {ServerlessProductName} operator creates the `webhook` and `net-istio-webhook` allow NetworkPolicies in the `knative-serving` namespace early in the reconciliation process, before restrictive OSSM policies can block webhook traffic.
+
As a result, Knative Serving can reach `Ready=True` on installations and upgrades where {ServerlessProductName} is used with OpenShift Service Mesh.
+
