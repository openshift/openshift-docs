= Azure storage for {entra-first} enabled clusters

[role="_abstract"]
If your cluster has {entra-first} enabled, the Cloud Credential Operator (CCO) supports short-term authentication by using {entra-short}.

.Prerequisites

* You installed the {loki-op}.
* You installed the {oc-first}.
* Your cluster has {entra-first} enabled.

.Procedure

* Create the Loki object storage secret by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc -n openshift-logging create secret generic logging-loki-azure \
  --from-literal=environment="<azure_environment>" \
  --from-literal=account_name="<storage_account_name>" \
  --from-literal=container="<container_name>"
----
+
`environment`::
  The Azure cloud environment, typically `AzureGlobal` for commercial Azure.

`account_name`::
  The name of your Azure storage account.

`container`::
  The name of the blob container where logs will be stored.

.Verification

Verify that the secret was created successfully:

[source,terminal]
----
$ oc get secret logging-loki-azure -n openshift-logging
----
