= Enabling or disabling Dynamic Configuration Manager (DCM)

[role="_abstract"]
If you need to handle operations dynamically, you an enable DCM.
DCM is disabled by default.

The standard fork-and-reload mechanism configures `spec.tuningOptions.configurationManagement` field directly on the `IngressController` CR.
You can configure this field to enable DCM.

.Prerequisites

* You have access to the cluster as a user with the `cluster-admin` role.
* You have installed the {oc-first}.

.Procedure

* If you need to enable dynamic updates by using DCM, enter the following command:
+
[source,terminal]
----
$ oc -n openshift-ingress-operator patch ingresscontrollers/default \
  --type=merge \
  --patch='{"spec":{"configurationManagement":"Dynamic"}}'
----

* If you need to disable DCM and revert to the fork-and-reload mechanism, enter the following command:
+
[source,terminal]
----
$ oc -n openshift-ingress-operator patch ingresscontrollers/default \
  --type=merge \
  --patch='{"spec":{"configurationManagement":"ForkAndReload"}}'
----
