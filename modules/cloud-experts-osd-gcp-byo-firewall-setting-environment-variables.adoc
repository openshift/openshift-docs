= Setting environment variables

[role="_abstract"]
Only the cluster name and {GCP} project need to be set manually. All other values are derived dynamically.

.Prerequisites
* You have an existing {product-title} on {GCP} cluster deployed with Workload Identity Federation (WIF).
* You have the `gcloud` CLI installed with permissions to manage firewall rules in the {GCP} project.
* You have the `oc` CLI authenticated to the cluster with `cluster-admin` privileges.
* You have the `ocm` CLI logged in to {cluster-manager}.

.Procedure
. Set the cluster name and {GCP} project:
+
[source,terminal]
----
$ export CLUSTER_NAME="<your_cluster_name>"
$ export GCP_PROJECT="<your_gcp_project>"
----

. Derive the infrastructure ID from {cluster-manager}:
+
[source,terminal]
----
$ export INFRA_ID=$(ocm describe cluster ${CLUSTER_NAME} --json | jq -r '.infra_id')
$ echo "INFRA_ID: ${INFRA_ID}"
----

. Derive the VPC network and BYO rule prefix:
+
[source,terminal]
----
$ export VPC_NETWORK="${INFRA_ID}-network"
$ export BYO_PREFIX="${CLUSTER_NAME}-byo"
----

. Derive the WIF service accounts from the cluster's compute instances:
+
[source,terminal]
----
$ export CP_SA=$(gcloud compute instances list \
  --project=${GCP_PROJECT} \
  --filter="name~${INFRA_ID}-master" \
  --format="value(serviceAccounts.email)" \
  --limit=1)
$ export WORKER_SA=$(gcloud compute instances list \
  --project=${GCP_PROJECT} \
  --filter="name~${INFRA_ID}-worker" \
  --format="value(serviceAccounts.email)" \
  --limit=1)
$ echo "CP_SA: ${CP_SA}"
$ echo "WORKER_SA: ${WORKER_SA}"
----

. Set the {GCP} health check probe IP ranges. These are link:https://cloud.google.com/load-balancing/docs/health-check-concepts#ip-ranges[{GCP} global health check source ranges], used by all {GCP} load balancers:
+
[source,terminal]
----
$ export LB_CIDRS="35.191.0.0/16,130.211.0.0/22,209.85.152.0/22,209.85.204.0/22"
----

.Verification
* Verify all variables are set:
+
[source,terminal]
----
$ echo "CLUSTER_NAME:  ${CLUSTER_NAME}"
$ echo "GCP_PROJECT:   ${GCP_PROJECT}"
$ echo "INFRA_ID:      ${INFRA_ID}"
$ echo "VPC_NETWORK:   ${VPC_NETWORK}"
$ echo "BYO_PREFIX:    ${BYO_PREFIX}"
$ echo "CP_SA:         ${CP_SA}"
$ echo "WORKER_SA:     ${WORKER_SA}"
$ echo "LB_CIDRS:      ${LB_CIDRS}"
----
