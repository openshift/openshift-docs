= Running LDAP sync

[role="_abstract"]
Review LDAP sync types before running group sync between your LDAP server and {product-title}. Each type defines sync direction and scope so you select the command that matches your directory layout.

Once you have created a sync configuration file, you can begin to sync. {product-title} allows administrators to perform several different sync types with the same server.
