= Viewing a list of available metrics

As a cluster administrator or as a user with view permissions for all projects, you can view a list of metrics available in a cluster and output the list in JSON format.

.Prerequisites
* You are a cluster administrator, or you have access to the cluster as a user with the `cluster-monitoring-view` cluster role.
* [.pr:openshift-enterprise]#You have installed the OpenShift Container Platform CLI (`oc`).# [.pr:openshift-origin]#You have installed the OKD CLI (`oc`).# [.pr:microshift]#You have installed the Red Hat build of MicroShift CLI (`oc`).#
* [.pr:openshift-enterprise]#You have obtained the OpenShift Container Platform API route for Thanos Querier.# [.pr:openshift-origin]#You have obtained the OKD API route for Thanos Querier.# [.pr:microshift]#You have obtained the Red Hat build of MicroShift API route for Thanos Querier.#
* You are able to get a bearer token by using the `oc whoami -t` command.
+
[IMPORTANT]
====
You can only use bearer token authentication to access the Thanos Querier API route.
====

.Procedure

. [.pr:openshift-enterprise]#If you have not obtained the OpenShift Container Platform API route for Thanos Querier, run the following command:# [.pr:openshift-origin]#If you have not obtained the OKD API route for Thanos Querier, run the following command:# [.pr:microshift]#If you have not obtained the Red Hat build of MicroShift API route for Thanos Querier, run the following command:#
+
[source,terminal]
----
$ oc get routes -n openshift-monitoring thanos-querier -o jsonpath='{.status.ingress[0].host}'
----

. Retrieve a list of metrics in JSON format from the Thanos Querier API route by running the following command. This command uses `oc` to authenticate with a bearer token.
+
[source,terminal]
----
$ curl -k -H "Authorization: Bearer $(oc whoami -t)" https://<thanos_querier_route>/api/v1/metadata <1>
----
<1> [.pr:openshift-enterprise]#Replace `<thanos_querier_route>` with the OpenShift Container Platform API route for Thanos Querier.# [.pr:openshift-origin]#Replace `<thanos_querier_route>` with the OKD API route for Thanos Querier.# [.pr:microshift]#Replace `<thanos_querier_route>` with the Red Hat build of MicroShift API route for Thanos Querier.#
