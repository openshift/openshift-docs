= RHSA-2026:90274 - {product-title} 4.12.102 bug fix and security update

Issued: 27 October 2026

[role="_abstract"]
{product-title} release 4.12.102 is now available with updates to packages and images that fix several bugs and add enhancements. This release includes a security update for the link:https://access.redhat.com/errata/RHSA-2026:90274[{product-title} 4.12] RPM packages.

Red Hat Product Security has rated this update as having a security impact of link:https://access.redhat.com/security/updates/classification/#important[Important]. A link:https://access.redhat.com/security/cve/[Common Vulnerability Scoring System (CVSS)] base score, which gives a detailed severity rating, is available for each vulnerability from the CVE links in the References.

For more details about the security issues, including the impact, CVSS score, acknowledgments, and other related information, refer to the link:https://access.redhat.com/security/updates/classification/#important[CVE page] listed in the References.

You can view the container images in this update by running the following command:

[source,terminal]
----
$ oc adm release info 4.12.102 --pullspecs
----

There are no notable fixed issues in this release.
