= Spectrum-X architecture with {product-title}

[role="_abstract"]
{product-title} provides the cluster platform for artificial intelligence (AI) workloads, while NVIDIA Spectrum-X provides the Ethernet fabric used to connect supported network adapters and Spectrum switches.

The {product-title} cluster runs the control plane, Operators, and workloads. The NVIDIA Network Operator manages NVIDIA networking components on selected worker nodes.
{product-title} networking Operators configure worker nodes and secondary networks, including single root I/O virtualization (SR-IOV) resources and node network policies.

In a single-plane deployment, the workload's east-west traffic uses the Spectrum-X fabric.
A rail is a physical network path from a worker adapter to the fabric. The configuration associates each rail with a named adapter interface, an SR-IOV resource, an IP address pool, and a network attachment.

BlueField-3 SuperNICs and BlueField data processing units (DPUs) have different roles.
The single-plane example uses BlueField-3 SuperNICs as network adapters for Spectrum-X.
A design that uses DPUs for data-plane functions, such as storage or inference traffic, has separate lifecycle and configuration requirements. For those tasks, see "About the NVIDIA DOCA Platform Framework (DPF) Operator".
