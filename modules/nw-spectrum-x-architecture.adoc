= Spectrum-X architecture with {product-title}

[role="_abstract"]
{product-title} provides the cluster platform for AI workloads, while NVIDIA Spectrum-X provides the Ethernet fabric used to connect supported network adapters and Spectrum switches.

The {product-title} cluster runs the control plane, Operators, and workloads. The NVIDIA Network Operator manages NVIDIA networking components on selected worker nodes.
OpenShift networking Operators configure worker nodes and secondary networks, including SR-IOV resources and node network policies.

In the single-plane example in this guide, the workload's east-west traffic uses the Spectrum-X fabric.
A rail is a physical network path from a worker adapter to the fabric. The configuration associates each rail with a named adapter interface, an SR-IOV resource, an IP address pool, and a network attachment.

BlueField-3 SuperNICs and BlueField data processing units (DPUs) have different roles.
The repository example uses BlueField-3 SuperNICs as network adapters for Spectrum-X. It does not deploy or configure BlueField DPUs.
A design that uses DPUs for data-plane functions, such as storage or inference traffic, has separate DPU lifecycle and configuration requirements. For those tasks, see the NVIDIA DPU Operator documentation.

Spectrum-X is the network fabric and configuration described in this guide.
The procedures do not configure an end-to-end AI workload, storage service, or DPU deployment.
For DPU lifecycle and configuration tasks, see the NVIDIA DPF Operator documentation.
