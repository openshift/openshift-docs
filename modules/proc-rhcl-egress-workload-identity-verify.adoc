= Verify that workloads are using TokenReview

[role="_abstract"]
Check that your `AuthPolicy` CR is working as expected on your external service.

.Prerequisites

include::snippets/egress-gateway-prereqs.adoc[]

* A test client pod is available in the `egress-test` namespace.

.Procedure

. Verify that an authorized workload receives a `200` response by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc exec test-client -n egress-test -- sh -c '
curl -s -o /dev/null -w "%{http_code}" \
    -H "Host: _<httpbin.org>_" \
    -H "Authorization: Bearer $(cat /var/run/secrets/kubernetes.io/serviceaccount/token)" \
    http://'"${EGRESS_IP}"'/get
'
----
+
Replace `_<httpbin.org>_` with your external target service.
+
.Expected output
[source,text]
----
200
----

. Verify that a request without a token is rejected by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc exec test-client -n egress-test -- \
    curl -s -o /dev/null -w "%{http_code}" -H "Host: _<httpbin.org>_" http://${EGRESS_IP}/get
----
+
Replace `_<httpbin.org>_` with your external target service.
+
.Expected output
[source,text]
----
401
----

. Verify that a workload from an unauthorized namespace is rejected by running the following commands:
+
[source,terminal]
----
$ oc run bad-client --image=curlimages/curl:latest -n default --restart=Never \
    --command -- sleep infinity
$ oc wait --for=condition=Ready pod/bad-client -n default --timeout=30s
----
+
[source,terminal,subs="+quotes"]
----
$ oc exec bad-client -n default -- sh -c '
curl -s -o /dev/null -w "%{http_code}" -H "Host: _<httpbin.org>_" \
    -H "Authorization: Bearer $(cat /var/run/secrets/kubernetes.io/serviceaccount/token)" \
    http://'"${EGRESS_IP}"'/get
'
----
+
Replace `_<httpbin.org>_` with your external target service.
+
.Expected output
[source,terminal]
----
403
----
. Clean up the test pod by running the following command:
+
[source,terminal]
----
$ oc delete pod bad-client -n default
----
