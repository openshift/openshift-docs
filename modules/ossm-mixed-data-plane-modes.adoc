= Support mixed data plane modes in your mesh

[role="_abstract"]
{SMProductName} supports running sidecar and ambient workloads in the same {istio} mesh. Use this capability to migrate workloads to ambient mode in increments. You can keep specific workloads in sidecar mode if they depend on features that ambient mode does not yet support.
