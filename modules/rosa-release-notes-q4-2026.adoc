= Q4 2026

[role="_abstract"]
The following items were added during the fourth quarter of 2026.

ifdef::openshift-rosa-hcp[]
Spaces in AWS tags::
+
You can include spaces in AWS tag keys and values. For more information, see link:https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws/4/html/cluster_administration/managing-compute-nodes-using-machine-pools#rosa-adding-tags_rosa-managing-worker-nodes[Adding tags to a machine pool].

Machine pool tags take precedence over cluster tags::
+
When the same AWS tag key is defined at both the cluster and machine pool levels, the machine pool tag value takes precedence over the cluster tag value. For more information, see link:https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws/4/html/cluster_administration/managing-compute-nodes-using-machine-pools#rosa-adding-tags_rosa-managing-worker-nodes[Adding tags to a machine pool].

BGP routing for OpenShift Virtualization on AWS::
+
Border Gateway Protocol (BGP) Cloud Connector integrates {product-title} with {aws-short} Route Server allowing direct, routed connectivity to {VirtProductName} virtual machines (VMs) on {aws-short}. For more information, see the following documentation:

* link:https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws/4/html-single/advanced_networking/index#about-bgp-routing[About BGP routing for {product-title}]
endif::openshift-rosa-hcp[]
