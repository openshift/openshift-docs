= Attaching a virtual machine to a localnet network

[role="_abstract"]
You can connect a virtual machine (VM) to the physical network by configuring the localnet network interface in the `VirtualMachine` manifest.

[NOTE]
====
You can connect a VM to both the default pod network and a secondary localnet network.
====

.Prerequisites

* You have installed the {oc-first}.
* You have created a `ClusterUserDefinedNetwork` CR that defines the localnet network.
* You have created a namespace with a label that matches the `ClusterUserDefinedNetwork` namespace selector.

.Procedure

. Edit the `VirtualMachine` manifest to add the localnet network interface, as in the following example:
+
[source,yaml]
----
apiVersion: kubevirt.io/v1
kind: VirtualMachine
metadata:
  name: example-vm
  namespace: red
spec:
  template:
    spec:
      domain:
        devices:
          interfaces:
            - name: provider-network
              bridge: {}
              model: e1000e
      networks:
      - name: provider-network
        multus:
          networkName: provider-network-100
# ...
----
+
where:
+
`spec.template.spec.domain.devices.interfaces.name`:: Specifies the name of the network interface. This value must match the corresponding `spec.template.spec.networks.name` field.
`spec.template.spec.domain.devices.interfaces.bridge`:: Specifies the bridge binding for the interface.
`spec.template.spec.domain.devices.interfaces.model`:: Specifies the type of network interface driver. Possible values are `virtio` and `e1000e`. The default value is `virtio`. Use `e1000e` for Windows VMs that do not have VirtIO drivers installed.
`spec.template.spec.networks.multus.networkName`:: Specifies the name of the `ClusterUserDefinedNetwork` CR that defines the localnet network.
+
[NOTE]
====
With a VirtIO driver, the VM automatically inherits the MTU value of the network. If you use the `e1000e` driver, you must configure the MTU value inside the guest operating system.
====

. Apply the `VirtualMachine` manifest by running the following command:
+
[source,terminal]
----
$ oc apply -f <filename>.yaml
----
+
where:
+
`<filename>`:: Specifies the name of your `VirtualMachine` manifest YAML file.
