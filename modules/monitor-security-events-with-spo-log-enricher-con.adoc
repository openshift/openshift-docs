= Monitor security events with the SPO log enricher

[role="_abstract"]
With the Advanced Audit Logging Framework in the {product-title} Security Profiles Operator (SPO), you can correlate cluster users with actions during `oc exec`, `oc rsh`, and `oc debug` sessions. 

You can enable the log enricher, capture and correlate security events from pods and nodes, and disable it when monitoring is no longer required.
