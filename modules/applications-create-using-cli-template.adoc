= Creating an application from a template

[role="_abstract"]
You can use `oc new-app` to create an application from a template stored in your project or from a template file on your local system. Use this procedure when you have a template JSON or YAML file, or a template in the template library of your current project.

.Prerequisites

* You have installed the {oc-first} and logged in to your cluster.
* You have a template JSON or YAML file, or a template stored in the template library of your current project.

.Procedure

. Upload an application template to the template library of your current project by running the following command:
+
[source,terminal]
----
$ oc create -f examples/sample-app/application-template-stibuild.json
----

. Create a new application from a stored template by running the following command:
+
[source,terminal]
----
$ oc new-app ruby-helloworld-sample
----

. Create a new application from a template file on your local file system without storing it in {product-title} by running the following command:
+
[source,terminal]
----
$ oc new-app -f examples/sample-app/application-template-stibuild.json
----

. Set template parameter values when creating an application by running the following command:
+
[source,terminal]
----
$ oc new-app ruby-helloworld-sample \
    -p ADMIN_USERNAME=admin -p ADMIN_PASSWORD=mypassword
----

. Store template parameters in a file by creating a file such as `helloworld.params` with the following content:
+
[source,terminal]
----
ADMIN_USERNAME=admin
ADMIN_PASSWORD=mypassword
----

. Create a new application from a template by using a parameter file by running the following command:
+
[source,terminal]
----
$ oc new-app ruby-helloworld-sample --param-file=helloworld.params
----
+
[NOTE]
====
To read parameters from standard input, use `--param-file=-`.
====
