== Fixed issues

The following bug fix is available for this release:

* Before this update, the `CreateOnlyMode` condition remained `True` after you removed the `CREATE_ONLY_MODE` environment variable from the Operator subscription or set the variable to `false`. As a consequence, custom resource status continued to report that create-only mode was enabled. With this release, {zero-trust-full} sets the `CreateOnlyMode` condition to `False` with reason `CreateOnlyModeDisabled` when `CREATE_ONLY_MODE` is removed or set to `false`. (link:https://issues.redhat.com/browse/SPIRE-683[SPIRE-683])
