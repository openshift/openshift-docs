= Understand the out-of-cluster mode of the Image Mode for OpenShift feature

[role="_abstract"]
In out-of-cluster mode, you build a layered {op-system-first} image outside the cluster and point nodes at it, rather than having the cluster build the image for you. The node boots the image you supply.
