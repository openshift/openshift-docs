= Configuring an EgressIP object by using a node selector

[role="_abstract"]
You can configure the `egressNodeSelector` field to restrict what nodes can host a specific `EgressIP` object.
With this configuration, you can ensure traffic exits through controlled network segments to satisfy strict firewall rules, security isolation, and hardware performance requirements.

:FeatureName: Egress IP node selectors
include::snippets/technology-preview.adoc[]

.Prerequisites

* Your cluster uses the OVN-Kubernetes network plugin.
* You have a set of nodes labeled to match your intended `egressNodeSelector` value.

.Procedure

. Create an `EgressIP` object and specify your custom labels in the `egressNodeSelector.matchLabels` field:
+
[source,yaml]
----
apiVersion: k8s.ovn.org/v1
kind: EgressIP
metadata:
  name: egress-project1
spec:
  egressIPs:
    - 192.168.127.10
  namespaceSelector:
    matchLabels:
      env: production
  egressNodeSelector:
    matchLabels:
      node-role.kubernetes.io/egress: "true"
# ...
----
`egressNodeSelector` restricts allocation of the `EgressIP` object to nodes labeled with `node-role.kubernetes.io/egress: "true"`. Nodes matching this selector do not need the `k8s.ovn.org/egress-assignable` label.
+
[NOTE]
====
Both an `EgressIP` object and its matching node labels must exist before an egress IP address can be assigned. When you apply node labels after creating the `EgressIP` object, the labeled nodes are verified for reachability immediately. When you create the `EgressIP` object after the nodes are already labeled, the nodes are not verified until the next periodic health check runs. To avoid this delay, create the `EgressIP` object before applying the node labels that it selects.
====

. To create the object, enter the following command:
+
[source,terminal]
----
$ oc apply -f <egressips_name>.yaml
----
+
Replace `<egressips_name>` with the name of your Egress IP object.

.Verification

* Verify that the `EgressIP` object was created and successfully assigned to a node matching your custom label by entering the following command:
+
[source,terminal]
----
$ oc get egressips egress-project1
----
+
.Example output
[source,terminal]
----
NAME              EGRESSIPS        ASSIGNED NODE   ASSIGNED EGRESSIPS
egress-project1   192.168.127.10   worker-0        192.168.127.10
----

* Confirm that the assigned node carries the label that matches your `egressNodeSelector` value by entering the following command:
+
[source,terminal]
----
$ oc get node <assigned_node_name> --show-labels
----
+
Replace `<assigned_node_name>` with the node name.
Confirm that the output includes `node-role.kubernetes.io/egress=true`.
