= VirtualMachineTemplate parameter fields

[role="_abstract"]
Each parameter in `spec.parameters` of a `VirtualMachineTemplate` resource supports the following fields. You can use these fields to define static defaults, require user input, or auto-generate values when creating VMs from a template.

.Parameter fields
[options="header"]
|====
|Field |Description

|`name`
|The unique identifier for the parameter. This string acts as a substitution variable, for example, `${NAME}`, anywhere within the template's `virtualMachine` specification.

|`value`
|The static default value applied to the parameter. This field cannot be used if `required` is set to `true`.

|`generate`
|The mechanism used to dynamically create a value if the user omits it. Set this to `expression` to generate a random string based on the regex pattern defined in the `from` field.

|`from`
|The regular expression (regex) pattern that dictates the format of the generated string. This field is mandatory when `generate` is set to `expression`.

|`required`
|A boolean flag that determines whether the user must explicitly supply the parameter. If `true`, template processing fails without input. Cannot be combined with `value` or `generate`.

|`displayName`
|An optional human-readable name for a graphical user interface (GUI) display.

|`description`
|An optional description of the purpose of the parameter.
|====

[id="virt-vm-template-parameter-types_{context}"]
== Parameter types

Static parameters:: Have a fixed default value that is used if no override is provided.
+
[source,yaml]
----
- name: INSTANCETYPE
  value: u1.medium
  description: Instance type for the VM
----

Required parameters:: Must be provided during processing.
+
[source,yaml]
----
- name: PASSWORD
  required: true
  description: Password for the cloud-init user
----

Generated parameters:: Produce random values based on a pattern.
+
[source,yaml]
----
- name: NAME
  generate: expression
  from: "fedora-[a-z0-9]{16}"
  description: Unique VM name
----

Optional parameters:: Have no default value or generator. If not provided, the placeholder is replaced with an empty string.

[id="virt-vm-template-example_{context}"]
== Example VirtualMachineTemplate

The following example defines a template with a generated name, a default instance type, and a required password parameter:

[source,yaml]
----
apiVersion: template.kubevirt.io/v1beta1
kind: VirtualMachineTemplate
metadata:
  name: fedora-template
spec:
  parameters:
    - name: NAME
      generate: expression
      from: "fedora-[a-z0-9]{16}"
      description: Unique VM name
    - name: INSTANCETYPE
      value: u1.medium
      description: Instance type for the VM
    - name: PASSWORD
      required: true
      description: Password for the cloud-init user
  virtualMachine:
    metadata:
      name: ${NAME}
    spec:
      instancetype:
        kind: VirtualMachineClusterInstancetype
        name: ${INSTANCETYPE}
      preference:
        kind: VirtualMachineClusterPreference
        name: fedora
      runStrategy: Halted
      template:
        spec:
          domain:
            devices: {}
          volumes:
            - containerDisk:
                image: quay.io/containerdisks/fedora:latest
              name: rootdisk
            - cloudInitNoCloud:
                userData: |-
                  #cloud-config
                  user: fedora
                  password: ${PASSWORD}
                  chpasswd: { expire: False }
              name: cloudinitdisk
----
