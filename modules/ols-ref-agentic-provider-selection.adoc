= Choose an LLM provider pathway for Agentic {ols-long}

[role="_abstract"]
Agentic workflows depend on reliable tool calling and structured outputs. When you serve a model locally with vLLM, you can connect Agentic {ols-long} through either the OpenAI-compatible pathway or the Anthropic-compatible pathway. For agentic and tool-calling workloads, use the Anthropic provider pathway.

.vLLM provider pathway comparison
[cols="1,1,2", options="header"]
|===
| Provider pathway | Endpoint | Recommended use

| Anthropic
| `/v1/messages`
| Agentic and tool-calling workloads. Preserves tool calls and structured outputs.

| OpenAI-compatible
| `/v1/chat/completions`
| General chat completion workloads that do not depend on reliable tool calling.
|===

[IMPORTANT]
====
For tool-calling and agentic workloads, use the Anthropic provider pathway. The OpenAI provider pathway can suppress tool calls on vLLM, because the request format used for structured output suppresses tool calls on OpenAI-compatible endpoints. This suppression causes structured output failures for agentic workflows.
====

The Anthropic-compatible `/v1/messages` endpoint is available in vLLM version 0.24, the version currently supported with {rhelai}. Because this version ships with {rhelai}, the Anthropic pathway is also suitable for disconnected environments that host vLLM locally.

[NOTE]
====
Model quality also affects agentic outcomes, so results can vary by model. Red{nbsp}Hat does not provide support for any specific models or make suggestions or support statements pertaining to models.
====
