[id="zstream-4-19-53-fixed-issues_{context}"]
== Fixed issues

* Before this update, when two EgressIP custom resources (CRs) used the same IP address and the OVN-Kubernetes control-plane pod restarted or a node rebooted, the IP address was incorrectly assigned to more than one egress node. As a consequence, multiple egress nodes shared the same IP address, which caused unpredictable routing behavior. With this update, OVN-Kubernetes ensures that only the first assigned IP address is re-assigned to an egress node, while duplicate assignments are prevented. As a result, only one egress node is assigned the IP address defined in the EgressIP CR, preventing address conflicts. (link:https://issues.redhat.com/browse/OCPBUGS-129457[OCPBUGS-132715])
