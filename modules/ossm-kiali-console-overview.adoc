= Kiali console overview

[role="_abstract"]

The Kiali console is the console for {SMProductName} on {ocp-product-title}. Use it to configure, visualize, validate, and troubleshoot the mesh.

{KialiServer} serves the console. The console reads mesh data from {istio}, from the {ocp-product-title} API, and from the metrics store you configure for the mesh. It does not replace {KialiProduct}. Install and upgrade the console with the operator, as described in "Using {KialiProduct}".

The console provides the following views:

Topology:: A graph of live request traffic combined with {istio} configuration, so you can see how services communicate.

Health:: Color and status for infrastructure, applications, services, and workloads, so you can find problems quickly.

Details:: List and detail pages for applications, services, and workloads, with logs, metrics, and traces.

Tracing:: Traces from {TempoName}, correlated with metrics, logs, and the graph.

Validations:: Semantic checks of {istio} objects that go beyond the static schema checks {istio} performs at admission.

Wizards:: Guided actions that create routing, resiliency, and security objects without writing YAML first.

Configuration:: A YAML editor for {istio} custom resources on {ocp-product-title}.
