= Configure troubleshooting skills

[role="_abstract"]
Skills provide the agent with additional troubleshooting knowledge, such as runbooks, that guide how it investigates and remediates alerts. Each skill is packaged as an OCI image, and you reference it in the `alerts-adapter-config` ConfigMap by its image and the paths to the skill content within that image. To learn how to structure and build your own skills image, use the `openshift/agentic-skills` repository as a reference example.

By default, the adapter uses the cluster troubleshooting skills from the `cluster-troubleshoot` directory of the `openshift/agentic-skills` repository. Configure the `tools` settings to add your own skills.

Skills are used only during the analysis step of an `AgenticRun` workflow.

Each skill entry requires a `paths` field, which lists the paths to the skill content within the image, and accepts an optional `image` field for the OCI image reference. If you omit the `image` field, the adapter uses the default agentic skills image bundled with the {ols-long} Operator, built from the `openshift/agentic-skills` repository.

The following example uses the deployment's default image for the cluster troubleshooting skill and an explicit image for custom runbooks:

[source,yaml]
----
tools:
  skills:
    - paths:
        - /skills/cluster-troubleshoot/investigate-alert
    - image: quay.io/example/shared-runbooks:latest
      paths:
        - /runbooks/common
----
