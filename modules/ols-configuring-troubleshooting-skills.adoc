= Configure troubleshooting skills

[role="_abstract"]
Skills provide the agent with additional troubleshooting knowledge, such as runbooks, that guide how it investigates and remediates alerts. Each skill is packaged as an OCI image, and you reference it in the `alerts-adapter-config` ConfigMap by its image and the paths to the skill content within that image. To learn how to structure and build your own skills image, use the `openshift/agentic-skills` repository as a reference example.

Configure the `tools` settings to add your own skills.

Skills are used only during the analysis step of an `AgenticRun` workflow.

Each skill entry requires a `paths` field, which lists the paths to the skill content within the image, and an `image` field for the OCI image reference. 

The following example uses a an image for custom runbooks:

[source,yaml]
----
tools:
  skills:
    - image: quay.io/example/shared-runbooks:latest
      paths:
        - /runbooks/common
----
