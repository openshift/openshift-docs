= Log in with SSO from a browserless environment

Cloud IDEs and remote development environments might not have a browser available to complete the standard SSO login flow. You can use the `--no-browser` flag to authenticate with the OAuth 2.0 Device Authorization Grant. The CLI displays a verification URL and user code. You open the URL in a browser on any device, complete authentication, and approve the request. The CLI waits for approval and saves the resulting token.

.Prerequisites

* The Argo CD instance is configured for SSO with an OIDC provider.
* The OIDC provider supports the OAuth 2.0 Device Authorization Grant and advertises a `device_authorization_endpoint` in its discovery document.
* You have the {gitops-shortname} `argocd` CLI tool installed and configured.

.Procedure

. Log in to the Argo CD server with SSO using the `--no-browser` flag:
+
[source,terminal]
----
$ argocd login <server> --sso --no-browser
----
+
Replace `<server>` with your Argo CD server URL.
+
The CLI displays a verification URL and user code:
+
--
*Example output:*
[source,terminal]
----
To authenticate, visit:
https://device.provider.com/activate

And enter the code:
ABCD-EFGH

Waiting for authentication to complete...
----
--

. Open the verification URL in a browser on any device that has internet access.

. Enter the user code displayed by the CLI when prompted.

. Complete the authentication process with your identity provider.

. Return to the CLI terminal.
+
After you approve the authentication request, the CLI automatically receives the token and completes the login process:
+
--
*Example output:*
[source,terminal]
----
'admin:login' logged in successfully
Context '<server_url>' updated
----
--

. Optional: If the login session times out, use the `relogin` command with the `--no-browser` flag:
+
[source,terminal]
----
$ argocd relogin --no-browser
----

[NOTE]
====
Some OIDC providers might require you to enable the device authorization grant for the CLI OIDC client. Consult your identity provider documentation for specific configuration requirements.
====
