= Install {product-title} on Google Cloud Dedicated

[role="_abstract"]
Install {product-title} on Google Cloud Dedicated (GCD) sovereign cloud regions using installer-provisioned infrastructure with manual configuration for strict data and operational sovereignty requirements.

Google Cloud Dedicated is a sovereign cloud platform that provides {gcp-short} technology in a fully isolated environment. GCD deployments require specialized configuration including domain-scoped project IDs, universe domains, and limited machine and storage types to maintain sovereignty guarantees.
