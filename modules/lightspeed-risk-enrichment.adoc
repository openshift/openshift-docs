= Red Hat OpenShift Lightspeed risk enrichment

// JIRA: ROX-29069

[role="_abstract"]
This release introduces a Technology Preview integration with {osp} Lightspeed, enabling AI-generated natural language risk explanations for deployments directly in the {product-title-short} portal.

This provides clear insights into overall risk scores based on underlying scoring factors.

To enable this feature, you must configure the following:

. Create a `ClusterRoleBinding` in {osp} granting the Central `ServiceAccount` the OpenShift Lightspeed query role, so that OpenShift Lightspeed authorizes Central's API calls. For more information, see link:https://docs.redhat.com/en/documentation/red_hat_openshift_lightspeed/1.0/html/operate/ols-interacting-with-the-api#ols-proc-authenticate-with-the-api_ols-interacting-with-the-api[Authenticate with the API].

. Create a new network policy in OpenShift Lightspeed and add the namespace and pod selector so that only Central traffic is allowed from {product-title-short}. For more information, see link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.20/html/network_security/network-policy[About network policy].

. Optional: Set the `ROX_LIGHTSPEED_ENDPOINT` environment variable to `\https://lightspeed-app-server.openshift-lightspeed.svc:8443`. Set this variable only if OpenShift Lightspeed is running on a non-default address.
