= {osp} Lightspeed risk enrichment

// JIRA: ROX-29069

[role="_abstract"]
This release introduces a Technology Preview integration with {osp} Lightspeed, enabling AI-generated natural language risk explanations for deployments directly in the {product-title-short} portal.

This integration provides clear insights into overall risk scores based on underlying scoring factors.

[NOTE]
====
You cannot currently integrate {osp} Lightspeed with {rh-rhacscs-first}, and AI-generated risk explanations are not available for {product-title-managed-short} users.
====

To enable this feature, you must configure the following objects. For more information, see "Integrating Red Hat Advanced Cluster Security with OpenShift Lightspeed".

[IMPORTANT]
====
You must deploy {osp} Lightspeed on the same cluster as Central to use this feature.
====

. Create a `ClusterRoleBinding` in {osp} granting the Central `ServiceAccount` the {osp} Lightspeed query role, so that {osp} Lightspeed authorizes Central's API calls. For more information, see "Authenticate with the API".

. Create a new network policy in {osp} Lightspeed and add the namespace and pod selector so that the policy allows only Central traffic from {product-title-short}. For more information, see About network policy.

. Optional: By default, the `ROX_LIGHTSPEED_ENDPOINT` environment variable is set to `\https://lightspeed-app-server.openshift-lightspeed.svc:8443`. Change this variable if the {osp} Lightspeed deployment in your cluster has a different service endpoint.
