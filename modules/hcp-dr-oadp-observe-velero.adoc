= Using the OADP CLI to describe the Backup and Restore resources

[role="_abstract"]
When you use {oadp-full}, you can get more details of the `Backup` and `Restore` resources by using the OADP command-line interface (CLI).

.Procedure

. Get details of your `Restore` custom resource (CR) by running the following command:
+
[source,terminal]
----
$ oc oadp restore describe <restore_resource_name> --details
----
+
Replace `<restore_resource_name>` with the name of your `Restore` resource.

. Get details of your `Backup` CR by running the following command:
+
[source,terminal]
----
$ oc oadp backup describe <backup_resource_name> --details
----
+
Replace `<backup_resource_name>` with the name of your `Backup` resource.
