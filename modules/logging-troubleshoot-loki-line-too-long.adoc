= Troubleshoot log line size limit errors

[role="_abstract"]
Diagnose and resolve situations where LokiStack is permanently discarding log lines that exceed the maximum permitted entry size of 256 KB.

[IMPORTANT]
====
Unlike rate limit errors, log lines that exceed the size limit are permanently lost. The collector receives a 400 Bad Request response and drops the request without retrying.
====

.Prerequisites

* You have administrator permissions.
* You have installed the OpenShift CLI (`oc`).

.Procedure

. Confirm that log line size limit discards are occurring by running the following PromQL query in the OpenShift web console under *Observe* -> *Metrics*:
+
[source,promql]
----
sum by (tenant, reason) (irate(loki_discarded_samples_total[2m]))
----
+
A nonzero value with `reason="line_too_long"` confirms log line size discards.

. Check for the non-retriable 400 error in collector pods:
+
[source,terminal]
----
$ ns="openshift-logging"
$ for pod in $(oc -n ${ns} get pod \
    -l app.kubernetes.io/component=collector -o name); do
    oc -n ${ns} logs ${pod} | grep "Server responded with an error: 400 Bad Request"
  done | head -5
----
+
The presence of `Non-retriable error; dropping the request` in the output confirms that log lines are permanently dropped.

. Count the total number of dropped requests:
+
[source,terminal]
----
$ for pod in $(oc -n ${ns} get pod \
    -l app.kubernetes.io/component=collector -o name); do
    oc -n ${ns} logs ${pod}
  done | grep -c "Server responded with an error: 400 Bad Request"
----

. Identify the stream and log source in distributor pod logs:
+
[source,terminal]
----
$ for pod in $(oc -n ${ns} get pod \
    -l app.kubernetes.io/component=distributor -o name); do
    oc -n ${ns} logs ${pod}
  done | grep "Max entry size '256000' bytes exceeded" | head -5
----
+
The error message includes the stream labels (namespace, pod name, container name) that are producing oversized log lines, and the actual entry length in bytes.

. Verify the current maximum log line size configured on the LokiStack:
+
[source,terminal]
----
$ oc -n ${ns} get cm logging-loki-config -o yaml | grep -i max_line_size
----
+
The default value is `256000` (256 KB).

. Reduce the size of log lines produced by the identified containers. Options include:
+
--
* Reduce application log verbosity or change the log format to produce shorter lines.
* Split large structured JSON log fields into separate log entries at the application level.
* Apply content-based filters in the `ClusterLogForwarder` to drop or truncate fields before forwarding.
--
