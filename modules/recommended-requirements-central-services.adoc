= Central services (self-managed)

[role="_abstract"]
Review the recommended CPU and memory resource requirements for the Central services components in a self-managed {product-title} deployment.

[NOTE]
====
If you are using {rh-rhacscs-first}, you do not need to review the requirements for Central services, because Red{nbsp}Hat manages them. You only need to examine the requirements for secured cluster services.
====

Central services contain the following components:

* Central
* Central DB
* StackRox Scanner
* Scanner V4
