= Create multi-architecture compute clusters on {gcp-first}

[role="_abstract"]
You can run 64-bit ARM and 64-bit x86 workloads in the same {gcp-short} cluster by creating a compute machine set for each architecture. Each machine set references the boot image and the instance type that match its architecture.
