= olm.bundle schema

[role="_abstract"]
To package and distribute Operators within {product-title}, you can define your application manifests and metadata by using the `olm.bundle` schema. Use this format to ensure that Operator Lifecycle Manager (OLM) can correctly parse, validate, and deploy cluster extensions.

.`olm.bundle` schema
[%collapsible]
====
[source,go]
----
#Bundle: {
  schema: "olm.bundle"
  package: string & !=""
  name: string & !=""
  image: string & !=""
  properties: [...#Property]
  relatedImages?: [...#RelatedImage]
}

#Property: {
  // type is required
  type: string & !=""

  // value is required, and it must not be null
  value: !=null
}

#RelatedImage: {
  // image is the image reference
  image: string & !=""

  // name is an optional descriptive name for an image that
  // helps identify its purpose in the context of the bundle
  name?: string & !=""
}
----
