= Limitations and known issues for {cgu-operator-full} events

[role="_abstract"]
Review the following limitations and known issues when using {cgu-operator-first} events for automation workflows.

== Event transport requirement

{cgu-operator} events require the Multicluster Global Hub Operator to transport events to a message broker for consumption by external automation systems. For more information about configuring Multicluster Global Hub, see the link:https://docs.redhat.com/en/documentation/red_hat_advanced_cluster_management_for_kubernetes/{rh-rhacm-version}/html/multicluster_global_hub/[Multicluster Global Hub documentation].

== Missing cluster name annotation for newly provisioned clusters

In some scenarios, the `cgu.openshift.io/cluster-name` annotation might be missing from events generated for newly provisioned clusters. If your automation depends on the cluster name annotation to identify specific clusters, verify that the annotation is present in the events for your environment.
