= Configure a cluster TLS security profile for the Windows Machine Config Operator metrics server

[role="_abstract"]
The Windows Machine Config Operator (WMCO) metrics server uses the cluster-wide TLS security profile if the TLS adherence policy on the cluster `APIServer` resource is set to `StrictAllComponents`.

:FeatureName: The cluster TLS security profile for the Windows Machine Config Operator metrics server
include::snippets/technology-preview.adoc[]

When the `spec.tlsAdherence` parameter on the cluster API server is set to `StrictAllComponents`, the WMCO reads the `spec.tlsSecurityProfile` value from cluster API server and applies the corresponding TLS arguments to the WMCO metrics server. If you change the cluster-wide TLS profile or the adherence policy, the WMCO pod restarts and the metrics server applies the new settings.

This configuration applies only to the WMCO metrics server. It does not change the TLS configuration of the Windows nodes, Windows workloads, or Windows exporter.

To use this feature, you must enable the `TechPreviewNoUpgrade` feature set. For more information, see "Understanding feature gates".

[IMPORTANT]
====
Enabling this feature set cannot be undone and prevents minor version updates.
====

.Prerequisites

* You enabled the `TechPreviewNoUpgrade` feature set. For more information, see "Enabling features using feature gates".

.Procedure

. Edit the cluster `APIServer` custom resource (CR) by running the following command:
+
[source,terminal]
----
$ oc edit apiserver cluster
----

. Add or modify the `tlsAdherence` field in the `spec` section and set it to `StrictAllComponents` by using the following example:
+
[source,yaml]
----
apiVersion: config.openshift.io/v1
kind: APIServer
metadata:
  name: cluster
spec:
  tlsSecurityProfile:
    type: Intermediate
    intermediate: {}
  tlsAdherence: StrictAllComponents
----
+
where:

`tlsSecurityProfile.type`:: Specifies the TLS security profile type. Valid values are `Old`, `Intermediate`, `Modern`, or `Custom`. Also, specify the appropriate field for the selected type. The fields are `old: {}`, `intermediate: {}`, `modern: {}`, or `custom:`.
+
If a TLS security profile type is not specified, the default is `Intermediate`. This parameter is optional.

`tlsAdherence: StrictAllComponents`:: Specifies that cluster-wide TLS settings are enforced on all components.

. Save the changes and exit the editor.
