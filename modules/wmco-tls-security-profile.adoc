= Cluster TLS security profile for the Windows Machine Config Operator metrics server

[role="_abstract"]
The Windows Machine Config Operator (WMCO) metrics server uses the cluster TLS security profile if the TLS adherence policy on the cluster `APIServer` resource is set to `StrictAllComponents`.

The metrics server uses the cluster profile, including a custom profile, when the `spec.tlsAdherence` parameter is set to `StrictAllComponents` and `spec.tlsSecurityProfile` parameter is configured on the cluster API server. If you change the cluster TLS profile or the adherence policy, the WMCO pod restarts and the metrics server applies the new settings.

Windows nodes and Windows workloads keep their current TLS behavior. The Windows Exporter on each Windows node keeps its own TLS settings.

For more information, see "Configuring TLS security profiles".
