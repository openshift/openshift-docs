= Cluster TLS security profile for the Windows Machine Config Operator metrics server

[role="_abstract"]
The Windows Machine Config Operator (WMCO) metrics server uses the cluster TLS security profile if the TLS adherence policy on the cluster `APIServer` resource is set to `StrictAllComponents`.

:FeatureName: TLS adherence for the WMCO metrics server
include::snippets/technology-preview.adoc[]

The metrics server uses the cluster profile, including a custom profile, after you enable the `TechPreviewNoUpgrade` feature set and the TLS adherence on the cluster API server is set to `StrictAllComponents`. If you change the cluster TLS profile, the WMCO pod restarts and the metrics server applies the new settings.

Windows nodes and Windows workloads keep their current TLS behavior. The Windows Exporter on each Windows node keeps its own TLS settings.

For more information, see "Understanding feature gates" and "Configuring TLS security profiles".
