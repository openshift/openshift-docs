= Hierarchical cohort metrics

[role="_abstract"]
You can use cohort metrics to observe the hierarchy, shared quota, resource reservations, admitted workloads, and weighted share of each cohort subtree.

The following metrics describe hierarchical cohorts:

[cols="1,2",options="header"]
|===
|Metric
|Description

|`kueue_cohort_info`
|Reports the direct parent and root cohort for a cohort.

|`kueue_cohort_subtree_admitted_active_workloads`
|Reports the number of active, admitted workloads in a cohort subtree.

|`kueue_cohort_subtree_admitted_workloads_total`
|Reports the total number of workloads admitted in a cohort subtree.

|`kueue_cohort_subtree_quota`
|Reports nominal quota aggregated within a cohort subtree by resource and flavor.

|`kueue_cohort_subtree_resource_reservations`
|Reports resource reservations aggregated within a cohort subtree by resource and flavor.

|`kueue_cohort_weighted_share`
|Reports the highest ratio of resource usage that exceeds nominal quota to the resources that the cohort can lend, divided by the cohort weight.

|`kueue_cluster_queue_info`
|Reports the direct parent cohort and root cohort for a cluster queue.
|===

{kueue-name} enables cohort metrics by default. Only the `kueue_cohort_weighted_share` metric requires the `FairSharing` preemption policy. The cohort subtree metrics do not require fair sharing.
