= Compare architectural deployment models

[role="_abstract"]
{product-title} supports several architectural deployment models, from a standard cluster with dedicated control plane and compute machines to compact three-node clusters, single-node clusters, and clusters that run their control planes as workloads on a management cluster. Comparing these models helps you select one that meets your operational scale and hardware limits.
