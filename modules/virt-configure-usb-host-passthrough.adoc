= USB host passthrough configuration

[role="_abstract"]
You can enable passthrough of USB devices to allow a virtual machine (VM) to connect to USB hardware that is attached to an {product-title} node, as if the hardware and the VM are physically connected.

To expose a USB device, first enable host passthrough and then configure the VM to use the USB device.
