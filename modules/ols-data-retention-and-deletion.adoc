= Data retention and deletion

[role="_abstract"]
Interaction data from {ols-long} is stored locally within the {ols-long} Service pod logs and in your cluster's configured log aggregation system. {red-hat} does not have access to this local data.

If telemetry is enabled, conversation data, including user inputs, LLM outputs, tool call details, retrieval-augmented generation (RAG) context, and associated metadata, is sent to {red-hat} by using the {red-hat} Insights system. {red-hat} retains data that is collected through telemetry until you submit a formal request for data deletion.

To request deletion of your telemetry data, open a support ticket with {red-hat}. Include your cluster identifier and the scope of data that you want to be deleted.

You can disable telemetry at any time to stop all future data collection. Disabling telemetry does not affect data that {red-hat} has already collected. To delete previously collected data, you must submit a separate deletion request.
