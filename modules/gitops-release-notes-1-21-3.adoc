= Release notes for Red Hat OpenShift GitOps 1.21.3

[role="_abstract"]

{gitops-title} 1.21.3 is now available on {OCP} 4.18, 4.19, 4.20, 4.21, and 4.22.

[id="errata-updates-1-21-3_{context}"]
== Errata updates

RHBA-2026:54873 - {gitops-title} 1.21.3 enhancement update advisory::
Issued: 2026-08-14
+
The list of enhancements that are included in this release is documented in the following advisory:
+
* link:https://access.redhat.com/errata/RHBA-2026:54873[RHBA-2026:54873]

If you have installed the {gitops-title} Operator in the default namespace, run the following command to view the container images in this release:

[source,terminal]
----
$ oc describe deployment gitops-operator-controller-manager -n openshift-gitops-operator
----

[id="fixed-issues-1-21-3_{context}"]
== Fixed issues

Redis container image updated to the latest version::
Before this update, the {gitops-title} Operator used an outdated Redis container image that contained multiple known issues. With this update, the Operator uses the latest Redis container image, which includes security patches and dependency updates.
+
link:https://redhat.atlassian.net/browse/GITOPS-10464[GITOPS-10464]
