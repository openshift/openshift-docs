= Logging for Red Hat OpenShift capabilities and limitations

[role="_abstract"]
You can use {logging-uc} to collect, normalize, and forward application, infrastructure, and audit logs to supported storage and forwarding destinations.

[NOTE]
====
{logging-uc} provides log collection and forwarding. For long-term log retention and storage, configure external storage backends. For Security Information and Event Monitoring (SIEM), forward logs to SIEM-compatible systems. Audit logs are not stored locally by default and require explicit forwarding configuration.
====
