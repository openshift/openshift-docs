= Cluster operator authentication on Google Cloud Dedicated

[role="_abstract"]
No user configuration is required for cluster Operators on Google Cloud Dedicated.
All Operators automatically detect the sovereign cloud environment and authenticate to Google Cloud Dedicated APIs transparently.
The following information is provided for troubleshooting reference only.

[discrete]
== How authentication works

On standard {gcp-short}, cluster Operators authenticate to Google Cloud APIs by using OAuth token exchange.
On Google Cloud Dedicated, the standard OAuth token endpoint is not available, so Operators authenticate by using self-signed JSON Web Tokens (JWT) instead.
Operators generate tokens directly from the mounted service account credentials by using the `WithAuthCredentialsJSON` method.

Each Operator reads the universe domain from the mounted service account credential JSON file to determine which API endpoints to use.
For example, instead of calling `compute.googleapis.com`, an Operator on a French Google Cloud Dedicated deployment calls `compute.s3nsapis.fr`.
This endpoint detection is automatic.

[discrete]
== Service account email format

On Google Cloud Dedicated, service account email addresses use a domain-scoped format that differs from standard {gcp-short}.
For a project with the domain-scoped ID `eu0:my-project`, the service account email follows the pattern:

----
<name>@my-project.eu0.iam.gserviceaccount.com
----

This differs from the standard {gcp-short} format of `<name>@my-project.iam.gserviceaccount.com`.
The installation program automatically handles this format conversion during cluster creation.
