= Upgrade clusters deployed with the O-Cloud Manager

[role="_abstract"]
You can upgrade clusters provisioned by the O-Cloud Manager by creating a `ClusterTemplate` custom resource (CR) version for the target release and referencing it in the `ProvisioningRequest` CR. Single-node clusters use image-based upgrades; multi-node clusters use standard upgrades.

You can perform these upgrades by editing the `ProvisioningRequest` CR directly or through the Provisioning REST API.

The O-Cloud Manager is a Technology Preview feature only.
