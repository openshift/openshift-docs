= Sync Operator catalogs

[role="_abstract"]
To use digests newer than those bundled in the image, sync Operator catalog digests in the OpenShift Mirror Console. Syncing fetches the latest catalog digests from `registry.redhat.io` for supported {product-title} versions.

.Prerequisites

* The OpenShift Mirror Console is open in a browser.
* You have configured a pull secret.

.Procedure

. Click *Settings* to open the console settings.

. Click the *Sync Catalogs* tab to manage Operator catalog digests.

. Click *Sync Catalogs* to fetch the latest catalog digests from `registry.redhat.io`.
+
The sync can take several minutes.

. Expand the *Catalog Digests* section to review the synced catalog digests.
+
The table lists each catalog, the {product-title} version, the catalog digest, and the last updated time.

. Optional: To copy a digest, click the *Copy* icon next to the digest value.

. Optional: To delete the synced catalog digests and return the console to the catalogs bundled in the image, click *Clear Sync Data*.

.Verification

. If you did not clear the sync data, confirm that the *Catalog Digests* section lists one or more Operator catalogs for the supported {product-title} versions.

. If you did not clear the sync data, confirm that each row shows a digest and an updated timestamp.
