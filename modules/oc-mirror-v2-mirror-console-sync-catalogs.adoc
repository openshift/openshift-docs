= Sync Operator catalogs

[role="_abstract"]
Sync Operator catalog digests in the OpenShift Mirror Console to retrieve digests newer than those bundled in the console image. Synchronization retrieves the latest digests from `registry.redhat.io` for supported {product-title} versions.

.Prerequisites

* You have opened the OpenShift Mirror Console in a browser.
* You have configured a pull secret.

.Procedure

. Click *Settings* to open the console settings.

. Click the *Sync Catalogs* tab to manage Operator catalog digests.

. Click *Sync Catalogs* to fetch the latest catalog digests from `registry.redhat.io`.
+
The sync can take several minutes.

. Expand the *Catalog Digests* section to review the synced catalog digests.
+
The table lists each catalog, the {product-title} version, the catalog digest, and the last updated time.

. Optional: To copy a digest, click the *Copy* icon next to the digest value.

.Verification

. Confirm that the *Catalog Digests* section lists one or more Operator catalogs for the supported {product-title} versions.

. Confirm that each row shows a digest and an updated timestamp.

[NOTE]
====
*Clear Sync Data* deletes the synced catalog digests. The console then returns to the catalogs bundled in the console image.
====
