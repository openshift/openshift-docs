= Sync Operator catalogs

[role="_abstract"]
Sync Operator catalog digests so the OpenShift Mirror Console can fetch the latest catalog digests from `registry.redhat.io` for supported {product-title} versions.

Syncing catalogs is optional. Complete this procedure only if you need digests newer than the default image settings in the OpenShift Mirror Console.

.Prerequisites

* You are logged in to the OpenShift Mirror Console.
* You have configured a pull secret.

.Procedure

. Click *Settings* to open console settings.

. Click the *Sync Catalogs* tab to manage Operator catalog digests.

. Click *Sync Catalogs* to fetch the latest catalog digests from `registry.redhat.io`.
+
The sync can take several minutes.

. Expand the *Catalog Digests* to review the synced catalog digests.
+
The table lists each catalog, the {product-title} version, the catalog digest, and the last updated time. You can copy a digest by clicking the *Copy* icon next to the digest value.

. Optional: To remove the synced catalog digests from the application and revert to the default image settings, click *Clear Sync Data*.

.Verification

* Confirm that the *Catalog Digests* section lists one or more Operator catalogs for the supported {product-title} versions.

* Confirm that each row shows a digest and an updated timestamp.
