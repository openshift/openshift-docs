= Auth0 default claim mappings

[role="_abstract"]
The `Auth0` authentication provider maps the `sub`, `name`, `email`, and `groups` claims by default.

{product-title-short} applies the following default claim mappings for `Auth0`:

* `sub` to `userid`
* `name` to `name`
* `email` to `email`
* `groups` to `groups`
