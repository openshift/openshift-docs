= Query metrics from an egress gateway

[role="_abstract"]
Confirm that an egress `Gateway` object emits metrics for outbound traffic by reading the Prometheus endpoint of the gateway pod directly.

.Prerequisites

include::snippets/egress-gateway-prereqs.adoc[]

* You sent traffic through the egress `Gateway` object to an external service.

.Procedure

. Store the name of the egress gateway pod in a variable by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ export EGRESS_POD=$(oc get pods -n _<gateway_system>_ \
    -l gateway.networking.k8s.io/gateway-name=_<kuadrant_egressgateway>_ \
    -o jsonpath='{.items[0].metadata.name}')
----
+
* Replace `_<gateway_system>_` with the namespace where you applied your egress `Gateway` object.
* Replace `_<kuadrant_egressgateway>_` with the name of your egress `Gateway` object.

. Read the request counters from the metrics endpoint of the gateway pod by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc exec -n _<gateway_system>_ ${EGRESS_POD} -- \
    pilot-agent request GET /stats/prometheus | grep "^istio_requests_total"
----

.Verification

* Confirm that the output has one series for each combination of external destination, response code, and response flags, similar to the following example:
+
.Example output
[source,text]
----
istio_requests_total{...,destination_service="api.example.com",...,response_code="200",response_flags="-",...} 8
istio_requests_total{...,destination_service="api.example.com",...,response_code="503",response_flags="-",...} 24
istio_requests_total{...,destination_service="unknown",...,response_code="404",response_flags="NR",...} 4
----
