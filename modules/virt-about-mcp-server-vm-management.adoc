= MCP server tools for virtual machines

[role="_abstract"]
The Model Context Protocol (MCP) server for Red{nbsp}Hat {product-title} provides tools and prompts that you can use to manage virtual machines through a natural language interface. You can direct AI assistants to create, manage, and troubleshoot virtual machines on your behalf.

MCP server for Red{nbsp}Hat {product-title} is a Technology Preview feature only.
