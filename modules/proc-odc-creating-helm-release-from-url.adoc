= Installing a Helm release from a URL

[role="_abstract"]
A Helm release is a deployed instance of a Helm chart in your {product-title} cluster. You can install a Helm release directly from a chart URL instead of from the software catalog.

Usually, you install charts from the software catalog in the web console. By default, the catalog lists charts that Red Hat provides, and administrators can add more charts for the whole cluster or for a single namespace. If you need only one or two charts, you can skip adding them to the catalog and install a chart directly from its URL instead. However, a chart that you install from a URL does not get the review that Red Hat and your administrators give catalog charts, so use this method only when you trust the source of the chart.

[WARNING]
====
Charts that Red Hat or your administrators have not reviewed can introduce security risks to your cluster.
====

.Prerequisites
* You have logged in to the {product-title} web console.
* You have the necessary project permissions to install a Helm chart.
* You have a URL for a Helm chart.

.Procedure
. In the {product-title} web console, navigate to **Ecosystem > Helm**. The **Helm** view opens.
. In the **Project** drop-down menu, select the project where you want to install the Helm release; for example, **default**.
. From the **Helm releases** tab, click **Create**.
. Select **Helm chart URL**. The **Install Helm chart from URL** view opens.
. In the **Chart URL** field, enter the URL for the Helm chart you want to install.
+
[NOTE]
====
For Helm charts stored in an OCI-compliant registry, the URL must use the `oci://` protocol; for example, `oci://quay.io/organization/repository/chart-name`.
====
+
. In the **Release name** field, enter a name for the Helm release you want to install.
. In the **Chart version** field, enter the chart version number if the web console does not detect it automatically.
. Optional: If the chart URL requires authentication, select a secret from the **Secret for Basic authentication** list. If the secret you need does not exist, create it:
.. From the **Secret for Basic authentication** list, select **Create Secret**. The **Create authentication Secret** dialog opens.
.. In the **Secret name** field, enter a unique name for the secret.
.. Optional: In the **Secret username** field, enter the username for the chart URL.
.. In the **Secret password or token** field, enter the password or token for the chart URL.
.. Click **Create**. The web console selects the new secret in the **Secret for Basic authentication** list.
. Click **Next**. The **Configure Helm release** view opens.
. Review the configuration. Make sure that the **Chart URL**, **Release name**, and **Version** fields are correct.
. For the **Configure via** option, select either **Form view** or **YAML view**.
* Choose **Form view** (the default) for a guided configuration of standard parameters.
* Choose **YAML view** if you need to change advanced settings that are not available in **Form view**.
+
[NOTE]
====
The **Form view** might not display every field from your Helm chart. If the chart does not include a values schema, **Form view** is unavailable and you must use **YAML view**. For full control over all configuration parameters, select **YAML view**.
====
+
. Click **Install**. The **Helm releases** tab opens and displays a status of **Deployed** if the installation succeeds.

.Verification
* The **Helm releases** tab displays the new Helm release in the table.
* The **Status** column for the Helm release displays **Deployed**.
