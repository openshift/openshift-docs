= Include workflow context in log output

[role="_abstract"]
You can configure the Quarkus log format to include workflow context fields in log output.

MDC fields are populated when a workflow instance starts or resumes from a waiting state, and cleared when the instance completes, is canceled, or enters a waiting state. Fields with null values are omitted.

.Workflow MDC fields
[cols="1,2",options="header"]
|===
| MDC key | Description

| `instanceId` | Unique ID of the workflow instance
| `processId` | ID of the workflow definition
| `name` | Name of the workflow
| `version` | Version of the workflow
| `rootInstanceId` | ID of the root workflow instance in a nested workflow hierarchy
| `rootProcessId` | ID of the root workflow definition in a nested workflow hierarchy
| `parentInstanceId` | ID of the parent workflow instance
| `description` | Description of the workflow instance
| `businessKey` | Business key associated with the workflow instance
| `deploymentId` | Deployment ID
| `referenceId` | External reference ID
|===

.Prerequisites
* You have a workflow application deployed on {ocp-product-title}.
* You have access to the `application.properties` file for your workflow.

.Procedure

* Add the MDC fields you require to the log format by adding the following configuration to `application.properties`:
+
[source,properties]
----
quarkus.log.console.format=%d{yyyy-MM-dd HH:mm:ss,SSS} %-5p [%c{3.}] (%t) [%X{processId}/%X{instanceId}/%X{rootInstanceId}] %s%e%n
----
+
where:
+
`%X{<key>}`:: Specifies the MDC field value to insert into the log line. Replace `<key>` with any of the MDC keys listed in the "Workflow MDC fields" table.

.Verification

Start a workflow instance and inspect the console log output. Each log line emitted during execution includes the configured workflow context fields.
