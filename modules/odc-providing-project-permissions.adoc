= Providing access permissions to your project

[role="_abstract"]
You can use the *Project* page to grant or revoke access permissions to your project.

You can add users to your project and provide them with *Admin*, *Edit*, or *View* access.

.Prerequisites

* You have created a project.

.Procedure

. Go to the *Project* page.

. Select your project from the *Project* menu.

. Select the *RoleBindings* tab.

. Click the *Create binding* button to add a new row of permissions to the default ones.
+
.. Enter a name for the role binding in the *Name* field.
+
.. Enter a role name in the *Role name* field.
+
.. Enter a subject name in the *Subject name* field.
Ensure you click the *User*, *Group*, or *ServiceAccount* radio button to select the correct subject type.
+
.. Click the *Create* button.
