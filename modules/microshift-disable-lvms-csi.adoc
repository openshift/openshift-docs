= Disable the LVMS CSI provider and CSI snapshot

[role="_abstract"]
If your {microshift-short} deployment uses external or pre-provisioned storage and does not require dynamic local provisioning, you can disable the LVMS CSI driver and CSI snapshot controller. Disabling these components reduces resource usage on constrained devices.
