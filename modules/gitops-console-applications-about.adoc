= About Applications in the GitOps Console

The {gitops-shortname} Console Plugin provides list and details pages for Argo CD Applications in the {OCP} web console. You can view Application health and sync status, inspect sources and managed resources, review sync history, and access related events.

The Applications list page provides the following capabilities:

* Filter Applications by sync status and health status
* Search Applications by name
* View Application metadata including namespace, labels, and AppProject
* Create Applications from YAML templates

The Application details page includes the following tabs:

* *Details*: Identity, status, and sync policy configuration
* *YAML*: Live manifest editor
* *Sources*: Repository sources for single-source and multi-source Applications
* *Resources*: Managed resources in list or graph view
* *Sync Status*: Latest sync operation details
* *History*: Sync and deployment history
* *Events*: Kubernetes events for the Application object

[IMPORTANT]
====
The plugin displays the health status stored on the Application custom resource (CR). If health is missing or incorrect, set `controller.resource.health.persist: "true"` in the `argocd-cmd-params-cm` ConfigMap.
====
