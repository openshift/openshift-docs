= ConfigMap data modification example

[role="_abstract"]
The following overlay modifies the data in the `central-endpoints` ConfigMap, overriding only a single item, or file, under `data`.

[source,yaml]
----
apiVersion: platform.stackrox.io
kind: Central
metadata:
  name: central
spec:
    # ...
    overlays:
    - apiVersion: v1
      kind: ConfigMap
      name: central-endpoints
      patches:
      - path: data.endpoints\.yaml
        verbatim: |
          disableDefault: false
          # another line
----

* The `verbatim` key is used instead of `value` so that characters such as newlines or quotes pass through unaffected.
* The dot in the file name in the `path` key is escaped. Alternatively, you can write the path as `data["endpoints.yaml"]`.
