= Create certificate request policies

[role="_abstract"]
You can create a `CertificateRequestPolicy` resource to define the certificate requests that approver-policy can approve. Configure a policy that matches only the issuers, namespaces, and certificate attributes that your workloads require.

:FeatureName: Managing certificate request approval by using approver-policy
include::snippets/technology-preview.adoc[leveloffset=+1]

.Prerequisites

* The approver-policy operand is running.

* You have configured the issuer that the policy must match.

* You know the namespaces and certificate attributes that the policy must permit.

.Procedure

. Create a YAML file, for example, `certificate-request-policy.yaml`, that defines the `CertificateRequestPolicy` resource as shown in the following example:
+
.Example certificate-request-policy.yaml
[source,yaml]
----
apiVersion: policy.cert-manager.io/<api_version>
kind: CertificateRequestPolicy
metadata:
  name: <policy_name>
spec:
  selector:
    issuerRef:
      name: <issuer_name>
      kind: <issuer_kind>
    namespace:
      matchNames:
        - <namespace>
  allowed:
    <allowed_request_attributes>
----

. Create the policy by running the following command:
+
[source,terminal]
----
$ oc apply -f certificate-request-policy.yaml
----

.Verification

* Verify that the policy was created by running the following command:
+
[source,terminal]
----
$ oc get certificaterequestpolicy <policy_name>
----

* Create a certificate request that matches the policy.

* Inspect the request status and events by running the following command:
+
[source,terminal]
----
$ oc describe certificaterequest <certificate_request_name> -n <namespace>
----

* Confirm that approver-policy approves a request that meets the policy requirements. Confirm that a request that does not meet the requirements is denied or remains pending, according to the supported approver-policy behavior.
