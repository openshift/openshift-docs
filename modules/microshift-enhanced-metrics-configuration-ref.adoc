[id="microshift-enhanced-metrics-configuration-ref_{context}"]
= Enhanced metrics configuration reference

[role="_abstract"]
This reference lists the RPM packages, deployed resources, endpoints, and configuration parameters for enhanced metrics in {microshift-short}.

[id="microshift-enhanced-metrics-rpm-packages_{context}"]
== Optional RPM packages

.Enhanced metrics RPM packages table
[cols="1,2"]
|===
|Parameter |Description

|`microshift-metrics-node-exporter`
|Deploys node-exporter as a DaemonSet and exposes node hardware and operating system metrics.

|`microshift-metrics-server`
|Deploys metrics-server and registers the Kubernetes `metrics.k8s.io` API.

|`microshift-metrics-kube-state-metrics`
|Deploys kube-state-metrics and exposes Kubernetes object state metrics.

|`microshift-metrics-node-exporter-release-info`
|Contains image reference JSON files for offline image builds and ostree deployments of node-exporter.

|`microshift-metrics-server-release-info`
|Contains image reference JSON files for offline image builds and ostree deployments of metrics-server.

|`microshift-metrics-kube-state-metrics-release-info`
|Contains image reference JSON files for offline image builds and ostree deployments of kube-state-metrics.
|===

[id="microshift-enhanced-metrics-deployment_{context}"]
== Deployment and endpoints

Each enhanced metrics RPM deploys resources into the `openshift-monitoring` namespace.

.Enhanced metrics deployment and endpoints table
[cols="1,2"]
|===
|Parameter |Description

|`node-exporter.workload`
|DaemonSet `node-exporter`.

|`node-exporter.configurationObjects`
|Includes `ConfigMap/node-exporter-accelerators-collector-config`, `Secret/node-exporter-kube-rbac-proxy-config`, and `Service/node-exporter`.

|`node-exporter.endpoint`
|Service `node-exporter` on port `9100` (`https`). The exporter listens on `127.0.0.1:9101` inside the pod, and `kube-rbac-proxy` serves HTTPS on the node host network.

|`metrics-server.workload`
|Deployment `metrics-server`.

|`metrics-server.configurationObjects`
|Includes `ConfigMap/metrics-server-audit-profiles`, `Service/metrics-server`, and `APIService/v1beta1.metrics.k8s.io`.

|`metrics-server.endpoint`
|Service `metrics-server` on port `443` (`https`). The pod serves HTTPS on port `10250`.

|`kube-state-metrics.workload`
|Deployment `kube-state-metrics`.

|`kube-state-metrics.configurationObjects`
|Includes `ConfigMap/kube-state-metrics-custom-resource-state-configmap`, `Secret/kube-state-metrics-kube-rbac-proxy-config`, and `Service/kube-state-metrics`.

|`kube-state-metrics.endpoint.https-main`
|Service `kube-state-metrics` on port `8443` (`https-main`). The main exporter listens on `127.0.0.1:8081` inside the pod.

|`kube-state-metrics.endpoint.https-self`
|Service `kube-state-metrics` on port `9443` (`https-self`). The telemetry exporter listens on `127.0.0.1:8082` inside the pod.
|===

[id="microshift-enhanced-metrics-node-exporter-collectors_{context}"]
== node-exporter default collector settings

.node-exporter configuration fields definitions table
[cols="1,2"]
|===
|Parameter |Description

|`--web.listen-address`
|Address on which the node-exporter process listens inside the pod. The default value is `127.0.0.1:9101`.

|`--collector.cpu.info`
|Enables the CPU information collector. This collector is enabled by default.

|`--collector.textfile.directory`
|Directory for textfile collector metrics. The default value is `/var/node_exporter/textfile`.

|`--no-collector.wifi`
|Disables the WiFi collector. The WiFi collector is disabled by default.

|`--no-collector.btrfs`
|Disables the Btrfs collector. The Btrfs collector is disabled by default.

|`--collector.netclass.ignored-devices`
|Regular expression that excludes network class devices from collection. The default value is `^.*$`, which excludes all devices.

|`--collector.netdev.device-exclude`
|Regular expression that excludes network devices from the netdev collector. The default value is `^.*$`, which excludes all devices.

|`--collector.filesystem.mount-points-exclude`
|Regular expression that limits filesystem metrics to non-container mount points. The default value excludes `/dev`, `/proc`, `/sys`, and container runtime paths.
|===

[id="microshift-enhanced-metrics-node-exporter-accelerators_{context}"]
== node-exporter accelerators collector ConfigMap

The `node-exporter-accelerators-collector-config` `ConfigMap` defines hardware accelerator devices that the accelerators collector can expose. The default configuration includes PCI vendor and model mappings for NVIDIA, AMD, Intel, Qualcomm, Marvell, Mellanox, and Gaudi devices.

To customize accelerator detection, edit the `config.yaml` key in the `node-exporter-accelerators-collector-config` `ConfigMap` in the `openshift-monitoring` namespace.

[id="microshift-enhanced-metrics-kube-state-metrics-filters_{context}"]
== kube-state-metrics default metric filters

{microshift-short} applies default metric filters to limit sensitive or high-cardinality data.

.kube-state-metrics metric labels allowlist table
[cols="1,2"]
|===
|Parameter |Description

|`pods`
|Allows all labels (`[*]`) on pod metrics.

|`nodes`
|Allows all labels (`[*]`) on node metrics.

|`namespaces`
|Allows all labels (`[*]`) on namespace metrics.

|`persistentvolumes`
|Allows all labels (`[*]`) on persistent volume metrics.

|`persistentvolumeclaims`
|Allows all labels (`[*]`) on persistent volume claim metrics.

|`poddisruptionbudgets`
|Allows all labels (`[*]`) on pod disruption budget metrics.
|===

.kube-state-metrics metric denylist table
[cols="1,2"]
|===
|Parameter |Description

|`^kube_secret_labels$`
|Excludes secret label metrics from export.

|`^kube_.+_annotations$`
|Excludes annotation metrics from export.

|`^kube_customresource_.+_annotations_info$`
|Excludes custom resource annotation info metrics from export.

|`^kube_customresource_.+_labels_info$`
|Excludes custom resource label info metrics from export.

|`^kube_.+_created$`
|Excludes object creation timestamp metrics from export.

|`^kube_.+_metadata_resource_version$`
|Excludes metadata resource version metrics from export.

|`^kube_replicaset_metadata_generation$`
|Excludes ReplicaSet metadata generation metrics from export.

|`^kube_replicaset_status_observed_generation$`
|Excludes ReplicaSet observed generation metrics from export.

|`^kube_pod_restart_policy$`
|Excludes pod restart policy metrics from export.

|`^kube_pod_init_container_status_terminated$`
|Excludes init container terminated status metrics from export.

|`^kube_pod_init_container_status_running$`
|Excludes init container running status metrics from export.

|`^kube_pod_container_status_terminated$`
|Excludes container terminated status metrics from export.

|`^kube_pod_container_status_running$`
|Excludes container running status metrics from export.

|`^kube_pod_completion_time$`
|Excludes pod completion time metrics from export.

|`^kube_pod_status_scheduled$`
|Excludes pod scheduled status metrics from export.
|===

[id="microshift-enhanced-metrics-kube-state-metrics-custom-resources_{context}"]
== kube-state-metrics custom resource state ConfigMap

The `kube-state-metrics-custom-resource-state-configmap` `ConfigMap` defines additional metrics for custom resources. The default configuration includes metrics for the following API groups:

* `autoscaling.k8s.io/v1` `VerticalPodAutoscaler`
* `gateway.networking.k8s.io/v1` `GatewayClass`
* `gateway.networking.k8s.io/v1` `Gateway`

To add or change custom resource metrics, edit the `custom-resource-state-configmap.yaml` key in the `kube-state-metrics-custom-resource-state-configmap` `ConfigMap`.

[id="microshift-enhanced-metrics-server-config_{context}"]
== metrics-server configuration

.metrics-server configuration fields definitions table
[cols="1,2"]
|===
|Parameter |Description

|`--secure-port`
|Port on which metrics-server serves HTTPS inside the pod. The default value is `10250`.

|`--metric-resolution`
|Interval at which metrics are refreshed from kubelets. The default value is `15s`.

|`--kubelet-preferred-address-types`
|Address types that metrics-server uses when connecting to kubelets. The default value is `InternalIP,ExternalIP,Hostname`.

|`--kubelet-use-node-status-port`
|Uses the node status port reported by the kubelet. This setting is enabled by default.

|`--shutdown-delay-duration`
|Delay before metrics-server shuts down after receiving a termination signal. The default value is `150s`.

|`--disable-http2-serving`
|Disables HTTP/2 for the metrics-server web server. This setting is enabled by default.
|===

[id="microshift-enhanced-metrics-server-audit-profiles_{context}"]
== metrics-server audit profiles ConfigMap

The `metrics-server-audit-profiles` `ConfigMap` contains Kubernetes audit policy profiles that metrics-server can reference. The default `ConfigMap` defines the following profiles:

* `Metadata`
* `None`
* `Request`
* `RequestResponse`

[id="microshift-enhanced-metrics-otel-scrape-config_{context}"]
== OpenTelemetry Collector scrape configuration

When you install both a metrics RPM and the `microshift-observability` RPM, {microshift-short} installs an OpenTelemetry Collector scrape configuration drop-in file for each enabled exporter under `/etc/microshift/observability/otelcol.d/`.

.OpenTelemetry scrape drop-in files table
[cols="1,2"]
|===
|Parameter |Description

|`node-exporter.yaml`
|Installed when the `microshift-metrics-node-exporter` RPM is installed.

|`metrics-server.yaml`
|Installed when the `microshift-metrics-server` RPM is installed.

|`kube-state-metrics.yaml`
|Installed when the `microshift-metrics-kube-state-metrics` RPM is installed.
|===

The drop-in files define `scrape_configs` entries for the OpenTelemetry Collector Prometheus receiver.

.OpenTelemetry scrape configuration fields definitions table
[cols="1,2"]
|===
|Parameter |Description

|`scrape_interval`
|How often the collector scrapes the exporter endpoint. The default value is `10s`.

|`scheme`
|Protocol used to scrape metrics. The default value is `https`.

|`tls_config.ca_file`
|CA certificate used to verify the exporter service certificate. The default value is `/var/lib/microshift/certs/service-ca/ca.crt`.

|`tls_config.cert_file`
|Client certificate presented to `kube-rbac-proxy`. The default value is `/var/lib/microshift/certs/admin-kubeconfig-signer/openshift-observability-client/client.crt`.

|`tls_config.key_file`
|Client private key presented to `kube-rbac-proxy`. The default value is `/var/lib/microshift/certs/admin-kubeconfig-signer/openshift-observability-client/client.key`.

|`kubernetes_sd_configs.role`
|Service discovery mechanism used to locate exporter endpoints. The default value is `endpoints`.

|`kubernetes_sd_configs.namespaces.names`
|Namespace that contains exporter Services. The default value is `openshift-monitoring`.
|===

The kube-state-metrics drop-in file defines two scrape jobs:

* `kube-state-metrics` for the `https-main` endpoint on port `8443`
* `kube-state-metrics-self` for the `https-self` endpoint on port `9443`
