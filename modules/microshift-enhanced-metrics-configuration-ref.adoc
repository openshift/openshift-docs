= Enhanced metrics configuration reference

[role="_abstract"]
Enhanced metrics in {microshift-short} are enabled by installing optional RPM packages. Each exporter is deployed into the `openshift-monitoring` namespace and exposes metrics through a Kubernetes Service.

[id="microshift-enhanced-metrics-rpm-packages_{context}"]
== Optional RPM packages

[cols="2,3",options="header"]
|===
|RPM package |Description

|`microshift-metrics-node-exporter`
|Deploys node-exporter as a DaemonSet and exposes node hardware and operating system metrics.

|`microshift-metrics-server`
|Deploys metrics-server and registers the Kubernetes resource metrics API.

|`microshift-metrics-kube-state-metrics`
|Deploys kube-state-metrics and exposes Kubernetes object state metrics.
|===

Optional `*-release-info` packages are also available for offline image builds and ostree deployments. These packages contain image reference JSON files.

[id="microshift-enhanced-metrics-services_{context}"]
== Metrics endpoints

[cols="2,2,3",options="header"]
|===
|Exporter |Namespace |Metrics access

|node-exporter
|`openshift-monitoring`
|HTTPS metrics endpoint exposed by the `node-exporter` Service and local host endpoint on port `9100`

|metrics-server
|`openshift-monitoring`
|HTTPS metrics endpoint exposed by the `metrics-server` Service on port `10250`

|kube-state-metrics
|`openshift-monitoring`
|HTTPS metrics endpoints exposed by the `kube-state-metrics` Service on ports `8443` and `9443`
|===

[id="microshift-enhanced-metrics-configmaps_{context}"]
== Exporter configuration

The following configuration objects are deployed with the exporters:

node-exporter::
An accelerators collector `ConfigMap` defines optional hardware accelerator metrics that node-exporter can expose.

kube-state-metrics::
A custom resource state `ConfigMap` defines additional Kubernetes custom resource metrics, such as Vertical Pod Autoscaler and Gateway API metrics, that kube-state-metrics can expose.

metrics-server::
No user-facing configuration objects are required for a default deployment.

When {microshift-short} Observability is installed, each metrics RPM also installs an OpenTelemetry Collector scrape configuration drop-in file under `/etc/microshift/observability/otelcol.d/`. The collector loads only the drop-in files for installed exporters.
