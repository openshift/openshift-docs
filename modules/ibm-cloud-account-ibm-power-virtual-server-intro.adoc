= Configuring an {ibm-cloud-title} account

[role="_abstract"]
To install {product-title} on {ibm-power-server-name}, you must configure an {ibm-cloud-name} account with the correct quotas, DNS resolution, and IAM policies.

== Prerequisites

* You have an {ibm-cloud-name} account with a subscription. You cannot install {product-title} on a free or on a trial {ibm-cloud-name} account.
