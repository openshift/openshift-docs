= serverless logic 1.39

[role="_abstract"]
{ServerlessLogicProductName} 1.39 is generally available. New features that pertain to {ServerlessLogicProductName} on {ocp-product-title} are included in the following notes:

[id="new-features-osl-1-39-0_{context}"]
== New features

Built-in MDC logging for workflow process and instance correlation::

{ServerlessLogicProductName} includes built-in Mapped Diagnostic Context (MDC) logging that automatically adds process correlation fields, such as `processId` and `instanceId`, to log lines during workflow execution. As a result, you can correlate and troubleshoot workflow logs more effectively.
+
link:https://issues.redhat.com/browse/SRVLOGIC-936[SRVLOGIC-936]

Built-in sensitive data masking in workflow logging::

{ServerlessLogicProductName} includes a configurable sensitive data masking filter for workflow logging. When enabled, the filter automatically masks sensitive data, such as Bearer tokens and Authorization headers, in log output. You can specify custom masking patterns using regular expressions in the application configuration. As a result, the filter helps reduce the risk of exposing sensitive data in workflow log output during development and troubleshooting.
+
link:https://issues.redhat.com/browse/SRVLOGIC-935[SRVLOGIC-935]

Custom pod labels for Data Index and Job Service::

{ServerlessLogicProductName} supports configuring custom labels on Data Index and Job Service pods by setting the `podTemplate.metadata.labels` field in the `SonataFlowPlatform` custom resource (CR). As a result, you can attach custom metadata to these pods for purposes such as tracking, policy enforcement, or third-party tool integration.
+
link:https://issues.redhat.com/browse/SRVLOGIC-1015[SRVLOGIC-1015]

Logical workflow versioning::

{ServerlessLogicProductName} introduces a logical workflow versioning strategy that allows multiple versions of a workflow to share the same workflow identifier, linked through the `sonataflow.org/id` annotation in the `SonataFlow` custom resource (CR). This enables services such as Data Index to group different versions under a unified workflow lineage. As a result, you can deploy and manage multiple versions of a workflow while maintaining a consistent identity across the platform.
+
link:https://issues.redhat.com/browse/SRVLOGIC-975[SRVLOGIC-975]

[id="removed-features-osl-1-39-0_{context}"]
== Removed features

Dashbuilder is removed::

The Dashbuilder component, which provided dashboard capabilities in the {ServerlessLogicProductName} Management Console, is removed and is no longer supported. You can monitor workflows by using Prometheus metrics with Grafana dashboards instead.
+
link:https://issues.redhat.com/browse/SRVLOGIC-999[SRVLOGIC-999]
