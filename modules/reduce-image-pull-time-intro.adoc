= Reduce image pull time for operations that require a pull, such as cluster updates or application deployments

[role="_abstract"]
You can prevent a slow, unreliable connection to an image registry from interfering with operations that require pulled images by pulling those images in advance and _pinning_ them to a specific machine config pool (MCP) before they are needed. Pinning frequently used images in advance reduces pod startup time and improves the reliability of operations such as cluster updates and application deployments.
