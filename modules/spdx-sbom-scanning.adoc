= SPDX version 2.3 SBOM scanning

// JIRA: ROX-32694

[role="_abstract"]
Scanner V4 can now scan System Package Data Exchange (SPDX) version 2.3 Software Bill of Materials (SBOM) files to report vulnerabilities based on component inventory data.

This Technology Preview feature includes the following capabilities:

* Scanner V4 processes SPDX version 2.3-format SBOM files to identify vulnerable components.
* Vulnerability reporting uses SBOM component data without requiring direct image access.
* SBOM scanning complements traditional image scanning for air-gapped environments or when images are not directly available.
* API support enables automated SBOM submission and vulnerability retrieval workflows.

SBOM scanning is enabled by default in this release. Use the Scanner V4 APIs to submit SPDX version 2.3 SBOM files for vulnerability analysis.
