= Installing the {ols-long} Operator by using the CLI

[role="_abstract"]
As an alternative to the web console, you can install the {ols-long} Operator from the command line. The {ols-long} Operator v2.0 bundles both classic {ols-long} and Agentic {ols-long} into a single Operator installation.

.Prerequisites

// NOTE: "OpenShift 5.0+" is kept verbatim from the source install guide and conflicts with the OperatorHub module (ols-installing-operator-from-operatorhub.adoc), which states OCP 4.16 to 4.22. Reconcile the supported-version statement across the Install assembly before publishing.
* You have an OpenShift 5.0+ cluster with `cluster-admin` access.

* You have installed the {oc-first} and logged in to the cluster.

.Procedure

. Create the `Namespace`, `OperatorGroup`, and `Subscription` resources by running the following command:
+
[source,terminal]
----
$ oc apply -f - <<'EOF'
apiVersion: v1
kind: Namespace
metadata:
  name: openshift-lightspeed
---
apiVersion: operators.coreos.com/v1
kind: OperatorGroup
metadata:
  name: openshift-lightspeed
  namespace: openshift-lightspeed
spec:
  targetNamespaces:
    - openshift-lightspeed
  upgradeStrategy: Default
---
apiVersion: operators.coreos.com/v1alpha1
kind: Subscription
metadata:
  name: lightspeed-operator
  namespace: openshift-lightspeed
spec:
  channel: stable
  name: lightspeed-operator
  source: redhat-operators
  sourceNamespace: openshift-marketplace
  installPlanApproval: Automatic
EOF
----

. Wait for the cluster service version (CSV) to succeed by running the following command:
+
[source,terminal]
----
$ oc wait --for=jsonpath='{.status.phase}'=Succeeded csv -n openshift-lightspeed \
  -l operators.coreos.com/lightspeed-operator.openshift-lightspeed \
  --timeout=300s
----

.Verification

. Verify that both controllers are running by running the following command:
+
[source,terminal]
----
$ oc get deploy -n openshift-lightspeed
----
+
.Example output
[source,terminal]
----
lightspeed-operator-controller-manager         1/1
lightspeed-agentic-operator-controller-manager 1/1
----
