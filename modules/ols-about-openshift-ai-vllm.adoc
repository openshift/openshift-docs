= How {ocp-ai} vLLM serving runtime works
:context: ols-about-openshift-ai-vllm

[role="_abstract"]
{ocp-ai} supports the Virtual Large Language Model (vLLM) serving runtime for use with {ols-long} through an {openai}-compatible API.

While {ols-long} has not been fully tested with this runtime, you can use the {openai} configuration instructions to connect to your {ocp-ai} vLLM endpoint.

[NOTE]
====
For agentic and tool-calling workloads, use the Anthropic provider and the Anthropic-compatible `/v1/messages` endpoint instead of the {openai}-compatible endpoint. The `/v1/messages` endpoint is available in the vLLM version shipped with {rhelai}, which also makes this pathway suitable for disconnected environments that host vLLM locally.
====
