= Auto-instrumentation by using eBPF

[role="_abstract"]
Another auto-instrumentation tool is the zero-code OpenTelemetry eBPF Instrumentation (OBI).

OBI uses the extended Berkeley Packet Filter (eBPF) to automatically instrument supported Linux application executables at the kernel level and the operating system networking layer. OBI can capture trace spans, application metrics, runtime metrics, network metrics, and Rate Errors Duration (RED) metrics.
