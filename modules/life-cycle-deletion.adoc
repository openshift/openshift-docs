= Deletion policy

[role="_abstract"]
Red{nbsp}Hat reserves the right to delete {product-title} clusters within 15 days if the service notifications requiring actions are not addressed. These actions include upgrading the cluster to a supported {OCP-short} version or resolving cluster health issues so that the service can auto-upgrade the cluster to a supported {OCP-short} version.

{product-title} services will notify you when the cluster is unhealthy and when the {OCP-short} version is approaching end of life (EOL).

[IMPORTANT]
====
{product-title} clusters configured with delete protection enabled can still be deleted based on the deletion policy.
====

If a {product-title} cluster is deleted, any applications or business hosted on the cluster will be impacted. Additionally, cloud resources might remain in the AWS account after cluster deletion, which will continue to incur costs.
