= Overview of Changed block tracking

[role="_abstract"]
Changed block tracking (CBT) identifies the data blocks that change between two snapshots of a persistent volume, so backup solutions can copy only what changed rather than the entire volume.

:FeatureName: Changed block tracking
include::snippets/technology-preview.adoc[]

CBT enables efficient, incremental backups and disaster recovery for persistent volumes (PVs) managed by Container Storage Interface (CSI) drivers that support this feature. Consumers can request a list of the blocks that changed between two snapshots, which is useful for backup solution vendors. By backing up only changed blocks instead of entire volumes, backup processes are faster and more efficient.

For more information about CBT, see the Red Hat Knowledgebase solution "How to use Changed Block Tracking (Tech Preview) in OpenShift 5.0"
