= CertificateRequestPolicy resource fields

[role="_abstract"]
You can configure policy matching and permitted certificate-request attributes by modifying `CertificateRequestPolicy` resources.

:FeatureName: Managing certificate request approval by using approver-policy
include::snippets/technology-preview.adoc[leveloffset=+1]

The following table lists the parameters for configuring the `CertificateRequestPolicy` resource.

[cols="3,1,5a",options="header"]
|===
|Field |Type |Description

|`spec.selector`
|`object`
|Optional. Selects the `CertificateRequest` resources that approver-policy evaluates. Configure issuer and namespace selectors as required.

|`spec.allowed`
|`object`
|Optional. Defines the certificate request attributes that the policy permits.
|===
