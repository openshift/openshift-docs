= Mirror the {product-title} image repository

[role="_abstract"]
Mirror the {product-title} image repository to your registry to use during cluster installation or upgrade. Complete the following steps on the mirror host.

.Prerequisites

* Your mirror host has access to the internet.
* [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# You configured a mirror registry to use in your restricted network and
can access the certificate and credentials that you configured.
* [.pr:openshift-rosa .pr:openshift-dedicated]#{empty}# You configured a mirror registry to use.
* [.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#{empty}# You downloaded the {cluster-manager-url-pull} and modified it to include authentication to your mirror repository.
* [.pr:openshift-origin]#{empty}# You have created a pull secret for your mirror repository.
* If you use self-signed certificates, you have specified a Subject Alternative Name in the certificates.

.Procedure

. Review the
[.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#link:https://access.redhat.com/downloads/content/290/[Download {product-title}] page to determine the version of {product-title} that you want to install and determine the corresponding tag on the link:https://quay.io/repository/openshift-release-dev/ocp-release?tab=tags[Repository Tags] page.#
[.pr:openshift-origin]#link:https://github.com/okd-project/okd/releases/[{product-title} releases page]
to determine the version and tag of {product-title} that you want to install.#

. Set the following required environment variables:

.. Export the release version:
+
[source,terminal]
----
$ OCP_RELEASE=<release_version>
----
+
For `<release_version>`, specify the tag that corresponds to the version of {product-title} to install, such as `4.21.1`.

.. Export the local registry name and host port:
+
[source,terminal]
----
$ LOCAL_REGISTRY='<local_registry_host_name>:<local_registry_host_port>'
----
+
For `<local_registry_host_name>`, specify the registry domain name for your mirror repository, and for `<local_registry_host_port>`, specify the port that it serves content on.

.. Export the local repository name:
+
[source,terminal]
----
$ LOCAL_REPOSITORY='<local_repository_name>'
----
+
For `<local_repository_name>`, specify the name of the repository to create in your registry, such as `ocp4/openshift4`.

.. Export the name of the repository to mirror:
+
[role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
[source,terminal]
----
$ PRODUCT_REPO='openshift-release-dev'
----
+
[.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#For a production release, you must specify `openshift-release-dev`.#
+
[role="pr:openshift-origin"]
[source,terminal]
----
$ PRODUCT_REPO='okd'
----

.. Export the path to your registry pull secret:
+
[source,terminal]
----
$ LOCAL_SECRET_JSON='<path_to_pull_secret>'
----
+
For `<path_to_pull_secret>`, specify the absolute path to and file name of the pull secret for your mirror registry that you created.

.. Export the release mirror:
+
[role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
[source,terminal]
----
$ RELEASE_NAME="ocp-release"
----
+
[.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#For a production release, you must specify `ocp-release`.#
+
[role="pr:openshift-origin"]
[source,terminal]
----
$ RELEASE_NAME="scos-release"
----

.. [.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#{empty}# Export the type of architecture for your cluster:
+
[role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
[source,terminal]
----
$ ARCHITECTURE=<cluster_architecture>
----
+
[.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#Specify the architecture of the cluster, such as `x86_64`, `aarch64`, `s390x`, or `ppc64le`.#

.. Export the path to the directory to host the mirrored images:
+
[source,terminal]
----
$ REMOVABLE_MEDIA_PATH=<path>
----
+
Specify the full path, including the initial forward slash (/) character.

. [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# Mirror the version images to the mirror registry:
** [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# If your mirror host does not have internet access, take the following actions:
... [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# Connect the removable media to a system that is connected to the internet.
... [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# Review the images and configuration manifests to mirror:
+
[role="pr:openshift-origin"]
[source,terminal]
----
$ oc adm release mirror -a ${LOCAL_SECRET_JSON}  \
     --from=quay.io/${PRODUCT_REPO}/${RELEASE_NAME}:${OCP_RELEASE} \
     --to=${LOCAL_REGISTRY}/${LOCAL_REPOSITORY} \
     --to-release-image=${LOCAL_REGISTRY}/${LOCAL_REPOSITORY}:${OCP_RELEASE} --dry-run
----
+
[role="pr:openshift-enterprise pr:openshift-rosa-hcp pr:microshift"]
[source,terminal]
----
$ oc adm release mirror -a ${LOCAL_SECRET_JSON}  \
     --from=quay.io/${PRODUCT_REPO}/${RELEASE_NAME}:${OCP_RELEASE}-${ARCHITECTURE} \
     --to=${LOCAL_REGISTRY}/${LOCAL_REPOSITORY} \
     --to-release-image=${LOCAL_REGISTRY}/${LOCAL_REPOSITORY}:${OCP_RELEASE}-${ARCHITECTURE} --dry-run
----

... [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# Record the entire `imageContentSources` section from the output of the previous
command. The information about your mirrors is unique to your mirrored repository, and you must add the `imageContentSources` section to the `install-config.yaml` file during installation.
... [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# Mirror the images to a directory on the removable media:
+
[role="pr:openshift-origin"]
[source,terminal]
----
$ oc adm release mirror -a ${LOCAL_SECRET_JSON} --to-dir=${REMOVABLE_MEDIA_PATH}/mirror quay.io/${PRODUCT_REPO}/${RELEASE_NAME}:${OCP_RELEASE}
----
+
[role="pr:openshift-enterprise pr:openshift-rosa-hcp pr:microshift"]
[source,terminal]
----
$ oc adm release mirror -a ${LOCAL_SECRET_JSON} --to-dir=${REMOVABLE_MEDIA_PATH}/mirror quay.io/${PRODUCT_REPO}/${RELEASE_NAME}:${OCP_RELEASE}-${ARCHITECTURE}
----

... [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# Take the media to the restricted network environment and upload the images to the local container registry.
+
[role="pr:openshift-enterprise pr:openshift-origin pr:openshift-rosa-hcp pr:microshift"]
[source,terminal]
----
$ oc image mirror -a ${LOCAL_SECRET_JSON} --from-dir=${REMOVABLE_MEDIA_PATH}/mirror "file://openshift/release:${OCP_RELEASE}*" ${LOCAL_REGISTRY}/${LOCAL_REPOSITORY}
----
+
[.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#For the `REMOVABLE_MEDIA_PATH` variable, you must use the same path that you specified when you mirrored the images.#
+
[role="pr:openshift-enterprise pr:openshift-origin pr:openshift-rosa-hcp pr:microshift"]
[IMPORTANT]
====
Running the `oc image mirror` command might result in the following error: `error: unable to retrieve source image`. This error occurs when image indexes include references to images that no longer exist on the image registry. Image indexes might retain older references to allow users running those images an upgrade path to newer points on the upgrade graph. As a temporary workaround, you can use the `--skip-missing` option to bypass the error and continue downloading the image index. For more information, see link:https://access.redhat.com/solutions/6975305[Service Mesh Operator mirroring failed].
====

[source,terminal]

     --from=quay.io/${PRODUCT_REPO}/${RELEASE_NAME}:${OCP_RELEASE}-${ARCHITECTURE} \
     --to=${LOCAL_REGISTRY}/${LOCAL_REPOSITORY} \
     --to-release-image=${LOCAL_REGISTRY}/${LOCAL_REPOSITORY}:${OCP_RELEASE}-${ARCHITECTURE}
----
+
[.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#This command pulls the release information as a digest, and its output includes the `imageContentSources` data that you require when you install your cluster.#

... [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# Record the entire `imageContentSources` section from the output of the previous
command. The information about your mirrors is unique to your mirrored repository, and you must add the `imageContentSources` section to the `install-config.yaml` file during installation.
+
[role="pr:openshift-enterprise pr:openshift-origin pr:openshift-rosa-hcp pr:microshift"]
[NOTE]
====
The image name gets patched to Quay.io during the mirroring process, and the Podman images will show Quay.io in the registry on the bootstrap virtual machine.
====

. [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# To create the installation program that is based on the content that you
mirrored, extract it and pin it to the release:
** [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# If your mirror host does not have internet access, run the following command:
+
[role="pr:openshift-enterprise pr:openshift-origin pr:openshift-rosa-hcp pr:microshift"]
[source,terminal]
----
$ oc adm release extract -a ${LOCAL_SECRET_JSON} --icsp-file=<file> --command=openshift-install "${LOCAL_REGISTRY}/${LOCAL_REPOSITORY}:${OCP_RELEASE}-${ARCHITECTURE}" \
--insecure=true
----
+
[.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#Optional: If you do not want to configure trust for the target registry, add the `--insecure=true` flag.#

** [.pr:openshift-enterprise .pr:openshift-origin .pr:openshift-rosa-hcp .pr:microshift]#{empty}# If the local container registry is connected to the mirror host, run the following command:
+
[role="pr:openshift-origin"]
[source,terminal]
----
$ oc adm release extract -a ${LOCAL_SECRET_JSON} --command=openshift-install "${LOCAL_REGISTRY}/${LOCAL_REPOSITORY}:${OCP_RELEASE}"
----
+
[role="pr:openshift-enterprise pr:openshift-rosa-hcp pr:microshift"]
[source,terminal]
----
$ oc adm release extract -a ${LOCAL_SECRET_JSON} --command=openshift-install "${LOCAL_REGISTRY}/${LOCAL_REPOSITORY}:${OCP_RELEASE}-${ARCHITECTURE}"
----
+
[role="pr:openshift-enterprise pr:openshift-origin pr:openshift-rosa-hcp pr:microshift"]
[IMPORTANT]
====
To ensure that you use the correct images for the version of {product-title} that you selected, you must extract the installation program from the mirrored content.

You must perform this step on a machine with an active internet connection.
====

[source,terminal]

$ openshift-install
