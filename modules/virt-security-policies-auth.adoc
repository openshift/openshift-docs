= Authorization

[role="_abstract"]
{VirtProductName} uses role-based access control (RBAC) to define permissions for users and service accounts.

By default, {VirtProductName} aggregates virtualization permissions into standard {product-title} cluster roles (`view`, `edit`, and `admin`). You can disable this role aggregation if you want to grant virtualization permissions manually to specific users or groups.
