= Delete a standalone VMI by using the web console

[role="_abstract"]
You can delete a standalone virtual machine instance (VMI) by using the {product-title} web console. The deletion is permanent and you cannot recover the VMI.

.Procedure

. In the {product-title} web console, click *Virtualization* -> *VirtualMachines* from the side menu.

. Click *Actions* -> *Delete VirtualMachineInstance*.

. In the confirmation pop-up window, click *Delete* to permanently delete the standalone VMI.
