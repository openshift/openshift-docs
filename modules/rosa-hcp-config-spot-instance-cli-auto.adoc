= Setting up the AWS infrastructure for Spot instances automatically

[role="_abstract"]
You can set up the required AWS infrastructure using the automated ROSA CLI helper. This helper command creates all the required AWS resources in a single step.

These resources include the following:
* The SQS queue
* The `red-hat=true` tag
* The EventBridge rules
* The SQS queue resource policy

.Procedure
* Run the following command to create the necessary AWS resources:
+
[source,terminal]
----
$ rosa create spot-termination-queue --cluster <cluster-name> --mode auto
----

[NOTE]
====
If you are creating a new cluster, you must run this command before running `rosa create cluster`. For an existing cluster, the helper command described in this procedure associates the queue with the cluster automatically.
====
