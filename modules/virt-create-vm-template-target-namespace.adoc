= Create a virtual machine template in a target namespace

[role="_abstract"]
You can create a template in a shared namespace from a VM that runs in a different namespace.

.Prerequisites

* The source VM is stopped.
* You have the `virtualmachinetemplaterequest/create` permission in the source VM namespace.
* You have permission to create `VirtualMachineTemplates` and `DataVolumes` in the target namespace.

.Procedure

. Create a `VirtualMachineTemplateRequest` manifest that specifies the target namespace:
+
[source,yaml]
----
apiVersion: template.kubevirt.io/v1beta1
kind: VirtualMachineTemplateRequest
metadata:
  name: promote-to-catalog
  namespace: shared-templates
spec:
  virtualMachineRef:
    name: my-configured-vm
    namespace: my-namespace
  templateName: my-golden-vm
----
+
where:
+
`metadata.namespace`:: Specifies the namespace where the template is created.
`virtualMachineRef.name`:: Specifies the name of the source VM.
`virtualMachineRef.namespace`:: Specifies the namespace of the source VM.
`templateName`:: Specifies the name for the template to be created.

. Apply the manifest:
+
[source,terminal]
----
$ oc apply -f promote-to-catalog.yaml
----

.Verification

* Verify that the template was created in the target namespace:
+
[source,terminal]
----
$ oc get vmt my-golden-vm -n shared-templates
----
