= Install {kueue-name}

[role="_abstract"]
You install {kueue-name} by using the {kueue-op} from OperatorHub, and then create a `Kueue` custom resource (CR) to activate it on the cluster. Before {kueue-name} can admit any jobs, you must label the namespaces whose workloads you want it to manage.
