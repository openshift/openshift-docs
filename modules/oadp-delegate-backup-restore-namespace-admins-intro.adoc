= Delegate backup and restore to namespace administrators

[role="_abstract"]
Configure {oadp-short} self-service so that namespace administrators can perform backup and restore operations without the `cluster-admin` role. With self-service enabled, users with namespace-level access can create and manage backups and restores within their authorized namespaces.
