= Mirror an image set in a fully disconnected environment

[role="_abstract"]
You can mirror image sets in a fully disconnected environment where the {product-title} cluster cannot access the public internet.

The following high-level workflow describes the mirroring process:

// In the step below, can "prepare" be replaced with "mirror" to be worded more similarly to the last step, and still be accurate?

. *Mirror to disk*: Mirror the image set to an archive.

. *Disk transfer*: Manually transfer the archive to the network of the disconnected mirror registry.

. *Disk to mirror*: Mirror the image set from the archive to the target disconnected registry.

[WARNING]
====
Using different oc-mirror versions for the mirror to disk and disk to mirror operations can lead to unexpected results. For example, mirror to disk and disk to mirror can produce different rebuilt catalog tags. As a result, the disk to mirror operation fails because it looks for a tag that does not exist in the archive.
====

After you transfer the archive to the disconnected environment, disk to mirror reads image content from that archive and local storage.
Disk to mirror does not require network access to the source registry.
The authentication file that you use for disk to mirror needs credentials only for the destination mirror registry.
Disk to mirror must not prompt for source-registry credentials or attempt to authenticate to the source registry when the archive was generated correctly with the same oc-mirror version used for disk to mirror.
