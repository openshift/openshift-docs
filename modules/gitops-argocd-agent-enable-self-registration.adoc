= Enable agent self-registration

Enable agent self-registration on the principal component to automate cluster secret creation for new agents.

.Prerequisites

* You have installed the principal component. For more information, see _Installing the Principal component_.
* You have cluster administrator access to the control plane cluster.
* You have installed the `argocd-agentctl` CLI tool.

.Procedure

. Create the shared client certificate that self-registered agents use to authenticate:
+
[source,terminal]
----
$ argocd-agentctl pki issue shared-client \
    --principal-context <control_plane_context> \
    --principal-namespace <argocd_namespace> \
    --upsert
----
+
Replace `<control_plane_context>` with your control plane cluster context and `<argocd_namespace>` with the namespace where you installed the principal component.
+
This command creates a secret named `argocd-agent-shared-client-cert` that contains `tls.crt`, `tls.key`, and `ca.crt`. The certificate is trusted by the resource proxy CA.

. Enable self-registration in the principal's `ArgoCD` custom resource (CR):
+
[source,yaml]
----
apiVersion: argoproj.io/v1beta1
kind: ArgoCD
metadata:
  name: openshift-gitops
  namespace: <argocd_namespace>
spec:
  argoCDAgent:
    principal:
      enabled: true
      selfRegistration:
        enabled: true
        clientCertSecretName: argocd-agent-shared-client-cert
        clusterSecretLabels:
          env: production
          team: platform
----
+
where:
+
`selfRegistration.enabled`:: Set to `true` to enable automatic cluster secret creation when an authenticated agent connects. This field is set to `false` by default.
+
`selfRegistration.clientCertSecretName`:: Specifies the name of the shared client certificate secret. This field is required when self-registration is enabled.
+
`selfRegistration.clusterSecretLabels`:: Optional. Defines custom labels that the principal applies to cluster secrets it creates for self-registered agents. You can use these labels to organize or select those secrets.

. Deploy your agent components without running the `argocd-agentctl agent create` command:
+
The principal automatically creates the cluster secret when the agent first connects with valid credentials.

.Verification

. List the self-registered cluster secrets:
+
[source,terminal]
----
$ oc get secrets -n <argocd_namespace> \
    -l argocd-agent.argoproj-labs.io/self-registered-cluster=true
----
+
You should see a `cluster-<agent_name>` secret for each self-registered agent.

. Check the principal logs to verify successful registration:
+
[source,terminal]
----
$ oc logs -n <argocd_namespace> deployment/openshift-gitops-argocd-agent-principal | grep "self-registered"
----
+
You should see log entries similar to:
+
[source,terminal]
----
INFO Creating self-registered cluster secret for agent  agent=my-agent
INFO Successfully created self-registered cluster secret with shared client cert and bearer token
----
