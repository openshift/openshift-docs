= Mapping users to specific roles

[role="_abstract"]
The default Argo CD policy grants `role:admin` to members of the `cluster-admins` group. Add the user to that group. Membership in the group is what the Argo CD policy matches. Do not grant the OpenShift `cluster-admin` role unless the user should be a cluster administrator.

.Procedure

. Create a group named `cluster-admins`.
+
[source,terminal]
----
$ oc adm groups new cluster-admins
----
. Add the user to the group.
+
[source,terminal]
----
$ oc adm groups add-users cluster-admins <user>
----
