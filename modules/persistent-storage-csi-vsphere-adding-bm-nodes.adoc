= Storage requirements for nodes without {vmw-short} integration

[role="_abstract"]
Before you add bare-metal compute nodes or virtual machines (VMs) without {vmw-short} integration to your {product-title} cluster, disable the native {vmw-short} Container Storage Interface (CSI) driver for the cluster.

Migrate workloads that depend on {vmw-short} volumes to an alternative storage solution before you disable the driver. This requirement applies to all nodes in the target cluster, including the existing {vmw-short} nodes.

To disable the driver, set `spec.managementState` to `Removed` in the `csi.vsphere.vmware.com` `ClusterCSIDriver` object. If you enable the driver in a cluster that has nodes without {vmw-short} integration, the Cluster Storage Operator reports `Degraded=True`.
