= Adding bare-metal nodes

[role="_abstract"]
Adding bare-metal nodes to an {product-title} cluster on vSphere is supported. However, if you add bare-metal nodes, you must remove the vSphere CSI Driver, otherwise the cluster is marked as degraded. For information about how to remove the driver and the consequences of doing this, see Section "Disabling and enabling storage on vSphere". 

[IMPORTANT]
====
Adding bare-metal nodes is generally available for {product-title} 4.22.13 and later. However, this feature is Technology Preview for 4.21 through 4.22.12.
====

For information about how to add bare-metal nodes, see "Adding bare-metal compute machines to a vSphere cluster".
