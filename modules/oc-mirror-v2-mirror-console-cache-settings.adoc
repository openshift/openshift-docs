= Cache settings

[role="_abstract"]
Use the *Cache* tab on the Settings page of the OpenShift Mirror Console to check the cache location and size. You can also free disk space on the local system.

Cache Location:: The path on the local system where the console stores cache data. To change the cache location, set the `CACHE_DIR` environment variable on the host and restart the console. The startup scripts mount that directory and set the `OC_MIRROR_CACHE_DIR` environment variable inside the container. Setting only `OC_MIRROR_CACHE_DIR` on the host does not mount the host directory.

Cache Size:: The amount of disk space currently used by the cache.

Clean Up Cache:: Removes cached data to free disk space on the local system.
