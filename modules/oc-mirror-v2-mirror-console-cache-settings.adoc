= Cache settings

[role="_abstract"]
Check the cache location and size and free disk space from the *Cache* tab in the OpenShift Mirror Console.

Cache Location:: The cache directory inside the container. The default location is `/app/data/cache`.

Cache Size:: The amount of disk space currently used by the cache.

Clean Up Cache:: Removes data from the configured cache directory to free disk space.

[WARNING]
====
Cleaning the cache permanently removes cached image data. Subsequent mirror operations might need to download previously cached content again, increasing network usage and processing time.

Cleaning the cache does not remove existing mirror output.
====
