= Cache settings

[role="_abstract"]
The *Cache* tab on the Settings page shows the local cache location and size used by the OpenShift Mirror Console for mirroring operations. Cleaning up the cache frees disk space on the local system.

Cache Location:: The path on the local system where cache data is stored. To change the cache location, set the `OC_MIRROR_CACHE_DIR` environment variable when starting the container and mount the host directory as a volume.

Cache Size:: The amount of disk space currently used by the cache.

Clean Up Cache:: Removes cached data to free disk space on the local system.
