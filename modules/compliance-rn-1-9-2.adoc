* link:https://access.redhat.com/errata/RHSA-2026:xxxxx[RHSA-2026:xxxxx - OpenShift Compliance Operator 1.9.2 bug fix and enhancement update]

[id="compliance-operator-1-9-2-bug-fixes_{context}"]
== Bug fixes

* Before this release, the `compliance_operator_compliance_state` metric could report `NON-COMPLIANT` even when related `ComplianceSuite` and `ComplianceScan` results were `COMPLIANT`, which could trigger false alerts. With this release, the Compliance Operator keeps the metric in synchronization with the relevant suite and removes it when you delete that suite. For more information, see (link:https://redhat.atlassian.net/browse/CMP-4373[CMP-4373]).

* CVE-2026-33811 is resolved in the Compliance Operator 1.9.2 release. (link:https://access.redhat.com/security/cve/cve-2026-33811[CVE-2026-33811])

* CVE-2026-27145 is resolved in the Compliance Operator 1.9.2 release. (link:https://access.redhat.com/security/cve/cve-2026-27145[CVE-2026-27145])

* CVE-2026-42504 is resolved in the Compliance Operator 1.9.2 release. (link:https://access.redhat.com/security/cve/cve-2026-42504[CVE-2026-42504])
