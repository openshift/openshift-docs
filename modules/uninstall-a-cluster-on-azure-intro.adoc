= Uninstall a cluster on Azure

[role="_abstract"]
When you no longer need an {product-title} cluster on Microsoft Azure, you can uninstall the cluster and remove related cloud resources. Complete uninstallation so you avoid ongoing costs and leave no orphaned infrastructure.
