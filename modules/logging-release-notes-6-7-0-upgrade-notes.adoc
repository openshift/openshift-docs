= Required actions before upgrading

[role="_abstract"]
Before upgrading to {LoggingProductName} 6.7, complete the following required actions to avoid degraded `LokiStack` resources.

* If your `LokiStack` resources reference a BoltDB-based storage schema (v11 or v12), migrate to the time series database (TSDB) schema (v13) before upgrading. The {loki-op} does not reconcile `LokiStack` instances that use BoltDB-based schemas after the upgrade, resulting in a degraded `LokiStack`.
+
For migration instructions, see xref:../upgrade/migrate-lokistack-schema-before-upgrade.adoc#migrate-lokistack-schema-before-upgrade[Migrate the LokiStack storage schema before upgrading].

* The `spec.storage.schemas` field is required in the v1 `LokiStack` API. Explicitly configure this field in all `LokiStack` resources before upgrading. `LokiStack` resources without this field fail to reconcile after the upgrade, resulting in a degraded `LokiStack`.
+
