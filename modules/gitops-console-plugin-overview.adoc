= Overview of the GitOps Console plugin

The {gitops-shortname} Console plugin extends the {OCP} web console by adding {gitops-shortname} resources. The plugin is available as part of the {gitops-title} Operator and provides a console UI for managing Argo CD and Argo Rollouts custom resources.

After you install the {gitops-title} Operator and enable the {gitops-shortname} Console plugin, the {product-title} web console displays a *GitOps* navigation tab in the *Administrator* perspective. The GitOps navigation tab replaces the previous *Environments* tab and related pages in the *Developer* perspective.

The GitOps navigation tab provides access to the following Argo CD and Argo Rollouts resources:

* *Applications*: Argo CD Applications for managing application deployments
* *ApplicationSets*: Argo CD ApplicationSets for managing multiple Applications
* *AppProjects*: Argo CD AppProjects for controlling application access and permissions
* *ImageUpdaters*: Argo CD Image Updater resources for automated image updates (requires ImageUpdater CRD)
* *Rollouts*: Argo Rollouts resources for progressive deployment strategies (requires Rollout CRD)

Each resource provides list and details pages that follow the standard {product-title} web console experience. You can use these pages to:

* View GitOps resources in a selected namespace
* Create resources by using YAML templates
* Edit labels and annotations
* Filter resources by status
* Access related resources and events

The GitOps Console plugin integrates with the console navigation, allowing you to navigate between related resources and access contextual actions for each resource type.

.Prerequisites

* You have access to {OCP}.
* You have installed the {gitops-title} Operator. For installation instructions, see "Installing {gitops-title}".
* You can log in to the web console with cluster-admin permission to enable the plugin.

.Verification

After you enable the plugin:

* *GitOps* appears in the navigation menu in the *Administrator* perspective
* You can access Applications, ApplicationSets, AppProjects, ImageUpdaters, and Rollouts pages
* ImageUpdaters and Rollouts appear only when those CRDs are installed on the cluster
* After a browser refresh, *GitOps* remains in the navigation
