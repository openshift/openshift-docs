[id="cluster-compare-ignore-all-fields_{context}"]
= Excluding all fields not specified in a template

[role="_abstract"]
During the comparison process, the `cluster-compare` plugin renders a template by merging fields from the corresponding custom resource (CR). To focus the comparison on the fields specified in the template only, set `ignore-unspecified-fields` to `true`.

If `ignore-unspecified-fields: true`, all fields present in the CR that are not in the template are excluded from the merge.

.Procedure

* Create a `metadata.yaml` file to match your use case. Use the following structure as an example:
+
[source,yaml]
----
apiVersion: v2
parts:
  - name: Part1
    components:
      - name: Namespace
        allOf:
          - path: namespace.yaml
            config:
              ignore-unspecified-fields: true
#...
----
+
where:

`ignore-unspecified-fields: true`:: Specify `true` to exclude from the comparison all fields in a CR that are not explicitly configured in the corresponding `namespace.yaml` template.
