= Validating Day-2 operations (optional)

[role="_abstract"]
Optionally validate that BYO rules and the `firewall-rules-management` flag survive worker scale-up and z-stream upgrades.

.Procedure
. Scale a machine pool to verify new nodes are covered by BYO rules:
+
[source,terminal]
----
$ ocm edit machinepool worker --cluster=${CLUSTER_NAME} --replicas=3
----
+
Service-account-targeted rules apply to any instance running with the matching WIF service account, so new nodes require no firewall changes.

. Watch for the new node to reach `Ready` state:
+
[source,terminal]
----
$ oc get nodes -w
----

. Scale back down when done:
+
[source,terminal]
----
$ ocm edit machinepool worker --cluster=${CLUSTER_NAME} --replicas=2
----

. To validate a z-stream upgrade, list available upgrade versions:
+
[source,terminal]
----
$ ocm describe cluster ${CLUSTER_NAME} --json | jq -r '.version.available_upgrades[]'
----

. Schedule an upgrade:
+
[source,terminal]
----
$ CLUSTER_ID=$(ocm describe cluster ${CLUSTER_NAME} --json | jq -r '.id')
$ TARGET_VERSION="<target_version>" <1>
$ NEXT_TS=$(date -u -v+10M '+%Y-%m-%dT%H:%M:%SZ') <2>
$ echo '{"version":"'${TARGET_VERSION}'","schedule_type":"manual","next_run":"'${NEXT_TS}'"}' \
  > /tmp/upgrade-policy.json
$ ocm post /api/clusters_mgmt/v1/clusters/${CLUSTER_ID}/upgrade_policies \
  --body=/tmp/upgrade-policy.json
$ rm /tmp/upgrade-policy.json
----
<1> Replace `<target_version>` with the version from the previous command.
<2> On Linux, use `date -u -d '+10 minutes' '+%Y-%m-%dT%H:%M:%SZ'` instead.

+
[IMPORTANT]
====
On {product-title}, upgrades should be initiated through {cluster-manager}, not `oc adm upgrade`. The `Upgradeable=False` gate from the cloud-credential annotation only blocks minor version upgrades. Z-stream upgrades proceed without issue.
====

. Monitor upgrade progress:
+
[source,terminal]
----
$ ocm list upgradepolicies --cluster=${CLUSTER_NAME}
----

.Verification
After the upgrade completes:

. Verify the cluster version:
+
[source,terminal]
----
$ oc get clusterversion
----

. Verify all nodes are in `Ready` state:
+
[source,terminal]
----
$ oc get nodes
----

. Verify all cluster operators are healthy:
+
[source,terminal]
----
$ oc get co
----

. Confirm BYO firewall rules are still present:
+
[source,terminal]
----
$ gcloud compute firewall-rules list \
  --project=${GCP_PROJECT} \
  --filter="network=${VPC_NETWORK} AND name~${BYO_PREFIX}" \
  --format="table(name)"
----

. Confirm platform-managed rules are still absent:
+
[source,terminal]
----
$ gcloud compute firewall-rules list \
  --project=${GCP_PROJECT} \
  --filter="network=${VPC_NETWORK} AND name~${INFRA_ID}" \
  --format="table(name)"
----

. Confirm the flag persisted through the upgrade:
+
[source,terminal]
----
$ oc get cm cloud-conf -n openshift-cloud-controller-manager \
  -o jsonpath='{.data.cloud\.conf}' | grep firewall
----
+
The output should be `firewall-rules-management = Disabled`.
