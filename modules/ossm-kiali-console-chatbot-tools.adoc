= Chatbot tools

[role="_abstract"]

The chatbot calls tools that run inside {KialiServer}. Use these names in `spec.ai.chat.tools.enabled_tools` and `spec.ai.chat.tools.disabled_tools`.

[cols="1,2",options="header"]
|===
|Tool
|What it returns

|`get_action_ui`
|Links that open a page in the console

|`get_referenced_docs`
|Links to {istio} and Kiali documentation

|`get_mesh_status`
|Mesh health, control plane, observability stack, and connectivity

|`get_mesh_traffic_graph`
|Service-to-service topology with throughput, response time, and mutual TLS

|`get_metrics`
|{istio} or Envoy metrics for a service, workload, or application

|`get_pod_performance`
|Pod CPU and memory compared with requests and limits

|`get_logs`
|Workload or pod logs, with optional filters

|`list_traces`
|A short list of traces for a service

|`get_trace_details`
|Spans for one trace

|`list_or_get_resources`
|Services, workloads, applications, and namespaces on {ocp-product-title}

|`manage_istio_config_read`
|{istio} objects, read only

|`manage_istio_config`
|Create, patch, or delete {istio} objects after you confirm the change
|===

The tool result is JSON. The console shows that JSON in the tool card. Write operations through `manage_istio_config` still require the signed-in user to have permission to change that object on {ocp-product-title}.
