= Understand network policies and administrative network policies

[role="_abstract"]
Network policy in {product-title} is defined through both namespace-scoped and cluster-scoped APIs. Understanding how `NetworkPolicy`, `AdminNetworkPolicy`, and `BaselineAdminNetworkPolicy` differ in scope, precedence, and available actions lets you decide which one enforces a given connectivity requirement.
