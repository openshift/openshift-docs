= Release notes for {pipelines-title} 1.24.3

[role="_abstract"]
{pipelines-title} General Availability 1.24.3 is available on {OCP} 4.14 and later supported versions.

[id="fixed-issues-1-24-3_{context}"]
== Fixed issues

.Operator

//SRVKP-14944
OLMv1 installation fails due to duplicate multicluster proxy custom resource definition::
Before this update, installing {pipelines-shortname} through an OLMv1 `ClusterExtension` failed when bundles contained a duplicate `tektonmulticlusterproxyaaes.operator.tekton.dev` custom resource definition (CRD). As a consequence, installation could not complete. With this update, {pipelines-shortname} removes duplicate multicluster proxy CRD definitions from affected Operator and bundle manifests. As a result, OLMv1 installation succeeds in {pipelines-shortname} 1.24.3.
+
link:https://redhat.atlassian.net/browse/SRVKP-14944[SRVKP-14944]

.Security

//SRVKP-15070
Default OpenSSL cryptographic policy in container images not set to DEFAULT:PQ::
Before this update, container images in {pipelines-shortname} (including Operator, `must-gather`, and related operand and artifact images) did not enable the `DEFAULT:PQ` OpenSSL cryptographic policy required for post-quantum cryptography (PQC) support. As a consequence, affected container images lacked `DEFAULT:PQ` policy support. With this update, affected {pipelines-shortname} container images use PQC-enabled base images or configurations with the `DEFAULT:PQ` policy. As a result, PQC-capable OpenSSL policy is available in {pipelines-shortname} 1.24.3 container images, while FIPS mode continues to enforce FIPS 140 and disable PQC algorithms.
+
link:https://redhat.atlassian.net/browse/SRVKP-15070[SRVKP-15070]
