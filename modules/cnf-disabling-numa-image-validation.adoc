= Disabling image validation

[role="_abstract"]
You can disable scheduler or Resource Topology Exporter (RTE) image validation by setting the appropriate environment variables to `false` in the NUMA Resources Operator subscription.

[WARNING]
====
Disabling image validation removes important security controls. With validation disabled, users with write access to the respective custom resources can specify arbitrary container images that will run with elevated privileges.

Only disable validation in exceptional circumstances. If you disable validation, ensure that only cluster administrators can modify the respective resources, and implement additional security controls to verify image integrity.
====

[id="cnf-disabling-scheduler-image-validation_{context}"]
== Disabling scheduler image validation

You can disable scheduler image validation by setting the `SCHEDULER_IMAGE_VALIDATION` environment variable to `false`.

[WARNING]
====
Disabling scheduler image validation creates a significant privilege escalation risk. A malicious scheduler image can:

* Access and manipulate all pods and nodes in the cluster
* Bind workloads to nodes in ways that compromise security or stability
* Observe sensitive cluster resource topology information
* Execute arbitrary code with scheduler service account permissions
====

.Prerequisites

* You have installed the OpenShift CLI (`oc`).
* You have logged in as a user with `cluster-admin` privileges.
* You have installed the NUMA Resources Operator.

.Procedure

. Disable validation by patching the NUMA Resources Operator subscription by running the following command:
+
[source,terminal]
----
$ oc patch subscription numaresources-operator \
  -n openshift-numaresources \
  --type=merge \
  -p '{"spec":{"config":{"env":[{"name":"SCHEDULER_IMAGE_VALIDATION","value":"false"}]}}}'
----

. Wait for the NUMA Resources Operator pod to restart by monitoring the pod status with the following command:
+
[source,terminal]
----
$ oc get pods -n openshift-numaresources -w
----

. Verify that validation is disabled by checking the NUMA Resources Operator pod environment by running the following command:
+
[source,terminal]
----
$ oc exec -n openshift-numaresources deploy/numaresources-controller-manager -- \
  printenv SCHEDULER_IMAGE_VALIDATION
----
+
An example of the expected output is provided below:
+
[source,terminal]
----
false
----

[id="cnf-disabling-rte-image-validation_{context}"]
== Disabling RTE image validation

You can disable RTE image validation by setting the `RTE_IMAGE_VALIDATION` environment variable to `false`.

[WARNING]
====
Disabling RTE image validation creates a security risk. A malicious RTE image can:

* Access sensitive hardware topology information on worker nodes
* Observe node resource allocation and NUMA zone configurations
* Read detailed system information that could facilitate other attacks
* Execute code with the RTE daemon set service account permissions
====

.Prerequisites
