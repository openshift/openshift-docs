= Understand the OVN-Kubernetes network plugin

[role="_abstract"]
The {product-title} cluster uses a virtualized network for its pod and service networks. The OVN-Kubernetes network plugin is the default provider that implements this virtualized overlay network, supplying connectivity and policy enforcement across the nodes in the cluster.
