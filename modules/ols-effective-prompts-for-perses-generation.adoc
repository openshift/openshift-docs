= Effective user prompts for Perses generation

[role="_abstract"]
When formulating monitoring queries, you need verified natural language patterns so that you can maximize chart generation accuracy and avoid query processing errors.

The following table provides examples of effective user prompts that you can enter into the {ols-long} interface to generate real-time Prometheus data visualizations.

.Sample visualization queries
[cols="1,2,2",options="header"]
|===
|Optimization goal |Natural language prompt example |Expected visualization output

|Pod CPU tracking
|`Which pods are using the most CPU? Show me the top 5. Use Prometheus and visualize.`
|Top 5 CPU consumer pods formatted as a real-time tracking metric panel.

|Crashloop diagnostics
|`Which pods were crashlooping in the last 5 minutes? Use Prometheus and visualize.`
|Time-series visualization filtering active pod crash loops over a 5-minute window.

|Memory allocation
|`Which pods are using the most memory? Show me the top 5. Use Prometheus and visualize.`
|Bar or line graph representing the top 5 high-memory pod allocations.

|Namespace capacity
|`Which namespaces have the most running pods? Show me the top 5. Use Prometheus and visualize.`
|High-level density chart ranking the top 5 namespaces by running pod volume.

|Network observability
|`Which pods are receiving the most network traffic? Use Prometheus and visualize.`
|Throughput metric chart highlighting heavy ingress network traffic by pod.

|Pending state audits
|`Which pods are stuck in pending state? Use Prometheus and visualize.`
|Status-bound indicator widget highlighting unresolved pending pod contexts.
|===
