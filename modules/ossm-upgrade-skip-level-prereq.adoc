= Prerequisites for a skip-version upgrade

[role="_abstract"]
Before upgrading {SMProductShortName} by skipping a version, verify that your environment meets the required conditions and that you have the necessary access credentials and tools installed.

[#access-and-permissions_{context}]
== Access and permissions

* You have cluster-admin credentials for {ocp-product-title}.

* You have the `istioctl` command-line tool on your local machine.

[#configuration-requirements_{context}]
== Configuration requirements

* Your mesh uses sidecar mode.

* The `Istio` resource specifies the `RevisionBased` update strategy:
+
[source,yaml]
----
spec:
  updateStrategy:
    type: RevisionBased
----

* The `IstioCNI` resource version matches the current `Istio` resource version.

* An `IstioRevisionTag` resource named `default` references the `Istio` resource, rather than individual `IstioRevision` objects. You define this resource manually:
+
[source,yaml]
----
apiVersion: sailoperator.io/v1
kind: IstioRevisionTag
metadata:
  name: default
spec:
  targetRef:
    kind: Istio
    name: default
----

* All workload namespaces that participate in the mesh have the appropriate injection labels:
** For automatic injection: `istio-injection=enabled`.
** For revision-based injection: `istio.io/rev=default`.
