= About Operator groups

[role="_abstract"]
An `OperatorGroup` resource selects the namespaces that member Operators target. OLM uses this selection to generate RBAC permissions for access to resources within those namespaces. Operators can also request permissions for access across the cluster.

OLM records the target namespaces as a comma-separated list in the `olm.targetNamespaces` annotation on each member cluster service version (CSV). OLM also projects this annotation into the deployments for member Operators.
