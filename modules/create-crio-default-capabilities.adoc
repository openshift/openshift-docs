= CRI-O default capabilities on upgraded clusters

[role="_abstract"]
To improve the security of the platform, the `NET_RAW` and `SYS_CHROOT` capabilities were removed from the CRI-O default capability set in {product-title} 4.6. To avoid breaking existing workloads, the Machine Config Operator (MCO) preserves the previous default capability set on clusters that are upgraded from an earlier version.

When a cluster is upgraded from a version earlier than 4.6, the MCO creates a machine config that adds a CRI-O drop-in file, `/etc/crio/crio.conf.d/01-mc-defaultCapabilities`, to each node. This file restores the complete default capability list, including `NET_RAW` and `SYS_CHROOT`. Clusters that are installed at version 4.6 or later do not include this machine config and use the reduced default capability set.

The MCO records that it created this machine config in the `crio-capabilities` config map in the `openshift-machine-config-operator` namespace. If you delete the machine config, the MCO does not recreate it.

[NOTE]
====
If your workloads do not require the `NET_RAW` or `SYS_CHROOT` capabilities, you can delete the capabilities machine config so that your nodes use the reduced default capability set. Before deleting the machine config, verify which capabilities your workloads require.
====

To change other CRI-O settings, such as the log level or the container PID limit, use a `ContainerRuntimeConfig` custom resource (CR). For more information, see xref:create-a-containerruntimeconfig_{context}[Creating a ContainerRuntimeConfig CR to edit CRI-O parameters].

== Verifying the capabilities on a node

You can check the effective capability set of a node to determine whether your workloads rely on the preserved capabilities.

.Procedure
. Get the capability sets of the node:
+
[source,terminal]
----
$ cat /proc/1/status | grep Cap
----

. Decode the bounding set to list the capabilities by name, replacing `<CapBnd_value>` with the value of `CapBnd` from the previous output:
+
[source,terminal]
----
$ capsh --decode=<CapBnd_value>
----
