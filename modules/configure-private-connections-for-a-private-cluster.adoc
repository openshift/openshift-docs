= Configure private connections for a private cluster

[role="_abstract"]
Configure private connections to your {product-title} cluster by using AWS Virtual Private Cloud (VPC) peering, an AWS Virtual Private Network (VPN), or AWS Direct Connect, so that your cluster communicates securely with your on-premise infrastructure.
