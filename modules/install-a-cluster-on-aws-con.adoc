= Install a cluster on AWS

[role="_abstract"]
Install a {product-title} cluster on {aws-first} by using installer-provisioned infrastructure. This supplement follows the common installation journey and adds the steps that are specific to {aws-short}: subscribing to a Marketplace offer, choosing tested {aws-short} machine types, managing Route 53 as your DNS solution, and configuring short-term credentials with the Cloud Credential Operator utility.

Before you begin, set up your installation host by following the common installation journey.
