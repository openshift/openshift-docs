= Configuring encryption for nodes in an {ibm-z-title} or {ibm-linuxone-title} environment

[role="_abstract"]
When installing {product-title} on {ibm-z-name} or {ibm-linuxone-name} with {op-system-base} KVM, you can optionally encrypt the boot volumes of your control plane and compute nodes by using one of the following methods.

* {ibm-name} Secure Execution
* Linux Unified Key Setup (LUKS) encryption via {ibm-name} Crypto Express (CEX)
* Network Bound Disk Encryption (NBDE)
