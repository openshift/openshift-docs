= Perses dashboard deployment considerations

[role="_abstract"]
To ensure that your deployment configuration reliably supports AI-powered Red Hat build of Perses chart generation, review the supported environments and configuration requirements for {ols-long} and the Cluster Observability Operator (COO).

[NOTE]
====
Support for the following deployment scenarios and architectures is contingent upon your cluster meeting the minimum version requirements for the underlying operators: {ocp-product-title} version 4.22 or later, and Cluster Observability Operator (COO) version 1.5 or later.
====
