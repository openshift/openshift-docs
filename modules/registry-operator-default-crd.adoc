= Enable the Image Registry default route by using a CRD

[role="_abstract"]
In {product-title}, the `Registry` Operator controls the {product-registry} feature by using the `configs.imageregistry.operator.openshift.io` CRD. Patch this CRD to automatically enable the Image Registry default route.

.Procedure

* Patch the Image Registry Operator CRD:
+
[source,terminal]
----
$ oc patch configs.imageregistry.operator.openshift.io/cluster --type merge -p '{"spec":{"defaultRoute":true}}'
----
