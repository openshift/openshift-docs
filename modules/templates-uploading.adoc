= Uploading a template

[role="_abstract"]
To add a template to your {product-title} project, upload a JSON or YAML template file with the CLI. Uploaded templates are saved to the project template library for reuse by users with access to that project.

.Procedure

* Upload a template using one of the following methods:

** Upload a template to the template library of your current project, pass the JSON or YAML file with the following command:
+
[source,terminal]
----
$ oc create -f <filename>
----

** Upload a template to a different project using the `-n` option with the name of the project:
+
[source,terminal]
----
$ oc create -f <filename> -n <project>
----
+
The template is now available for selection using the web console or the CLI.
