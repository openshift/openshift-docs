= Deleting a Helm release

[role="_abstract"]
You can delete a Helm release that you no longer need.

.Procedure

. Navigate to *Ecosystem* -> *Helm*.
. Click the overflow menu in the release's row and select *Delete Helm Release*.
. In the confirmation prompt, enter the name of the release and click *Delete*.
