= Bug fixes

[role="_abstract"]
The following issues were resolved in this release of {LoggingProductName}.

* Previously, the `log_logged_bytes_total` metric in the `LogFileMetricExporter` reported container log byte counts that were too high by approximately a factor of six. This occurred because the exporter counted bytes from multiple hard links pointing to the same log file as separate entries. With this release, the metric correctly accounts for hard links, providing accurate byte counts for container log files. (link:https://issues.redhat.com/browse/LOG-10396[LOG-10396])
