= Provision clusters with the O-Cloud Manager

[role="_abstract"]
After you define cluster templates and onboard bare-metal servers, you can provision clusters by submitting a `ProvisioningRequest` custom resource (CR) with site-specific parameters. The O-Cloud Manager allocates hardware, installs the cluster, and applies Day 2 configuration automatically. You can perform these operations by editing the `ProvisioningRequest` CR directly or through the Provisioning REST API.
