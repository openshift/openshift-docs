= About VM template categories

[role="_abstract"]
You can assign a category to a virtual machine (VM) template to classify it by application type, such as "Database" or "Web Server". Categories help you organize a growing template catalog and make it easier for VM consumers to find the right template.

Categories differ from the legacy workload profile. Workload profiles describe the expected resource behavior of a VM, such as "desktop" or "server". Categories describe the application purpose of the template. VirtualMachineTemplates display the assigned category in the *Category* column on the *Templates* list page, while OpenShift templates continue to display the workload profile.

Categories have the following characteristics:

* A template can have only one category.
* Category is optional. Templates without a category display a blank *Category* field.
* You can select a predefined category or create a custom category.
* Categories are stored as the `vm.kubevirt.io/category` label on the `VirtualMachineTemplate` object.
* Custom category names are normalized to Kubernetes label-safe values. For example, spaces are converted to hyphens.
