= Limitations for virtual machine scanning

[role="_abstract"]
Scanning virtual machines (VMs) with {product-title} has some limitations.

Scanning VMs has the following limitations:

* Currently, {product-title-short} can only scan VMs that are running {op-system-base}.
* You must activate {op-system-base} with a valid subscription.
* You can only scan {op-system-base} packages indexed by DNF with valid repository links.
* Scanning requires sudo privileges for `roxagent` to scan package databases and communicate over vsock.
* {product-title-short} detects only packages managed by Red Hat Package Manager (RPM) and DNF.
* You must have internet connectivity for repository-to-CPE mapping downloads unless you configure a local mapping file.
