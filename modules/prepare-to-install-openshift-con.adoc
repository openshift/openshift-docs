= Prepare to install OpenShift

[role="_abstract"]
Before you install a {product-title} cluster on any platform, set up an installation host: install the OpenShift CLI (`oc`), generate an SSH key for cluster node access, and obtain the installation program for your platform.

Installing the CLI is the same on every platform. Obtaining the installation program and preparing your account, quotas, and network differ by platform.
