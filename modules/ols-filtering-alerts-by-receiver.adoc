= Filter alerts by receiver

[role="_abstract"]
After you configure the receiver names, set the receivers whose alerts you want the agent to investigate under `allowedReceivers`. The agent investigates only alerts that are routed to a listed receiver.

.Procedure

* To investigate only critical alerts, allow the `Critical` receiver:
+
[source,yaml]
----
filtering:
  allowedReceivers:
    - Critical
----

* To investigate any alert, allow the `Default` receiver. Because the `Default` receiver is the catch-all for alerts that no other route matches, allowing it causes the agent to act on any firing alert:
+
[source,yaml]
----
filtering:
  allowedReceivers:
    - Default
----
