= Understand virtual routing and forwarding

[role="_abstract"]
Virtual routing and forwarding (VRF) provides multi-tenancy functionality by giving each tenant its own unique routing tables and default gateways. VRF devices combined with IP address rules enable virtual routing domains at OSI model layer 3 without affecting layer 2 tools such as LLDP.
