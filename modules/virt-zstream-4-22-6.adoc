== Known issues

Windows guest VMs crash with BSOD on AMD EPYC hosts::
After migration from VMware to {VirtProductName} on AMD EPYC hosts, Windows guest VMs might crash intermittently with a Blue Screen of Death (BSOD). The stop code varies between crashes and between VMs; common stop codes include `SYSTEM_SERVICE_EXCEPTION` (`0x3B`), `IRQL_NOT_LESS_OR_EQUAL` (`0xA`), `BAD_POOL_HEADER` (`0x19`), and `PFN_LIST_CORRUPT` (`0x4E`). This is caused by a known KVM/QEMU issue where the `hv-tlbflush` Hyper-V enlightenment causes guest memory corruption on AMD hosts. This is not a {VirtProductName} defect.
+
For more information about this issue and a workaround, see link:https://access.redhat.com/solutions/7147022[Windows guest VMs randomly BSOD on AMD EPYC {VirtProductName} hosts].
