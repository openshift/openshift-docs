= About approver-policy

[role="_abstract"]
You can use approver-policy to control which certificate requests can be approved before an issuer signs a certificate. The {cert-manager-operator} manages the lifecycle of the approver-policy operand.

:FeatureName: Managing certificate request approval by using approver-policy
include::snippets/technology-preview.adoc[leveloffset=+1]

The {cert-manager-operator} manages the lifecycle of the approver-policy operand. Use approver-policy to control which certificate requests can be approved before an issuer signs a certificate.

An administrator creates an `ApproverPolicyManager` custom resource (CR) to deploy and configure the approver-policy operand. The Operator reconciles the operand and its related resources. When you update the `ApproverPolicyManager` CR, the Operator reconciles the managed resources to match the updated configuration. When you delete the CR, the Operator removes the resources that it manages.

After the operand is running, create `CertificateRequestPolicy` resources to define the certificate requests that approver-policy can approve. A policy can match requests by issuer reference and namespace, and can restrict the request attributes that are permitted.

The following resources have separate roles:

`ApproverPolicyManager`:: Configures the operator-managed approver-policy operand.

`CertificateRequestPolicy`:: Defines the conditions under which approver-policy can approve a `CertificateRequest`.

`CertificateRequest`:: Requests that an issuer sign a certificate. Approver-policy evaluates a request against the configured policies.
