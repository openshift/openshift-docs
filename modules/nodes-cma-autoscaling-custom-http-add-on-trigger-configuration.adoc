= About configuring an HTTP Add-on scaled object trigger

[role="_abstract"]
The HTTP trigger in a `ScaledObject` custom resource specifies how the Custom Metrics Autoscaler uses HTTP traffic metrics to scale your application. Understanding trigger parameters helps you configure appropriate activation and scaling thresholds for your workload.

The activation threshold determines when the application transitions from zero replicas to one replica.

* If the metric exceeds `activationThreshold`, the scaler creates one pod immediately (if none exist).

* If the metric falls below `activationThreshold` for the duration of `cooldownPeriod`, the scaler scales the deployment to zero replicas.

* The activation threshold takes precedence over the scaling threshold during zero-replica state.

The scaling threshold controls how the HPA scales once the application is active (at least one replica).

* If the metric exceeds `threshold`, the HPA scales up to additional replicas.

* If the metric falls below `threshold`, the HPA scales down (but not below one replica; the activation threshold must be exceeded for zero-replica scaling).

* The HPA respects its own cooldown periods and does not scale up or down on every metric spike.

The HTTP trigger is specified in the `ScaledObject` custom resource's `triggers` array. The trigger references an `InterceptorRoute` that provides the actual scaling metrics.

The following example demonstrates a complete HTTP trigger configuration with separate activation and scaling metrics. In this example:

* The application scales from zero to one replica when traffic exceeds 10 requests per second.

* Once active, the application scales to additional replicas as traffic grows beyond 100 requests per second.

* The application remains active as long as traffic does not fall below 10 requests per second for 5 minutes (300 seconds).

[source,yaml]
----
apiVersion: keda.sh/v1alpha1
kind: ScaledObject
metadata:
  name: web-app-scaler
  namespace: my-apps
spec:
  scaleTargetRef:
    name: web-app-deployment
  minReplicaCount: 0
  maxReplicaCount: 10
  triggers:
  - type: http
    metadata:
      namespace: my-apps
      name: web-app-routes
      scalingMetric: "rps"
      activationThreshold: "10"
      threshold: "100"
      cooldownPeriod: "300"
----
where:

`spec.trigger.metadata.namespace`:: Specifies the namespace containing the `InterceptorRoute` custom resource being referenced.
`spec.trigger.metadata.name`:: Specifies the name of the `InterceptorRoute` custom resource to use for scaling metrics.
`spec.trigger.metadata.scalingMetric`:: Specifies the metric to use for scaling decisions. Use either requests per second (rps) or concurrent request count (concurrency):
+
--
* `rps`. The `rps` metric measures the rate of incoming HTTP requests averaged over a measurement window. Use this option with applications where incoming request rate directly matches needed capacity.
* `concurrency`. The `concurrency` metric measures the number of in-flight HTTP requests being processed simultaneously. Use this option with applications where request duration is long or variable (e.g., file uploads, complex processing, streaming responses).
--
`spec.trigger.metadata.activationThreshold`:: Specifies the traffic threshold that triggers activation from zero replicas. When the metric value exceeds this threshold, the application scales from zero to one replica. Specified as a numeric value. For example, specify `5` for five requests/second or five concurrent connections.
`spec.trigger.metadata.threshold`:: Specifies the traffic threshold for the scaling phase. After the application is active, at least one replica, the HPA uses this threshold to determine whether to scale up or down. Specified as a numeric value.
`spec.trigger.metadata.cooldownPeriod`:: Specifies the number of seconds to wait before scaling to zero replicas when traffic is below the activation threshold. This prevents rapid scaling oscillations during brief traffic dips. Specified as a numeric value representing seconds. The default is 300 seconds (5 minutes).
