= Release notes for OpenShift Security Profiles Operator 0.10.1

[role="_abstract"]
OpenShift Security Profiles Operator 0.10.1 is now available. The `stable` update channel tracks and receives updates for the Security Profiles Operator. The following Red Hat Bug Fix Advisory (RHBA) is available:

* link:https://access.redhat.com/errata/RHSA-2026:76752[RHSA-2026:76752 - OpenShift Security Profiles Operator 0.10.1 bug fix and enhancement update]

[id="spo-0-10-1-new-features-and-enhancements_{context}"]
== New features and enhancements

* With this release, the Security Profiles Operator uses the `ubi9/ubi-minimal-pqc` as a base image. This change enables Post-Quantum Cryptography (PQC) support through OpenSSL and helps TLS endpoints offer ML-KEM during key exchange. (link:https://issues.redhat.com/browse/CMP-4572[CMP-4572])

* This update includes upgraded dependencies in the underlying base images.
