= {SMProductName} version 3.5 removed features

[role="_abstract"]

Removed functionality no longer exists in the product.

Service Mesh `must-gather` image removed::
This release removes the `must-gather` image specifically for debugging OpenShift Service Mesh. Instead, use the Service Mesh debugging capabilities in the default OpenShift Container Platform `must-gather` image. 
+
For more information, see the OpenShift Container Platform documentation: link:https://docs.redhat.com/en/documentation/openshift_container_platform/latest/html/support/gathering-cluster-data#about-must-gather_gathering-cluster-data[About the must-gather tool]
