= {SMProductName} version 3.5 removed features

[role="_abstract"]

The `must-gather` container specifically for debugging OpenShift Service Mesh is removed and is no longer supported. Instead, use the Service Mesh debugging capabilities in the generic OpenShift `must-gather` container. 
+
For more information, see the OpenShift Container Platform documentation: link:https://docs.redhat.com/en/documentation/openshift_container_platform/latest/html/support/gathering-cluster-data#about-must-gather_gathering-cluster-data[About the must-gather tool]
