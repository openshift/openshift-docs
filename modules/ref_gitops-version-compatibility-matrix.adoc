= Version compatibility matrix

[role="_abstract"]
Verify that your {OCP} version is compatible with the {gitops-title} version you plan to install. Different {gitops-title} versions support different {OCP} releases.

For the complete compatibility and support matrix, including component versions for Argo CD, Helm, Kustomize, and other bundled tools, see the Release notes.

*Minimum supported versions*

{gitops-title} 1.21 requires:

* {OCP} 4.14 or later
* OpenShift CLI (`oc`) version matching your cluster version
* Git 2.20 or later for repository access

*Supported Kubernetes versions*

{gitops-title} supports Kubernetes versions that correspond to supported {OCP} releases. The Argo CD components included in {gitops-title} are tested against the Kubernetes versions bundled with {OCP}.

*Component compatibility*

{gitops-title} includes specific versions of the following components:

* Argo CD
* Argo Rollouts
* Argo CD Image Updater
* Argo CD Agent
* Dex (for SSO authentication)

For the exact versions included in {gitops-title} 1.21, see the compatibility matrix in the Release notes.

*Platform lifecycle*

For information about {gitops-title} product lifecycle, supported platforms, and end-of-support dates, see the link:https://access.redhat.com/support/policy/updates/openshift-gitops[{gitops-title} Life Cycle Policy].
