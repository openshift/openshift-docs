= Troubleshoot OVN-Kubernetes networking issues

[role="_abstract"]
To troubleshoot OVN-Kubernetes in {product-title}, you can use built-in health checks and alerts, diagnose node networking and Open vSwitch configuration, trace Open vSwitch and OVN traffic flows with `ovnkube-trace`, or use the MCP server `ovn-kubernetes` and `cni-diagnostics` toolsets to collect evidence across Kubernetes, OVN, Open vSwitch, and kernel networking layers.
