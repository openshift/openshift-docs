= AI-assisted panel identification

[role="_abstract"]
To maintain transparency, any panel or dashboard created with {ols-long} displays a distinct AI-assisted badge, which is a robot icon. This badge helps operators distinguish human-authored content from AI-generated visualizations. Always verify the formatting and data accuracy of AI-generated panels before using them for long-term monitoring.
