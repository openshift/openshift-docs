== Fixed issues

* Before this update, when you added a routing rule on a virtual local area network (VLAN) interface that was stacked on a bond, for example, `bond0.12`, the rule did not work as expected. As a consequence, network traffic that relied on that rule was not routed correctly. With this release, rule handling for VLAN-over-bond interfaces is corrected. As a result, routing rules on VLAN interfaces on top of bonds work as expected. (link:https://redhat.atlassian.net/browse/OCPBUGS-97801[OCPBUGS-97801])

* Before this update, the {vmw-first} Problem Detector (VPD) incorrectly treated a custom resource pool as requiring additional privileges instead of read-only access. As a consequence, some newly deployed clusters reported privilege-related VPD issues that did not affect older clusters. With this release, VPD correctly treats custom resource pools as read-only. As a result, those incorrect privilege warnings do not occur. (link:https://redhat.atlassian.net/browse/OCPBUGS-123520[OCPBUGS-123520])
