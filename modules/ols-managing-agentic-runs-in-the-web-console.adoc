= Manage agentic runs in the web console

[role="_abstract"]
When an alert triggers an autonomous investigation, review, approve, or deny proposed remediations in the {ocp-product-title} web console so that you can resolve cluster incidents safely.

As a cluster administrator, you can monitor and manage agentic runs in the {ocp-product-title} web console to review automated diagnoses and approve or deny proposed remediation plans.

From the *Agentic Runs* -> *Configuration* page, you can also set the approval policy that governs whether each workflow stage requires manual approval or runs automatically.

.Approval policy configuration in the web console
image::ols-agentic-approval-policy-configuration.png[Configuration page in the web console showing the Approval policy tab with Manual and Automatic toggles for the Analysis, Execution, Verification, and Escalation stages, and a Max retry attempts field]

.Prerequisites

* You are logged in to the {ocp-product-title} web console as a cluster administrator.

* The {ols-long} Agentic Operator is installed and configured.

* The `alerts-adapter-config` ConfigMap is configured to authorize the processing of firing alerts.

.Procedure

. In the web console, navigate to *Agentic Runs*.

. Review the list of runs. Each run displays one of the following lifecycle statuses:
+
--
* *Analyzing*: The agent is actively investigating the alert and gathering diagnostics to form a root cause analysis.
* *Proposed*: The agent completed its analysis and presents a diagnosis, risk assessment, and remediation plan for your review.
* *Completed*: The proposed remediation was approved and executed successfully.
* *Failed*: The agent attempted to execute the remediation, but execution failed or was interrupted before completion.
* *Denied*: A cluster administrator explicitly denied the proposed remediation plan.
* *Escalated*: The run was escalated because the remediation failed, verification was unsuccessful, or manual intervention is required.
--

. Click a run with a *Proposed* status to view the root cause analysis, risk assessment, and proposed changes.

. Complete one of the following actions:
+
--
* To inspect diagnostic artifacts, click *Review Details*.
* To deny the remediation without applying changes, click *Deny Run*.
* To approve execution, click *Approve*, and then confirm the decision in the *Execute Remediation* prompt.
--

. Optional: To stop an investigation without modifying cluster resources, click the *Stop* icon while the run is in the *Analyzing* state.
