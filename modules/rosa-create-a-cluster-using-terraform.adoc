= Create a cluster using Terraform

[role="_abstract"]
Create a {product-title} cluster with a Terraform cluster template that is configured with the default cluster options.

After you prepare your AWS account, you can create a {product-title} cluster by using Terraform. Terraform lets you define your cluster as code so that you can version, review, and reproduce the deployment.

Red{nbsp}Hat provides a Terraform cluster template that is configured with the default cluster options. Prepare your environment, create your Terraform files, and apply them to create the cluster.
