= OpenShift 5 cluster availability matrix

[role="_abstract"]
The following matrix details the availability of OpenShift versions based on cluster architecture (Classic compared to Hosted Control Planes).

.OpenShift version availability by architecture
[cols="30%,35%,35%",options="header"]
|===
| Operation | Classic Clusters | Hosted Control Planes (HCP) Clusters

| *OpenShift 5.x Installs*
| Not Supported
| Supported

| *Upgrades to OpenShift 5.x*
| Not Supported
| Supported (from 4.x HCP)

| *OpenShift 4.x Installs*
| Supported
| Supported
|===
