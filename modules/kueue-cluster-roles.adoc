[id="kueue-cluster-roles_{context}"]
= {kueue-name} cluster roles

[role="_abstract"]
The {kueue-name} Operator deploys the `kueue-batch-admin-role` and `kueue-batch-user-role` cluster roles by default. Bind these cluster roles to your own users and groups to grant {kueue-name} permissions.

kueue-batch-admin-role:: This cluster role includes the permissions to manage cluster queues, local queues, workloads, and resource flavors.
kueue-batch-user-role:: This cluster role includes the permissions to manage jobs and to view local queues and workloads.
