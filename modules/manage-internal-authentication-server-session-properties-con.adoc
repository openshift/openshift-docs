= Manage internal authentication server session properties

[role="_abstract"]
The {product-title} control plane includes a built-in OAuth server that issues the tokens users log in with. You can configure token duration, inactivity timeouts, and the OAuth server URL so that dormant or unneeded sessions close automatically.
