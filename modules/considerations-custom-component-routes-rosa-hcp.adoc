= Considerations for custom component routes

[role="_abstract"]
When you configure custom component routes on {product-title}, review the following considerations to avoid certificate issues, DNS misconfigurations, and security concerns.

Certificate expiration:: {product-title} does not automatically validate or renew TLS certificates. If a certificate expires, web browsers display security warnings. You must update the TLS secret in the `openshift-config` namespace before the certificate expires.

Hostname validation:: {product-title} does not perform automated fully qualified domain name (FQDN) reachability checks. You must verify that the hostname is correct and properly mapped in DNS.

Secret storage:: Private keys for custom route certificates reside securely in the cluster data plane. etcd encryption protects the keys, and the cluster does not export them.
