= Widget options

[role="_abstract"]
Some widgets are customizable to help you focus on specific data. Widgets offer different controls that you can use to change how the data sorts, filter the data, and customize the output of the widget.

Widgets offer two ways to customize different aspects:

* An *Options* menu, when present, provides specific options applicable to that widget.
* A *dynamic axis legend*, when present, provides a method to filter data by hiding one or more of the axis categories. For example, in the *Policy violations by category* widget, you can click a severity to include or exclude violations of a selected severity from the data.

[NOTE]
====
Individual widget customization settings are short-lived and are reset to the system default upon leaving the Dashboard.
====
