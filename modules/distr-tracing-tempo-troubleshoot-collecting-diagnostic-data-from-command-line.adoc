= Collect diagnostic data

[role="_abstract"]
If you experience difficulty with {dt}, visit the Red Hat Customer Portal, where you can submit a support case to Red Hat Support. When submitting a support case, include diagnostic information about your cluster.

.Prerequisites

* You are logged in to the cluster as a user with the `cluster-admin` role.
+
[TIP]
====
Ensure that your {oc-first} version is up to date and matches your {ocp-product-title} version.

You can verify your login by running the following command:

[source,terminal]
----
$ oc whoami
----
====

Use the `oc adm must-gather` tool to gather diagnostic data for resources of various types, such as `TempoStack`, and for created resources, such as `Deployment`, `Pod`, or `ConfigMap`.

The `oc adm must-gather` tool creates a new pod that collects this data.

[TIP]
====
The {TempoOperator} supports monitoring and alerts about each TempoStack component, such as the distributor or ingester, and exposes upgrade and operational metrics about the Operator itself.
====

.Procedure

* From the directory where you want to save the collected data, run the `oc adm must-gather` command to collect the data:
+
[source,terminal]
----
$ oc adm must-gather --image=ghcr.io/grafana/tempo-operator/must-gather -- \
/usr/bin/must-gather --operator-namespace <operator_namespace>
----
where:

`--operator-namespace`:: Default namespace where the Operator is installed is `openshift-tempo-operator`.

.Verification

* Verify that the new directory is created and contains the collected data.
