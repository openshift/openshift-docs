= IPv6 limitations

[role="_abstract"]
{product-title} supports IPv6 on {oci-c3} and {oci-edge} with platform-specific limitations.

IPv6 is limited to Single Root I/O Virtualization (SR-IOV) virtual network interface cards (VNICs).
