= Installing the BGP Cloud Connector Operator

[role="_abstract"]
You can install the BGP Cloud Connector Operator on an {product-title} cluster by using either the {oc-first} or the web console.
After you install the Operator, you can deploy the Operator through the {olm-first}.

.Procedure

. To install the BGP Cloud Connector Operator by using the {oc-first}, complete the following steps:
+
.. Create a dedicated namespace and an `OperatorGroup` manifest file for the BGP Cloud Connector Operator by entering the following command:
+
[source,terminal]
----
$ oc create namespace bgp-cloud-connector
----
+
.. Create an `OperatorGroup` manifest file in the dedicated namespace by entering the following command:
+
[source,terminal]
----
$ echo '{"apiVersion":"operators.coreos.com/v1","kind":"OperatorGroup","metadata":{"name":"bgp-cloud-connector-operatorgroup","namespace":"bgp-cloud-connector"}}' | oc apply -f -
----
+
.. Configure {aws-short} authentication for the Operator based on the credential mode of your cluster. The Cloud Credential Operator (CCO) automatically manages {aws-short} credentials for the Operator based on the credential mode of your cluster.
+
ifndef::openshift-rosa-hcp[]
* Mint Mode: No manual credential setup is required.
CCO automatically creates an IAM user with the necessary permissions and populates the required secret in the namespace of the Operator.
* Manual or STS Mode: Pass your pre-created IAM role ARN to the Operator by using the `ROLEARN` environment variable. CCO updates the `CredentialsRequest` and provisions a secret containing the projected web identity token.
endif::openshift-rosa-hcp[]
ifdef::openshift-rosa-hcp[]
* STS Mode: Pass your pre-created IAM role ARN to the Operator by setting the `ROLEARN` environment variable in the `Subscription` custom resource (CR) or specifying it in the Role ARN field in the web console.
endif::openshift-rosa-hcp[]
+
If you are deploying the Operator manually through a `Subscription` CR, set the `ROLEARN` environment variable in your manifest:
+
[source,yaml]
----
apiVersion: operators.coreos.com/v1alpha1
kind: Subscription
metadata:
  name: bgp-cloud-connector-operator
  namespace: bgp-cloud-connector
spec:
  channel: stable
  name: bgp-cloud-connector-operator
  source: redhat-operators
  sourceNamespace: openshift-marketplace
  config:
    env:
      - name: ROLEARN
        value: arn:aws:iam::<aws_account_id>:role/<iam_role_name>
----
+
[NOTE]
====
If you install the Operator by using the web console, the console automatically prompts you for the `Role ARN` and then populates `ROLEARN` for you.

You must create the IAM role in {aws-short} before setting `ROLEARN`.
The Operator cannot generate its own IAM role.
Ensure the trust policy of the role trusts the OIDC provider of your cluster.
====
+
.. Verify that the Operator installation succeeded by entering the following command:
+
[source,terminal]
----
$ oc get csv -n bgp-cloud-connector
----
+
Confirm that the `PHASE` column displays `Succeeded`.

. To install BGP Cloud Connector Operator by using the {product-title} web console, complete the following steps:
+
.. Log in to the web console as a cluster administrator.
+
.. Go to *Ecosystem* --> *Software Catalog*
+
.. Search for `BGP cloud connector`.
+
.. Click the *Install* button.
+
.. Select `bgp-cloud-connector` as the namespace.
+
.. Click the *Install* button.
