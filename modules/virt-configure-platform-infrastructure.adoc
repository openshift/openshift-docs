= Configure platform infrastructure

[role="_abstract"]
After you install {VirtProductName}, the `virt-platform-autopilot` controller performs and manages postinstallation configuration of the platform infrastructure to support the VM workloads. 

NOTE: You must manually configure some infrastructure, such as networking, storage, node placement, and VM boot settings.
