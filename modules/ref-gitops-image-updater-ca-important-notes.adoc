= CA certificate configuration considerations

[role="_abstract"]
Understand the following considerations when you configure custom CA certificates for Argo CD Image Updater.

[IMPORTANT]
====
* *System trust store*: The system adds custom CA certificates to the trust store; it does not replace the trust store. Image Updater trusts both system CAs and your custom CAs.

* *Insecure registries*: When you set `insecure: true` for a registry, the system skips CA certificate processing entirely and disables TLS verification.

* *PEM format*: CA certificates must be in PEM format. The system supports both single certificates and certificate bundles (multiple certificates in one file).
====
