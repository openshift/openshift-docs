= Application delivery and management with Argo CD

[role="_abstract"]
{gitops-title} provides tools for deploying, managing, and progressively rolling out applications across {OCP} clusters. Argo CD synchronizes application state from Git repositories, while ApplicationSets and Argo Rollouts add multi-cluster automation and progressive delivery.

Application delivery and management includes the following areas:

* *Deploy and manage applications*: Create and synchronize Argo CD applications by using the {gitops-shortname} CLI in default or core mode.
* *Manage applications across namespaces*: Configure Application resources in non-control plane namespaces for multitenancy environments, manage application links with the `managed-by-url` annotation, and use the GitOps console plugin for monitoring.
* *Manage ApplicationSets*: Automate deployments of multiple Argo CD applications from a single repository to many clusters by using ApplicationSet resources in non-control plane namespaces.
* *Use Progressive Sync*: Control application rollout strategies across multiple clusters by configuring ApplicationSet creation, update, and deletion strategies.
* *Roll out application updates progressively*: Use Argo Rollouts for advanced deployment capabilities such as blue-green, canary, and canary analysis with traffic management through OpenShift Routes or Service Mesh.
