= Logging 6.4.7 release notes

[role="_abstract"]

This release includes link:https://access.redhat.com/errata/RHSA-2026:77639[RHSA-2026:77639].

[id="logging-release-notes-6-4-7-enhancements_{context}"]
== New features and enhancements

* With this update, Loki has been updated to 3.7.3. The Loki operator configuration includes migration to the object storage client in this release.
(link:https://issues.redhat.com/browse/LOG-9868[LOG-9868])

* With this update, Loki is now version 3.7.8.
(link:https://issues.redhat.com/browse/LOG-10137[LOG-10137])

[id="logging-release-notes-6-4-7-bug-fixes_{context}"]
== Bug fixes

* Before this update, Loki failed to upload data to certain S3-compatible object storage backends that do not support the `STREAMING-AWS4-HMAC-SHA256-PAYLOAD-TRAILER` value in the `x-amz-content-sha256` header. As a consequence, Loki ingesters failed to flush logs to object storage. With this update, Loki uploads succeed with those S3-compatible backends. As a result, log data is stored successfully.
(link:https://issues.redhat.com/browse/LOG-9632[LOG-9632])

* Before this update, the `detectMultilineException` filter incorrectly concatenated independent JSON log records. As a consequence, unrelated JSON log messages could be merged into a single record. With this update, the filter correctly identifies exception stack traces and no longer concatenates independent JSON log records. As a result, each independent JSON log record is forwarded separately.
(link:https://issues.redhat.com/browse/LOG-10102[LOG-10102])

* Before this update, after upgrading the {clo}, the `log-file-metric-exporter` metrics endpoint required authentication. Prometheus lacked the configuration to provide it. As a consequence, all log file metric exporter (LFME) Prometheus scrape targets returned HTTP `401 Unauthorized`, and metrics such as `log_logged_bytes_total` were absent from Prometheus. With this update, the LFME metrics endpoint no longer requires that authentication. As a result, LFME metrics remain available in Prometheus after an upgrade.
(link:https://issues.redhat.com/browse/LOG-10298[LOG-10298])
