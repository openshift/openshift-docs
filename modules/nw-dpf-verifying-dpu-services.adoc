= Verify DPU service reconciliation

[role="_abstract"]
You can verify that all DPU services, IPAM pools, service interfaces, and service chains are reconciled after creating the DPF resources.

[NOTE]
====
The `nvidia-k8s-ipam` service remains in a `Pending` state until DPU provisioning completes. This is expected behavior.
====

.Prerequisites

* You have created the DPF custom resources: `DPFOperatorConfig`, `NodeSRIOVDevicePluginConfig`, `DPUFlavor`, `BFB`, and `DPUDeployment`.
* You have created the HBN, OVN-Kubernetes, and DTS DPU service resources.
* You have access to the management cluster as a user with the `cluster-admin` role.
* You have installed the `oc` CLI.

.Procedure

. Verify that the `DPUDeployment` resource is fully reconciled:
+
[source,terminal]
----
$ oc wait dpudeployment/dpudeployment \
  --for=condition=ReconcileComplete=True \
  -n dpf-operator-system \
  --timeout=10m
----

. Verify that all DPU service IPAM pools are synced:
+
[source,terminal]
----
$ oc wait dpuserviceipmapools.svc.dpu.nvidia.com --all \
  --for=condition=Synced=True \
  -n dpf-operator-system \
  --timeout=10m
----

. Verify that all DPU service interfaces are synced:
+
[source,terminal]
----
$ oc wait dpuserviceinterfaces.svc.dpu.nvidia.com --all \
  --for=condition=Synced=True \
  -n dpf-operator-system \
  --timeout=10m
----

. Verify that all DPU service chains are synced:
+
[source,terminal]
----
$ oc wait dpuservicechains.svc.dpu.nvidia.com --all \
  --for=condition=Synced=True \
  -n dpf-operator-system \
  --timeout=10m
----
