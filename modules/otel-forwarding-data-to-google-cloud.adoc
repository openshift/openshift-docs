= Forwarding telemetry data to Google Cloud

[role="_abstract"]
To forward telemetry data to Google Cloud Operations Suite, use the OTLP HTTP Exporter with the Google Client Authorization Extension. The exporter sends traces to Google Cloud Trace, metrics to Google Cloud Monitoring, and logs to Google Cloud Logging through the `telemetry.googleapis.com` endpoint.

[IMPORTANT]
====
The OTLP HTTP Exporter requires the Google Client Authorization Extension for authentication. You can authenticate by using a secret or Google Workload Identity Federation (WIF).
====

The following `OpenTelemetryCollector` custom resource configures the OTLP HTTP Exporter to forward traces, metrics, and logs to Google Cloud:

[source,yaml]
----
# ...
  env:
    - name: GOOGLE_APPLICATION_CREDENTIALS # <4>
      value: /var/secrets/google/key.json
    - name: GOOGLE_CLOUD_PROJECT
      value: <project_id> # <5>
  volumeMounts:
    - name: google-application-credentials
      mountPath: /var/secrets/google
      readOnly: true
  volumes:
    - name: google-application-credentials
      secret:
        secretName: google-application-credentials
  config:
    extensions:
      googleclientauth: {}

    exporters:
      otlp_http/googlecloud:
        endpoint: https://telemetry.googleapis.com
        auth:
          authenticator: googleclientauth

    processors:
      resource/gcp:
        attributes:
          - key: gcp.project_id # <1>
            value: <project_id>
            action: upsert
          - key: service.instance.id # <2>
            from_attribute: service.name
            action: upsert
          - key: cloud.availability_zone # <3>
            value: <availability_zone> # <6>
            action: upsert

    service:
      extensions: [googleclientauth]
      pipelines:
        traces:
          processors: [resource/gcp]
          exporters: [otlp_http/googlecloud]
        metrics:
          processors: [resource/gcp]
          exporters: [otlp_http/googlecloud]
        logs:
          processors: [resource/gcp]
          exporters: [otlp_http/googlecloud]
# ...
----
<1> Required for all signals (traces, metrics, logs). Identifies the Google Cloud project for the telemetry data.
<2> Required for metrics. The `prometheus_target` monitored resource type requires an instance identifier.
<3> Required for metrics. The `prometheus_target` monitored resource type requires a location identifier.
<4> You can configure the `GOOGLE_APPLICATION_CREDENTIALS` environment variable to use a secret or Google Workload Identity Federation (WIF). This example uses a secret.
<5> The Google Cloud project ID.
<6> The Google Cloud availability zone, for example `us-central1-a`.
