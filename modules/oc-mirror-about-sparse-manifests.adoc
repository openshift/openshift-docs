= Sparse manifest lists in oc-mirror plugin v2

[role="_abstract"]
A sparse manifest list in oc-mirror plugin v2 stores only a subset of referenced architectures while preserving the original manifest list digest. Sparse manifests reduce network, disk, and registry storage and keep digest-based references valid in disconnected environments.

For example, a sparse manifest can reference only `amd64` or `arm64` so the mirrored image set matches the node architectures in a disconnected {product-title} cluster.

[IMPORTANT]
====
You must be able to disable manifest list validation on your target mirror registry. Registries that enforce the presence of all child manifests reject sparse pushes and cause the mirroring operation to fail.
====
