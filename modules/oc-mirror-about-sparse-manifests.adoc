= Sparse manifests in oc-mirror plugin v2

[role="_abstract"]
You can use sparse manifests in oc-mirror plugin v2 to mirror only the compute architectures your disconnected cluster uses, while keeping the manifest list and its digest unchanged.

Many {product-title} images, including release payloads and Operator images, are distributed as multi-architecture manifest lists. A manifest list is a single top-level object referencing per-architecture manifests for variants such as `amd64`, `arm64`, `ppc64le`, and `s390x`. Each per-architecture manifest points to the underlying image blobs for that specific architecture.

[id="oc-mirror-sparse-manifest-behavior_{context}"]
== How sparse manifests work

When you mirror using a sparse manifest, oc-mirror retains the original manifest list and its digest. Although the manifest list continues to list all supported architectures, the target mirror registry only stores and serves the image blobs for the architectures you chose to mirror.

.Sparse manifest registry state when mirroring `amd64` only

|`s390x`

|===
