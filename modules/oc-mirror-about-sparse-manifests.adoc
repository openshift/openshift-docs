= Multi-architecture filtering using sparse manifests in oc-mirror plugin v2

[role="_abstract"]
You can use multi-architecture filtering with sparse manifests in oc-mirror plugin v2 to mirror only the compute architectures your disconnected cluster uses. The manifest list digest remains unchanged, so image references and image signatures in your disconnected cluster remain valid.

A sparse manifest is a manifest list that references child manifests for architectures that are not all present in the target registry. When oc-mirror plugin v2 applies architecture filtering, it pushes only the child manifests and image blobs for the architectures you select. The oc-mirror plugin v2 then pushes the original manifest list to the target registry without modification.

Architectures that you did not select have no blobs in the target registry. The manifest list still references them because it is not modified during the mirroring process.

[IMPORTANT]
====
Your target mirror registry must allow you to disable manifest list validation. Registries that enforce the presence of all child manifests reject sparse pushes and cause the mirroring operation to fail.
====
