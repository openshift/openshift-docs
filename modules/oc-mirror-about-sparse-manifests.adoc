= Sparse manifests in oc-mirror plugin v2

[role="_abstract"]
To transfer and store only the architectures your disconnected cluster needs, use sparse manifests in oc-mirror plugin v2. That approach reduces network, disk, and registry storage.

A sparse manifest list stores only a subset of the referenced architectures, such as `amd64` or `arm64`, while the original manifest list digest is preserved. That behavior keeps digest-based image references valid in disconnected {product-title} environments.

[IMPORTANT]
====
You must be able to disable manifest list validation on your target mirror registry. Registries that enforce the presence of all child manifests reject sparse pushes and cause the mirroring operation to fail.
====
