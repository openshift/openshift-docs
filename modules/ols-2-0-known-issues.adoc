= Known issues

[role="_abstract"]
{ols-official} 2.0 contains a known issue where the tool classifier can fail a tool result as malicious when processing larger contexts.

//No associated ticket
* *Tool classifier can fail a tool result as malicious with larger contexts*
+
The tool classifier has been observed to incorrectly fail a tool result as malicious when processing larger contexts.
+
Workaround: Turn off tool inspection in your {ols-official} configuration custom resource (CR).
