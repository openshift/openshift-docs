= Known issues

[role="_abstract"]
Review the following known issues for {ols-official} 2.0.

//No associated ticket
* *Tool classifier can fail a tool result as malicious with larger contexts*
+
The tool classifier has been observed to incorrectly fail a tool result as malicious when processing larger contexts.
+
Workaround: Turn off tool inspection in your {ols-official} configuration custom resource (CR).

* *Reader RBAC must be created manually*
+
The OLM bundle creates the `lightspeed-agent` service account but not the `ClusterRoleBinding` resources that it needs. You must create them manually.

* *Execution RBAC must be created manually*
+
The OLM-granted `ClusterRole` for the agentic Operator service account lacks `apps`, `batch`, and `networking.k8s.io` permissions. Execution steps fail due to RBAC escalation prevention unless you create the execution RBAC.

* *Agentic deployment requires two separate LLM secret keys*
+
Classic {ols-long} uses the key `apitoken` in the secret `credentials`, and agentic uses the key `OPENAI_API_KEY` in the secret `llm-creds-openai`. These can be the same secret, but it still needs two separate keys holding the same value. The `OLSConfig` CR supports `credentialKey` to override the default `apitoken`, but `LLMProvider` hardcodes the key name per provider.

* *Offline knowledge portal image pull can take up to 20 minutes*
+
The `rhokp` offline knowledge portal image is approximately 7.7 GB compressed and requests 75Gi of ephemeral storage. The first pull can take 5 to 20 minutes.
