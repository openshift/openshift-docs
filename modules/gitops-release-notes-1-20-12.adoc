== Fixed issues

Improved warning message for resource tracking method changes during upgrade::
Starting with {gitops-title} 1.19, the {gitops-title} Operator changes the default resource tracking behavior from label-based tracking to annotation-based tracking. When upgrading from previous versions that do not explicitly set `.spec.resourceTrackingMethod`, users may notice diff for labels on resources, such as Namespaces, Subscriptions and Secrets, which are managed by controllers other than Argo CD and the Application status changes to `OutOfSync`. For Secret resources specifically, syncing the application deletes the labels managed or added by other controllers. The issue is observed even when `ignoreDifferences` is added to the Application.
+
With this update, the {gitops-title} Operator now logs a warning message to help users identify and address this issue before upgrading:
+
[source,terminal]
----
WARNING: resource tracking method in argocd-cm is changing from 'label' to the default
'annotation' because .spec.resourceTrackingMethod is not set. ...
----
+
To avoid the above issues, users should explicitly configure `.spec.resourceTrackingMethod` in the Argo CD CR before starting the upgrade to continue using label-based tracking:
+
[source,yaml]
----
apiVersion: argoproj.io/v1beta1
kind: ArgoCD
metadata:
  name: example-argocd
spec:
  resourceTrackingMethod: label
----
