= Edit machine pool AWS tags by using the {rosa-cli}

[role="_abstract"]
Add, update, or remove the custom AWS tags on an existing machine pool by running the `rosa edit machinepool` command with the `--tags` option. Machine pool tags apply only to the AWS resources that {product-title} creates for that machine pool. The machine pool continues to inherit cluster tags unless it defines a tag with the same key.

.Prerequisites

* You installed and configured {rosa-cli} 1.2.68 or later.
* You logged in to your Red{nbsp}Hat account by using the {rosa-cli}.
* You have a {product-title} cluster that runs version 4.20.0 or later.
* You created a machine pool.

.Procedure

. Set the complete list of custom tags for the machine pool by running the following command:
+
--
[source,terminal]
----
$ rosa edit machinepool --cluster=<cluster_name> <machine_pool_name> --tags '<key>:<value>,<key>:<value>'
----

where:

`<key>:<value>,<key>:<value>`:: Specifies the complete set of custom tags that you want on the machine pool, as a comma-separated list of key-value pairs. {product-title} removes any existing machine pool tag that you omit. Do not include tags that the machine pool inherits from the cluster, unless you want to override their values. You can also specify the `--tags` option more than once. If a key or value includes a space or a colon, enclose the key or value in double quotation marks and enclose the entire value in single quotation marks, for example, `--tags '"Cost Center":"Finance Team"'`.
--
+
.Example command
[source,terminal]
----
$ rosa edit machinepool --cluster=mycluster mp1 --tags '"Cost Center":"Finance Team"'
----
+
[NOTE]
====
If you use the Windows Command Prompt (`cmd.exe`), escape double quotation marks by doubling them, for example, `--tags """Cost Center"":""Finance Team"""`.
====

. Optional: To remove all tags that you define on the machine pool, run the following command:
+
[source,terminal]
----
$ rosa edit machinepool --cluster=<cluster_name> <machine_pool_name> --tags ''
----
+
The machine pool continues to inherit tags from the cluster.

.Verification

* Verify that the machine pool has the tags that you specified by running the following command:
+
[source,terminal]
----
$ rosa describe machinepool --cluster=<cluster_name> --machinepool=<machine_pool_name>
----
+
The `Tags` field in the output lists the tags for the machine pool.
