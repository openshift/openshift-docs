= Usage of oc and kubectl commands

[role="_abstract"]
Because OpenShift Container Platform is a certified Kubernetes distribution, you can use the Kubernetes CLI (`kubectl`) to interact with your cluster. You can also gain extended functionality specific to OpenShift Container Platform by using the {oc-first} binary.
