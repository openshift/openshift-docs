= Load an existing mirror configuration

[role="_abstract"]
Reuse a mirror configuration by loading an existing `ImageSetConfiguration` file into the OpenShift Mirror Console. Review or edit the platform channels, Operator catalogs, additional images, and archive size before you save it.

.Prerequisites

* You have opened the OpenShift Mirror Console in a browser.
* You have configured a pull secret.
* You have an `ImageSetConfiguration` file.

.Procedure

. On the Mirror Configuration page, click the *Load Configuration* tab to upload an existing configuration.

. Upload your `ImageSetConfiguration` file by doing one of the following:

.. Drag and drop the `ImageSetConfiguration` file onto the upload area.

.. Click *Browse*.

.. Select the `ImageSetConfiguration` file on your local system.

. Confirm that the console displays a `Valid ImageSetConfiguration detected` message.

. Click *Load into Editor* to load the configuration into the form editor.

. Optional: To review or change the configuration, use the *Platform Channels*, *Operators*, and *Additional Images* tabs.

. Optional: To review or change the archive size, use the *Archive Size* field on the *Preview* tab.
+
The field sets the maximum size of each archive in GiB when you mirror to disk. If you leave the field empty or enter `0`, oc-mirror uses the default archive size.

. Optional: To rename the file, complete the following steps:

.. Click the *Edit* icon next to the filename.

.. Enter a new name.
+
[NOTE]
====
The console does not copy the name of the loaded file. To update an existing saved configuration, enter its exact name before you save. If you do not rename the file, the console creates a new file with a timestamped name.
====

. After reviewing or editing the configuration, save or download the file by doing one of the following:

.. Click *Save Configuration* to save the file.
+
If you did not rename the file, the console saves it as `imageset-config-<utc_timestamp>.yaml`. The timestamp uses Coordinated Universal Time (UTC), for example, `imageset-config-2026-11-11-11-14-00-UTC.yaml`. If you enter the name of an existing configuration, the console overwrites it. The file appears in the *ImageSetConfiguration File* list on the Mirror Operations page.

.. Click *Download YAML* to download a copy of the file to the default downloads location on your local system. The copy does not appear on the Mirror Operations page.

.Verification

. Confirm that the *Platform Channels*, *Operators*, and *Additional Images* tabs show the expected values from your uploaded file.

. If your file sets an archive size, confirm that the *Archive Size* field on the *Preview* tab shows that value.

. If you saved the configuration, confirm that it appears in the *ImageSetConfiguration File* list on the Mirror Operations page.
