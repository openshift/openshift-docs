= Load an existing mirror configuration

[role="_abstract"]
Load an existing `ImageSetConfiguration` file into the OpenShift Mirror Console to reuse a mirror configuration. Loading a saved configuration preserves existing platform, Operator, and additional image settings for review or editing before the next mirror operation.

.Prerequisites

* You are logged in to the OpenShift Mirror Console.
* You have configured a pull secret.
* You have a saved `ImageSetConfiguration` file available in the OpenShift Mirror Console.

.Procedure

. On the Mirror Configuration page, click the *Load Configuration* tab to upload an existing configuration.

. Upload your `ImageSetConfiguration` YAML file by doing one of the following:

.. Drag and drop the `.yaml` file onto the upload area.

.. Click *Browse* and select the `.yaml` file on your local system.

. Confirm that a `Valid ImageSetConfiguration detected` message appears. 

. Click *Load into Editor* to load the configuration into the form editor. You can review and modify it using the *Platform Channels*, *Operators*, and *Additional Images* tabs.

. To save the configuration after reviewing or editing it, do one of the following:

.. Click *Save Configuration* to save the file with the auto-generated filename.

.. Optional: To rename the file before saving, click the *Edit* icon next to the filename and enter the new name into the text box.

.. Click *Download YAML* to download the updated `ImageSetConfiguration` file to your local system.

.Verification

* Confirm that the *Platform Channels*, *Operators*, and *Additional Images* tabs show the expected values from your uploaded file.
