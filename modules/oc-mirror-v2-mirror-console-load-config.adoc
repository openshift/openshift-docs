= Load an existing mirror configuration

[role="_abstract"]
To reuse a mirror configuration, load an existing `ImageSetConfiguration` file from your local system into the OpenShift Mirror Console. Loading the file preserves the platform, Operator, and additional image settings for review or editing before the next mirror operation.

.Prerequisites

* The OpenShift Mirror Console is open in a browser.
* You have configured a pull secret.
* You have an `ImageSetConfiguration` file with a `.yaml` or `.yml` extension on your local system.

.Procedure

. On the Mirror Configuration page, click the *Load Configuration* tab to upload an existing configuration.

. Upload your `ImageSetConfiguration` YAML file by doing one of the following:

.. Drag and drop the `.yaml` or `.yml` file onto the upload area.

.. Click *Browse* and select the `.yaml` or `.yml` file on your local system.

. Confirm that the console displays a `Valid ImageSetConfiguration detected` message.

. Click *Load into Editor* to load the configuration into the form editor.

. Optional: To review or change the configuration, use the *Platform Channels*, *Operators*, and *Additional Images* tabs.

. Optional: To rename the file, use the *Edit* icon next to the filename to enter a new name.

. After reviewing or editing the configuration, save or download the file by doing one of the following:

.. Click *Save Configuration* to save the file with the default filename, or with the new name if you renamed it. The file then appears in the *ImageSetConfiguration File* list on the Mirror Operations page.

.. Click *Download YAML* to download a copy of the file to the default downloads folder on your computer. The copy does not appear on the Mirror Operations page.

.Verification

* Confirm that the *Platform Channels*, *Operators*, and *Additional Images* tabs show the expected values from your uploaded file.
