= About hybrid post-quantum key exchange

[role="_abstract"]
SPIRE control-plane components negotiate hybrid Module-Lattice-Based Key-Encapsulation Mechanism (ML-KEM) key exchange during a Transport Layer Security (TLS) 1.3 handshake when the remote peer offers a supported group. A hybrid group keeps a classical elliptic-curve exchange alongside ML-KEM.

The supported hybrid groups are:

* `X25519MLKEM768`
* `SecP256r1MLKEM768`
* `SecP384r1MLKEM1024`

[id="zero-trust-manager-pqc-modes_{context}"]
== Preferred and strict modes

Preferred mode is the default. The connection uses a hybrid ML-KEM group when the peer offers one. When the peer does not offer a hybrid group, the connection uses a classical curve.

Strict mode is optional. On endpoints that support it, strict mode requires TLS 1.3 and a hybrid ML-KEM group. Those endpoints reject a peer that does not negotiate a hybrid group.

[NOTE]
====
Keep preferred mode when any SPIRE Server, SPIRE Agent, or federation peer cannot offer a hybrid group. Strict mode rejects those peers on the endpoints that support it.
====
