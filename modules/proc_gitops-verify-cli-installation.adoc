= Verify the installation

[role="_abstract"]
Verify that the {gitops-shortname} `argocd` CLI is installed correctly and can communicate with the Argo CD server.

.Prerequisites

* You have installed the {gitops-shortname} `argocd` CLI.
* You have access to an {OCP} cluster with {gitops-title} installed.

.Procedure

. Verify the CLI version:
+
[source,terminal]
----
$ argocd version --client
----
+
*Example output:*
[source,terminal]
----
argocd: v3.4.3+unknown
  BuildDate: 2024-10-15T18:30:00Z
  GitCommit: abc123def456
  GoVersion: go1.21.5
  Platform: linux/amd64
----

. Log in to your {OCP} cluster:
+
[source,terminal]
----
$ oc login --token=<token> --server=<server_url>
----
+
Replace `<token>` and `<server_url>` with your cluster credentials.

. Get the Argo CD server URL:
+
[source,terminal]
----
$ oc get route openshift-gitops-server -n openshift-gitops -o jsonpath='{.status.ingress[0].host}'
----
+
*Example output:*
[source,terminal]
----
openshift-gitops-server-openshift-gitops.apps.example.com
----

. Optional: Verify the CLI can connect to the Argo CD server:
+
[source,terminal]
----
$ argocd version --server <server_url> --insecure
----
+
Replace `<server_url>` with the route URL from the previous step. Add the `--insecure` flag if you are using self-signed certificates.
+
*Example output:*
[source,terminal]
----
argocd: v3.4.3+unknown
argocd-server: v3.4.3+unknown
----

.Verification

The CLI is installed correctly if both the client and server versions display without errors.
