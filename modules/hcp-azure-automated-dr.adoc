= Automated disaster recovery for {hcp} on {azure-short}

[role="_abstract"]
You can automate disaster recovery (DR) for {hcp} on {azure-first} by using {oadp-first} 1.6. The {oadp-short} `hypershift` plugin automatically detects the platform and includes the required platform-specific resources in backup and restore operations.

The following limitations apply to {oadp-short}-based restore operations on {hcp} on {azure-short}:

Same-management-cluster-only restore:: Cross-management-cluster restore is not currently supported for {azure-short}. Only same-cluster restore, where you restore to the management cluster from which the backup was taken, is supported.

Compute node reprovisioning:: Compute nodes are reprovisioned after a restore. Applications running on compute nodes experience downtime while the nodes are reprovisioned and rejoin the cluster. Plan for this disruption when scheduling recovery operations.
