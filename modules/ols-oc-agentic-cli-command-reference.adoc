= oc-agentic CLI command reference

[role="_abstract"]
Use the following `oc-agentic` commands to manage troubleshooting runs and system states from your terminal.

[NOTE]
====
The default namespace for CLI commands is `openshift-lightspeed` unless you override it with `-n` or specify it in the kubeconfig context.
====

.oc-agentic commands
[cols="1,2",options="header"]
|===
|Command |Description

|`oc agentic run create`
|Creates a new agentic run. Accepts the `--request`, `--agent`, and `--target-namespaces` flags.

|`oc agentic run list`
|Lists agentic runs. Accepts the `-A`, `--phase`, and `-o wide` flags.

|`oc agentic run get <run_id>`
|Displays details for a specific run. Accepts the `-o json` flag.

|`oc agentic run approve <run_id>`
|Approves a stage. Accepts the `--stage`, `--option`, `--agent`, `--all`, and `--wait` flags.

|`oc agentic run deny <run_id>`
|Denies a stage. Accepts the `--stage` flag.

|`oc agentic run watch <run_id>`
|Streams phase transitions until a terminal state is reached.

|`oc agentic run logs <run_id>`
|Streams sandbox pod logs. Accepts the `--step` and `-f` flags.

|`oc agentic run delete <run_id>`
|Deletes an agentic run.

|`oc agentic status`
|Shows the system suspension state.

|`oc agentic suspend`
|Suspends all agentic operations. Accepts the `--yes` flag to skip the confirmation prompt.

|`oc agentic resume`
|Resumes agentic operations.

|`oc agentic version`
|Prints the plugin version.
|===
