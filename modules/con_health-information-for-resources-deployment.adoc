= Monitor health information for application resources

[role="_abstract"]
Monitor health information for application resources by using the {gitops-title} *Environments* page in the *Developer* perspective of the {OCP} web console. View successful deployments, revision links, health status, synchronization status, deployment configurations, and deployment history.
