= Access your cluster

[role="_abstract"]
Access your {product-title} cluster, grant administration privileges, and set up external authentication and break glass credentials.

After your {product-title} cluster is running, you can access the cluster and control administrator and user access.

{product-title} lets you access the cluster through the web console, grant administrator privileges, configure an external authentication provider, and create break glass credentials for emergency access when the external provider is unavailable.
