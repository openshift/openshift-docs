= Enable automated machine management on user-provisioned infrastructure

[role="_abstract"]
On a cluster you provisioned yourself, the Machine API cannot manage compute nodes until the cluster supplies what it needs: the infrastructure ID, vCenter credentials in the openshift-machine-api namespace, and a valid Ignition configuration. An installer-provisioned cluster already has all three.
