= Prometheus Remote Write Receiver

[role="_abstract"]
The Prometheus Remote Write Receiver receives metrics from Prometheus using the Remote Write protocol and converts them to the OpenTelemetry format. This receiver supports only the Prometheus Remote Write v2 protocol.

:FeatureName: The Prometheus Remote Write Receiver
include::snippets/technology-preview.adoc[]

The following `OpenTelemetryCollector` custom resource configures the Prometheus Remote Write Receiver:

[source,yaml]
----
# ...
  config:
    receivers:
      prometheus_remote_write:
        endpoint: 0.0.0.0:9090
    # ...
    service:
      pipelines:
        metrics:
          receivers: [prometheus_remote_write]
# ...
----
where:

`endpoint`:: Endpoint where the receiver listens for Prometheus Remote Write requests.

The following prerequisites apply for using this receiver with Prometheus:

* Prometheus 3.8 or later.

* The remote write configuration of Prometheus uses the protocol version 2 message, `io.prometheus.write.v2.Request`. This receiver does not accept the protocol version 1.

* Prometheus is started with the `metadata-wal-records` feature flag so that the metric type, unit, and help text are sent with the samples. Without this feature flag, all metrics arrive as untyped gauges. Prometheus 3.10.0 through 3.15.0 do not send the metadata even when this feature flag is enabled.

* Prometheus is configured to scrape native histograms (`scrape_native_histograms`) and to convert classic histograms into native histograms with custom buckets (`convert_classic_histograms_to_nhcb`). This receiver drops classic histogram and summary series that are sent with their metric type.

To receive the metrics of the {ocp-product-title} monitoring stack, see "Sending metrics from the monitoring stack to the Collector by using remote write".
