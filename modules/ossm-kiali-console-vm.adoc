= Virtual machine workloads

[role="_abstract"]

The graph can include a virtual machine that joins the mesh with a `WorkloadEntry`, next to workloads that run as pods on {ocp-product-title}. The console does not mark which nodes are virtual machines, and it does not open a detail page for them beyond the graph. Give the virtual machine a distinct `version` label if you need to tell the nodes apart.

The {istio} proxy must be running on the virtual machine, and Prometheus must scrape its metrics. The usual endpoint is port 15020 and the path `/stats/prometheus`. After those metrics are in the same Prometheus that {KialiServer} queries, the virtual machine appears in the graph. No extra field is required in the `Kiali` custom resource.
