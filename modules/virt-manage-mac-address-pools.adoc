= Manage MAC address pools

[role="_abstract"]
You can manage KubeMacPool to control MAC address allocation for virtual machine (VM) network interfaces, including disabling automatic allocation for specific namespaces and customizing the MAC address range.

A virtual machine instance created from that VM retains the assigned MAC address across reboots.

[NOTE]
====
KubeMacPool does not handle virtual machine instances created independently from a VM.
====
