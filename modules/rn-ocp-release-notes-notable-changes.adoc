== etcd

KMS v2 encryption updates (Technology Preview)::
+
{KMS} encryption for etcd now uses an OLM-managed architecture where KMS plugins run as sidecar containers alongside the API server, configured through a `VaultKMSConfig` custom resource. This release adds direct migration between KMS providers, per-node KMS plugin health reporting, and pre-flight validation of KMS configuration changes. HashiCorp Vault Enterprise is the only supported KMS provider.
+
For more information, see xref:../etcd/KMS_v2/kms-configuring.adoc#kms-configuring[Configuring KMS encryption].
