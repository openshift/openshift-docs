= Resolve catalog content

[role="_abstract"]
When you specify the cluster extension that you want to install in a custom resource (CR), {olmv1-first} uses catalog selection to resolve what content is installed. You can select catalogs by name or label, exclude catalogs with match expressions, and set catalog priority to decide which source resolves first when more than one catalog provides the requested package.
