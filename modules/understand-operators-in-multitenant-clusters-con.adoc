= Understand Operators in multitenant clusters

[role="_abstract"]
When planning Operator installations in a multitenant cluster, review the install modes supported by each Operator, the namespaces that each instance watches, and the RBAC permissions granted to Operators and tenants.

The following sections describe install-mode behavior and a workflow for deploying separate Operator instances for individual tenants, including the limitations of that workflow.
