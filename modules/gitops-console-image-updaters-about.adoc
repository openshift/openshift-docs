= About ImageUpdaters in the GitOps Console

The {gitops-shortname} Console plugin provides list and details pages for Argo CD Image Updater custom resources in the {OCP} web console. You can view ImageUpdaters, review matched applications, managed images, and recent update activity.

The ImageUpdaters list page provides the following capabilities:

* Filter ImageUpdaters by apps and ready status
* Search ImageUpdaters by name
* View ImageUpdater metadata including apps count, images count, last checked time, and ready status
* Create ImageUpdaters from YAML templates

The ImageUpdater details page includes the following tabs:

* *Details*: Identity, status, and conditions
* *Recent Updates*: Image updates from the most recent reconciliation cycle
* *YAML*: Live manifest editor

*Details tab*

The *Details* tab summarizes identity and ImageUpdater status.

The summary section shows:

* *Name*
* *Namespace*
* *Labels* with inline edit
* *Annotations*
* *Created at*

The status and configuration section shows:

* *Ready*: Whether the last reconciliation completed without errors
* *Applications Matched*: Number of applications matched by this ImageUpdater
* *Images Managed*: Number of images eligible for update checking
* *Last Checked At*: When the controller last checked for image updates
* *Last Updated At*: When the controller last performed an image update
* *Observed Generation*: Generation of the resource that was last reconciled

When the ImageUpdater reports status conditions, a *Conditions* section appears below the summary. The conditions table helps diagnose reconciliation problems and includes condition type, status, updated time, reason, and message.

*Recent Updates tab*

The *Recent Updates* tab shows image updates from the most recent reconciliation cycle in a paginated, sortable table. Each row includes alias, image, new version, apps updated, updated time, and message. If no updates were recorded in the last cycle, the tab shows an empty state.

[NOTE]
====
The ImageUpdaters page is available only when the ImageUpdater custom resource definition is installed on the cluster.
====
