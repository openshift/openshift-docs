= About Kiali

[role="_abstract"]

You can use {KialiProduct} to view configurations, monitor traffic, and analyze traces in a single console on {ocp-product-title}. {KialiProduct} derives its core functionality from the open source Kiali project.

{KialiProduct} is the management console for {SMProductName}. It provides dashboards, observability, and configuration and validation capabilities. It shows the structure of your service mesh by inferring traffic topology and displays the health of your mesh. Kiali provides detailed metrics, validations, wizards for {istio} routing, and integration with {TempoName}.

The console views, including topology, health, detail pages, tracing, and the optional chatbot, are described in "Kiali Service Mesh Console".
