= Manage custom resource definition upgrade safety

[role="_abstract"]
When you update a custom resource definition (CRD) provided by a cluster extension, {olmv1-first} runs a CRD upgrade safety preflight check to ensure compatibility with earlier versions.

The CRD update must pass the validation checks before the change can progress on a cluster.
