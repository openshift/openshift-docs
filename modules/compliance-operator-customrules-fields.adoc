= CustomRule CRD fields

[role="_abstract"]
Review the key `spec` fields in a `CustomRule` manifest before you define CEL inputs, write the compliance expression, and configure the messages that appear when a check fails.

The following table describes the fields you set in a `CustomRule` `spec` when you use the CEL scanner.

[cols="1,2a",options="header"]
|===
|Field
|Description

|`title`
|Human-readable name of the check. This value appears in compliance reports and scan results.

|`description`
|Explains what the check validates and the risk it mitigates. You can include commands that help administrators find noncompliant resources.

|`severity`
|Severity assigned to a failing `ComplianceCheckResult`, such as `high` or `medium`.

|`failureReason`
|Message displayed when the check fails. State what is wrong and what an administrator must do to remediate the finding.

|`scannerType`
|Scanner that evaluates the rule. For `CustomRule` resources, set this field to `CEL`.

|`inputs`
|Kubernetes resources that the CEL expression reads. Each input has a `name` and a `kubernetesInputSpec` with `apiVersion` and `resource`. Request only the resources your expression needs.

|`expression`
|CEL logic that evaluates the compliance condition. The expression must evaluate to `true` when evaluated resources are compliant and `false` when they are not.
|===

== Best practices

When you author `CustomRule` definitions, follow these guidelines:

* Write CEL expressions that evaluate to `true` when resources are compliant.
* Use specific, descriptive `metadata.name` values rather than generic identifiers.
* Keep `spec.id` and `metadata.name` aligned when possible to reduce ambiguity.
* Use `spec.description` to explain the risk the rule mitigates and, when helpful, include commands that locate violating resources.
* Write `spec.failureReason` messages that state what failed and what an administrator must do to remediate the finding.
* In `spec.inputs`, request only the Kubernetes resources that your expression requires. Extra inputs can increase scan time and memory use.
