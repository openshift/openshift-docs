= Prevent my cluster from automatically updating the boot image on my nodes

[role="_abstract"]
To keep new nodes on their current boot images, you can prevent your cluster from automatically updating the boot images that new nodes use. Disabling boot image management stops the cluster from updating the boot image reference so that new nodes are created from the boot image that was current when the cluster was installed.
