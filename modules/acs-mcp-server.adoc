= {product-title-short} MCP server

// JIRA: ROX-32129

[role="_abstract"]
{product-title-short} introduces a Model Context Protocol (MCP) server. AI assistants and AI agents can use the MCP server to query and interact with {product-title-short} security data, such as vulnerabilities, policies, and deployments, through a standardized protocol.

For more information, see the documentation in the `stackrox-mcp` GitHub repository.
