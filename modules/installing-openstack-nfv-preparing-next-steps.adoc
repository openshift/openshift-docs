= Next steps after completing preparatory tasks

[role="_abstract"]
After you completed preparatory configurations, you can complete additional tasks.

These additional tasks are listed as follows:
 
* xref:what-huge-pages-do_huge-pages[Configure the Node Tuning Operator with huge pages support] for either type of deployment.
* After you deploy your cluster, you can xref:installing-sr-iov-operator_installing-sriov-operator[install the SR-IOV Network Operator], xref:nw-sriov-networknodepolicy-object_configuring-sriov-device[configure an SR-IOV network device], and xref:machineset-yaml-osp-sr-iov_creating-machineset-osp[create a compute machine set on {rh-openstack}].
* After you deploy your cluster, you can improve the performance of your cluster by completing any of the following tasks:
** Create a xref:nw-openstack-ovs-dpdk-testpmd-pod_using-dpdk-and-rdma[test pod template for clusters that use OVS-DPDK on {rh-openstack}].
** Create a xref:nw-openstack-sr-iov-testpmd-pod_configuring-sriov-device[ test pod template for clusters that use SR-IOV on {rh-openstack}].
** Create a xref:installation-openstack-ovs-dpdk-performance-profile_cnf-tuning-low-latency-nodes-with-perf-profile[performance profile template for clusters that use OVS-DPDK on {rh-openstack}].
