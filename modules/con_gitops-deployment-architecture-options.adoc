= Deployment architecture options

[role="_abstract"]
{gitops-title} offers several architecture options for deploying Argo CD instances. Choose the architecture that matches your security requirements, operational model, and cluster topology.

The main architectural decisions are:

* *Instance scope* - Whether the Argo CD instance has cluster-wide or namespace-level permissions
* *Instance location* - Whether you use the default instance or create custom instances
* *Multi-cluster model* - Whether you manage multiple clusters from a single control plane or use distributed agents

These architectural choices impact how you manage applications, control access, and scale your GitOps infrastructure.
