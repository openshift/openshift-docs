= Roll back a skip-version upgrade

[role="_abstract"]
If you have issues after a skip-version upgrade, roll back the Istio control plane and workload proxies to the previous version.

.Prerequisites

* You have logged in to OpenShift Container Platform with the `cluster-admin` role.

.Procedure

. Roll back the `IstioCNI` resource. 
+
This procedure uses the example of rolling back a 3.2 > 3.4 skip-version upgrade. The steps roll back the `IstioCNI` resource (and `Istio` resource) from 1.30.5 to 1.27.9.

.. Edit the `IstioCNI` resource and set the `spec.version` field to the previous version:
+
[source,terminal]
----
$ oc patch istiocni default -n istio-cni --type='merge' -p '{"spec":{"version":"v1.27.9"}}'
----

.. Verify the rollback by running the following command:
+
[source,terminal]
----
$ oc get istiocni default
----
+
The output shows the previous version:
+
[source,terminal]
----
NAME      READY   STATUS    VERSION   AGE
default   True    Healthy   v1.27.9   52m
----

. Roll back the `Istio` control plane.

.. Edit the `Istio` resource and set the `spec.version` field to the previous version:
+
[source,terminal]
----
$ oc patch istio default --type='merge' -p '{"spec":{"version":"v1.27.9"}}'
----

.. Verify the rollback by running the following command:
+
[source,terminal]
----
$ oc get istio default
----
+
The output shows the previous version:
+
[source,terminal]
----
NAME      REVISIONS   READY   IN USE   ACTIVE REVISION     STATUS    VERSION   AGE
default   2           2       2        default-v1-27-9     Healthy   v1.27.9   57m
----

.. Verify that both revisions are present by running the following command:
+
[source,terminal]
----
$ oc get istiorevisions
----
+
The output shows both the older and newer revisions:
+
[source,terminal]
----
NAME              TYPE    READY   STATUS    IN USE   VERSION   AGE
default-v1-27-9   Local   True    Healthy   True     v1.27.9   40s
default-v1-30-5   Local   True    Healthy   True     v1.30.5   21m
----

.. Confirm that the `IstioRevisionTag` resource points to the older revision by running the following command:
+
[source,terminal]
----
$ oc get istiorevisiontags
----
+
The output shows the older revision:
+
[source,terminal]
----
NAME      STATUS    IN USE   REVISION          AGE
default   Healthy   True     default-v1-27-9   56m
----

. Restart workloads to reconnect to the older control plane.

.. Restart all deployments in namespaces that participate in the mesh. For example, to restart the bookinfo application:
+
[source,terminal]
----
$ oc rollout restart deployment -n bookinfo
----

.. Verify that all proxies are connected to the older control plane by running the following command:
+
[source,terminal]
----
$ istioctl proxy-status
----
+
The output shows all proxies as using the older version:
+
[source,terminal]
----
NAME                                       CLUSTER        CDS              LDS              EDS              RDS              ECDS        ISTIOD                                     VERSION
details-v1-7d4b8f6c55-h6bq2.bookinfo       Kubernetes     SYNCED (15s)     SYNCED (15s)     SYNCED (15s)     SYNCED (15s)     IGNORED     istiod-default-v1-27-9-6f7b58d4c8-w2ndp    1.27.9
productpage-v1-6c9b48d7f4-sk3vj.bookinfo   Kubernetes     SYNCED (17s)     SYNCED (17s)     SYNCED (17s)     SYNCED (17s)     IGNORED     istiod-default-v1-27-9-6f7b58d4c8-w2ndp    1.27.9

+
[NOTE]
====
Newer versions of istioctl might require the revision to be named explicitly when more than one control plane is running. If the output is empty or shows an incomplete list of proxies, specify the revision:

[source,terminal]
----
$ istioctl proxy-status --istioNamespace istio-system --revision default-v1-27-9
----
====

. Confirm that no proxies use the newer revision after the grace period defined by `spec.updateStrategy.inactiveRevisionDeletionGracePeriodSeconds`. Run the following command:
+
[source,terminal]
----
$ oc get istiorevisions
----
+
The output shows only the newer revision:
+
[source,terminal]
----
NAME              TYPE    READY   STATUS    IN USE   VERSION   AGE
default-v1-30-5   Local   True    Healthy   True     v1.30.5   6m
----
