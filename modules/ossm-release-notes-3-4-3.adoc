= {SMProductName} version 3.4.3

[role="_abstract"]
This release of {SMProductName} is included with the {SMProductName} Operator 3.4.3. To view the {ocp-product-title} versions that support {SMProduct} 3.4.3, see link:https://access.redhat.com/support/policy/updates/openshift_operators[OpenShift Operator Life Cycles]. {SMProductShortName} 3.4.3 includes the following fixed issue.

[id="ossm-fixed-issues-3-4-3_{context}"]
== Fixed issue

Proxies enforce correct cipher suites from OpenShift TLS security profiles::
Before this update, {SMProductShortName} proxies did not correctly enforce OpenShift TLS security profiles. When configured with the `modern` profile, TLS version 1.3, and `tlsAdherence` set to `StrictAllComponents`, proxies accepted cipher suites outside the profile. This issue no longer occurs. Proxies correctly enforce only the cipher suites specified in the OpenShift TLS security profile.

link:https://redhat.atlassian.net/browse/OSSM-15376[OSSM-15376]
