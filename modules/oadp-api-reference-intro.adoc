= OADP API reference

[role="_abstract"]
You can use the following APIs with {oadp-short}. Review the API type descriptions in the following sections for each configurable part of the DPA specification.

Velero API::
Velero API documentation is maintained by Velero and is not maintained by Red{nbsp}Hat. For more information, see link:https://velero.io/docs/main/api-types/[Velero API types].

OADP API::
The following are the {oadp-short} APIs:
+
* `DataProtectionApplicationSpec`
* `BackupLocation`
* `SnapshotLocation`
* `ApplicationConfig`
* `VeleroConfig`
* `CustomPlugin`
* `ResticConfig`
* `PodConfig`
* `Features`
* `DataMover`
