= AWS EBS CSI Driver Operator

[role="_abstract"]
You can provision and manage AWS Elastic Block Storage (EBS) in {product-title} by using the AWS EBS Container Storage Interface (CSI) Driver Operator and driver, which provide dynamic volume provisioning and eliminate the need to pre-provision storage.
