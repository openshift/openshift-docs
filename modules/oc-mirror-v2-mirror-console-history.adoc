= Operation history

[role="_abstract"]
To review past mirror operations, use the History page in the OpenShift Mirror Console. The page lists each operation with its name, configuration file, status, start time, and duration.

The History page opens an Operations list of mirror operations. By default, the filter shows *All Operations*. You can also filter the list by *Successful*, *Failed*, or *Stopped*.

Each entry in the list includes the following information:

Operation:: The name of the mirror operation, including a unique identifier.

Config:: The `ImageSetConfiguration` file used for the operation. Click the file name to open the configuration.

Status:: The result of the operation. Displays one of the following statuses:
+
* *Success*: The operation completed without errors.
* *Failed*: The operation did not complete successfully.
* *Stopped*: You stopped the operation before it finished.

Started:: The date and time the operation began.

Duration:: The total time the operation ran.

Click a row to open the Operation Details pane, which can include the following information:

Name:: The operation name and unique identifier.

Status:: The result of the operation.

Started:: The date and time the operation began.

Completed:: The date and time the operation completed. The console displays this field only when the status is *Success*.

Failed At:: The date and time the operation failed. The console displays this field only when the status is *Failed*.

Duration:: The total time the operation ran.

Stopped At:: The date and time you stopped the operation. The console displays this field only when the status is *Stopped*.

Config File:: Downloads the `ImageSetConfiguration` YAML file used for the operation.

Error:: An alert that shows the error message for a failed operation. The console displays this field only when the status is *Failed*.

Operation Statistics:: Summary values for the operation. The values include the following:
+
* *Images Mirrored*
* *Operators Mirrored*
* *Total Size*
* *Platform Images*
* *Additional Images*
* *Helm Charts*

To export or delete entries in the Operations list, use the following buttons:

Export CSV:: Downloads the Operations list as a CSV file.

Delete Selected:: Removes the entries that you selected. Each entry has a checkbox, and the checkbox in the header row selects all entries.

Delete All:: Removes every operation in the current filter, including entries that you did not check.
