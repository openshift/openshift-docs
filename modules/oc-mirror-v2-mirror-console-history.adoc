= Operation history

[role="_abstract"]
The *History* page in the OpenShift Mirror Console lists mirror operations with name, configuration file, status, start time, and duration. You can filter the list by status and export the history as a CSV file.

The *History* page opens an *Operations* list of mirror operations. By default, the filter shows *All Operations*. You can filter the list by status. Click *Export CSV* to download the history. Click *Delete All* to remove all history entries from the list.

Each entry in the list includes the following information:

Operation:: The name of the mirroring operation, including a unique identifier.

Config:: The `ImageSetConfiguration` file used for the operation. Click the file name to open the configuration.

Status:: The result of the operation. Displays one of the following statuses:

* *Successful* — The operation completed without errors.
* *Failed* — The operation did not complete successfully.
* *Stopped* — The operation was manually stopped before it was completed.

Started:: The date and time the operation began.

Duration:: The total time the operation ran.

Expand an operation to view *Operation Details*, which can include the following information:

Name:: The operation name and unique identifier.

Status:: The result of the operation.

Started:: The date and time the operation began.

Failed At:: The date and time the operation failed. Appears when the status is *Failed*.

Duration:: The total time the operation ran.

Config File:: The `ImageSetConfiguration` file used for the operation.

Error:: The error message for a failed operation. Appears when the status is *Failed*.

Operation Statistics:: Summary values for the operation, such as *Images Mirrored*.
