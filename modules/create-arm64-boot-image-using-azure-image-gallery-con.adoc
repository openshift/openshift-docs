= Create a 64-bit ARM boot image by using the {azure-short} Compute Gallery

[role="_abstract"]
To add 64-bit ARM compute nodes to an {azure-short} cluster, upload the {op-system} VHD to a storage account and publish it as a versioned image in an {azure-short} Compute Gallery. Compute machine sets can then reference that image when they provision virtual machines.
