= Recover from an incomplete execution

[role="_abstract"]
When a remediation process is interrupted, inspect cluster resources and manually revert partial changes to preserve cluster stability.

.Procedure

. Check cluster resources and recent events to determine applied changes:
+
[source,terminal]
----
$ oc get pods --all-namespaces
----
+
[source,terminal]
----
$ oc get events --sort-by='.lastTimestamp'
----

. Inspect run details and execution logs to identify completed and interrupted steps:
+
[source,terminal]
----
$ oc agentic run get <run_id>
----
+
[source,terminal]
----
$ oc agentic run logs <run_id> --step=Execution
----

. Manually revert partially applied changes based on the remediation steps listed in the run details.

. If you cannot safely determine or restore cluster state, open a case with Red{nbsp}Hat Support.
