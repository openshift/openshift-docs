= Remove no-longer used machine config objects

[role="_abstract"]
You can remove old, unused rendered machine configs by using the `oc adm prune renderedmachineconfigs` command. By removing these objects, you can free up disk space and reduce performance issues. You can delete a specific number of unused rendered machine configs or all of them.
