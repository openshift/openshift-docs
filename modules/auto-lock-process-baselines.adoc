= Configuring auto-lock for process baselines

[role="_abstract"]
You can configure {product-title} ({product-title-short}) to automatically lock process baselines when they leave the observation period. You must enable auto-lock feature in both Central and in the secured cluster. 

Follow these guidelines when using auto-lock:

* Central enables the feature by default, and the secured clusters disable it by default. Therefore, enabling the feature does not require restarting Central. However, changing the state of the feature in Central does require a restart of Central.
* The feature only applies to process baselines for secured clusters that enable it.
* Disabling the feature after enabling it does not unlock process baselines that the feature locked.
* Enabling the feature does not lock process baselines that left the observation period before you enabled the feature.

.Procedure

. In the {ocp} web console, go to the {product-title-short} Operator page.
. In the top navigation menu, select *Secured Cluster*.
. Click the instance name, for example, *stackrox-secured-cluster-services*.
. Use one of the following methods to change the setting:
* In the *Form view*, under *Process baselines settings* -> *Auto Lock*, select *Enabled* or *Disabled*.
* Click *YAML* to open the YAML editor and locate the `spec.processBaselines.autoLock` attribute. Change to `Enabled` or `Disabled`.
. Click *Save.*
. To enable or disable the feature in Central, set the `ROX_AUTO_LOCK_PROCESS_BASELINES` environment variable. The default value is `true`.
