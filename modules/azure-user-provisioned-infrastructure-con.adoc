= Configure image registry storage on {azure-short} user-provisioned infrastructure

[role="_abstract"]
Save your container images to a durable storage location by configuring the built-in image registry to use dedicated {azure-short} storage. This setup provides persistent, scalable storage for your registry that is separate from ephemeral cluster storage.
