= Configure role-based permissions for {kueue-name}

[role="_abstract"]
You can configure role-based access control (RBAC) for your {kueue-name} deployment to control which users can create specific {kueue-name} objects. The {kueue-name} Operator deploys default cluster roles for batch administrators and batch users that you bind to your own users and groups.
