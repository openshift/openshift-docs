= Image versions

[role="_abstract"]
You can manually pull, retag, and push {rh-rhacs-first} images to your registry. The current version includes the following images:


.{product-title} images
[%header,cols="1,1,2"]
|===
|Image |Description |Current version

|Main
|Includes Central, Sensor, Admission controller, and Compliance components. Also includes `roxctl` for use in continuous integration (CI) systems.
a|`registry.redhat.io/advanced-cluster-security/rhacs-main-rhel9:{rhacs-version}`

|Central DB
|PostgreSQL instance that provides the database storage for Central.
a|`registry.redhat.io/advanced-cluster-security/rhacs-central-db-rhel9:{rhacs-version}`

//NOT IN 5.0
//Scanner
//Scans images and nodes.
//`registry.redhat.io/advanced-cluster-security/rhacs-scanner-rhel9:{rhacs-version}`
//`registry.redhat.io/advanced-cluster-security/rhacs-scanner-slim-rhel9:{rhacs-version}`

//Scanner DB
//Stores image scan results and vulnerability definitions.
//`registry.redhat.io/advanced-cluster-security/rhacs-scanner-db-rhel9:{rhacs-version}`

|Scanner V4
|Scans images.
a|`registry.redhat.io/advanced-cluster-security/rhacs-scanner-v4-rhel9:{rhacs-version}`

|Scanner V4 DB
|Stores image scan results and vulnerability definitions for Scanner V4.
a|`registry.redhat.io/advanced-cluster-security/rhacs-scanner-v4-db-rhel9:{rhacs-version}`

|Collector
|Collects runtime activity in Kubernetes or {ocp} clusters.
a| `registry.redhat.io/advanced-cluster-security/rhacs-collector-rhel9:{rhacs-version}`

| Fact
| `registry.redhat.io/advanced-cluster-security/rhacs-fact-rhel9:5.0.0`
| Image used by the {product-title-short} Compliance Operator to run compliance checks and collect node configuration facts.

| Operator
| `registry.redhat.io/advanced-cluster-security/rhacs-rhel9-operator:5.0.0`
| Image for the {produc-title-short} Operator, used to deploy and manage {product-title-short} components on Red Hat {ocp}.

| roxctl
| `registry.redhat.io/advanced-cluster-security/rhacs-roxctl-rhel9:5.0.0`
| Containerized version of the `roxctl` command-line interface tool, used for performing administrative and CI/CD tasks.

| Operator bundle
| `registry.redhat.io/advanced-cluster-security/rhacs-operator-bundle:5.0.0`
| Container image containing the Operator Lifecycle Manager (OLM) metadata bundle required to install and manage the {product-title-short} Operator.

|===
