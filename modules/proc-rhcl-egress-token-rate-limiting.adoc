= Apply a global token limit to egress traffic

[role="_abstract"]
Cap the total number of artificial intelligence (AI) tokens that all workloads can consume through an egress `Gateway` object by applying a `TokenRateLimitPolicy` custom resource (CR) to the `HTTPRoute` object of the external AI service.

.Prerequisites

include::snippets/egress-gateway-prereqs.adoc[]
include::snippets/egress-ai-service-prereqs.adoc[]

.Procedure

. Export the egress `Gateway` object IP address by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ export EGRESS_IP=$(oc get gtw _<kuadrant_egressgateway>_ -n _<gateway_system>_ \
    -o jsonpath='{.status.addresses[0].value}')
----
+
Replace `_<kuadrant_egressgateway>_` with the name of your egress `Gateway` object.

. Create a `TokenRateLimitPolicy` CR that targets the `HTTPRoute` object of your external AI service by using the following example:
+
[source,yaml,subs="+quotes"]
----
apiVersion: kuadrant.io/v1alpha1
kind: TokenRateLimitPolicy
metadata:
  name: _<ai_token_limit>_
  namespace: _<gateway_system>_
spec:
  targetRef:
    group: gateway.networking.k8s.io
    kind: HTTPRoute
    name: _<ai_external>_
  limits:
    global:
      rates:
        - limit: 100
          window: 1m
----
+
* Replace the `metadata.name` value with the name of your token rate limit policy.
* Replace the `metadata.namespace` value with the namespace where you applied your egress `Gateway` object.
* Replace the `spec.targetRef.name` value with the name of the `HTTPRoute` object of your external AI service.
* The `spec.limits.global.rates` setting caps token consumption across all workloads at 100 tokens per minute, regardless of which workload sends the request.

. Apply the `TokenRateLimitPolicy` CR by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc apply -f _<ai_token_limit>_
----
+
Replace `_<ai_token_limit>_` with the name of the file that holds your token rate limit policy.

. Wait for the policy to be accepted by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc wait --timeout=60s tokenratelimitpolicy/_<ai_token_limit>_ -n _<gateway_system>_ \
    --for=jsonpath='{.status.conditions[?(@.type=="Accepted")].status}'=True
----

. Wait for the policy to be enforced by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc wait --timeout=60s tokenratelimitpolicy/_<ai_token_limit>_ -n _<gateway_system>_ \
    --for=jsonpath='{.status.conditions[?(@.type=="Enforced")].status}'=True
----

.Verification

. Send a chat completion request through the egress `Gateway` object by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc exec test-client -n egress-test -- \
    curl -s -H "Host: _<api.example.com>_" \
         -H "Content-Type: application/json" \
         -X POST http://${EGRESS_IP}/v1/chat/completions \
         -d '{"model": "_<model_name>_", "messages": [{"role": "user", "content": "What is Kubernetes?"}], "max_tokens": 100, "stream": false, "usage": true}'
----
+
* Replace `_<api.example.com>_` with the hostname of your external AI service.
* Replace `_<model_name>_` with a model that your external AI service provides.
* The response body has a `usage.total_tokens` field. Each request consumes that number of tokens from the 100 token budget.

. Send requests in a loop until the gateway rejects them by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ for i in $(seq 1 20); do
    CODE=$(oc exec test-client -n egress-test -- \
        curl -s -o /dev/null -w "%{http_code}" \
             -H "Host: _<api.example.com>_" \
             -H "Content-Type: application/json" \
             -X POST http://${EGRESS_IP}/v1/chat/completions \
             -d '{"model": "_<model_name>_", "messages": [{"role": "user", "content": "Hello"}], "max_tokens": 100, "stream": false, "usage": true}')
    echo "Request $i: HTTP $CODE"
    [ "$CODE" = "429" ] && break
  done
----
+
After the cumulative token count exceeds 100, the gateway rejects further requests with a `429` status code until the one-minute window resets.

.Next steps

* Before you configure per-workload limits, delete the global policy by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc delete tokenratelimitpolicy _<ai_token_limit>_ -n _<gateway_system>_
----
