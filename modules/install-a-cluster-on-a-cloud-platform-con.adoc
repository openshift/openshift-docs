= Install a cluster on a cloud platform

[role="_abstract"]
Installing {product-title} with installer-provisioned infrastructure on a public cloud follows the same journey on every supported cloud provider. You generate an `install-config.yaml` file, size the cluster, customize the configuration and network, supply cloud credentials, run the installation program, and log in to the cluster that it creates.

Only the details change from cloud to cloud: the machine types you can choose, the DNS service the cluster uses, and the credential model the Cloud Credential Operator applies. Follow the supplement for your cloud provider.

Before you begin, set up your installation host by following "Prepare to install OpenShift".
