= About enhanced metrics in {microshift-short}

[role="_abstract"]
Enhanced metrics in {microshift-short} are optional Kubernetes metric exporters that expose Prometheus-compatible endpoints through cluster Services. You can install each exporter individually to align edge monitoring with metrics used in {product-title} clusters.

{microshift-short} does not deploy the full {product-title} Cluster Monitoring Operator (CMO) stack, such as Prometheus or Alertmanager. Instead, enhanced metrics reuse OpenShift-built container images for the following optional components:

node-exporter::
Exposes hardware and operating system metrics, such as CPU, memory, disk, and network utilization.

metrics-server::
Provides the Kubernetes resource metrics API so that you can run `oc top nodes` and `oc top pods`.

kube-state-metrics::
Exposes metrics about the state of Kubernetes API objects, such as deployments, pods, and nodes.

When you install an enhanced metrics RPM package, {microshift-short} deploys the corresponding component into the `openshift-monitoring` namespace. Each exporter exposes a metrics endpoint that external tools, such as a locally running OpenTelemetry Collector or a remote Prometheus database, can scrape.

Installing enhanced metrics packages is independent of installing the `microshift-observability` RPM. You can use enhanced metrics without deploying the OpenTelemetry Collector, and you can install observability without installing any enhanced metrics exporters.
