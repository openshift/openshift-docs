= Finding deployments affected by a specific CVE

[role="_abstract"]
You can search for deployments that a specific Common Vulnerabilities and Exposures (CVE) affects.

|===
| Query | Example

| `CVE:<CVE_number>`
| `CVE:CVE-2018-11776`
|===
