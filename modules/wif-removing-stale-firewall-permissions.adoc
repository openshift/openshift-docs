= Remove stale firewall permissions from Workload Identity Federation service accounts

[role="_abstract"]
If you have an existing Workload Identity Federation (WIF) configuration created with a version earlier than 4.21, the `osd_deployer` and `openshift_gcp_ccm` custom roles might still include `compute.firewalls.create` and `compute.firewalls.delete` permissions. Remove these stale permissions from both roles to align with the reduced permission model introduced in version 4.21.

.Prerequisites

* You have created the required firewall rules for your cluster. For more information, see _Creating firewall rules for reduced Workload Identity Federation permissions on {gcp-short}_ in the _Additional resources_ section.

.Procedure

. Set the `PROJECT_ID` environment variable to your {gcp-full} project:
+
[source,terminal]
----
$ PROJECT_ID=<project_id>
----

. Remove stale firewall permissions from the `osd_deployer` role:

.. Retrieve the existing role definition:
+
[source,terminal]
----
$ gcloud iam roles describe \
  osd_deployer_v4.19 \
  --project=$PROJECT_ID \
  --format=yaml > /tmp/deployer_role.yaml
----
+
.. Remove the firewall permissions:
+
[source,terminal]
----
$ cat /tmp/deployer_role.yaml | \
grep -v "compute.firewalls.create" | \
grep -v "compute.firewalls.delete" > /tmp/updated_deployer_role.yaml
----
+
.. Review the changes:
+
[source,terminal]
----
$ diff /tmp/deployer_role.yaml /tmp/updated_deployer_role.yaml
----
+
.. Update the role:
+
[source,terminal]
----
$ gcloud iam roles update \
  osd_deployer_v4.19 \
  --project=$PROJECT_ID \
  --file=/tmp/updated_deployer_role.yaml
----

. Remove stale firewall permissions from the `openshift_gcp_ccm` role:

.. Retrieve the existing role definition:
+
[source,terminal]
----
$ gcloud iam roles describe \
  openshift_gcp_ccm_v4.19 \
  --project=$PROJECT_ID \
  --format=yaml > /tmp/ccm_role.yaml
----
+
.. Remove the firewall permissions:
+
[source,terminal]
----
$ cat /tmp/ccm_role.yaml | \
grep -v "compute.firewalls.create" | \
grep -v "compute.firewalls.delete" > /tmp/updated_ccm_role.yaml
----
+
.. Review the changes:
+
[source,terminal]
----
$ diff /tmp/ccm_role.yaml /tmp/updated_ccm_role.yaml
----
+
.. Update the role:
+
[source,terminal]
----
$ gcloud iam roles update \
  openshift_gcp_ccm_v4.19 \
  --project=$PROJECT_ID \
  --file=/tmp/updated_ccm_role.yaml
----

.Verification

* Verify that the `osd_deployer` role no longer includes firewall permissions:
+
[source,terminal]
----
$ gcloud iam roles describe osd_deployer_v4.19 --project=$PROJECT_ID --format="value(includedPermissions)" | grep "compute.firewalls"
----
+
The command returns no output if the permissions were removed successfully.

* Verify that the `openshift_gcp_ccm` role no longer includes firewall permissions:
+
[source,terminal]
----
$ gcloud iam roles describe openshift_gcp_ccm_v4.19 --project=$PROJECT_ID --format="value(includedPermissions)" | grep "compute.firewalls"
----
+
The command returns no output if the permissions were removed successfully.
