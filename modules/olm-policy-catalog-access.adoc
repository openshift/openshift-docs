= Operator catalog access control

[role="_abstract"]
Catalogs in the default `openshift-marketplace` namespace make Operators available across the cluster. Other catalogs make Operators available only in the namespace containing the catalog. Catalog selection does not limit the permissions used to install or run an Operator.

Disabling a global catalog changes catalog availability across the cluster. Creating a catalog in an Operator installation namespace does not remove access to other catalogs in the global catalog namespace.

To provide curated catalogs for delegated installations, take the following actions:

* Review permissions granted to the Operator group service account, the service accounts used by installed Operators, and users in the installation namespace.
* Review permissions to create or modify `CatalogSource` objects in the global catalog namespace and the Operator installation namespaces.
* Review any custom catalogs in `openshift-marketplace` for Operators and versions outside the curated selection.
* Create curated catalogs in the namespaces containing the Operator groups used for delegated installations.
* Disable the default global catalogs.
