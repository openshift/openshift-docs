= Adding labels

[role="_abstract"]
To add labels when you process a template with the CLI on your {product-title} cluster, pass label selectors to the `oc process` command. The labels specified in the template are applied to every object that is generated from the template.

Labels are used to manage and organize generated objects, such as pods.

.Procedure

* Add labels in the template by running the following command:
+
[source,terminal]
----
$ oc process -f <filename> -l name=otherLabel
----
