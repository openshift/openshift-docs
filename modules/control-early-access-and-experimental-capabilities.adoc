= Control early-access and experimental capabilities

[role="_abstract"]
Technology Preview features are not functionally complete, so you decide which ones reach your users. Set the environment variable behind a feature flag on the deployment, Helm chart, or Operator custom resource, then confirm the change in the `/v1/featureflags` endpoint.
