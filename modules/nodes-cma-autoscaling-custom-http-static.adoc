= Configure static HTTP routes

[role="_abstract"]
You can answer selected requests, such as health checks, without scaling the workload up from zero replicas. A static route on an `InterceptorRoute` resource is excluded from the scaling metrics.

Use `responseMode: WhenUnavailable` when the real workload should answer the path while it is running, and a static response should be returned while it is scaled to zero. This is the default. Use `responseMode: Always` when the interceptor must return the static response even if the workload is running.

A cold-start placeholder is different. A placeholder is a temporary response for requests that should still scale the workload. A static route never scales the workload.

.Prerequisites

* An `InterceptorRoute` resource exists for the workload.

.Procedure

. Add `spec.staticRoutes` to the `InterceptorRoute` resource. The following example returns HTTP `200` for `/healthz` while the workload has no ready pods, and forwards `/healthz` to the workload when it is ready:
+
.Example static health check
[source,yaml]
----
apiVersion: http.keda.sh/v1beta1
kind: InterceptorRoute
metadata:
  name: sample-app
  namespace: my-namespace
spec:
  target:
    service: sample-app
    port: 8080
  scalingMetric:
    concurrency:
      targetValue: 100
  staticRoutes:
    - rules:
        - paths:
            - value: /healthz <1>
      response:
        statusCode: 200 <2>
        body: OK <3>
----
<1> Specifies the path prefix that must not trigger autoscaling. You can also match `hosts` and `headers` in the same rule.
<2> Specifies the status code to return when the static response is used.
<3> Specifies the response body.

. To return a static response even when the workload is available, set `responseMode` to `Always`. For example, use this mode for a maintenance response:
+
[source,yaml]
----
staticRoutes:
  - rules:
      - paths:
          - value: /
    responseMode: Always <1>
    response:
      statusCode: 503
      body: Unavailable
----
<1> Always returns the static response. `WhenUnavailable` returns it only while the target has no ready pods.

. Apply the updated resource by running the following command:
+
[source,terminal]
----
$ oc apply -f interceptorroute.yaml
----
