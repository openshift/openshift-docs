= Enable FIPS mode on your nodes

[role="_abstract"]
To meet federal cryptographic standards, you can run {product-title} in FIPS mode so that the cluster uses only FIPS-validated cryptographic modules. FIPS mode is selected when you install the cluster and applies to every node.
