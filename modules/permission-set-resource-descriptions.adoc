= Clearer write permission descriptions in permission sets

// JIRA: ROX-32456

[role="_abstract"]
The {product-title-short} portal was updated to add or improve the resource descriptions in permission sets. These fields now explain what write access allows for each resource. For example, with write access to the `Image` resource, you can trigger image scans and remove image information.
