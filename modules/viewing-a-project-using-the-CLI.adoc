= Viewing a project using the CLI

[role="_abstract"]
When viewing projects, you are restricted to seeing only the projects you have
access to view based on the authorization policy.

.Procedure

. To view a list of projects, enter the following command:
+
[source,terminal]
----
$ oc get projects
----

. To change from the current project to a different project for CLI operations, enter the following command. 
The specified project is then used in all subsequent operations that manipulate project-scoped content.
+
[source,terminal]
----
$ oc project <project_name>
----
