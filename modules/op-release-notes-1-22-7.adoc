= Release notes for {pipelines-title} 1.22.7

[role="_abstract"]
With this update, {pipelines-title} General Availability (GA) 1.22.7 is available on {OCP} 4.14, 4.16, and later supported versions.

[id="fixed-issues-1-22-7_{context}"]
== Fixed issues

.Triggers

//SRVKP-14556
Tekton Triggers pods enter CrashLoopBackOff state due to missing ConfigMap::
Before this update, upgrading to {pipelines-shortname} 1.22.6 caused Tekton Triggers components (`tekton-triggers-controller`, `tekton-triggers-core-interceptors`, and `tekton-triggers-webhook`) to fail due to a missing `config-triggers-core-interceptors` ConfigMap. As a consequence, the pods entered a `CrashLoopBackOff` state and `TektonConfig` remained in a not-ready state. With this update, the missing ConfigMap is reconciled correctly during deployment and upgrade. As a result, Tekton Triggers components start successfully and transition to a ready state.
