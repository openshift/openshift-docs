= Use the oc CLI

[role="_abstract"]
The `oc` CLI tool provides a superset of `kubectl` functionality for interacting with {microshift-short}. You can use `oc` to view resource status, retrieve logs, and run commands against the cluster. {microshift-short} supports a subset of `oc` commands that are relevant to single-node edge deployments.
