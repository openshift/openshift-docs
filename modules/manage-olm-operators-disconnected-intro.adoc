= Manage OLM Operators in a disconnected environment

[role="_abstract"]
To install and update Operators in a disconnected cluster, you must mirror Operator catalogs and configure Operator Lifecycle Manager (OLM) to use your local content. This ensures Operators remain available without direct internet connectivity.
