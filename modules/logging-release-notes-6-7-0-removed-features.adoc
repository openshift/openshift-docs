= Removed features

[role="_abstract"]
The following Prometheus alerts are removed in {LoggingProductName} 6.7.0 as part of the BoltDB storage backend removal.

*Log storage*

* The `LokiStorageSlowWrite` and `LokiStorageSlowRead` Prometheus alerts are removed. These alerts relied on BoltDB Shipper metrics that are removed in this release to prepare for Loki 4.0 compatibility. No replacement alerts are provided.
