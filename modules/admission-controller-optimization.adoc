= Admission controller latency optimization

// JIRA: ROX-36410

[role="_abstract"]
This release improves admission controller latency by allowing scan reuse for tag-based admission review requests when image digests remain the same.

You can pre-scan by tag using the `roxctl image scan <tag>` command. With the improved admission controller behavior in this release, the admission controller checks if a previously scanned digest exists for tag-based image references. If scan results are already available, {product-title-short} does not scan again. As a result, admission controller latency and scanner load are significantly reduced for frequently deployed images that are referenced by tags and have stable digests.
