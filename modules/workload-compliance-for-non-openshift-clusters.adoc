= Workload compliance for non-OpenShift clusters

[role="_abstract"]
For non-OpenShift clusters, {product-title} ({product-title-short}) provides workload compliance through standard and custom security policies rather than through the default compliance profiles that earlier releases provided.

{product-title-short} previously provided default compliance profiles to scan user workloads on non-OpenShift clusters. {product-title-short} no longer includes this functionality.

You can use standard {product-title-short} security policies to replace most of the checks that earlier compliance scans performed. Tag specific security policies with the relevant compliance benchmark controls. The {product-title-short} policy engine then continuously evaluates your workloads against these tagged policies and reports a pass or fail result.
