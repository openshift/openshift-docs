== Fixed issues

* Before this update, Vital Product Data (VPD) would incorrectly think a custom resource pool would require additional privileges instead of being read-only. With this release, this issue is fixed. As a result, custom resource pools are correctly recognized as read-only. (link:https://issues.redhat.com/browse/OCPBUGS-88024[OCPBUGS-88024])

* Before this update, a programming error forced load balancers to always use control plane instance groups rather than treating them as optional. As a consequence, load balancers included control plane nodes even when they had the `node.kubernetes.io/exclude-from-external-load-balancers` label. With this release, the logic for reusing the instance groups is corrected. As a result, nodes with the `node.kubernetes.io/exclude-from-external-load-balancers` label are correctly excluded from load balancers. (link:https://issues.redhat.com/browse/OCPBUGS-99227[OCPBUGS-99227])

* Before this update, upstream GitHub Actions workflow and issue template files that were not used in the {product-title} downstream fork were present in the release branches. These files relied on Prow and the `ci-operator` tool, rather than a GitHub Actions workflow. As a consequence, the `golangci-lint` job failed on every pull request. With this release, these unused files are removed from the release branches. As a result, the lint job does not fail on pull requests.  (link:https://issues.redhat.com/browse/OCPBUGS-123527[OCPBUGS-123527])
