= Provisioning API operations

[role="_abstract"]
The Provisioning API manages the full lifecycle of provisioning requests. Use this API to create, retrieve, update, and delete provisioning requests that drive cluster provisioning, scaling, configuration changes, and upgrades.

All endpoints use the base path `/o2ims-infrastructureProvisioning/v1`.

The `provisioningRequestId` value is a UUID that you generate and assign as the `metadata.name` of the `ProvisioningRequest` custom resource (CR) when you create it.

.Provisioning API endpoints
[cols="1,3,3",options="header"]
|===
|Method |Path |Description

|`GET`
|`/provisioningRequests`
|List all provisioning requests

|`GET`
|`/provisioningRequests/{provisioningRequestId}`
|Get a specific provisioning request

|`POST`
|`/provisioningRequests`
|Create a provisioning request

|`PUT`
|`/provisioningRequests/{provisioningRequestId}`
|Update a provisioning request (full replace)

|`DELETE`
|`/provisioningRequests/{provisioningRequestId}`
|Delete a provisioning request and its managed cluster
|===
