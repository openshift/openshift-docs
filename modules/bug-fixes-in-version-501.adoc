= Bug fixes and security updates in version 5.0.1

[role="_abstract"]
This release includes the following bug fixes:

//ROX-36432
* Before this update, some nodes displayed stale scan timestamps even though Central continued to update the node regularly. This occurred when users created the default Scanner V4 integration before node scanning was available and it lacked the NODE_SCANNER category. With this release, Red{nbsp}Hat fixed this issue so that node scan timestamps now update correctly.

//ROX-37244
* Before this update, the Scanner V4 matcher could run out of memory and crash when matching vulnerabilities in certain workloads. With this release, Red{nbsp}Hat reduced the memory that the matcher uses during vulnerability matching. As a result, the matcher is less likely to run out of memory and crash.

//ROX-37315
* Before this update, when you added an image exclusion to a policy, you could incorrectly configure the policy for both the build and deploy stages. This caused {product-title-short} to not evaluate deployments. With this release, Red{nbsp}Hat fixed policy exclusions so that image exclusions apply only at the build stage. 

//ROX-37694
* Before this update, `NetworkPolicy` YAML files viewed or exported from the {product-title-short} portal were missing the `apiVersion` field, which made the exported YAML invalid for use with tools such as `oc`. With this release, Red{nbsp}Hat fixed the `NetworkPolicy` YAML file generation. As a result, users can apply exported `NetworkPolicy` YAML files directly to clusters.

//ROX-37721
* Before this update, creating a policy from search results caused the {product-title-short} portal to crash when you used search filters that the portal could not convert into policy criteria. With this fix, the portal now provides an error message instead of crashing.

//ROX-37779
* Before this update, deployment details in the *Vulnerability Management* window did not include container information, unlike deployment details in other views. With this release, Red{nbsp}Hat added container information to the *Vulnerability Management* deployment details. 

This release also addresses the following security vulnerabilities:

//ROX-37849
* klauspost/compress: Denial of Service via crafted `zstd` compressed input (link:https://access.redhat.com/security/cve/CVE-2026-116591[CVE-2026-116591])
