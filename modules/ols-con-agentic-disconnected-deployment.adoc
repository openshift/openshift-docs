= Deploy Agentic {ols-long} in disconnected environments

[role="_abstract"]
You can deploy Agentic {ols-long} in disconnected or air-gapped clusters that do not have full access to the internet. In a disconnected environment, you host the large language model (LLM) locally, typically with a vLLM server provided by {rhelai}, and you mirror the required container images into your internal registry.

For agentic and tool-calling workloads in a disconnected environment, use the Anthropic provider pathway with a locally hosted vLLM server. The Anthropic-compatible `/v1/messages` endpoint is available in vLLM version 0.24, the version currently supported with {rhelai}, and this pathway helps ensure that tool calls and structured outputs work reliably. Avoid the OpenAI-compatible pathway for tool-calling workloads, because it can suppress tool calls on vLLM.

To deploy Agentic {ols-long} in a disconnected environment, complete the following tasks:

Mirror container images::
Mirror the {ols-long} Operator images and any required agentic deployment images into your internal registry. For more information, see "How to run on restricted networks without external access" and the {ocp-product-title} documentation about mirroring in disconnected environments.

Host the model locally::
Deploy a vLLM server, version 0.24 or later, that serves your model and exposes the Anthropic-compatible `/v1/messages` endpoint. The model is remote to the agentic workloads and must be reachable at a cluster-internal URL over a secure connection. Preparing the model and the serving platform is the responsibility of your serving platform, such as {rhelai}.

Configure the Anthropic provider::
Create an `LLMProvider` CR of type `Anthropic` whose `spec.anthropic.url` field points to the cluster-internal base URL of your vLLM server. Agentic {ols-long} calls the `/v1/messages` endpoint against this URL internally. For bearer token authentication, store the token in the credentials secret as `ANTHROPIC_AUTH_TOKEN`, and set `ANTHROPIC_API_KEY` to any non-empty placeholder value. For the full procedure, see "Connect a vLLM server through the Anthropic provider".

[NOTE]
====
In a disconnected environment, prepare the model, images, and endpoints while the cluster still has the required access. After the environment is isolated, the agentic workloads do not download packages, model artifacts, tools, or binaries from an external network.
====
