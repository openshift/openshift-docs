= Understand traffic flow among networking components

[role="_abstract"]
Traffic in a {product-title} cluster passes between clients, nodes, pods, and services, and enters and leaves the cluster through routes and ingress. Understanding how traffic flows between these components helps you identify where connectivity problems occur.
