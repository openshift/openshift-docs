= Collect comprehensive data for vendor support

[role="_abstract"]
When you cannot resolve a cluster issue yourself, you collect comprehensive diagnostic data so that Red{nbsp}Hat support can reproduce and diagnose the problem. You use tools such as `oc adm must-gather`, the Insights Operator log gatherer, and targeted image-specific gather commands to capture logs, events, and cluster state.
