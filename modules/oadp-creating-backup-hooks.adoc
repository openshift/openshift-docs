= Creating backup hooks

[role="_abstract"]
You create backup hooks to run commands in a container in a pod by editing the `Backup` custom resource (CR).

_Pre_ hooks run before the pod is backed up. _Post_ hooks run after the backup.

.Procedure

* Add a hook to the `spec.hooks` block of the `Backup` CR, as in the following example:
+
[source,yaml]
----
apiVersion: velero.io/v1
kind: Backup
metadata:
  name: <backup>
  namespace: openshift-adp
spec:
  hooks:
    resources:
      - name: <hook_name>
        includedNamespaces:
        - <namespace>
        excludedNamespaces:
        - <namespace>
        includedResources:
        - pods
        excludedResources: []
        labelSelector:
          matchLabels:
            app: velero
            component: server
        pre:
          - exec:
              container: <container>
              command:
              - /bin/uname
              - -a
              onError: Fail
              timeout: 30s
        post:
...
----
+
where:
+
`includedNamespaces`:: Optional: Specifies namespaces to which the hook applies. If this value is not specified, the hook applies to all namespaces.
`excludedNamespaces`:: Optional: Specifies namespaces to which the hook does not apply.
`pods`:: Currently, pods are the only supported resource that hooks can apply to.
`excludedResources`:: Optional: Specifies resources to which the hook does not apply.
`labelSelector`:: Optional: The hook only applies to objects matching the label. If this value is not specified, the hook applies to all namespaces.
`pre`:: Array of hooks to run before the backup.
`container`:: Optional: If the container is not specified, the command runs in the first container in the pod.
`command`:: The entrypoint for the init container being added.
`onError`:: Allowed values for error handling are `Fail` and `Continue`. The default is `Fail`.
`timeout`:: Optional: How long to wait for the commands to run. The default is `30s`.
`post`:: Defines an array of hooks to run after the backup, with the same parameters as the pre-backup hooks.
