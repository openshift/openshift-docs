= Release notes for the {otel} 3.10.1

[role="_abstract"]
The {otel} 3.10.1 is available through the link:https://catalog.redhat.com/software/containers/rhosdt/opentelemetry-operator-bundle/615618406feffc5384e84400[{OTelOperator} 0.152.0] and is based on the open source link:https://opentelemetry.io/docs/collector/[OpenTelemetry] release 0.152.1.

[NOTE]
====
You can access some linked Jira tickets only with Red{nbsp}Hat credentials.
====

The {otel} 3.10.1 release has this known issue:

Automatic RBAC of the Operator fails::
The automatic Role-Based Access Control (RBAC) feature of the {OTelOperator} fails due to a regression. As a consequence, the Kubernetes Cluster Receiver fails.
+
To work around this problem, add these two entries to the `ClusterRole` object named `otelcontribcol`:
+
[source,yaml]
----
# ...
  resources:
# ...
  - persistentvolumeclaims
  - persistentvolumes
# ...
----
+
link:https://redhat.atlassian.net/browse/TRACING-6381[TRACING-6381]
