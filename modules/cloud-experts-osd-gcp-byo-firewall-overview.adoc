= Overview of the BYO firewall retrofit procedure

[role="_abstract"]
The retrofit procedure replaces platform-managed firewall rules that use {GCP} network tags with customer-managed rules that target WIF service accounts.

The high-level steps are:

. Create service-account-targeted BYO rules alongside the existing tag-targeted rules.
. Verify coexistence, ensuring both rule sets are active with no conflicts.
. Delete the platform-managed tag-targeted rules.
. Disable CCM firewall management so the Cloud Controller Manager does not recreate rules.
. Optionally, validate Day-2 operations such as scale-up and upgrades with BYO rules only.
