= Enrich Istio metrics with MCP context

[role="_abstract"]
If you use {service-mesh}, make your infrastructure metrics context-aware so that you can parse traffic performance directly by Model Context Protocol (MCP) server and tool operations.

When you deploy {mcpg} using {service-mesh} as your Gateway API provider, you can enrich standard Istio proxy metrics with MCP context by applying an Istio `Telemetry` custom resource. This adds `mcp_server_name` and `mcp_method` labels to metrics without requiring code changes or custom application metric definitions.

[IMPORTANT]
====
An Istio-based Gateway API provider that uses `gatewayClassName: istio` or {service-mesh} is required. Enriched Istio metrics are not supported on standard HAProxy-based OpenShift Ingress routes.
====

.Prerequisites

* You installed {mcpg} using an Istio-backed Gateway API implementation.
* You configured {mcpg} to set standard 2026 MCP routing headers on requests.

.Procedure

. Create an Istio `Telemetry` custom resource in your {mcpg} namespace using the 2026 standardized MCP HTTP headers:
+
.Example Telemetry resource for MCP context enrichment
[source,yaml,subs="+quotes"]
----
apiVersion: telemetry.istio.io/v1alpha1
kind: Telemetry
metadata:
  name: mcp-metrics-enrichment
  namespace: _<mcp_gateway_system>_
spec:
  metrics:
  - dimensions:
      mcp_server_name: request.headers["x-mcp-server-name"]
      mcp_method: request.headers["mcp-method"]
    overrides:
    - match:
        metric: ALL_METRICS
      tagOverrides:
        mcp_server_name:
          operation: UPSERT
        mcp_method:
          operation: UPSERT
----
+
* Replace `_<mcp_gateway_system>_` with the namespace of your {mcpg} deployment.
* The `dimensions:` field extracts values from the standard 2026 `Mcp-Method` and backend server routing headers.
* The `tagOverrides:` field with `UPSERT` operation attaches these metric labels across all Envoy-generated request metrics.

.Verification

. In the OpenShift web console, go to the *Observe > Metrics* view to query for Istio metrics using the enriched MCP labels:
+
[source,text]
----
istio_requests_total{mcp_method!=""}
----
+
A successful response returns time series containing `mcp_method` and `mcp_server_name` dimensions.
