= Using {azure-short} managed identities

[role="_abstract"]
To provide the identity that the installation program requires on {azure-short}, you can use a system-assigned or user-assigned managed identity.

If you are unable to use a managed identity, you can use a service principal.

[NOTE]
====
Use a user-assigned managed identity. System-assigned managed identities are no longer recommended. The {azure-short} SDK packages used by the {product-title} 4.21 installation program require that you provide the client ID explicitly, because it is no longer discovered automatically as in earlier versions.

You can continue to use a system-assigned managed identity by specifying its client ID in the installation program credentials.
====

.Procedure

. If you are using a system-assigned managed identity, complete the following steps:
.. Enable it on the virtual machine that you will run the installation program from.
.. Record its client ID. You require this value when installing the cluster.
. If you are using a user-assigned managed identity:
.. Assign it to the virtual machine that you will run the installation program from.
.. Record its client ID. You require this value when installing the cluster.
. Verify that the required permissions are assigned to the managed identity.
