= Deploy an egress gateway

[role="_abstract"]
Deploy the egress `Gateway` object and infrastructure to route outbound traffic from your cluster to an external service through a centralized gateway.

include::snippets/egress-gateway-ossm.adoc[]

.Prerequisites

include::snippets/egress-gateway-prereqs.adoc[]

.Procedure

. Create the egress `Gateway` object with a `ClusterIP` service type by using the following example:
+
[source,yaml,subs="+quotes"]
----
apiVersion: gateway.networking.k8s.io/v1
kind: Gateway
metadata:
  name: _<kuadrant_egressgateway>_
  namespace: _<gateway_system>_ # does this object have to be in the parent gateway ns we used at install?
  annotations:
    networking.istio.io/service-type: ClusterIP
spec:
  gatewayClassName: istio
  listeners:
    - name: http
      port: 80
      protocol: HTTP
      allowedRoutes:
        namespaces:
          from: All
----
+
* Replace the `metadata.name` value with the name of your egress `Gateway` object.
* Replace the `metadata.namespace` value with the namespace where you applied your egress `Gateway` object.
* You must use `istio` for the `gatewayClassName`.
+
include::snippets/egress-gateway-clusterip-v-lb.adoc[]

. Apply the CR by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc apply -f _<kuadrant_egressgateway>_
----
+
Replace `_<kuadrant_egressgateway>_` with the name of your egress `Gateway` object.

. Create the `ServiceEntry` resource to register the external service in the {service-mesh} service registry by using the following example:
+
[source,yaml,subs="+quotes"]
----
apiVersion: networking.istio.io/v1
kind: ServiceEntry
metadata:
  name: _<httpbin_external>_
  namespace: _<gateway_system>_
spec:
  hosts:
    - _<httpbin.org>_
  ports:
    - number: 443
      name: https
      protocol: HTTPS
  location: MESH_EXTERNAL
  resolution: DNS
----
+
* Replace the `metadata.name` value with the name of your external service.
* Replace the `metadata.namespace` value with namespace where you applied your egress `Gateway` object.
* Replace `_<httpbin_external>_` with the name of your external service.

. Apply the mesh service registry by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc apply -f _<httpbin_external>_
----
+
Replace `_<httpbin_external>_` with the name of your external service.

. Create the `DestinationRule` resource to configure TLS origination by using the following example:
+
[source,yaml,subs="+quotes"]
----
apiVersion: networking.istio.io/v1
kind: DestinationRule
metadata:
  name: _<httpbin_external_dr>_
  namespace: _<gateway_system>_
spec:
  host: _<httpbin.org>_
  trafficPolicy:
    tls:
      mode: SIMPLE
      sni: _<httpbin.org>_
----
+
* Replace the `metadata.name` value with name of the external `DestinationRule` CR.
* Replace the `metadata.namespace` value with the namespace where you applied the egress `Gateway` object.
* Replace `_<httpbin.org>_` with the external target service.

. Apply the `DestinationRule` CR by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc apply -f _<httpbin_external_dr>_
----
+
Replace `_<httpbin_external_dr>_` with the name of your external service.

. Create the `HTTPRoute` resource to route traffic through the `Gateway` object to the external service by using the following example:
+
[source,yaml,subs="+quotes"]
----
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: _<httpbin_external_httproute>_
  namespace: _<gateway_system>_
spec:
  parentRefs:
    - name: _<kuadrant_egressgateway>_
      namespace: _<gateway_system>_
  hostnames:
    - _<httpbin.org>_
  rules:
    - filters:
        - type: URLRewrite
          urlRewrite:
            hostname: _<httpbin.org>_
      backendRefs:
        - group: networking.istio.io
          kind: Hostname
          name: _<httpbin.org>_
          port: 443
----
+
* Replace the `metadata.name` value with name of the external `HTTPRoute` CR.
* Replace the `metadata.namespace` value with the namespace where you applied the egress `Gateway` object.
* Replace the `spec.parentRefs.name` value with the egress `Gateway` object name.
* Replace the `spec.parentRefs.namespace` value with namespace where you applied the egress `Gateway` object.
* Replace `_<httpbin.org>_` with the external target service.
* The `ServiceEntry` object provides the `Hostname` backend. The `URLRewrite` filter ensures that the correct `Host` header reaches the external service.

. Apply the CR by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc apply -f _<httpbin_external_httproute>_
----
+
Replace `_<httpbin_external_httproute>_` with the name of the `HTTPRoute` CR for your external service.

. Wait for the `Gateway` object to be ready by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc wait --timeout=5m -n _<gateway_system>_ gateway/_<kuadrant_egressgateway>_ --for=condition=Programmed
----
+
Replace `_<kuadrant_egressgateway>_` value with the egress `Gateway` object name.

. Export the `Gateway` object IP address for use in future procedures by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ export EGRESS_IP=$(oc get gtw _<kuadrant_egressgateway>_ -n _<gateway_system>_ \
    -o jsonpath='{.status.addresses[0].value}')
----
+
Replace `_<kuadrant_egressgateway>_` value with the egress `Gateway` object name.
