= Manage kernel modules across cluster nodes

[role="_abstract"]
The Kernel Module Management (KMM) Operator manages the loading, unloading, and lifecycle of out-of-tree kernel modules on your cluster nodes. Use KMM to unload modules cleanly, manage the lifecycle of Day 1 kmod images, and distribute kernel modules across multiple clusters from a central hub.
