= Add a network interface to a VM by using the web console

[role="_abstract"]
You can add a network interface to a virtual machine (VM) from the {product-title} web console and attach it to an existing network attachment definition. Restart or live migrate the VM to apply the change.

.Prerequisites

* You created a network attachment definition for the network.

.Procedure

. Navigate to *Virtualization* -> *VirtualMachines*.
. Click a VM to view the *VirtualMachine details* page.
. On the *Configuration* tab, click the *Network interfaces* tab.
. Click *Add network interface*.
. Enter the interface name and select the network attachment definition from the *Network* list.
. Click *Save*.
. Restart or live migrate the VM to apply the changes.
