= OCI 1.1 Referrers API support for image signatures

// JIRA: ROX-34488

[role="_abstract"]
Support is added for Cosign v3 signature discovery by using OCI 1.1 referrers, including Dead Simple Signing Envelope (DSSE) verification for sigstore bundle-format signatures.
