= Understand network policy types

[role="_abstract"]
{product-title} defines network policy through both cluster-scoped and namespace-scoped APIs. Understanding how `NetworkPolicy`, `AdminNetworkPolicy`, and `BaselineAdminNetworkPolicy` differ helps you choose the right API for each isolation requirement.
