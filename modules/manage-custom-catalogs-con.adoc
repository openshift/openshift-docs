= Manage custom catalogs

[role="_abstract"]
[.pr:openshift-enterprise .pr:openshift-origin .pr:microshift]#Cluster administrators#
[.pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp]#Administrators with the `dedicated-admin` role#
and Operator catalog maintainers can create and manage custom catalogs packaged using the bundle format on Operator Lifecycle Manager (OLM) in {product-title}.

[IMPORTANT]
====
Kubernetes periodically deprecates certain APIs and removes them in later releases. As a result, Operators are unable to use removed APIs starting with the version of {product-title} that uses the Kubernetes version that removed the API.
====
