== Resolved issues

Custom CA certificates no longer make other BSLs unavailable::
Before this update, adding a custom certificate authority (CA) certificate for one `BackupStorageLocation` (BSL) replaced the system CA bundle used by Velero. As a result, other BSLs that relied on system-trusted certificates became unavailable. With this release, the {oadp-short} Operator combines unique custom CA certificates from all BSLs and includes system CA certificates when custom certificates are present. As a result, you can use BSLs with custom and system-trusted certificates together.
