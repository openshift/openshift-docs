== Resolved issues

Custom CA certificates no longer make other BSLs unavailable::
Before this update, when image backup was enabled, configuring a custom certificate authority (CA) certificate for a `BackupStorageLocation` (BSL) caused Velero to use a CA bundle that excluded system CA certificates. As a result, other S3-compatible BSLs that relied on system-trusted certificates became unavailable. With this release, the {oadp-short} Operator combines custom CA certificates from AWS-provider BSLs in the DPA namespace with system CA certificates. As a result, S3-compatible BSLs that use custom and system-trusted certificates can operate together.
