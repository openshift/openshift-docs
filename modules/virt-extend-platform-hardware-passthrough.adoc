= Extend the platform with hardware passthrough

[role="_abstract"]
Add hardware passthrough capabilities to the platform so that VMs can directly access physical hardware, such as GPUs, specialized accelerators, and USB peripherals, for hardware-accelerated workloads with near-native performance.
