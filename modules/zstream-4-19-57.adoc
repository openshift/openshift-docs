== Fixed issues

The following issues are fixed for this release:

* Before this update, the Cluster Autoscaler's Cluster API provider could repeatedly reduce a node group's target size for the same pending `Machine`, potentially reducing the group to its minimum size. As a consequence, node groups could be scaled down to their minimum size while a single `Machine` was still pending, for example when cloud provider capacity was exhausted. With this release, the provider skips pending `Machine` objects already marked for deletion, and also skips stale pending-machine deletion requests for `Machine` objects that have since registered as nodes, so those nodes go through the normal scale-down checks. As a result, a pending `Machine` is counted only once for scale-down. (link:https://issues.redhat.com/browse/OCPBUGS-140550[OCPBUGS-140550])
