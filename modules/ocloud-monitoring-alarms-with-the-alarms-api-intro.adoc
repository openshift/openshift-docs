= Monitor infrastructure health with the Alarms API

[role="_abstract"]
You can monitor infrastructure and cluster health by querying alarms through the O-Cloud Manager Alarms API. The Alarms API aggregates alerts from {rh-rhacm} Observability into standardized alarm records. You can query, filter, and acknowledge alarms, and create subscriptions to receive real-time notifications when alarm states change.

[NOTE]
====
The Alarms API aggregates alerts from {rh-rhacm} Observability into standardized alarm records that conform to the O-RAN O2 IMS specification for the telecommunications use case.
====
