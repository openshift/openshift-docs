= Control access to cluster extension resources with {olmv1}

[role="_abstract"]
A cluster extension managed by {olmv1-first} can provide `CustomResourceDefinition` (CRD) objects that expose new cluster APIs.

Cluster administrators automatically have full access to these resources, but {olmv1} does not configure role-based access control (RBAC) for regular users, so you must define the policy that lets them create, view, or edit the extension's custom resources.
