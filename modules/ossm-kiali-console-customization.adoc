= Console defaults

[role="_abstract"]

You can set the time range, the refresh interval, the namespaces selected on first login, and the graph find and hide presets in the `Kiali` custom resource. User choices in the console override these defaults until the next reload, except for the namespace list, which resets to the configured set.

== Metrics duration and refresh

`metrics_per_refresh` is how far back the console queries metrics and traces. `refresh_interval` is how often the console reloads. The default duration is the shortest valid range, and the default refresh interval is 60 seconds.

[source,yaml]
----
spec:
  kiali_feature_flags:
    ui_defaults:
      metrics_per_refresh: "1m"
      refresh_interval: "15s"
----

Valid durations are `1m`, `2m`, `5m`, `10m`, `30m`, `1h`, `3h`, `6h`, `12h`, `1d`, `7d`, and `30d`. Valid refresh values are `pause`, `manual`, `10s`, `15s`, `30s`, `1m`, `5m`, and `15m`.

== Default namespaces

To open the console on a fixed set of namespaces, list them under `ui_defaults.namespaces`. A namespace that no longer exists is ignored.

[source,yaml]
----
spec:
  kiali_feature_flags:
    ui_defaults:
      namespaces:
      - istio-system
      - bookinfo
----

== Graph find, hide, and traffic

Find and hide presets appear in the graph toolbar. If you set your own list, it replaces the built-in presets, so include any default expression you still want. Set `auto_select` to `true` to apply a preset when the graph opens.

[source,yaml]
----
spec:
  kiali_feature_flags:
    ui_defaults:
      graph:
        find_options:
        - auto_select: false
          description: "Find: slow edges (> 1s)"
          expression: "rt > 1000"
        hide_options:
        - auto_select: false
          description: "Hide: healthy nodes"
          expression: "healthy"
        traffic:
          grpc: "requests"
          http: "requests"
          tcp: "sent"
----

Traffic rates come from {istio} telemetry. Only the `requests` source includes response codes, so health is calculated only when the graph uses request metrics. The graph can change when you switch the traffic source.

Valid values for `grpc` and `tcp` are `none`, `requests`, `sent`, `received`, and `total`. Valid values for `http` are `none` and `requests`.
