= Known issues

[role="_abstract"]
{ols-official} 1.1.2 contains a known issue where the initial installation and pod startup for the OKP RAG system takes additional time to complete indexing when upgrading from version 1.1.1 to 1.1.2.

The following issues are identified with {ols-official} 1.1.2:

* *Initial installation delay for the OKP RAG system*
+
When you upgrade from version 1.1.1 to 1.1.2, the initial installation and pod startup for the OKP RAG system takes additional time to complete indexing. Standard restarts take less time.
+
During this initial setup, {ols-long} is temporarily unavailable. You must wait for the indexing process to finish before expecting full RAG functionality.
+
Workaround: None.
