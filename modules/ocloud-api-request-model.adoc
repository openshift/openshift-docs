= O-Cloud Manager API request model

[role="_abstract"]
The O-Cloud Manager REST APIs are served over a single ingress route on the hub cluster with different paths routing to different backend services.

Base URL::
All APIs share a single hostname exposed through an {product-title} route on the hub cluster. Each API uses a versioned path prefix appended to this hostname. For example, the Inventory API base URL has the following form: `https://<route-hostname>/o2ims-infrastructureInventory/v2`


Authentication::
All API requests require a bearer token in the `Authorization` header. Each backend service independently validates the token before processing the request. For more information about acquiring a token, see the authentication procedures in the section "Prepare the O-Cloud Manager environment".

Payload conventions::
`PUT` operations replace the entire resource. Always retrieve the current resource with `GET`, modify the required fields, and then submit the full payload with `PUT`.

Schema discovery::
Use the Artifacts API to discover the parameters that a cluster template accepts before creating or updating a provisioning request. The `managedInfrastructureTemplates/{id}` endpoint returns the template including its `templateParameterSchema`, and the `managedInfrastructureTemplates/{id}/defaults` endpoint returns the preconfigured default values.

Filtering::
Most list endpoints support the `filter` query parameter. Filters use the syntax `(operator,field,value)` with multiple conditions separated by semicolons to apply `AND` logic.
+
.Supported filter operators
[cols="1,2",options="header"]
|===
|Operator |Description

|`eq`
|Equal to

|`neq`
|Not equal to

|`gt`
|Greater than

|`gte`
|Greater than or equal to

|`lt`
|Less than

|`lte`
|Less than or equal to

|`cont`
|Contains

|`ncont`
|Does not contain

|`in`
|One of the specified values

|`nin`
|Not one of the specified values
|===
+
Use slash-separated paths for nested fields, for example `extensions/<field_name>`. Values containing spaces must be surrounded by single quotes.
+
For examples of REST API requests that use the `filter` parameter, see "Discover O-Cloud resources with O-Cloud Manager APIs".

Field selection::
Use the `fields` query parameter to return only specific fields in the response. Use the `exclude_fields` query parameter to omit specific fields. Both parameters accept comma-separated lists with slash-separated paths for nested fields.
