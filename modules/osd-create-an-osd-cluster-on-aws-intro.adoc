= Create an OSD cluster on AWS

[role="_abstract"]
Create an {product-title} cluster on Amazon Web Services (AWS) by using your own AWS account. You prepare your account, set up access, and delete the cluster when you no longer need it.

Creating a cluster on AWS helps you to do the following:

* Run {product-title} on AWS infrastructure that you own and manage.
* Apply your organization's AWS account, network, and security standards to the cluster.
* Control the full lifecycle of the cluster, from creation through deletion.
