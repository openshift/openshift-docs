= Prerequisites for compute machines without {vmw-short} integration

[role="_abstract"]
Before you add bare-metal compute machines or virtual machines (VMs) without {vmw-short} integration to your {product-title} cluster, prepare the machines, network, and storage.

* You have an existing {product-title} cluster installed on {vmw-short}.
* You have bare-metal hardware or VMs with network connectivity to the existing cluster's machine network.
* You have configured DHCP with persistent IP addresses and hostname reservations for the new compute machines.
* You have configured forward and reverse DNS resolution for the new hostnames.
* You have obtained a {op-system-first} image that matches the target cluster version.
* You have migrated workloads that use the native {vmw-short} Container Storage Interface (CSI) driver to an alternative storage solution.
* You have disabled the native {vmw-short} CSI driver in the target cluster by setting `spec.managementState` to `Removed` in the `csi.vsphere.vmware.com` `ClusterCSIDriver` object.

[WARNING]
====
Disabling the native {vmw-short} CSI driver affects every node in the target cluster, including the existing {vmw-short} nodes. These nodes lose the ability to provision or attach {vmw-short} volumes. Migrate workloads that depend on these volumes before you disable the driver.
====
