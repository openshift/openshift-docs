= Configure gang scheduling for {kueue-name} jobs

[role="_abstract"]
You can use gang scheduling to ensure that a group, or gang, of related jobs starts only when all required resources are available. {kueue-name} suspends jobs until the {product-title} cluster can guarantee the capacity to start and run all of the related jobs together, which is also known as all-or-nothing scheduling.
