= Enable `virt-platform-autopilot` controller-managed logging

[role="_abstract"]
Enable `virt-platform-autopilot` controller-managed logging for {VirtProductName} by adding annotations to the `HyperConverged` custom resource.

.Prerequisites

* You have installed the {oc-first}.
* You have logged in to the cluster as a user with `cluster-admin` privileges.
* The `virt-platform-autopilot` controller is enabled on the cluster.

.Procedure

. Enable the collection of virtualization-related logs by annotating the `HyperConverged` CR.
+
Example command:
+
[source,terminal]
----
$ oc annotate hyperconverged kubevirt-hyperconverged \
  platform.kubevirt.io/enable-logging=true \
  -n {CNVNamespace}
----

. Optional: Enable the collection of audit logs by running the following command:
+
[source,terminal]
----
$ oc annotate hyperconverged kubevirt-hyperconverged \
  platform.kubevirt.io/enable-audit-logging=true \
  -n {CNVNamespace}
----

.Verification

* Verify that the annotations are set on the `HyperConverged` CR by running the following command and observing the output:
+
[source,terminal]
----
$ oc get hyperconverged kubevirt-hyperconverged \
  -n {CNVNamespace} \
  -o jsonpath='{.metadata.annotations}' | jq .
----
+
The output includes the logging annotations:
+
[source,json]
----
{
  "platform.kubevirt.io/enable-logging": "true",
  "platform.kubevirt.io/enable-audit-logging": "true"
}
----
