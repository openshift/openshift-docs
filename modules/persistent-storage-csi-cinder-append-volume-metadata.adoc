= Adding custom metadata to OpenStack Cinder CSI volumes

[role="_abstract"]
To attach custom metadata to the volumes that are provisioned by the OpenStack Cinder Container Storage Interface (CSI) driver, create a storage class that sets the `appendVolumeMetadata` parameter. The driver applies this metadata to the underlying Cinder volume in {rh-openstack} when it provisions the volume.

.Prerequisites
* {rh-openstack-first} is deployed with an appropriate Cinder storage back end.
* Access to a cluster with administrator privileges.

.Procedure
. Create a YAML file for your storage class based on the following example:
+
.Example storage class file
[source,yaml]
----
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: csi-cinder-metadata
provisioner: cinder.csi.openstack.org
parameters:
  appendVolumeMetadata: '{"environment": "production", "team": "storage"}'
----
+
* `metadata.name`: Specifies a descriptive name for your storage class.
* `parameters.appendVolumeMetadata`: Specifies a JSON-formatted string of key-value pairs that the driver applies as custom metadata to the provisioned Cinder volume. In this example, the volume is tagged with an `environment` key set to `production` and a `team` key set to `storage`.

. Apply the storage class from the file by running the following command:
+
[source,terminal]
----
$ oc apply -f csi-cinder-metadata.yaml
----

. Verify that the storage class was created by running the following command:
+
[source,terminal]
----
$ oc get storageclass csi-cinder-metadata
----
+
.Example output
[source,terminal]
----
NAME                  PROVISIONER                RECLAIMPOLICY   VOLUMEBINDINGMODE   ALLOWVOLUMEEXPANSION   AGE
csi-cinder-metadata   cinder.csi.openstack.org   Delete          Immediate           true                   6s
----

. Create a persistent volume claim (PVC) that uses the storage class based on the following example:
+
.Example PVC file
[source,yaml]
----
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: pvc-cinder-metadata
spec:
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 10Gi
  storageClassName: csi-cinder-metadata
----
+
`spec.storageClassName` is the name of the storage class that applies custom metadata. In this example, the name is `csi-cinder-metadata`.

. Apply the PVC from the file by running the following command:
+
[source,terminal]
----
$ oc apply -f pvc-cinder-metadata.yaml
----

.Verification
. Get the Cinder volume ID for the persistent volume that backs the PVC by running the following command:
+
[source,terminal]
----
$ oc get pv -o jsonpath='{range .items[?(@.spec.claimRef.name=="pvc-cinder-metadata")]}{.spec.csi.volumeHandle}{"\n"}{end}'
----

. Confirm that the custom metadata is applied to the Cinder volume by running the following command:
+
[source,terminal]
----
$ openstack volume show <volume_id>
----
+
where `<volume_id>` is the volume ID from the previous step. The custom key-value pairs that you specified in the `appendVolumeMetadata` parameter are listed in the `properties` field of the output.
