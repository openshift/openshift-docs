= Expose Central API using OpenShift service signing certificates

// JIRA: ROX-35973

[role="_abstract"]
On {ocp}, the Central API is now exposed using a new `central-ocp` service, signed and rotated by {ocp}.

If you already trust the {osp} root certificate authority (CA), you can use this service without adding a custom certificate.
