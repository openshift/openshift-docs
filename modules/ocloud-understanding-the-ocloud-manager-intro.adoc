= Infrastructure and cluster lifecycle management with the O-Cloud Manager

[role="_abstract"]
The O-Cloud Manager provides template-based cluster lifecycle management from a hub cluster. It automates provisioning, hardware management, Day 2 configuration, scaling, and upgrades with custom resources built on {rh-rhacm-first} and the SiteConfig Operator.

The O-Cloud Manager also exposes REST APIs for programmatic access to inventory, provisioning, alarms, and monitoring operations.

The O-Cloud Manager is a Technology Preview feature only.
