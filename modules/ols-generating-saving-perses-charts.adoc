= Generate and save Perses charts to analyze performance

[role="_abstract"]
To analyze cluster performance during troubleshooting or application monitoring, you can generate custom Red Hat build of Perses metric charts using natural language prompts in {ols-long} and save them directly to a dashboard.

.Prerequisites

* You have deployed an {ocp-product-title} cluster running version 4.22 or later.
* You have installed and configured {ols-long}.
* You have installed the Cluster Observability Operator (COO) version 1.5 or later.
* You have edit permissions in the target namespace, such as the `persesdashboard-editor-role` cluster role.

.Procedure

. In the {ocp-product-title} web console, click the {ols-official} icon to open the chat interface.

. Toggle the interface to troubleshooting mode before entering your query.
+
// TODO: Add updated UI screenshot of toggling the interface to troubleshooting mode. Tracked in https://redhat.atlassian.net/browse/OU-1422

. In the chat prompt, enter a natural language request for the metrics that you want to visualize, for example:
+
----
Show me the top 5 Pods with highest CPU consumption in the cluster in the last hour and visualize it
----
+
[NOTE]
====
Generation times are typically fast. If processing takes longer than expected, a loading spinner appears in the interface.
====

. In the chat window, scroll down to review the generated PatternFly-themed chart preview for formatting and data accuracy.

. Confirm that the preview panel displays the AI-assisted badge, which is a robot icon.
+
[IMPORTANT]
====
Always review AI-generated content prior to use. Verify the formatting and data accuracy of the PatternFly-themed chart preview before saving it to your dashboard.
====
+
image::ols-perses-dashboard-chat-preview.png[Dashboard open with the {ols-official} chat window displaying a generated chart preview]

. To permanently save your charts, in the web console, go to *Observe* -> *Dashboards (Perses)*, and open an existing dashboard or click *Create* to set up a new dashboard.
+
image::ols-perses-dashboards-create.png[Dashboards (Perses) list page with the Create button]

. In the chat widget, click *Add To dashboard* to insert the generated panel into your active dashboard layout.
+
image::ols-perses-add-to-dashboard.png[Chat window with the Add To dashboard button for the generated chart preview]
+
[NOTE]
====
At this stage, the dashboard modifications exist in the browser only.
====

. Perform any optional native configuration edits on the panel, and then save the dashboard to finalize the changes.
+
image::ols-perses-saved-dashboard-panel.png[Generated chart saved as a panel on a Perses dashboard]

.Verification

. Access the designated Red Hat build of Perses dashboard page in the {ocp-product-title} console.

. Confirm that the saved chart or widget appears within your chosen dashboard layout.

. Interact with the visualization to verify that the refresh, drill-down, and hover capabilities function correctly.
