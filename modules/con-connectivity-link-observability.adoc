= {prodname} observability

[role="_abstract"]
{prodname} uses component metrics, Gateway API state metrics, and standard Envoy metrics to build template dashboards and alerts. Envoy is part of {service-mesh}. In this case, it runs as a gateway deployment.

You can download community-based templates to integrate with Grafana, Prometheus, and Alertmanager deployments. You can also use those templates as starting points that you can change for your specific needs. Use the secure images available in the Red{nbsp}Hat Catalog at: link:https://catalog.redhat.com/en/software/containers/rhcl-1/rhcl-rhel9-operator/672a14ffb6ba8300a48c3799#get-this-image[Red{nbsp}Hat Connectivity Link].

{prodname} includes the following observability capabilities:

* Metrics: Prometheus metrics for monitoring gateway and policy performance
* Tracing: Distributed tracing with Red Hat build of OpenTelemetry support for request flows
* Access Logs: Envoy access logs with request correlation and structured logging
* Dashboards: Pre-built Grafana dashboards for visualization
