= Zero Trust Workload Identity Manager overview

[role="_abstract"]
The {zero-trust-full} is an {product-title} Operator that manages the lifecycle of SPIFFE Runtime Environment (SPIRE) components. 

It enables workload identity management based on the Secure Production Identity Framework for Everyone (SPIFFE) standard, providing cryptographically verifiable identities (SVIDs) to workloads running in {product-title} clusters.
