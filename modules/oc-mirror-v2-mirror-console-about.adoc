= Image set configuration in the OpenShift Mirror Console

[role="_abstract"]
Define what to mirror for a disconnected environment by selecting platform channels, Operator catalogs, and additional images in the OpenShift Mirror Console. Save the generated `ImageSetConfiguration` file, and start mirror operations that run oc-mirror plugin v2.

On the Mirror Configuration page, you can include the following kinds of content in the generated `ImageSetConfiguration` file:

platform channels:: The {product-title} release images that you need to install and upgrade clusters.

Operator catalogs:: The images for the Operators that you select.

additional images:: Individual container images that platform channels and Operator catalogs do not cover.

You can preview the generated YAML before you save it. To use the file in a mirror operation, click *Save Configuration*. To keep a copy outside the console, click *Download YAML*. The browser saves the copy to the default downloads location on your local system. Mirror operations do not use downloaded copies.

The console stores saved configurations, pull secrets, mirrored content, cache, and operation history inside the container. If you remove the container, you lose this data unless you configure persistent storage.

[NOTE]
====
Configure a pull secret on the *Pull Secret* tab in *Settings* before starting mirror operations.
====
