= OpenShift Mirror Console

[role="_abstract"]
The OpenShift Mirror Console is a guided web UI for building `ImageSetConfiguration` files for disconnected {product-title} mirroring with oc-mirror plugin v2. Use it to create image sets in the UI instead of relying only on manual YAML files and CLI options.

Disconnected mirroring with oc-mirror plugin v2 often depends on a manually created `ImageSetConfiguration` YAML file and CLI options. The OpenShift Mirror Console provides a guided editor for building and reviewing that configuration in the UI. You can complete common image-set setups without relying on the CLI.

Configure platform channels, Operator catalogs, and additional images, then preview and save the generated YAML file. When you click *Download YAML*, the browser saves the `ImageSetConfiguration` file to the default downloads location on the local computer. 

Before you start a mirroring operation, configure a pull secret in *Settings* -> *Pull Secret*. Without a configured pull secret, mirroring operations are unavailable.
