= OpenShift Mirror Console

[role="_abstract"]
To generate `ImageSetConfiguration` files for disconnected mirroring, use the OpenShift Mirror Console with oc-mirror plugin v2. The console provides a guided web interface for common image-set setups.

The console generates an `ImageSetConfiguration` file from three kinds of content:

* platform channels
* Operator catalogs
* additional images

A preview shows the generated YAML file before you save it. When you click *Download YAML*, the browser saves the file to the default downloads location on the local computer. Mirror operations do not use downloaded files.

[NOTE]
====
Mirror operations are unavailable until you configure a pull secret.
====
