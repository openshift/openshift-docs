= OpenShift Mirror Console

[role="_abstract"]
The OpenShift Mirror Console is a guided web UI for building `ImageSetConfiguration` files for disconnected {product-title} mirroring with oc-mirror plugin v2. The console replaces manual YAML editing for common image-set setups.

Configure platform channels, Operator catalogs, and additional images, then preview and save the generated YAML file. When you click *Download YAML*, the browser saves the `ImageSetConfiguration` file to the default downloads location on the local computer. 

Before you start a mirroring operation, add a pull secret in *Settings* -> *Pull Secret*. Without a configured pull secret, mirroring operations are unavailable.
