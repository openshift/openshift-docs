= Overview dashboard in the GitOps Console

[role="_abstract"]
The {gitops-shortname} Console plugin provides an Overview page under the GitOps navigation tab. Use it to see Application sync and health at a glance, review Applications that need attention, check recent sync operations, and inspect GitOps infrastructure in the selected project or across all projects.

The Overview page has two tabs:

* *Application Overview*: Displays Application sync and health status, operational metrics, and recent activity.
* *Infrastructure*: Shows GitOps-related operators and custom resources in the selected project or across all projects.

[NOTE]
====
The *Operational metrics*, *Application Sync Activity (24 hours)*, and *Application Reconciliation Performance (24 hours)* cards require cluster monitoring and Argo CD Prometheus metrics. The *Sync status*, *Health status*, *Applications Needing Attention*, and *Recent Operations* cards use Application data from the Kubernetes API and do not require Prometheus. When Prometheus metrics do not exist, the three metric cards show an error or empty state.
====
