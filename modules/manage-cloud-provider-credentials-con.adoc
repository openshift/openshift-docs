= Manage cloud provider credentials

[role="_abstract"]
The Cloud Credential Operator (CCO) manages cloud provider credentials as custom resources so that {product-title} components can request only the permissions they require. Depending on the CCO mode your cluster uses, you can mint short-lived credentials, pass through an existing account, or manage credentials manually with short-term tokens.
