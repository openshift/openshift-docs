= Manage network policy lifecycle

[role="_abstract"]
Network policy has to change as the application it protects changes. Viewing, editing, and deleting `NetworkPolicy` objects from the CLI or the web console gives you one lifecycle for namespace policy instead of scattered, single-purpose procedures.
