= About the File Restore Operator

[role="_abstract"]
The File Restore Operator is a Kubernetes operator that enables file-level restore operations for virtual machines (VMs). You can restore individual files and directories to running VMs without restarting the VM.

The operator uses hot-plug technology to attach a restore volume to a running VM and SSH to copy files from the source to the target VM.

The File Restore Operator supports the following source types:

* *PersistentVolumeClaims (PVCs)*: Restore from backup PVCs.
* *VolumeSnapshots*: Restore from Kubernetes volume snapshots.
* *Remote storage*: Restore from remote storage by using `rclone`, such as Amazon S3 or Google Cloud Storage.
