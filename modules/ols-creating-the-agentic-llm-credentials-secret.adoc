= Creating the Agentic {ols-long} LLM credentials secret

[role="_abstract"]
Create the credentials secret that Agentic {ols-long} uses to authenticate with the large language model (LLM) provider. The agentic Operator uses a separate secret with a different key name than classic {ols-long} (`OPENAI_API_KEY` instead of `apitoken`).

.Prerequisites

* You have installed the {ols-long} Operator.

* You have an LLM provider API key.

.Procedure

* Create the credentials secret by running the following command:
+
[source,terminal]
----
$ oc apply -f - <<'EOF'
apiVersion: v1
kind: Secret
metadata:
  name: llm-creds-openai
  namespace: openshift-lightspeed
type: Opaque
stringData:
  OPENAI_API_KEY: <YOUR_OPENAI_API_KEY>
EOF
----
