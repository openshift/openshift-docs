= Install a cluster on on-premise infrastructure

[role="_abstract"]
Installing {product-title} with installer-provisioned infrastructure in your own data center follows the same journey as a cloud installation, but you supply what a cloud provider would otherwise supply. You define the regions, zones, and failure domains of your virtualization platform, provide an external load balancer for the API and ingress endpoints, and configure storage for the internal image registry.

Supported on-premise platforms are {vmw-short}, {rh-openstack}, Nutanix, and bare metal. Follow the supplement for your platform.

Before you begin, set up your installation host by following "Prepare to install OpenShift".
