= Ensure external communication by customizing IP, DNS, and routing

[role="_abstract"]
Node network configuration policies can set static and dynamic IP addressing, DNS servers, and routing rules on cluster nodes. Customize these settings so that your nodes communicate with the systems in the surrounding data center.
