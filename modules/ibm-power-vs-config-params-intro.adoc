= Installation configuration parameters for IBM Power Virtual Server

[role="_abstract"]
Before you deploy an {product-title} cluster on {ibm-power-server-name}, you supply parameters to customize your cluster and the platform that hosts it.

When you create the `install-config.yaml` file, you provide values for the required parameters through the command line. You can then modify the `install-config.yaml` file to customize your cluster further.
