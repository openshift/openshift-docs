= {mcpg} in the web console navigation


[role="_abstract"]
After you install {mcpg} and enable the {ocp} web console in your {prodname} deployment, you can use the web console for your {mcpg} resources according to your permissions.

Use the *MCP management* section to see all of the {mcpg} resources in the cluster or current namespace. For example, the following options are available:

* Within the *MCP gateway setup wizard*, you can follow the steps to choose or create a `Gateway` object, create a customized `HTTPRoute` object, create an `MCPGatewayExtension` CR, and verify that the objects are applied.

*MCPGatewayExtensions*: Lists the `MCPGatewayExtension` CR name, the name of the `Gateway` object that it references, and the namespace where the `Gateway` object is applied.

*MCP Servers*: Lists the MCP server name, namespace, and status. The status indicates whether a server is online or offline. You can also register an on-premise or external MCP server.

*Reference grants*: Lists the name of the `ReferenceGrant` object and the namespace it is mapped to. You can also create a `ReferenceGrant` object.

*Policies attached to `Gateway` or `HTTPRoute` objects*: Lists the type of policy, the namespace where it is applied, and the status. You can also create or edit a policy.
