= {mcpg} in the web console navigation


[role="_abstract"]
After you install {mcpg} and enable the {ocp} web console in your {prodname} deployment, you can use the web console for your {mcpg} set up according to your permissions.

In the navigation menu, use the *MCP management* section to select one of the following pages as available for your role.

*Get Started* is displayed if you have not created an `MCPGatewayExtension` CR. Click the *MCP gateway setup wizard*.

*MCPGatewayExtensions*: Lists the `MCPGatewayExtension` CR name, the name of the `Gateway` object that it references, and the namespace where the `Gateway` object is applied. If you have not created an object yet, the *Get Started* page is displayed. Click the *MCP gateway setup wizard*.

* Within the *MCP gateway setup wizard*, you can follow the steps to choose or create a `Gateway` object, create an `HTTPRoute` object, create an `MCPGatewayExtension` CR, and verify that the objects are applied.

*MCP Servers*: Lists the MCP server name, namespace, and status. The status indicates whether a server is online or offline. You can register an on-premise or external MCP server by clicking *Register MCP server*.

*Reference grants*: Lists the name of the `ReferenceGrant` object and the namespace it is mapped to. You can create a ReferenceGrant` object by clicking *Create ReferenceGrant*.

*Policies attached to MCP gateways or servers*: Lists the type of policy, the namespace where it is applied, and the status. You can create a policy by clicking *Create policy*.
