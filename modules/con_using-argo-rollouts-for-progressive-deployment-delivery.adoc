= Use progressive deployment delivery

[role="_abstract"]
To use Argo Rollouts for progressive delivery, create and configure a `RolloutManager` custom resource (CR) instance in the namespace of your choice. You can scope the `RolloutManager` CR for single or multiple namespaces.
