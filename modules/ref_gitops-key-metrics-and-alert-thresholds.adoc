= Key metrics and alert thresholds

[role="_abstract"]
Monitor key Argo CD metrics to identify performance issues, resource constraints, and operational problems. Configure alert thresholds based on these metrics to receive notifications before issues impact users.

*Application controller metrics*

Monitor these metrics to track application reconciliation performance:

[cols="1,2,1",options="header"]
|===
|Metric |Description |Recommended threshold
|`argocd_app_reconcile_count` |Number of application reconciliations |N/A (counter)
|`argocd_app_reconcile_duration_seconds` |Time to reconcile an application |Alert if p95 > 30s
|`argocd_app_sync_total` |Total number of application syncs |N/A (counter)
|`argocd_app_k8s_request_total` |Kubernetes API requests from controller |Alert if rate increases >50%
|`argocd_cluster_api_resource_objects` |Number of cached API resources per cluster |Alert if > 50,000 per cluster
|===

*Repo server metrics*

Monitor repository server metrics to track Git operations and manifest generation:

[cols="1,2,1",options="header"]
|===
|Metric |Description |Recommended threshold
|`argocd_git_request_total` |Git fetch operations |N/A (counter)
|`argocd_git_request_duration_seconds` |Git operation duration |Alert if p95 > 10s
|`argocd_repo_pending_request_total` |Pending repository requests |Alert if > 10
|`argocd_redis_request_duration` |Redis operation duration |Alert if p95 > 100ms
|===

*API server metrics*

Monitor API server metrics to track user requests and web console performance:

[cols="1,2,1",options="header"]
|===
|Metric |Description |Recommended threshold
|`argocd_api_request_total` |Total API requests |N/A (counter)
|`argocd_api_request_duration_seconds` |API request duration |Alert if p95 > 2s
|`grpc_server_handled_total` |gRPC requests handled |N/A (counter)
|`grpc_server_handling_seconds` |gRPC request duration |Alert if p95 > 1s
|===

*Resource utilization metrics*

Monitor pod resource usage to prevent out-of-memory errors and CPU throttling:

[cols="1,2,1",options="header"]
|===
|Component |Metric |Recommended threshold
|Application controller |Memory usage |Alert if > 80% of limit
|Application controller |CPU usage |Alert if throttled > 10%
|Repo server |Memory usage |Alert if > 80% of limit
|Redis |Memory usage |Alert if > 90% of limit
|===

*Sync failure metrics*

Track synchronization failures to identify deployment issues:

[cols="1,2,1",options="header"]
|===
|Metric |Description |Recommended threshold
|`argocd_app_sync_total{phase="Failed"}` |Failed sync operations |Alert if > 5 in 10 minutes
|`argocd_app_sync_total{phase="Error"}` |Sync errors |Alert if > 0
|Application health status |Applications in Degraded state |Alert if any critical app degraded
|===

*Configuring Prometheus alerts*

Create Prometheus alert rules based on these thresholds:

*Example Prometheus alert:*
[source,yaml]
----
apiVersion: monitoring.coreos.com/v1
kind: PrometheusRule
metadata:
  name: argocd-alerts
  namespace: openshift-gitops
spec:
  groups:
  - name: argocd
    interval: 30s
    rules:
    - alert: ArgoCDAppSyncFailure
      expr: |
        increase(argocd_app_sync_total{phase="Failed"}[10m]) > 5
      annotations:
        summary: "High rate of Argo CD sync failures"
        description: "Application {{ $labels.name }} has {{ $value }} sync failures in 10 minutes"
    - alert: ArgoCDReconcileSlow
      expr: |
        histogram_quantile(0.95, argocd_app_reconcile_duration_seconds) > 30
      annotations:
        summary: "Argo CD reconciliation is slow"
        description: "95th percentile reconciliation time is {{ $value }}s"
----

*Accessing metrics*

Access Argo CD metrics through:

* *Prometheus UI* - Query metrics directly from the {OCP} monitoring stack
* *Grafana dashboards* - Import pre-built Argo CD dashboards
* *Argo CD metrics endpoint* - Scrape metrics at `https://<argocd-server>/metrics`

For more information about accessing metrics, see xref:../observe/monitor-argo-cd-health-and-performance.adoc#monitor-argo-cd-health-and-performance[Monitor Argo CD health and performance].
