= Configuration by using policy as code

[role="_abstract"]
You can create and manage policies as code by authoring policies as Kubernetes custom resources (CRs), and then applying them to the {product-title-short} Central namespace by using a GitOps tool such as OpenShift GitOps, which builds on ArgoCD.
