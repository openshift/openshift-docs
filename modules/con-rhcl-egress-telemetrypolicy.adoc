= Add custom labels to data plane metrics

[role="_abstract"]
The `istio_*` metrics of an egress `Gateway` object cannot identify the workload that made an outbound call. You can close that gap by using a `TelemetryPolicy` custom resource (CR) to add labels to the metrics that the {prodname} data plane emits.

A `TelemetryPolicy` CR does not have egress-specific fields. A telemetry policy that you write for an egress `Gateway` object has the same fields as a policy for a `Gateway` object that handles incoming traffic.
