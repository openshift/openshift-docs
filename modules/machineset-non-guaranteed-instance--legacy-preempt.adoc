[id="machineset-non-guaranteed-instance_{context}"]

[role="_abstract"]
You can save on costs by creating a compute machine set running on {gcp-short} that deploys machines as non-guaranteed preemptible VM instances. Preemptible VM instances use excess Compute Engine capacity and are less expensive than normal instances.
