= Configure your cluster to use an image registry

[role="_abstract"]
You can configure {product-title} to use a specific image registry for pulling container images. This includes setting up repository mirroring so that requests to a source registry are redirected to a mirror registry, and updating the global pull secret used to authenticate with registries.
