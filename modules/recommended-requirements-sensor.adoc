= Sensor

[role="_abstract"]
Sensor monitors your Kubernetes and {ocp} clusters, handling interactions with the Kubernetes API and coordinating with Collector.

== Memory and CPU requirements

The following table lists the minimum memory and CPU values required to run Sensor on a secured cluster.

|===
| Deployments | CPU | Memory

| < 25,000
| 2 cores
| 10 GiB

| < 50,000
| 2 cores
| 20 GiB
|===
