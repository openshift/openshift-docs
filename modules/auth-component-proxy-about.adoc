= Component-scoped proxy for authentication

[role="_abstract"]
You can configure a component-scoped proxy for the authentication stack. This proxy allows the Cluster Authentication Operator (CAO) and the OAuth server to reach external identity providers (IdPs) without using the cluster-wide egress proxy.

The OAuth server makes outbound calls to IdP endpoints on every login for OpenID Connect (OIDC) discovery, token exchange, user info retrieval, and group membership resolution. The CAO validates IdP connectivity through the proxy on each configuration change. Without this feature, the only option in a restricted network is the cluster-wide egress proxy, which opens egress for all components. The component-scoped proxy limits egress to authentication components only.

== When to use a component-scoped proxy

Use a component-scoped proxy when you need to limit proxy-based egress to authentication components only. Use the cluster-wide proxy when all components share the same proxy.

When `spec.proxy` is set on the `Authentication` operator resource, it completely replaces the cluster-wide proxy for authentication components. Individual fields are not inherited from the cluster-wide proxy.

== Proxy precedence

The authentication stack resolves proxy configuration as follows:

. When `spec.proxy` is set, authentication components use only those settings. The cluster-wide proxy is ignored for authentication.
. When `spec.proxy` is absent, authentication components fall back to the cluster-wide proxy.
. When neither is configured, no proxy is used.

Removing `spec.proxy` restores the cluster-wide proxy for authentication components.

== Scope and limitations

The component-scoped proxy applies to the following components:

* Cluster Authentication Operator (CAO)
* OAuth server

The component-scoped proxy does not apply to the following:

* Hosted control planes: The CAO does not run in hosted control plane environments.
* MicroShift: The authentication stack is not present.
* External OIDC mode: Not included in the initial implementation.
* Per-identity-provider proxy: You cannot configure different proxy settings for different identity providers.

LDAP group sync `CronJob` resources are not managed by the authentication operator. You must configure proxy settings independently on the `CronJob` pod specification.

== Feature gate requirement

This feature requires the `AuthenticationComponentProxy` feature gate, which is enabled by the `TechPreviewNoUpgrade` or `DevPreviewNoUpgrade` feature set. This feature is available on self-managed clusters only.
