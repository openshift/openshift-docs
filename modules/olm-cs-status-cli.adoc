= View Operator catalog source status by using the CLI

[role="_abstract"]
You can view the status of an Operator catalog source by using the CLI.

.Prerequisites

* [.pr:openshift-enterprise .pr:openshift-origin .pr:microshift]#{empty}# You have access to the cluster as a user with the `cluster-admin` role.
* [.pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp]#{empty}# You have access to the cluster as a user with the `dedicated-admin` role.
* You have installed the OpenShift CLI (`oc`).

.Procedure

. List the catalog sources in a namespace. For example, you can check the [.pr:openshift-origin]#`olm`# [.pr:openshift-enterprise .pr:openshift-dedicated .pr:openshift-rosa .pr:openshift-rosa-hcp .pr:microshift]#`openshift-marketplace`# namespace, which is used for cluster-wide catalog sources:
+
[source,terminal,subs="attributes+",role="pr:openshift-origin"]
----
$ oc get catalogsources -n olm
----
+
[source,terminal,subs="attributes+",role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
----
$ oc get catalogsources -n openshift-marketplace
----
+
.Example output
[source,terminal]
----
NAME                  DISPLAY               TYPE   PUBLISHER   AGE
certified-operators   Certified Operators   grpc   Red Hat     55m
community-operators   Community Operators   grpc   Red Hat     55m
example-catalog       Example Catalog       grpc   Example Org 2m25s
redhat-operators      Red Hat Operators     grpc   Red Hat     55m
----

. Use the `oc describe` command to get more details and status about a catalog source:
+
[source,terminal,subs="attributes+",role="pr:openshift-origin"]
----
$ oc describe catalogsource example-catalog -n olm
----
+
[source,terminal,subs="attributes+",role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
----
$ oc describe catalogsource example-catalog -n openshift-marketplace

. List the pods in the namespace where your catalog source was created:
+
[source,terminal,subs="attributes+",role="pr:openshift-origin"]
----
$ oc get pods -n olm
----
+
[source,terminal,subs="attributes+",role="pr:openshift-enterprise pr:openshift-dedicated pr:openshift-rosa pr:openshift-rosa-hcp pr:microshift"]
----
$ oc get pods -n openshift-marketplace
----
+
.Example output
[source,terminal]
----
NAME                                    READY   STATUS             RESTARTS   AGE
certified-operators-cv9nn               1/1     Running            0          36m
community-operators-6v8lp               1/1     Running            0          36m
marketplace-operator-86bfc75f9b-jkgbc   1/1     Running            0          42m
example-catalog-bwt8z                   0/1     ImagePullBackOff   0          3m55s
redhat-operators-smxx8                  1/1     Running            0          36m
----
+
When a catalog source is created in a namespace, a pod for the catalog source is created in that namespace. In the preceding example output, the status for the `example-catalog-bwt8z` pod is `ImagePullBackOff`. This status indicates that there is an issue pulling the catalog source's index image.
