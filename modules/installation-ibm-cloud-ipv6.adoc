= IPv6 limitations

[role="_abstract"]
Review IPv6 networking limitations before you install {product-title} on {ibm-cloud-name} Virtual Private Cloud (VPC) infrastructure.

[IMPORTANT]
====
{ibm-cloud-name} VPC infrastructure does not provide IPv6. You cannot install a cluster that uses IPv6 or dual-stack networking on {ibm-cloud-name} VPC.
====
