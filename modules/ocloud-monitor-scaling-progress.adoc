= Monitor scaling progress

[role="_abstract"]
You can monitor the progress of a scaling operation by watching the `ProvisioningRequest` custom resource status conditions and provisioning phase. The O-Cloud Manager updates the resource status as the scaling operation progresses through hardware allocation, node provisioning, and cluster membership changes.

.Prerequisites

* A node addition, node removal, or node replacement operation is in progress on the `ProvisioningRequest` CR.

.Procedure

. Watch the `ProvisioningRequest` CR status in real time by running the following command:
+
[source,terminal]
----
$ oc get provisioningrequests.clcm.openshift.io <uuid> -w
----
+
where:
+
--
`<uuid>`:: Specifies the UUID of the `ProvisioningRequest` CR for the target cluster.
--

. View the detailed status conditions by running the following command:
+
[source,terminal]
----
$ oc get provisioningrequests.clcm.openshift.io <uuid> -o jsonpath='{.status.conditions[?(@.type=="ClusterProvisioned")]}'
----
+
During scaling operations, the `ClusterProvisioned` condition transitions to `InProgress` with a message indicating the current phase.

. Check the high-level provisioning phase by running the following command:
+
[source,terminal]
----
$ oc get provisioningrequests.clcm.openshift.io <uuid> -o jsonpath='{.status.provisioningStatus.provisioningPhase}'
----
+
The `provisioningPhase` progresses through the following values during a scaling operation:
+
* `fulfilled` - The initial state before the scaling request is detected.
* `pending` - The scaling request is queued and awaiting processing.
* `progressing` - The scaling operation is actively in progress.
* `fulfilled` - The scaling operation completed successfully.

.Verification

* Confirm that the scaling operation completed by verifying the `ProvisioningRequest` CR has returned to `fulfilled` state by running the following command:
+
[source,terminal]
----
$ oc get provisioningrequests.clcm.openshift.io <uuid>
----
+
.Example output
[source,terminal]
----
NAME                                   AGE    PROVISIONPHASE   PROVISIONDETAILS
123e4567-e89b-12d3-a456-426614174000   120m   fulfilled        Provisioning request has completed successfully
----
