[id="zstream-4-20-41-fixed-issues_{context}"]
== Fixed issues

* Before this update, on disconnected clusters, repetitive API re-discovery disrupted watch-based data fetching. As a consequence, the Operator-backed catalog in the *Developer* perspective showed `No Catalog items found`. With this release, watch-based data fetching is replaced with a plain HTTP request. As a result, the Operator-backed catalog correctly lists Operator-backed services on disconnected clusters. (link:https://issues.redhat.com/browse/OCPBUGS-60136[OCPBUGS-60136])

* Before this update, the `kube-apiserver-to-kubelet` client signer certificate was being refreshed every 30 days despite having a 365-day validity period. With this release, the refresh interval is corrected to 292 days, 80% of validity, which is consistent with other signers. As a result, certificate rotations are prevented and the signer behavior is aligned with the intended configuration. (link:https://issues.redhat.com/browse/OCPBUGS-128037[OCPBUGS-128037])
