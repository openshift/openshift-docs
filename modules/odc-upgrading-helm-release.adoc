= Upgrading a Helm release

[role="_abstract"]
You can upgrade a Helm release to use a new chart version or update your release configuration.

.Procedure

. Navigate to *Ecosystem* -> *Helm*.
. Click the overflow menu in the release's row and select *Upgrade Helm release*.
. On the *Upgrade Helm release* page, select the chart version you want, if available.
. Optional: If the release uses a chart URL that requires authentication, select a secret from the *Secret for Basic authentication* list. If you selected a secret when you installed the release, that secret is already selected. If that secret no longer exists, the page displays a notification, and you must select or create a different secret.
. Edit the values as needed, then click *Upgrade* to create a revision of the Helm release. The *Ecosystem* -> *Helm* page shows the updated revision count.
