= Upgrading a Helm release

[role="_abstract"]
You can upgrade a Helm release to use a new chart version or update your release configuration.

.Procedure

. Navigate to *Ecosystem* -> *Helm*.
. Click the overflow menu in the release's row and select *Upgrade Helm Release*.
. On the *Upgrade Helm Release* page, if you can edit the *Chart Version* field, select the chart version you want to upgrade to, edit the values as needed, then click *Upgrade* to create a revision of the Helm release. The *Ecosystem* -> *Helm* page shows both revisions.
+
NOTE: If you installed the Helm chart by using a direct URL, you can't change *Chart Version*. Instead, edit the values in *Form view* or *YAML view*.
