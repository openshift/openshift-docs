= Upgrading a Helm release

[role="_abstract"]
You can upgrade a Helm release to use a new chart version or update your release configuration.

.Procedure

. Navigate to *Ecosystem* -> *Helm*.
. Click the overflow menu in the release's row and select *Upgrade Helm Release*.
. On the *Upgrade Helm Release* page, select the chart version you want if available, edit the values as needed, then click *Upgrade* to create a revision of the Helm release. The *Ecosystem* -> *Helm* page shows the updated revision count.
