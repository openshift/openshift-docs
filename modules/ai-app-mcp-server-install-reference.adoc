= NetEdge toolset reference

[role="_abstract"]
The netedge toolset provides tools for monitoring and troubleshooting OpenShift network ingress and DNS components.

The following table outlines router tools:

[cols="3",options="header"]
|===
|Tool
|Description
|Parameters

|`get_router_config`
|Retrieves the current HAProxy configuration of the router.
|`pod` is an optional parameter that states the router pod name.

|`get_router_info`
|Retrieve HAProxy runtime information from the router.
|`pod` is an optional parameter that states the router pod name.

|`get_router_sessions`
|Retrieve all active sessions from the router.
|`pod` is an optional parameter that states the router pod name.
|===

[NOTE]
====
If you do not provide the optional `pod` parameter, a router tool automatically selects any available router pod from the default ingress controller. 
====
