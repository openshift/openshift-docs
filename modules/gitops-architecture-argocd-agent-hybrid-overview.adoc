= Hybrid architecture overview

In a hybrid architecture, you run the Argo CD Agent components alongside an existing Argo CD instance. This allows you to operate both reconciliation models simultaneously on a single control plane.

Push model:: The hub's application controller reconciles applications and syncs changes to the workload cluster. The application state is managed centrally on the hub.

Pull model:: The Argo CD Agent syncs application definitions to the spoke cluster, where a local application controller reconciles them, and the application status is reported back to the hub.

Use a hybrid architecture when you want to:

* Adopt the Argo CD Agent incrementally, one workload cluster or one application at a time.
* Evaluate the agent model without changing how your existing applications are deployed.
* Keep clusters reachable from the control plane on the push model, and move network-restricted or large-scale clusters to the pull model.

[IMPORTANT]
====
The hybrid architecture is intended for users already familiar with Argo CD and the Argo CD Agent architecture. Review the Argo CD Agent architecture overview before you configure a hybrid architecture.
====
