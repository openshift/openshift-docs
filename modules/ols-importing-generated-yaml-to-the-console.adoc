= Importing generated YAML into the web console

[role="_abstract"]
When {ols-long} returns a code block in a response, you can import the content directly into the *Import YAML* page of the {ocp-product-title} web console to review and create the resource.

[NOTE]
====
Always review AI-generated content before you use it.
====

.Prerequisites

* You are running {ocp-product-title} 4.18 or later.

.Procedure

. Click the {ols-official} icon in the lower-right corner of the screen.

. Enter a question that asks {ols-long} to generate a resource definition, and then click the *Submit* button.

. In the response, hover over the code block, and then click the *Import to console* icon.

. If you are prompted to leave the current page, click *Leave*.
+
The *Import YAML* page opens with the generated content.

. Review the content, and then click *Create*.
