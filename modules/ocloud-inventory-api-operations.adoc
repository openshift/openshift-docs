= Inventory API operations

[role="_abstract"]
The Inventory API provides read-only access to the physical infrastructure hierarchy including locations, sites, resource pools, individual resources, resource types, and deployment managers. It also supports subscriptions for change notifications.

All endpoints use the base path `/o2ims-infrastructureInventory/v2`.

The `globalLocationId` value is the `metadata.name` of the associated `Location` custom resource (CR). All other identifiers in this API, such as `oCloudSiteId`, `resourcePoolId`, `resourceId`, `resourceTypeId`, `deploymentManagerId`, and `alarmDictionaryId`, are generated by the O-Cloud Manager. Use the corresponding list operation to discover these values. For example, send a request to the `/resourcePools` endpoint to find a `resourcePoolId`. The `subscriptionId` value is returned in the response when you create a subscription.

|`/resourceTypes`
|List resource types

|`/subscriptions`

|`/subscriptions/{subscriptionId}`
|Delete an inventory subscription

|`GET`
|`/alarmDictionaries`
|List alarm dictionaries

|`GET`
|`/alarmDictionaries/{alarmDictionaryId}`
