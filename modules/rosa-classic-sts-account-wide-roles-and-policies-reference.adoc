= Account-wide IAM role and policies reference

[role="_abstract"]
{product-title} clusters that use Security Token Service (STS) require the following account-wide Identity and Access Management (IAM) roles and policies. Review roles and policies descriptions and examples JSON files that define each policy.

[NOTE]
====
The account number present in the `sts_installer_trust_policy.json` and `sts_support_trust_policy.json` samples represents the Red{nbsp}Hat account that is allowed to assume the required roles.
====

.{product-title} installer role, policy, and policy files
[cols="1,2",options="header"]
|===
|Resource|Description

|`ManagedOpenShift-Installer-Role`
|An IAM role used by the {product-title} installer.

|`ManagedOpenShift-Installer-Role-Policy`
|An IAM policy that provides the {product-title} installer with the permissions required to complete cluster installation tasks.
|===
