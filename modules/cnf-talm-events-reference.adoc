= {cgu-operator-full} event reference

[role="_abstract"]
The {cgu-operator-first} emits Kubernetes events during `ClusterGroupUpgrade` reconciliation. Each event includes a reason, type, and scope that you can use to filter events in Event Driven Ansible rulebooks. Events also include annotations that provide additional metadata about the affected clusters and policies.

== Event types

The following table describes the events that {cgu-operator} emits during policy remediation.

.{cgu-operator} event types
[cols="1,1,1,2", options="header"]
|====
|Reason
|Type
|Scope
|Description

|`CguCreated`
|Normal
|Global
|A new `ClusterGroupUpgrade` resource is found by the reconciler.

|`CguStarted`
|Normal
|Global
|The reconciler has started remediating policies based on the remediation plan.

|`CguStarted`
|Normal
|Batch
|Policy remediation has started for the clusters in a specific batch of the remediation plan.

|`CguStarted`
|Normal
|Cluster
|Policy remediation has started for a specific cluster.

|`CguSuccess`
|Normal
|Cluster
|Policy remediation has finished successfully for a specific cluster.

|`CguSuccess`
|Normal
|Batch
|Policy remediation has finished successfully for all clusters in a specific batch.

|`CguSuccess`
|Normal
|Global
|All policies have been successfully remediated for all clusters in the remediation plan.

|`CguTimedout`
|Warning
|Batch
|Some clusters in the current batch timed out while remediating policies.

|`CguTimedout`
|Warning
|Global
|Some clusters timed out while remediating policies across the entire remediation plan.

|`CguValidationFailure`
|Warning
|Global
|The validation of the `ClusterGroupUpgrade` resource failed due to missing clusters, missing policies, invalid policies, or ambiguous policies.
|====

== Event annotations

{cgu-operator} events include annotations that provide structured metadata for filtering and processing. The annotation keys use the `cgu.openshift.io/` prefix.

.{cgu-operator} event annotations
[cols="2,1,2", options="header"]
|====
|Annotation
|Possible values
|Description

|`cgu.openshift.io/event-type`
|`global`, `batch`, `cluster`
|Indicates the scope of the event. Use this annotation to filter events by scope in rulebook conditions.

|`cgu.openshift.io/cluster-name`
|Cluster name string
|Identifies the specific cluster for cluster-scoped events. Present only on events with `cluster` scope.

|`cgu.openshift.io/batch-clusters`
|Comma-separated cluster names
|Lists the clusters in the current batch. Present on batch-scoped events.

|`cgu.openshift.io/batch-clusters-count`
|Integer
|The number of clusters in the current batch. Present on batch-scoped events.

|`cgu.openshift.io/total-clusters-count`
|Integer
|The total number of clusters in the remediation plan. Present on `CguStarted` and `CguSuccess` events.

|`cgu.openshift.io/total-batches-count`
|Integer
|The total number of batches in the remediation plan. Present on global `CguStarted` events.

|`cgu.openshift.io/timedout-clusters`
|Comma-separated cluster names
|Lists the clusters that timed out during remediation. Present on `CguTimedout` events.

|`cgu.openshift.io/missing-clusters`
|Comma-separated cluster names
|Lists the clusters specified in the `ClusterGroupUpgrade` resource that do not exist. Present on `CguValidationFailure` events.

|`cgu.openshift.io/missing-clusters-count`
|Integer
|The number of missing clusters. Present on `CguValidationFailure` events when clusters are missing.

|`cgu.openshift.io/missing-policies`
|Comma-separated policy names
|Lists the policies that do not exist. Present on `CguValidationFailure` events.

|`cgu.openshift.io/invalid-policies`
|Comma-separated policy names
|Lists the policies that are invalid. Present on `CguValidationFailure` events.

|`cgu.openshift.io/ambiguous-policies`
|Comma-separated policy names
|Lists the policies that are duplicated across different namespaces. Present on `CguValidationFailure` events.
|====

== Example event filtering

The following rulebook condition filters for successful cluster-level remediation events:

[source,yaml]
----
condition: >-
  event.body is selectattr('reason', 'match', 'CguSuccess')
  and event.body is selectattr('eventAnnotations.cgu.openshift.io/event-type', 'eq', 'cluster')
----
