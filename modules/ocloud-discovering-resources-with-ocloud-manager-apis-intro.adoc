= Discover O-Cloud resources with O-Cloud Manager APIs

[role="_abstract"]
After you define cluster templates and onboard bare-metal servers, external clients such as Service Management and Orchestration (SMO) frameworks and automation systems can discover available infrastructure, templates, and provisioned clusters through the O-Cloud Manager REST APIs. The Inventory API provides read-only access to locations, resource pools, and physical resources. The Artifacts API exposes available cluster templates. The Cluster API provides information about provisioned clusters.
