= Add a compute machine subnet

[role="_abstract"]
If new compute machines use an additional subnet, add it to the machine networks in your {product-title} cluster's infrastructure configuration before the machines join.

Apply this procedure to both bare-metal machines and virtual machines (VMs) without {vmw-short} integration. If their subnet is already listed, continue to the ISO installation procedure.

Adding the subnet to the cluster configuration does not configure external routing or establish virtual IP address (VIP) reachability. Configure that connectivity before adding the machines.

.Prerequisites

* You have installed the {oc-first}.
* You are logged in to the target cluster as a user with the `cluster-admin` role.
* You know the subnets in Classless Inter-Domain Routing (CIDR) notation that your network administrator assigned to the existing machines and the new machines.

.Procedure

. Display the configured machine networks by running the following command:
+
[source,terminal]
----
$ oc get infrastructure cluster -o jsonpath='{.spec.platformSpec.vsphere.machineNetworks}{"\n"}'
----

. Edit the `Infrastructure` object named `cluster` by running the following command:
+
[source,terminal]
----
$ oc edit infrastructure cluster
----

. In `spec.platformSpec.vsphere.machineNetworks`, retain the existing entries and append the new subnet. If `machineNetworks` is absent, add the list with the existing and new machine subnets.
+
The following excerpt shows the location of the list:
+
[source,yaml,subs="+quotes"]
----
spec:
  platformSpec:
    type: VSphere
    vsphere:
      machineNetworks:
      - <existing_machine_network_cidr>
      - <new_machine_network_cidr>
----
+
where:
+
`<existing_machine_network_cidr>`:: Specifies an existing machine subnet. Retain all existing entries.
`<new_machine_network_cidr>`:: Specifies the subnet for the new machines, for example, `192.0.2.0/24`. Add each new subnet only once.

. Save your changes and exit the editor.

.Verification

* Verify that the list contains the existing networks and each new subnet by running the following command:
+
[source,terminal]
----
$ oc get infrastructure cluster -o jsonpath='{.spec.platformSpec.vsphere.machineNetworks}{"\n"}'
----
