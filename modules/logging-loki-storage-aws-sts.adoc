= AWS storage for STS enabled clusters

[role="_abstract"]
If your cluster has {aws-first} Security Token Service (STS) enabled, the Cloud Credential Operator (CCO) supports short-term authentication by using AWS tokens.

.Prerequisites

* You installed the {loki-op}.
* You installed the {oc-first}.
* Your cluster has AWS STS enabled.

.Procedure

* Create the Loki object storage secret by running the following command:
+
[source,terminal,subs="+quotes"]
----
$ oc -n openshift-logging create secret generic logging-loki-aws \
  --from-literal=bucketnames="<s3_bucket_name>" \
  --from-literal=region="<bucket_region>" \
  --from-literal=audience="<oidc_audience>"
----
+
`bucketnames`::
  The name of your S3 bucket.

`region`::
  The AWS region where your bucket is located.

`audience`::
  Optional annotation, default value is `openshift`.

.Verification

Verify that the secret was created successfully:

[source,terminal]
----
$ oc get secret logging-loki-aws -n openshift-logging
----
