= Release notes for {pipelines-title} 1.23.3

[role="_abstract"]
{pipelines-title} General Availability 1.23.3 is available on {OCP} 4.14 and later supported versions.

[id="fixed-issues-1-23-3_{context}"]
== Fixed issues

.User interface

//SRVKP-14864
`PipelineRun` list crashes when displaying canceled pipeline runs with task runs::
Before this update, the {pipelines-shortname} web console `PipelineRuns` list failed to render with a `TypeError: Cannot read properties of undefined (reading 'length')` error. This occurred when the list contained a `PipelineRun` that was canceled after one or more `TaskRun` resources were created. As a consequence, the `PipelineRuns` list page was unusable. With this update, task status resolution logic handles canceled pipeline runs correctly. As a result, the `PipelineRuns` list renders properly, including canceled pipeline runs with their task status bars.
+
link:https://redhat.atlassian.net/browse/SRVKP-14864[SRVKP-14864]

//SRVKP-14930
`TektonDashboard` API no longer appears under Provided APIs in the web console::
Before this update, the {pipelines-shortname} operator details page in the web console incorrectly displayed the `TektonDashboard` API under the *Provided APIs* section. As a consequence, the web console displayed an unavailable `TektonDashboard` API entry. With this update, the `TektonDashboard` API is removed from the list of provided APIs. As a result, only intended APIs appear in the operator details page.
+
link:https://redhat.atlassian.net/browse/SRVKP-14930[SRVKP-14930]

.Pipelines as Code

//SRVKP-14599
Pipeline runs fail when using dynamic Git authentication secrets::
Before this update, the Git authentication secret was created in the reconciler instead of the controller. As a consequence, timing issues occurred during `PipelineRun` creation, which could cause pipeline runs to fail when using the `git-clone` task with the HTTP resolver. With this update, the controller manages the lifecycle of the Git authentication secret. The controller creates the secret before creating the `PipelineRun` and sets its owner reference after creation succeeds. As a result, `PipelineRun` authentication with the Git provider works reliably without timing-related failures.
+
link:https://redhat.atlassian.net/browse/SRVKP-14599[SRVKP-14599]
