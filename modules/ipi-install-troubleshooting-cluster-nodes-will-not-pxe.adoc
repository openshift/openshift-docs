= Cluster nodes do not PXE boot

[role="_abstract"]
When {product-title} cluster nodes do not PXE boot, run the troubleshooting checks on the cluster nodes that do not PXE boot. 

This procedure does not apply when installing an {product-title} cluster without the `provisioning` network.

.Procedure

. Check the network connectivity to the `provisioning` network.

. Ensure PXE is enabled on the NIC for the `provisioning` network and PXE is disabled for all other NICs.

. Verify that the `install-config.yaml` configuration file includes the `rootDeviceHints` parameter and boot MAC address for the NIC connected to the `provisioning` network. 
+
For example:
+
* Control plane node settings
+
[source,terminal]
----
bootMACAddress: 24:6E:96:1B:96:90 # MAC of bootable provisioning NIC
----
+
* Compute node settings
+
[source,terminal]
----
bootMACAddress: 24:6E:96:1B:96:90 # MAC of bootable provisioning NIC
----
