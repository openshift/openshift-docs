= Upgrade machine pools

[role="_abstract"]

In {product-title}, machine pool upgrades are decoupled from hosted control plane upgrades. This strategy gives you fine-grained control over cluster availability and allows you to schedule maintenance for one or several machine pools independently on your preferred schedule.
