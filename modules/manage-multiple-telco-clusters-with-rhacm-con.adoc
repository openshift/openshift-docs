= Manage multiple telco clusters with {rh-rhacm}

[role="_abstract"]
You can use {rh-rhacm-first} and {cgu-operator-full} ({cgu-operator}) to manage the lifecycle of many spoke clusters from a single hub cluster. You define policies on the hub, and {cgu-operator} orchestrates their enforcement across the clusters you target, so that you operate a fleet at scale instead of administering each cluster individually.
