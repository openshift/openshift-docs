= Run AI and ML workloads with {kueue-name}

[role="_abstract"]
You can run batch artificial intelligence (AI) and machine learning (ML) workloads on a shared {product-title} cluster by using {kueue-name}, a job queuing system that decides when workloads start, wait, or are preempted. {kueue-name} admits jobs against the quotas that you configure, so that expensive accelerator capacity stays fully used and important jobs are not delayed by less critical ones.
