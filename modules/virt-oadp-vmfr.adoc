= {oadp-short} virtual machine file restore (VMFR)

[role="_abstract"]
Current virtual machine (VM) backup recovery workflows require you to restore an entire VM to access a single file. This uses substantial cluster resources and time. The virtual machine file restore (VMFR) feature addresses this problem by providing a Kubernetes-native mechanism for file-level recovery from VM backups created by {oadp-short}.

By using standard tools such as a web browser or `rsync`, you can browse multiple backups simultaneously and recover only the files you need without restoring the entire VM.
