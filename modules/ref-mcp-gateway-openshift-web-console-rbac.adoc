= RBAC for the {mcpg} in the web console


[role="_abstract"]
You can use the web console for your {mcpg} resources according to your permissions.

Role-based-access (RBAC) is granted to the signed-in {ocp} web console user. The Model Context Protocol (MCP) Inspector backend uses the signed-in user token to read the selected `MCPGatewayExtension` and its referenced `Gateway`.

[cols="1,1,1,1,1", options="header"]
|===
| Feature | API group | Resources | Required verbs | Scope and notes

| MCP overview and setup
| `mcp.kuadrant.io`
| `mcpgatewayextensions`, `mcpserverregistrations`
| `get`, `list`, `watch`; add `create`, `update`, `delete` to manage them
| Namespace-scoped for normal use.

| Gateway and route management
| `gateway.networking.k8s.io`
| `gateways`, `httproutes`, `referencegrants`
| `get`, `list`, `watch`; add `create`, `update`, `delete` to manage them
| Grant access in each target namespace. Cross-namespace setup can create a `ReferenceGrant` in the Gateway's namespace.

| Policies shown on the MCP overview
| `kuadrant.io`
| `authpolicies`, `ratelimitpolicies`, `dnspolicies`, `tlspolicies`
| `get`, `list`, `watch`; add `create`, `update`, `delete` to manage them
| Namespace-scoped.

| External MCP server wizard
| `networking.istio.io`
| `serviceentries`, `destinationrules`
| `create`; add
| Needed only for external server registration.

| External server credentials
| Core (`""`)
| `secrets`
| `create`; add `delete` for rollback cleanup
| Secret read permission is not needed.

| External wizard namespace selectors
| Core (`""`)
| `namespaces`
| `list`, `watch`
| Cluster-scoped.

| Inspector gateway selection
| `mcp.kuadrant.io`, `gateway.networking.k8s.io`
| Selected `mcpgatewayextensions` and referenced `gateways`
| `get`
| The MCP inspector backend uses the signed-in user's token.

| Cross-namespace overview discovery
| `mcp.kuadrant.io`
| `mcpgatewayextensions`
| `list`, `watch`
| Optional cluster-wide access. Otherwise, discovery falls back to the selected namespace.
|===
