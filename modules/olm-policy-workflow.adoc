= Installation workflow

[role="_abstract"]
To troubleshoot installation or update issues, review the workflow Operator Lifecycle Manager (OLM) follows during the installation process.

When an Operator group specifies a service account, OLM completes the following steps:

. OLM picks up the `Subscription` object.
. OLM fetches the Operator group linked to the subscription.
. OLM checks if the Operator group specifies a service account.
. OLM creates a client scoped to the service account and uses it to install the Operator, ensuring permissions remain confined to that service account.
. OLM creates a new service account with the permissions specified in the CSV and assigns it to the Operator. The Operator then runs using this assigned service account.
