= Convert a virtual machine to a reusable template

[role="_abstract"]
You can create a `VirtualMachineTemplate` from an existing virtual machine (VM) by submitting a `VirtualMachineTemplateRequest` CR.

[WARNING]
====
The template creation process does not generalize the source VM. All secrets, credentials, and machine-specific identifiers from the source VM remain in the resulting template. Review and parameterize sensitive values before distributing the template.
====

.Prerequisites

* The source VM is stopped.
* You have the `virtualmachinetemplaterequest/create` permission in the source VM namespace.
* You have permission to create `VirtualMachineTemplates` and `DataVolumes` in the source VM namespace.

.Procedure

. Create a `VirtualMachineTemplateRequest` manifest:
+
[source,yaml]
----
apiVersion: template.kubevirt.io/v1beta1
kind: VirtualMachineTemplateRequest
metadata:
  name: my-template-request
spec:
  templateName: my-template
  virtualMachineRef:
    namespace: my-namespace
    name: my-source-vm
----
+
where:
+
`templateName`:: Specifies the name for the template to be created.
`virtualMachineRef.namespace`:: Specifies the namespace of the source VM.
`virtualMachineRef.name`:: Specifies the name of the source VM.

. Apply the manifest:
+
[source,terminal]
----
$ oc apply -f my-template-request.yaml
----

. Wait for the template to be created:
+
[source,terminal]
----
$ oc wait vmtr my-template-request --for=condition=Ready
----

.Verification

* Verify that the template was created:
+
[source,terminal]
----
$ oc get vmt my-template
----
