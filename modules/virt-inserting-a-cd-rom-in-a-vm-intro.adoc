= Virtual CD-ROM drives for running VMs

[role="_abstract"]
Configure a virtual machine (VM) to use a virtual CD-ROM drive to attach a storage device to a running VM. The storage device provides the VM with data as an ISO image. This makes it possible to install an operating system on a VM by using a CD-ROM.
