= Deploy machines on Ephemeral OS disks

[role="_abstract"]
An Ephemeral OS disk holds the operating system on the local storage of the virtual machine rather than on remote cloud storage. The local disk costs nothing extra and gives lower latency for reading, writing, and reimaging.
