= Monitor pending {kueue-name} workloads

[role="_abstract"]
{kueue-name} provides the `VisibilityOnDemand` feature so that you can monitor the pipeline of pending jobs in a cluster queue or a local queue. Monitoring pending workloads helps batch users estimate when their jobs will start, and helps batch administrators see where the queue is backed up.
