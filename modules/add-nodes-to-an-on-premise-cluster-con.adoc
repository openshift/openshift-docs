= Add nodes to an on-premise cluster

[role="_abstract"]
To run more application workloads on-premise and to maintain high availability, you can expand your {product-title} cluster with additional compute nodes. You can add worker nodes by using the {oc-first} to generate an ISO image, or by creating {op-system} machines directly on bare metal or VMware vSphere infrastructure and then approving their certificate signing requests.
