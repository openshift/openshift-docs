= Troubleshoot cluster infrastructure issues

[role="_abstract"]
Cluster administrators and Site Reliability Engineering (SRE) teams need to identify and resolve infrastructure-level problems so that their {product-title} clusters stay available and performant.

Troubleshooting cluster infrastructure helps you:

* *Diagnose infrastructure problems*: Investigate installation failures, network connectivity problems, and node-health symptoms to understand what is affecting cluster operation.
* *Minimize downtime*: Restore cluster health before problems affect your workloads.
* *Support cluster recovery*: Address configuration or capacity issues within your control, and gather relevant diagnostics for problems that require escalation to Red{nbsp}Hat.
