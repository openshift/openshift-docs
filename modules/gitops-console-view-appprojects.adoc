= View and manage AppProjects in the GitOps Console

You can view, create, and manage Argo CD AppProjects through the {gitops-shortname} Console Plugin.

.Prerequisites

* You have access to the {OCP} web console.
* You have enabled the {gitops-shortname} Console plugin.
* Your permissions allow you to list AppProjects in one or more namespaces.

.Procedure

. Navigate to *GitOps* -> *AppProjects* in the *Administrator* perspective.

. Optional: Select a specific project from the *Project* dropdown to view AppProjects in that namespace, or select all projects to view AppProjects across all namespaces.

. Optional: Filter AppProjects using the available filters:
+
* *Description*: Has Description, No Description
* *Applications*: Has Applications, No Applications
* *Project Type*: Default Project, Custom Projects
* *Source Repositories*: Has Source Repos, No Source Repos
* *Destinations*: Has Destinations, No Destinations

. To create a new AppProject:
+
.. Click *Create AppProject*.
.. Edit the YAML template with your project configuration including source repositories, destinations, and resource allow or deny lists.
.. Click *Create*.

. To view AppProject details, click an AppProject name in the list.
+
The details page provides the following tabs:
+
* *Details*: View identity and configuration summary
* *YAML*: Edit the AppProject manifest
* *Allow/Deny*: View allowed sources, destinations, and resource kinds
* *Applications*: View Applications that belong to this AppProject
* *Roles*: View Argo CD project roles and bindings
* *Sync Windows*: View configured sync windows
* *Events*: View Kubernetes events
