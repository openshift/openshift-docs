= Understand admission plugins for API request regulation

[role="_abstract"]
Admission plugins intercept requests to the {product-title} API server after authentication and authorization, and can validate or mutate them before they are persisted.
Understanding the default and webhook-based plugins helps you regulate what enters your cluster.
