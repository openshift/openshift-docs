= About release 4.10

[role="_abstract"]
{product-title-short} 4.10 includes new features, improvements, and updates.

Platform::
* OpenShift console dynamic security plugin (Technology Preview)
* Global node taints and tolerations in custom resources
* Enhanced status output for Central and secured cluster resources
* Administrative events for scan failures

Policy::
* Policy criteria for CVE fix availability

Vulnerability Management::
* Standardized base image definition and layer detection
* Vulnerability management for virtual machine workloads (Technology Preview)

Security::
* Automatic HTTP to HTTPS redirection for Central URLs
* Cluster registration secret for secure bootstrapping
* File activity monitoring (Technology Preview)
