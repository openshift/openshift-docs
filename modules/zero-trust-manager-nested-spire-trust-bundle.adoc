= Copying the trust bundle

[role="_abstract"]
Copy the trust domain root bundle from the parent cluster into a secret on the nested cluster. The agent sidecar uses the secret the first time it attests, and again when its pod is recreated.

Put X.509 certificates in Privacy-Enhanced Mail (PEM) format in the secret key `bundle.crt`. The nested `SpireServer` custom resource (CR) references the secret name in `spec.upstreamAuthority.spire.trustBundleSecret`.

.Prerequisites

* You logged in to the parent cluster with permission to read the trust bundle `ConfigMap`.
* You can log in to the nested cluster with permission to create secrets in the Operator namespace.
* You confirmed that the parent {spiffe-full} Runtime Environment (SPIRE) server is running.

.Procedure

. On the parent cluster, export the trust bundle by running the following command:
+
[source,terminal]
----
$ oc get configmap spire-bundle -n zero-trust-workload-identity-manager -o jsonpath='{.data.bundle\.crt}' > bundle.crt
----
+
If `spec.bundleConfigMap` on the `ZeroTrustWorkloadIdentityManager` CR is not `spire-bundle`, use the `ConfigMap` name from `spec.bundleConfigMap`. Copy the bundle from the parent server that signs the nested server certificate authority (CA).

. Confirm that the file contains a PEM certificate by running the following command:
+
[source,terminal]
----
$ openssl x509 -in bundle.crt -noout -subject
----

. Log in to the nested cluster.

. Create the secret in the Operator namespace by running the following command:
+
[source,terminal]
----
$ oc create secret generic spire-trust-bundle \
  -n zero-trust-workload-identity-manager \
  --from-file=bundle.crt=bundle.crt \
  --dry-run=client -o yaml | oc apply -f -
----

. Delete the local bundle file by running the following command:
+
[source,terminal]
----
$ rm -f bundle.crt
----

.Verification

* Confirm that the secret contains `bundle.crt` by running the following command:
+
[source,terminal]
----
$ oc get secret spire-trust-bundle -n zero-trust-workload-identity-manager -o go-template='{{if index .data "bundle.crt"}}bundle.crt present{{end}}{{"\n"}}'
----
