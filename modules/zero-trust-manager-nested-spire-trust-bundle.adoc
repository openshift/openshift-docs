= Copying the upstream trust bundle

[role="_abstract"]
Copy the upstream root trust bundle into a Secret on the downstream cluster. The downstream SPIRE server uses this bundle to authenticate the upstream server. You copy the bundle once for each new upstream link.

.Prerequisites

* You configured `spec.grpcEndpoint` and `spec.nestedSpire` on the upstream cluster.
* The `UPSTREAM_KUBECONFIG` and `DOWNSTREAM_KUBECONFIG` environment variables are set.

.Procedure

. Read the trust bundle ConfigMap name from the upstream cluster by running the following command:
+
[source,terminal]
----
$ BUNDLE_CM=$(oc get ZeroTrustWorkloadIdentityManager cluster --kubeconfig="${UPSTREAM_KUBECONFIG}" -o jsonpath='{.spec.bundleConfigMap}')
$ BUNDLE_CM=${BUNDLE_CM:-spire-bundle}
----
+
The default ConfigMap name is `spire-bundle`.

. Copy the PEM bundle from the upstream cluster by running the following command:
+
[source,terminal]
----
$ oc get configmap "${BUNDLE_CM}" -n zero-trust-workload-identity-manager --kubeconfig="${UPSTREAM_KUBECONFIG}" -o jsonpath='{.data.bundle\.crt}' > ./upstream-bundle.crt
----

. Create a Secret on the downstream cluster by running the following command:
+
[source,terminal]
----
$ oc create secret generic spire-upstream-bundle --from-file=bundle.crt=./upstream-bundle.crt -n zero-trust-workload-identity-manager --kubeconfig="${DOWNSTREAM_KUBECONFIG}"
----
+
The Secret data key must be `bundle.crt`. The value is the PEM-encoded upstream root certificate or certificates.

. Remove the local bundle file by running the following command:
+
[source,terminal]
----
$ rm -f ./upstream-bundle.crt
----

.Verification

* Confirm that the Secret contains the `bundle.crt` key by running the following command:
+
[source,terminal]
----
$ oc get secret spire-upstream-bundle -n zero-trust-workload-identity-manager --kubeconfig="${DOWNSTREAM_KUBECONFIG}" -o jsonpath='{.data.bundle\.crt}'
----
+
The command prints a non-empty base64 value.
