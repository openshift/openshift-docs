= Prompt injection safeguards

[role="_abstract"]
Prompt injection is a class of attack in which untrusted content attempts to override the instructions that govern a large language model (LLM). {ols-long} applies the following safeguards to reduce this risk.

[id="ols-prompt-injection-defense-posture_{context}"]
== Default defense posture

{ols-long} uses two complementary mechanisms to defend against prompt injection:

Main-model tool-safety instructions:: The default system prompt instructs the model to treat tool results as data rather than as instructions. These instructions remain active for all runtimes and whenever you use the default system prompt.

Active tool-result safety inspection:: {ols-long} inspects tool results for safety before the main model uses them. This inspection runs a classifier against the configured model provider and detects prompt injection attempts that are embedded in tool output, such as content that tries to override the system prompt, change the role of the model, or manipulate conversation context. If the inspection detects an injection attempt or cannot complete, the runtime stops the operation and does not send the rejected result to the model.

[id="ols-prompt-injection-limitations_{context}"]
== Known limitations

Be aware of the following gaps in coverage when you assess {ols-long}:

* Active tool-result inspection examines tool results only. It does not inspect user prompts, conversation history, retrieval-augmented generation (RAG) content, attachments, or skills.
* Content from a BYO Knowledge database enters the prompt as RAG context and is not inspected by the tool-result classifier. Treat any custom knowledge base as trusted content.
* If you replace the default system prompt by setting the `querySystemPrompt` field, you replace the default guardrails. You are then responsible for including topic restrictions and tool-safety instructions in your custom prompt.
* Inspection depends on the configured model provider. If the provider rejects the classifier request, inspection fails closed and {ols-long} reports a fixed safety message even when the underlying tool call succeeded.
