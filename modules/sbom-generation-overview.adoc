= SBOM generation overview

[role="_abstract"]
A Software Bill of Materials (SBOM) gives you a detailed overview of the software components, dependencies, and libraries within your application.

{product-title-short} generates an SBOM from the results of the image scans that it performs. You can generate an SBOM by using the {product-title-short} portal, the `roxctl` CLI, or the {product-title-short} API.
