= Capture network traces for support

[role="_abstract"]
When a network problem is difficult to reproduce from logs alone, you capture live packet traces on the host network or on a pod interface. {product-title} supports two collection methods, and Red{nbsp}Hat support uses these packet capture records to analyze traffic patterns and identify the root cause.
