= Configure a private storage endpoint by using Image Registry Operator discovery

[role="_abstract"]
On {azure-short} installer-provisioned infrastructure, the Image Registry Operator can discover the virtual network and subnet names for you and create a private endpoint to the registry storage account. Use this option to keep registry storage traffic off the public network with the least configuration.
