= Assign IP addresses on secondary networks

[role="_abstract"]
You can configure IP address assignments for secondary networks so that pods can connect to those networks. {product-title} supports static IP assignment, dynamic assignment through DHCP, and the Whereabouts IP Address Management (IPAM) plug-in for secondary network address management.
