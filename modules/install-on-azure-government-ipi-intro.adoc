= Install on Azure Government with installer-provisioned infrastructure

[role="_abstract"]
In {product-title} version {product-version}, you can install a cluster on Microsoft Azure into a government region. To configure the government region, you modify parameters in the `install-config.yaml` file before you install the cluster.
