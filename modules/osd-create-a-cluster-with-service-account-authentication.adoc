= Create an OSD cluster on {GCP} with Service Account authentication

[role="_abstract"]
Create an {product-title} cluster on {GCP} that authenticates with a service account.

Service Account authentication lets an {product-title} cluster access your {GCP} resources by using a Google Cloud service account. Use this method when the processes of your organization rely on service account keys.
