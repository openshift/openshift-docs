= Console Operator

[role="_abstract"]
The Console Operator is an optional cluster capability that can be disabled by cluster administrators during installation. If you disable the Console Operator at installation, your cluster is still supported and upgradeable. 

For more information about optional cluster capabilities, see "Cluster capabilities".


The Console Operator installs and maintains the {product-title} web console on a cluster. The Console Operator is installed by default and automatically maintains a console.
