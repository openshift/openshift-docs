= Customize S2I builder behavior

[role="_abstract"]
To modify the default `assemble` and `run` script behavior in {product-title}, you can customize Source-to-Image (S2I) builder images. You can override the scripts embedded in a builder image, pass environment variables and environment files into the build, and exclude source files from it.
