== Fixed issues

The following issues are fixed for this release:

* Before this update, an infinite boot loop occurred during Lenovo SR645 V3 hardware provisioning. As a consequence, the host stalled on a boot option restoration screen and could not complete the provisioning. With this release, the `ironic` resource skips setting the boot device. As a result, NVRAM loss does not occur, and provisioning succeeds. (link:https://issues.redhat.com/browse/OCPBUGS-129569[OCPBUGS-129569])

* Before this update, on the *Observe* -> *Metrics* page, multiple queries previously restarted their color index at `0`. As a consequence, series color squares were misaligned with graph lines. With this release, the color index is correctly offset by counting series from earlier queries. As a result, each color square matches its corresponding graph line. (link:https://issues.redhat.com/browse/OCPBUGS-132931[OCPBUGS-132931])
