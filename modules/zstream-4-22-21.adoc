== Fixed issues

The following issues are fixed for this release:

* Before this update, provisioning Lenovo SR645 V3 hardware with UEFI could enter an infinite boot loop after RHCOS was written to disk because NVRAM boot-option changes were lost due to Lenovo NVRAM restore behavior. As a consequence, the host stuck on a boot option restoration screen and could not complete provisioning. With this release, Ironic skips setting the boot device for Lenovo so the UEFI boot order with the shim bootloader can handle boot without triggering those NVRAM changes. As a result, provisioning of Lenovo SR645 V3 hardware succeeds. (link:https://issues.redhat.com/browse/OCPBUGS-129569[OCPBUGS-129569])

* Before this update, on the *Observe* -> *Metrics* page, when you ran more than one query the color square for each series used an offset that was always zero, so earlier queries never advanced through the color palette and each query restarted at the first color. As a consequence, the color square did not stay aligned with its graph line, and with more than one query the squares could share the same color so you could not tell which line belonged to which query. With this release, the color square counts the series from each earlier query and uses that total as its color index, matching the index the graph uses for the line. As a result, with more than one query on *Observe* -> *Metrics*, the color square beside each series matches that series line on the graph. (link:https://issues.redhat.com/browse/OCPBUGS-132931[OCPBUGS-132931])
