= Verify access to {product-title} web console for {product-title} cluster in ready state

[role="_abstract"]
Even when a {product-title} cluster returns a `ready` status, the web console is not accessible until the worker nodes have joined the cluster and the console workloads are running.

{product-title} clusters return a `ready` status when the control plane hosted in the {product-title} service account becomes ready. Cluster console workloads are deployed on the cluster's worker nodes.

.Procedure

* If your {product-title} cluster is ready but you are unable to access the {product-title} web console for the cluster, wait for the worker nodes to join the cluster and retry accessing the console.
+
You can either log in to the {product-title} cluster or use the `rosa describe machinepool` command in the `rosa` CLI watch the nodes.
