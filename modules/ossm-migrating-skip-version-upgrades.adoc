= Skip-version upgrades

[role="_abstract"]

You can upgrade to Service Mesh 3.3 with the skip-version method. Your mesh must use sidecar proxies and the `RevisionBased` update strategy.

For details, see link:https://docs.redhat.com/en/documentation/red_hat_openshift_service_mesh/3.1/html/updating/ossm-updating-openshift-service-mesh#skip-version-upgrade-with-the-RevisionBased-strategy_ossm-updating-openshift-service-mesh[Skip-version upgrades with the RevisionBased strategy and IstioRevisionTag].
