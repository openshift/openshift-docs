= Configure {cgu-operator} for cluster updates

[role="_abstract"]
Configure Operator coordination and `ClusterGroupUpgrade` custom resources so that {cgu-operator-full} can manage cluster updates.

To update managed clusters with `PolicyGenerator` resources in a {ztp} workflow, see "Upgrade managed clusters with the {cgu-operator-full}".
