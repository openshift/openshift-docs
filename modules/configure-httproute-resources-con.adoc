= Configure HTTPRoute resources

[role="_abstract"]
An `HTTPRoute` custom resource (CR) specifies how a gateway matches incoming HTTP requests and forwards them to backend services. Define `HTTPRoute` rules to control the routing behavior for the applications behind your gateway.
