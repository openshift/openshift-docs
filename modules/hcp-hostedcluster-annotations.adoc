= HostedCluster annotations reference

[role="_abstract"]
Several annotations are supported on `HostedCluster` objects. Annotations in the `hypershift.openshift.io/` namespace are set on the `HostedCluster` resource of the management cluster.

[NOTE]
====
Where a `spec` field is available for the same purpose as an annotation, use the `spec` field. The `spec` fields are admission-validated and provide stronger guarantees than annotations.
====

[cols="3,3,1", options="header"]
|===
|Annotation |Description |Status

|`hypershift.openshift.io/enable-metrics-forwarding`
|*Deprecated.* Previously used to enable forwarding of control plane metrics to the hosted cluster's monitoring stack.
Use `spec.monitoring.metricsForwarding` instead.
The annotation continues to be honored when `spec.monitoring` is not set.
When `spec.monitoring.metricsForwarding` is set, it takes precedence and the annotation is ignored.
For migration instructions, see xref:../hosted_control_planes/hcp-observability.adoc#hcp-metrics-forwarding-migrate-from-annotation_{context}[Migrating from annotation-based to API-based metrics forwarding].
|Deprecated since {product-title} 5.0

|`hypershift.openshift.io/disable-pki-reconciliation`
|Disables PKI reconciliation for the hosted cluster.
Use with caution; disabling PKI reconciliation prevents automatic certificate rotation.
|Supported

|`hypershift.openshift.io/skip-release-image-validation`
|Skips release image validation enforced by the HyperShift Operator, including minimum supported version checks for NodePools.
Applies to all reconciliation, not only creation and update events.
|Supported

|`hypershift.openshift.io/destroy-grace-period`
|Sets a grace period before destroying the hosted cluster.
Accepts a duration string such as `10m` or `1h`.
|Supported

|`hypershift.openshift.io/restart-date`
|Forces a rolling restart of control plane components when the value changes.
Set to the current timestamp to trigger a restart.
|Supported

|`hypershift.openshift.io/release-image`
|Read-only.
Records the release image that a given control plane deployment is tied to.
Set by the HyperShift Operator; not intended for user configuration.
To force an upgrade or override the release image, use `hypershift.openshift.io/force-upgrade-to`.
|Supported

|`hypershift.openshift.io/force-upgrade-to`
|Forces an upgrade to a specific release image, bypassing normal upgrade validation.
|Supported

|`hypershift.openshift.io/disable-profiling`
|Disables pprof profiling endpoints on control plane components.
|Supported

|`hypershift.openshift.io/cleanup-cloud-resources`
|When set to `true`, instructs the operator to clean up cloud resources when the hosted cluster is destroyed.
|Supported

|`hypershift.openshift.io/control-plane-priority-class`
|Specifies the priority class to use for control plane components.
|Supported

|`hypershift.openshift.io/api-critical-priority-class`
|Specifies the priority class for API-critical components such as the Kubernetes API server.
|Supported

|`hypershift.openshift.io/etcd-priority-class`
|Specifies the priority class for etcd.
|Supported

|`hypershift.openshift.io/topology`
|Specifies the topology mode for the hosted cluster.
Accepted values include `dedicated-request-serving-components`.
|Supported

|`hypershift.openshift.io/disable-monitoring-services`
|Disables the management cluster monitoring service monitors for the hosted control plane.
|Supported

|`hypershift.openshift.io/pod-security-admission-label-override`
|Overrides the pod security admission label applied to hosted cluster namespaces.
|Supported

|`hypershift.openshift.io/image-overrides`
|Comma-separated list of `image=ref` pairs that override control plane component images.
Example: `cluster-network-operator=example.com/cno:latest,ovn-kubernetes=example.com/ovnkube:latest`.
Used in disconnected or mirrored environments.
|Supported

|`hypershift.openshift.io/olm-catalogs-is-registry-overrides`
|Overrides the image registries for OLM catalog images.
|Supported

|`hypershift.openshift.io/kube-apiserver-gogc`
|Sets the `GOGC` environment variable on the Kubernetes API server.
|Supported

|`hypershift.openshift.io/kube-apiserver-gomemlimit`
|Sets the `GOMEMLIMIT` environment variable on the Kubernetes API server.
|Supported

|`hypershift.openshift.io/kube-apiserver-max-requests-inflight`
|Sets the `--max-requests-inflight` flag on the Kubernetes API server.
|Supported
|===
