= Download a kubeconfig file for a service account

[role="_abstract"]
You can download a kubeconfig file for a service account from the {product-title} web console. Use the file to grant cluster access as the service account to automation, continuous integration and continuous delivery (CI/CD) pipelines, or external tools, without generating a token and building the file manually.

.Prerequisites

* You're logged in to the web console.
* You installed the {oc-first}.
* You have permission to create tokens for the service account. If you don't have this permission, the *Download kubeconfig* action doesn't display.
* The service account has the roles it needs for its tasks.

.Procedure

. In the web console, select the project that contains the service account you want to download a kubeconfig file for from the *Project* list.

. Navigate to *User Management* -> *ServiceAccounts*.

. Click the Options menu {kebab} next to the service account, then select *Download kubeconfig*.
+
Alternatively, click the service account name to open its details page, then select *Download kubeconfig* from the *Actions* list.
+
Your browser downloads a file named `kubeconfig-<project_name>-<service_account_name>`. The file contains the cluster API server URL, a token for the service account, and a context that combines them so `oc` can connect.
+
[IMPORTANT]
====
The token in the file expires after 1 hour, and the file stops working. When that happens, download a new file.

Anyone who has the file can access the cluster with the service account's permissions. Store it securely, and don't share it.
====

.Verification

* Run the following command, using the file you downloaded:
+
[source,terminal]
----
$ oc --kubeconfig <path_to_kubeconfig_file> whoami
----
+
The output shows the service account in the format `system:serviceaccount:<project_name>:<service_account_name>`.
