[id="zstream-4-16-73-fixed-issues_{context}"]
== Fixed issues

* Before this update, Kubernetes API server rollouts in clusters that had encrypted etcd caused Transmission Control Protocol (TCP) reset (RST) storms. This behavior resulted in application pod traffic drops. With this release, the Kubernetes API server rollouts do not cause traffic drops in encrypted clusters, which improves service stability.(link:https://redhat.atlassian.net/browse/OCPBUGS-81479) (link:https://issues.redhat.com/browse/OCPBUGS-128828[OCPBUGS-128828])
