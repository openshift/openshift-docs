= Deploy machines into a placement group for network performance

[role="_abstract"]
A placement group controls how your cloud provider distributes machines across the underlying hardware. Placing machines in one group shortens the network path between them, and a high-bandwidth network adapter can then improve throughput and latency for workloads that communicate across those machines.
