= Configuring hierarchical cohorts

[role="_abstract"]
Configure a hierarchical cohort with a root cohort, a child cohort, and a cluster queue. The root cohort defines shared quota that the cluster queue can borrow through the child cohort.

.Prerequisites

* You have cluster administrator permissions.
* You installed the {kueue-name} Operator on your cluster.
* You created a `Kueue` custom resource (CR).
* A `ResourceFlavor` object named `default-flavor` exists.

.Procedure

. Create a file named `cohorts.yaml` with the following content:
+
.Example two-level cohort hierarchy
[source,yaml]
----
apiVersion: kueue.x-k8s.io/v1beta2
kind: Cohort
metadata:
  name: shared-resources
spec:
  resourceGroups:
  - coveredResources: ["cpu"]
    flavors:
    - name: default-flavor
      resources:
      - name: cpu
        nominalQuota: 1
---
apiVersion: kueue.x-k8s.io/v1beta2
kind: Cohort
metadata:
  name: engineering
spec:
  parentName: shared-resources
---
apiVersion: kueue.x-k8s.io/v1beta2
kind: ClusterQueue
metadata:
  name: borrow-only-queue
spec:
  namespaceSelector: {}
  cohortName: engineering
  resourceGroups:
  - coveredResources: ["cpu"]
    flavors:
    - name: default-flavor
      resources:
      - name: cpu
        nominalQuota: 0
----
+
where:

`shared-resources`:: Specifies the root cohort that contributes 1 CPU. Cohorts and cluster queues below it can share this CPU.
`engineering`:: Specifies the child cohort that forms a structural level without adding quota.
`borrow-only-queue`:: Specifies the cluster queue that defines the CPU and `default-flavor` pair with zero nominal quota. It can use up to 1 CPU from the root cohort.

. Apply the configuration by running the following command:
+
[source,terminal]
----
$ oc apply -f cohorts.yaml
----

.Verification

. Verify the cohort objects by running the following command:
+
[source,terminal]
----
$ oc get cohorts
----
+
.Example output
[source,terminal]
----
NAME               AGE
engineering        10s
shared-resources   10s
----

. Verify that the cluster queue belongs to the `engineering` cohort by running the following command:
+
[source,terminal]
----
$ oc get clusterqueue borrow-only-queue -o jsonpath='{.spec.cohortName}{"\n"}'
----
+
.Example output
[source,terminal]
----
engineering
----
