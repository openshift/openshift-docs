= Updating {support-log-gather}

[role="_abstract"]
You can update {support-log-gather} to ensure compatibility with the {product-title} version after upgrading your cluster.


.Prerequisites
* You have updated your {product-title} cluster.
* You have installed a previous version of {support-log-gather}.
* You have installed the OpenShift CLI (`oc`).
* You have access to the cluster using an account with `cluster-admin` permissions.

.Procedure
. Log in to the OpenShift CLI (`oc`).

. Update the `Subscription` custom resource (CR) that you created while installing {support-log-gather} by running the following command:
+
[NOTE]
====
Because `operator.openshift.io/v1alpha1` is deprecated and will be removed in a future release, you can update the CR to use `operator.openshift.io/v1`.
====
+
[source,terminal]
----
$ oc patch subscription support-log-gather-operator -n must-gather-operator --type merge -p '{"spec":{"channel":"stable"}}'
----

.Verification

* Verify that the Operator updated successfully by running the following command:
+
[source,terminal]
----
$ oc get csv -n must-gather-operator
----
+
.Expected output
[source,terminal]
----
NAME                                  DISPLAY                VERSION   REPLACES                              PHASE
support-log-gather-operator.v5.0.0    support log gather     5.0.0     support-log-gather-operator.v4.22.0   Succeeded
----
