= Gang scheduling configuration

[role="_abstract"]
The `spec.config.gangScheduling.policy` field in the `Kueue` custom resource (CR) controls the gang scheduling policy for workloads.

The following example uses parallel admission and a 10-minute start timeout:

// Example sources:
// Timeout of 600 seconds:
// https://github.com/openshift/kueue-operator/blob/f940304dae5befd94ffdf0a9a7f9a34aa4e9fd6f/pkg/configmap/configmap_test.go#L273-L335
// BatchJob integration with the ByWorkload policy:
// https://github.com/openshift/kueue-operator/blob/f940304dae5befd94ffdf0a9a7f9a34aa4e9fd6f/test/e2e/e2e_gangscheduling_test.go#L264-L430
.Example `Kueue` CR with gang scheduling configured
[source,yaml]
----
apiVersion: kueue.openshift.io/v1
kind: Kueue
metadata:
  name: cluster
  labels:
    app.kubernetes.io/managed-by: kustomize
    app.kubernetes.io/name: kueue-operator
spec:
  config:
    integrations:
      frameworks:
      - BatchJob
    gangScheduling:
      policy: ByWorkload
      byWorkload:
        admission: Parallel
        timeoutSeconds: 600
----

The `policy` field accepts the following values:

.`spec.config.gangScheduling.policy` values
[cols="1,3",options="header"]
|===
|Value
|Behavior

|`ByWorkload`
|Processes each workload as a single unit for admission. The readiness timeout applies to the entire workload. If retries remain or you omit the limit, {kueue-name} evicts and requeues the workload for another admission attempt. If no retries remain, {kueue-name} deactivates the workload. Include the `byWorkload` field.

|`ByWorkloadDefaults`
|Processes each workload as a single unit for admission and uses the default admission, timeout, and requeue settings. The `ByWorkloadDefaults` policy does not allow the `byWorkload` field.

|`None`
|Uses parallel admission and a fixed one-year readiness timeout. For workloads that reach a ready state within one year, this policy provides the same behavior as disabling gang scheduling. Workloads that do not reach a ready state remain subject to the timeout. The `None` policy does not allow the `byWorkload` field.

|Empty string (`""`)
|Uses `ByWorkloadDefaults`, the default policy. An empty `policy` value does not allow the `byWorkload` field.
|===
