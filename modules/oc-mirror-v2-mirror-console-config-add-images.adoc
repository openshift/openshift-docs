= Configure additional images for mirroring

[role="_abstract"]
To include individual container images in a mirror, configure additional images in the OpenShift Mirror Console. Additional images supply the container images required for disconnected environments that the platform channels or Operator catalogs do not cover.

.Prerequisites

* The OpenShift Mirror Console is open in a browser.
* You have configured a pull secret.

.Procedure

. On the Mirror Configuration page, click the *Additional Images* tab to select container images for the mirror.

. Click *Add image*.

. In the *Image Name* field, enter the reference for the container image to mirror.

. Optional: To include another image in the mirror, click *Add image* and repeat the previous steps for each image.

. Click the *Preview* tab to review the generated `ImageSetConfiguration` file before saving.

. Optional: On the *Preview* tab, in the *Archive Size* field, enter the size of each archive in GiB. If you leave the field empty or enter `0`, oc-mirror uses the default archive size.

. Optional: To rename the file, use the *Edit* icon next to the filename to enter a new name.

. Save or download the configuration by doing one of the following:

.. Click *Save Configuration* to save the file with the default filename, or with the new name if you renamed it. The file then appears in the *ImageSetConfiguration File* list on the Mirror Operations page.

.. Click *Download YAML* to download a copy of the file to the default downloads folder on your computer. The copy does not appear on the Mirror Operations page.

.Verification

* Confirm that the *Preview* tab shows the expected `additionalImages` entries.
