= Configure additional images for mirroring

[role="_abstract"]
Configure additional images in the OpenShift Mirror Console to include individual container images in a mirror. You can add one or more image references, then preview and save or download the configuration.

.Prerequisites

* You are logged in to the OpenShift Mirror Console.
* You have configured a pull secret.

.Procedure

. On the Mirror Configuration page, click the *Additional Images* tab to choose container images for the mirror.

. Click *Add Image* and enter the details of the container image you want to mirror.

. Optional: To include another image in the mirror, click *Add Image* and repeat the previous step for each image.

. Click the *Preview* tab to review the generated `ImageSetConfiguration` file before saving.

. To save the configuration, do one of the following:

.. Click *Save Configuration* to save the file with the auto-generated filename shown above the *Save Configuration* button.

.. Optional: To rename the file before saving, click the *Edit* icon next to the filename and enter the new name into the text box.

.. Click *Download YAML* to download the `ImageSetConfiguration` file to your local system.

.Verification

* Confirm that the downloaded or saved file contains the expected `additionalImages` entries by opening the YAML file in a text editor.
