= Configure additional images for mirroring

[role="_abstract"]
Include individual container images in a mirror by adding them as additional images in the OpenShift Mirror Console. Add images that platform channels and Operator catalogs do not cover.

.Prerequisites

* You have opened the OpenShift Mirror Console in a browser.
* You have configured a pull secret.

.Procedure

. On the Mirror Configuration page, click the *Additional Images* tab to select container images for the mirror.

. Click *Add image*.

. In the *Image Name* field, enter the reference for the container image to mirror.
+
Enter a complete image reference that includes either a tag or a SHA-256 digest, as in the following examples:
+
* `registry.redhat.io/example/image:tag`
* `registry.redhat.io/namespace/image@sha256:<digest>`
+
[NOTE]
====
The console displays a warning when the image name:

* contains spaces
* does not contain a `/`
* contains neither a `:` nor a `@`

The warning does not prevent you from saving the configuration, so check the reference before you save.
====

. Optional: To include another image in the mirror, repeat the previous two steps for each image.

. Click the *Preview* tab to review the generated `ImageSetConfiguration` file before saving.

. Optional: On the *Preview* tab, in the *Archive Size* field, enter the maximum size of each archive in GiB. This setting applies when you mirror to disk. If you leave the field empty or enter `0`, oc-mirror uses the default archive size.

. Optional: To rename the file, complete the following steps:

.. Click the *Edit* icon next to the filename.

.. Enter a new name.

. Save or download the configuration by doing one of the following:

.. Click *Save Configuration* to save the file.
+
If you did not rename the file, the console saves it as `imageset-config-<utc_timestamp>.yaml`. The timestamp uses Coordinated Universal Time (UTC), for example, `imageset-config-2026-11-11-11-14-00-UTC.yaml`. If you enter the name of an existing configuration, the console overwrites it. The file appears in the *ImageSetConfiguration File* list on the Mirror Operations page.

.. Click *Download YAML* to download a copy of the file to the default downloads location on your local system. The copy does not appear on the Mirror Operations page.

.Verification

. If you saved the configuration in the console, verify that it is available for mirror operations:

.. Go to the Mirror Operations page.

.. Confirm that the configuration appears in the *ImageSetConfiguration File* list.

. If you downloaded a copy of the configuration, verify its contents:

.. Open the downloaded YAML file.

.. Confirm that the file contains the expected `additionalImages` entries.
