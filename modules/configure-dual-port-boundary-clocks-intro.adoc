= Configure dual-port boundary clocks

[role="_abstract"]
You can configure boundary clocks that use both ports on a NIC, with or without GNSS assistance, to improve resiliency of the PTP synchronization chain.

.Prerequisites

* The PTP Operator is installed.
* You are familiar with the dual-port boundary clock topology.
See the "Understand PTP clock topologies" section of the "Understand PTP concepts" job.
