= Configure and maintain the pod network

[role="_abstract"]
The Cluster Network Operator manages the pod network that your cluster was installed with, including the CIDR ranges and network plugin settings that every pod depends on. Review and adjust that configuration so that pod, service, and machine address space stays non-overlapping and meets your organization's requirements.
