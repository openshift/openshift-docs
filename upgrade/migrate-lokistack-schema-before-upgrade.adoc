= Migrate the LokiStack storage schema before upgrading

:context: migrate-lokistack-schema-before-upgrade

toc::[]

[role="_abstract"]
Complete this migration if your LokiStack references a BoltDB-based storage schema (v11 or v12). {logging-title-uc} 6.7 includes Loki 4.0, which requires all LokiStack instances to use the Time Series Database (TSDB) schema (v13).
