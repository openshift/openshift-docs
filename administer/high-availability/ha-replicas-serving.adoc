= Configure high availability for Knative Serving
:context: ha-replicas-serving

[role="_abstract"]
You can change the number of replicas for the Knative Serving components by modifying the `spec.high-availability.replicas` value in the `KnativeServing` custom resource (CR).

High availability (HA) is available by default for the Knative Serving `activator`, `autoscaler`, `autoscaler-hpa`, `controller`, `webhook`, `domain-mapping`, `domainmapping-webhook`, `kourier-control`, and `kourier-gateway` components, which are configured to have two replicas each.
