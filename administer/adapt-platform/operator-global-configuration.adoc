= Set {ServerlessOperatorName} global configuration
:context: operator-global-configuration

toc::[]

[role="_abstract"]
The {ServerlessOperatorName} manages the global configuration of your Knative installation. Set values in the `KnativeServing` and `KnativeEventing` custom resources (CRs) so that the Operator propagates them to the system ConfigMaps that each component reads.
