[role="_abstract"]
You can override the default configuration of the deployments that the {ServerlessOperatorName} manages by modifying the `workloads` spec in the `KnativeServing` and `KnativeEventing` custom resources (CRs).

Use these overrides to set resource requests and limits, adjust readiness and liveness probes, and control scheduling for individual platform components.
