[role="_abstract"]
You can set the resource requests and limits for the `kube-rbac-proxy` container in each part of your {ServerlessProductName} installation independently, through the corresponding custom resource (CR).

The `kube-rbac-proxy` component provides internal authentication and authorization capabilities for {ServerlessProductName}, and each part of the installation runs its own `kube-rbac-proxy` container.
