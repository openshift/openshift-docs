= Understanding security for {product-title}

toc::[]

[role="_abstract"]
Review the Red{nbsp}Hat, Amazon Web Services (AWS), and customer security responsibilities for the managed {product-title}, including data management, network security, and regulatory compliance. Understanding these boundaries helps you prevent security gaps.
