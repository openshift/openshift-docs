= Control, secure, and monitor outbound traffic from your cluster
:context: rhcl-egress-gateway

toc::[]

[role="_abstract"]
You can allow egress gateways to inject sensitive credentials, such as API keys or bearer tokens, into outbound requests on behalf of application workloads. This ensures that applications do not store or manage credentials directly.

Credential injection builds upon the egress gateway deployment and workload identity verification mechanisms. For setup details, see "Control, secure, and monitor outbound traffic from your cluster".
