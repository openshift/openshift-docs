= Route pod traffic through an egress gateway
:context: rhcl-egress-dns-routing

toc::[]

[role="_abstract"]
You can configure how workload pods route traffic through an egress `Gateway` object to external services. {prodname} supports multiple routing approaches depending on whether the application can be modified to use an internal hostname.

Before you configure DNS routing for egress traffic, ensure that you have deployed an egress gateway in your cluster. For more information, see "Deploying an egress gateway".
