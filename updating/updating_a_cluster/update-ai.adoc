= Updating a cluster with the AI Console Plugin
include::_attributes/common-attributes.adoc[]
:context: updating-ai

toc::[]

[role="_abstract"]
For simplified planning of updates, you can use the AI Console Plugin on the web console to check update availability, evaluate compatibility with your cluster, and produce an update plan that you can approve in order to start a cluster update.

The plugin uses OpenShift Lightspeed Service (OLS) to gather information about possible update paths, perform an update precheck and compatibility analysis, and store proposed plans in an `AnalysisResult` custom resource (CR) for you to review.

You can then approve the plan to manually trigger a cluster update or reject the plan. The plugin does not trigger cluster updates without your manual approval.

[IMPORTANT]
====
Always review AI-generated update analysis before beginning an update.
====
