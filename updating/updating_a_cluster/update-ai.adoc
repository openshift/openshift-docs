= Creating an AI-generated cluster update assessment
include::_attributes/common-attributes.adoc[]
:context: updating-ai

toc::[]

[role="_abstract"]
For simplified planning of updates, you can use the AI-driven *Cluster Update* page on the web console to check update availability, evaluate compatibility with your cluster, and produce an update assessment that you can review as you prepare for a cluster update.

:FeatureName: Creating an AI-generated cluster update assessment
include::snippets/technology-preview.adoc[]

The assessment tool uses OpenShift Lightspeed Service (OLS) to run an `AgenticRun` custom resource (CR), which is used to perform an update precheck and compatibility analysis, and store proposed plans in an `AnalysisResult` CR for you to review.

You can then review the assessment before deciding whether or not to manually start a cluster update using a method of your choosing. The assessment tool does not trigger cluster updates.

[IMPORTANT]
====
Always review an AI-generated update analysis before beginning an update.
====
