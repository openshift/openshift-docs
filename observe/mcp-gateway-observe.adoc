= Observe {mcpg} connections
:context: mcp-gateway-observe

toc::[]

[role="_abstract"]
You can use observability in {mcpg} to achieve the following goals:

* Track the lifecycle of a request through contexts, tool calls, and APIs.
* Capture high-fidelity, event-driven context at state boundaries and critical moments.
* Monitor total system performance, saturation, and overall service health in real time.
