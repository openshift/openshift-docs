= Contributing to OpenShift documentation

== Maintenance mode: contributions limited to the documentation team

[IMPORTANT]
====
This repository is in maintenance mode and is not accepting contributions from outside the OpenShift documentation team, including AI-generated pull requests.

We are migrating the documentation to a new platform, with completion planned by the end of calendar year 2026. The migration requires extensive restructuring and coordination across the documentation set. To keep this work consistent, contributions are limited to the documentation team during the transition.

Customers and stakeholders, including engineering and support teams, should https://redhat.atlassian.net/secure/CreateIssueDetails%21init.jspa?priority=10003&summary=%5BDoc%5D&pid=10325&issuetype=10016&components=14669[open a documentation bug in Jira] instead of submitting a pull request. Include the affected documentation URL, a description of the issue, and any suggested corrections.
====
