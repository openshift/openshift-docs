= Creating virtual machines by using the CLI
include::_attributes/common-attributes.adoc[]
:context: virt-creating-vms-cli

toc::[]

[role="_abstract"]
You can create virtual machines (VMs) from the command line by editing or creating a `VirtualMachine` manifest. You can also create a VM from an operating system image that you import, upload, build into a container disk, or clone from an existing persistent volume claim (PVC).

[NOTE]
====
You can also create VMs from instance types by using the {product-title} web console.
====

[IMPORTANT]
====
You must install the QEMU guest agent on VMs created from operating system images that are not provided by Red{nbsp}Hat.
====
