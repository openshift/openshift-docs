= Run automated postinstallation configuration
:context: virt-platform-autopilot

toc::[]

[role="_abstract"]
The `virt-platform-autopilot` controller replaces manual postinstallation configuration by automatically applying opinionated defaults to the virtualization platform and installed optional components.
You can customize or opt out of any managed configuration.
