= Specifying nodes for {VirtProductName} components
:context: virt-node-placement-virt-components

toc::[]

[role="_abstract"]
You can configure node placement rules to specify where {VirtProductName} Operators, workloads, and controllers are deployed. Custom placement rules allow you to isolate virtual machine (VM) traffic or dedicate specialized compute resources to critical workloads.

[IMPORTANT]
====
You can configure node placement rules for some components after installing {VirtProductName}, but virtual machines cannot be present if you want to configure node placement rules for workloads.
====
