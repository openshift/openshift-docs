= Connect a virtual machine to a physical network by using an Open vSwitch bridge
include::_attributes/common-attributes.adoc[]
:context: virt-connecting-vm-to-physical-network-ovs-bridge

toc::[]

[role="_abstract"]
You can connect a virtual machine (VM) to the physical network infrastructure by configuring an OVN-Kubernetes secondary user-defined network (UDN) with the localnet topology. By configuring the `ClusterUserDefinedNetwork` custom resource (CR), you can select the projects that have access to the physical network and assign VLANs to projects.
