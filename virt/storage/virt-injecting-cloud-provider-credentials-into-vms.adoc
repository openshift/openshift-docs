= Injecting cloud provider credentials into virtual machines
include::_attributes/common-attributes.adoc[]
:context: virt-injecting-cloud-provider-credentials-into-vms

toc::[]

[role="_abstract"]
You can enable virtual machines (VMs) running on managed clusters to authenticate with cloud provider APIs without managing static credentials. To do this, you can inject cloud provider service account tokens into a VM guest by using `containerPath` volumes and `virtiof` filesystems.
