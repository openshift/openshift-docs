= Injecting cloud provider credentials into virtual machines
include::_attributes/common-attributes.adoc[]
:context: virt-injecting-cloud-provider-credentials-into-vms

toc::[]

[role="_abstract"]
You can inject cloud provider service account tokens into virtual machine (VM) guests by using containerPath volumes and virtiofs. This enables VMs running on managed {product-title} clusters, such as Red{nbsp}Hat OpenShift Service on AWS (ROSA) and Azure Red{nbsp}Hat OpenShift (ARO), to authenticate with cloud provider APIs.
