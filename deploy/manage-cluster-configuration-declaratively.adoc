= Manage cluster configuration declaratively

:context: manage-cluster-configuration-declaratively

toc::[]

[role="_abstract"]
Manage your {OCP} cluster configuration declaratively through Git repositories and Argo CD. Configure the default Argo CD instance, deploy applications with cluster-wide configurations, and customize permissions for cluster-scoped instances.

== Prerequisites

* You have logged in to the {OCP} cluster as an administrator.
* You have installed the {gitops-title} Operator on your {OCP} cluster.
* You have installed the OpenShift CLI (`oc`).
