= Enable GitOps across multiple clusters

:context: enable-gitops-across-multiple-clusters

toc::[]

[role="_abstract"]
Enable multi-cluster GitOps by configuring the Argo CD Agent in a hub-and-spoke model. Set up the Principal component on the hub cluster, prepare spoke cluster environments, and install Agent components in managed or autonomous mode.

[id="prerequisites_{context}"]
== Prerequisites

* You have installed the {gitops-title} Operator on two {OCP} clusters.
* You have installed the OpenShift CLI (`oc`).
* You have installed a cluster-scoped Argo CD instance on the hub cluster.
* You have configured the `Apps in any namespace` feature on the hub cluster.
* You have installed the `argocd-agentctl` CLI tool.
* You have installed the `helm` CLI for your Agent setup. Ensure that the `helm` CLI version is later than v3.8.0.
