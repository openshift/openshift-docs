= Using enhanced metrics in {microshift-short}
include::_attributes/attributes-microshift.adoc[]
:context: microshift-enhanced-metrics

toc::[]

[role="_abstract"]
You can enable optional Kubernetes metric exporters on {microshift-short} to expose node, cluster object, and resource usage metrics that are compatible with OpenShift monitoring dashboards and alerting rules. Install each exporter individually as an optional RPM package and restart {microshift-short} to deploy the component.
