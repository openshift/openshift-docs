= Install and configure {mcpg}
:context: mcp-gateway-install

toc::[]

[role="_abstract"]
To use {mcpg} with {prodname}, first install the Kuadrant Operator by using the supported method for your environment. The Kuadrant Operator manages {mcpg} and other included components through Helm charts. You can use OLM or the {ocp} web console to install the Kuadrant Operator where supported. Do not install managed components separately. After installation, set up connections by applying the custom resources that you require.
