= Inspect clusters with MCP server for Red Hat OpenShift
include::_attributes/common-attributes.adoc[]
:context: mcp-server-overview

toc::[]

[role="_abstract"]
The MCP server for Red{nbsp}Hat OpenShift helps you diagnose problems on your {product-title} cluster. Optional `ovn-kubernetes` and `cni-diagnostics` toolsets extend it with read-only OVN, OVS, and CNI tools for OVN-Kubernetes troubleshooting.
