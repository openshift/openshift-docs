[role="_abstract"]
Configure the {insights-operator} to control how {red-hat-lightspeed} identifies cluster issues and recommendations. Customize what configuration and component failure data is gathered, manage alerts, enable on-demand gathering, and obfuscate data before transmission to Red{nbsp}Hat.
