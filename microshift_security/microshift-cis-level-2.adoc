= Preparing {microshift-short} for CIS Level 2 compliance
:context: microshift-cis-level-2

toc::[]

[role="_abstract"]
You can run {microshift-short} on a {op-system-base-full} host that is hardened to the Center for Internet Security (CIS) Level 2 benchmark.
Use this content when you must meet organizational security compliance requirements for edge deployments while keeping core {microshift-short} functions such as scheduling, ingress, and persistent storage available.

[IMPORTANT]
====
This documentation covers RPM package-mode installations only.
Image-based deployments such as {op-system-ostree} and {op-system-image} are out of scope for the initial CIS Level 2 support.
====
