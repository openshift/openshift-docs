= Troubleshoot the installation
include::_attributes/common-attributes.adoc[]
:context: troubleshoot-installation

toc::[]

[role="_abstract"]
Diagnose and resolve common installation issues. Most installation failures occur when cluster prerequisites are not met before installing operators.

[IMPORTANT]
====
Missing storage prerequisites cause many silent installation failures. Verify that your cluster meets both storage requirements before installing operators:

* **Block storage (StorageClass)**: For `LokiStack` internal PVCs
* **Object storage (S3-compatible)**: For actual log data

For complete prerequisites, see xref:../install/verify-cluster-prerequisites.adoc#verify-cluster-prerequisites[Verify cluster prerequisites for logging].
====
