[role="_abstract"]
You can modify the hostname and TLS certificate of the Web console, OAuth server, and Downloads component routes in {product-title} version 4.14 and later.

The changes that you make to the component routes in this guide are described in greater detail in the {OCP} documentation, see resources about customizing the internal OAuth server URL, console route, and download route in __Additional resources__.
