[role="_abstract"]
The Knative (`kn`) CLI is the command-line interface for {ServerlessProductName}. Look up the syntax, flags, and arguments for a command you already know you need, grouped by the part of the product it acts on.

Knative Serving CLI commands:: Create, update, apply, and describe Knative services, work with service configurations in offline mode, define multiple containers in a service spec, and create and manage domain mappings.

Knative Eventing CLI commands:: List event source types, create and manage container sources, API server sources, ping sources, and Apache Kafka event sources, and specify sinks with the `--sink` flag.

Knative Functions CLI commands:: Create, run, build, deploy, list, describe, call, and delete functions.
