= Build a custom event source by using a sink binding
include::_attributes/common-attributes.adoc[]
:context: serverless-sinkbinding

toc::[]

[role="_abstract"]
If your event producer embeds a `PodSpec` template, you can connect it to a sink by creating a `SinkBinding` object. You can create a sink binding by using YAML, the Knative (`kn`) CLI, or the {ocp-product-title} web console, and you can run it inside {SMProductShortName}.
