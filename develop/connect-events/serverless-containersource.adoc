= Build a custom event source by using a container source
include::_attributes/common-attributes.adoc[]
:context: serverless-containersource

toc::[]

[role="_abstract"]
If your event producer runs as a container image, you can connect it to a sink by creating a `ContainerSource` object.

Build a container image that follows the Knative guidelines, then create the container source by using the Knative (`kn`) CLI or the {ocp-product-title} web console. You can also run the container source inside {SMProductShortName}.
