= Route and filter events so each consumer gets only what it needs
include::_attributes/common-attributes.adoc[]
:context: route-and-filter-events

toc::[]

[role="_abstract"]
Route events through brokers, filter them to the right consumer with triggers, and fan out a single event stream to multiple subscribers using channels and subscriptions. You can also subscribe a function directly to a CloudEvent stream.
