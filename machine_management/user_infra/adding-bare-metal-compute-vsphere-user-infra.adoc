= Add compute machines without {vmw-short} integration
:context: adding-bare-metal-compute-vsphere-user-infra

toc::[]

[role="_abstract"]
You can expand an existing {product-title} cluster on {vmw-first} by adding bare-metal compute machines or virtual machines (VMs) without {vmw-short} integration.

This workflow applies to compute machines added after cluster installation. The control plane remains on {vmw-short}.

You must provision and replace the added compute machines manually. You cannot use the Machine API, compute machine sets, or the cluster autoscaler to manage these machines.

This workflow applies to clusters installed by using installer-provisioned infrastructure, user-provisioned infrastructure, or the Assisted Installer.
