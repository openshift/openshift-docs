= Managing RHCOS version streams within a hosted cluster
:context: hcp-dual-stream

toc::[]

[role="_abstract"]
In {hcp}, {op-system-base-full} 9 and {op-system-base} 10 compute nodes can run simultaneously within a single hosted cluster. By controlling the {op-system-first} major version for each `NodePool` object independently, you can incrementally migrate from {op-system-base} 9 to {op-system-base} 10 without replacing the entire cluster.
