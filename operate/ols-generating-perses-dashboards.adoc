[role="_abstract"]
When monitoring cluster operations, use {ols-long} to generate interactive Red Hat build of Perses charts using natural language queries. Generating charts using natural language eliminates the requirement to manually write complex PromQL queries and allows you to save these visualizations directly to your active dashboards.
