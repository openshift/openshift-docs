= Monitor infrastructure health with the Alarms API
include::_attributes/common-attributes.adoc[]
:context: ocloud-monitoring-alarms-with-the-alarms-api

toc::[]

[role="_abstract"]
You can monitor infrastructure and cluster health by querying alarms through the O-Cloud Manager Alarms API. The Alarms API aggregates alerts from {rh-rhacm} Observability and exposes them as O-RAN O2 IMS compliant alarm records. You can query, filter, and acknowledge alarms, and create subscriptions to receive real-time notifications when alarm states change.
