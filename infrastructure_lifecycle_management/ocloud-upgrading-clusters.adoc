= Upgrade clusters deployed with the O-Cloud Manager
include::_attributes/common-attributes.adoc[]
:context: ocloud-upgrading-clusters

toc::[]

[role="_abstract"]
You can upgrade clusters provisioned by the O-Cloud Manager by creating a new `ClusterTemplate` custom resource (CR) version for the target release and updating the `ProvisioningRequest` CR to reference it. The O-Cloud Manager supports image-based upgrades for single-node {product-title} clusters and ClusterVersion upgrades for multi-node clusters. You can perform these operations by editing the `ProvisioningRequest` CR directly or through the Provisioning REST API.
