= Scale worker nodes with the O-Cloud Manager
include::_attributes/common-attributes.adoc[]
:context: ocloud-scaling-worker-nodes

toc::[]

[role="_abstract"]
After a multi-node cluster is provisioned, you can adjust its capacity by adding, removing, or replacing worker nodes by updating the `ProvisioningRequest` custom resource. The O-Cloud Manager coordinates hardware allocation, node provisioning, and cluster membership changes automatically. 

You can perform these operations by editing the `ProvisioningRequest` CR directly or through the Provisioning REST API. For more information about scaling with the Provisioning API, see "Scale worker nodes with the Provisioning API
".
