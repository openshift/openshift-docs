= Update cluster configuration with the O-Cloud Manager
include::_attributes/common-attributes.adoc[]
:context: ocloud-updating-cluster-configuration

toc::[]

[role="_abstract"]
After a cluster is provisioned, you can apply configuration changes, update firmware, and modify cluster metadata by updating the `ProvisioningRequest` custom resource (CR) or by creating a new `ClusterTemplate` CR version with updated defaults. The O-Cloud Manager detects changes and orchestrates the Day-2 operations on the running cluster. You can perform these operations by editing the `ProvisioningRequest` CR directly or through the Provisioning REST API. For more information about using the Provisioning API, see "Update cluster configuration with the Provisioning API".
