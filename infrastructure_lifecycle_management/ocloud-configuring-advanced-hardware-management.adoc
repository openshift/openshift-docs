= Configure advanced hardware management
include::_attributes/common-attributes.adoc[]
:context: ocloud-configuring-advanced-hardware-management

toc::[]

[role="_abstract"]
After provisioning clusters with a basic template, you can configure advanced hardware management to control how the O-Cloud Manager selects hosts, applies hardware profiles, and handles specific site variation. This includes defining resource selectors in the `ClusterTemplate` CR, configuring multiple node groups with distinct hardware requirements, and overriding template defaults in the `ProvisioningRequest` CR for individual deployment sites.
