= Integrating by using the syslog protocol
:context: integrate-using-syslog-protocol

toc::[]

[role="_abstract"]
Syslog is an event logging protocol that applications use to send messages to a central location, such as a SIEM or a syslog collector, for data retention and security investigations. With {product-title}, you can send alerts and audit events by using the syslog protocol.
