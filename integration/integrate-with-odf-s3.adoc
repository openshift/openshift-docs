= Integrating with {rh-storage} S3
include::modules/common-attributes.adoc[]
:context: integrate-with-odf-s3

toc::[]

[role="_abstract"]
You can integrate {product-title} with {rh-storage-first} to enable data backups to an S3-compatible storage endpoint.
You can use these backups for data restoration in the case of an infrastructure disaster or corrupt data.
{rh-storage} provides the Multicloud Object Gateway, which exposes an S3-compatible endpoint for object storage on your OpenShift cluster.
