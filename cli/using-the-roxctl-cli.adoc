= Use the roxctl CLI
:context: using-roxctl-cli

toc::[]

[role="_abstract"]
Use the `roxctl` CLI to interact with {product-title-short} for authentication, configuration, and administrative tasks.

Before you begin, configure the `ROX_ENDPOINT` environment variable to specify the host and port information for Central:

[source,terminal,subs="+quotes"]
----
$ export ROX_ENDPOINT=_<host:port>_
----

where `<host:port>` specifies the host and port information for Central.
