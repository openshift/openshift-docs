Create a {product-title} cluster or update an existing one using the CLI that is configured for AWS Spot instances.

[id="rosa-hcp-config-aws-spot-instances-cli-prerequisites"]
== Prerequisites

Before configuring Spot instances for {product-title} clusters, you must meet the following prerequisites:

* You have available AWS service quotas.
* You have enabled {product-title} in the AWS console.
* You have installed and configured the latest ROSA CLI (`rosa`) on your installation host. Run `rosa version` to see your currently installed version of the ROSA CLI. If a newer version is available, the CLI provides a link to download this upgrade.
* You have logged into your Red Hat account by using the ROSA CLI.
* You have created an OIDC configuration.
* You have verified that the AWS Elastic Load Balancing (ELB) service role exists in your AWS account.
* You have installed and configured the AWS CLI with appropriate credentials.
