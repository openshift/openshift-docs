[id="rosa-hcp-config-aws-spot-instances-terraform-prerequisites"]
== Prerequisites

Before configuring Spot instances for {product-title} clusters, you must meet the following prerequisites:

* You have installed Terraform version 1.4.6 or newer.

* You have one of the following Terraform providers:
+
** Red Hat Cloud Services: `terraform-provider-rhcs`
+
** AWS: `terraform-provider-aws`
+
This is for Enhanced mode Simple Queue Service (SQS) and EventBridge resources)

* You have the required `sqs:ReceiveMessage` and `sqs:DeleteMessage` IAM permissions. These are included in the standard `ROSANodePoolManagementPolicy`
+
You do not need any additional IAM role changes. The managed policy scopes access to SQS queues tagged with `red-hat=true`.

* (Optional): You have AWS CLI access so that you can retrieve the NodePoolManagement role ARN, if you do not already know it.
