= Cluster Operators reference
include::_attributes/common-attributes.adoc[]
:context: operator-reference

toc::[]

[role="_abstract"]
Cluster Operators are the architectural foundation for {product-title} and are installed and managed by default by the Cluster Version Operator (CVO).

Cluster administrators can view cluster Operators in the {product-title} web console from the *Administration* -> *Cluster Settings* page.

[NOTE]
====
Cluster Operators are not managed by Operator Lifecycle Manager (OLM) and the software catalog. OLM and the software catalog are part of the Operator Framework used in {product-title} for installing and running optional add-on Operators.
====

Some of the following cluster Operators can be disabled before installation. For more information see cluster capabilities.
