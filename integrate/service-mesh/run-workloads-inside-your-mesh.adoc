= Run serverless workloads inside your service mesh
include::_attributes/common-attributes.adoc[]
:context: run-workloads-inside-your-mesh

toc::[]

[role="_abstract"]
You can run {ServerlessProductShortName} workloads inside {SMProductShortName} to apply mesh-wide traffic management, mutual TLS, and network policy to your Knative services and event sources.

The {ServerlessOperatorName} uses Kourier as the default ingress for Knative, and you can use {SMProductShortName} whether you enable Kourier or disable it.

Choose the integration path that matches the version of {SMProductShortName} that you run, then isolate network traffic and bring your event sources into the mesh as needed.
