After you install the {ols-long} Operator, configure Agentic {ols-long} by creating the LLM credentials secret, the `LLMProvider`, `Agent`, and `ApprovalPolicy` custom resources (CRs), and the role-based access control (RBAC) that the agent requires. To configure classic {ols-long}, including the credentials secret and `OLSConfig` CR, see xref:../configure/ols-configuring-openshift-lightspeed.adoc#ols-configuring-openshift-lightspeed[Configuring and deploying {ols-long}].
