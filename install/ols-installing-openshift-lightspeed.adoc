After you install the {ols-long} Operator, create the role-based access control (RBAC) that the agent requires, and then configure Agentic {ols-long}. To configure and deploy Agentic {ols-long}, including the LLM credentials secret and the `LLMProvider`, `Agent`, and `ApprovalPolicy` custom resources (CRs), see xref:../configure/ols-configuring-deploying-agentic-lightspeed.adoc#ols-configuring-deploying-agentic-lightspeed[Configure and deploy Agentic {ols-long}]. To configure classic {ols-long}, including the credentials secret and `OLSConfig` CR, see xref:../configure/ols-configuring-openshift-lightspeed.adoc#ols-configuring-openshift-lightspeed[Configuring and deploying {ols-long}].
