= Install the {loki-op}

:context: install-the-loki-operator

[role="_abstract"]
The {loki-op} deploys and manages a `LokiStack` instance that serves as the log store for {logging}. You can install the {loki-op} by using the {oc-first} or the {ocp-product-title} web console.

Before installing the {loki-op}, review the xref:../discover/loki-deployment-sizing.adoc#loki-deployment-sizing[Loki deployment sizing] guidance to choose an appropriate initial size for your deployment.
