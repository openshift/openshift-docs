= Installing the Knative CLI and Workflow plugin
include::_attributes/common-attributes.adoc[]
:context: serverless-logic-install-kn-workflow-plugin-cli

toc::[]

[role="_abstract"]
{ServerlessLogicProductName} provides a plugin named `kn-workflow` for the Knative (`kn`) CLI, enabling you to set up a local workflow project by using the command line. Install the Knative (`kn`) CLI first, then install the `kn-workflow` plugin.

The Knative (`kn`) CLI does not have its own login mechanism. To log in to the cluster, you must install the OpenShift CLI (`oc`) and use the `oc login` command.
