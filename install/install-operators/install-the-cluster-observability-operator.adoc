= Install the Cluster Observability Operator
include::../_attributes/common-attributes.adoc[]
:context: install-the-cluster-observability-operator

toc::[]

[role="_abstract"]
The Cluster Observability Operator provides log visualization in the OpenShift Container Platform web console. Install the Cluster Observability Operator if you want to view and query logs under *Observe -> Logs* in the web console.

[NOTE]
====
The {coo-short} is optional. You can collect, store, and forward logs without it by using only the {loki-op} and {clo}. Install the {coo-short} only if you need the web console visualization feature.
====
