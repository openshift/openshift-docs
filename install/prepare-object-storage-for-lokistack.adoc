= Prepare object storage for LokiStack
include::_attributes/common-attributes.adoc[]
:context: prepare-object-storage-for-lokistack

toc::[]

[role="_abstract"]
After choosing your object storage backend in the Plan section, configure it and create the required Kubernetes secret before creating the `LokiStack` custom resource.

[IMPORTANT]
====
This section covers **object storage** preparation procedures. For storage backend selection and requirements planning, see xref:../plan/choose-lokistack-storage-backend.adoc#choose-lokistack-storage-backend[Choose a LokiStack storage backend].

Both block storage and object storage are mandatory:

* **Block storage (StorageClass):** For LokiStack internal PVCs (verified in prerequisites)
* **Object storage (S3-compatible):** For actual log chunks and indices (configured in this section)

The `storageClassName` field in the `LokiStack` CR refers to block storage, NOT object storage. Object storage is configured via the secret referenced in `spec.storage.secret.name`.
