= Installing {gitops-title} on non-OpenShift Kubernetes platforms
:context: installing-gitops-on-kubernetes

toc::[]

[role="_abstract"]
Install the {gitops-title} Operator on non-OpenShift Kubernetes platforms by using the OCI Helm chart published to `registry.redhat.io`. After installing the Operator, create an Argo CD instance and configure external access to the Argo CD web UI.

[id="prerequisites_{context}"]
== Prerequisites

* You have a CNCF-conformant Kubernetes cluster.
* You have access to the cluster by using the `kubectl` or `oc` CLI.
* You have installed Helm version 3.8 or later with OCI support enabled.
* You have an active Red Hat Developer account with access to `registry.redhat.io`.
* Optional: For Ingress-based access to the Argo CD web UI, you have an Ingress controller installed and configured on your cluster, for example, NGINX Ingress Controller, AWS Application Load Balancer Ingress, or Google Cloud Load Balancer Ingress.
