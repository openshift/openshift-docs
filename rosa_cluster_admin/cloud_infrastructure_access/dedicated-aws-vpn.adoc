include::_attributes/common-attributes.adoc[]
:context: dedicated-aws-vpn

toc::[]

[role="_abstract"]
Configure your Amazon Web Services (AWS) {product-title} cluster to connect to an on-site hardware VPN device.

[NOTE]
====
AWS VPN does not currently provide a managed option to apply NAT to VPN traffic. Routing all traffic, for example `0.0.0.0/0`, through a private connection is not supported. This requires deleting the internet gateway, which disables SRE management traffic.
====
