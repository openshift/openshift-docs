= Configuring private connections
include::_attributes/attributes-openshift-dedicated.adoc[]
:context: rosa-configuring-private-connections

toc::[]

[role="_abstract"]
You can configure private connections for your {product-title} cluster by using AWS VPC peering, AWS VPN, or AWS Direct Connect. These methods establish secure, dedicated network communication between your infrastructure and your cluster.
