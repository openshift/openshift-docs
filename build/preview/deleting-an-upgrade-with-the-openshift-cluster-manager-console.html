Deleting an upgrade with the OpenShift Cluster Manager console

You can use the OpenShift Cluster Manager console to delete a scheduled upgrade.

Procedure

  1. Log in to OpenShift Cluster Manager.

  2. Select the cluster with the scheduled upgrade.

  3. Click the Settings tab.

  4. In the Update status pane, click Cancel this update.

  5. Review the update details in the Cancel update dialog and click Cancel this update.

You will receive an email notification confirming that the scheduled upgrade has been canceled.
