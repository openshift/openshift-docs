= Mask sensitive annotation values in Argo CD UI
:context: masking-sensitive-annotations-in-the-argo-cd-web-ui

toc::[]

[role="_abstract"]
Mask sensitive annotation values in the Argo CD web UI to prevent accidental exposure of sensitive information. Configure which annotation keys to hide by adding them to the Argo CD custom resource (CR).

[id="prerequisites_{context}"]
== Prerequisites
* You have created an Argo CD instance. For more information, see "Installing a user-defined Argo CD instance".
