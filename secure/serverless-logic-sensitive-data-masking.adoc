= Masking sensitive data in workflow logs
include::_attributes/common-attributes.adoc[]
:context: serverless-logic-sensitive-data-masking

toc::[]

[role="_abstract"]
{product-title} includes a built-in log filter that masks sensitive data in workflow runtime logs. When request and response logging is enabled, HTTP headers such as `Authorization: Bearer <token>` can appear in plain text. You can enable and configure the sensitive data filter to prevent credentials and tokens from being written to log output.
