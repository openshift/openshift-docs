= Enable guardrails on {mcpg} 
:context: mcp-gateway-guardrails

toc::[]

[role="_abstract"]
The MCP Gateway allows integration with NeMo Guardrails available in {rhcl}. NeMo Guardrails is a collaboration between {rh} and Nvidia to deliver an enterprise-ready, open source framework that allows you to add programmable safety rails to any LLM application. The MCP Gateway integration extends its capabilities to MCP tool calls. For incoming requests to the MCP Gateway, the Gateway uses NeMo Guardrails to inspect the arguments in the request body before the proxy sends the request to a server backend. For responses, the Gateway uses the guardrails to inspect content in the tool result before sending the result back to the client. This happens independently of any authentication or authorization. Tool call traffic is checked according to guardrail configurations, a set of files that define different text classification algorithms and how they are applied.
