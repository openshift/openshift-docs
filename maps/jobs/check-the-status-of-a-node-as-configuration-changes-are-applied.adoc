= Check the status of a node as configuration changes are applied.
:context: check-the-status-of-a-node-as-configuration-changes-are-applied
:job-gap:

[role="_abstract"]
When someone updates a node so that a new machine config is created, you can view the status of the affected nodes as they update, so you can make sure there are no issues and learn when the nodes are available.
