= Change the installed disk-partition schema for new nodes.
:context: change-the-installed-disk-partition-schema-for-new-nodes
:job-gap:

[role="_abstract"]
When you want to change the install-time disk partition schema on nodes in a specific pool, you can create a machine config object, so that new nodes in that pool use the new partitioning on all the nodes.
