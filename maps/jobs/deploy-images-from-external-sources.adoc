= Deploy images from external sources
:context: deploy-images-from-external-sources
:job-gap:

[role="_abstract"]
When your applications depend on images hosted outside of OpenShift's integrated image registry, learn how to authenticate and pull from third-party registries so that you can deploy containers that are not stored in the OpenShift image registry.
