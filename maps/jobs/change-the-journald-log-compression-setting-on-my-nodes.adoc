= Change the journald log compression setting on my nodes.
:context: change-the-journald-log-compression-setting-on-my-nodes
:job-gap:

[role="_abstract"]
When you want to modify journald log compression settings on nodes in a specific pool, you can create a machine config object to configure the `Compress` setting, so that you can ensure changes are rolled out across all the nodes.
