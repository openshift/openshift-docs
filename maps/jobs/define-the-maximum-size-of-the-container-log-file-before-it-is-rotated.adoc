= Define the maximum size of the container log file before it is rotated.
:context: define-the-maximum-size-of-the-container-log-file-before-it-is-rotated
:job-gap:

[role="_abstract"]
When you want to modify the log limits on nodes in a specific pool, you can create a `KubeletConfig` object to set the `containerLogMaxSize` Kubelet parameter on those nodes.
