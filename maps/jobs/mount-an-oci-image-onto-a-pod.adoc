= Mount an OCI image onto a pod
:context: mount-an-oci-image-onto-a-pod

[role="_abstract"]
When you need to distribute large, static datasets, binaries, or specialized tools across multiple applications without rebuilding those application images, you want to mount an OCI image as a read-only volume, so that you can decouple your application code from its dependencies and simplify your CI/CD pipeline
