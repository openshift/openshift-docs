= Allow LSO to use tainted nodes by using tolerations
:context: allow-lso-to-use-tainted-nodes-by-using-tolerations
:job-gap:

[role="_abstract"]
When you have tainted nodes with local storage, you want to allow LSO to use tainted nodes by using tolerations, so that local storage can be provisioned on all appropriate nodes.
