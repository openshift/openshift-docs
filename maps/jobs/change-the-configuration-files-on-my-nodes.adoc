= Change the configuration files on my nodes.
:context: change-the-configuration-files-on-my-nodes
:job-gap:

[role="_abstract"]
When you want to modify the configuration files in the `/var` or `/etc` directory on nodes in a specific pool, you can create machine config objects that define file contents and permissions, so you can ensure consistent system-level configuration across your node pools without manual file management.
