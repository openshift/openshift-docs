= Add software or drivers not available as extensions in the base RHCOS image during cluster installation.
:context: add-software-or-drivers-not-available-as-extensions-in-the-base-rhcos-image-during-cluster-installation

[role="_abstract"]
When installing a cluster, you can add software or drivers not available as extensions in the base RHCOS image to extend the functionality of your cluster, by using a `MachineOSConfig` object during the cluster installation.
