= Manage certificates and connection encryption for cluster services
:context: manage-certificates-and-connection-encryption-for-cluster-services

[role="_abstract"]
When securing network communications within the cluster, you want to automate the issuance, renewal, and enforcement of TLS certificates, so that data-in-transit between platform services and external clients is fully encrypted and protected from interception.
