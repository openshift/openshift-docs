= Understanding how to customize the kernel behavior on my nodes to meet specific needs.
:context: understanding-how-to-customize-the-kernel-behavior-on-my-nodes-to-meet-specific-needs
:job-gap:

[role="_abstract"]
When you want to enable non-default kernel behavior on nodes in a specific pool, you can create a machine config object to add kernel arguments, so that you can enable debugging, security, or performance settings safely on those nodes.
