= Manually update the boot image on a platform: None or platform: external cluster
:context: manually-update-the-boot-image-on-a-platform-none-or-platform-external-cluster

[role="_abstract"]
When managing a cluster configured as platform: None or platform: External (such as user-provisioned infrastructure, RHACM-managed, or external provider clusters), learn how to manually update the boot image in your underlying infrastructure or node provisioning configuration so that you can ensure new nodes successfully scale up with the most current operating system version.
