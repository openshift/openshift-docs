= Enable specific troubleshooting tools by configuring SE Linux permissive mode.
:context: enable-specific-troubleshooting-tools-by-configuring-se-linux-permissive-mode
:job-gap:

[role="_abstract"]
When you want to configure Security Enhanced Linux (SELinux) permissive mode on nodes in a specific pool, you can create a machine config object to set the `enforcing` kernel parameter, so that you can configure SELinux permissive mode on those nodes to enable certain troubleshooting.
