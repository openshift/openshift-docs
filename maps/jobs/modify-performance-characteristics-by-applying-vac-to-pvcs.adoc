= Modify performance characteristics by applying VAC to PVCs

[role="_abstract"]
When you need to optimize storage performance, you may want to modify performance characteristics by applying Volume Attribute Classes (VAC) to PVCs, so that you can adjust performance parameters without reprovisioning volumes.
