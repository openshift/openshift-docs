= Reduce image pull time for operations that require a pull, such as cluster updates or application deployments.
:context: reduce-image-pull-time-for-operations-that-require-a-pull-such-as-cluster-updates-or-application-deployments

[role="_abstract"]
When you need to reduce pod startup time for frequently-used images, you can use a `PinnedImageSet` to pin container images to a machine config pools, so you can reduce image pull time and ensure critical images are always available locally to the nodes in that pool.
