= Add pre-packaged software that is not in the base RHCOS to my nodes.
:context: add-pre-packaged-software-that-is-not-in-the-base-rhcos-to-my-nodes
:job-gap:

[role="_abstract"]
When you want to add pre-packaged software that is not in the base RHCOS on nodes in a specific pool, you can create a machine config object to enable certain RHEL extensions, so you can add supported functionality like USB device control or specialized kernel modules without compromising cluster supportability across all the nodes.
