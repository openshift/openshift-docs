= Replace failed bare-metal control plane nodes without BMC credentials
:context: replace-failed-bare-metal-control-plane-nodes-without-bmc-credentials

[role="_abstract"]
When a bare-metal control plane node suffers a hardware failure and out-of-band management access is unavailable, you want to manually provision a replacement host and re-integrate it into the existing etcd quorum, so that you can restore high availability and cluster consensus without needing remote power management credentials.
