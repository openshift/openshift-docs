= Change the installed RAID configuration for new nodes.
:context: change-the-installed-raid-configuration-for-new-nodes

[role="_abstract"]
When you want to change the RAID configuration on nodes in a specific pool, you can use a machine config, so that new nodes in that pool use the new configuration.
