= Disable/enable storage on vSphere
:context: disable-enable-storage-on-vsphere

[role="_abstract"]
When you need to perform vSphere storage maintenance or troubleshoot storage issues, you want to disable and re-enable storage provisioning, so that you can control when new persistent volumes can be created and safely perform infrastructure changes.
