= Run background tasks on a node with daemonsets
:context: run-background-tasks-on-a-node-with-daemonsets

[role="_abstract"]
When you need to save time by automating certain tasks across nodes, you want to create shared storage, run a logging pod on each node, or deploy a monitoring agent on each node using DaemonSets that ensure a node is running a copy of a pod meant to perform one of those tasks so you don’t need to manually create those pods.
