= Manually update the boot image on a bare-metal cluster
:context: manually-update-the-boot-image-on-a-bare-metal-cluster

[role="_abstract"]
When managing a bare-metal cluster installed with OpenShift Container Platform version 4.9 or earlier, learn how to migrate the node provisioning configuration from the legacy qcow2-based method to the current machine-os-images method so that you can ensure new nodes successfully scale up using the latest release version as the boot image without skew risks.
