= Adjust maximum number of pods on a node
:context: adjust-maximum-number-of-pods-on-a-node

[role="_abstract"]
When your node hardware resources (CPU/RAM) are disproportionately large compared to the footprint of your microservices, you want to increase the maximum pod per node limit, so that you can fully utilize your hardware investment and scale your application horizontally without being artificially throttled by default orchestrator constraints.
