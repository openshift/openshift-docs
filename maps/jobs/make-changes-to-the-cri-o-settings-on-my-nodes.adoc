= Make changes to the CRI-O settings on my nodes.
:context: make-changes-to-the-cri-o-settings-on-my-nodes

[role="_abstract"]
When you want to modify the CRI-O configuration on nodes in a specific pool, you can create a `ContainerRuntimeConfig` object, so that you can change CRI-O settings such as the log levels, Overlay size, and container runtime on those nodes.
