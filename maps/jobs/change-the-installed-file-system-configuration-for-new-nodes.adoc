= Change the installed file system configuration for new nodes.
:context: change-the-installed-file-system-configuration-for-new-nodes
:job-gap:

[role="_abstract"]
When you want to change the install-time file system configuration on nodes in a specific pool, you can create a machine config object, so that new nodes in the pool use the new configuration.
