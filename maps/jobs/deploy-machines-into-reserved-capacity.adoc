= Deploy machines into reserved capacity
:context: deploy-machines-into-reserved-capacity

[role="_abstract"]
When you have a planned workload that needs resources with specific parameters, you want to deploy machines into capacity that you have reserved with your cloud provider so that your workload can be deployed as required.
