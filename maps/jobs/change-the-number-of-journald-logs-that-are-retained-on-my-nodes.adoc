= Change the number of journald logs that are retained on my nodes.
:context: change-the-number-of-journald-logs-that-are-retained-on-my-nodes
:job-gap:

[role="_abstract"]
When you want to control the number of journald logs on nodes in a specific pool, you can create a machine config object that sets the log lifetime value, so that you can ensure changes are rolled out across all the nodes.
