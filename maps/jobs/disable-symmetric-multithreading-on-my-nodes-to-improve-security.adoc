= Disable symmetric multithreading on my nodes to improve security
:context: disable-symmetric-multithreading-on-my-nodes-to-improve-security
:job-gap:

[role="_abstract"]
When you want to disable multithreading on nodes in a specific pool, you can create a machine config object to disable symmetric multithreading (SMT), so that you can improve security on those nodes.
