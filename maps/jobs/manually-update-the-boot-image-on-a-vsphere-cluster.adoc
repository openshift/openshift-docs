= Manually update the boot image on a vSphere cluster
:context: manually-update-the-boot-image-on-a-vsphere-cluster

[role="_abstract"]
When managing a cluster deployed on VMware vSphere, learn how to manually upload the latest Red Hat Enterprise Linux CoreOS (RHCOS) OVA image to the vSphere vCenter to create a virtual machine template and configure your machine sets to use it so that you can ensure new nodes successfully scale up with the most current operating system version.
