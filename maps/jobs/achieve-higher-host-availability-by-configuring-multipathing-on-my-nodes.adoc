= Achieve higher host availability by configuring multipathing on my nodes.

[role="_abstract"]
When you want to configure multipathing on nodes in a specific pool, you can create a machine config object to configure the Device Mapper (DM) Multipath framework, so that you can achieve higher host availability and stronger resilience against hardware failure on those nodes.
