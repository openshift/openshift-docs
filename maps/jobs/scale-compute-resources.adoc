= Scale compute resources
:context: scale-compute-resources

[role="_abstract"]
When application load increases or decreases, you want to scale the number of worker machines (nodes) dynamically or manually so you can ensure your cluster has adequate compute resources to handle demand and manage cloud/hardware costs effectively. Covers HPA and VPA.
