= Install CIFS/SMB CSI Driver Operator
:context: install-cifs-smb-csi-driver-operator

[role="_abstract"]
When you need to access Windows file shares, you want to install CIFS/SMB CSI Driver Operator, so that you can mount SMB shares in pods.
