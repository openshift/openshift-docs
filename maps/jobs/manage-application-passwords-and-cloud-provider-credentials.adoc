= Manage application passwords and cloud provider credentials
:context: manage-application-passwords-and-cloud-provider-credentials

[role="_abstract"]
When deploying applications that require external access, you want to centralize the management and rotation of secrets, so that workloads can authenticate securely without exposing plaintext passwords or cloud credentials in source code.
