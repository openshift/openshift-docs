= Configure a cluster to use an external registry
include::_attributes/common-attributes.adoc[]
:context: configure-a-cluster-to-use-an-external-registry
:chunk-to-content:

[role="_abstract"]
When you have a cluster that you installed without an external registry, you can configure it to use a mirror registry in your environment, so that you can manage your own release images and install more Operators than were initially available at deployment.
