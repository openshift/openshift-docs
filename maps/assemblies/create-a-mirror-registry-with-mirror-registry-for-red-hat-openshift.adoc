When you need to create a local container registry for disconnected environments, you can deploy mirror registry for Red{nbsp}Hat OpenShift to have a supported registry solution that meets your mirroring needs. The _mirror registry for Red{nbsp}Hat OpenShift_ is a small and streamlined container registry that you can use as a target for mirroring the required container images of {product-title} for disconnected installations.
