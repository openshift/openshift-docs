= Mirror images to a mirror registry using the oc adm release mirror command
include::_attributes/common-attributes.adoc[]
:context: mirror-images-to-a-mirror-registry-using-the-oc-adm-release-mirror-command
:chunk-to-content:

[role="_abstract"]
When preparing for a disconnected installation, you can mirror {product-title} release images and Operator catalogs to your local registry by using the `oc adm release mirror` command. You can ensure your clusters only use container images that satisfy your organizational controls on external content. Before you install a cluster on infrastructure that you provision in a restricted network, you must mirror the required container images into that environment.
