= Migrate from oc-mirror v1 to v2
include::_attributes/common-attributes.adoc[]
:context: migrate-from-oc-mirror-v1-to-v2
:chunk-to-content:

[role="_abstract"]
When you have images mirrored to your disconnected environment using the deprecated oc-mirror plugin v1, you can migrate your environment to use the oc-mirror plugin v2 for your mirroring operations, so that you can update clusters and OLM Operator catalogs without internet access. The oc-mirror v2 plugin introduces major changes to image mirroring workflows. Understand the migration process and check for compatibility with oc-mirror plugin v2 to ensure a successful migration.
