= Mirror images to a mirror registry using oc-mirror v2
include::_attributes/common-attributes.adoc[]
:context: mirror-images-to-a-mirror-registry-using-oc-mirror-v2
:chunk-to-content:

[role="_abstract"]
When preparing for a disconnected installation, you can mirror {product-title} release images and Operator catalogs to your local registry by using the oc-mirror plugin v2. You can run your cluster in a disconnected environment if you install the cluster from a mirrored set of {product-title} container images in a private registry. This registry must be running whenever your cluster is running.
