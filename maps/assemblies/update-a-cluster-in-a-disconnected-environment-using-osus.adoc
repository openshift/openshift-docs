[role="_abstract"]
When you need to update your disconnected cluster, you can use a local OpenShift Update Service (OSUS) instance to provide update recommendations and manage cluster updates without internet access. You can install and configure OSUS in a disconnected environment to get an update experience similar to the connected clusters.
