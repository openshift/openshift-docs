= Mirror images to a mirror registry using oc-mirror v1
include::_attributes/common-attributes.adoc[]
:context: mirror-images-to-a-mirror-registry-using-oc-mirror-v1
:chunk-to-content:

[role="_abstract"]
When preparing for a disconnected installation, you can mirror {product-title} release images and Operator catalogs to your local registry by using the oc-mirror plugin v1. You can run your cluster in a restricted network by installing from a mirrored set of {product-title} container images in a private registry. This registry must be running whenever the cluster is running.
