= Install a cluster without an external registry
include::_attributes/common-attributes.adoc[]
:context: install-a-cluster-without-an-external-registry
:chunk-to-content:

[role="_abstract"]
When you need to deploy a cluster in a disconnected environment, you can install the cluster without having to set up a mirror registry and mirror images to the registry, so that you can quickly deploy a cluster without internet access. You can deploy an {product-title} cluster without the need for an external image registry, either in a connected or disconnected environment. This installation method uses a simplified user interface and self-contained media to facilitate the installation.
