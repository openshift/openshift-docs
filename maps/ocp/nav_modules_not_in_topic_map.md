## Method

* Topic map: 1833 `File:` entries (1819 unique) -> 1819 assemblies -> 7168 distinct modules.
* Nav map: 23 category maps -> 900 wired job maps -> 4359 distinct modules.
  (969 job map files exist under `maps/ocp-jobs/`; the rest are not wired into a category map
  and are therefore out of scope here.)
* Raw difference (nav minus topic map): 492 modules.
* Matching is conservative: any live `include::modules/...` in a topic-map
  assembly counts as referenced, regardless of `ifdef`/`ifeval` guards.
  Commented-out includes do not count.
* Excluded as JTBD-era (the module's adding commit is one of the 49 commits
  that touched `maps/ocp/` or `maps/ocp-jobs/`; computed without `--follow`, so a file
  git scores as a rename of older content still counts as newly added here):
  - 452 intro concept (first include of a job map)
* **Remaining findings: 40**
