= GitOps Console features and troubleshooting
:context: gitops-console-features-troubleshooting

toc::[]

The {gitops-shortname} Console plugin provides features for filtering, searching, and paginating resources, viewing graphical layouts, and troubleshooting common issues. These features help you work efficiently with GitOps resources in the {product-title} web console.

.Prerequisites

* You have installed the {gitops-title} Operator.
* You have enabled the {gitops-shortname} Console plugin. For more information, see xref:../argocd_applications/gitops-console-plugin-setup.adoc#gitops-console-plugin-setup[GitOps Console plugin setup and configuration].
