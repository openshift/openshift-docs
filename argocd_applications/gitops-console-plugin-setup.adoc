= GitOps Console plugin setup and configuration
:context: gitops-console-plugin-setup

toc::[]

The {gitops-shortname} Console plugin extends the {product-title} web console with GitOps resource management capabilities. You can enable the plugin through the web console or CLI to view and manage Argo CD Applications, ApplicationSets, AppProjects, ImageUpdaters, and Argo Rollouts.
