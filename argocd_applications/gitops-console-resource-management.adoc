= GitOps Console resource management
:context: gitops-console-resource-management

toc::[]

The {gitops-shortname} Console plugin provides dedicated pages for viewing and managing GitOps resources. You can create, view, and manage Argo CD Applications, ApplicationSets, AppProjects, ImageUpdaters, and Argo Rollouts through the {product-title} web console.

.Prerequisites

* You have installed the {gitops-title} Operator.
* You have enabled the {gitops-shortname} Console plugin. For more information, see xref:../argocd_applications/gitops-console-plugin-setup.adoc#gitops-console-plugin-setup[GitOps Console plugin setup and configuration].
