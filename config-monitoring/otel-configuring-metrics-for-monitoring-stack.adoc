= Configuring metrics for the monitoring stack
:context: otel-configuring-metrics-for-monitoring-stack

toc::[]

[role="_abstract"]
You can configure the in-cluster monitoring stack to send its metrics to the OpenTelemetry Collector by using remote write. Alternatively, you can configure the Collector to scrape the metrics from the federation endpoint of the monitoring stack. You can also configure a Prometheus `ServiceMonitor` CR for scraping the Collector pipeline metrics and enabled Prometheus Exporter.
